كتالوج الإضافات (Plugins)

إضافات Hermes التي يمكنك تثبيتها بالاسم عبر أمر واحد. الإضافات الرسمية يصدرها فريق Hermes، والمجتمعية يساهم بها المستخدمون ويراجعها الفريق قبل إدراجها.

معلومة

القائمة أدناه تعكس الكتالوج وقت إعداد هذه الترجمة. للاطلاع على أحدث نسخة تفاعلية راجع صفحة الإضافات الرسمية (بالإنجليزية). ولمعرفة طريقة الإضافة والتثبيت راجع كتالوج الإضافات ونظام الإضافات.

hermes-telegram-businessرسمية

وضع Telegram Business بأسلوب المراقبة مع الموافقة (بوت سكرتير): كل رد مقترح على العميل يحتاج موافقة المالك قبل إرساله.

hermes plugins install hermes-telegram-business

plugin-llm-async-exampleرسمية

إضافة مرجعية غير متزامنة لـ ctx.llm، تسجّل الأمر /translate وتنفّذ الترجمة ذهابًا وإيابًا بالتوازي عبر acomplete().

hermes plugins install plugin-llm-async-example

plugin-llm-exampleرسمية

إضافة مرجعية توضّح وصول LLM المنظّم الذي يديره المضيف عبر ctx.llm.complete_structured()، وتسجّل الأمر /receipt-extract.

hermes plugins install plugin-llm-example

snykرسمية

فحص الكود (SAST) والاعتماديات وصور الحاويات والبنية التحتية كشيفرة وملفات SBOM عبر خادم MCP الرسمي لـ Snyk، مع مهارة snyk-security-scan. يحتاج Node.js و npm وحساب Snyk مجاني.

hermes plugins install snyk

touchdesignerرسمية

تشغيل جلسة TouchDesigner حيّة عبر خادم twozero MCP، مع مهارة touchdesigner-mcp. يعمل TouchDesigner نفسه على macOS و Windows.

hermes plugins install touchdesigner

herdr-auto-reconcileمجتمعية

ينبّه Hermes عندما تحتاج أجزاء Herdr المسموح بها إلى مُطابقة، دون التحكم في عملها أو توجيهها.

hermes plugins install herdr-auto-reconcile

hermes-plugin-chrome-profilesمجتمعية

تبديل أدوات المتصفح في Hermes بين ملفات Chrome و Edge المحلية والبعيدة عبر CDP. (أداة واحدة)

hermes plugins install hermes-plugin-chrome-profiles

hermes-plugin-netboxمجتمعية

إدارة التغييرات في NetBox: الاستعلام عن كائنات DCIM و IPAM، وبناء diff مراجَع على مستوى الحقول، والتطبيق مع سجل وإمكانية التراجع. (5 أدوات)

hermes plugins install hermes-plugin-netbox

hermes-rustpush-imessageمجتمعية

إضافة منصة iMessage محلية بالكامل تعتمد على sidecar من OpenBubbles RustPush يديره launchd عبر Unix socket لنفس المستخدم.

hermes plugins install hermes-rustpush-imessage

hermes-snapcompactمجتمعية

محرّك سياق Snapcompact: يؤرشف تاريخ المحادثة كإطارات PNG نقطية كثيفة تقرأها نماذج الرؤية بثلث تكلفة الـ tokens تقريبًا.

hermes plugins install hermes-snapcompact

jackal-verifiedمجتمعية

محوّل مكتوب الأنواع لإصدار JACKAL v1.7.3 القابل لإعادة الإنتاج: 41 أداة تحقق مشتقة من الكتالوج (تحقق دقيق وعددي ومسارات محدودة مدقّقة بـ Lean وإعادة تشغيل الادعاءات).

hermes plugins install jackal-verified
