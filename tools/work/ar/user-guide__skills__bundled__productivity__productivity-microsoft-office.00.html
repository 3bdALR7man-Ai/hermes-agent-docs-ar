مهارة Microsoft Office

أنشئ ملفات Word (.docx) و PowerPoint (.pptx) و Excel (.xlsx, .csv) واقرأها وحرّرها واعمل عليها بالقوالب دون اتصال بالإنترنت، باستخدام أدوات CLI صغيرة بلغة Python مبنية على python-docx و python-pptx و openpyxl. لا حاجة إلى Office نفسه إطلاقًا. لا تفتح هذه المهارة الصيغ الثنائية القديمة (.doc, .ppt, .xls) ولا تعرض الصفحات دون LibreOffice.

اختر الصيغة، ثم اقرأ المرجع الخاص بها باستخدام skill_view قبل البدء بالعمل:

المتطلبات الأساسية

  • Python 3.10+ مع python-docx و python-pptx و openpyxl (أسماء الاستيراد docx و pptx و openpyxl).

  • اختر المفسّر (interpreter) باستخدام terminal. استخدم python إذا كان يستورد المكتبات أصلًا (تأتي مثبّتة في صورة Docker الخاصة بـ Hermes). وإلا، فعندما يكون hermes على PATH، دع Hermes يبني بيئة المستندات المشتركة والمثبّتة الإصدارات تحت مجلد Hermes الرئيسي: تبقى بعد إعادة تشغيل الحاويات، ولا تمسّ تثبيت Hermes نفسه، ويمكن تشغيلها بأمان من عدة وكلاء في آن واحد. وعندما لا يكون كذلك (الطرفية تعمل داخل sandbox من Docker لا يوجد فيه Hermes)، يبني الـ block بيئة venv في المجلد الرئيسي للـ sandbox بالإصدارات المثبّتة نفسها. استخدم هذا الـ block نفسه حرفيًا في كل مهارة مستندات كي تشترك كلها في بيئة واحدة:

    شغّل كل أداة مساعدة باستخدام "$PY". في PowerShell (يعمل Hermes على ذلك المضيف، ولذلك يكون على PATH): $env:PY = hermes pm environment documents --extra documents --extra documents-pdf. لا تنفّذ pip install أبدًا في المفسّر الذي يشغّل Hermes ولا في مفسّر hermes pm environment؛ فكلاهما يديره Hermes.

  • اختياري: LibreOffice (soffice) لتصدير PDF وإعادة حساب Excel وعرض الشرائح، إضافةً إلى poppler (pdftoppm أو pdftocairo) لإنتاج صور PNG للشرائح. تُبلغ الأدوات المساعدة التي تحتاج إليها بما هو ناقص وتنتهي بالرمز 0.

طريقة التشغيل

توجد كل أداة مساعدة في scripts/، وهي CLI مبنية على argparse وتدعم --help، وتطبع JSON إلى stdout، وتنتهي برمز غير صفري عند الفشل. شغّلها باستخدام terminal من مجلد المهارة. اكتب مواصفات JSON باستخدام write_file؛ واقرأ النتائج باستخدام read_file أو مباشرةً من stdout.

الإجراء

  1. حدّد الصيغة من امتداد الملف أو من الطلب، وحمّل مرجعها (skill_view مع file_path=references/<format>.md).
  2. اضبط PY باستخدام block المتطلبات الأساسية مرة واحدة لكل جلسة.
  3. أنشئ أو حرّر أو اقرأ باستخدام الأدوات المساعدة الخاصة بتلك الصيغة؛ ومرّر مسار إخراج للإبقاء على الأصل كلما كانت الأداة تدعم ذلك.
  4. تحقق من النتيجة كما يوضح قسم Verification في المرجع، ثم أعطِ المستخدم مسار الإخراج الدقيق.

التحويل إلى PDF

عند تثبيت LibreOffice، حوّل دون واجهة (headless):

تحقق أولًا باستخدام command -v soffice || command -v libreoffice. الخطوط غير الموجودة على المضيف يُستعاض عنها بغيرها، ولذلك افحص العروض بعد عرضها (render) قبل تسليمها. لا يوجد مسار بلغة Python وحدها للتحويل إلى PDF لأي من هذه الصيغ: فإذا كان soffice غير موجود، أبلغ بذلك بدلًا من التقريب. وبالنسبة إلى الأوراق الأخرى استخدم xlsx_to_csv.py --sheet NAME.

المزالق

  • لا تفك الضغط وتحرّر XML مباشرةً أبدًا. هذه الملفات حزم zip؛ والاستبدال النصي الخام يفسدها. حرّر عبر الأدوات المساعدة (أو المكتبات) واستخدم patch/write_file لمدخلات JSON فقط.
  • يتجزأ النص إلى مقاطع (runs). يجزّئ Word و PowerPoint النص عند حدود التحرير؛ وتدمج أدوات الاستبدال المقاطع المتساوية التنسيق أولًا، لكن أي تطابق يمتد عبر مقاطع مختلفة التنسيق يأخذ تنسيق المقطع الأول.
  • لا شيء يحسب الحقول أو الصيغ. حقول جدول المحتويات/الصفحات في Word وصيغ Excel يملؤها تطبيق Office عند الفتح (أو xlsx_recalc.py).
  • الترميز. اكتب المواصفات بترميز UTF-8؛ فالأدوات المساعدة تقرأ UTF-8 صراحةً.
  • المزالق الخاصة بكل صيغة موجودة في مرجعها.

التحقق

  • أعد قراءة كل ناتج باستخدام أداة القراءة الخاصة بالصيغة، وتأكد من وجود المحتوى المتوقع ومن اختفاء المحتوى القديم.
  • Word: ينتهي docx_validate.py out.docx بالرمز 0 بعد إجراء تعديل على المراجعات أو التعليقات أو الحقول.
  • PowerPoint: اعرض الشرائح باستخدام pptx_render.py وافحص كل صورة PNG باستخدام vision_analyze عند توفر أدوات العرض.
  • Excel: يسرد xlsx_read.py --formulas الصيغ المكتوبة؛ وشغّل xlsx_recalc.py عندما تهمّ القيم المخزّنة مؤقتًا.
  • الاختبارات المضمّنة هي العقد الكامل: "$PY" -m pytest tests/ -q (يحتاج إلى pytest في ذلك المفسّر).
