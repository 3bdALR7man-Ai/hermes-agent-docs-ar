Darwinian Evolver

شغّل أداة darwinian_evolver من Imbue — وهي حلقة بحث تطوري (evolutionary search loop) مدفوعة بـ LLM — لتحسين prompt أو تعبير نمطي (regex) أو استعلام SQL، أو مقتطف كود صغير وفق دالة لياقة (fitness function).

الحالة: هذه المهارة غلاف رقيق حول الأداة الأصلية (upstream). تقوم المهارة بتثبيتها، وترشد الوكيل خلال كتابة تعريف Problem (organism + evaluator + mutator)، وتدير الحلقة عبر CLI الأصلية أو عبر برنامج تشغيل Python صغير مخصّص.

الترخيص: الأداة الأصلية مرخّصة بـ AGPL-3.0. تستدعيها المهارة فقط عبر CLI الأصلية أو عبر استدعاء subprocess/uv run (مجرد تجميع/aggregation). لا تستورد أصناف (classes) الأداة الأصلية داخل Hermes نفسه.

متى تُستخدم

  • يقول المستخدم "حسّن هذا الـ prompt"، أو "طوّر تعبيرًا نمطيًا (regex) لكذا"، أو "حسّن هذا الكود/SQL تلقائيًا"، أو "ابحث عن تعليمة أفضل".
  • لديك مقيِّم (تطابق تام، معدل نجاح regex، اختبار وحدة، حَكَم LLM، مقياس وقت تشغيل) بالإضافة إلى مرشّح بداية (organism). إن لم يكن لديك مقيِّم، توقف وعرّف واحدًا أولًا — فهذا هو الجزء الصعب.
  • التكلفة مقبولة: تتراوح التشغيلة النموذجية بين 50 و500 استدعاء LLM. على gpt-4o-mini هذا لا يتجاوز سنتات؛ وعلى Claude Sonnet قد يبلغ بضعة دولارات.

لا تستخدم هذه المهارة عندما:

  • يكون هدف التحسين قابلًا للاشتقاق (differentiable) (استخدم الانحدار التدريجي / DSPy).
  • تحتاج فقط تجربة 2-3 صيغ — اكتبها يدويًا مباشرةً.
  • تكون إشارة اللياقة (fitness) ذاتية بحتة دون معيار قابل للقياس.

تعريف مسألة مخصّصة

تُرفق المهارة templates/custom_problem_template.py — انسخه، عدّله، شغّله. عليك تعريف ثلاثة أشياء:

  1. Organism — صنف فرعي من BaseModel الخاص بـ Pydantic يحمل القطعة (artifact) قيد التطور (prompt_template: str، regex_pattern: str، sql_query: str، code_block: str، إلخ). أضف طريقة run(*args) تُشغِّلها.

  2. Evaluator — .evaluate(organism) -> EvaluationResult(score=..., trainable_failure_cases=[...], holdout_failure_cases=[...], is_viable=True).

    • score يقع ضمن [0, 1]. الأعلى أفضل.
    • trainable_failure_cases — ما يراه المُطفِّر (mutator). أدرج سياقًا كافيًا (المُدخل، المتوقَّع، الفعلي) ليتمكن LLM من التشخيص.
    • holdout_failure_cases — تُبقى بعيدة عن نظر المُطفِّر. استخدمها لكشف الإفراط في المطابقة (overfitting).
    • is_viable=True ما لم يكن الكائن (organism) معطوبًا تمامًا (يرفع استثناءً، يُرجع None، إلخ). كائن صالح بدرجة 0 أمر مقبول — سيُخفَّض وزنه فقط عند اختيار الآباء (parent selection).

  3. Mutator — .mutate(organism, failure_cases, learning_log_entries) -> list[Organism]. عادةً: ابنِ prompt لـ LLM يتضمّن الكائن الحالي + حالة فشل + طلب اقتراح إصلاح؛ حلّل استجابة LLM؛ أرجِع Organism جديدًا. أرجِع [] عند فشل التحليل — تتكفّل الحلقة بالباقي.

ثم اكتب سكربت تشغيل يربط Problem(initial_organism, evaluator, [mutators]) بـ EvolveProblemLoop ويكرّر عبر loop.run(num_iterations=N) — يُعد scripts/parrot_openrouter.py المُرفَق المرجع لذلك.

المزالق

  1. Initial organism must be viable — يجب أن يكون الكائن الأولي صالحًا: اضبط is_viable=True في EvaluationResult حتى مع بذرة بدرجة 0. ترفض الحلقة الكائنات غير الصالحة لأنها تعني أن الحلقة ليس لديها ما تتطوّر منه.
  2. مرشِّحات محتوى المزوّد تُفشل التشغيلات. ترفض نماذج OpenRouter المدعومة بـ Azure عبارات مثل "ignore previous instructions" بخطأ HTTP 400. لُفّ استدعاء LLM بـ try/except وأرجِع f"<LLM_ERROR: {e}>" — سيمنح المُطوِّر (evolver) ذلك الكائن درجة 0 فقط ويتابع.
  3. loop.run() عبارة عن مولِّد (generator) — استدعاؤه لا يُشغِّل شيئًا حتى تكرّر عليه. استخدم for snap in loop.run(num_iterations=N):.
  4. اللقطات (snapshots) عبارة عن ملفات pickle متداخلة. يحتوي iteration_N.pkl على قاموس فيه population_snapshot (المزيد من بايتات pickle). لفكّ الترميز يجب أن يكون صنف Organism قابلًا للاستيراد ضمن نفس المسار المنقّط الذي رُمِّز به.
  5. إعدادات التزامن الافتراضية عدوانية. 10/10 ستصطدم بحدود المعدل لدى معظم المزوّدين. ابدأ بـ 2/2.
  6. CLI مُقيَّدة على Anthropic. يعتمد uv run darwinian_evolver <problem> على ANTHROPIC_API_KEY ويستخدم Claude Sonnet. لاستخدام أي مزوّد آخر، اكتب برنامج تشغيل مثل parrot_openrouter.py.
  7. AGPL. لا تكتب أبدًا from darwinian_evolver import ... داخل نواة Hermes. سكربتات التشغيل المخصّصة تحت ~/.hermes/skills/... جانب المستخدم ومقبولة.
  8. لا توجد حزمة PyPI. سيجلب pip install darwinian-evolver الحزمة الخاطئة. ثبّت دائمًا من مستودع GitHub.
