البحث عن GIF (عبر Tenor API)

ابحث عن ملفات GIF وحمّلها مباشرة عبر Tenor API باستخدام curl. لا حاجة لأدوات إضافية.

متى تُستخدم

مفيدة للعثور على ملفات GIF لردود الفعل، وإنشاء محتوى بصري، وإرسال ملفات GIF في المحادثة.

الإعداد

اضبط مفتاح Tenor API الخاص بك في بيئتك (أضفه إلى ${HERMES_HOME:-~/.hermes}/.env):

احصل على مفتاح API مجاني من https://developers.google.com/tenor/guides/quickstart — مفتاح Tenor API من Google Cloud Console مجاني وله حدود معدل (rate limits) سخية.

المتطلبات المسبقة

  • curl وjq (كلاهما قياسي على macOS/Linux)
  • متغير البيئة TENOR_API_KEY

معاملات API

المعاملالوصف
qاستعلام البحث (رمّز المسافات كـ +)
limitالحد الأقصى للنتائج (1-50، الافتراضي 20)
keyمفتاح API (من متغير البيئة $TENOR_API_KEY)
media_filterصيغ الفلترة: gif, tinygif, mp4, tinymp4, webm
contentfilterالأمان: off, low, medium, high
localeاللغة: en_US, es, fr, وغيرها

صيغ الوسائط المتاحة

لكل نتيجة صيغ متعددة تحت .media_formats:

الصيغةحالة الاستخدام
gifGIF بجودة كاملة

mp4نسخة فيديو (حجم ملف أصغر)
tinymp4معاينة فيديو صغيرة
webmفيديو WebM
nanogifصورة مصغّرة صغيرة جدًا
