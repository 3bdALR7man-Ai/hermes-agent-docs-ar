صيغة نتائج البحث

تتضمن كل نتيجة:

  • id و session_id و role و timestamp
  • snippet — مقتطف مُولَّد من FTS5 بعلامات >>>match<<< لتحديد المطابقات
  • context — رسالة واحدة قبل وبعد المطابقة (يُقتَطع المحتوى إلى 200 حرف)
  • source و model و session_started — من الجلسة الأصل

تتعامل الدالة _sanitize_fts5_query() مع الحالات الخاصة:

  • إزالة علامات الاقتباس غير المتطابقة والأحرف الخاصة
  • إحاطة المصطلحات ذات الشرطات بعلامات اقتباس (chat-send → "chat-send")
  • إزالة عوامل التشغيل المنطقية المعلَّقة (hello AND → hello)

التصدير والتنظيف

موقع قاعدة البيانات

المسار الافتراضي: get_hermes_home() / "state.db" — ~/.hermes/state.db للـ profile الافتراضي، و ~/.hermes/profiles/<name>/state.db للـ profile المسمّى، أو أي مكان تشير إليه قيمة HERMES_HOME (راجع مجلد Hermes الرئيسي وعزل profiles).

يُنشَأ ملف قاعدة البيانات وملف WAL (state.db-wal) وملف الذاكرة المشتركة (state.db-shm) جميعها في نفس المجلد.
