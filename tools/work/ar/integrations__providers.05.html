Perplexity

مفيد عندما تريد نموذجًا يجري البحث الحي في الويب ويضيف الاستشهادات تلقائيًا. يفرض قيودًا صارمة على النماذج المتاحة — راجع perplexity.ai/settings/api للقائمة الحالية.

تحجز Agent API في Perplexity (api: https://api.perplexity.ai/v1 مع api_mode: codex_responses) اسمَي الدالتين web_search, search_files, fetch_url, people_search و finance_search لأدواتها المدمجة الخاصة. ويعيد Hermes تسمية أدوات العميل لديه ذات الاسم نفسه إلى hermes_<name> عند النقل، ويعيد ربطها قبل التوزيع، في حلقة الوكيل الرئيسية والاستدعاءات المساعدة (توليد العنوان، والضغط، وتجميع MoA) على السواء — وهي المعالجة نفسها التي تتلقاها endpoints /v1/responses في OpenCode.

استضافة Firecrawl ذاتيًا

يستخدم Hermes افتراضيًا Firecrawl cloud API للبحث في الويب واستخراج بياناته. إذا كنت تفضّل تشغيل Firecrawl محليًا، يمكنك توجيه Hermes إلى نسخة مستضافة ذاتيًا بدلًا منها. راجع SELF_HOST.md في Firecrawl لتعليمات الإعداد الكاملة.

ما تحصل عليه: لا حاجة إلى مفتاح API، ولا حدود معدل، ولا تكلفة لكل صفحة، وسيادة كاملة على البيانات.

ما تفقده: تستخدم النسخة السحابية "Fire-engine" المملوك لـ Firecrawl لتجاوز أنظمة مكافحة الروبوتات المتقدمة (Cloudflare، و CAPTCHAs، وتدوير IP). وتستخدم النسخة المستضافة ذاتيًا fetch أساسيًا + Playwright، لذا قد تفشل بعض المواقع المحمية. ويستخدم البحث DuckDuckGo بدل Google.

ملاحظات:

  • min_coding_score لا يُرسَل إلا عندما تكون model.model هي openrouter/pareto-code. ولا تؤثر القيمة مع أي نموذج آخر.
  • اضبطه على سلسلة فارغة (أو أزل السطر) ليختار OpenRouter أقوى نموذج برمجة متاح — وهو سلوكه الموثَّق عند إغفال كتلة الإضافات.
  • الاختيار حتمي لكل درجة في يوم معين، لكن النموذج المختار فعليًا قد يتغير بتحرك حد Pareto (نماذج جديدة، وتحديثات المعايير).
  • راجع وثائق Pareto Router في OpenRouter لسلوك الموجّه الكامل.
  • لاستخدام موجّه Pareto Code في مهمة مساعدة محددة (الضغط، والرؤية، وغيرها) بدل الوكيل الرئيسي، اضبط extra_body.plugins ضمن تلك المهمة — راجع النماذج المساعدة → توجيه OpenRouter & Pareto Code للمهام المساعدة.

العنصر الذي يسمّي كتلة providers.<name> (provider: my-relay أو provider: custom:my-relay) يرث transport / api_mode لتلك الكتلة حين لا يحدد العنصر قيمة، كي يحتفظ وسيط خاص بـ Responses أو Anthropic-Messages بصيغة نقله المعلنة عند التبديل الاحتياطي. اضبط api_mode في العنصر لتجاوزها.
