تشغيل Hermes على Android باستخدام Termux

Termux لا يعمل حاليًا

حزمة Termux لا تعمل الآن. يجري إعداد إصلاح سيصدر قريبًا. وحتى ذلك الحين، قد تفشل الخطوات التالية أو تثبّت حزمة لا تعمل.

تشغّل حزمة Termux برنامج Hermes على أجهزة Android بمعمارية aarch64 (arm64-v8a). تُنشر قناتا APT ضمن https://hermes-assets.nousresearch.com/releases/termux/<channel>:

القناةمجموعة APTالمحتويات
stablehermes-stableإصدارات vMAJOR.MINOR.PATCH ذات الوسوم التي اجتازت بوابة الإصدار المستقر
canaryhermes-canaryبُنى ما قبل الإصدار من وسوم canary؛ تحمل الإصدارات ~canary.<timestamp>

تستخدم الخطوات التالية stable. لمتابعة الإصدارات التمهيدية، استبدل stable بـ canary و hermes-stable بـ hermes-canary في الخطوتين 2 و 4. تُوقّع القناتان بالمفتاح نفسه.

تتضمن الحزمة Python و Node.js و npm و uv و ripgrep و ffmpeg ومكتبات تشغيلها. تبني CI حزم Python wheels الأصلية و TUI قبل إنشاء الحزمة. ولا يترجم الجهاز الاعتماديات الأساسية أو يُنشئ بيئة Python الأساسية أثناء التثبيت. تستخدم الحزمة Python 3.14 مع تثبيت مفسّر bionic؛ ولا تشترط إصدار التصحيح نفسه المستخدم في CPython على Desktop. تشمل مجموعة wheels المغلقة الأساسيات إضافةً إلى acp، لا جميع إضافات Desktop.

التثبيت

استخدم تطبيق Termux القياسي. تتطلب الحزمة بادئته القياسية، /data/data/com.termux/files/usr. المعماريات الأخرى وحزم تطبيق Termux المعاد تسميتها غير مدعومة. تستهدف wheels إصدار Android API 24 (android_24_arm64_v8a). لا تستخدم install.sh الخاص بـ Desktop/الخادم أو أرشيف glibc Linux على هذا الهدف.

حدّث عبر APT:

hermes update تعديل تثبيت مملوك لـ APT. ويطبع أمر مدير الحزم بدلًا من ذلك. تحتوي إصدارات canary على ~canary.<timestamp> وتُرتّب قبل الإصدار المستقر المقابل. ولا تسرد كل مجموعة إلا حزم قناتها؛ للانتقال بين القنوات، حرّر مسار القناة والمجموعة في hermes-agent.list، ثم pkg update && pkg upgrade hermes-agent.

قيود عمليات Android

قد يعلّق Android عمليات Termux في الخلفية أو ينهيها. يمكن أن تساعد الاستثناءات من تحسين البطارية و termux-wake-lock، لكنها لا تضمن التشغيل المستمر.

القيود

لا تتضمن الحزمة مُصدّر nemo-relay. لا تدعم سلسلة أدوات البناء المضمّنة معه هذا الهدف.

لا تتضمن الحزمة Electron أو Chromium محليًا أو أدوات استخدام حاسوب Desktop. ولا يُعدّ Docker daemon محلي جزءًا من بيئة Termux. وللخدمات البعيدة متطلباتها وقيود اتصالها الخاصة.

لا يوفر مسار الحزمة هذا محوّلات الميكروفون والحافظة الأصلية للهاتف عبر Termux:API. ولا يثبت وجود CLI/TUI مبنيتين مسبقًا دعم الصوت المحلي أو كلمة التنبيه. وقد تتطلب التكاملات الاختيارية والإضافات الخارجية اعتماديات لا تدعم Android.

يُبلغ Python 3.14 على هذا الهدف عن sys.platform == "android". ولا تصبح اعتمادية أو مهارة مقيّدة فقط بـ linux متاحة تلقائيًا على Android.

إلغاء التثبيت

يزيل APT الحزمة وروابط أوامرها الرمزية. ويحتفظ بإعداداتك وجلساتك ومهاراتك وذكرياتك.

استكشاف الأخطاء وإصلاحها

  • الحزمة غير موجودة: تحقّق من مدخل المستودع، ثم نفّذ pkg update.
  • خطأ في التوقيع: تحقّق من بصمة المفتاح العام. لا تستخدم مستودعًا غير موقّع ولا تتجاوز الخطأ.
  • أمر مفقود: تحقّق من وجود $PREFIX/bin في PATH، أو أعد تثبيت الحزمة.
  • مكتبة أو حزمة TUI مفقودة: أبلغ عن hermes --version والخطأ كاملًا. يجب ألّا تتطلب الحزمة الأساسية إعادة بناء محليًا.
  • يتوقف الـ gateway عند إطفاء الشاشة: راجع قيود البطارية والعمليات في الخلفية في Android.

للتشخيص العام، نفّذ hermes doctor.
