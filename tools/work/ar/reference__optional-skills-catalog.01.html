المساهمة بمهارات اختيارية

لإضافة مهارة اختيارية جديدة إلى المستودع:

  1. أنشئ دليلًا تحت optional-skills/<category>/<skill-name>/
  2. أضف ملف SKILL.md مع ترويسة (frontmatter) قياسية (الاسم، الوصف، الإصدار، المؤلف)
  3. أدرج أي ملفات مساندة في الأدلة الفرعية references/ أو templates/ أو scripts/
  4. قدّم pull request — ستظهر المهارة في هذا الكتالوج وتحصل على صفحة توثيق خاصة بها بمجرد الدمج
