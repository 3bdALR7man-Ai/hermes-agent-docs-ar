مهارة Xlsx

العمل مع ملفات Excel بصيغة xlsx باستخدام Python و openpyxl: بناء ملفات عمل منسّقة متعددة الأوراق مع صيغ ومخططات، وفحص الملفات الموجودة أو تفريغ محتواها، وتحرير الخلايا والبنية، والتحويل من/إلى CSV. جميع السكربتات المساعدة هي واجهات argparse سطر أوامر تطبع JSON وتستخدم إدخال/إخراج UTF-8 صريحًا.

متى تُستخدم

  • إنشاء تقارير xlsx: أوراق متعددة، تنسيقات أرقام، تنسيق شكلي، خلايا مدمجة، تجميد الأجزاء (freeze panes)، تصفية تلقائية (autofilter)، تنسيق شرطي، مخططات، قوائم منسدلة للتحقق من صحة البيانات، جداول Excel أصلية، أسماء معرّفة، روابط تشعبية، ملاحظات على الخلايا، حماية الأوراق.
  • قراءة ملف عمل: جرد الأوراق، تفريغ البيانات بصيغة JSON أو CSV، سرد الصيغ مقابل القيم المخزّنة، الملاحظات، الأسماء المعرّفة، الجداول.
  • تحرير ملفات موجودة: ضبط الخلايا، إلحاق صفوف، إدراج/حذف صفوف/أعمدة (بوعي بالمراجع عبر xlsx_restructure.py)، نسخ/إعادة تسمية الأوراق والجداول والأسماء والملاحظات والحماية.
  • إعادة حساب الصيغ بلا واجهة رسومية عبر LibreOffice (xlsx_recalc.py).
  • التبادل مع CSV مع استنتاج النوع وترميزات غير UTF-8.
  • غير مخصصة لصيغة .xls الثنائية القديمة (استخدم LibreOffice للتحويل أولًا: soffice --headless --convert-to xlsx old.xls).

المتطلبات المسبقة

  • Python 3.10 أو أحدث مع openpyxl (pip install openpyxl). لا توجد حزم خارجية أخرى مطلوبة؛ كل ما عداها من مكتبة Python القياسية.
  • اختياري: LibreOffice (soffice) لإعادة الحساب بلا واجهة رسومية أو تحويل الصيغة.

الإجراء

  1. الإنشاء: اكتب مواصفات JSON (المخطط موثّق في xlsx_create.py --help وفي docstring الخاص به). كل ورقة تدعم rows (قيم مباشرة أو كائنات خلايا منسّقة)، وتجاوزات cells المتناثرة، column_widths، row_heights، merges، freeze_panes، autofilter، conditional_formats (قواعد cell_is ومقاييس الألوان)، charts (أعمدة/خطوط/دائرية من نطاقات الخلايا)، validations (قوائم منسدلة)، tables (جداول Excel أصلية مع اسم نمط)، وprotection. تربط defined_names على مستوى ملف العمل الأسماء بالمراجع. كائنات الخلايا تقبل أيضًا hyperlink وnote. القيم المُنمّطة: أرقام/قيم منطقية JSON تمرّ كما هي؛ التواريخ تُكتب بصيغة {"value": "2026-01-31", "type": "date"}. تنسيقات الأرقام هي سلاسل تنسيق Excel: العملة "$#,##0.00"، النسبة المئوية "0.0%"، التاريخ "yyyy-mm-dd".
  2. الصيغ: تُضبط عبر "formula": "SUM(B2:B9)" في المواصفات أو --set "C1==SUM(A:A)" في المحرّر. عند كتابة الصيغ، أضف "full_calc_on_load": true (في المواصفات) أو --recalc (في المحرّر)؛ هذا يضبط علامة fullCalcOnLoad الخاصة بملف العمل بحيث يعيد Excel/LibreOffice حساب كل شيء عند الفتح. openpyxl نفسها لا تُقيّم الصيغ أبدًا.
  3. القراءة: --sheets للجرد (الأسماء، الأبعاد، النطاقات المدمجة، عدد المخططات، الجداول، الحماية، الأسماء المعرّفة)، --json/--csv للبيانات، --formulas لإقران كل نص صيغة بنتيجته المخزّنة، --notes لملاحظات الخلايا، --names للأسماء المعرّفة. النتائج المخزّنة لا تكون متوفرة إلا إذا كان الملف قد حُفظ آخر مرة من تطبيق جداول بيانات حقيقي؛ الملفات الجديدة من openpyxl تُعيد null هناك. لتحقيق النتائج بلا واجهة رسومية شغّل xlsx_recalc.py file.xlsx (يستخدم LibreOffice؛ يطبع {"recalculated": false, ...} ويخرج بالرمز 0 عند غياب soffice)، ثم أعد التحميل مع --data-only.
  4. التحرير: يطبّق xlsx_edit.py إعادة التسمية/النسخ أولًا، ثم تغييرات الصفوف/الأعمدة البنيوية، ثم --set/--append. يحرّر في المكان نفسه ما لم يُعطَ --out — انسخ الملف أولًا إذا احتجت الأصل.
  5. إعادة الهيكلة: للإدراج/الحذف في أوراق تحتوي على صيغ، خلايا مدمجة، جداول، أو مرشِّحات، استخدم xlsx_restructure.py بدلًا من xlsx_edit.py. فهو يعيد كتابة مراجع الصيغ على جميع الأوراق (المراجع المطلقة $، النطاقات، المراجع بين الأوراق)، ويزيح الخلايا المدمجة، التصفية التلقائية، تجميد الأجزاء، ونطاقات التحقق من صحة البيانات والتنسيق الشرطي، ومراجع الجداول، والأسماء المعرّفة، وأبعاد الصفوف/الأعمدة، ثم يطبع تقرير JSON يتضمن قائمة not_shifted. القواعد والحدود: references/restructuring.md.
  6. التبادل مع CSV: يستنتج csv_to_xlsx.py نوع int/float/bool/تاريخ ISO لكل خلية وينسّق صف الترويسة؛ يكتب xlsx_to_csv.py تواريخ ISO وسلاسل فارغة للخلايا الفارغة. كلاهما يستخدم UTF-8 افتراضيًا ويقبل --encoding (مثل utf-8-sig لعلامة BOM المتوافقة مع Excel، وcp1252 لملفات Windows القديمة المُصدَّرة).

التحويل إلى PDF

يحوّل LibreOffice بلا واجهة رسومية (يعمل أيضًا لتصدير CSV لورقة واحدة):

الورقة الأولى فقط تُصدَّر إلى CSV؛ للأوراق الأخرى استخدم xlsx_to_csv.py --sheet NAME. إذا كان soffice غير موجود، ثبّت LibreOffice أو سلّم الملف للمستخدم دون تحويل.

المزالق

  • openpyxl لا تحسب. نتائج الصيغ متوفرة فقط عبر load_workbook(path, data_only=True) وفقط عندما يكون الملف قد حُفظ سابقًا من Excel/LibreOffice. وإلا ستحصل على None.
  • إدراج/حذف xlsx_edit.py لا يُزيح المراجع (سلوك openpyxl الخام). استخدم xlsx_restructure.py، الذي يفعل ذلك — لكن حتى هو لا يستطيع نقل مرابط المخططات أو الصور أو صيغ قواعد التنسيق الشرطي؛ راجع قائمة not_shifted في تقرير JSON الخاص به و references/restructuring.md.
  • حماية الورقة ليست أمانًا. يضبط --protect تجزئة حماية الورقة القياسية في xlsx: تشير إلى "لا تعدّل هذا" للتطبيقات المنضبطة فحسب، ولا شيء أكثر. يمكن لأي شخص إزالتها بتعديل XML الخاص بالأرشيف المضغوط أو بإلغاء تحديدها في LibreOffice. لا تعتمد عليها أبدًا للسرية أو السلامة؛ فهي لا تشفّر أي شيء.
  • استخدام data_only=True ثم الحفظ يُسقط جميع الصيغ بصمت (تحل القيم المخزّنة محلها). لا تحفظ أبدًا ملف عمل حُمِّل بهذه الطريقة ما لم يكن ذلك هو الهدف.
  • التحميل يُسقط المخططات/الصور: لا تحافظ openpyxl على المخططات عند إعادة الحفظ، لذا فإن تحرير ملف عمل يحتوي على مخططات وحفظه يُسقط المخططات. أعد إضافة المخططات بعد التحرير، أو تجنّب إعادة حفظ الملفات التي تحتوي عليها.
  • مزالق ترميز CSV: مرّر دائمًا ترميزات صريحة (السكربتات تفعل ذلك بالفعل) وتذكّر أن ملفات CSV الأوروبية غالبًا ما تستخدم فاصلة ; وفواصل عشرية بالفاصلة — استخدم --delimiter ';' وتوقّع أن تبقى سلاسل مثل "12,5" نصية.
  • التواريخ هي كائنات datetime: يخزّن Excel التواريخ كأرقام تسلسلية؛ تُعيد openpyxl كائنات datetime/date. التفريغات هنا تُصدر سلاسل ISO.
  • أسماء الأوراق محدودة بـ 31 حرفًا وترفض [ ] : * ? / \.

التحقق

  • بعد الإنشاء: نفّذ xlsx_read.py out.xlsx --sheets وتأكّد من مطابقة أسماء الأوراق، والأبعاد، والنطاقات المدمجة، وعدد المخططات للمقصود.
  • فرّغ البيانات باستخدام --json وقارنها بالقيم المصدرية.
  • بعد التحرير: أعد تفريغ النطاق المتأثر؛ إذا كُتبت صيغ، تأكّد أن --formulas يسردها وأن --recalc قد طُبِّق.
  • بعد xlsx_restructure.py: اقرأ تقرير JSON الخاص به، ثم أعد تشغيل --formulas و--sheets للتأكد أن المراجع والنطاقات استقرّت كما هو متوقّع.
  • للتحقق البصري الكامل، افتح في LibreOffice: soffice --headless --convert-to pdf out.xlsx وافحص ملف PDF.
