مهارة Solana Blockchain

استعلم عن بيانات Solana على السلسلة مُثراة بتسعير بالدولار عبر CoinGecko. 8 أوامر: portfolio المحفظة، معلومات العملة (token)، المعاملات، النشاط، قطع NFT، رصد الحيتان (whale detection)، إحصاءات الشبكة، والبحث عن السعر.

لا حاجة إلى مفتاح API. تُستخدم مكتبة Python القياسية فقط (urllib، json، argparse).

متى تُستخدم

  • يطلب المستخدم رصيد محفظة Solana، أو العملات المملوكة، أو قيمة الـ portfolio
  • يريد المستخدم فحص معاملة معيّنة عبر توقيعها (signature)
  • يريد المستخدم بيانات وصفية أو سعرًا أو المعروض أو أهم حاملي عملة SPL
  • يريد المستخدم سجل المعاملات الأخيرة لعنوان معيّن
  • يريد المستخدم قطع NFT التي تملكها محفظة ما
  • يريد المستخدم العثور على تحويلات SOL كبيرة (رصد الحيتان)
  • يريد المستخدم صحة شبكة Solana أو TPS أو الحقبة (epoch) أو سعر SOL
  • يسأل المستخدم "ما سعر BONK/JUP/SOL؟"

المتطلبات الأساسية

يستخدم السكربت المساعد مكتبة Python القياسية فقط (urllib، json، argparse). لا حاجة إلى حزم خارجية.

تأتي بيانات التسعير من واجهة CoinGecko المجانية (بلا حاجة إلى مفتاح، بحدّ معدل ~10-30 طلبًا في الدقيقة). للبحث الأسرع، استخدم الخيار --no-prices.

الإجراء

0. التحقق من الإعداد

1. Portfolio المحفظة

احصل على رصيد SOL، وعملات SPL المملوكة بقيمها بالدولار، وعدد قطع NFT، وإجمالي الـ portfolio. العملات مرتّبة حسب القيمة، مع تصفية الغبار (dust)، والعملات المعروفة موسومة بأسمائها (BONK، JUP، USDC، إلخ).

الخيارات (Flags):

  • --limit N — عرض أعلى N عملة (الافتراضي: 20)
  • --all — عرض جميع العملات، بلا تصفية غبار، وبلا حد
  • --no-prices — تخطّي عمليات البحث عن الأسعار عبر CoinGecko (أسرع، عبر RPC فقط)

تتضمن المخرجات: رصيد SOL + قيمته بالدولار، قائمة العملات مع الأسعار مرتّبة حسب القيمة، عدد عناصر الغبار، ملخص NFT، وإجمالي قيمة الـ portfolio بالدولار.

2. تفاصيل المعاملة

افحص معاملة كاملة عبر توقيعها (signature) بصيغة base58. يُظهر تغيّرات الرصيد بكل من SOL والدولار.

المخرجات: slot، الطابع الزمني، الرسوم، الحالة، تغيّرات الرصيد (SOL + الدولار)، واستدعاءات البرامج (program invocations).

3. معلومات العملة (Token)

احصل على البيانات الوصفية لعملة SPL، والسعر الحالي، والقيمة السوقية، والمعروض، وعدد المنازل العشرية، وصلاحيات الإصدار (mint) والتجميد (freeze)، وأهم 5 حاملين.

المخرجات: الاسم، الرمز، المنازل العشرية، المعروض، السعر، القيمة السوقية، أهم 5 حاملين مع نسبهم المئوية.

4. النشاط الأخير

اعرض المعاملات الأخيرة لعنوان معيّن (الافتراضي: آخر 10، بحد أقصى: 25).

5. Portfolio قطع NFT

اعرض قطع NFT التي تملكها محفظة ما (بشكل إرشادي: عملات SPL بكمية=1 ومنازل عشرية=0).

ملاحظة: لا يكتشف هذا الأسلوب الإرشادي قطع NFT المضغوطة (cNFTs).

6. كاشف الحيتان

افحص أحدث كتلة بحثًا عن تحويلات SOL كبيرة مع قيمها بالدولار.

ملاحظة: يفحص أحدث كتلة فقط — لقطة (snapshot) في لحظة معينة، وليس بيانات تاريخية.

7. إحصاءات الشبكة

صحة شبكة Solana مباشرة: الـ slot الحالي، الحقبة (epoch)، TPS، المعروض، إصدار المُصادِق (validator)، سعر SOL، والقيمة السوقية.

8. البحث عن السعر

تحقق سريع من سعر أي عملة عبر عنوان mint أو رمز معروف.

الرموز المعروفة: SOL، USDC، USDT، BONK، JUP، WETH، JTO، mSOL، stSOL، PYTH، HNT، RNDR، WEN، W، TNSR، DRIFT، bSOL، JLP، WIF، MEW، BOME، PENGU.

المزالق

  • حدود معدل CoinGecko — تسمح الفئة المجانية بـ ~10-30 طلبًا في الدقيقة. تستخدم عمليات البحث عن السعر طلبًا واحدًا لكل عملة. قد لا تحصل المحافظ التي تحتوي عملات كثيرة على أسعار لجميعها. استخدم --no-prices للسرعة.
  • حدود معدل RPC العامة — يحدّ RPC العام لشبكة Solana الرئيسية عدد الطلبات. للاستخدام الإنتاجي، اضبط SOLANA_RPC_URL على endpoint خاص (Helius، QuickNode، Triton).
  • اكتشاف NFT إرشادي — كمية=1 + منازل عشرية=0. لن تظهر قطع NFT المضغوطة (cNFTs) وقطع Token-2022.
  • يفحص كاشف الحيتان أحدث كتلة فقط — وليس بيانات تاريخية. تختلف النتائج حسب لحظة الاستعلام.
  • سجل المعاملات — يحتفظ RPC العام بنحو يومين فقط. قد لا تتوفر المعاملات الأقدم.
  • أسماء العملات — نحو 25 عملة معروفة موسومة بأسمائها. أما البقية فتظهر بعناوين mint مختصرة. استخدم أمر token للحصول على المعلومات الكاملة.
  • إعادة المحاولة عند 429 — تُعاد محاولة طلبات كل من RPC وCoinGecko حتى مرتين مع تأخير تصاعدي (exponential backoff) عند حدوث أخطاء تجاوز حد المعدل.
