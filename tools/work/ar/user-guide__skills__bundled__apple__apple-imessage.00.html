iMessage

استخدم imsg لقراءة وإرسال رسائل iMessage/SMS عبر Messages.app في macOS.

المتطلبات الأساسية

  • macOS مع تسجيل الدخول في Messages.app
  • التثبيت: brew install steipete/tap/imsg
  • امنح صلاحية Full Disk Access للطرفية (System Settings → Privacy → Full Disk Access)
  • امنح صلاحية Automation لتطبيق Messages.app عند الطلب

متى تُستخدم

  • عندما يطلب المستخدم إرسال iMessage أو رسالة نصية
  • قراءة سجلّ محادثات iMessage
  • الاطلاع على محادثات Messages.app الأخيرة
  • الإرسال إلى أرقام هواتف أو معرّفات Apple ID

متى لا تُستخدم

  • رسائل Telegram/Discord/Slack/WhatsApp → استخدم قناة gateway المناسبة
  • إدارة المحادثات الجماعية (إضافة/إزالة أعضاء) → غير مدعومة
  • الرسائل الجماعية/الجماعية الكبيرة → تأكّد دائمًا من المستخدم أولًا

مراقبة الرسائل الجديدة

خيارات الخدمة

  • --service imessage — فرض iMessage (يتطلب أن يكون لدى المستلم iMessage)
  • --service sms — فرض SMS (الفقاعة الخضراء)
  • --service auto — اترك Messages.app يقرر (الافتراضي)

القواعد

  1. تأكّد دائمًا من المستلم ومحتوى الرسالة قبل الإرسال
  2. لا ترسل أبدًا إلى أرقام مجهولة دون موافقة صريحة من المستخدم
  3. تحقّق من مسارات الملفات قبل إرفاقها
  4. لا ترسل رسائل مزعجة — قيّد وتيرة إرسالك
