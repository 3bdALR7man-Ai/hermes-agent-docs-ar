معلومة

ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

1Password CLI

استخدم هذه المهارة عندما يريد المستخدم إدارة الأسرار عبر 1Password بدلًا من متغيرات البيئة أو الملفات النصية غير المشفّرة.

المتطلبات

  • حساب 1Password
  • واجهة سطر أوامر 1Password (op) مثبَّتة
  • أحد الآتي: تكامل تطبيق سطح المكتب، أو رمز حساب خدمة (OP_SERVICE_ACCOUNT_TOKEN)، أو خادم Connect
  • tmux متاح لجلسات مصادقة مستقرة أثناء استدعاءات terminal في Hermes (لمسار تطبيق سطح المكتب فقط)

متى تُستخدم

  • تثبيت أو إعداد 1Password CLI
  • تسجيل الدخول باستخدام op signin
  • قراءة مراجع الأسرار مثل op://Vault/Item/field
  • حقن الأسرار في الإعدادات/القوالب باستخدام op inject
  • تشغيل أوامر بمتغيرات بيئة سرّية عبر op run

طرق المصادقة

حساب الخدمة (المُوصى به لـ Hermes)

اضبط OP_SERVICE_ACCOUNT_TOKEN في ${HERMES_HOME:-~/.hermes}/.env (ستطلب المهارة ذلك عند أول تحميل). لا حاجة لتطبيق سطح المكتب. يدعم op read وop inject وop run.

تكامل تطبيق سطح المكتب (تفاعلي)

  1. فعّله في تطبيق 1Password لسطح المكتب: Settings ← Developer ← Integrate with 1Password CLI
  2. تأكد من أن التطبيق غير مقفل
  3. شغّل op signin ووافق على طلب المقياس الحيوي (biometric)

نمط تنفيذ Hermes (مسار تطبيق سطح المكتب)

أوامر terminal في Hermes غير تفاعلية بشكل افتراضي وقد تفقد سياق المصادقة بين الاستدعاءات. لاستخدام op بشكل موثوق مع تكامل تطبيق سطح المكتب، شغّل عمليات تسجيل الدخول والتعامل مع الأسرار داخل جلسة tmux مخصصة.

ملاحظة: هذا غير ضروري عند استخدام OP_SERVICE_ACCOUNT_TOKEN — إذ يبقى الرمز مستمرًا عبر استدعاءات terminal تلقائيًا.

ضوابط الأمان

  • لا تطبع الأسرار الخام للمستخدم أبدًا إلا إذا طلب القيمة صراحةً.
  • فضّل op run / op inject على كتابة الأسرار في الملفات.
  • إذا فشل الأمر بخطأ "account is not signed in"، شغّل op signin مرة أخرى في نفس جلسة tmux.
  • إذا كان تكامل تطبيق سطح المكتب غير متاح (بيئة headless/CI)، استخدم مسار رمز حساب الخدمة.

ملاحظة CI / بيئة Headless

للاستخدام غير التفاعلي، صادق باستخدام OP_SERVICE_ACCOUNT_TOKEN وتجنّب op signin التفاعلي. تتطلب حسابات الخدمة إصدار CLI 2.18.0 فأعلى.
