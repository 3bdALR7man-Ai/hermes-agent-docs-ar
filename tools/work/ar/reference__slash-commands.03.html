Slash commands في المراسلة

أوامر خيوط Slack (بادئة !): يمنع Slack نفسه slash commands الأصلية داخل خيوط الرسائل ("/queue is not supported in threads. Sorry!") ولا يوصلها أبدًا إلى Hermes. داخل خيط Slack، استخدم بادئة ! بدلًا منها — !stop، !new، !status — ويوجّهها الـ gateway تمامًا كما لو كانت بصيغة slash. تعمل @Hermes !stop و@Hermes /stop في الخيوط أيضًا. تُفحص الكلمة الأولى فقط مقابل قائمة الأوامر المعروفة، لذا رسائل مثل !nice work تمرّ إلى الوكيل دون تغيير. راجع استخدام الأوامر داخل الخيوط للتفاصيل.

يدعم messaging gateway الأوامر المدمجة التالية داخل محادثات Telegram وDiscord وSlack وWhatsApp وSignal والبريد الإلكتروني وHome Assistant وTeams:

الأمرالوصف
/startأمر بروتوكول خاص بالمنصة. ترسل منصات محادثة كثيرة (Telegram، Discord، ...) أمر /start تلقائيًا عند أول فتح للمستخدم محادثة مع بوت. يُقرّ Hermes باستلامها بصمت — بلا رد من الوكيل، ودون استهلاك دور — بحيث لا تهدر مصافحات أول اتصال دورًا. يمكنك أيضًا إرسالها صراحةً للتأكد من إمكانية الوصول إلى الـ gateway.
/new [name] (الاسم البديل: /reset)ابدأ جلسة جديدة (معرّف جلسة وسجلّ جديدان). المعامل الاختياري [name] يضبط عنوان الجلسة الابتدائي. أضف now أو --yes أو -y لتخطي نافذة التأكيد — مثل /reset now أو /new --yes my-experiment.
/statusاعرض معلومات الجلسة، يتبعها محليًا كتلة ملخّص الجلسة (Session recap) (عدد الأدوار الأخيرة، أكثر الأدوات استخدامًا، الملفات التي جرى التعامل معها، آخر prompt + رد).
/stopأنهِ كل العمليات الخلفية الجارية وقاطع الوكيل قيد التشغيل.
/discardأسقِط دورًا فقده Hermes في إعادة تشغيل كي تعمل الرسائل المنتظرة في هذه المحادثة من جديد. لا يُعاد تشغيل الدور المفقود (أنت وحدك تعرف إن كان ينبغي إرساله مجددًا)؛ بل يُسجَّل على أنه مقاطَع. يعرض Hermes هذا الخيار عندما يوقف محادثة مؤقتًا بسبب دور مفقود. على Slack استخدم /hermes discard.
/pause [reason | off]إيقاف طوارئ عام، وهو الصيغة داخل المحادثة لـ hermes pause: يعلّق أعمال cron و kanban والـ gateway الجديدة حتى /pause off. تكتمل الأعمال الجارية بصورة طبيعية، وتظل slash commands تعمل أثناء الإيقاف المؤقت، ليتمكن مشغّل يستخدم المراسلة فقط من رفعه دائمًا.
/model [provider:model]اعرض أو غيّر النموذج. يدعم تبديل المزوّدين (/model zai:glm-5)، والـ endpoints المخصصة (/model custom:model)، والمزوّدين المخصصين المُسمّين (/model custom:local:qwen)، والاكتشاف التلقائي (/model custom)، وأنماط حساب OpenRouter المُعدّة مسبقًا (/model @preset/<slug> — خاصة بالحساب، تتخطى فحص قائمة النماذج العامة)، والأسماء المستعارة التي يعرّفها المستخدم (/model fav، /model grok — راجع الأسماء المستعارة المخصصة للنماذج). استخدم --global لحفظ التغيير في config.yaml؛ كما يُزيل اختيار --global ناجح (كتابةً أو عبر المنتقي) تجاوز هذه المحادثة الخاص بالجلسة، فيصبح config.yaml وحده محدِّد النموذج بعد إعادة تشغيل gateway (المحادثة التي لها نموذج channel_overrides تحتفظ بالتجاوز، وإلا لتقدّم إعداد القناة على config.yaml؛ ويُبقي CLI/TUI عمدًا التثبيت الخاص بكل جلسة كي يستعيد الاستئناف النموذج الذي استخدمته المحادثة). ملاحظة: يقتصر /model على التبديل بين مزوّدين مُعدّين مسبقًا. لإضافة مزوّد جديد أو ضبط مفاتيح API، استخدم hermes model من الطرفية (خارج جلسة المحادثة). ملاحظة حول التكلفة: تبديل النموذج في منتصف الجلسة يصفّر التخزين المؤقت للـ prompt (لأن مفتاح التخزين المؤقت يتضمن النموذج)، فتُعاد قراءة المحادثة بأكملها في الرسالة التالية بسعر الإدخال الكامل.
/codex-runtime [auto|codex_app_server|on|off]بدّل تشغيل Codex app-server runtime الاختياري. يُحفظ في model.openai_runtime في config.yaml ويُخرج الوكيل المخزَّن مؤقتًا بحيث تلتقط الرسالة التالية runtime الجديد. يسري اعتبارًا من الجلسة التالية.
/personality [name]اضبط تراكب شخصية للجلسة. /personality none (أو default / neutral) يزيله.
/fast [normal|fast|auto|cold|status]الوضع السريع — OpenAI Priority Processing / Anthropic Fast Mode. auto/cold يفتحان نافذة سريعة محدودة لكل دور / لكل جلسة.
/retryأعد إرسال الرسالة الأخيرة.
/undoاحذف آخر تبادل.
/sethome (الاسم البديل: /set-home)اجعل المحادثة الحالية القناة الرئيسية للمنصة من أجل التسليمات.
/compress [here [N] | focus topic]اضغط سياق المحادثة يدويًا. /compress here [N] يبقي آخر N تبادلات (الافتراضي 2) كما هي حرفيًا ويلخّص الباقي. تحديد موضوع تركيز يضيّق ما يحتفظ به التلخيص الكامل.
/topic [off|help|session-id]حصري لمحادثات Telegram المباشرة (DM). أدِر وضع المواضيع متعدد الجلسات الذي يديره المستخدم. /topic يفعّله أو يعرض حالته؛ و/topic off يعطّله ويمسح الارتباطات؛ و/topic help يعرض طريقة الاستخدام؛ و/topic <session-id> داخل موضوع يستعيد جلسة سابقة. راجع وضع المحادثة المباشرة متعدد الجلسات.
/title [name]اضبط أو اعرض عنوان الجلسة.
/resume [name]استأنف جلسة مُسمّاة سابقًا.
/sessions [all] [search <query>]اسرد الجلسات السابقة لهذه المحادثة؛ تظهر الجلسة النشطة بعلامة (current). /sessions search <query> يصفّي حسب تطابق العنوان/المعرّف (الأحدث نشاطًا أولًا)؛ و/sessions all يسرد عبر كل المصادر (للمدراء فقط — غير المدراء يحصلون على إشعار والقائمة المقتصرة على المحادثة).
/usageاعرض استخدام الـ token، وتقدير تفصيل التكلفة (إدخال/إخراج)، وحالة نافذة السياق، ومدة الجلسة، و — عند توفرها من المزوّد النشط — قسم حدود الحساب (Account limits) بالحصة/الأرصدة المتبقية مسحوبة مباشرة من واجهة API الخاصة بالمزوّد.
/topupاعرض رصيدك في Nous وأدِر الفوترة على البوابة.
/loginسجّل الدخول بحساب Nous. حصري للرسائل المباشرة المزدوجة (paired) — في مجموعة أو قناة أو منصة شبيهة بالبث يرفض Hermes ذلك. على Slack استخدم /hermes login.
/whoamiاعرض مستوى صلاحية الوصول إلى slash commands الخاص بك (admin / user).
/insights [days]اعرض تحليلات الاستخدام.
/reasoning [level|show|hide|full|clamp] [--global]غيّر جهد التفكير (حتى مستوى max / ultra) أو بدّل عرض التفكير (بما في ذلك full / clamp). --global يحفظ في الإعدادات.
/voice [on|off|tts|join|channel|leave|status]تحكّم بالردود الصوتية في المحادثة. join/channel/leave تدير وضع قناة Discord الصوتية.
/rollback [number]اعرض أو استعِد نقاط حفظ نظام الملفات.
/diff [staged|all|session] [--stat]اعرض تغييرات git في مجلد العمل (مُنسّقة ومختصرة وفق حدود رسائل المنصة). session يعرض الفرق التراكمي لكل ما غيّره Hermes؛ و--stat يعرض الملخّص فقط.
/bg <prompt>شغّل prompt في جلسة خلفية منفصلة. تُسلَّم النتائج إلى المحادثة نفسها عند انتهاء المهمة. راجع الجلسات الخلفية في المراسلة.
/btw <question>اطرح سؤالًا جانبيًا حول المحادثة الحالية دون مقاطعتها. يُجاب من لقطة للنص؛ ويُرسل الجواب إلى المحادثة عند الجاهزية.
/queue <prompt> (الاسم البديل: /q)ضع prompt في قائمة الانتظار للدور التالي دون مقاطعة الحالي.
/steer <prompt>أدرج رسالة بعد استدعاء الأداة التالي دون مقاطعة — يلتقطها النموذج في تكراره التالي بدلًا من كونها دورًا جديدًا.
/goal <text>اضبط هدفًا دائمًا يعمل Hermes على تحقيقه عبر الأدوار — تفسيرنا لحلقة Ralph. يتحقق نموذج حَكَم بعد كل دور؛ وإن لم يكتمل الهدف يواصل Hermes تلقائيًا حتى يكتمل، أو تُوقفه/تمسحه، أو تصل ميزانية الأدوار (الافتراضي 20). الأوامر الفرعية: /goal status، /goal pause، /goal resume، /goal clear. آمن للتشغيل أثناء عمل الوكيل من أجل الحالة/الإيقاف/المسح؛ ضبط هدف جديد يتطلب /stop أولًا. راجع الأهداف الدائمة (Persistent Goals).
/subgoal <text>أضِف معايير إلى /goal النشط أثناء الحلقة (/subgoal، /subgoal remove <N>، /subgoal clear).
/heartbeat every <interval> <prompt> (الاسم البديل: /hb)اضبط prompt متكررًا يدخل من جديد في هذه الجلسة عند الخمول. الأوامر الفرعية: status، pause، resume، clear. على Slack استخدم /hermes heartbeat ….
/loop [interval] <prompt> [--times N] [--until <condition>] (الاسم البديل: /proactive)أعد تشغيل prompt على فاصل متكرر في هذه الجلسة. الأوامر الفرعية: status، pause، resume، stop. راجع الحلقات.
/refine [focus]شغّل مراجعة التحسين الذاتي للذاكرة/المهارات الآن، اختياريًا بتعليمات تركيز. على Slack استخدم /hermes refine ….
/review [instructions]ابدأ subagent مراجعة مستقلًا للعمل الذي جرى مناقشته للتو (PR أو كود أو مستندات)؛ وتعود مراجعته إلى هذه المحادثة عند الانتهاء. على Slack استخدم /hermes review ….
/moa <prompt>شغّل prompt واحدًا عبر الإعداد الافتراضي لـMixture of Agents، ثم استعِد نموذج الجلسة.
/branch [--here] [name] (الاسم البديل: /fork)أنشئ branch من الجلسة الحالية. تفتح المنصات الداعمة لـ threads (Discord، و Telegram، و Slack، و Matrix) الفرع في thread شقيقة جديدة وتُبقي هذه المحادثة على الأصل؛ و --here ينقل هذه المحادثة إلى الفرع.
/agents (الاسم البديل: /tasks)اعرض الوكلاء النشطين والمهام الجارية.
/sessionsتصفّح واستأنف الجلسات السابقة.
/context [all] (الاسم البديل: /ctx)مقياس استخدام نافذة السياق وتفصيل الفئات (بصيغة نصية ملائمة للمراسلة). /context all يضيف تفاصيل التكلفة لكل مهارة / toolset.
/egress [status]اعرض حالة Docker egress proxy.
/init [notes]أنشئ أو حدّث AGENTS.md من فحص المستودع.
/learn <what to learn from>استخلص مهارة قابلة لإعادة الاستخدام من أي شيء تصفه.
/plan [task]اكتب خطة تنفيذ بصيغة markdown إلى .hermes/plans/؛ دون تنفيذ.
/bundlesاسرد حزم المهارات المُعدّة (أسماء بديلة على شكل /<name> تحمّل مسبقًا عدة مهارات).
/reload-skills (الاسم البديل: /reload_skills)أعد مسح ~/.hermes/skills/ بحثًا عن مهارات مُثبَّتة أو مُزالة حديثًا.
/footer [on|off|status]بدّل تذييل بيانات تشغيل الـ runtime الوصفية في الردود النهائية (يعرض النموذج، ونسبة السياق، ومجلد العمل).
/curator [status|run|pin|archive]عناصر تحكم صيانة المهارات الخلفية.
/suggestions [accept|dismiss N|catalog|clear]راجع الأتمتة المُقترحة من داخل المحادثة مباشرة. /suggestions يسرد الاقتراحات المعلّقة، وcatalog يضيف أتمتة تمهيدية منتقاة، وclear يشذّب سجلّات الاقتراحات المحسومة. الاقتراحات المقبولة تُبقي هذه المحادثة/الخيط مصدر تسليم المهمة.
/blueprint [name] [slot=value ...]تصفّح مخططات cron، أو ابدأ محادثة موجّهة لتعبئة الحقول، أو أنشئ مهمة blueprint مباشرة. المهام المُنشأة مباشرة تُسلَّم إلى المحادثة/الخيط الحالي.
/memory [pending|approve|reject|approval]راجع كتابات الذاكرة المعلّقة التي تنتظرها بوابة الموافقة (memory.write_approval) — اقبلها أو ارفضها من داخل المحادثة مباشرة — وبدّل حالة البوابة بـ /memory approval on|off. راجع التحكم بكتابات الذاكرة.
/skills [pending|approve|reject|diff|approval]راجع كتابات المهارات المعلّقة التي تنتظرها بوابة الموافقة (skills.write_approval). يعرض ملخّصًا بسطر واحد لكل كتابة معلّقة؛ و/skills diff <id> مختصر للمحادثة — اقرأ الفرق الكامل على CLI أو في ~/.hermes/pending/skills/<id>.json. يظهر فقط عند تفعيل البوابة (أو وجود كتابات معلّقة)؛ البحث/التثبيت يبقيان حصريين لـ CLI.
/kanban <action>شغّل لوحة التعاون متعددة الـ profiles ومتعددة المشاريع من المحادثة — نفس سطح المعاملات في CLI. يتجاوز حارس "الوكيل قيد التشغيل"، فتعمل أوامر مثل /kanban unblock t_abc و/kanban comment t_abc "…" و/kanban list --mine و/kanban boards switch <slug> إلخ في منتصف الدور. /kanban create … يشترك تلقائيًا المحادثة المُنشِئة في أحداث طرفية المهمة الجديدة. راجع الأمر Kanban.
/platform <list|pause|resume> [name]شغّل منصة gateway جارية مباشرة من المحادثة. /platform list يعرض كل adapter وحالته (يعمل، متوقف مؤقتًا بواسطة circuit breaker، متوقف يدويًا)؛ و/platform pause <name> يوقف توجيه الرسائل الجديدة إلى ذلك الـ adapter دون إلغاء تحميله؛ و/platform resume <name> يعيد تفعيله ويصفّر circuit breaker متعثّر بمجرد استعادة سلامة المصدر.
/reload-mcp (الاسم البديل: /reload_mcp)أعد تحميل خوادم MCP من الإعدادات وأعد فحص توفّر الأدوات.
/verboseتنقّل بين أوضاع عرض تقدّم الأدوات. معطّل افتراضيًا في المراسلة — فعّله بضبط display.tool_progress_command: true في config.yaml.
/yoloبدّل وضع YOLO — تخطَّ كل موافقات الأوامر الخطرة.
/commands [page]تصفّح كل الأوامر والمهارات (مقسّمة إلى صفحات).
/approve [session|always]وافق على أمر خطر معلّق ونفّذه. session يوافق لهذه الجلسة فقط؛ وalways يضيفه إلى القائمة الدائمة المسموحة.
/denyارفض أمرًا خطرًا معلّقًا.
/updateحدّث Hermes Agent إلى أحدث إصدار.
/restartأعد تشغيل الـ gateway بسلاسة بعد استنفاد عمليات التشغيل النشطة. عند عودة الـ gateway إلى الاتصال، يرسل تأكيدًا إلى محادثة/خيط الطالب.
/debugارفع تقرير تصحيح (معلومات النظام + السجلّات) واحصل على روابط قابلة للمشاركة.
/helpاعرض مساعدة المراسلة.
/<skill-name>استدعِ أي مهارة مُثبَّتة باسمها.

ملاحظات

  • /skin، /snapshot، /export، /import، /reload، /tools، /toolsets، /browser، /config، /cron، /platforms، /paste، /image، /statusbar، /battery، /focus، /plugins، /indicator، /wake، /journey، /redraw، /clear، /history، /save، /copy، /handoff، /prompt، /pet، /hatch، /timestamps، /subscription، و/quit هي أوامر حصرية لـ CLI.
  • /skills حصري لـ CLI للبحث/التصفّح/التثبيت؛ أوامر مراجعة موافقة الكتابة الفرعية فيه (pending، approve، reject، diff، approval) تعمل أيضًا على منصات المراسلة عند تفعيل skills.write_approval. /memory يعمل على كلا السطحين.
  • /verbose حصري لـ CLI افتراضيًا، لكن يمكن تفعيله لمنصات المراسلة بضبط display.tool_progress_command: true في config.yaml. عند تفعيله، يتنقّل عبر وضع display.tool_progress ويحفظه في الإعدادات.
  • يشترك /focus و/verbose في مسار كبت واحد (display.tool_progress)، لذا لا يمكن أن يتعارضا أبدًا: /focus on يثبّت تقدّم الأدوات على off ويخزّن وضعك تحت display.focus_saved_tool_progress؛ و/focus off يستعيده؛ والتنقّل عبر /verbose أثناء تفعيل التركيز يستعيد الوضع ويمسح شارة التركيز. عرض التركيز للعرض فقط — لا يغيّر أبدًا سجلّ المحادثة، أو الـ system prompt، أو أي شيء يُرسل إلى النموذج، لذا ليس له أثر على التخزين المؤقت للـ prompt.
  • /sethome و /restart و /approve و /deny و /topic و /platform و /pause و /discard و /commands هي أوامر حصرية للمراسلة.
  • /status، /egress، /version، /whoami، /bg، /btw، /queue، /steer، /voice، /reload-mcp، /reload-skills، /rollback، /diff، /debug، /fast، /approvals، /busy، /footer، /curator، /kanban، /topup، /login، /suggestions، /blueprint، /learn، /init، /sessions، و/loop، و /yolo تعمل في كل من CLI وmessaging gateway.
  • /voice join، و/voice channel، و/voice leave ذات معنى فقط على Discord.
  • /connectors لـ TUI فقط.
  • في TUI، يعرض /sessions الجلسات الحيّة في عملية TUI الحالية. استخدم /resume [name] أو hermes --tui --resume <id-or-title> للمحادثات المحفوظة أو المُغلقة.

تأكيدات الأوامر المدمّرة

يطلب CLI تأكيدًا قبل تنفيذ slash commands التي تُلقي بحالة الجلسة غير المحفوظة. المجموعة المدمّرة الحالية هي:

الأمرما يدمّره
/clearيمسح الشاشة ويبدأ جلسة جديدة — معرّف الجلسة الحالية والسجلّ الموجود في الذاكرة يختفيان.
/new / /resetيبدأ جلسة جديدة (معرّف جلسة وسجلّ فارغ جديدان).
/undoيحذف آخر تبادل بين المستخدم والوكيل من السجلّ.
/exit --delete / /quit --deleteيخرج ويحذف نهائيًا سجلّ SQLite للجلسة الحالية والمحادثات المخزَّنة على القرص.

لكل واحد من هذه الأوامر يفتح CLI نافذة بثلاثة خيارات: Approve Once (تابع لهذه المرة)، وAlways Approve (تابع واحفظ approvals.destructive_slash_confirm: false بحيث تعمل الأوامر المدمّرة القادمة دون سؤال)، أو Cancel.

تخطٍّ مضمَّن: أضف now أو --yes أو -y لتجاوز النافذة لاستدعاء واحد — مثل /reset now، و/new --yes my-session، و/clear -y، و/undo -y. مفيد عندما لا تُعرض النافذة بشكل صحيح على طرفيتك (راجع issue #30768 بخصوص PowerShell الأصلي على Windows) أو عند برمجة سكربتات تتفاعل مع CLI.

اضبط approvals.destructive_slash_confirm: false في ~/.hermes/config.yaml لتعطيل التأكيدات عالميًا؛ وأعده إلى true لإعادة التفعيل. راجع الأمان — تأكيد slash command المدمّرة للسياق.
