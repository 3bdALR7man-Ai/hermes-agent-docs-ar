مرجع متغيرات البيئة

يقرأ Hermes متغيرات البيئة من بيئة العملية، ومن ~/.hermes/.env بالنسبة للأسرار التي يديرها المستخدم. احتفظ بمفاتيح API، وtokens البوت، وأسرار OAuth، وبيانات الاعتماد الأخرى في .env؛ وفضّل config.yaml لإعدادات السلوك غير السرّية عندما يوجد مفتاح إعداد مناسب. بعض المتغيرات أدناه هي تجاوزات خاصة بالعملية فقط أو متغيرات جسر (bridge) داخلية ولا ينبغي وضعها في .env لمجرد أنها موثّقة هنا.

مصادقة المزوّد (OAuth)

بالنسبة لمصادقة Anthropic الأصلية، يفضّل Hermes ملفات بيانات اعتماد Claude Code الخاصة به عندما تكون موجودة لأن بيانات الاعتماد هذه يمكن أن تُجدَّد تلقائيًا. مصادقة OAuth ضد Anthropic تتطلب خطة Claude Max مع أرصدة استخدام إضافية مشتراة — يوجّه Hermes الطلبات باعتباره Claude Code، الذي لا يسحب إلا من أرصدة خطة Max الإضافية/الزائدة، وليس من مخصصات Max الأساسية، ولا يعمل مع Claude Pro. دون Max + أرصدة إضافية، استخدم مفتاح API بدلًا من ذلك. متغيرات البيئة مثل ANTHROPIC_TOKEN تبقى مفيدة كتجاوزات يدوية، لكنها لم تعد المسار المفضَّل لتسجيل الدخول بـ Claude Max.
