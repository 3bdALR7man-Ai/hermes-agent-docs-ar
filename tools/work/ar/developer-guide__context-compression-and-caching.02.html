التخزين المؤقت للـ Prompt (Anthropic)

المصدر: agent/prompt_caching.py

يخفّض تكاليف tokens المدخلات بنحو ~75% في المحادثات متعددة الأدوار عبر التخزين المؤقت لبادئة المحادثة. ويستخدم نقاط التوقف (breakpoints) cache_control لدى Anthropic.

أنماط تصميم تراعي التخزين المؤقت

  1. System prompt ثابت: الـ system prompt هو نقطة التوقف 1 ويُخزَّن مؤقتًا عبر جميع الأدوار. تجنّب تعديله في منتصف المحادثة (يُلحق الضغط ملاحظة عند أول عملية ضغط فقط).

  2. ترتيب الرسائل مهم: تتطلب إصابات التخزين المؤقت (cache hits) مطابقة البادئة. وإضافة رسائل في المنتصف أو إزالتها تُبطل التخزين المؤقت لكل ما يليها.

  3. تفاعل الضغط مع التخزين المؤقت: بعد الضغط، يُبطَل التخزين المؤقت للمنطقة المضغوطة، لكن التخزين المؤقت للـ system prompt يبقى. وتعيد النافذة المتحركة المكوّنة من 3 رسائل إرساء التخزين المؤقت خلال 1-2 دور.

  4. اختيار TTL: القيمة الافتراضية 5m (5 دقائق). استخدم 1h للجلسات طويلة الأمد التي يأخذ فيها المستخدم فترات راحة بين الأدوار.

  5. هوية النموذج جزء من مفتاح التخزين المؤقت: ترتبط ذاكرات التخزين المؤقت لدى المزوّد بالنموذج (والحساب/مفتاح API) الذي يخدم الطلب. فأي تغيير للنموذج في منتصف المحادثة — سواء أكان تبديلًا صريحًا عبر /model، أم انتقالًا احتياطيًا (fallback) من النموذج الأساسي، أم تدويرًا لمجمّع بيانات الاعتماد إلى حساب مختلف — يعني أن الطلب التالي لن يحقق أي إصابة في التخزين المؤقت، وسيعيد قراءة المحادثة كاملة بسعر المدخلات غير المخفّض. هذا متأصل في طريقة عمل ذاكرات التخزين المؤقت لدى المزوّدين، وليس أمرًا يستطيع Hermes تجنّبه؛ ولهذا السبب تتضمن وثائق المستخدم الخاصة بـ /model والمزوّدين الاحتياطيين ومجمّعات بيانات الاعتماد تحذيرات بشأن التكلفة. لا تُضف ميزات تبدّل النموذج أو بيانات الاعتماد بصمت في منتصف الجلسة.

تفعيل التخزين المؤقت للـ Prompt

يُفعَّل التخزين المؤقت للـ prompt تلقائيًا عندما:

  • يكون النموذج من نماذج Anthropic Claude (يُكتشف ذلك من اسم النموذج)
  • يدعم المزوّد cache_control (Anthropic API الأصلي أو OpenRouter)

"auto" تُحدَّد مرة واحدة لكل جلسة في agent/agent_init.py::_init_prompt_cache_config عبر agent/prompt_caching.py::auto_cache_ttl_for_source: 1h للمصادر ذات وتيرة بشرية، و 5m لـ MACHINE_PACED_SOURCES (subagent، cron، oneshot، webhook، kanban، api، tool، batch). تتعامل الاستدعاءات المساعدة/الوهمية (configured_cache_ttl()) مع auto بوصفها 5m.

تحذيرات امتلاء السياق

أُزيلت تحذيرات امتلاء السياق الوسيطة (راجع كتلة ميزانية التكرارات في agent/turn_iteration_prep.py، التي تنص على: "No intermediate pressure warnings — they caused models to 'give up' prematurely on complex tasks"). يبدأ الضغط عندما تصل tokens الـ prompt إلى قيمة compression.threshold المضبوطة (الافتراضية 50%) دون أي خطوة تحذير مسبقة؛ ويعمل تنظيف جلسات gateway بوصفه شبكة الأمان الثانوية عند 85% من context window الخاصة بالنموذج.
