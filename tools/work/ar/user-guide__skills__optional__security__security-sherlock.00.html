البحث عن اسم مستخدم عبر Sherlock OSINT

تعقّب حسابات وسائل التواصل الاجتماعي حسب اسم المستخدم عبر أكثر من 400 شبكة اجتماعية باستخدام Sherlock Project.

متى تُستخدم

  • يطلب المستخدم إيجاد الحسابات المرتبطة باسم مستخدم معيّن
  • يريد المستخدم التحقق من توفّر اسم مستخدم عبر المنصات
  • يجري المستخدم بحث OSINT أو استطلاع استخباراتي
  • يسأل المستخدم "أين هذا الاسم مسجَّل؟" أو ما شابه

المتطلبات

  • أن يكون Sherlock CLI مثبّتًا: pipx install sherlock-project أو pip install sherlock-project
  • أو بديلًا: توفّر Docker (docker run -it --rm sherlock/sherlock)
  • الوصول إلى الشبكة للاستعلام من منصات التواصل الاجتماعي

  • إذا فشل التثبيت، أبلِغ المستخدم وتوقّف

2. استخراج اسم المستخدم

استخرج اسم المستخدم مباشرة من رسالة المستخدم إذا كان واضحًا.

أمثلة لا ينبغي فيها استخدام clarify:

  • "ابحث عن حسابات nasa" ← اسم المستخدم هو nasa
  • "ابحث عن johndoe123" ← اسم المستخدم هو johndoe123
  • "تحقق من وجود alice على وسائل التواصل الاجتماعي" ← اسم المستخدم هو alice
  • "ابحث عن المستخدم bob على الشبكات الاجتماعية" ← اسم المستخدم هو bob

استخدم clarify فقط إذا:

  • ذُكرت عدة أسماء مستخدمين محتملة ("ابحث عن alice أو bob")
  • كانت الصياغة غامضة ("ابحث عن اسم المستخدم الخاص بي" دون تحديد)
  • لم يُذكر أي اسم مستخدم إطلاقًا ("نفّذ بحث OSINT")

عند الاستخراج، خذ اسم المستخدم كما هو تمامًا — حافظ على حالة الأحرف والأرقام والشرطات السفلية وما إلى ذلك.

3. بناء الأمر

الأمر الافتراضي (استخدمه ما لم يطلب المستخدم غير ذلك صراحة):

خيارات اختيارية (أضِفها فقط إذا طلبها المستخدم صراحة):

  • --nsfw — تضمين المواقع غير اللائقة (فقط إذا طلب المستخدم ذلك)
  • --tor — التوجيه عبر Tor (فقط إذا طلب المستخدم إخفاء الهوية)

المزالق

لا نتائج

إذا لم يجد Sherlock أي حسابات، فهذا غالبًا صحيح — قد لا يكون اسم المستخدم مسجّلًا في المنصات المفحوصة. اقترح:

  • التحقق من الإملاء أو الأشكال المشابهة
  • تجربة أسماء مستخدمين مشابهة باستخدام حرف البدل ?: sherlock "user?name"
  • قد يكون لدى المستخدم إعدادات خصوصية أو حسابات محذوفة

مشكلات المهلة الزمنية

بعض المواقع بطيئة أو تحظر الطلبات الآلية. استخدم --timeout 120 لزيادة زمن الانتظار، أو --site لتضييق النطاق.

إعداد Tor

يتطلب --tor تشغيل خدمة Tor. إذا أراد المستخدم إخفاء الهوية ولم يكن Tor متاحًا، اقترح:

  • تثبيت خدمة Tor
  • استخدام --proxy مع خادم وكيل بديل

النتائج الإيجابية الخاطئة

بعض المواقع تُرجع دائمًا نتيجة "موجود" بسبب بنية استجابتها. قارن النتائج غير المتوقعة بفحوص يدوية.

تحديد المعدل

قد تؤدي عمليات البحث المكثفة إلى تفعيل حدود المعدل (rate limit). لعمليات البحث الدفعية عن أسماء مستخدمين متعددة، أضِف فواصل زمنية بين الاستدعاءات أو استخدم --local مع بيانات مخزَّنة محليًا.

الاستخدام الأخلاقي

هذه الأداة مخصّصة لأغراض OSINT والبحث المشروعة فقط. ذكّر المستخدمين بما يلي:

  • ابحث فقط عن أسماء المستخدمين التي تملكها أو لديك إذن للتحقيق فيها
  • احترم شروط خدمة المنصات
  • لا تستخدمها للتحرّش أو الملاحقة أو أي أنشطة غير قانونية
  • ضع في اعتبارك الآثار المترتبة على الخصوصية قبل مشاركة النتائج

التحقق

بعد تشغيل sherlock، تحقق من:

  1. أن الإخراج يعرض المواقع الموجودة مع الروابط
  2. إنشاء ملف <username>.txt (الإخراج الافتراضي) عند استخدام إخراج الملف
  3. إذا استُخدم --print-found، يجب أن يحتوي الإخراج فقط على أسطر [+] الخاصة بالمطابقات

مثال على التفاعل

المستخدم: "هل يمكنك التحقق من وجود اسم المستخدم 'johndoe123' على وسائل التواصل الاجتماعي؟"

إجراء الوكيل:

  1. تحقق من sherlock --version (تأكيد التثبيت)
  2. اسم المستخدم متوفّر — تابع مباشرة
  3. نفّذ: sherlock --print-found --no-color "johndoe123" --timeout 90
  4. حلّل الإخراج واعرض الروابط
