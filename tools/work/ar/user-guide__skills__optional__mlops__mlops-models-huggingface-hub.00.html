دليل مرجعي لواجهة سطر أوامر Hugging Face (hf)

الأمر hf هو واجهة سطر الأوامر الحديثة للتعامل مع Hugging Face Hub، وتوفّر أدوات لإدارة المستودعات والنماذج ومجموعات البيانات وSpaces.

مهم: الأمر hf يحلّ محلّ الأمر huggingface-cli المُهمَل (deprecated) الآن.

البدء السريع

  • التثبيت: curl -LsSf https://hf.co/cli/install.sh | bash -s
  • المساعدة: استخدم hf --help لعرض كل الوظائف المتاحة وأمثلة واقعية.
  • المصادقة: يُنصح بها عبر متغير البيئة HF_TOKEN أو الخيار --token.

الأوامر الأساسية

عمليات عامة

  • hf download REPO_ID: تنزيل ملفات من الـ Hub.
  • hf upload REPO_ID: رفع ملفات/مجلدات (يُنصح به للرفع بكوميت واحد؛ ويدعم أيضًا استئناف رفع المجلدات الكبيرة).
  • hf upload-large-folder REPO_ID LOCAL_PATH: [مُهمَل] — استخدم hf upload بدلًا منه.
  • hf sync: مزامنة الملفات بين مجلد محلي و bucket.
  • hf env / hf version: عرض تفاصيل البيئة والإصدار.

المصادقة (hf auth)

  • login / logout: إدارة الجلسات باستخدام tokens من huggingface.co/settings/tokens.
  • list / switch: إدارة عدة tokens وصول مخزّنة والتبديل بينها.
  • whoami: تحديد الحساب المسجَّل الدخول حاليًا.

إدارة المستودعات (hf repos)

  • create / delete: إنشاء المستودعات أو حذفها نهائيًا.
  • duplicate: استنساخ نموذج أو مجموعة بيانات أو Space إلى معرّف (ID) جديد.
  • move: نقل مستودع بين namespaces.
  • branch / tag: إدارة مراجع شبيهة بـ Git.
  • delete-files: إزالة ملفات محدَّدة باستخدام أنماط (patterns).

تفاعلات متخصّصة مع الـ Hub

مجموعات البيانات والنماذج

  • مجموعات البيانات: hf datasets list، وinfo، وparquet (سرد روابط parquet).
  • استعلامات SQL: hf datasets sql SQL — تنفيذ استعلامات SQL خام عبر DuckDB على روابط parquet لمجموعة البيانات.
  • النماذج: hf models list وinfo.
  • الأوراق البحثية: hf papers ls — عرض الأوراق البحثية اليومية.

النقاشات وطلبات السحب (hf discussions)

  • إدارة دورة حياة مساهمات الـ Hub: list، create، info، comment، close، reopen، وrename.
  • diff: عرض التغييرات في pull request.
  • merge: إنهاء pull requests.

البنية التحتية والحوسبة

  • Endpoints: نشر Inference Endpoints وإدارتها (deploy، pause، resume، scale-to-zero، catalog).
  • Jobs: تشغيل مهام حوسبة على بنية HF التحتية. يشمل ذلك hf jobs uv لتشغيل سكربتات Python مع اعتماديات مضمّنة، وstats لمراقبة الموارد.
  • Spaces: إدارة التطبيقات التفاعلية. يشمل ذلك dev-mode وhot-reload لملفات Python دون إعادة تشغيل كاملة.

التخزين والأتمتة

  • Buckets: إدارة كاملة لـ buckets شبيهة بـ S3 (create، cp، mv، rm، sync).
  • Cache: إدارة التخزين المحلي عبر list، وprune (إزالة المراجعات المنفصلة)، وverify (فحوصات checksum).
  • Webhooks: أتمتة سير العمل عبر إدارة webhooks الخاصة بالـ Hub (create، watch، enable/disable).
  • Collections: تنظيم عناصر الـ Hub في مجموعات (add-item، update، list).

استخدام متقدّم ونصائح

الخيارات العامة (Global Flags)

  • --format json: ينتج مخرجات قابلة للقراءة آليًا للأتمتة.
  • -q / --quiet: يقتصر المخرَج على المعرّفات (IDs) فقط.

الإضافات والمهارات

  • الإضافات: توسيع وظائف CLI عبر مستودعات GitHub باستخدام hf extensions install REPO_ID.
  • المهارات: إدارة مهارات مساعد الذكاء الاصطناعي باستخدام hf skills add.
