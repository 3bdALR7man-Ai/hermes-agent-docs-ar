معلومة

ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

مهارة مخططات Excalidraw

أنشئ مخططات بكتابة JSON عناصر Excalidraw القياسية وحفظها كملفات .excalidraw. يمكن سحب هذه الملفات وإفلاتها على excalidraw.com للعرض والتحرير. لا حسابات، لا مفاتيح API، لا مكتبات عرض (rendering) -- فقط JSON.

متى تستخدمها

ولّد ملفات .excalidraw لمخططات البنية المعمارية، والمخططات الانسيابية، ومخططات التسلسل، وخرائط المفاهيم، وغيرها. يمكن فتح الملفات على excalidraw.com أو رفعها للحصول على روابط قابلة للمشاركة.

سير العمل

  1. حمّل هذه المهارة (فعلت ذلك بالفعل)
  2. اكتب JSON العناصر -- مصفوفة من كائنات عناصر Excalidraw
  3. احفظ الملف باستخدام write_file لإنشاء ملف .excalidraw
  4. ارفعه اختياريًا للحصول على رابط قابل للمشاركة باستخدام scripts/upload.py عبر terminal

يرفع هذا الملف إلى excalidraw.com (بلا حاجة لحساب) ويطبع رابط URL قابلًا للمشاركة. يتطلب حزمة pip باسم cryptography (pip install cryptography).

مرجع تنسيق العناصر

الحقول المطلوبة (كل العناصر)

type, id (نص فريد), x, y, width, height

القيم الافتراضية (تخطَّها -- تُطبَّق تلقائيًا)

  • strokeColor: "#1e1e1e"
  • backgroundColor: "transparent"
  • fillStyle: "solid"
  • strokeWidth: 2
  • roughness: 1 (مظهر مرسوم باليد)
  • opacity: 100

خلفية اللوحة بيضاء.

أنواع العناصر

مستطيل:

  • roundness: { "type": 3 } لزوايا مستديرة
  • backgroundColor: "#a5d8ff", fillStyle: "solid" للتعبئة

شكل بيضاوي:

معيّن (Diamond):

شكل مُعنوَن (ربط بحاوية) -- أنشئ عنصر نص مربوطًا بالشكل:

تحذير: لا تستخدم "label": { "text": "..." } على الأشكال. هذه ليست خاصية Excalidraw صالحة وسيتم تجاهلها بصمت، مما ينتج أشكالًا فارغة. يجب عليك استخدام أسلوب ربط الحاوية أدناه.

يحتاج الشكل إلى boundElements يسرد النص، ويحتاج النص إلى containerId يشير إليه:

  • يعمل مع المستطيل والشكل البيضاوي والمعيّن
  • يتوسّط النص تلقائيًا بواسطة Excalidraw عند ضبط containerId
  • قيم x/y/width/height للنص تقريبية -- تُعيد Excalidraw حسابها عند التحميل
  • يجب أن يطابق originalText قيمة text
  • ضمّن دائمًا fontFamily: 1 (خط Virgil المرسوم باليد)

سهم مُعنوَن -- نفس أسلوب ربط الحاوية:

نص مستقل (للعناوين والتعليقات التوضيحية فقط -- بلا حاوية):

  • x هو الحافة اليسرى. للتوسيط عند الموضع cx: x = cx - (text.length * fontSize * 0.5) / 2
  • لا تعتمد على textAlign أو width لتحديد الموضع

سهم:

  • points: إزاحات [dx, dy] عن x, y الخاصَّين بالعنصر
  • endArrowhead: null | "arrow" | "bar" | "dot" | "triangle"
  • strokeStyle: "solid" (افتراضي) | "dashed" | "dotted"

روابط الأسهم (وصل الأسهم بالأشكال)

إحداثيات fixedPoint: top=[0.5,0], bottom=[0.5,1], left=[0,0.5], right=[1,0.5]

ترتيب الرسم (z-order)

  • ترتيب المصفوفة = ترتيب الطبقات (الأول = الخلف، الأخير = الأمام)
  • أضف العناصر تدريجيًا: مناطق الخلفية ← الشكل ← نصه المربوط ← أسهمه ← الشكل التالي
  • سيئ: كل المستطيلات، ثم كل النصوص، ثم كل الأسهم
  • جيد: bg_zone ← shape1 ← text_for_shape1 ← arrow1 ← arrow_label_text ← shape2 ← text_for_shape2 ← ...
  • ضع دائمًا عنصر النص المربوط مباشرة بعد شكل الحاوية الخاص به

إرشادات الأحجام

أحجام الخط:

  • الحد الأدنى لـ fontSize: 16 لنص الجسم، والتسميات، والأوصاف
  • الحد الأدنى لـ fontSize: 20 للعناوين والعناوين الرئيسية
  • الحد الأدنى لـ fontSize: 14 للتعليقات الثانوية فقط (باعتدال)
  • لا تستخدم أبدًا fontSize أقل من 14

أحجام العناصر:

  • الحد الأدنى لحجم الشكل: 120x60 للمستطيلات/الأشكال البيضاوية المُعنوَنة
  • اترك فجوات لا تقل عن 20-30 بكسل بين العناصر
  • فضّل عناصر أقل وأكبر بدلًا من عناصر صغيرة كثيرة
