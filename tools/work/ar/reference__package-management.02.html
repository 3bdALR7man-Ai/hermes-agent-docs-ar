عمر الإصدار ومرايا الحِزم (package mirrors)

يجب أن يكون عمر كل حزمة Python يعتمد عليها Hermes نفسه ثلاثة أيام على الأقل عندما يقفلها Hermes (الخيار exclude-newer في uv، ويفرضه فحص lock في CI)، فلا يمكن لإصدار منشور حديثًا وربما مخترَق أن يصل إلى uv.lock. ويثبّت المستخدمون من ذلك lock، ولا يعيد تثبيتُ إضافة أو تفعيلها فحصَ التواريخ، لذلك تعمل مرايا الحِزم التي لا تنشر أوقات الرفع. والاستثناء الوحيد هو مخازن الثقة في CA (certifi): فالإصدار الذي يسحب الثقة من CA مخترَقة يُقفل في يوم صدوره، لأن الانتظار يُبقي الجذر السيئ موثوقًا. اضبط مرآة عبر index-url في pip.conf، الذي يمرّره Hermes إلى uv، أو عبر UV_INDEX_URL.

hermes pm lock هو الخطوة الوحيدة التي تطبّق هذا الفحص. وإذا نفّذته على مرآة لا تحتوي أوقات رفع، فسيتوقف برسالة has no publish time؛ استخدم https://pypi.org/simple لتلك الخطوة.

التشخيص

  • بناء اعتماديات Python بطيء: تفعّل أوامر uv المتدفقة من PM المخرجات التفصيلية. تعرض سجلات الحزم والبناء نشاط الحزم و stdout/stderr الخاص بـ build-backend أثناء البناء، لا بعد الفشل فقط.
  • أداة مفقودة أو قديمة: اقرأ hermes pm doctor ، ثم استخدم تثبيت PM صريحًا على تثبيت قابل للكتابة.
  • بيئة جديدة تتطلب إعادة التشغيل: أعد تشغيل عملية Hermes المتأثرة. لا تضف شجرة site-packages ثانية إلى استيراداتها الحيّة.
  • تعارض اعتماديات: اقرأ hermes pm status. صحّح متطلبات الإضافة قبل إعادة محاولة القبول.
  • اعتماديات Python متضررة: شغّل hermes pm repair ، ثم أعد تشغيل Hermes. يعيد الإصلاح بناء مساحة عمل الجيل المحدد و lock المحفوظين دون تحليل إعدادات الإضافات. السجل غير المقروء أو lock المحفوظ المفقود يفشل دون اختيار مجموعة اعتماديات ناقصة. قبل وجود جيل، يستخدم الإصلاح lock المشحون أو المعتمد ومجموعة الميزات المسجّلة.
  • تثبيت اعتماديات منقطع: يطلب بدء التشغيل إصلاح PM نفسه قبل تفعيل الاعتماديات. المحاولات التلقائية محدودة؛ ويعيد pm repair المحاولة صراحة. يحفظ الإصلاح الفاشل الاختيار السابق وعلامة إعادة المحاولة.
  • ملف Python تنفيذي أو مصدر تطبيق متضرر: أصلح أو أعد التثبيت عبر مالك الحزمة. لا يستطيع PM العمل دون تلك الملفات. لا يعدّل إصلاح الاعتماديات ملفات الحمولة الموقّعة مطلقًا.
  • حزمة أو extra غير معروفة: استخدم الاسم المعلن. يأخذ pm install أسماء الحزم، لا أسماء extras الخاصة بـ Python أو مواصفات pip.
