مهارة ASCII Art

أدوات متعددة لاحتياجات مختلفة من فن ASCII. كل الأدوات إما برامج CLI محلية أو REST APIs مجانية — لا حاجة لمفاتيح API.

الأداة 1: لافتات نصية (pyfiglet — محلية)

حوّل النص إلى لافتات فن ASCII كبيرة. 571 خطًا مدمجًا.

الأداة 2: لافتات نصية (asciified API — عن بُعد، بلا تثبيت)

REST API مجاني يحوّل النص إلى فن ASCII. أكثر من 250 خط FIGlet. يُعيد نصًا صرفًا مباشرة — بلا حاجة للتحليل (parsing). استخدمه عندما لا يكون pyfiglet مثبّتًا أو كبديل سريع.

الاستخدام (عبر terminal بأمر curl)

نصائح

  • رمّز المسافات في معامل النص كـ + (URL-encode)
  • الاستجابة هي فن ASCII نصي صرف — بلا تغليف JSON، جاهز للعرض مباشرة
  • أسماء الخطوط حساسة لحالة الأحرف؛ استخدم endpoint الخطوط للحصول على الأسماء الدقيقة
  • يعمل من أي terminal يحتوي على curl — لا حاجة لـ Python أو pip

الأداة 5: TOIlet (فن نصي ملوّن)

مثل pyfiglet لكن مع تأثيرات ألوان ANSI ومرشحات (filters) بصرية. رائعة لإضفاء لمسة جمالية على الـ terminal.

الاستخدام

ملاحظة: تُخرج toilet أكواد ANSI escape للألوان — تعمل في الطرفيات لكن قد لا تُعرض بشكل صحيح في كل السياقات (مثل ملفات النصوص الصرفة أو بعض منصات المحادثة).

الأداة 9: فن مخصّص يولّده LLM (احتياطي)

عندما لا توفّر الأدوات أعلاه ما هو مطلوب، ولّد فن ASCII مباشرة باستخدام أحرف Unicode التالية:

لوحة الأحرف

رسم الصناديق: ╔ ╗ ╚ ╝ ║ ═ ╠ ╣ ╦ ╩ ╬ ┌ ┐ └ ┘ │ ─ ├ ┤ ┬ ┴ ┼ ╭ ╮ ╰ ╯

عناصر الكتل: ░ ▒ ▓ █ ▄ ▀ ▌ ▐ ▖ ▗ ▘ ▝ ▚ ▞

الأشكال الهندسية والرموز: ◆ ◇ ◈ ● ○ ◉ ■ □ ▲ △ ▼ ▽ ★ ☆ ✦ ✧ ◀ ▶ ◁ ▷ ⬡ ⬢ ⌂

القواعد

  • العرض الأقصى: 60 حرفًا لكل سطر (آمن لعرض الـ terminal)
  • الارتفاع الأقصى: 15 سطرًا للافتات، و25 للمشاهد
  • أحادي المسافة فقط: يجب أن يُعرض الناتج بشكل صحيح في الخطوط ثابتة العرض

مخطط اتخاذ القرار

  1. نص كلافتة ← pyfiglet إن كان مثبّتًا، وإلا فـ asciified API عبر curl
  2. وضع رسالة داخل فن شخصيات ممتع ← cowsay
  3. إضافة حدود/إطار زخرفي ← boxes (يمكن دمجها مع pyfiglet/asciified)
  4. فن لشيء محدد (قطة، صاروخ، تنين) ← ascii.co.uk عبر curl والتحليل (parsing)
  5. تحويل صورة إلى ASCII ← ascii-image-converter أو jp2a
  6. رمز QR ← qrenco.de عبر curl
  7. فن الطقس/القمر ← wttr.in عبر curl
  8. شيء مخصّص/إبداعي ← توليد بواسطة LLM مع لوحة Unicode
  9. أي أداة غير مثبّتة ← ثبّتها، أو انتقل إلى الخيار التالي
