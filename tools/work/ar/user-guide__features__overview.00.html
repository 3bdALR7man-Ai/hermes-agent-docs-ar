نظرة عامة على الميزات

يتضمن Hermes Agent مجموعة غنية من القدرات التي تتجاوز المحادثة الأساسية بكثير. فمن الذاكرة الدائمة والسياق المُدرك للملفات إلى أتمتة المتصفح والمحادثات الصوتية، تعمل هذه الميزات معًا لتجعل من Hermes مساعدًا مستقلًا وقويًا.

لا تعرف من أين تبدأ؟

يُعدّ الأمر hermes setup --portal مزوّد نماذج إضافةً إلى أدوات Tool Gateway الأربع جميعها (البحث في الويب، وتوليد الصور، و TTS، والمتصفح) بأمر واحد. راجع Nous Portal.

الأساسيات

  • الأدوات و Toolsets — الأدوات دوال توسّع قدرات الوكيل. وهي منظّمة في toolsets منطقية يمكن تفعيلها أو تعطيلها لكل منصة، وتغطي البحث في الويب، والتنفيذ في الطرفية، وتحرير الملفات، والذاكرة، والتفويض، وغير ذلك.
  • نظام المهارات (Skills) — مستندات معرفية عند الطلب يمكن للوكيل تحميلها عند الحاجة. تتبع المهارات نمط الإفصاح التدريجي (progressive disclosure) لتقليل استهلاك الـ tokens، وهي متوافقة مع المعيار المفتوح agentskills.io.
  • الذاكرة الدائمة (Persistent Memory) — ذاكرة محدودة الحجم ومنتقاة تستمر عبر الجلسات. يتذكر Hermes تفضيلاتك ومشاريعك وبيئتك والأشياء التي تعلّمها عبر MEMORY.md و USER.md.
  • ملفات السياق (Context Files) — يكتشف Hermes تلقائيًا ملفات سياق المشروع (.hermes.md و AGENTS.md و CLAUDE.md و SOUL.md و .cursorrules) ويحمّلها، وهي التي تحدد سلوكه داخل مشروعك.
  • مراجع السياق (Context References) — اكتب @ متبوعًا بمرجع لحقن الملفات والمجلدات و git diffs وعناوين URL مباشرةً في رسائلك. يوسّع Hermes المرجع ضمن السطر ويُلحق المحتوى تلقائيًا.
  • نقاط الحفظ (Checkpoints) — يأخذ Hermes تلقائيًا لقطة من مجلد العمل قبل إجراء تغييرات على الملفات، مما يمنحك شبكة أمان للتراجع باستخدام /rollback إذا حدث خطأ ما.

الأتمتة

  • المهام المجدولة (Cron) — جدول المهام لتعمل تلقائيًا باستخدام اللغة الطبيعية أو تعبيرات cron. يمكن للمهام إرفاق مهارات وتسليم النتائج إلى أي منصة، كما تدعم عمليات الإيقاف المؤقت/الاستئناف/التعديل.
  • تفويض المهام إلى Subagents — تُطلق الأداة delegate_task نُسخًا فرعية من الوكيل بسياق معزول و toolsets مقيّدة وجلسات طرفية خاصة بها. ويمكن تشغيل 3 subagents متزامنة افتراضيًا (العدد قابل للضبط) لمسارات عمل متوازية.
  • تنفيذ الكود — تتيح الأداة execute_code للوكيل كتابة سكربتات Python تستدعي أدوات Hermes برمجيًا، مما يختزل سير العمل متعدد الخطوات في دور LLM واحد عبر تنفيذ RPC داخل sandbox.
  • Event Hooks — شغّل كودًا مخصصًا عند النقاط الرئيسية في دورة الحياة. تتولى hooks الـ gateway التسجيل والتنبيهات و webhooks؛ بينما تتولى hooks الإضافات اعتراض الأدوات والمقاييس وضوابط الحماية (guardrails).
  • المعالجة الدفعية (Batch Processing) — شغّل وكيل Hermes على مئات أو آلاف الـ prompts بالتوازي، مع توليد بيانات trajectory منظّمة بصيغة ShareGPT لتوليد بيانات التدريب أو للتقييم.

الوسائط والويب

  • الوضع الصوتي (Voice Mode) — تفاعل صوتي كامل عبر CLI ومنصات المراسلة. تحدّث إلى الوكيل باستخدام الميكروفون، واستمع إلى الردود المنطوقة، وأجرِ محادثات صوتية مباشرة في القنوات الصوتية على Discord.
  • كلمة التنبيه (Wake Word) — تفعيل دون استخدام اليدين عبر عبارة "Hey Hermes" في CLI و TUI وتطبيق سطح المكتب. يبدأ مستمع كلمة التنبيه العامل على الجهاز نفسه جلسة صوتية عندما تنطق عبارة التنبيه.
  • أتمتة المتصفح — أتمتة كاملة للمتصفح مع عدة backends: خدمة Browserbase السحابية، أو خدمة Browser Use السحابية، أو Chrome/Brave/Chromium/Edge محليًا عبر CDP، أو Chromium محلي. تصفّح المواقع، واملأ النماذج، واستخرج المعلومات.
  • الرؤية (Vision) ولصق الصور — دعم الرؤية متعددة الوسائط. الصق الصور من الحافظة في CLI واطلب من الوكيل تحليلها أو وصفها أو العمل عليها باستخدام أي نموذج يدعم الرؤية.
  • توليد الصور — ولّد الصور من prompts نصية باستخدام FAL.ai. هناك أحد عشر نموذجًا مدعومًا (FLUX 2 Klein/Pro، و GPT-Image 1.5/2، و Nano Banana Pro، و Ideogram V3، و Recraft V4 Pro، و Qwen، و Z-Image Turbo، و Krea V2 Medium/Large)؛ اختر أحدها عبر hermes tools.
  • الصوت و TTS — تحويل النص إلى كلام وتفريغ الرسائل الصوتية نصيًا عبر جميع منصات المراسلة، مع عشرة خيارات لمزوّدين أصليين: Edge TTS (مجاني)، و ElevenLabs، و OpenAI TTS، و MiniMax، و Mistral Voxtral، و Google Gemini، و xAI، و NeuTTS، و KittenTTS، و Piper — إضافةً إلى مزوّدي الأوامر المخصصة لأي CLI محلي لـ TTS.

التكاملات

  • التكامل مع MCP — اتصل بأي خادم MCP عبر نقل stdio أو HTTP. واستخدم أدوات خارجية من GitHub وقواعد البيانات وأنظمة الملفات وواجهات API الداخلية دون كتابة أدوات Hermes أصلية. ويتضمن تصفية الأدوات لكل خادم ودعم sampling.
  • توجيه المزوّدين (Provider Routing) — تحكّم دقيق في مزوّدي الذكاء الاصطناعي الذين يعالجون طلباتك. حسّن التكلفة أو السرعة أو الجودة عبر الفرز وقوائم السماح وقوائم الحظر وترتيب الأولويات.
  • المزوّدون الاحتياطيون (Fallback Providers) — تحويل تلقائي إلى مزوّدي LLM احتياطيين عندما يواجه نموذجك الأساسي أخطاء، بما في ذلك fallback مستقل للمهام المساعدة مثل الرؤية والضغط.
  • مجمّعات بيانات الاعتماد (Credential Pools) — وزّع استدعاءات API على عدة مفاتيح للمزوّد نفسه، مع تدوير تلقائي عند بلوغ حدّ المعدل أو حدوث أعطال.
  • التخزين المؤقت للـ Prompt (Prompt caching) — تخزين مؤقت مدمج للبادئات يمتد عبر الجلسات لمدة ساعة لنماذج Claude على Anthropic مباشرةً و OpenRouter و Nous Portal. مفعّل دائمًا؛ ولا يتطلب أي إعداد.
  • مزوّدو الذاكرة (Memory Providers) — أضف backends ذاكرة خارجية (Honcho و OpenViking و Mem0 و Hindsight و Holographic و RetainDB و ByteRover و Supermemory) لنمذجة المستخدم عبر الجلسات والتخصيص بما يتجاوز نظام الذاكرة المدمج.
  • خادم API — اعرض Hermes كـ HTTP endpoint متوافق مع OpenAI. واربط أي واجهة أمامية تتعامل بصيغة OpenAI — مثل Open WebUI و LobeChat و LibreChat وغيرها.
  • التكامل مع IDE (ACP) — استخدم Hermes داخل المحررات المتوافقة مع ACP مثل VS Code و Zed و JetBrains. تُعرض المحادثة ونشاط الأدوات وفروق الملفات وأوامر الطرفية داخل محررك.
  • المعالجة الدفعية (Batch Processing) — شغّل الوكيل على العديد من الـ prompts أو المهام بالتوازي من CLI، مع مخرجات منظّمة والتقاط لبيانات trajectory مناسب لعمليات التقييم (evals) أو لـ pipelines التدريب اللاحقة.

التخصيص

  • الشخصية و SOUL.md — شخصية وكيل قابلة للتخصيص بالكامل. يُعد SOUL.md ملف الهوية الأساسي — وهو أول ما يرد في الـ system prompt — ويمكنك التبديل بين الإعدادات المسبقة لـ /personality، المدمجة منها أو المخصصة، لكل جلسة.
  • المظاهر والسمات (Skins & Themes) — خصّص المظهر المرئي لـ CLI: ألوان الشعار، ووجوه مؤشر الانتظار (spinner) وأفعاله، وتسميات صندوق الرد، ونص العلامة التجارية، وبادئة نشاط الأدوات.
  • الإضافات (Plugins) — أضف أدوات و hooks وتكاملات مخصصة دون تعديل الكود الأساسي. هناك ثلاثة أنواع من الإضافات: الإضافات العامة (أدوات/hooks)، ومزوّدو الذاكرة (معرفة عبر الجلسات)، ومحركات السياق (context engines) لإدارة السياق بطريقة بديلة. وتُدار عبر الواجهة التفاعلية الموحّدة hermes plugins.
