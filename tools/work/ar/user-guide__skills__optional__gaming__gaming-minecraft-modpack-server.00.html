إعداد خادم حزمة تعديلات Minecraft

متى تُستخدم

  • يريد المستخدم إعداد خادم Minecraft مُعدَّل من ملف zip لحزمة الخادم
  • يحتاج المستخدم إلى مساعدة في إعداد NeoForge/Forge للخادم
  • يسأل المستخدم عن ضبط أداء خادم Minecraft أو النسخ الاحتياطي

اجمع تفضيلات المستخدم أولًا

قبل بدء الإعداد، اسأل المستخدم عن:

  • اسم الخادم / رسالة اليوم (MOTD) — ماذا يجب أن يظهر في قائمة الخوادم؟
  • البذرة (Seed) — بذرة محددة أم عشوائية؟
  • الصعوبة — سلمية / سهلة / عادية / صعبة؟
  • نمط اللعب — البقاء / الإبداع / المغامرة؟
  • الوضع المتصل (Online mode) — صحيح (مصادقة Mojang، حسابات شرعية) أم خاطئ (مناسب لشبكة محلية/حسابات مقرصنة)؟
  • عدد اللاعبين — كم عدد اللاعبين المتوقع؟ (يؤثر على ضبط الذاكرة العشوائية ومسافة الرؤية)
  • تخصيص الذاكرة العشوائية (RAM) — أم تترك الوكيل يقرر بناءً على عدد التعديلات والذاكرة المتاحة؟
  • مسافة الرؤية / مسافة المحاكاة — أم تترك الوكيل يختار بناءً على عدد اللاعبين والعتاد؟
  • PvP — مفعّل أم معطّل؟
  • القائمة البيضاء — خادم مفتوح أم قائمة بيضاء فقط؟
  • النسخ الاحتياطي — هل تريد نسخًا احتياطيًا تلقائيًا؟ كم مرة؟

استخدم قيمًا افتراضية معقولة إذا لم يهتم المستخدم، لكن اسأل دائمًا قبل توليد الإعدادات.

الخطوات

1. نزّل الحزمة وافحصها

ابحث عن: startserver.sh، وملف تثبيت jar (neoforge/forge)، وuser_jvm_args.txt، ومجلد mods/. تحقّق من السكربت لتحديد: نوع مُحمِّل التعديلات، والإصدار، وإصدار Java المطلوب.

2. ثبّت Java

  • Minecraft 1.21+ ← Java 21: sudo apt install openjdk-21-jre-headless
  • Minecraft 1.18-1.20 ← Java 17: sudo apt install openjdk-17-jre-headless
  • Minecraft 1.16 وما دونه ← Java 8: sudo apt install openjdk-8-jre-headless
  • تحقّق: java -version

6. اضبط معطيات JVM (user_jvm_args.txt)

اضبط الذاكرة العشوائية حسب عدد اللاعبين وعدد التعديلات. قاعدة عامة للخوادم المُعدَّلة:

  • 100-200 تعديل: 6-12 جيجابايت
  • 200-350+ تعديل: 12-24 جيجابايت
  • اترك 8 جيجابايت على الأقل حرة لنظام التشغيل/المهام الأخرى

7. افتح جدار الحماية

تحقّق باستخدام: sudo ufw status | grep 25565

8. أنشئ سكربت تشغيل

ملاحظة: بالنسبة لـ Forge (وليس NeoForge)، يختلف مسار ملف المعطيات. تحقّق من startserver.sh لمعرفة المسار الدقيق.

مزالق شائعة

  • اضبط دائمًا allow-flight=true للخوادم المُعدَّلة — التعديلات التي تحتوي على نفاثات/طيران ستطرد اللاعبين وإلا
  • max-tick-time=180000 أو أعلى — غالبًا ما تكون للخوادم المُعدَّلة دورات (ticks) طويلة أثناء توليد العالم
  • التشغيل الأول بطيء (عدة دقائق للحزم الكبيرة) — لا داعي للقلق
  • تحذيرات "Can't keep up!" عند التشغيل الأول طبيعية، وتستقر بعد توليد القطع (chunks) الأولي
  • إذا كان online-mode=false، اضبط enforce-secure-profile=false أيضًا وإلا سيُرفض العملاء
  • غالبًا ما يحتوي startserver.sh الخاص بالحزمة على حلقة إعادة تشغيل تلقائية — أنشئ سكربت تشغيل نظيف بدونها
  • احذف مجلد world/ لإعادة التوليد ببذرة جديدة
  • بعض الحزم لديها متغيرات بيئة للتحكم بالسلوك (مثلًا، تستخدم ATM10: ATM10_JAVA وATM10_RESTART وATM10_INSTALL_ONLY)

التحقق

  • pgrep -fa neoforge أو pgrep -fa minecraft للتحقق مما إذا كان قيد التشغيل
  • تحقّق من السجلات: tail -f ~/minecraft-server/server/logs/latest.log
  • ابحث عن "Done (Xs)!" في السجل = الخادم جاهز
  • اختبر الاتصال: يضيف اللاعب عنوان IP الخاص بالخادم في وضع اللاعبين المتعددين
