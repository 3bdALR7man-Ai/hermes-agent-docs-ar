Canvas LMS — الوصول إلى المقررات والواجبات

وصول للقراءة فقط إلى Canvas LMS لسرد المقررات والواجبات.

السكربتات

  • scripts/canvas_api.py — سكربت Python لاستدعاءات Canvas API

الإعداد

  1. سجّل الدخول إلى نسخة Canvas الخاصة بك عبر المتصفح
  2. انتقل إلى Account → Settings (انقر رمز ملفك الشخصي، ثم Settings)
  3. مرّر إلى Approved Integrations وانقر + New Access Token
  4. سمِّ الرمز (مثلًا "Hermes Agent")، واضبط تاريخ انتهاء اختياريًا، وانقر Generate Token
  5. انسخ الرمز وأضفه إلى ${HERMES_HOME:-~/.hermes}/.env:

الرابط الأساسي هو أي رابط يظهر في متصفحك عندما تكون مسجّلًا الدخول إلى Canvas (دون شرطة مائلة ختامية).

الاستخدام

صيغة المخرجات

يُعيد list_courses:

يُعيد list_assignments:

ملاحظة: تُختصر أوصاف الواجبات إلى 500 حرف. يربط الحقل html_url بصفحة الواجب الكاملة في Canvas.

مرجع API (curl)

يستخدم Canvas ترويسات Link للتصفح بالصفحات (pagination). يتولّى سكربت Python هذا التصفح تلقائيًا.

القواعد

  • هذه المهارة للقراءة فقط — تجلب البيانات فقط، ولا تُعدّل المقررات أو الواجبات أبدًا
  • عند أول استخدام، تحقق من المصادقة بتشغيل $CANVAS list_courses — إذا فشل بخطأ 401، أرشد المستخدم خلال الإعداد
  • يحدّ Canvas معدل الطلبات إلى نحو 700 طلب كل 10 دقائق؛ تحقق من ترويسة X-Rate-Limit-Remaining عند بلوغ الحدود
