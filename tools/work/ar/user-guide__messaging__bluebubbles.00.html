BlueBubbles (iMessage)

اربط Hermes بخدمة Apple iMessage عبر BlueBubbles — وهو خادم مجاني ومفتوح المصدر يعمل على macOS ويصل iMessage بأي جهاز.

المتطلبات المسبقة

  • جهاز Mac (يعمل باستمرار) يشغّل BlueBubbles Server
  • حساب Apple ID مسجَّل الدخول في Messages.app على ذلك الـ Mac
  • BlueBubbles Server بالإصدار v1.0.0 أو أحدث (تتطلب الـ webhooks هذا الإصدار)
  • اتصال شبكي بين Hermes وخادم BlueBubbles

الإعداد

1. تثبيت BlueBubbles Server

نزّله وثبّته من bluebubbles.app. أكمل معالج الإعداد — سجّل الدخول بحساب Apple ID الخاص بك واضبط طريقة الاتصال (الشبكة المحلية، أو Ngrok، أو Cloudflare، أو Dynamic DNS).

2. الحصول على عنوان URL للخادم وكلمة المرور

في BlueBubbles Server → Settings → API، دوّن ما يلي:

  • Server URL (مثلًا http://192.168.1.10:1234)
  • Server Password

5. تشغيل الـ Gateway

سيتصل Hermes بخادم BlueBubbles الخاص بك، ويسجّل webhook، ثم يبدأ بالاستماع لرسائل iMessage.

آلية العمل

  • الوارد: يرسل BlueBubbles أحداث webhook إلى مستمع محلي عند وصول رسائل جديدة. لا يوجد استطلاع دوري (polling) — فالتسليم فوري.
  • الصادر: يرسل Hermes الرسائل عبر BlueBubbles REST API.
  • الوسائط: الصور والرسائل الصوتية ومقاطع الفيديو والمستندات مدعومة في الاتجاهين. وتُنزَّل المرفقات الواردة وتُخزَّن مؤقتًا محليًا كي يعالجها الوكيل.

الميزات

المراسلة النصية

أرسل رسائل iMessage واستقبلها. ويُزال تنسيق Markdown تلقائيًا لتسليم نص عادي نظيف.

الوسائط الغنية

  • الصور: تظهر الصور بشكل أصلي في محادثة iMessage
  • الرسائل الصوتية: تُرسَل الملفات الصوتية كرسائل iMessage صوتية
  • مقاطع الفيديو: مرفقات فيديو
  • المستندات: تُرسَل الملفات كمرفقات iMessage

تفاعلات Tapback

تفاعلات الحب والإعجاب وعدم الإعجاب والضحك والتأكيد والاستفهام. تتطلب Private API helper الخاص بـ BlueBubbles.

مؤشرات الكتابة

يعرض "typing..." في محادثة iMessage أثناء معالجة الوكيل للرسالة. يتطلب Private API.

إشعارات القراءة

يضع علامة "مقروءة" على الرسائل تلقائيًا بعد معالجتها. يتطلب Private API.

تحديد المحادثات

يمكنك تحديد المحادثات بالبريد الإلكتروني أو رقم الهاتف — إذ يحوّلها Hermes تلقائيًا إلى معرّفات GUID للمحادثات في BlueBubbles، فلا حاجة إلى استخدام صيغة GUID الخام.

Private API

تتطلب بعض الميزات Private API helper الخاص بـ BlueBubbles:

  • تفاعلات Tapback
  • مؤشرات الكتابة
  • إشعارات القراءة
  • إنشاء محادثات جديدة عبر العنوان

ومن دون Private API، تظل المراسلة النصية الأساسية والوسائط تعمل.

استكشاف الأخطاء وإصلاحها

ظهور "Cannot reach server"

  • تحقق من صحة عنوان URL للخادم ومن أن الـ Mac قيد التشغيل
  • تحقق من أن BlueBubbles Server يعمل
  • تأكد من الاتصال الشبكي (جدار الحماية، وإعادة توجيه المنافذ)

الرسائل لا تصل

  • تحقق من تسجيل الـ webhook في BlueBubbles Server → Settings → API → Webhooks
  • تحقق من إمكانية الوصول إلى عنوان URL للـ webhook من الـ Mac
  • راجع hermes logs gateway بحثًا عن أخطاء الـ webhook (أو استخدم hermes logs -f لمتابعة السجلات لحظيًا)

ظهور "Private API helper not connected"

  • ثبّت Private API helper: docs.bluebubbles.app
  • تعمل المراسلة الأساسية من دونه — ولا تتطلبه إلا التفاعلات ومؤشرات الكتابة وإشعارات القراءة
