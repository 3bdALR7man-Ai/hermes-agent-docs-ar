Photon iMessage

اربط Hermes بخدمة iMessage عبر Photon، وهي خدمة مُدارة تتولى تخصيص خطوط Apple وطبقة منع إساءة الاستخدام، فلا تحتاج إلى تشغيل وسيط (relay) خاص بك على جهاز Mac.

تستخدم الفئة المجانية مجموعة خطوط iMessage المشتركة لدى Photon — فقد يرى المستلمون المختلفون أرقام إرسال مختلفة، لكن كل محادثة تبقى ثابتة على رقمها. أما فئة Business المدفوعة فتمنح جميع المستخدمين الرقم المخصص نفسه؛ وتدعم الإضافة (plugin) كلتا الفئتين، والفئة المجانية هي نقطة البداية الموصى بها.

مجاني للبدء

مجموعة الخطوط المشتركة لدى Photon مجانية. لا يلزمك أي اشتراك لإرسال أول رسالة iMessage من Hermes — كل ما تحتاج إليه رقم هاتف يمكن ربطه بحسابك.

البنية

Photon قناة تعتمد على اتصال دائم، مثل Discord أو Slack — لا webhook، ولا عنوان URL عام، ولا سر توقيع (signing secret) تحتاج إلى إدارته.

تحتفظ SDK المسمّاة spectrum-ts بـ تدفق gRPC طويل الأمد مع Photon في الاتجاهين. ولأن هذه الـ SDK متاحة بلغة TypeScript فقط، يشغّلها Hermes داخل Node sidecar صغير خاضع للإشراف، ويتواصل معه عبر عنوان loopback:

  • الوارد — يستهلك الـ sidecar تدفق gRPC ‏app.messages الخاص بالـ SDK ويمرّر كل رسالة إلى محوّل (adapter) Python عبر طلب loopback GET /inbound ‏(NDJSON). ويزيل المحوّل الرسائل المكررة ويوجّهها إلى الوكيل، ويعيد الاتصال تلقائيًا إذا انقطع التدفق.
  • الصادر — الردود عبارة عن طلبات POST عبر loopback إلى الـ sidecar، الذي يستدعي space.send(...) في الـ SDK.

تتولى إضافة Python تشغيل الـ sidecar والإشراف عليه وإيقافه تلقائيًا.

المتطلبات المسبقة

  • حساب Photon — سجّل عبر app.photon.codes
  • Node.js 18.17 أو أحدث ضمن PATH ‏(node --version)
  • رقم هاتف يستقبل رسائل iMessage (يُستخدم لربط حسابك)

هذا كل شيء — لا يوجد عنوان URL عام أو نفق (tunnel) يلزم إعداده.

الحالة واستكشاف الأخطاء وإصلاحها

يطبع هذا الأمر بيانات الاعتماد المحفوظة، وحالة سلامة الـ sidecar، ورقمك المسجّل، وخط iMessage المخصص الذي يستخدمه Hermes. وعند توفر token لـ Photon ومشروع في لوحة التحكم، يحدّث status صفوف الأرقام الناقصة من لوحة التحكم دون تخصيص خطوط جديدة.

المشكلات الشائعة:

  • sidecar deps : ✗ run hermes photon install-sidecar — Node مثبّت لكن spectrum-ts غير مثبّتة. شغّل الأمر المقترح.
  • device token : ✗ missing — شغّل hermes photon setup لتسجيل الدخول.
  • No iMessage line assigned yet — Spectrum مفعّل لكن لم يُخصَّص أي خط بعد؛ أعد تشغيل hermes photon setup أو راجع لوحة التحكم.
  • الـ sidecar لا يبدأ العمل — تأكد من أن node --version يُظهر الإصدار 18.17 أو أحدث، ومن أن hermes photon install-sidecar اكتمل دون أخطاء.

القيود الحالية

  • المرفقات الواردة تقتصر على البيانات الوصفية. تحمل الأحداث الواردة اسم الملف + نوع MIME؛ فيرى الوكيل علامة تدل على المرفق لكنه لا يستطيع بعد قراءة محتواه. وتتيح الـ SDK محتوى المرفقات عبر content.read()، لذا فهذه مهمة متابعة في الـ sidecar.
  • المرفقات الصادرة مدعومة. يرسل Hermes الصور والملاحظات الصوتية ومقاطع الفيديو والمستندات عبر مُنشئات المحتوى attachment() / voice() في spectrum-ts، من خلال endpoint ‏/send-attachment الخاص بالـ sidecar. وتصل التعليقات التوضيحية كفقاعة iMessage منفصلة بعد الوسائط.
  • الاستطلاعات الأصلية مدعومة. يرسل Hermes محتوى الاستطلاع عبر المُنشئ poll() في spectrum-ts، من خلال endpoint ‏/send-poll الخاص بالـ sidecar.
  • إشعارات القراءة مدعومة. يضع الـ sidecar علامة "مقروءة" على رسالة iMessage الواردة بعد تمريرها إلى Hermes، فيرى المرسل Read دون انتظار دور النموذج/الأدوات. أما إشعارات القراءة الواردة للرسائل التي أرسلها Hermes فتُستهلك كبيانات قياس عن بُعد للحضور (presence telemetry) ولا تُنشئ أبدًا دورًا للوكيل. اضبط PHOTON_READ_RECEIPTS=false لإبقاء الرسائل عند حالة Delivered.
  • مؤثرات الرسائل مدعومة. يرسل Hermes النصوص مع مؤثرات الفقاعة/الشاشة الأصلية في iMessage عبر المُنشئ effect() الخاص بـ iMessage في spectrum-ts، من خلال endpoint ‏/send-effect الخاص بالـ sidecar.
  • الحصص المجانية في Photon: 5,000 رسالة لكل خادم يوميًا، و 50 محادثة جديدة يمكن بدؤها لكل خط مشترك يوميًا. ويمكن زيادة هذه الحصص — راسل help@photon.codes.
  • تحتاج مهام cron وعمليات الإرسال المستقلة إلى تشغيل الـ gateway. تعيد جهات الإرسال العاملة خارج العملية (مهام cron، و hermes send، ولوحة التحكم) استخدام الـ sidecar الذي أنشأه الـ gateway — إذ تقرأ المنفذ/الـ token الخاص به من <hermes-home>/runtime/photon-sidecar.json، الذي يُكتب بمجرد اجتياز الـ sidecar فحص السلامة ويُحذف عند توقفه. وإذا أفادت عملية إرسال مستقلة بأن الـ gateway يبدو متوقفًا، فشغّل الـ gateway (أو أعد تشغيله) أولًا.
  • لا تستطيع الخطوط المشتركة/خطوط الفئة المجانية بدء محادثات مع مستلمين جدد. وهذه سياسة من جانب Photon: لا يمكن للخط المشترك مراسلة رقم إلا بعد أن يرسل ذلك الرقم رسالة إلى الخط أولًا. لذا سيرفض Photon أي إرسال عبر cron أو إرسال مستقل إلى مستلم جديد تمامًا حتى لو كان Hermes مُعدًّا بشكل صحيح — فإما أن تطلب من المستلم مراسلة الخط مرة واحدة، أو أن تنتقل إلى خط مخصص.
