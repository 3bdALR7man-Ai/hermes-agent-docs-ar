ملاحظات

  • استخدم --output json للحصول على مخرجات منظّمة أسهل في التحليل
  • الخوادم العرضية (رابط HTTP أو أمر --stdio) تعمل دون أي إعدادات — مفيدة للاستدعاءات لمرة واحدة
