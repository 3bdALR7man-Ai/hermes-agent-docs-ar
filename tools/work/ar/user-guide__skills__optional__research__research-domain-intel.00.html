توافقية المنصات

مكتبة Python القياسية (stdlib) الخالصة (socket، ssl، urllib، json، concurrent.futures). تعمل بالطريقة نفسها على Linux وmacOS وWindows دون أي اعتماديات.

  • استعلامات crt.sh تستخدم HTTPS (المنفذ 443) — تعمل خلف معظم جدران الحماية
  • استعلامات WHOIS تستخدم منفذ TCP رقم 43 — قد تُحجب على الشبكات المقيَّدة
  • استعلامات DNS تستخدم Google DoH (HTTPS) لسجلات MX/NS/TXT — مناسبة لجدران الحماية
  • فحوصات SSL تتصل بالهدف على المنفذ 443 — العملية "النشطة" الوحيدة

مصادر البيانات

جميع الاستعلامات سلبية — لا فحص منافذ، ولا اختبار ثغرات:

  • crt.sh — سجلّات شفافية الشهادات (اكتشاف النطاقات الفرعية، HTTPS فقط)
  • خوادم WHOIS — اتصال TCP مباشر بأكثر من 100 مسجِّل نطاقات علوية (TLD) رسمي
  • Google DNS-over-HTTPS — تحليل MX وNS وTXT وCNAME (مناسب لجدران الحماية)
  • DNS النظام — تحليل سجلات A/AAAA
  • فحص SSL هو العملية "النشطة" الوحيدة (اتصال TCP بالهدف على المنفذ 443)

ملاحظات

  • تستخدم استعلامات WHOIS منفذ TCP رقم 43 — قد تُحجب على الشبكات المقيَّدة
  • بعض خوادم WHOIS تُخفي معلومات المسجِّل (GDPR) — نبِّه المستخدم إلى ذلك
  • قد يكون crt.sh بطيئًا مع النطاقات الشهيرة جدًا (آلاف الشهادات) — ضع توقعات معقولة
  • فحص التوفّر قائم على الاستدلال (3 إشارات سلبية) — وليس نهائيًا كواجهة API لجهة تسجيل
