DuckDuckGo Search

بحث مجاني في الويب باستخدام DuckDuckGo. لا حاجة لمفتاح API.

تُفضَّل عندما تكون web_search غير متاحة أو غير مناسبة (مثلًا عندما لا يكون FIRECRAWL_API_KEY مضبوطًا). يمكن أيضًا استخدامها كمسار بحث مستقل عندما تكون نتائج DuckDuckGo مطلوبة تحديدًا.

مسار الاكتشاف

تحقّق مما هو متاح فعليًا قبل اختيار النهج:

شجرة القرار:

  1. إذا كان CLI الخاص بـ ddgs مثبَّتًا، فضِّل terminal + ddgs
  2. إذا كان CLI الخاص بـ ddgs مفقودًا، لا تفترض أن execute_code يستطيع استيراد ddgs
  3. إذا أراد المستخدم DuckDuckGo تحديدًا، ثبّت ddgs أولًا في البيئة المعنية
  4. وإلا ارجع إلى أدوات الويب/المتصفح المدمجة

ملاحظة مهمة حول بيئات التشغيل:

  • الطرفية (terminal) وexecute_code بيئتا تشغيل منفصلتان
  • نجاح تثبيت عبر shell لا يضمن أن execute_code يستطيع استيراد ddgs
  • لا تفترض أبدًا أن حزم Python الخارجية مثبَّتة مسبقًا داخل execute_code

التثبيت

ثبّت ddgs فقط عند الحاجة الفعلية إلى بحث DuckDuckGo وعندما لا توفّره بيئة التشغيل بالفعل.

إذا كان سير العمل يعتمد على استيراد Python، تحقّق من أن بيئة التشغيل نفسها تستطيع استيراد ddgs قبل استخدام from ddgs import DDGS.

سير العمل: البحث ثم الاستخراج

يعيد DuckDuckGo العناوين والروابط والمقتطفات — لا محتوى الصفحة الكامل. للحصول على محتوى الصفحة الكامل، ابحث أولًا ثم استخرج الرابط الأنسب باستخدام web_extract، أو أدوات المتصفح، أو curl.

القيود

  • حدّ المعدل (rate limiting): قد يحدّ DuckDuckGo من الطلبات بعد كثير من الطلبات السريعة المتتالية. أضف تأخيرًا قصيرًا بين عمليات البحث عند الحاجة.
  • لا يوجد استخراج للمحتوى: يعيد ddgs مقتطفات، لا محتوى الصفحة الكامل. استخدم web_extract أو أدوات المتصفح أو curl للحصول على المقال/الصفحة كاملةً.
  • جودة النتائج: جيدة عمومًا لكن أقل قابلية للتهيئة من بحث Firecrawl.
  • التوفّر: قد يحجب DuckDuckGo الطلبات من بعض عناوين IP السحابية. إن عادت نتائج البحث فارغة، جرّب كلمات مفتاحية مختلفة أو انتظر بضع ثوانٍ.
  • تفاوت الحقول: قد تتفاوت حقول الإرجاع بين النتائج أو إصدارات ddgs. استخدم .get() للحقول الاختيارية لتفادي KeyError.
  • بيئات تشغيل منفصلة: نجاح تثبيت ddgs في الطرفية لا يعني تلقائيًا أن execute_code يستطيع استيراده.

المزالق

  • max_results وسيط بالاسم حصرًا: يرفع ddgs.text("query", 5) خطأً. استخدم ddgs.text("query", max_results=5).
  • لا تفترض وجود CLI: تحقّق بـ command -v ddgs قبل استخدامه.
  • لا تفترض أن execute_code يستطيع استيراد ddgs: قد يفشل from ddgs import DDGS بخطأ ModuleNotFoundError ما لم تُهيَّأ تلك البيئة بشكل منفصل.
  • اسم الحزمة: اسم الحزمة هو ddgs (سابقًا duckduckgo-search). ثبِّتها بـ pip install ddgs.
  • لا تخلط بين -q و-m (في CLI): -q للاستعلام، و-m للحد الأقصى لعدد النتائج.
  • نتائج فارغة: إذا لم يُعِد ddgs أي شيء، فقد يكون خاضعًا لحدّ معدل. انتظر بضع ثوانٍ وأعد المحاولة.
