LLaVA - المساعد اللغوي والبصري الكبير

نموذج بصري-لغوي مفتوح المصدر لفهم الصور بأسلوب محادثة.

متى تستخدم LLaVA

استخدمه عندما:

  • تبني روبوتات محادثة بصرية-لغوية
  • تحتاج إلى الإجابة على أسئلة بصرية (VQA)
  • تحتاج إلى وصف الصور والتعليق عليها (captioning)
  • تجري محادثات متعددة الأدوار حول الصور
  • تحتاج إلى اتّباع تعليمات بصرية
  • تحتاج إلى فهم المستندات المتضمّنة صورًا

المقاييس:

  • أكثر من 23,000 نجمة على GitHub
  • قدرات تستهدف مستوى GPT-4V
  • ترخيص Apache 2.0
  • أحجام نماذج متعددة (7B-34B معامل)

استخدم البدائل بدلًا من ذلك:

  • GPT-4V: أعلى جودة، عبر API
  • CLIP: تصنيف بسيط بلا أمثلة تدريبية (zero-shot)
  • BLIP-2: أفضل للتعليق على الصور (captioning) فقط
  • Flamingo: للأبحاث فقط، وليس مفتوح المصدر

التكميم (Quantization) (لتقليل VRAM)

أفضل الممارسات

  1. ابدأ بنموذج 7B - جودة جيدة، استهلاك VRAM يمكن التحكم فيه
  2. استخدم التكميم 4-bit - يقلّل استهلاك VRAM بشكل كبير
  3. GPU مطلوبة - الاستدلال على المعالج (CPU) بطيء للغاية
  4. prompts واضحة - الأسئلة المحدَّدة تعطي إجابات أفضل
  5. محادثات متعددة الأدوار - حافظ على سياق المحادثة
  6. Temperature بين 0.2-0.7 - وازن بين الإبداع والاتّساق
  7. max_new_tokens بين 512-1024 - للحصول على استجابات مفصّلة
  8. المعالجة الدفعية (Batch) - عالج عدة صور بشكل متسلسل

معايير الأداء (Benchmarks)

يحقّق LLaVA نتائج تنافسية على:

  • VQAv2: 78.5%
  • GQA: 62.0%
  • MM-Vet: 35.4%
  • MMBench: 64.3%

القيود

  1. الهلوسة (Hallucinations) - قد يصف أشياء غير موجودة في الصورة
  2. الاستدلال المكاني - يواجه صعوبة مع المواقع الدقيقة
  3. النص الصغير - صعوبة في قراءة الخط الدقيق
  4. عدّ الأجسام - غير دقيق مع عدد كبير من الأجسام
  5. متطلبات VRAM - يحتاج إلى GPU قوية
  6. سرعة الاستدلال - أبطأ من CLIP
