مهارة PDF

أنشئ ملفات PDF من مواصفات مُهيكلة، وابنِ نماذج AcroForm واملأها (مع فحص التخطيط وتراكب مرئي)، واستخرج النص/الجداول/البيانات الوصفية، وادمج/قسّم/دوّر/ضع علامة مائية/اختم الصفحات، وصدّر صور الصفحات، وأدر البيانات الوصفية والمرفقات، وشفّر/فكّ تشفير — باستخدام pypdf وreportlab وpdfplumber. توجد إمكانيتان مدمجتان ضمن references/ (اقرأ الملف المطابق قبل تنفيذ تلك المهام):

  • ملفات PDF الممسوحة ضوئيًا/المكوّنة من صور فقط وOCR (مسار pymupdf السريع، ومسار marker-pdf عالي الجودة، وscripts/extract_pymupdf.py + scripts/extract_marker.py): references/ocr-extraction.md
  • تحرير النص داخل ملف PDF موجود عبر مطالبات باللغة الطبيعية (واجهة nano-pdf CLI): references/nano-pdf-editing.md

متى تُستخدم

  • توليد تقرير أو فاتورة أو مستند متعدد الصفحات بصيغة PDF.
  • بناء نموذج AcroForm قابل للتعبئة (نص/مربع اختيار/زر راديو/قائمة منسدلة) من مواصفة JSON، مع فحص التخطيط أولًا.
  • استخراج نص أو جداول (JSON/CSV) أو بيانات وصفية أو قيم حقول نموذج من ملف PDF.
  • دمج، أو تقسيم، أو تدوير، أو استخراج مجموعات فرعية من الصفحات، أو وضع علامة مائية، أو ختم نص/صور عند إحداثيات محددة، أو إضافة إشارات مرجعية، أو ضغط ملفات PDF.
  • تصدير الصفحات كصور PNG للمراجعة المرئية أو لتسليمها إلى OCR؛ وضبط/مسح البيانات الوصفية للمستند؛ وإضافة/استخراج مرفقات الملفات.
  • تعبئة أو تسطيح (flatten) نماذج AcroForm؛ والتشفير أو فك التشفير بكلمات مرور.
  • لا تُستخدم من أجل ملفات PDF الممسوحة ضوئيًا/المكوّنة من صور فقط (استخدم references/ocr-extraction.md) ولا من أجل تحويل HTML إلى PDF بدقة بكسل تامة (استخدم متصفحًا بلا واجهة رسومية).

المتطلبات المسبقة

  • Python 3.10 فما فوق مع pypdf وreportlab وpdfplumber: python -m pip install pypdf reportlab pdfplumber
  • اختياري، لترستير الصفحات (pdf_page_image.py، وعرض التراكبات): python -m pip install pypdfium2، أو أداة pdftoppm من poppler في PATH. تعود السكربتات من pypdfium2 إلى pdftoppm وتُبلغ بـ {"rendered": false, "missing": [...]} (رمز خروج 0) عند غياب كليهما.
  • يتحقق كل سكربت مساعد من الاستيرادات بشكل كسول (lazily) ويطبع تلميح تثبيت إذا كانت إحدى الاعتماديات مفقودة.

طريقة التشغيل

تقع كل الأدوات المساعدة داخل scripts/ وهي واجهات CLI مبنية على argparse — شغّلها باستخدام أداة terminal؛ يدعم كل منها --help. تقرأ وتكتب JSON بترميز UTF-8 صراحةً، وتطبع نتائج JSON إلى stdout، وتخرج برمز غير صفري عند الفشل.

الإجراء

  1. افحص أولًا. شغّل pdf_read.py file.pdf --meta. تحقق من encrypted (إن كانت true، فكّ التشفير أولًا باستخدام pdf_secure.py --decrypt) ومن likely_scanned_pages. إذا كانت الصفحات مكوّنة من صور فقط، صدّرها باستخدام pdf_page_image.py --pages <scanned> --dpi 300 --out-dir imgs/ وسلّم صور PNG إلى مهارة references/ocr-extraction.md — لا تُبلغ عن النص الفارغ على أنه "لا يوجد محتوى".
  2. الإنشاء. اكتب مواصفة JSON باستخدام write_file (العناصر: heading، وparagraph، وtable، وimage، وpagebreak؛ بيانات وصفية اختيارية title/author؛ تُضاف أرقام الصفحات تلقائيًا)، ثم شغّل pdf_create.py. تحقق بصريًا باستخدام vision_analyze على صورة صفحة مُصيَّرة إذا كان التخطيط مهمًا.
  3. الاستخراج. يُعطي --text قائمة JSON من السلاسل لكل صفحة؛ ويُعطي --tables مصفوفات صفوف لكل صفحة ويمكنه أيضًا إخراج ملفات CSV. اقرأ النتائج باستخدام read_file؛ لا تُعاين ملف PDF الثنائي مباشرة أبدًا.
  4. التعديل. يدمج pdf_merge.py الملفات ويمكنه إضافة إشارة مرجعية واحدة لكل ملف مصدر؛ ويتعامل pdf_split.py مع نطاقات الصفحات (تبدأ من 1، مثل 1-3,5,9-)، والتدوير بخطوات 90 درجة، و--compress. أضِف علامة مائية بإعداد ملف PDF ختم من صفحة واحدة (مثلًا عبر pdf_create.py) وتراكبه باستخدام pdf_watermark.py؛ أمّا للأختام السريعة بسطر واحد ("وقّع هنا"، DRAFT قطريًا، تسميات الزوايا) فاستخدم pdf_stamp.py بنص أو صورة عند إحداثيات صريحة.
  5. بناء النماذج. اكتب مواصفة نموذج JSON واحدة (حقول تحمل label_box/entry_box بوحدات نقاط PDF — انظر references/forms.md)، وافحصها باستخدام pdf_form_layout.py وأصلح كل مشكلة يُبلغ عنها، وراجع اختياريًا صورة --render-overlay باستخدام vision_analyze، ثم ابنِ النموذج باستخدام pdf_make_form.py وتأكد منه باستخدام pdf_read.py --fields.
  6. تعبئة النماذج. اسرد الحقول (--fields) لمعرفة الأسماء والأنواع الدقيقة، واكتب ملف JSON بترميز UTF-8 من {"FieldName": "value"} باستخدام write_file (تقبل مربعات الاختيار true/false؛ يجب أن تطابق قيم أزرار الراديو/الاختيار خيارات التصدير الخاصة بالحقل)، ثم شغّل pdf_fill_form.py. أعِد القراءة باستخدام --fields للتأكد من استقرار القيم.
  7. البيانات الوصفية والمرفقات. تكتب pdf_meta.py --set-meta العنوان/المؤلف/الموضوع/الكلمات المفتاحية (DocInfo)؛ وتُسقطها --clear-meta؛ وتتعامل --attach/--list-attachments/--extract-attachments مع الملفات المضمّنة في الاتجاهين.
  8. التأمين. شفّر بكلمتي مرور منفصلتين للمستخدم والمالك وباستخدام AES-256. لإزالة كلمة مرور تعرفها، تكتب --decrypt نسخة غير مشفّرة.
  9. التحقق (انظر أدناه) قبل الإبلاغ عن النجاح.

مزالق شائعة

  • ملفات PDF الممسوحة ضوئيًا: يعني extract_text() الفارغ مع صور الصفحات عدم وجود طبقة نصية. وجّهها إلى references/ocr-extraction.md؛ لا تختلق نصًا.
  • حدود التسطيح (flattening): يستخدم pdf_fill_form.py --flatten دعم التسطيح في pypdf، الذي يحوّل مظاهر عناصر التحكم (widgets) إلى محتوى صفحة. وهو موثوق للحقول النصية العادية ومربعات الاختيار لكنه قد يُسقط أو يُشوّه عناصر تحكم غريبة (نص منسّق، تدفقات مظهر مخصصة، بعض مجموعات أزرار الراديو). تحقق من الناتج المسطّح بصريًا باستخدام vision_analyze؛ وللتسطيح المضمون استخدم مُصيِّرًا خارجيًا (مثل Ghostscript أو pdftoppm+إعادة التجميع) كخطة احتياطية.
  • NeedAppearances: بعد التعبئة، لا تعرض العارضات القيم إلا إذا وُجدت تدفقات مظهر. يضبط سكربت التعبئة علم NeedAppearances في AcroForm بحيث تعيد العارضات المتوافقة توليدها؛ تتجاهله بعض العارضات البسيطة — سطّح النموذج إذا كانت دقة العرض مهمة.
  • قيم النماذج غير اللاتينية: تُخزَّن القيم بشكل صحيح (UTF-16)، لكن قد يفتقر الخط الافتراضي للحقل إلى الحروف اللازمة، فقد يعرض العارض حقولًا فارغة رغم صحة البيانات عند التبادل. تحقق باستخدام --fields، لا بصريًا فقط.
  • توقعات الضغط: يضغط --compress تدفقات المحتوى فقط (deflate). التوفير النموذجي يتراوح بين 0-20%؛ ولا يفعل شيئًا لملفات PDF التي تهيمن عليها الصور أو التدفقات المضغوطة بالفعل. وهو ليس بديلًا عن تقليل دقة الصور (مجال Ghostscript).
  • أعلام الصلاحيات غير مُلزِمة: بتات صلاحية كلمة مرور المالك (منع الطباعة، منع النسخ) هي طلبات مهذّبة قد تحترمها العارضات؛ ويمكن لأي مكتبة (بما فيها pypdf) قراءتها وإزالتها. كلمة مرور المستخدم وحدها هي التي تُقيّد المحتوى فعليًا عبر التشفير. لا تعرض أعلام الصلاحيات أبدًا كإجراء أمني.
  • استخراج الجداول استدلالي (heuristic): يكتشف pdfplumber الجداول من خطوط التسطير/محاذاة الكلمات؛ قد تحتاج الجداول بلا حدود أو ذات الخلايا المدمجة إلى ضبط table_settings أو تنظيف يدوي.
  • ترقيم الصفحات: تأخذ واجهات CLI المساعدة أرقام صفحات تبدأ من 1؛ بينما واجهات pypdf تبدأ من 0. تقوم السكربتات بالتحويل — لا تُحوّل مرتين.
  • استخراج نص الأختام المدوَّرة: يُشوّش تجميع أسطر pdfplumber الحروف المدوَّرة (يُستخرج "DRAFT" بزاوية 45 درجة كأحرف متناثرة)؛ تحقق من الأختام المدوَّرة باستخدام pypdf عبر extract_text() أو صورة مُصيَّرة بدلًا من ذلك.
  • مجموعات أزرار الراديو: يحتاج reportlab إلى عنصرَي radio() على الأقل لكل مجموعة، وتحتاج التعبئة إلى قيمة التصدير مع الشرطة المائلة ("/red")، ودقة التسطيح أسوأ ما تكون لأزرار الراديو — انظر references/forms.md.
  • نطاق البيانات الوصفية: تكتب pdf_meta.py قاموس DocInfo الكلاسيكي فقط؛ وتبقى بيانات XMP الوصفية المضمّنة (إن وُجدت) دون تغيير وقد تُظهر قيمًا مختلفة في بعض العارضات.
  • معيار PDF/A خارج النطاق: لا يستطيع pypdf/reportlab إنتاج أو التحقق من مطابقة PDF/A. إذا لزمت مطابقة الأرشفة، شغّل Ghostscript عبر أداة terminal (مثل gs -dPDFA=2 -dPDFACompatibilityPolicy=1 -sColorConversionStrategy=UseDeviceIndependentColor -sDEVICE=pdfwrite -o out.pdf in.pdf مع ملف تعريف ICC مناسب) وتحقق باستخدام veraPDF — كلاهما تثبيتات خارجية، وتظل النتيجة بحاجة إلى تحقق فعلي لا افتراض.
  • يجب أن يكون التدوير من مضاعفات 90؛ ويجب فك تشفير المدخلات المشفّرة قبل أي عملية أخرى.

التحقق

  • بعد الإنشاء/الدمج/التقسيم: pdf_read.py out.pdf --meta — تحقق من page_count، ومن rotation لكل صفحة عند التدوير.
  • بعد الاستخراج: تحقق من أن JSON غير فارغ وتفقّد عينة من سلسلة أو خلية معروفة.
  • حلقة تصميم النموذج: يجب أن يخرج pdf_form_layout.py spec.json برمز 0؛ ثم --render-overlay boxes.png --pdf form.pdf وراجع صورة PNG باستخدام vision_analyze (الأحمر = صناديق الإدخال بأسماء الحقول، الأزرق = صناديق التسمية) للتحقق من التداخلات، وسوء المحاذاة، والتسميات المنفصلة عن حقولها. كرّر: مواصفة ← فحص ← تراكب حتى يخلو من الأخطاء.
  • بعد بناء نموذج: يسرد pdf_read.py form.pdf --fields كل حقل من المواصفة بالنوع والخيارات الصحيحة.
  • بعد تعبئة نموذج: pdf_read.py filled.pdf --fields وقارن القيم (تطابق تام، بما فيها غير ASCII).
  • بعد الختم: أعِد استخراج النص (pypdf للأختام المدوَّرة) أو صيّر الصفحة باستخدام pdf_page_image.py وافحصها باستخدام vision_analyze.
  • بعد تعديلات البيانات الوصفية/المرفقات: pdf_read.py --meta / pdf_meta.py --list-attachments، وأعِد استخراج مرفق للمقارنة بايتًا ببايت.
  • بعد التشفير: يُظهر --meta القيمة "encrypted": true ويفشل الفتح بلا كلمة مرور؛ وبعد فك التشفير، يطابق استخراج النص الأصل.
  • لأي عنصر مرئي (علامات مائية، نماذج مسطّحة)، صيّر وافحص باستخدام vision_analyze.
