جدول مرجعي سريع

الإجراءghgit + curl
الاستنساخgh repo clone o/rgit clone https://github.com/o/r.git
إنشاء مستودعgh repo create name --publiccurl POST /user/repos
فرع (Fork)gh repo fork o/r --clonecurl POST /repos/o/r/forks + git clone
معلومات المستودعgh repo view o/rcurl GET /repos/o/r
تعديل الإعداداتgh repo edit --...curl PATCH /repos/o/r
إنشاء إصدار (release)gh release create v1.0curl POST /repos/o/r/releases
سرد سير العمل (workflows)gh workflow listcurl GET /repos/o/r/actions/workflows
إعادة تشغيل CIgh run rerun IDcurl POST /repos/o/r/actions/runs/ID/rerun
ضبط سر (secret)gh secret set KEYcurl PUT /repos/o/r/actions/secrets/KEY (+ تشفير)
