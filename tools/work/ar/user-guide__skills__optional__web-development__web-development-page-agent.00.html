معلومة

ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

page-agent

مشروع alibaba/page-agent (https://github.com/alibaba/page-agent، بأكثر من 17 ألف نجمة، ترخيص MIT) هو وكيل GUI داخل الصفحة مكتوب بـ TypeScript. يعيش داخل صفحة الويب، ويقرأ DOM كنص (دون لقطات شاشة، ودون LLM متعدد الوسائط)، وينفّذ تعليمات بلغة طبيعية مثل "انقر على زر تسجيل الدخول، ثم املأ اسم المستخدم بـ John" على الصفحة الحالية. يعمل بالكامل من جانب العميل — الموقع المضيف يكتفي بتضمين سكربت وتمرير نقطة نهاية LLM متوافقة مع OpenAI.

متى تُستخدم هذه المهارة

حمّل هذه المهارة عندما يريد المستخدم:

  • شحن مساعد ذكاء اصطناعي داخل تطبيق الويب الخاص به (SaaS، لوحة إدارة، أداة B2B، ERP، CRM) — "يجب أن يستطيع مستخدمو لوحتي كتابة 'أنشئ فاتورة لشركة Acme Corp وأرسلها بالبريد' بدلًا من النقر عبر خمس شاشات"
  • تحديث تطبيق ويب قديم دون إعادة كتابة الواجهة الأمامية — يُدرَج page-agent فوق DOM الموجود
  • إضافة إمكانية وصول عبر اللغة الطبيعية — يتحكّم مستخدمو الصوت / قارئ الشاشة بواجهة المستخدم عبر وصف ما يريدونه
  • تجربة أو تقييم page-agent مقابل LLM محلي (Ollama) أو مستضاف (Qwen، OpenAI، OpenRouter)
  • بناء عروض تدريبية / توضيحية تفاعلية للمنتج — دع الذكاء الاصطناعي يقود المستخدم عبر "كيفية تقديم تقرير مصروفات" مباشرة في الواجهة الفعلية

متى لا تُستخدم هذه المهارة

  • يريد المستخدم أن يقود Hermes نفسه متصفحًا ← استخدم أداة المتصفح المدمجة في Hermes (Browserbase / Camofox). page-agent يعمل في الاتجاه المعاكس.
  • يريد المستخدم أتمتة عبر تبويبات متعددة دون تضمين ← استخدم Playwright، أو browser-use، أو إضافة page-agent لـ Chrome
  • يحتاج المستخدم إلى تأصيل بصري (visual grounding) / لقطات شاشة ← يعمل page-agent مع DOM النصي فقط؛ استخدم وكيل متصفح متعدد الوسائط بدلًا منه

المتطلبات المسبقة

  • Node 22.13 أو أحدث أو Node 24 أو أحدث، npm 10 أو أحدث (تذكر المستندات 11 أو أحدث لكن 10.9 يعمل جيدًا)
  • نقطة نهاية LLM متوافقة مع OpenAI: Qwen (DashScope)، أو OpenAI، أو Ollama، أو OpenRouter، أو أي واجهة تدعم /v1/chat/completions
  • متصفح مزوَّد بأدوات المطوّر (لأغراض التصحيح)

حقول الإعدادات الأساسية (تُمرَّر إلى new PageAgent({...})):

  • model، baseURL، apiKey — اتصال LLM
  • language — لغة واجهة المستخدم (en-US، zh-CN، إلخ)
  • توجد آليات قوائم سماح (allowlist) وإخفاء بيانات (data-masking) لتقييد ما يستطيع الوكيل التعامل معه — راجع https://alibaba.github.io/page-agent/ للحصول على قائمة الخيارات كاملة

الأمان. لا تضع apiKey الخاص بك في كود جانب العميل لنشر حقيقي — مرّر استدعاءات LLM عبر الخادم الخلفي الخاص بك ووجّه baseURL إلى ذلك الوكيل (proxy). CDN التجريبي موجود لأن alibaba تُشغّل ذلك الوكيل لأغراض التقييم.

التحقق من أنه يعمل

بعد المسار 1 أو المسار 2:

  1. افتح الصفحة في متصفح مع فتح أدوات المطوّر
  2. يجب أن ترى لوحة عائمة. إن لم تظهر، تحقّق من وحدة التحكم بحثًا عن أخطاء (الأكثر شيوعًا: CORS على نقطة نهاية LLM، أو baseURL خاطئ، أو مفتاح API غير صالح)
  3. اكتب تعليمة بسيطة تطابق شيئًا ظاهرًا في الصفحة ("انقر على رابط Login")
  4. راقب تبويب Network — يجب أن ترى طلبًا إلى baseURL الخاص بك

بعد المسار 3:

  1. يطبع npm run dev:demo السطر Accepting connections at http://localhost:5174
  2. يُعيد curl -I http://localhost:5174/page-agent.demo.js استجابة HTTP/1.1 200 OK مع Content-Type: application/javascript
  3. انقر على الـ bookmarklet في أي موقع؛ تظهر اللوحة

المزالق

  • CDN التجريبي في الإنتاج — لا تفعل ذلك. فهو محدود المعدل، ويستخدم وكيل alibaba المجاني، وشروطهم تمنع الاستخدام الإنتاجي.
  • كشف مفتاح API — أي مفتاح يُمرَّر إلى new PageAgent({apiKey: ...}) يُشحَن ضمن حزمة JS الخاصة بك. مرّر دائمًا عبر الخادم الخلفي الخاص بك للنشر الحقيقي.
  • نقاط النهاية غير المتوافقة مع OpenAI تفشل بصمت أو بأخطاء غامضة. إذا احتاج مزوّدك صياغة Anthropic/Gemini الأصلية، ضع وكيل توافق مع OpenAI (LiteLLM، OpenRouter) أمامه.
  • حظر CSP — قد ترفض المواقع ذات سياسة أمان محتوى (Content-Security-Policy) صارمة تحميل سكربت CDN أو تمنع eval المضمّن. في هذه الحالة، استضفه ذاتيًا من نطاقك (origin).
  • أعد تشغيل خادم التطوير بعد تعديل .env في المسار 3 — يقرأ Vite متغيرات البيئة فقط عند بدء التشغيل.
  • إصدار Node — يشترط المستودع ^22.13.0 || >=24. سيفشل Node 20 في npm ci بأخطاء محرّك (engine).
  • npm 10 مقابل 11 — تذكر المستندات npm 11 أو أحدث؛ لكن npm 10.9 يعمل جيدًا فعليًا.
