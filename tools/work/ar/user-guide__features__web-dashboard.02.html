أمر /reload (Slash Command)

يضيف الـ PR الخاص بلوحة التحكم أيضًا slash command باسم /reload إلى CLI التفاعلي. بعد تغيير مفاتيح API عبر لوحة التحكم على الويب (أو بتحرير .env مباشرةً)، استخدم /reload في جلسة CLI نشطة لتطبيق التغييرات دون إعادة التشغيل:

يُعيد هذا الأمر قراءة ~/.hermes/.env إلى بيئة العملية الجارية. وهو مفيد عندما تضيف مفتاح مزوّد جديدًا عبر لوحة التحكم وتريد استخدامه فورًا.

REST API

توفّر لوحة التحكم على الويب REST API تستهلكه الواجهة الأمامية. ويمكنك أيضًا استدعاء هذه الـ endpoints مباشرةً لأغراض الأتمتة:

Endpoints مقيّدة بنطاق profile

تقبل مجموعات endpoints الإدارية — /api/config و /api/env و /api/skills و /api/tools/toolsets و /api/mcp و /api/model/{info,options,auxiliary,set} — معامل استعلام اختياريًا ?profile=<name> (أو "profile" في جسم JSON لعمليات الكتابة) يقيّد القراءة/الكتابة بـ HERMES_HOME الخاص بذلك الـ profile. وعند حذفه يُستخدَم الـ profile الخاص بلوحة التحكم نفسها. وأسماء الـ profiles غير المعروفة تُعيد 404. ويقبل اتصال WebSocket في /api/pty المعامل نفسه لتشغيل محادثة تحت الـ profile المختار.

GET /api/status

يُعيد إصدار الوكيل، وحالة الـ gateway، وحالات المنصات، وعدد الجلسات النشطة.

تتضمن الاستجابة أيضًا كتلتين استشاريتين عن الموارد (لا تؤثران أبدًا في حكم السلامة components/overall):

  • memory — مستخلصة من نبضة الـ gateway (heartbeat) التي تتكرر كل 30 ثانية ومن دفتر دورة الحياة (lifecycle ledger). الحقول: pressure (ok / elevated / critical / unknown)، و gateway_rss_mb، و system_total_mb، و system_available_mb، و swap_used_mb، و sampled_at، و boot_id، و last_boot_unclean، و last_boot_suspected_oom. تكون قيمة الضغط elevated عندما تقل ذاكرة النظام المتاحة عن 128 MiB (أو 15%)، و critical عندما تقل عن 64 MiB (أو 5%) — وهي المستويات نفسها التي يُصنَّف عندها أي خروج غير نظيف لاحق على أنه إنهاء يُشتبه في أنه بسبب OOM. أما النبضات الأقدم من 150 ثانية (أو ذات التاريخ المستقبلي) فتحتفظ بأرقامها، لكن قيمة pressure تتراجع إلى unknown، حتى لا تتنكّر آخر عيّنة من gateway متوقف في صورة قراءة حية.
  • disk — عيّنة حية من shutil.disk_usage() لوحدة التخزين التي تحتوي على ~/.hermes. الحقول: pressure، و free_mb، و total_mb، و used_percent، و sampled_at. تكون قيمة الضغط elevated عندما تقل المساحة الحرة عن 512 MB (أو عند استخدام ≥85% مع هامش أقل من 4 GB)، و critical عندما تقل المساحة الحرة عن 256 MB (أو عند استخدام ≥95% مع هامش أقل من 1 GB).

كلا المُجمِّعين آمنان عند الفشل: فأي خطأ في أخذ العيّنات يُحوّل الكتلة إلى {"pressure": "unknown"} بدلًا من إفشال endpoint الحالة. والأرقام تقريبية (ميغابايتات كاملة ونِسب مئوية صحيحة) لأن /api/status عام.

GET /api/sessions

يُعيد أحدث 20 جلسة مع بياناتها الوصفية (النموذج، وأعداد الـ tokens، والطوابع الزمنية، والمعاينة).

GET /api/config

يُعيد محتويات config.yaml الحالية بصيغة JSON.

GET /api/config/defaults

يُعيد قيم الإعدادات الافتراضية.

GET /api/config/schema

يُعيد مخططًا (schema) يصف كل حقل من حقول الإعدادات — النوع، والوصف، والفئة، وخيارات الاختيار حيثما تنطبق. وتستخدمه الواجهة الأمامية لعرض عنصر الإدخال المناسب لكل حقل.

PUT /api/config

يحفظ إعدادات جديدة. الجسم: {"config": {...}}.

GET /api/env

يُعيد جميع متغيرات البيئة المعروفة مع حالة ضبطها، وقيمها المحجوبة، وأوصافها، وفئاتها.

PUT /api/env

يضبط متغير بيئة. الجسم: {"key": "VAR_NAME", "value": "secret"}.

DELETE /api/env

يزيل متغير بيئة. الجسم: {"key": "VAR_NAME"}.

GET /api/sessions/{session_id}

يُعيد البيانات الوصفية لجلسة واحدة.

GET /api/sessions/{session_id}/messages

يُعيد صفحة محدودة من سجل الرسائل، بما في ذلك استدعاءات الأدوات والطوابع الزمنية. ويُعيد افتراضيًا أحدث 500 رسالة بترتيب زمني. استخدم limit (بحد أقصى 500) و offset و order=oldest|latest للتقسيم الصريح إلى صفحات.

GET /api/sessions/search

بحث نصي كامل في محتوى الرسائل. معامل الاستعلام: q. يُعيد معرّفات الجلسات المطابقة مع مقتطفات مُبرَزة.

DELETE /api/sessions/{session_id}

يحذف جلسة وسجل رسائلها.

GET /api/logs

يُعيد أسطر السجل. معاملات الاستعلام: file (agent/errors/gateway)، و lines (العدد)، و level، و component.

GET /api/analytics/usage

يُعيد تحليلات استهلاك الـ tokens والتكلفة والجلسات. معامل الاستعلام: days (القيمة الافتراضية 30). وتتضمن الاستجابة تفصيلات يومية وإجماليات لكل نموذج.

GET /api/cron/jobs

يُعيد جميع مهام cron المُعدّة مع حالتها وجدولها وسجل تشغيلها.

POST /api/cron/jobs

يُنشئ مهمة cron جديدة. الجسم: {"prompt": "...", "schedule": "0 9 * * *", "name": "...", "deliver": "local"}.

POST /api/cron/jobs/{job_id}/pause

يوقف مهمة cron مؤقتًا.

POST /api/cron/jobs/{job_id}/resume

يستأنف مهمة cron موقوفة مؤقتًا.

POST /api/cron/jobs/{job_id}/trigger

يُطلق مهمة cron فورًا خارج جدولها.

DELETE /api/cron/jobs/{job_id}

يحذف مهمة cron.

GET /api/skills

يُعيد جميع المهارات مع اسمها، ووصفها، وفئتها، وحالة تفعيلها.

PUT /api/skills/toggle

يفعّل مهارة أو يعطّلها. الجسم: {"name": "skill-name", "enabled": true}.

GET /api/tools/toolsets

يُعيد جميع الـ toolsets مع التسمية، والوصف، وقائمة الأدوات، وحالة النشاط/الإعداد.
