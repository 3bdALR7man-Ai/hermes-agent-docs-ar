System

لوحة إدارة موحّدة للعمليات على مستوى التثبيت:

  • Host — إحصاءات النظام الحية: نظام التشغيل / النواة، والبنية المعمارية، واسم المضيف، وإصدارات Python و Hermes، وعدد أنوية CPU + استخدامها، والذاكرة، واستخدام القرص في مجلد Hermes الرئيسي، ومدة التشغيل، ومتوسط الحمل. (تأتي بيانات CPU/الذاكرة/القرص من psutil عند تثبيتها؛ وتظهر حقول الهوية دائمًا). ويعرض إصدار Hermes شارة حالة التحديث (محدّث / متأخر N commits) وزر Check for updates . وعندما يتوفر تحديث في تثبيت Git، يفتح زر Update now مربع حوار للتأكيد — يعرض عدد commits التي ستسحبها — قبل تشغيل hermes update في الخلفية. وفي تثبيتات Docker/Nix لا يمكن للوحة تطبيق التحديث في موضعه، لذا تعرض بدلًا من ذلك الأمر الصحيح الذي يُنفَّذ خارجها.
  • Nous Portal — حالة تسجيل الدخول، ومزوّد inference النشط، وجدول توجيه Tool Gateway (الأدوات التي تعمل عبر Portal مقابل محليًا)، مع رابط لإدارة اشتراكك. نسخة للقراءة فقط من hermes portal.
  • Skill curator — حالة صيانة المهارات في الخلفية (نشطة / متوقفة مؤقتًا، والفاصل، وآخر تشغيل)، مع الإيقاف المؤقت/الاستئناف وزر تشغيل فوري. تعكس hermes curator.
  • Gateway — بدء gateway المراسلة وإيقافه وإعادة تشغيله، مع الحالة الحية (يعمل/متوقف، و PID، والحالة)
  • Memory — اختر مزوّد الذاكرة الخارجي (أو المدمج فقط)، وأعد ضبط مخازن MEMORY.md / USER.md المدمجة
  • Credential pool — أضف واحذف مفاتيح API الدوّارة التي يتناوب الوكيل عليها (لكل مزوّد). تُحجب المفاتيح في القائمة؛ ولا تصل قيمتها الخام إلا إلى الوكيل.
  • Operations — شغّل doctor، أو تدقيقًا أمنيًا، أو أنشئ نسخة احتياطية، أو استعد من أرشيف نسخة احتياطية، أو حدّث المهارات، أو اعرض تفصيل حجم system prompt، أو ولّد حزمة دعم، أو رحّل الإعدادات للخيارات المتوقفة. ينشئ كل منها إجراءً في الخلفية يُبث سجله الحي في الصفحة.
  • Checkpoints — اعرض حجم المخزن الخفي لـ /rollback وقلّمه
  • Shell hooks — اعرض hooks المضبوطة مع حالة الموافقة عليها + قابليتها للتنفيذ، و أنشئ hook (الحدث، والأمر، والمطابق، والمهلة، مع منح موافقة اختياري)، واحذف hook. تشغّل hooks أوامر عشوائية، لذا يحمل نموذج الإنشاء تحذيرًا أمنيًا ولا يعمل hook إلا بعد منح الموافقة.

الأمان

تقرأ لوحة تحكم الويب ملف .env الذي يحتوي مفاتيح API وأسرارًا وتكتب فيه. وتُربط بـ 127.0.0.1 افتراضيًا — فلا يمكن الوصول إليها إلا من جهازك المحلي، دون تسجيل دخول. والربط بأي عنوان غير loopback (بما فيه 0.0.0.0) يفعّل بوابة المصادقة: يرفض الخادم بدء التشغيل حتى يُضبط مزوّد مصادقة (اسم المستخدم/كلمة المرور أو OAuth).

REST API

توفّر لوحة التحكم على الويب REST API تستهلكه الواجهة الأمامية. ويمكنك أيضًا استدعاء هذه الـ endpoints مباشرةً لأغراض الأتمتة:

endpoints ضمن نطاق profile

عائلات endpoints الإدارية — /api/config, /api/env, /api/skills, /api/tools/toolsets, /api/mcp, /api/model/{info,options,auxiliary,set,recommended-default}, /api/cron/{delivery-targets,blueprints}, /api/audio/voice-config, /api/ops/debug-share, /api/learning/{graph,node}، و /api/dashboard/plugins/hub — تقبل معامل استعلام اختياريًا ?profile=<name> (أو "profile" في جسم JSON للكتابة) يحدد نطاق القراءة/الكتابة إلى HERMES_HOMEللـ profile المعني. عند الإغفال = profile لوحة التحكم نفسها. وتُعيد أسماء profiles المجهولة 404. ويقبل WebSocket /api/pty المعامل نفسه لبدء محادثة ضمن الـ profile المختار.

GET /api/status

يُعيد إصدار الوكيل، وحالة الـ gateway، وحالات المنصات، وعدد الجلسات النشطة.

يحمل الرد أيضًا كتلتَي موارد استرشاديتين (لا تؤثران أبدًا في نتيجة السلامة components/overall ):

  • memory — مستخلصة من نبضة الـ gateway كل 30 ثانية وسجل دورة الحياة. الحقول: pressure (ok / elevated / critical / unknown), gateway_rss_mb, system_total_mb, system_available_mb, swap_used_mb, sampled_at, boot_id, last_boot_unclean, last_boot_suspected_oom. ويكون الضغط elevated عند انخفاض ذاكرة النظام المتاحة عن 128 MiB (أو 15%) و critical عند انخفاضها عن 64 MiB (أو 5%) — وهما المستويان نفسيهما اللذان يُعلَّم عندهما خروج لاحق غير سليم كإنهاء مشتبه به بسبب OOM. وتحتفظ النبضات الأقدم من 150 ثانية (أو ذات تاريخ مستقبلي) بأرقامها لكنها تخفض pressure إلى unknown، كي لا تبدو آخر عينة لـ gateway متوقف كقراءة حية.
  • disk — عينة حية عبر shutil.disk_usage() لوحدة التخزين التي تحتوي ~/.hermes. الحقول: pressure, free_mb, total_mb, used_percent, sampled_at. ويكون الضغط elevated عندما تقل المساحة الحرة عن 512 MB (أو ≥85% استخدام مع مساحة متبقية دون 4 GB) و critical عندما تقل عن 256 MB (أو ≥95% استخدام مع مساحة متبقية دون 1 GB).

كلا الجامعَين آمن عند الإخفاق: أي خطأ في أخذ العينات يخفض الكتلة إلى {"pressure": "unknown"} بدلًا من إفشال endpoint الحالة. والأرقام تقريبية (MB كاملة ونسب مئوية صحيحة) لأن /api/status عام.

GET /api/chat/workspaces

الأدلة التي يمكن أن تبدأ فيها جلسة جديدة من تبويب Chat: مشاريع الـ profile (ذات المجلدات) ومستودعات Git المكتشفة (root, label, sessions, last_active)، إضافة إلى default_cwd (حيث تبدأ المحادثة إن لم تختر شيئًا)، ويعيد home. ?scan=1 مسح desktop.repo_scan_roots على المضيف أولًا. قرنه بـ /api/pty?cwd=<path>، الذي يرفض بأمان إذا كان الدليل مفقودًا.

GET /api/sessions

يُعيد أحدث 20 جلسة مع بياناتها الوصفية (النموذج، وأعداد الـ tokens، والطوابع الزمنية، والمعاينة).

GET /api/config

يُعيد محتويات config.yaml الحالية بصيغة JSON.

GET /api/config/defaults

يُعيد قيم الإعدادات الافتراضية.

GET /api/config/schema

يُعيد مخططًا (schema) يصف كل حقل من حقول الإعدادات — النوع، والوصف، والفئة، وخيارات الاختيار حيثما تنطبق. وتستخدمه الواجهة الأمامية لعرض عنصر الإدخال المناسب لكل حقل.

PUT /api/config

يحفظ إعدادات جديدة. الجسم: {"config": {...}}.

GET /api/env

يُعيد جميع متغيرات البيئة المعروفة مع حالة ضبطها، وقيمها المحجوبة، وأوصافها، وفئاتها.

PUT /api/env

يضبط متغير بيئة. الجسم: {"key": "VAR_NAME", "value": "secret"}.

DELETE /api/env

يزيل متغير بيئة. الجسم: {"key": "VAR_NAME"}.

GET /api/sessions/{session_id}

يُعيد البيانات الوصفية لجلسة واحدة.

GET /api/sessions/{session_id}/messages

يُعيد صفحة محدودة من سجل الرسائل، بما في ذلك استدعاءات الأدوات والطوابع الزمنية. ويُعيد افتراضيًا أحدث 500 رسالة بترتيب زمني. استخدم limit (بحد أقصى 500) و offset و order=oldest|latest للتقسيم الصريح إلى صفحات.

GET /api/sessions/search

بحث نصي كامل في محتوى الرسائل. معامل الاستعلام: q. يُعيد معرّفات الجلسات المطابقة مع مقتطفات مُبرَزة.

DELETE /api/sessions/{session_id}

يحذف جلسة وسجل رسائلها. ويُعيد 409 Conflict إذا كانت للجلسة مهلة ملكية نشطة لدور أو قفل ضغط.

GET /api/logs

يُعيد أسطر السجل. معاملات الاستعلام: file (agent/errors/gateway)، و lines (العدد)، و level، و component.

GET /api/analytics/usage

يُعيد تحليلات استهلاك الـ tokens والتكلفة والجلسات. معامل الاستعلام: days (القيمة الافتراضية 30). وتتضمن الاستجابة تفصيلات يومية وإجماليات لكل نموذج.

GET /api/cron/jobs

يُعيد جميع مهام cron المُعدّة مع حالتها وجدولها وسجل تشغيلها.

POST /api/cron/jobs

يُنشئ مهمة cron جديدة. الجسم: {"prompt": "...", "schedule": "0 9 * * *", "name": "...", "deliver": "local"}.

POST /api/cron/jobs/{job_id}/pause

يوقف مهمة cron مؤقتًا.

POST /api/cron/jobs/{job_id}/resume

يستأنف مهمة cron موقوفة مؤقتًا.

POST /api/cron/jobs/{job_id}/trigger

يُطلق مهمة cron فورًا خارج جدولها.

DELETE /api/cron/jobs/{job_id}

يحذف مهمة cron.

GET /api/skills

يُعيد جميع المهارات مع اسمها، ووصفها، وفئتها، وحالة تفعيلها.

PUT /api/skills/toggle

يفعّل مهارة أو يعطّلها. الجسم: {"name": "skill-name", "enabled": true}.

GET /api/tools/toolsets

يُعيد جميع الـ toolsets مع التسمية، والوصف، وقائمة الأدوات، وحالة النشاط/الإعداد.
