مخططات الأتمتة (Automation Blueprints)

مخططات جاهزة للنسخ واللصق لأنماط الأتمتة الشائعة. يستخدم كل مخطط مُجدوِل cron المدمج في Hermes للمُحفِّزات الزمنية، ومنصة webhook للمُحفِّزات القائمة على الأحداث.

يعمل كل مخطط مع أي نموذج، فهو غير مقيّد بمزوّد واحد.

للاطلاع على مخططات ذات معاملات تُملأ عبر نماذج إدخال بدلًا من صياغة cron، راجع كتالوج Automation Blueprints.

ثلاثة أنواع من المُحفِّزات
المُحفِّزالكيفيةالأداة
الجدولةيعمل وفق وتيرة محددة (كل ساعة، أو كل ليلة، أو كل أسبوع)الأداة cronjob أو الـ slash command /cron
حدث GitHubينطلق عند فتح PR، أو عمليات push، أو الـ issues، أو نتائج CIمنصة Webhook (hermes webhook subscribe)

تدعم الأنواع الثلاثة جميعها التسليم إلى Telegram و Discord و Slack و SMS والبريد الإلكتروني وتعليقات GitHub أو الملفات المحلية.

سير عمل التطوير

فرز الأعمال المتراكمة ليليًا

المُحفِّز: جدولة (ليليًا)

اكتشاف انحراف التوثيق
