مهارة قوائم العقارات

اعرض العقارات التي جرى البحث عنها كبطاقات قابلة للتصفح في نسخة سطح مكتب Hermes. هذه وصفة عرض، وليست خدمة بحث عن قوائم أو تقييمًا استثماريًا.

متى تُستخدم

  • عرض نتائج البحث عن عقارات أو إيجارات، أو مقارنة قائمة مختصرة، أو إعادة ترتيب العقارات.
  • عند المتابعة على عقار سبق عرضه: واصل استخدام البطاقات كي تبقى القائمة المختصرة قابلة للمقارنة.
  • خارج تطبيق سطح المكتب، استخدم Markdown عاديًا مع روابط المصدر بدلًا من ذلك؛ فالعملاء الآخرون لا يحتاجون إلى عرض أسيجة (fences) القوائم.

المتطلبات المسبقة

  • محادثة على سطح مكتب Hermes لعرض البطاقات الأصلية؛ يمكن أن يكون الخادم محليًا أو بعيدًا.
  • تفاصيل العقار المقدَّمة من المستخدم أو التي جرى التحقق منها عبر web_search أو web_extract أو أدوات المتصفح المتاحة في هذه الجلسة.
  • لا حاجة إلى مفاتيح API أو اعتماديات إضافية لتنسيق البطاقات.

طريقة التشغيل

ثبّت هذه المهارة الاختيارية عبر كتالوج المهارات، أو استخدم terminal:

حمّلها عبر skill_view(name="property-listings") عند عرض القوائم. لا يعيد التثبيت فهرسة مهارات المحادثة الجارية؛ ابدأ محادثة جديدة لاكتشافها تلقائيًا، أو حمّل المهارة المثبَّتة الآن صراحةً.

مرجع سريع

أصدر كتلة كود مُسيَّجة (fenced) لغتها listing ومحتواها JSON صالح. استخدم كائنًا واحدًا، أو مصفوفة كائنات، أو { "listings": [...] } للمقارنة.

الإجراء

  1. اجمع العنوان والسعر والمواصفات والصور ورابط صفحة التفاصيل الأساسي. ميّز الحقائق الموثَّقة عن غير المعروفة؛ لا تختلق أسعارًا أو مرافق أو روابط صور.
  2. ادمج نسخ البوابات المكرَّرة لنفس العقار في بطاقة واحدة، مع الاحتفاظ بروابط المصدر المفيدة. أبقِ تواريخ المصدر وتحذيرات التوافر في النص المحيط.
  3. أصدر سياج listing لكل عقار معروض، بما في ذلك عمليات المتابعة وإعادة الترتيب. اجعل الحقائق مختصرة وضع المخاوف غير المحسومة في catches.
  4. تحقق من صحة JSON قبل الإرسال. هذا مثال خيالي على الصيغة يوضّح كل الحقول؛ استبدل قيمه وروابط المثال ببيانات قوائم موثَّقة:

المزالق

  • تُؤلَّف البطاقات من البيانات المجموعة، لا من جلبها مباشرة من رابط قائمة أو صفحة بوابة مضمَّنة.
  • تحتاج البطاقة المقتضبة إلى العنوان فقط. احذف الحقول غير المعروفة بدلًا من ملئها بتخمينات.
  • استخدم روابط صور بعيدة مباشرة، لا مسارات محلية أو data URLs أو صفحات نتائج بحث. الصور المنتهية الصلاحية أو المحظورة تختفي من المعرض؛ يبقى النص والروابط مهمَّين.
  • لا يتجاوز السياج الواحد 24 عقارًا، و40 صورة لكل عقار، و12 إدخالًا في facts وcatches وlinks. تُقتطَع الحقول النصية عند 400 حرف من قِبل المُصيِّر.
  • يتحول JSON غير الصالح أو بطاقة بلا هوية إلى كتلة كود عادية. صلاحية البطاقة ليست دليلًا على أن العقار الأساسي حديث أو دقيق.

التحقق

  • لكل عقار معروض عنوان ورابط مصدر موثَّق؛ والمجاهيل مذكورة صراحةً.
  • يعرض سطح المكتب العنوان والسعر والمواصفات وfacts وcatches وlinks كبطاقة أصلية.
  • تشكّل الصور معرضًا؛ يفتح اختيار صورة صندوق العرض (lightbox). تستخدم ثلاث صور أو أكثر فسيفساء رئيسية-وداعمة؛ وتبقى الصور الإضافية قابلة للتصفح فيها.
  • إذا فشلت البطاقة في العرض، تحقق من لغة السياج وJSON، ثم احتفظ ببديل Markdown مقروء يحمل الحقائق والروابط نفسها.
