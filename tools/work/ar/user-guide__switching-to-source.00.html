الانتقال إلى تثبيت من المصدر

النسخة المسحوبة من المصدر والتطبيق المحزّم تثبيتان منفصلان. يواصل التطبيق المحزّم استخدام حمولته الخاصة؛ ولا يعتمد نسخة مسحوبة قريبة منه. استخدم تطبيق سطح مكتب مبنيًا من المصدر عندما تريد أن تشغّل GUI كودًا معدّلًا.

توجد بيانات المستخدم عادةً خارج التطبيق:

المضيفالموقع الافتراضي للبيانات
Linux و macOS و WSL و Termux~/.hermes/
Windows الأصلي%LOCALAPPDATA%\hermes\
حاوية Docker الرسمية/opt/data/، مع تعيينه إلى تخزين المضيف

HERMES_HOME و profile المختار تجاوز هذه القيم الافتراضية. سجّل مجلدي المصدر والوجهة الفعليين قبل تغيير التثبيتات.

1. انسخ احتياطيًا وأوقف وقت التشغيل القديم

أغلق تطبيق سطح المكتب وأوقف gateways/الخدمات التي تملكها قبل التسليم. إغلاق Desktop و hermes gateway stop عمليتان مختلفتان: لا يعني إغلاق التطبيق بالضرورة إيقاف messaging gateway يُدار بشكل مستقل.

يمنع قفل gateway لكل profile وجود gateways مكرّرة. أما أقفال الجلسات وتزامن SQLite فمسألتان منفصلتان؛ لا يغيّر بدء عملية ثانية وضع سجل SQLite بحد ذاته. عند التسليم، تجنّب أن تكتب إصدارات كود مختلطة إلى المجلد نفسه بينما ينفّذ أي منها ترحيلات.

2. استنسخ نسخة مسحوبة مستقلة

للتطوير، استنسخ fork الخاص بك بدلًا من ذلك وأضف المستودع الأصلي باسم upstream. اختر branch أو commit قبل تجهيز الاعتماديات. لا تستنسخ داخل حزمة تطبيق موقّعة ولا تستبدل وقت التشغيل المحزّم.

يقرأ bootstrap إصدارات الأدوات المثبّتة من pm/lock.json ويفوّض التثبيت إلى PM. يعمل الكود الحالي المطوَّر رسميًا على Python 3.14. لا تتيح بيانات الحزمة الوصفية الأوسع >=3.11,<3.15 إلا للتثبيتات الأقدم تشغيل برنامج التحديث قبل أن ينقلها PM إلى 3.14؛ وليست نطاقًا لدعم وقت التشغيل. القيمة الافتراضية للمصدر هي الإضافات (extras) all، لا --all-extras.

يجمع التفعيل بيئة الأدوات المثبّتة ويعرّف hermes بوصفه CLI الخاص بهذه worktree. تحجب الدالة أمر hermes أقدم أو alias MSIX، وترفض العمل خارج worktree. يستعيد deactivate بيئة الـ shell ويزيل الدالة عند الانتهاء.

لاعتماديات الاختبار والبيئات اليدوية، استخدم إعداد التطوير. راجع إدارة الحزم لأجيال Python المختارة ومخزن الأدوات القابل للكتابة.

4. اختر البيانات عمدًا

للاستخدام العادي على المضيف نفسه، اختر HERMES_HOME و profile نفسيهما كما في التثبيت السابق. للتطوير، يكون مجلد مستقل أكثر أمانًا لأن الكود الجديد قد يرحّل البيانات المخزّنة.

لبناء تطبيق سطح مكتب من المصدر، نفّذ hermes desktop من النسخة المسحوبة المجهّزة. ولا يزال فتح التطبيق المحزّم القديم يبدأ backend المحزّم الخاص به.

مستخدمو Docker

/opt/data مسار حاوية، وليس بالضرورة مسار مضيف قابلًا للاستخدام. في حالة bind mount، استخدم المجلد على جهة المضيف بوصفه HERMES_HOME لعملية المصدر. بالنسبة إلى volume مسمّى أو تخزين Docker Desktop VM، أوقف gateway القديم أولًا. ثم صدّر/استورد نسخة احتياطية أو انسخ البيانات عبر تركيب مضبوط. تحقّق من الملكية والصلاحيات على الوجهة.

ينتج التنفيذ المحلي لـ docker build -t hermes-agent . تثبيتًا آخر تديره الصورة. لا يحوّل الحاوية العاملة إلى نسخة مسحوبة من المصدر تحدّث نفسها. أعد إنشاء الحاوية لاستخدام تلك الصورة. راجع Docker.

مستخدمو Nix و Termux

يظل التنفيذ المحلي لـ nix run . يشغّل اشتقاقًا يملكه Nix. تبقى ملفات حزمته غير قابلة للتعديل وتظل التحديثات من اختصاص Nix. استخدم nix develop للحصول على shell للتطوير، أو إجراء المصدر أعلاه حيث يدعمه المضيف.

توزيع Termux حزمة APT مبنية لـ bionic. ليس bootstrap المصدر لسطح المكتب/الخادم مسار تطوير أو إصلاح مدعومًا له. استخدم دليل Termux لمعرفة حدود الحزمة والبناء.

العودة دون افتراض أن الرجوع إلى إصدار أقدم آمن

أوقف وقت التشغيل من المصدر، واخرج من تفعيله، وافتح التطبيق المحزّم. افحص أمر CLI الذي يُحلّ قبل استخدام hermes مجددًا:

على Windows، استخدم Get-Command hermes -All. لا تستبدل أمرًا أو alias تنفيذ غير ذي صلة دون التحقّق من مالكه.

قد يغيّر إصدار مصدر أحدث تنسيقات البيانات. العودة إلى حزمة أقدم ليست عكس ترحيل مخطط. احتفظ بالبيانات الحالية واستعد نسخة احتياطية متوافقة أُخذت قبل الانتقال إذا احتاجت الحزمة الأقدم إليها.

لا يحذف حذفُ النسخة المسحوبة من المصدر التطبيقَ المحزّم. ولا يجمع تلقائيًا كل إدخالات أدوات PM أو أجيال Python. استخدم تشخيص PM وجمع الموارد غير المستخدمة بدلًا من حذف جذر البيانات المشترك.

استكشاف الأخطاء وإصلاحها

  • إصدار خاطئ: افحص حلّ الأوامر، ثم استخدم hermes --version من النسخة المسحوبة المفعّلة.
  • اعتماديات مفقودة: نفّذ python -m pm.cli install من بيئة المصدر المقصودة، ثم أعد تشغيل عملية Hermes المتأثرة.
  • gateway يعمل بالفعل: افحص hermes gateway status للـ profile المختار. أوقف المالك المحدّد؛ ولا تقتل عمليات غير مرتبطة.
  • مهارات مختلفة بعد التشغيل الأول: قد يزامن الكود الأحدث المهارات المضمّنة إلى مجلد البيانات. ليست النسخة المسحوبة من المصدر عرضًا للقراءة فقط لذلك المجلد.
