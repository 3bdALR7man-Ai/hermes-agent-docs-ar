لوحة تحكم الويب و Hermes Desktop

المصادقة الخاصة بـ لوحة تحكم الويب ولربط Hermes Desktop بخلفية (backend) عن بُعد. بحسب اصطلاح الاقتصار على الأسرار (secrets-only)، تنتمي بيانات الاعتماد إلى ~/.hermes/.env، أما client_id الخاص بـ OAuth فمن الأفضل ضبطه تحت dashboard.oauth في config.yaml (يفوز متغير البيئة عند ضبطه)

يأتي ثلاثة مزوّدي مصادقة للوحة التحكم مضمَّنين افتراضيًا. لاتصال Hermes Desktop عن بُعد أو أي لوحة تحكم مكشوفة على الإنترنت، المزوّد الموصى به هو OAuth (Nous Portal) — اضبط HERMES_DASHBOARD_OAUTH_CLIENT_ID (وفّره عبر hermes dashboard register). مزوّد اسم المستخدم/كلمة المرور المضمَّن (HERMES_DASHBOARD_BASIC_AUTH_*) هو الخيار الأسرع لخلفية على شبكة محلية موثوقة أو خلف VPN، لكنه غير مناسب للتعريض المباشر على الإنترنت العام. للمصادقة مقابل مزوّد الهوية الخاص بك، استخدم مزوّد OIDC المستضاف ذاتيًا (HERMES_DASHBOARD_OIDC_*). في كل الأحوال، الربط بعنوان غير loopback (hermes dashboard --host 0.0.0.0) يفعّل بوابة المصادقة. راجع لوحة تحكم الويب ← المصادقة للصورة الكاملة

IRC_NICKNAMEالاسم المستعار للبوت (الافتراضي: hermes-bot). مطلوب
IRC_PORTمنفذ الخادم (الافتراضي: 6697 مع TLS، و6667 بدونه)
IRC_USE_TLSاستخدام TLS (true/false؛ الافتراضي true على المنفذ 6697)
IRC_SERVER_PASSWORDكلمة مرور الخادم لأمر PASS (اختياري)
IRC_NICKSERV_PASSWORDكلمة مرور NickServ للـ IDENTIFY التلقائي عند الاتصال (اختياري)
IRC_ALLOWED_USERSأسماء مستعارة مفصولة بفواصل مسموح لها بمحادثة البوت
IRC_ALLOW_ALL_USERSالسماح لأي شخص في القناة بمحادثة البوت (للتطوير فقط)
IRC_HOME_CHANNELالقناة لتسليم مهام cron / الإشعارات (الافتراضي IRC_CHANNEL)

SimpleX

اربط Hermes بشبكة SimpleX Chat عبر daemon محلي لـ simplex-chat. راجع دليل مراسلة SimpleX

المتغيرالوصف
SIMPLEX_WS_URLعنوان WebSocket لـ daemon الخاص بـ simplex-chat (مثلًا ws://127.0.0.1:5225)
SIMPLEX_ALLOWED_USERSمعرّفات جهات اتصال SimpleX مفصولة بفواصل مسموح لها بمحادثة البوت
SIMPLEX_ALLOW_ALL_USERSالسماح لأي جهة اتصال بمحادثة البوت (للتطوير فقط — يعطّل قائمة السماح)
SIMPLEX_AUTO_ACCEPTقبول طلبات جهات الاتصال الواردة تلقائيًا (الافتراضي: true)
SIMPLEX_GROUP_ALLOWEDمعرّفات مجموعات SimpleX مفصولة بفواصل ينبغي على البوت المشاركة فيها، أو * للسماح بأي مجموعة. اتركه فارغًا لتجاهل رسائل المجموعات كليًا (الافتراضي الأكثر أمانًا — وإلا فإن بوتًا في مجموعة يعالج حركة كل عضو فيها)
SIMPLEX_HOME_CHANNELمعرّف جهة اتصال/مجموعة افتراضي لتسليم مهام cron / الإشعارات
SIMPLEX_HOME_CHANNEL_NAMEتسمية بشرية للقناة الرئيسية (الافتراضي المعرّف نفسه)

Photon

اربط Hermes بـ Photon / Spectrum (iMessage ومنصات Spectrum الأخرى) عبر sidecar الخاص بـ Node. راجع دليل مراسلة Photon

المتغيرالوصف
PHOTON_PROJECT_IDمعرّف مشروع Spectrum (قيمة spectrumProjectId الخاصة بالمشروع؛ يضبطها hermes photon setup)
PHOTON_PROJECT_SECRETسر المشروع المقترن بمعرّف مشروع Spectrum (يضبطه hermes photon setup)
PHOTON_ALLOWED_USERSأرقام هواتف بصيغة E.164 مفصولة بفواصل مسموح لها بمحادثة البوت
PHOTON_ALLOW_ALL_USERSالسماح لأي مرسِل بتشغيل البوت (للتطوير فقط — يعطّل قائمة السماح)
PHOTON_REQUIRE_MENTIONتجاهل رسائل المحادثات الجماعية ما لم تطابق كلمة تنبيه (wake word) للإشارة (true/false، الافتراضي false)
PHOTON_MENTION_PATTERNSتعبيرات نمطية لكلمات تنبيه الإشارة للمحادثات الجماعية (قائمة JSON أو مفصولة بفواصل/أسطر جديدة؛ الافتراضي كلمات تنبيه Hermes)
PHOTON_HOME_CHANNELهدف Photon الافتراضي لتسليم مهام cron / الإشعارات: معرّف مساحة Spectrum، أو GUID محادثة مباشرة، أو رقم هاتف عارٍ بصيغة E.164
PHOTON_HOME_CHANNEL_NAMEتسمية بشرية للقناة الرئيسية
PHOTON_MARKDOWNإرسال ردود الوكيل بصيغة markdown — يعرضها iMessage أصليًا، بينما تتراجع منصات Spectrum الأخرى إلى نص عادي (true/false، الافتراضي true)
PHOTON_REACTIONSوضع تفاعل Tapback 👀/👍/👎 على الرسائل كحالة معالجة، وتوجيه تفاعلات tapback على رسائل البوت إلى الوكيل (true/false، الافتراضي false)
PHOTON_READ_RECEIPTSوضع علامة "مقروءة" على رسائل iMessage الواردة بعد إحالتها إلى Hermes (true/false، الافتراضي true)
PHOTON_TELEMETRYتفعيل تحليلات (telemetry) SDK الخاصة بـ Spectrum في الـ sidecar (true/false، الافتراضي false؛ بدّله باستخدام `hermes photon telemetry on
PHOTON_SIDECAR_PORTمنفذ loopback للتحكم في sidecar الخاص بـ Node وقناة الدخل الواردة (الافتراضي 8789)
PHOTON_SIDECAR_AUTOSTARTتشغيل sidecar الخاص بـ Node عند الاتصال (true/false، الافتراضي true)
PHOTON_NODE_BINمسار ملف node التنفيذي (الافتراضي: shutil.which('node'))
PHOTON_DASHBOARD_HOSTمضيف Photon Dashboard API (الافتراضي https://app.photon.codes)
PHOTON_SPECTRUM_HOSTمضيف Photon Spectrum API (الافتراضي https://spectrum.photon.codes)
