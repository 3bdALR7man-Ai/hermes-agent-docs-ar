MiniMax OAuth

يدعم Hermes Agent خدمة MiniMax عبر تدفّق تسجيل دخول OAuth قائم على المتصفح، باستخدام بيانات الاعتماد نفسها الخاصة بـ بوابة MiniMax. لا حاجة إلى مفتاح API أو بطاقة ائتمان — سجّل الدخول مرة واحدة، ويجدّد Hermes جلستك تلقائيًا.

يعيد النقل استخدام محوّل anthropic_messages (تعرض MiniMax endpoint متوافقًا مع Anthropic Messages على /anthropic)، لذا تعمل جميع ميزات استدعاء الأدوات والبث والسياق الحالية دون أي تغيير في المحوّل.

تدفّق OAuth

ينفّذ Hermes تدفّق OAuth عبر المتصفح باستخدام PKCE مقابل نقاط نهاية OAuth الخاصة بـ MiniMax:

  1. يولّد Hermes زوج تحقّق/تحدٍّ (verifier / challenge) PKCE وقيمة state عشوائية.
  2. يرسل طلب POST إلى {base_url}/oauth/code مع التحدي ويستلم user_code و verification_uri.
  3. يفتح متصفحك verification_uri. إذا طُلب منك، أدخل user_code.
  4. يستطلع Hermes {base_url}/oauth/token إلى أن يصل الرمز (أو تنتهي المهلة).
  5. تُحفظ الرموز (access_token، refresh_token، تاريخ الانتهاء) في ~/.hermes/auth.json تحت المفتاح minimax-oauth.

يُشغَّل تجديد الرمز (منح refresh_token القياسي في OAuth) تلقائيًا عند بدء كل جلسة عندما يكون رمز الوصول على بعد 60 ثانية من انتهاء صلاحيته.

استكشاف الأخطاء وإصلاحها

انتهت صلاحية الرمز (token) — لا يعيد تسجيل الدخول تلقائيًا

يجدّد Hermes الرمز عند بدء كل جلسة إذا كان على بعد 60 ثانية من انتهاء صلاحيته. إذا كان رمز الوصول منتهي الصلاحية بالفعل (مثلًا بعد فترة طويلة دون اتصال)، يحدث التجديد تلقائيًا عند الطلب التالي. إذا فشل التجديد بخطأ refresh_token_reused أو invalid_grant، يُعلِّم Hermes الجلسة بأنها تحتاج إلى إعادة تسجيل دخول.

عندما يكون فشل التجديد نهائيًا (HTTP 4xx، أو invalid_grant، أو منح مُلغى، وما شابه)، يُعلِّم Hermes رمز التجديد بأنه ميت ويعزله محليًا حتى لا يستمر في إعادة محاولة تبادل محكوم عليه بالفشل. يعرض الوكيل رسالة واحدة تفيد بـ"لزوم إعادة المصادقة" ويتوقف عن التدخل إلى أن تسجّل الدخول مرة أخرى.

الحل: شغّل hermes auth add minimax-oauth مرة أخرى لبدء تسجيل دخول جديد. يُزال الحجر (quarantine) عند أول تبادل ناجح تالٍ.

انتهت مهلة التفويض

لتدفّق رمز الجهاز (device code) نافذة انتهاء صلاحية محدودة. إذا لم توافق على تسجيل الدخول في الوقت المحدد، يُطلق Hermes خطأ انتهاء مهلة.

الحل: أعد تشغيل hermes auth add minimax-oauth (أو hermes model). يبدأ التدفّق من جديد.

عدم تطابق state (احتمال CSRF)

اكتشف Hermes أن قيمة state التي أعادها خادم التفويض لا تطابق ما أرسله.

الحل: أعد تشغيل تسجيل الدخول. إذا استمرت المشكلة، تحقّق من وجود وكيل (proxy) أو إعادة توجيه يعدّل استجابة OAuth.

خطأ "Not logged into MiniMax OAuth" أثناء التشغيل

لا يحتوي مخزن المصادقة على بيانات اعتماد لـ minimax-oauth. إما أنك لم تسجّل الدخول بعد، أو أن ملف بيانات الاعتماد قد حُذف.

الحل: شغّل hermes model واختر MiniMax (OAuth)، أو شغّل hermes auth add minimax-oauth.
