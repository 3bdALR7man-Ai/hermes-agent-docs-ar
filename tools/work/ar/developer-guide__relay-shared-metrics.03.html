الضغط المُعَدّ مسبقًا (Prepared compaction)

أُضيف داخل مخطط الحزمة v4. يجيب عمّا إذا كانت التثبيتات التي تفعّل compression.prepare_ahead (راجع compression_prepare_ahead في اللقطة) تحصل على ملخص قابل للاستخدام، أم تدفع كلفة تمريرات لا يستخدمها أحد، أو تنتظرها، أو ترى فشل ضغط مُدمَج. لا يظهر أي نص من النصوص أو فهرس نافذة أو ملخص أو نص إخفاق في أي بُعد: فسبب إخفاق الدمج النصي الحر يُختزل إلى رمز مغلق.

hermes.compression.count؛ وnone ما لم يكن الحدث فشلًا), wait bucket (none, lt_1s, 1s_to_5s, 5s_to_30s, 30s_to_120s, gte_120s: المدة التي انتظرها الضغط لتمريرة جارية)هل تؤتي التمريرات المُعَدّة مسبقًا ثمارها، وإن لم تفعل فلماذا. جانب التمريرة (من الخيط الخلفي): pass_started، وpass_completed (نُشر الملخص)، وpass_failed (لم يُرجع المُلخِّص شيئًا؛ وفئته هي التي كانت ستسجّلها محاولة مضمّنة، وأولها فشل الملخص النهائي)، وpass_cancelled (رأت التمريرة حدث الإلغاء؛ والسبب superseded أو session_boundary أو agent_released أو wait_timeout أو host_cancelled، ويضبطه من ألغاها)، وskipped_busy (رفض السقف على مستوى العملية، وهو تمريرتان متزامنتان، تمريرةً إضافية؛ ويُحتسب مرة واحدة لكل نافذة مرفوضة لا لكل دفعة أدوات)، وinternal_error (فئة الفشل exception). جانب الضغط: used (دُمج الملخص في النص المضغوط، حدّ جلسة يُقرأ session_boundary، وتحرير الوكيل (إخلاء الـ cache، أو الإرجاع، أو الإغلاق، أو انتهاء دور تشغيل لمرة واحدة أو دور عامل مُدار) يُقرأ agent_released، والملخص الذي أخذه الضغط ثم أُجهض أو لم يُنفّذ شيئًا قبل الدمج يُقرأ compaction_aborted)، وcompaction_failed (ضغط دمج ملخصًا مُعَدًّا لكنه لم يُثبَّت، مع فئة محاولته)، وauto_disabled (أول ضغط يحتاج إلى سياق مزوّد ذاكرة أوقف التمريرات للوكيل). قد تُحتسب تمريرة واحدة على الجانبين، فلا تجمع الجانبين معًا أبدًا: discarded + pass_cancelled لتمريرة جارية لم تلائم أو أُسقطت عند حدّ (والحدّ الذي يوقظ ضغطًا منتظرًا يحتسب discarded مرة واحدة، من الحدّ).

دقة بيئة تشغيل الوكيل

تضبط هذه المقاييس حلقة الوكيل نفسها. لا تُحتسَب حلقات المراجعة الخلفية و Curator الخاصة بـ Hermes مطلقًا؛ وتُحتسَب subagents المفوّضة (فاستدعاءات أدواتها وحلقاتها وردودها سلوك نموذج أيضًا). لا يغادر نص الأوامر أو مسارات الملفات أو وسائط الأدوات أو نص الرد مطلقًا — بل القيم المغلقة أدناه وحدها.

الكفاءة: تكلفة الدور والهدر وكلفة الأدوات وانقطاعات التخزين المؤقت للـ prompt

يتبع المزوّد والنموذج قواعد مسار النموذج أعلاه. "دور المستخدم" هو رسالة مستخدم واحدة حتى ردها النهائي؛ ولا يُعد العمل الذي يملكه Hermes (مراجعة الذاكرة/المهارات في الخلفية و Curator وأدوار subagents المفوَّضة نفسها) دور مستخدم.cache_break و tool_output_truncation سلوك النموذج والأداة، لذا تُحتسَب subagents المفوَّضة فيهما؛ ولا تُحتسَب مراجعة الخلفية و Curator أبدًا.

المقياسالأبعادالسؤال الذي يجيب عنه
hermes.task_cost.countالمزوّد، النموذج، فئة عدد tokens (lt_2k … gte_1m, unknown)، فئة عدد استدعاءات الأدوات، فئة عدد استدعاءات API (0 … 51_to_100, gte_101)، النتيجة (completed, interrupted, failed)تكلفة دور المستخدم لكل نموذج. تمثل tokens مجموع الـ prompt (بما فيه قراءات/كتابات التخزين المؤقت) والإكمال عبر استدعاءات الدور الأساسية؛ تكون القيمة unknown عندما لا يبلّغ المزوّد عن الاستخدام. صف واحد لكل دور تفاعلي رأى المستخدم نهايته (لا يُعد الإلغاء عند إغلاق الجلسة دورًا).

التفاعل والرضا الضمني عن النموذج

المقياسالأبعادالسؤال الذي يجيب عنه
hermes.engagement.surface_day.countالواجهة (cli, tui, desktop, gateway, acp)، فئة دقائق النشاط (0, lt_5m, 5m_to_30m, 30m_to_2h, 2h_to_6h, gte_6h)مدة الاستخدام الفعلي لكل واجهة يوميًا. صف واحد لكل واجهة استُخدمت في يوم UTC انتهى.

يُجمَّع الوقت النشط محليًا لكل يوم UTC: مجموع الفواصل بين التفاعلات المتتالية (بدء دور المستخدم أو نهايته على واجهة تفاعلية أو رسالة gateway؛ تُستثنى تشغيلات cron غير المراقبة، التي يحتسبها hermes.cron.run، والعمليات الفرعية المفوّضة ومراجعة الخلفية و Curator والمعالجة الدفعية وخادم API / تضمين Python)، بحد أقصى 5 دقائق لكل فاصل. تُسجَّل صفوف اليوم بعد انتهائه، مع أول تفاعل في يوم لاحق، داخل معاملة قاعدة بيانات واحدة، فيُبلَّغ عن اليوم مرة واحدة تمامًا لكل profile مهما كان عدد العمليات التي ترصد انتقال اليوم؛ وتُؤرَّخ بيومها المعني. النموذج الأساسي هو الذي خدم أكبر عدد من أدوار المستخدم تلك في ذلك اليوم (none إن لم يخدم أيٌّ منها)، ويُسمّى بحسب قواعد مسار النموذج. تُشتق أيام النشاط أسبوعيًا والعودة بحسب النموذج على الخادم من هذه الصفوف اليومية و install_id الموجود: لا يحتفظ Hermes بنافذة أسبوعية أو معرّف غير install_id لهما.

active_profile_count_bucket يحتسب الـ profiles المختلفة على المضيف ذات دور يملكه المستخدم (التفاعلات أعلاه) في يوم UTC ذاك. يضمّ كل profile أدواره إلى مجمّع واحد للمضيف محفوظ في قاعدة بيانات الـ profile الجذري (الافتراضي)، كقيم hash محلية مبهمة لمجلد كل profile لا تغادرها أبدًا، فيُحتسب كل profile مرة واحدة مهما كانت العملية أو بيئة التشغيل متعددة الإرسال التي خدمته. يحمل صف اليوم للـ profile الجذري العدد فقط (ويبلّغ عن يوم حتى حين يكون الجذر خاملًا، مع 0 من دقائق النشاط والواجهات)؛ وتكون قيمة صف كل profile آخر 0. عندما يكون الجمع معطّلًا في الـ profile الجذري، لا يُكتب شيء في قاعدة بياناته ولا يُبلَّغ عن العدد.

hermes.tool_unavailable.countالمزوّد، النموذج، اسم الأداة (المدمجة المضمّنة فقط)toolsets التي ينبغي تفعيلها افتراضيًا: استدعى النموذج أداة مضمّنة في Hermes لم تفعّلها هذه الجلسة. يبقى أي اسم مجهول آخر (إضافة أو MCP أو اسم متوهَّم) مشكلة model_tool_quality unknown_tool فقط. الأداة المدمجة التي فعّلتها الجلسة لكنها مؤجَّلة خلف tool_search (يمكن الوصول إليها عبر tool_call) ليست غير متاحة. تُستثنى مراجعات الخلفية والعمليات الفرعية المفوَّضة ومهام cron، التي تُضيَّق toolsets الخاصة بها عمدًا.
hermes.provider_setup.countالمزوّد (اسم الكتالوج؛ تظهر endpoints المخصّصة بقيمة custom)، الواجهة (cli_setup, cli_model, tui, desktop, dashboard)، الحدث (started, completed, failed, abandoned)، فئة الإخفاق (auth, network, no_models, other; none ما لم يفشل؛ لم تعد cancelled تُسجَّل، ويُسجَّل الإلغاء كـ abandoned)موضع تعثر ربط المزوّد. يُحتسب started بمجرد اختيار مزوّد؛ وتسجّل نهاية المسار الواجهة التي نفّذته. يُسجَّل المسار الذي تركه المستخدم كـ abandoned، وليس failed أبدًا: Esc أو Ctrl-C في محدّدات CLI، و Cancel/Back في تسجيل دخول Desktop أو لوحة التحكم، ورفض الموافقة في صفحة المزوّد، وترك رمز دخول حتى انتهاء صلاحيته (أي مزوّد). يُبقي Back (السهم الأيسر) في CLI المسار مفتوحًا، لذا يواصل اختيار المزوّد نفسه المسار (started واحد)، بينما ينهي اختيار مزوّد آخر أو مغادرة الأمر المسار كـ abandoned. يترك المسار الذي لم يُكمله أحد علامة محلية يبلّغ عنها بدء الإعداد أو بدء Hermes التالي في الـ profile كـ abandoned (اختفت عمليته أو بقي معلّقًا أكثر من ساعة). يحتفظ تسجيل دخول Desktop/لوحة التحكم الذي يتوقف أثناء الاستقصاء بفئة الخطأ الذي أنهى العملية (network لاتصال انقطع، و auth لرفض)، لا مجرد other. يبدأ مفتاح API جديد أو متغيّر محفوظ من نموذج (TUI/Desktop/لوحة التحكم) و endpoint مخصّص مضاف حديثًا وينتهيان في إجراء واحد؛ لا يُحتسب مسح مفتاح أو حفظ المفتاح نفسه مجددًا أو تعديل endpoint قائم أو tokens المنظومة (GITHUB_TOKEN, GH_TOKEN, HF_TOKEN) أو المفاتيح التي تطلبها أيضًا لوحة إعدادات أداة (مثل GEMINI_API_KEY, XAI_API_KEY, DEEPINFRA_API_KEY) من نموذج المفاتيح العام (تميّز عملية البدء وإعدادات النموذج في Desktop عمليات حفظها كربط مزوّد، فتُحتسب). لا يُسجَّل أبدًا مفتاح أو token أو عنوان URL أساسي أو نص خطأ. لا تُحتسب مغادرة محدّد المزوّدين قبل اختيار واحد.
hermes.feature_adoption.countالميزة (memory, skills_created, delegation, cron, gateway_platform, desktop, tui, mcp, plugins, browser, voice, kanban, projects, bot_mode, curator)، الأيام منذ التثبيت (same_day, 1d_to_7d, 7d_to_30d, 30d_to_90d, gte_90d, unknown)المدة بعد التثبيت حتى أول استخدام فعلي لكل ميزة رئيسية. مرة واحدة لكل ميزة لكل تثبيت، تُثبَّت في قاعدة البيانات المحلية وتُشتق من العدادات أعلاه (كتابة ذاكرة في الواجهة الأمامية، أو مهارة أُنشئت بطلب المستخدم لا بمراجعة الخلفية في Hermes، أو استدعاء ناجح لأداة MCP/إضافة/متصفح/TTS/Kanban، أو مهمة Desktop/TUI/gateway، أو تشغيل cron، أو تشغيل Curator يدوي؛ لا تُحتسب جولة Curator المجدولة)، مع تقارير مباشرة عن الاستخدام الأول لرسائل Bot Mode وإنشاء المشاريع. العمر يعود إلى الـ profile المالك (جلسته الأولى).
hermes.feature_disabled.countالنوع (toolset, skill, plugin, platform, setting, memory, curator, compression)، الاسم، الواجهة (cli_tools, cli_config, cli_slash, tui, desktop, dashboard)، الحدث (disabled, re_enabled)ما يعطّله المستخدمون. تُقارَن الفروق عند كتابة الإعدادات نفسها: إزالة toolset مفعّلة افتراضيًا، أو إضافة مهارة أو إضافة إلى قائمة تعطيلها، أو ضبط إعداد قيمته الافتراضية true على false (وكل إعادة عكسية). لا تكون الأسماء علنية إلا إذا كانت مضمّنة — مفتاح toolset أو مهارة مضمّنة/من الكتالوج أو إضافة مضمّنة/من الكتالوج (تُبلّغ إضافات منصات المراسلة كـ platform), DEFAULT_CONFIG مسار مفتاح (لا قيمة أبدًا) — وإلا custom. يُحتسب إلغاء تثبيت مهارة كتالوج كـ disabled. تسجّل نقاط دخول المستخدم فقط (hermes tools / config / skills / plugins و slash commands للمحادثة و TUI/Desktop ولوحة التحكم)؛ ولا يسجّل الإعداد أو الترحيل حتى عندما يجري الترحيل داخل إحداها (hermes config migrate، أو profile أُنشئ من لوحة التحكم). لا تُقارَن إعدادات قيمتها قالب ${VAR}. تعمل مقارنة الفروق والتسجيل على thread في الخلفية بعد الكتابة، خارج كل أقفال الإعدادات. مرة واحدة كحد أقصى لكل (نوع، اسم، حدث) يوميًا.
