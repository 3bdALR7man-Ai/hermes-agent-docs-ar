MCP (Model Context Protocol)

تستخدم أوامر اعتماديات Python في هذه الصفحة نسخة مصدر مسحوبة أعدّها PM. بعد تغيير اعتماديات، أعد تفعيل النسخة المسحوبة وأعد تشغيل Hermes.

يتيح MCP لـ Hermes Agent الاتصال بخوادم أدوات خارجية، بحيث يستطيع الوكيل استخدام أدوات موجودة خارج Hermes نفسه — مثل GitHub ، وقواعد البيانات، وأنظمة الملفات، وحِزم المتصفحات، وواجهات API الداخلية، وغير ذلك.

إذا سبق أن أردت أن يستخدم Hermes أداة موجودة بالفعل في مكان آخر، فإن MCP هو عادةً أنظف طريقة لتحقيق ذلك.

قادم من Claude Code ؟

تقابل كتلة mcpServers في ملف ~/.claude.json لديك المفتاح mcp_servers في ملف Hermes config.yaml الخاص بـ Hermes — ويتولى الأمر hermes import-agent claude-code ترحيلها تلقائيًا (إلى جانب المهارات والتعليمات). راجع الاستيراد من وكلاء آخرين.

ما الذي يمنحك إياه MCP

  • الوصول إلى منظومات أدوات خارجية دون الحاجة إلى كتابة أداة Hermes أصلية أولًا
  • خوادم stdio محلية وخوادم HTTP MCP بعيدة في ملف الإعدادات نفسه
  • اكتشاف الأدوات وتسجيلها تلقائيًا عند بدء التشغيل
  • أغلفة (wrappers) مساعدة لموارد MCP والـ prompts عندما يدعمها الخادم
  • تصفية على مستوى كل خادم، بحيث لا تكشف إلا أدوات MCP التي تريد فعلًا أن يراها Hermes

الكتالوج: تثبيت بنقرة واحدة لخوادم MCP المعتمدة من Nous

يأتي Hermes مع كتالوج منتقى من خوادم MCP راجعها فريق Nous ودمجها. وهي معطّلة افتراضيًا — فلا تثبّت إلا ما تحتاجه فعلًا.

يمكنك أيضًا الطلب في المحادثة: "أضف Linear MCP". يستدعي الوكيل manage_connections مع هدف mcp: true فتظهر بطاقة إعداد. تعمل البطاقة بالطريقة نفسها في تطبيق Desktop (نافذة حوار)، وواجهة الطرفية (hermes --tui، تنبيه فوق محرر الرسالة)، و CLI التقليدي (لوحة):

  1. الحقول. إذا أعلن الإدخال قيم إعداد، تعرضها البطاقة كلها دفعة واحدة. تُملأ القيمة العادية مسبقًا بقيمتها الافتراضية. ويُخفى السر. لا يُحفظ شيء أثناء الكتابة.
  2. Connect أو Cancel. يتجاوز Cancel ذلك الخادم وحده؛ وتستمر الخوادم الأخرى في الطلب نفسه.
  3. التفويض. لإدخال OAuth تعرض البطاقة رابط التفويض. لا يفتح Hermes المتصفح بنفسه مطلقًا: انقر Open in browser في Desktop ، أو اضغط Enter في الطرفية. وعبر SSH تخبرك البطاقة كيف تصل إلى منفذ callback أو تلصق URL المعاد التوجيه إليه.
  4. الحفظ. يحفظ Hermes إعدادات الخادم و tokens وقيم إعدادك معًا، بعد قبول الخادم الـ token الجديد وعودة الاتصال الأول. إذا رفض الخادم الـ token ، أو ألغيت قبل تلك النقطة، فلا يُحتفظ بشيء من المحاولة، وتبقى إعداداتك و tokens السابقة كما كانت، ويُفتح النموذج الفاشل مجددًا بما كتبته. ويتصل الخادم المفوّض بالفعل بـ tokens المحفوظة؛ ولا يطلب Hermes إعادة التفويض إلا حين تتوقف عن العمل.
  5. الأدوات. يسرد Hermes بعد ذلك أدوات الخادم ويسجلها. يستطيع الوكيل استدعاءها في الدور نفسه. إذا نجح التفويض وفشل سرد الأدوات، تقول البطاقة "Authorized. Tools unavailable."، ويستطيع الوكيل إعادة الاكتشاف لاحقًا دون طلب إعادة التفويض.

لا توجد بطاقة في تطبيقات المراسلة؛ بل ينقل الوكيل الأوامر أدناه.

تعرض أداة الاختيار كل إدخال مع حالته الحالية:

اضغط Enter على أي صف للتثبيت (مع المرور بخطوات إدخال أي بيانات اعتماد مطلوبة)، أو التفعيل، أو التعطيل، أو إلغاء التثبيت. تُخزَّن إدخالات الكتالوج ضمن optional-mcps/ في مستودع hermes-agent — ووجود الإدخال في ذلك المجلد يعني أنه معتمد من Nous. لا يوجد مستوى لإسهامات المجتمع؛ إذ تُضاف الإدخالات عبر دمج PR.

لم يعد جسر n8n الخارجي متاحًا للتثبيت من الكتالوج. تحتفظ التثبيتات الموجودة بإعدادات mcp_servers وبيانات الاعتماد والملفات المثبّتة والأدوات المختارة. وتستمر في التحميل كخوادم MCP مُعدّة، وتظهر كإدخالات مخصصة في المنتقي، حيث يمكنك الاستمرار في إعداد الأدوات أو تفعيلها وتعطيلها. لم تعد إعادة التثبيت من الكتالوج متاحة. ولا يرحّل هذا التغيير الاتصالات الموجودة إلى خادم MCP الرسمي لـ n8n.

قد تتطلب إدخالات الكتالوج:

  • مفتاح API — يطلبه Hermes عند التثبيت ويكتب القيمة في ~/.hermes/.env. وتُكتب القيم غير السرية (مثل عناوين URL الأساسية) في الملف نفسه.
  • OAuth (لخوادم MCP البعيدة) — يُكتب كـ auth: oauth في ملف الإعدادات؛ ويفتح عميل MCP المتصفح عند أول اتصال.
  • OAuth (لمزوّد خارجي مثل Google/GitHub) — يوجّهك Hermes إلى hermes auth <provider> إذا لم تكن قد أجريت المصادقة بعد.

خادم MCP الرسمي لـ n8n

يتصل إدخال الكتالوج n8n-official مباشرة بنُسخة n8n Cloud أو نُسختك المستضافة ذاتيًا عبر HTTP باستخدام OAuth في المتصفح. ولا يلزم جسر محلي أو مفتاح API لـ n8n.

  1. اطلب من مالك أو مسؤول تفعيل Settings > Instance-level MCP في n8n.
  2. افتح Connect وانسخ Server URL الكامل المنتهي بـ /mcp-server/http، لا URL المحرر. تعرض الإصدارات الأقدم endpoint مباشرة في صفحة إعدادات MCP.
  3. نفّذ hermes mcp install n8n-official وأدخل ذلك URL عند الطلب.
  4. أكمل OAuth في المتصفح. عند الحاجة نفّذ hermes mcp login n8n-official أو استخدم Authorize على الخادم المُعدّ في Desktop أو لوحة التحكم.
  5. راجع الأدوات باستخدام hermes mcp configure n8n-official، ثم ابدأ جلسة جديدة أو استخدم /reload-mcp.

يجب أن يتمكن backend Hermes من الوصول إلى URL. يتحكم n8n في الصلاحيات وإتاحة workflows ؛ وبعض الأدوات تعدّل workflows أو تشغّلها. راجع دليل الاتصال في n8n.

يستخدم هذا الإدخال سلوك إعداد الكتالوج والتخزين الموجود. وهو منفصل عن الجسر n8n المتقاعد، فلا تُستبدل الاتصالات الموجودة أو بيانات الاعتماد أو الملفات المثبّتة أو اختيارات الأدوات.

اختيار الأدوات عند التثبيت

بعد إعداد بيانات الاعتماد، يفحص Hermes خادم MCP ليسرد كل أداة يوفّرها، ثم يعرض قائمة تحقق:

تأتي الصفوف المحددة مسبقًا من:

  1. اختيارك السابق إذا كنت قد ثبّتّ هذا الإدخال من قبل (إعادة التثبيت تحافظ على ما كان لديك — ولا تتجاوزه القيم الافتراضية في الـ manifest)
  2. قيمة tools.default_enabled إذا صرّح بها الإدخال (بعض إدخالات الكتالوج تستبعد مسبقًا الأدوات التي تُجري تغييرات أو نادرًا ما تكون مفيدة)
  3. كل الأدوات إذا لم ينطبق أيٌّ مما سبق

بعض الإدخالات ذات الواجهات الضخمة المولَّدة تلقائيًا (مثل cloudflare، بنحو 3,300 أداة تمثّل endpoints من OpenAPI) تُصرّح بدلًا من ذلك بـ tools.default_excluded — وهي قائمة حظر منتقاة من الأسماء وأنماط glob. يؤدي تثبيت أحد هذه الإدخالات إلى تخطي قائمة التحقق كليًا وكتابة tools.exclude؛ ويبقى كل ما لا يطابقها مفعّلًا، بما في ذلك الأدوات التي يضيفها الخادم لاحقًا. عدّل mcp_servers.<name>.tools.exclude في config.yaml لإعادة تفعيل عائلة من الأدوات.

أرسل قائمة التحقق بالضغط على ENTER. لا ينتهي في mcp_servers.<name>.tools.include إلا الأدوات المحددة. وإذا اخترت كل الأدوات، فلن يُكتب أي مرشّح (أنظف شكل للإعدادات، مع سلوك مطابق).

إذا فشل الفحص (الخادم غير قابل للوصول، أو لم تكتمل OAuth بعد، أو الخدمة الخلفية لا تعمل)، يظل التثبيت ناجحًا: إذ تُطبَّق قيمة tools.default_enabled من الـ manifest مباشرةً (إن كانت مُصرَّحًا بها)، وإلا فلا يُكتب أي مرشّح. أعد تشغيل hermes mcp configure <name> بمجرد أن يصبح الخادم قابلًا للوصول لتحسين الاختيار.

نموذج الثقة

يؤدي تثبيت إدخال من الكتالوج إلى تنفيذ كل ما يحدده الـ manifest — أي git clone، وأوامر bootstrap الخاصة بالإدخال (pip install, npm install، وغيرها)، وفي النهاية كود خادم MCP نفسه. تخضع ملفات الـ manifest لمراجعة PR قبل دمجها في مستودع hermes-agent ، لذا راجع فريق Nous كل إدخال قبل إصداره — لكن ينبغي لك مع ذلك قراءة الـ manifest قبل التثبيت، ولا سيما المستودع المذكور في الحقل source:، وأوامر install.bootstrap:، وأي استدعاء في transport.command: الاستدعاء.

توجد ملفات الـ manifest في optional-mcps/<name>/manifest.yaml على GitHub. كما تطبع أداة الاختيار عنوان source: URL الخاص بالـ manifest عند التثبيت، لتتمكن من التحقق سريعًا من المستودع الأصلي. وتعرض صفحة MCP في لوحة التحكم على الويب التفاصيل نفسها لكل إدخال في الكتالوج — طبقة النقل، ونوع المصادقة، وعنوان URL للـ endpoint ‏(HTTP) أو الأمر + الوسائط (stdio)، ومصدر التثبيت/المرجع في git وأوامر bootstrap ، وملاحظات الإعداد — مع عرض source: كرابط قابل للنقر، حتى تتمكن من فحص ما يتصل به الإدخال أو ينفّذه بالضبط قبل النقر على Install.

توافق إصدارات الـ manifest

تُثبّت ملفات الـ manifest قيمة manifest_version. والكتالوج متوافق مع الإصدارات المستقبلية: فإذا أضاف PR إدخالًا بقيمة manifest_version أحدث مما يفهمه إصدار Hermes المثبّت لديك، فستعرض أداة الاختيار تحذيرًا (⚠ '<name>' requires a newer Hermes) لذلك الإدخال بدلًا من إخفائه بصمت. شغّل hermes update لتثبيت أحدث إصدار من Hermes عندما ترى ذلك.

استبدال ${ENV_VAR} وقت التشغيل

داخل transport.command, transport.args, transport.url، وheaders, ${VAR} تُحدَّد العناصر النائبة وقت اتصال الخادم من متغيرات البيئة (التي تشمل كل ما في ~/.hermes/.env). يفيد هذا عندما يريد إدخال في الكتالوج الإشارة إلى قيمة ضبطها المستخدم في مكان آخر — مثل ${HOME}/foo أو ${MY_PROVIDER_TOKEN}.

تُستبدل أيضًا متغيرات السياق على نمط Cursor (مع مراعاة حالة الأحرف): ${userHome} (المجلد الرئيسي)، و${workspaceFolder} (جذر مساحة عمل الجلسة)، و${workspaceFolderBasename}، و${pathSeparator} / ${/} (فاصل المسارات في نظام التشغيل). راجع مرجع إعدادات MCP للتفاصيل.

لاحظ أن هذا يختلف عن ${INSTALL_DIR} في ملفات manifest الخاصة بالكتالوج، والذي يُستبدل وقت التثبيت بالمسار الذي نسخ إليه الكتالوجُ مستودعَ الإدخال.

إدخالات تحتاج تطبيق OAuth خاصًا بك (دون DCR)

يشغّل بعض المزوّدين MCP البعيد خلف OAuth لكنهم لا يوفرون Dynamic Client Registration — فيجب أن يكون كل عميل تطبيقًا يسجله المستخدم مسبقًا في لوحة مطوّري المزوّد. وخادم Asana V2 (https://mcp.asana.com/v2/mcp) هو المثال المضمّن: كان خادم V1 المتقاعد https://mcp.asana.com/sse يقبل أي عميل؛ أما V2 فلا.

يعلن manifest كهذا بيانات الاعتماد تحت auth.env ويثبّت العميل تحت auth.oauth، لذا يطلب تثبيته (منتقي CLI أو لوحة الويب أو Desktop) Client ID / Client secret ، ويخزنهما في .env الخاص بالـ profile ، ولا يكتب إلى ${VAR} إلا مراجع config.yaml:

اقرأ ملاحظات post_install للإدخال لمعرفة نوع التطبيق و URL إعادة التوجيه المطلوب تسجيلهما بدقة، ثم نفّذ hermes mcp login <name> وأعد تشغيل (أو /reload-mcp) الجلسة أو الـ gateway الذي ينبغي أن يعرض الأدوات. ويعمل زر Authorize في لوحة التحكم / Desktop أيضًا: لأن العميل مسجل مسبقًا مع redirect_port مثبّت، يحتفظ Hermes بـ callback loopback المسجّل (http://localhost:27890/callback) بدل URL callback الخاص بلوحة التحكم — لذا يجب أن يعمل متصفح الموافقة على الجهاز نفسه الذي يشغّل عملية Hermes. وللمضيف البعيد استخدم hermes mcp login عبر توجيه منفذ SSH.

تحديث اختيار الأدوات لاحقًا

يعيد فتح قائمة التحقق نفسها مع تحديد اختيارك الحالي مسبقًا. استخدمه عندما تريد تفعيل مزيد من الأدوات، أو عندما يضيف الخادم أدوات جديدة تريد الاشتراك فيها.

تحديث manifest الكتالوج

لا تُحدَّث خوادم MCP تلقائيًا أبدًا. أعد تشغيل hermes mcp install <name> للتحديث بعد تحديث Hermes إذا تغيّر إصدار الـ manifest.

لإضافة خادم MCP إلى الكتالوج، افتح PR على optional-mcps/.

بيانات الاقتراح الوصفية (suggest:)

يمكن للـ manifest أن يُصرّح بكتلة suggest: اختيارية تحتوي على قائمتَي keywords: و/أو hosts:. تستخدمها واجهات المستخدم (حاليًا محرّر الرسائل في تطبيق Desktop) لعرض زر "Add <server>" بنقرة واحدة عندما تذكر مسودتك إحدى الكلمات المفتاحية ككلمة مكتملة، أو تحتوي على رابط ملصوق ينتهي اسم مضيفه بإحدى لواحق المضيفين. وهي استشارية بحتة — إذ تمر عمليات التثبيت دائمًا عبر مسارات الكتالوج/الإعدادات نفسها التي خضعت للتحقق — وتُصرّح بها معظم الإدخالات البعيدة المستضافة (Atlassian و Sentry و Notion و Stripe و Vercel و Supabase وغيرها).applications: (حتى 16 اسم تطبيق)، و requires_app: true (يحتاج MCP ذلك التطبيق المحلي؛ ولا تُعرض هذه الإدخالات مطلقًا كزر سريع بنقرة واحدة)، و examples: (حتى 6 نتائج من سطر واحد) تصف الإدخالات التي تتحكم في تطبيق Desktop.

GitHub عمدًا غير في الكتالوج: يتطلب MCP المستضاف الخاص به أن يقدم كل عميل تطبيق OAuth خاصًا به (ويُرفض dynamic client registration العام)، كما أن مهارات Hermes المضمّنة github/* المضمّنة في Hermes التي تعتمد على CLI ‏gh تمثّل تكاملًا أكثر قدرة. وفي Desktop ، يؤدي ذكر GitHub بدلًا من ذلك إلى اقتراح المهارة github-auth عندما لا يكون gh مسجَّل الدخول بعد.
