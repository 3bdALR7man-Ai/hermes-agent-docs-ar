slime: إطار عمل للتدريب اللاحق لنماذج LLM لتوسيع التعلّم المعزز

slime هو إطار عمل للتدريب اللاحق لنماذج LLM من فريق THUDM بجامعة Tsinghua، ويشغّل GLM-4.5 وGLM-4.6 وGLM-4.7. يربط بين Megatron-LM للتدريب وSGLang لتوليد rollout بإنتاجية عالية.

متى تستخدم slime

اختر slime عندما تحتاج إلى:

  • تدريب أصلي بـ Megatron-LM مع استدلال بـ SGLang
  • سير عمل مخصص لتوليد البيانات مع مخازن بيانات (data buffers) مرنة
  • تدريب نماذج GLM أو Qwen3 أو DeepSeek V3 أو Llama 3
  • إطار عمل بحثي المستوى مدعوم إنتاجيًا (من Z.ai)

ضع البدائل في الاعتبار عندما:

  • تحتاج إلى ميزات استقرار بمستوى المؤسسات ← استخدم miles
  • تريد مرونة في تبديل الواجهة الخلفية (backend) ← استخدم verl
  • تحتاج إلى تجريدات (abstractions) أصلية لـ PyTorch ← استخدم torchforge

الميزات الرئيسية

  • التدريب: Megatron-LM مع دعم كامل للتوازي (TP وPP وDP وSP)
  • Rollout: توليد بإنتاجية عالية قائم على SGLang مع موجّه (router)
  • مخزن البيانات (Data Buffer): إدارة مرنة للمطالبات وتخزين العينات
  • النماذج: GLM-4.x، Qwen3، DeepSeek V3/R1، Llama 3
