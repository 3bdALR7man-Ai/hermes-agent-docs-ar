TensorRT-LLM

مكتبة NVIDIA مفتوحة المصدر لتحسين inference نماذج LLM بأداء عالٍ على معالجات NVIDIA GPU.

متى تستخدم TensorRT-LLM

استخدم TensorRT-LLM عندما:

  • تنشر على معالجات NVIDIA GPU (A100، H100، GB200)
  • تحتاج إلى أقصى إنتاجية (+24,000 token/ثانية على Llama 3)
  • تحتاج إلى زمن استجابة منخفض للتطبيقات الفورية (real-time)
  • تعمل مع نماذج مُكمَّمة (quantized) (FP8، INT4، FP4)
  • توسّع النطاق عبر عدة GPU أو عُقد

استخدم vLLM بدلًا من ذلك عندما:

  • تحتاج إلى إعداد أبسط و API يعتمد على Python بالدرجة الأولى
  • تريد PagedAttention دون الحاجة إلى تجميع TensorRT
  • تعمل مع معالجات AMD أو عتاد من غير NVIDIA

استخدم llama.cpp بدلًا من ذلك عندما:

  • تنشر على CPU أو Apple Silicon
  • تحتاج إلى نشر على الحافة (edge) بدون معالجات NVIDIA GPU
  • تريد صيغة تكميم GGUF الأبسط

الميزات الرئيسية

تحسينات الأداء

  • In-flight batching: تجميع ديناميكي أثناء التوليد
  • Paged KV cache: إدارة ذاكرة فعّالة
  • Flash Attention: نوى انتباه (attention kernels) مُحسَّنة
  • Quantization: FP8، INT4، FP4 لتسريع الـ inference بمقدار 2-4×
  • CUDA graphs: تقليل تكاليف إطلاق النوى (kernel launch overhead)

التوازي (Parallelism)

  • Tensor parallelism (TP): تقسيم النموذج عبر عدة GPU
  • Pipeline parallelism (PP): توزيع على مستوى الطبقات
  • Expert parallelism: لنماذج Mixture-of-Experts
  • Multi-node: التوسع إلى ما بعد جهاز واحد

ميزات متقدمة

  • Speculative decoding: توليد أسرع باستخدام نماذج مسودة (draft models)
  • LoRA serving: نشر فعّال لعدة محوّلات (adapters)
  • Disaggregated serving: فصل مرحلتَي prefill والتوليد

معايير الأداء (Benchmarks)

Meta Llama 3-8B (معالج H100):

  • الإنتاجية: 24,000 token/ثانية
  • زمن الاستجابة: نحو 10 مللي ثانية لكل token
  • مقارنة بـ PyTorch: أسرع بمقدار 100×

Llama 3-70B (8× A100 80GB):

  • تكميم FP8: أسرع بمقدار 2× من FP16
  • الذاكرة: انخفاض بنسبة 50% مع FP8

  • عائلة LLaMA: Llama 2، Llama 3، CodeLlama
  • عائلة GPT: GPT-2، GPT-J، GPT-NeoX
  • Qwen: Qwen، Qwen2، QwQ
  • DeepSeek: DeepSeek-V2، DeepSeek-V3
  • Mixtral: Mixtral-8x7B، Mixtral-8x22B
  • Vision: LLaVA، Phi-3-vision
