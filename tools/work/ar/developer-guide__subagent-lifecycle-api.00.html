API دورة حياة Subagent العامة

يمكن للإضافات إطلاق جلسات Hermes فرعية جديدة والإشراف عليها دون استيراد tools.delegate_tool، أو آليات gateway الداخلية، أو حالة TUI، أو حقول AIAgent. تحل الخدمة والد العملية من دور الوكيل الحالي، لذا تعمل في جلسات CLI، وgateway، وغير التفاعلية، وعامل kanban. إطلاق الخدمة خارج دور وكيل نشط يفشل بأمان (fail closed) برسالة No active Hermes parent session.

SubagentHandle قابل للتسلسل (serializable) ويحمل صلاحية مبهمة ذات إصدار. مرّره إلى status أو wait أو cancel أو result أو reconnect؛ أي مقبض مشوَّه أو مزوَّر يُعيد UNKNOWN/UNKNOWN_HANDLE ولا يمكنه الوصول إلى العملية الفرعية.

الحالات المستقرة هي PENDING، وSTARTING، وRUNNING، وSUCCEEDED، وFAILED، وINTERRUPTED، وCANCEL_REQUESTED، وCANCELLED، وUNKNOWN.

cancel(handle, reason=...) تعاونية بطبيعتها: تطلب من الوكيل الفرعي مقاطعة العمل عند أقرب نقطة آمنة له وتعيد CANCEL_REQUESTED؛ ولا تدّعي أبدًا الاكتمال حتى تلاحظ wait أو result حالة نهائية. النتائج النهائية غير قابلة للتغيير، ومتماثلة القوة (idempotent)، ومحدودة بـ 32 ألف حرف، وتحذف النصوص الكاملة والتفكير المخفي، وتتضمن تجزئة (hash) نتيجة مستقرة.

هذه الواجهة تنفيذ غير متزامن (asynchronous) مُدار بدورة حياة. يستخدم إنشاء العملية الفرعية وإكمالها نفس المسار المملوك للمضيف الذي يستخدمه delegate_task، بما في ذلك استعادة حل الأداة الخاص بالوالد، وإشعار الذاكرة، وhooks subagent_stop المُسلسَلة، وتنظيف الموارد، وتجميع تكلفة العملية الفرعية. وهي لا تغيّر أداة delegate_task المتزامنة، ولا التفويض الدفعي، ولا عرضها في gateway/TUI. يحتفظ التنفيذ الأولي بالبيانات الوصفية والنتائج النهائية داخل العملية لمدة ساعة واحدة. بعد إعادة تشغيل العملية، تعيد reconnect RECONNECT_UNAVAILABLE ولا تُطلق أبدًا عملية فرعية بديلة. كما لا يمكن لخيوط Python (threads) قيد التشغيل النجاة من خروج العملية؛ يجب على المستدعين معاملة تلك المقابض على أنها مقاطعة بسبب خروج العملية.

الطلبات تفشل بأمان (fail-closed): أحجام الهدف/السياق/البيانات الوصفية محدودة، وتُرفض مجموعات الأدوات (toolsets) غير المعروفة أو التي توسّع نطاق الوالد، وتُرفض صراحةً حظر الأدوات الفردية، وتجاوزات دليل العمل، ومهلات الإطلاق الفردية حتى يستطيع Hermes دعمها دون إضعاف العزل. استخدم allowed_toolsets لتضييق نطاق العملية الفرعية؛ ويظل حظر الأدوات غير الآمنة الموجود مسبقًا في Hermes مفروضًا.
