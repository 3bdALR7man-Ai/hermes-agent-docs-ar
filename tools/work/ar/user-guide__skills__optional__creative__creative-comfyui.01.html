قائمة تحقق التحقّق

استخدم python scripts/health_check.py لتشغيل القائمة كاملة دفعة واحدة. يدويًا:

  • نتيجة hardware_check.py هي ok أو اختار المستخدم Comfy Cloud صراحةً
  • يعمل comfy --version (أو uvx --from comfy-cli comfy --help)
  • يعيد curl http://HOST:PORT/system_stats JSON
  • يُظهر comfy model list نقطة تفتيش (checkpoint) واحدة على الأقل (محلي) أو يعيد /api/experiment/models/checkpoints نماذج (Cloud)
  • JSON الخاص بالـ workflow بصيغة API
  • يبلّغ check_deps.py عن is_ready: true (أو node_check_skipped فقط على الفئة المجانية من Cloud)
  • تكتمل تجربة تشغيل بـ workflow صغير؛ وتهبط النواتج في --output-dir
