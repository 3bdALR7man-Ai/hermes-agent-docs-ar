المزالق

  1. صيغة API مطلوبة — يتوقع كل سكربت وendpoint /api/prompt JSON بصيغة workflow بصيغة API. تكتشف السكربتات صيغة المحرِّر (مصفوفتا nodes وlinks على المستوى الأعلى) وتخبرك بإعادة التصدير عبر "Workflow → Export (API)" (الواجهة الأحدث) أو "Save (API Format)" (الواجهة الأقدم).

  2. يجب أن يكون الخادم قيد التشغيل — يتطلب كل تنفيذ خادمًا نشطًا. يشغّل comfy launch --background واحدًا. تحقق بـ curl http://127.0.0.1:8188/system_stats.

  3. أسماء النماذج دقيقة — حساسة لحالة الأحرف، وتشمل امتداد الملف. يقوم check_deps.py بمطابقة تقريبية (مع/بدون امتداد وبادئة دليل)، لكن يجب أن يستخدم الـ workflow نفسه الاسم الرسمي (canonical). استخدم comfy model list لاكتشاف ما هو مثبَّت.

  4. عُقد مخصّصة ناقصة — تعني رسالة "class_type not found" أن عقدة مطلوبة غير مثبَّتة. يبلّغ check_deps.py عن الحزمة الواجب تثبيتها؛ ويشغّل auto_fix_deps.py التثبيت نيابةً عنك.

  5. دليل العمل — تكتشف comfy-cli مساحة عمل ComfyUI تلقائيًا. إذا فشلت الأوامر برسالة "no workspace found"، استخدم comfy --workspace /path/to/ComfyUI <command> أو comfy set-default /path/to/ComfyUI.

  6. حدود API للفئة المجانية على Cloud — تعيد /api/prompt و/api/view و/api/upload/* و /api/object_info جميعها 403 على الحسابات المجانية. تتعامل health_check.py و check_deps.py مع ذلك بسلاسة وتُظهران رسالة واضحة.

  7. مهلة workflows الفيديو/الصوت — تُكتشف تلقائيًا عندما تكون عقدة الناتج VHS_VideoCombine أو SaveVideo، إلخ؛ تقفز القيمة الافتراضية من 300 ثانية إلى 900 ثانية. تجاوزها صراحةً بـ --timeout 1800.

  8. اجتياز المسارات (path traversal) في أسماء ملفات الناتج — تُمرَّر أسماء الملفات القادمة من الخادم عبر safe_path_join لرفض أي شيء يفلت من --output-dir. أبقِ هذه الحماية مفعّلة — قد تنتج workflows بعُقد حفظ مخصّصة مسارات عشوائية.

  9. JSON الخاص بـ workflow كود تنفيذي عشوائي — تشغّل العُقد المخصّصة بايثون، لذا فتقديم workflow مجهول له نفس مستوى الثقة الخاص بـ eval. افحص الـ workflows من مصادر غير موثوقة قبل تشغيلها.

  10. seed عشوائي تلقائي — مرّر seed: -1 في --args (أو استخدم --randomize-seed وأغفل الـ seed) للحصول على seed جديد لكل تشغيل. تُسجَّل قيمة الـ seed الفعلية إلى stderr.

  11. مطالبة tracking — قد يطلب أول تشغيل لـ comfy موافقة على التحليلات (analytics). استخدم comfy --skip-prompt tracking disable لتخطّيها بشكل غير تفاعلي. يقوم comfyui_setup.sh بذلك نيابةً عنك.

قائمة تحقق التحقّق

استخدم python scripts/health_check.py لتشغيل القائمة كاملة دفعة واحدة. يدويًا:

  • نتيجة hardware_check.py هي ok أو اختار المستخدم Comfy Cloud صراحةً
  • يعمل comfy --version (أو uvx --from comfy-cli comfy --help)
  • يعيد curl http://HOST:PORT/system_stats JSON
  • يُظهر comfy model list نقطة تفتيش (checkpoint) واحدة على الأقل (محلي) أو يعيد /api/experiment/models/checkpoints نماذج (Cloud)
  • JSON الخاص بالـ workflow بصيغة API
  • يبلّغ check_deps.py عن is_ready: true (أو node_check_skipped فقط على الفئة المجانية من Cloud)
  • تكتمل تجربة تشغيل بـ workflow صغير؛ وتهبط النواتج في --output-dir
