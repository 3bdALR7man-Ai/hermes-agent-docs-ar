دعم المنصات

يحافظ Hermes Agent على دعم العديد من المنصات وطرق التوزيع، لكن لا يمكننا دعم كل طريقة تثبيت ممكنة.

المستوى 1 (Tier 1)

نسعى جاهدين لعدم تعطيل عمليات التثبيت والتحديث على هذه المنصات أبدًا. تحظى المشكلات والتراجعات (regressions) في المستوى 1 بالأولوية القصوى لدينا، وتتقدم على المنصات الأخرى.

نظام التشغيل / المعماريةطرق التثبيتملاحظات
macOS (Apple Silicon)Hermes Desktop, install.sh
Windows 10 / 11 (x86_64, aarch64)install.ps1, تطبيق سطح المكتب بصيغة MSIXتتطلب حزمة MSIX إصدار Windows 11 22H2 أو أحدث. للاعتماديات الاختيارية قيود معمارية.
Linux / WSL2 (x86_64, aarch64)install.shنختبر على أحدث إصدار من Ubuntu وعلى WSL2. إذا كانت توزيعتك تتضمن glibc و systemd وتتبع معيار Filesystem Hierarchy Standard، فمن المرجح أن يعمل Hermes عليها بشكل جيد جدًا.
حاوية Docker (x86_64, aarch64)docker pullلا تدعم عمليات التثبيت عبر Docker الأمر hermes update. يتم التحديث بتشغيل صورة (image) جديدة.

المستوى 2 (Tier 2)

تُصان هذه المنصات ضمن شجرة الكود الرئيسية (in-tree) بأفضل جهد فقط. قد تتعطل مع الإصدارات الجديدة، ولا يمكننا أن نعد بإصلاحها سريعًا عند تعطلها.

نقبل طلبات pull request (PR) لإصلاح مشكلاتها، لكن أولويتها تأتي بعد إصلاح مشكلات منصات المستوى 1.

نظام التشغيل / المعماريةطرق التثبيتملاحظات
Nix (macOS, Linux, NixOS)Nix flake والوحداتيتولى Nix تثبيت وقت التشغيل وتحديثاته.
Android / Termux (aarch64)مستودع APT موقّع، ثم pkg install hermes-agentحزمة ما قبل الإصدار مع Python و Node و TUI. شغّل gateway في جلسة Termux؛ فقد ينهي Android العمليات التي تعمل في الخلفية.

أهداف البناء وأولوية الدعم

تتضمن pipeline الحِزم الأصلية Intel macOS (x64) وكذلك Apple Silicon. وتحدّد أيضًا قبول تحديثات الحزم الموقّعة لكلتا المعماريتين. لا تغيّر هذه التغطية أولوية المستوى 1 (Tier 1) الممنوحة لـ Apple Silicon. الاستثناء هو مُثبّت bootstrap Hermes-Setup.dmg: فهو مبني لـ Apple Silicon (arm64) فقط، لذا يُبلّغ على Intel Mac بالرسالة "not supported on this Mac". تستخدم أجهزة Intel Mac حزمة سطح المكتب darwin-x64 بدلًا منه، أو تثبّت CLI وتنفّذ hermes desktop. تغليف تطبيق سطح المكتب على Linux معطّل في سير عمل الإصدار، رغم وجود إصدارات AppImage محلية وفحوص حِزم PM الأصلية لـ Linux.

غير مدعومة

هذه المنصات وطرق التوزيع غير مدعومة. نقترح عليك الانتقال إلى طريقة توزيع أو منصة مدعومة. قد تكون معطّلة حاليًا، وقد يزداد تعطلها في المستقبل. لن تُقبل طلبات PR لإصلاحها، وقد يُزال في أي وقت أي كود يحافظ على التوافق معها.

  • Android / Termux على الأجهزة غير aarch64 (معمارية aarch64 مدعومة عبر حزمة APT الخاصة بنا)
  • التثبيت عبر AUR (قد نرفع التعديلات إلى المشروع الأصلي upstream إن كان ذلك يساعد <3)
  • macOS على x86 من 32 بت. توجد لـ Intel x86_64 مسارات قبول لبناء الحِزم الأصلية وتحديث الحزم؛ ولا يغيّر ذلك أولوية المستوى 1 (Tier 1) لـ Apple Silicon.
  • التثبيت عبر pypi (مثل uv tool install hermes-agent و pip install hermes-agent وغيرها)
  • التثبيت عبر brew (brew install hermes-agent)

إذا كنت تستخدم طريقة توزيع غير مدعومة، فيُرجى قراءة دليل التثبيت لمعرفة كيفية الانتقال إلى طريقة مدعومة.
