Scrapling

Scrapling إطار عمل لاستخلاص بيانات الويب يضم تجاوزًا لأنظمة مكافحة البوتات، وأتمتة متصفح خفية، وإطار زحف (spider). يوفر ثلاث استراتيجيات جلب (HTTP، وJS الديناميكي، والخفي/Cloudflare) وواجهة CLI كاملة.

هذه المهارة لأغراض تعليمية وبحثية فقط. يجب على المستخدمين الامتثال لقوانين استخلاص البيانات المحلية/الدولية واحترام شروط خدمة المواقع.

متى تُستخدم

  • استخلاص صفحات HTML الثابتة (أسرع من أدوات المتصفح)
  • استخلاص الصفحات المُصيَّرة بـ JS التي تحتاج إلى متصفح حقيقي
  • تجاوز Cloudflare Turnstile أو كشف البوتات
  • زحف عدة صفحات باستخدام spider
  • عندما لا تُعيد أداة web_extract المدمجة البيانات التي تحتاجها

مزالق

  • تثبيت المتصفح مطلوب: شغّل scrapling install بعد تثبيت pip — بدونه سيفشل DynamicFetcher وStealthyFetcher
  • المهلات الزمنية: مهلة DynamicFetcher/StealthyFetcher بـالميلي ثانية (الافتراضي 30000)، ومهلة Fetcher بـالثواني
  • تجاوز Cloudflare: solve_cloudflare=True يضيف 5-15 ثانية إلى زمن الجلب — لا تفعّله إلا عند الحاجة
  • استهلاك الموارد: يشغّل StealthyFetcher متصفحًا حقيقيًا — قيّد الاستخدام المتزامن
  • الجانب القانوني: تحقق دائمًا من robots.txt وشروط خدمة الموقع قبل الاستخلاص. هذه المكتبة لأغراض تعليمية وبحثية
  • إصدار Python: يتطلب Python 3.10 فأعلى
