حالة معالجة ملاحظات تدقيق PM

هذا سجل تدقيق تاريخي، لا صفحة حالة إصدار عند رأس الكود الحالي. تنطبق الأعداد وإثباتات التنفيذ الأصلية أدناه على الإصدارات المسماة فقط. يضيف العمل اللاحق تجميع الحزم المشترك واختبارات E2E للحزم الموقّعة وبوابة الإصدار المستقر وتوزيع Termux APT و Python 3.14. لا توسّع تلك التغييرات إثباتات الاختبارات السابقة بأثر رجعي.

للعقود التنفيذية الحالية، استخدم إدارة الحزم, بناء الحزم المشترك, الإصدارات المستقرة و قبول تحديث الحزم المضمّنة.

يدمج هذا التغيير إصلاحات من تدقيق branch التجميعي. وهو ليس شهادة إصدار. قارن التدقيق 49945b14029e09fef608db9ede899377cdb54e11 مع قاعدة الدمج 433f7196760e5d76f77ea6d5464ee7f1b602a4ee.

إصلاحات وقت التشغيل بعد تدقيق التوثيق

وجد التدقيق اختلافًا في تخطيط Python في Electron، وعائلة Python مثبتة في Nix، ومتطلبات cryptography متناقضة، وأخطاء في إعداد Windows نظيف. وتغيّر المتابعة التطبيقات المالكة:

  • يفحص منشئ الحزمة الحمولة المكتملة وينشر مسارات تشغيلها. يستهلك Electron ذلك العقد دون فحص الحمولة أو تبنّيها أو إنشائها.
  • يختار Nix الإصدارين الرئيسي/الفرعي لـ Python من pm/lock.json. تستخدم بيئة uv2nix وتجاوزات الحزم والحزم الإضافية و shell المطوّر تلك العائلة. يبقى قبول تقييم Nix وبنائه الحقيقيين بوابتين في CI.
  • يتطابق متطلب cryptography المباشر وتجاوز الأمان مع الإصدار المُرقّع في uv.lock. ما يزال التجاوز يتخطى السقف القديم لـ SDK المورّد.
  • ينتظر bootstrap اكتمال uv، ثم يشغّل PM عبر Python مباشرة. يمكن لـ PM استبدال إدخال uv الخاص به دون أن يحتفظ bootstrap بملفه التنفيذي.
  • يستخدم نشر إثباتات PM كتابة JSON ذرية عبر stdlib وحدها تحت قفل مشترك. لم يعد الإبلاغ عن الفشل يستورد PyYAML عبر utils.
  • أُزيل أمر shell التطوير غير المستخدم. الإعداد ثم التفعيل و deactivate هو مسار المطوّر الوحيد لـ PM.

بدأ فحص Windows أصلي بمخزن أدوات فارغ في home مؤقت. اكتمل الإعداد، ونشر PM جيل اعتماديات، وشغّل تفعيل PowerShell مفسّر المخزن و CLI المصدر. اجتاز تثبيت PM منفصل فحص اعتمادياته الحقيقي. لا تثبت هذه الفحوص تثبيت الحزم الموقّعة أو تحديثاتها أو بناء Nix. يبقى الترابط الأوسع بين PM وإضافات/إعدادات YAML دون تغيير. يميّز سير عمل المطوّر تفعيل وقت التشغيل عن بيئات الاختبار والمحرر المستقلة.
