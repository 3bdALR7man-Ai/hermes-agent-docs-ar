Find My (Apple)

تتبّع أجهزة Apple وأدوات AirTag عبر تطبيق FindMy.app على macOS. بما أن Apple لا توفّر واجهة سطر أوامر (CLI) لـ FindMy، تستخدم هذه المهارة AppleScript لفتح التطبيق والتقاط الشاشة لقراءة مواقع الأجهزة.

المتطلبات المسبقة

  • macOS مع تطبيق Find My وتسجيل الدخول إلى iCloud
  • أجهزة/أدوات AirTag مُسجّلة مسبقًا في Find My
  • صلاحية تسجيل الشاشة للطرفية (System Settings → Privacy → Screen Recording)
  • اختياري لكنه مُوصى به: ثبّت peekaboo لأتمتة أفضل لواجهة المستخدم: brew install steipete/tap/peekaboo

متى تُستخدم

  • عندما يسأل المستخدم "أين جهازي/قطتي/مفاتيحي/حقيبتي؟"
  • تتبّع مواقع أدوات AirTag
  • التحقّق من مواقع الأجهزة (iPhone، iPad، Mac، AirPods)
  • مراقبة تحرّك حيوان أليف أو غرض بمرور الوقت (مسارات تجوّل AirTag)

القيود

  • لا يملك FindMy أي واجهة سطر أوامر أو API — يجب استخدام أتمتة واجهة المستخدم
  • لا تُحدَّث مواقع أدوات AirTag إلا أثناء عرض صفحة FindMy فعليًا
  • تعتمد دقّة الموقع على أجهزة Apple القريبة ضمن شبكة FindMy
  • صلاحية تسجيل الشاشة مطلوبة لالتقاط لقطات الشاشة
  • قد تتعطّل أتمتة واجهة المستخدم عبر AppleScript بين إصدارات macOS المختلفة

القواعد

  1. أبقِ تطبيق FindMy في المقدمة أثناء تتبّع أدوات AirTag (تتوقّف التحديثات عند تصغيره)
  2. استخدم vision_analyze لقراءة محتوى لقطة الشاشة — لا تحاول تحليل البكسلات يدويًا
  3. للتتبّع المستمر، استخدم مهمة cron لالتقاط المواقع وتسجيلها دوريًا
  4. احترم الخصوصية — تتبّع فقط الأجهزة/الأغراض التي يملكها المستخدم
