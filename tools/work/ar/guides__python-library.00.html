استخدام Hermes كمكتبة Python

Hermes ليس مجرد أداة CLI، إذ يمكنك استيراد AIAgent مباشرةً واستخدامه برمجيًا في سكربتات Python الخاصة بك، أو تطبيقات الويب، أو pipelines الأتمتة. يوضّح لك هذا الدليل كيفية ذلك.

التثبيت

انسخ مستودع Hermes (clone) وأنشئ بيئة التطوير القابلة للتعديل (editable) المدعومة الخاصة به:

شغّل تطبيقك باستخدام uv run python your_app.py من داخل تلك النسخة المسحوبة (checkout). لا ينشر Hermes حزمة wheel أو توزيعة مصدرية (source distribution) مدعومة للتثبيت عبر requirements.txt.

نصيحة

متغيرات البيئة نفسها التي يستخدمها CLI مطلوبة أيضًا عند استخدام Hermes كمكتبة. اضبط على الأقل OPENROUTER_API_KEY (أو OPENAI_API_KEY / ANTHROPIC_API_KEY إذا كنت تستخدم الوصول المباشر إلى المزوّد).

تحذير

اضبط دائمًا quiet_mode=True عند تضمين Hermes في الكود الخاص بك. فمن دونه، يطبع الوكيل مؤشرات الدوران (spinners) الخاصة بـ CLI، ومؤشرات التقدّم، وغيرها من مخرجات الطرفية التي ستُربك مخرجات تطبيقك.

التحكم الكامل في المحادثة

لمزيد من التحكم في المحادثة، استخدم run_conversation() مباشرةً. يُعيد هذا التابع قاموسًا (dictionary) يحتوي على الرد الكامل، وسجل الرسائل، والبيانات الوصفية:

يحتوي القاموس المُعاد على:

  • final_response — الرد النصي النهائي للوكيل
  • messages — سجل الرسائل الكامل (system، و user، و assistant، واستدعاءات الأدوات)

(يُخزَّن task_id الذي تمرّره في نسخة الوكيل لأغراض عزل VM، لكنه لا يُعاد ضمن القاموس المُعاد.)

استخدم ephemeral_system_prompt لضبط system prompt مخصص يوجّه سلوك الوكيل لكنه لا يُحفظ في ملفات الـ trajectory (ما يُبقي بيانات التدريب لديك نظيفة):

هذا مثالي لبناء وكلاء متخصصين — مراجع كود، أو كاتب توثيق، أو مساعد SQL — يستخدمون جميعًا الأدوات الأساسية نفسها.

ملاحظات مهمة

نصيحة
  • اضبط skip_context_files=True إذا كنت لا تريد تحميل ملفات AGENTS.md الموجودة في مجلد العمل ضمن system prompt.
  • اضبط skip_memory=True لمنع الوكيل من القراءة من الذاكرة الدائمة أو الكتابة إليها — وهو موصى به لـ API endpoints عديمة الحالة (stateless).
  • يحقن المعامل platform (مثل "discord"، "telegram") تلميحات تنسيق خاصة بالمنصة، ليُكيّف الوكيل أسلوب مخرجاته وفقًا لها.
تحذير
  • الأمان مع تعدد الـ threads: أنشئ نسخة واحدة من AIAgent لكل thread أو مهمة، ولا تشارك أي نسخة أبدًا بين استدعاءات متزامنة.
  • تنظيف الموارد: ينظّف الوكيل الموارد تلقائيًا (جلسات الطرفية، ونُسخ المتصفح) عند انتهاء المحادثة. إذا كنت تعمل ضمن عملية طويلة الأمد، فتأكد من أن كل محادثة تكتمل بشكل طبيعي.
  • حدود التكرار: القيمة الافتراضية max_iterations=500 سخية. في حالات الاستخدام البسيطة القائمة على السؤال والجواب، فكّر في خفضها (مثل max_iterations=10) لمنع حلقات استدعاء الأدوات الخارجة عن السيطرة وللتحكم في التكاليف.
