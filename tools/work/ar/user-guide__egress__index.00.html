Egress proxy

جدار حماية اختياري للاتصالات الصادرة يحقن بيانات الاعتماد، مخصّص لـ sandboxes الطرفية البعيدة. لا تحمل الـ sandbox سوى proxy tokens معتمة لا تكشف شيئًا؛ أما مفاتيح API الحقيقية فلا تغادر الجهاز المضيف أبدًا.

  • iron-proxy — proxy يعترض اتصالات TLS في ملف تنفيذي واحد من ironsh/iron-proxy، يُثبَّت عند الحاجة ويُدار عبر hermes egress.
