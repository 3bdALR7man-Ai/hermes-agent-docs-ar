Polymarket — بيانات أسواق التنبؤ

استعلم عن بيانات أسواق التنبؤ من Polymarket باستخدام واجهات REST API العامة الخاصة بها. جميع نقاط النهاية للقراءة فقط ولا تتطلب أي مصادقة.

راجع references/api-endpoints.md للمرجع الكامل لنقاط النهاية مع أمثلة curl.

متى تُستخدم

  • يسأل المستخدم عن أسواق التنبؤ، أو احتمالات الرهان، أو احتمالات الأحداث
  • يريد المستخدم معرفة "ما احتمالات حدوث X؟"
  • يسأل المستخدم عن Polymarket تحديدًا
  • يريد المستخدم أسعار السوق، أو بيانات دفتر الأوامر، أو سجل الأسعار
  • يطلب المستخدم مراقبة أو تتبّع تحركات أسواق التنبؤ

المفاهيم الأساسية

  • تحتوي الأحداث (Events) على سوق واحد أو أكثر من الأسواق (Markets) (علاقة واحد إلى متعدد)
  • الأسواق نتائج ثنائية بأسعار Yes/No بين 0.00 و1.00
  • الأسعار هي احتمالات فعليًا: السعر 0.65 يعني أن السوق يرى احتمال 65%
  • حقل outcomePrices: مصفوفة مُرمَّزة بصيغة JSON مثل ["0.80", "0.20"]
  • حقل clobTokenIds: مصفوفة مُرمَّزة بصيغة JSON لمعرّفَي توكن [Yes, No] لاستعلامات السعر/الدفتر
  • حقل conditionId: سلسلة سداسية عشرية تُستخدم في استعلامات سجل الأسعار
  • الحجم بعملة USDC (دولار أمريكي)

ثلاث واجهات API عامة

  1. Gamma API على gamma-api.polymarket.com — الاكتشاف، البحث، التصفّح
  2. CLOB API على clob.polymarket.com — الأسعار الفورية، دفاتر الأوامر، السجل التاريخي
  3. Data API على data-api.polymarket.com — الصفقات، الفائدة المفتوحة (open interest)

سير العمل النموذجي

عندما يسأل المستخدم عن احتمالات سوق التنبؤ:

  1. ابحث باستخدام نقطة نهاية البحث العام في Gamma API مع استعلامه
  2. حلّل الاستجابة — استخرج الأحداث وأسواقها المتداخلة
  3. اعرض سؤال السوق، والأسعار الحالية كنسب مئوية، والحجم
  4. تعمّق إذا طُلب منك ذلك — استخدم clobTokenIds لدفتر الأوامر، وconditionId للسجل التاريخي

عرض النتائج

نسّق الأسعار كنسب مئوية لسهولة القراءة:

  • outcomePrices ["0.652", "0.348"] تصبح "Yes: 65.2%, No: 34.8%"
  • اعرض دائمًا سؤال السوق والاحتمال
  • أدرِج الحجم عند توفره

مثال: "Will X happen?" — 65.2% Yes ($1.2M volume)

تحليل الحقول المُرمَّزة مرتين

تُعيد Gamma API الحقول outcomePrices وoutcomes وclobTokenIds كسلاسل JSON داخل استجابات JSON (ترميز مزدوج). عند المعالجة باستخدام Python، حلّلها باستخدام json.loads(market['outcomePrices']) للحصول على المصفوفة الفعلية.

حدود المعدل (Rate Limits)

سخيّة — من غير المرجح بلوغها في الاستخدام العادي:

  • Gamma: 4,000 طلب لكل 10 ثوانٍ (عام)
  • CLOB: 9,000 طلب لكل 10 ثوانٍ (عام)
  • Data: 1,000 طلب لكل 10 ثوانٍ (عام)

القيود

  • هذه المهارة للقراءة فقط — لا تدعم تنفيذ الصفقات
  • يتطلّب التداول مصادقة عبر محفظة عملات رقمية (توقيعات EIP-712)
  • قد يكون لبعض الأسواق الجديدة سجل أسعار فارغ
  • تنطبق القيود الجغرافية على التداول، لكن بيانات القراءة فقط متاحة عالميًا
