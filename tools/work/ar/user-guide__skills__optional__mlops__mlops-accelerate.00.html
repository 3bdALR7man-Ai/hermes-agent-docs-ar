متى تستخدمه مقابل البدائل

استخدم Accelerate عندما:

  • تريد أبسط تدريب موزّع
  • تحتاج سكربتًا واحدًا يعمل على أي عتاد
  • تستخدم منظومة HuggingFace
  • تريد المرونة (DDP/DeepSpeed/FSDP/Megatron)
  • تحتاج نموذجًا أوليًا سريعًا

المزايا الرئيسية:

  • 4 أسطر: أقل قدر من تغييرات الكود
  • واجهة برمجية موحّدة (Unified API): نفس الكود لـ DDP وDeepSpeed وFSDP وMegatron
  • تلقائي: توزيع الأجهزة، الدقة المختلطة، التجزئة (sharding)
  • إعداد تفاعلي: بلا إعداد يدوي للمُشغِّل (launcher)
  • تشغيل موحّد: يعمل في كل مكان

استخدم البدائل بدلًا من ذلك:

  • PyTorch Lightning: عند الحاجة إلى callbacks وتجريدات عالية المستوى
  • Ray Train: تنسيق متعدد العقد (multi-node)، وضبط المعاملات الفائقة (hyperparameter tuning)
  • DeepSpeed: التحكم المباشر بالواجهة البرمجية، والميزات المتقدمة
  • DDP الخام: أقصى تحكم، وأقل تجريد

متطلبات العتاد

  • CPU: يعمل (ببطء)
  • GPU واحدة: يعمل
  • عدة GPU: DDP (الافتراضي)، أو DeepSpeed، أو FSDP
  • عدة عقد (multi-node): DDP، DeepSpeed، FSDP، Megatron
  • TPU: مدعوم
  • Apple MPS: مدعوم

متطلبات المُشغِّل (launcher):

  • DDP: torch.distributed.run (مدمج)
  • DeepSpeed: deepspeed (pip install deepspeed)
  • FSDP: PyTorch 1.12+ (مدمج)
  • Megatron: إعداد مخصّص
