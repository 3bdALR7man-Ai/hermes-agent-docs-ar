حزم اللغات

يتضمن Hermes 17 لغة للواجهة (display.language). القائمة قابلة للتوسعة: حزمة اللغة إضافة أو مجلد داخل مجلد Hermes الرئيسي يضيف لغة جديدة أو يتجاوز صياغة لغة موجودة — لجانب Python (prompts موافقة CLI وردود gateway وأفعال الأدوات والنصائح)، وواجهة hermes --tui وتطبيق Desktop، جميعها من حزمة واحدة.

ما تترجمه الحزمة هو نص الواجهة الثابت. تبقى ردود الوكيل وخرج الأدوات والسجلات و أسماء slash commands كما هي؛ لجعل الوكيل نفسه يجيب بلغة أخرى، اطلب ذلك في الـ prompt.

مصادر اللغات

عندما يبحث Hermes عن نص، يمر بهذه الطبقات من الأعلى إلى الأسفل ويأخذ أول تطابق:

  1. حزم اللغات في الإضافات — كل إضافة مثبّتة تصرّح بـ provides_locales (تكون الأولوية لآخر حزمة محمَّلة عندما تغطي حزمتان المفتاح نفسه).
  2. overlay الخاص بك — <HERMES_HOME>/locales/<lang>.yaml (لكل profile: يمتلك المجلد الرئيسي لكل profile مجلد locales/ الخاص به).
  3. المضمّنة — ملفات locales/<lang>.yaml المضمّنة مع Hermes.
  4. الطبقات الثلاث نفسها للإنجليزية، ثم المفتاح الخام.

يمكن أن تكون كل طبقة جزئية: لا تحتاج الحزمة أو overlay إلا إلى المفاتيح التي تغيّرها.

hermes config set display.language <id> يقبل أي معرّف توفّره إحدى هذه الطبقات. تُرفض المعرّفات المجهولة مع قائمة اللغات المتاحة:

استخدام حزمة

أعد تشغيل gateways وواجهات TUI الجارية كي تلتقط الحزمة. تسرد محدّدات اللغات في TUI و Desktop اللغات المضمّنة ولغات overlay الخاص بك وكل حزمة مثبّتة باسمها في لغتها الأصلية. يظل إدخال HERMES_LANGUAGE في .env يتجاوز display.language.

كتابة حزمة

لا تحتاج الحزمة إلى أي كود Python. أبسط بنية:

plugin.yaml:

provides_locales يمكن أن تكون أيضًا معرّفات بسيطة (- pl)؛ ويكون الاسم الأصلي افتراضيًا هو المعرّف عندئذٍ. عندما يصرّح manifest بـ provides_locales، يسجّل محمّل الإضافات كل locales/<lang>[.tui|.desktop].yaml تلقائيًا.

الملفات والمفاتيح

  • pl.yaml (الأساسي) يعكس بنية locales/en.yaml المضمّن. تُحوَّل YAML المتداخلة إلى مفاتيح منقّطة (approval.denied, gateway.goal_cleared). انسخ en.yaml، وترجم القيم، واحذف ما لا تريد تجاوزه.
  • pl.tui.yaml / pl.desktop.yaml يعكسان الكتالوجين الإنجليزيين لتطبيقَي TUI و Desktop. تُصدَّر مجموعتا المفاتيح إلى locales/_keys.tui.json و locales/_keys.desktop.json في مستودع Hermes، ويتحقق المدقق بمقارنتهما.
  • يجب أن تكون قيم YAML نصوصًا. يُرفض الرقم أو القائمة أو true/false أو القيمة الفارغة.
  • لا تستخدم أبدًا كلمات YAML المحجوزة (on, off, yes, no) كمفاتيح.

العناصر النائبة

  • تستخدم نصوص الجانب الأساسي (Python) عناصر نائبة مسمّاة كما في الإنجليزية تمامًا: "⏳ Draining {count} active agent(s)...". احتفظ بكل {name} في القيمة الإنجليزية؛ يجعل العنصر النائب المفقود أو المكتوب خطأ Hermes يعود إلى النص غير المترجم لذلك المفتاح.
  • تُكتب إدخالات TUI و Desktop التي تكون قيمتها الإنجليزية دالة (تأخذ معاملات) في YAML كسلاسل تحتوي على عناصر نائبة موضعية: "{0} of {1} sessions".

التحقق

يتحقق المدقق من أن لكل معرّف مصرّح به ملف locales/<id>.yaml، وأن كل ملف يُحلَّل ولا يتضمن إلا نصوصًا (القيمة غير النصية خطأ)، كما يحذّر — مع سرد المفاتيح — من المفاتيح غير الموجودة في الكتالوج الإنجليزي لتلك الواجهة (لا تسبب ضررًا لكنها لا تفعل شيئًا). تُجرى فحوص .tui.yaml / .desktop.yaml عندما يوجد تصدير _keys.*.json المناظر.

التسجيل من Python (اختياري)

يمكن لإضافة تحتوي بالفعل على كود Python تسجيل الكتالوجات بنفسها:

register_locale(lang, source, *, endonym=None, rtl=False, surface="core") يأخذ مسار YAML أو mapping؛ وتكون قيمة surface هي core, tui أو desktop. يُلغى التسجيل عند إلغاء تحميل الإضافة ولا يغيّر display.language.

تجاوزات شخصية دون إضافة

ضع ملفًا جزئيًا في مجلد Hermes الرئيسي:

ينطبق overlay على ذلك الـ profile فقط (~/.hermes/profiles/<name>/locales/ لـ profile مسمّى). تجعل ملفات overlay للغة لا يضمّنها Hermes تلك اللغة قابلة للاختيار أيضًا. تُقرأ التعديلات عند البدء التالي أو تغيير display.language التالي.

استكشاف الأخطاء وإصلاحها

  • Unknown language ... for display.language — الحزمة غير مثبّتة أو غير مفعّلة (hermes plugins list)، أو لا يطابق المعرّف في provides_locales اسم الملف (pl يحتاج إلى locales/pl.yaml).
  • نص مترجم ما زال يظهر بالإنجليزية — المفتاح غير موجود في الكتالوج الإنجليزي (شغّل hermes plugins validate؛ تُسرد المفاتيح المجهولة)، أو تختلف مجموعة العناصر النائبة عن الإنجليزية.
  • اللغة مدرجة لكن TUI/Desktop لا يزال بالإنجليزية — لا تحتوي الحزمة على .tui.yaml / .desktop.yaml؛ تعرض تلك الواجهات الإنجليزية مع ما توفّره الحزمة. للغات المضمّنة البالغ عددها 16، يضمّن TUI ملفات locales/<lang>.tui.yaml الخاصة به في شجرة Hermes (ويضمّن Desktop ترجماته داخل التطبيق)، لذا لا تحتاج حزمة لإحدى تلك اللغات إلا إلى المفاتيح التي تريد تجاوزها.
