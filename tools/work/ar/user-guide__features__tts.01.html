تفريغ الرسائل الصوتية نصيًا (STT)

تُفرَّغ الرسائل الصوتية المُرسَلة على Telegram أو Discord أو WhatsApp أو Slack أو Signal نصيًا بشكل تلقائي، ويُدرَج النص في المحادثة. ويرى الوكيل النص المُفرَّغ كأي نص عادي.

دون أي إعدادات

يعمل التفريغ المحلي مباشرةً دون إعداد إضافي عند تثبيت faster-whisper. وإذا لم يكن متاحًا، يمكن لـ Hermes أيضًا استخدام أداة CLI محلية باسم whisper من مواقع التثبيت الشائعة (مثل /opt/homebrew/bin) أو أمر مخصّص عبر HERMES_LOCAL_STT_COMMAND.

الإعدادات

تفاصيل المزوّدين

Local (faster-whisper) — يشغّل Whisper محليًا عبر faster-whisper. يستخدم CPU افتراضيًا، و GPU إن كان متاحًا. أحجام النماذج:

النموذجالحجمالسرعةالجودة
tiny~75 MBالأسرعأساسية
base~150 MBسريعجيدة (الافتراضي)
small~500 MBمتوسطأفضل
medium~1.5 GBأبطأعالية جدًا
large-v3~3 GBالأبطأالأفضل

Groq API — يتطلب GROQ_API_KEY. خيار سحابي احتياطي جيد عندما تريد خدمة STT مستضافة مجانية. اضبط stt.groq.language (أو متغير البيئة العام HERMES_LOCAL_STT_LANGUAGE) لتجاوز الاكتشاف التلقائي للغة في Whisper وتقليل زمن الاستجابة عندما تكون لغة الصوت معروفة.

OpenAI API — يقبل VOICE_TOOLS_OPENAI_KEY أولًا، ثم يعود إلى OPENAI_API_KEY احتياطيًا. ويدعم whisper-1 و gpt-4o-mini-transcribe و gpt-4o-transcribe و gpt-transcribe.

Mistral API (Voxtral Transcribe) — يتطلب MISTRAL_API_KEY. يستخدم نماذج Voxtral Transcribe من Mistral. ويدعم 13 لغة، وتمييز المتحدثين (speaker diarization)، والطوابع الزمنية على مستوى الكلمة. ثبّته باستخدام cd ~/.hermes/hermes-agent && uv pip install -e ".[mistral]".

xAI Grok STT — يتطلب XAI_API_KEY. يُرسل الطلبات إلى https://api.x.ai/v1/stt بصيغة multipart/form-data. وهو خيار جيد إذا كنت تستخدم xAI بالفعل للمحادثة أو TTS وتريد مفتاح API واحدًا لكل شيء. يأتي بعد Groq في ترتيب الاكتشاف التلقائي — لذا اضبط stt.provider: xai صراحةً لفرض استخدامه.

أمر CLI محلي مخصّص كخيار احتياطي — اضبط HERMES_LOCAL_STT_COMMAND إذا أردت أن يستدعي Hermes أمر تفريغ محليًا مباشرةً. يدعم قالب الأمر العناصر النائبة {input_path} و {output_dir} و {language} و {model}. يقسّم Hermes القالب بعد تعبئته إلى قائمة وسائط وينفّذه دون shell، لذا تُمرَّر العوامل مثل | و > و && و ; كوسائط حرفية. ويجب أن يكتب أمرك ملف تفريغ .txt في مكانٍ ما داخل {output_dir}.

السلوك الاحتياطي (Fallback)

يُلتزَم بدقة بالاختيار الصريح للمزوّد عبر stt.provider (المكتوب في config.yaml، مثلًا عبر hermes tools) — فإذا تعذّر تشغيل ذلك المزوّد، يفشل التفريغ برسالة خطأ واضحة (stt is configured to use <provider> (set via hermes tools), but <failure>. Run 'hermes tools' to change it.) بدلًا من التبديل بصمت إلى محرّك آخر. لاحظ أن كتابة stt.provider: local في إعداداتك تُعدّ اختيارًا صريحًا.

عندما لا يكون أي مزوّد قد اختير من قبل، يكتشف Hermes تلقائيًا ما هو متاح:

  • Local faster-whisper غير متاح → يجرّب أداة CLI محلية باسم whisper أو HERMES_LOCAL_STT_COMMAND قبل المزوّدين السحابيين
  • مفتاح Groq غير مضبوط → يُتجاوَز؛ وينتقل إلى المزوّد المتاح التالي
  • مفتاح OpenAI غير مضبوط → يُتجاوَز؛ وينتقل إلى المزوّد المتاح التالي
  • مفتاح Mistral أو الـ SDK غير مضبوط → يُتجاوَز في الاكتشاف التلقائي؛ وينتقل إلى المزوّد المتاح التالي
  • لا شيء متاح → تمرّ الرسائل الصوتية كما هي مع ملاحظة دقيقة للمستخدم

مزوّدو STT القائمون على أوامر مخصّصة

إذا لم يكن محرّك STT الذي تريده مدعومًا بشكل أصلي (Doubao ASR، أو NVIDIA Parakeet، أو نسخة مبنية من whisper.cpp، أو أداة CLI مفتوحة المصدر لـ SenseVoice، أو أي شيء آخر يوفّر أمر shell)، فاربطه بوصفه مزوّدًا من نوع command دون كتابة أي كود Python. يشغّل Hermes أمر الـ shell الخاص بك على الملف الصوتي، ثم يقرأ النص المُفرَّغ.

عرّف مزوّدًا واحدًا أو أكثر تحت stt.providers.<name> وبدّل بينها باستخدام stt.provider: <name> — بالبنية نفسها المستخدمة في سجل مزوّدي الأوامر الخاص بـ TTS، مع تكييفها لاتجاه الإدخال=صوت → الإخراج=نص مُفرَّغ.

يُكمّل هذا منفذ الطوارئ القديم HERMES_LOCAL_STT_COMMAND المتاح عبر المسار المدمج local_command. وعلى عكس سجل مزوّدي الأوامر المعتمد على الـ shell، يُقسَّم القالب القديم إلى argv ويعمل دون تفسير ضمني من الـ shell. استخدم stt.providers.<name> عندما تريد عدة محرّكات STT معتمدة على الـ shell، أو اسمًا يمكنك اختياره عبر stt.provider، أو أي شيء يحتاج إلى language / model / timeout خاصة بكل مزوّد.

العناصر النائبة في STT

يمكن لقالب الأمر الخاص بك الإشارة إلى العناصر النائبة التالية. يستبدلها Hermes وقت التعبئة، ويُطبّق على كل قيمة اقتباس الـ shell المناسب للسياق المحيط بها (دون اقتباس / داخل علامات اقتباس مفردة / داخل علامات اقتباس مزدوجة)، لذا فالمسارات التي تحتوي على مسافات آمنة.

العنصر النائبالمعنى
{input_path}المسار المطلق لملف الصوت المُدخَل (موقعه الأصلي، للقراءة فقط)
{output_path}المسار المطلق الذي يجب أن يكتب الأمر النص المُفرَّغ إليه
{output_dir}المجلد الأب لـ {output_path} (مفيد للأدوات المشابهة لـ whisper)
{format}صيغة الإخراج المُعدّة: txt / json / srt / vtt
{language}رمز اللغة المُعدّ (القيمة الافتراضية en)
{model}stt.providers.<name>.model، ويكون فارغًا إن لم يُضبط

استخدم {{ و }} للأقواس المعقوفة الحرفية (مفيد عند تضمين مقتطفات JSON في الأمر).

كيف يُقرأ النص المُفرَّغ

بعد أن ينتهي أمرك بنجاح:

  1. إذا كان {output_path} موجودًا وغير فارغ → يقرأه Hermes كنص UTF-8.
  2. وإلا، إذا كتب الأمر إلى stdout → يستخدم Hermes ذلك الناتج.
  3. وإلا → خطأ: "Command STT provider wrote no output file and produced no stdout".

يتيح لك هذا استخدام السجل مع أدوات CLI التي تكتب ملفات (whisper-cli، parakeet-asr) ومع الأوامر ذات السطر الواحد على طريقة curl التي تُخرج النص المُفرَّغ إلى stdout (curl … | jq -r .text).

مع format: json / srt / vtt، يُعيد Hermes محتوى الملف الخام في الحقل transcript. واستخراج .text من JSON خارج نطاق المُشغّل — فإما أن تضبط format: txt، أو تعالج JSON لاحقًا في مرحلة تالية.

ملاحظات حول سلوك مزوّدي أوامر STT

  • المزوّدون المدمجون لهم الأولوية دائمًا. تعريف stt.providers.openai: type: command لا يتجاوز معالج OpenAI Whisper الحقيقي. إذ يُحسم الاسم المدمج مبكرًا قبل تشغيل آلية تحديد مزوّدي الأوامر.
  • تنظيف شجرة العمليات. عندما يتجاوز أمرٌ مدة timeout، تُنهى شجرة عملياته بالكامل، لا الـ shell wrapper وحده. لذا تُحصَد بشكل موثوق خطوط ASR طويلة التشغيل التي تُنشئ عمليات فرعية لتحميل النماذج.
  • اقتباس الـ shell تلقائي. العناصر النائبة داخل '…' تحصل على تهريب آمن لعلامات الاقتباس المفردة؛ وداخل "…" تحصل على تهريب لـ $/`/"؛ وخارج علامات الاقتباس تُعالَج بـ shlex.quote. لا تضع علامات اقتباس مسبقًا حول قيم العناصر النائبة.

أمان مزوّدي أوامر STT

يعمل أمر الـ shell بصلاحيات المستخدم نفسه الذي يشغّل Hermes مع وصول كامل إلى نظام الملفات — وهو نموذج الثقة نفسه المتّبع في tts.providers.<name>: type: command و HERMES_LOCAL_STT_COMMAND. لا تعرّف مزوّدي أوامر إلا من مصادر تثق بها.

مزوّدو الإضافات بلغة Python (STT)

لمحرّكات STT غير المدمجة والتي لا يمكن التعبير عنها كأمر shell (لأنها تحتاج إلى Python SDK، أو مصادقة مع تحديث OAuth، أو مقاطع متدفقة، وما إلى ذلك)، سجّل إضافة Python عبر ctx.register_transcription_provider(). تعمل الإضافة جنبًا إلى جنب مع المزوّدين المدمجين الثمانية (local، local_command، groq، openai، mistral، xai، elevenlabs، deepinfra) ومع سجل stt.providers.<name>: type: command — إذ يحتفظ المزوّدون المدمجون بتطبيقاتهم الأصلية ولهم الأولوية دائمًا عند تعارض الأسماء؛ ولمزوّدي الأوامر الأولوية على الإضافات التي تحمل الاسم نفسه (لأن الإعدادات أقرب محليًا من تثبيت الإضافة).

ترتيب التحديد

  1. stt.provider اسم مزوّد مدمج → توجيه إلى المزوّد المدمج. له الأولوية دائمًا.
  2. stt.provider يطابق stt.providers.<name> مع ضبط command: → مُشغّل مزوّد الأوامر (راجع مزوّدو STT القائمون على أوامر مخصّصة). وله الأولوية على إضافة تحمل الاسم نفسه.
  3. stt.provider يطابق TranscriptionProvider مسجّلًا عبر إضافة → توجيه إلى الإضافة:
    • إذا أعادت الدالة is_available() الخاصة بالإضافة القيمة False (بسبب نقص بيانات الاعتماد أو الـ SDK)، يُظهر الاستدعاء رسالة خطأ بعدم التوفر تحدّد الإضافة المعنية — وليس الرسالة العامة "No STT provider available".
    • وإلا، تُستدعى الدالة transcribe() الخاصة بالإضافة مع model (من الوسيط العام model=، مع الرجوع احتياطيًا إلى stt.<provider>.model) و language (من stt.<provider>.language).
  4. لا يوجد تطابق → خطأ "No STT provider available".

Hooks اختيارية

أعِد تعريف ما يلي في صنف المزوّد الخاص بك للحصول على تكامل أغنى:

  • list_models() → قائمة من القواميس بالشكل {id, display, languages, max_audio_seconds}.
  • default_model() → سلسلة نصية تُعاد عندما لا يحدّد المستخدم نموذجًا آخر.
  • get_setup_schema() → أعِد {name, badge, tag, env_vars: [{key, prompt, url}]} لتغذية صفوف أداة الاختيار في hermes tools / hermes setup (فئة أداة الاختيار الخاصة بـ STT لم تُطرح بعد — وهذه البيانات الوصفية متاحة للإضافات من أجل التوافق المستقبلي).

راجع agent/transcription_provider.py للاطلاع على الصنف المجرّد (ABC) الكامل مع docstrings.
