Nous Portal

Nous Portal هو gateway الاشتراك الموحّد من Nous Research، والطريقة الموصى بها لتشغيل Hermes Agent. فتسجيل دخول واحد عبر OAuth يُغنيك عن التنقّل بين حسابات منفصلة ومفاتيح API وعلاقات فوترة متعددة مع كل مختبر نماذج، وواجهة API للبحث، ومولّد صور، ومزوّد متصفح كنت ستحتاج إلى ربطه يدويًا لولا ذلك.

إذا لم يكن لديك وقت إلا لإعداد شيء واحد، فأعِدّ هذا. أسرع طريق:

يشغّل هذا الأمر الواحد مصادقة OAuth الخاصة بـ Portal، ويتيح لك اختيار نموذج من Nous، ويضبط Nous كمزوّد inference في config.yaml، ويفعّل Tool Gateway. وبعدها تكون جاهزًا مباشرة لتشغيل hermes chat.

ألا تملك اشتراكًا بعد؟ توجّه إلى portal.nousresearch.com/manage-subscription — سجّل، ثم عُد ونفّذ الأمر أعلاه.

في الخلفية، يوجّه Portal كل نموذج إلى الـ backend الأنسب له — فبعض النماذج تمرّ عبر OpenRouter، وأخرى عبر مزوّدين خاصين أو ثانويين، وقد يتغيّر التوجيه الخاص بنموذج معيّن مع مرور الوقت. وفي كل الأحوال تُحتسب التكلفة كلها على اشتراكك في Nous. يمكنك التبديل بين Claude Sonnet 4.6 للبرمجة و Gemini 3 Pro للسياقات الطويلة باستخدام /model في منتصف الجلسة — دون بيانات اعتماد جديدة، ودون شحن رصيد، ودون أخطاء مفاجئة بسبب نفاد الرصيد.

ملاحظة

بما أن التوجيه يتم لكل نموذج على حدة ولا يمرّ دائمًا عبر OpenRouter، فإن امتدادات الطلبات الخاصة بـ OpenRouter (مثل تفضيلات التوجيه provider، أو التوجيه الثابت عبر session_id، أو cache_control على المستوى الأعلى) ليست جزءًا من عقد API الخاص بـ Portal، وقد تُتجاهل بحسب الـ backend الذي يخدم النموذج.

Nous Tool Gateway

يفتح الاشتراك نفسه الوصول إلى Tool Gateway، الذي يوجّه استدعاءات الأدوات في Hermes Agent عبر بنية تحتية تديرها Nous. خمسة backends بتسجيل دخول واحد:

بدون الـ gateway، يعني ربط كل واحدة من هذه الأدوات إنشاء حساب Firecrawl، وحساب FAL، وحساب Browser Use، ومفتاح OpenAI، وحساب Modal — خمس عمليات تسجيل منفصلة، وخمس لوحات تحكم منفصلة، وخمس آليات منفصلة لشحن الرصيد. أما مع الـ gateway، فيمرّ كل ذلك عبر اشتراك واحد.

يمكنك أيضًا تفعيل أدوات معيّنة فقط من الـ gateway (مثل البحث في الويب دون توليد الصور) — راجع دمج الـ gateway مع backends الخاصة بك أدناه.

لا بيانات اعتماد في ملفات dotfiles لديك

بما أن كل شيء يمرّ عبر جلسة Portal واحدة مُصادَق عليها عبر OAuth، فلن يتراكم لديك ملف .env يحتوي على عشرات مفاتيح API طويلة الأمد. فالـ refresh token الموجود في ~/.hermes/auth.json هو بيانات الاعتماد الوحيدة المخزّنة على القرص، ويولّد Hermes منه JWTs قصيرة الأمد لكل طلب — راجع التعامل مع الـ token أدناه.

تجربة متكافئة عبر المنصات

في Windows الأصلي يُعدّ إعداد مفاتيح API لكل أداة الجانب الأكثر صعوبة — فإنشاء حساب Firecrawl وحساب FAL وحساب Browser Use ومفتاح OpenAI من Windows هو أكثر أجزاء تجهيز وكيل مفيد إرهاقًا. ويسهّل اشتراك Portal ذلك: فمصادقة OAuth واحدة تغطي النموذج وكل أدوات الـ gateway، فيحصل مستخدمو Windows على التجربة نفسها التي يحصل عليها مستخدمو macOS/Linux دون إعداد أربعة backends يدويًا.

ملاحظة حول Hermes 4

تتوفّر عائلة Hermes 4 التابعة لـ Nous Research (Hermes-4-70B و Hermes-4-405B) عبر Portal بأسعار مخفّضة كثيرًا. وهي نماذج محادثة متقدّمة بتفكير هجين — قوية في الرياضيات والعلوم واتباع التعليمات والالتزام بالمخططات (schemas) ولعب الأدوار والكتابة المطوّلة.

ومع ذلك، لا يوصى باستخدامها داخل Hermes Agent. فـ Hermes 4 مضبوط للمحادثة والتفكير، لا لحلقة استدعاء الأدوات السريعة المتلاحقة التي يعتمد عليها الوكيل. استخدمها في سير عمل البحث أو عبر وكيل الاشتراك (subscription proxy) من أدوات أخرى — أما لعمل الوكيل، فاختر بدلًا منها نموذجًا وكيليًا متقدّمًا من الكتالوج:

تحمل صفحة معلومات النماذج الخاصة بـ Portal التحذير نفسه، لذا فهذا ليس رأيًا من جانب Hermes — بل هو الإرشاد الرسمي من Nous Research.

الإعداد

تثبيت جديد — أمر واحد

ينفّذ هذا الإعداد الكامل دفعة واحدة:

  1. يفتح متصفحك على portal.nousresearch.com لتسجيل الدخول عبر OAuth
  2. يخزّن الـ refresh token في ~/.hermes/auth.json
  3. يتيح لك اختيار نموذج من Nous من القائمة المنتقاة (أو التخطّي للإبقاء على نموذجك الحالي)
  4. يضبط Nous كمزوّد inference في ~/.hermes/config.yaml (عند اختيارك نموذجًا)
  5. يفعّل Tool Gateway (توجيه الويب والصور و TTS والمتصفح)
  6. يعيدك إلى الطرفية جاهزًا لتشغيل hermes chat

إذا لم يكن لديك اشتراك بعد، فسجّل أولًا في portal.nousresearch.com/manage-subscription.

تثبيت قائم — أضف Portal إلى جانب المزوّدين الآخرين

إذا كان Hermes مُعدًّا لديك بالفعل مع OpenRouter أو Anthropic أو أي مزوّد آخر، وتريد إضافة Portal إلى جانبهم:

يبقى المزوّدون الحاليون مُعدّين كما هم. ويمكنك التبديل بينهم باستخدام /model في منتصف الجلسة أو hermes model بين الجلسات — إذ يصبح Portal أحد المزوّدين المتاحين لك، لا المزوّد الوحيد.

الإعداد بلا واجهة (Headless) / عبر SSH / عن بُعد

تحتاج مصادقة OAuth إلى متصفح، لكن استدعاء الرجوع (callback) عبر loopback يعمل على الجهاز الذي يعمل عليه Hermes. بالنسبة إلى الأجهزة البعيدة، راجع OAuth عبر SSH / الأجهزة البعيدة — فالأساليب نفسها تعمل مع Portal كما تعمل مع أي مزوّد آخر قائم على OAuth (إعادة توجيه المنافذ عبر ssh -L).

إعداد الـ Profiles

إذا كنت تستخدم profiles في Hermes، فإن الـ refresh token الخاص بـ Portal يُشارَك تلقائيًا بين جميع الـ profiles عبر مخزن tokens مشترك. سجّل الدخول مرة واحدة في أي profile، وستلتقطه بقية الـ profiles تلقائيًا — دون الحاجة إلى تكرار خطوات OAuth لكل profile.

توجد إعدادات Tool Gateway ضمن أقسام الأدوات الخاصة بكل منها — لكل فئة مفتاح اختيار واحد، واختيار Nous Subscription في hermes tools (أو hermes setup --portal) يكتب القيمة nous:

تتبع بيئة التشغيل دائمًا الاختيار المخزَّن — فمفاتيح API المباشرة المتروكة في .env تُتجاهل ما دامت الفئة مضبوطة على nous، واختيار مزوّد مباشر (مثل image_gen.provider: fal) دون مفتاحه يُنتج خطأً واضحًا بدلًا من إعادة التوجيه بصمت عبر الـ gateway. (كانت الإعدادات القديمة تستخدم الخيار القديم use_gateway: true؛ وهو يُقرأ على أنه مكافئ لـ nous لكنه لم يعد يُكتب.)

يُخزَّن الـ refresh token الخاص بـ OAuth بشكل منفصل في ~/.hermes/auth.json (وليس في config.yaml — إذ يُفصل بين بيانات الاعتماد والإعدادات عن قصد في التصميم).

التعامل مع الـ token

يولّد Hermes رمز JWT قصير الأمد من الـ refresh token المخزَّن الخاص بـ Portal عند كل استدعاء inference، بدلًا من إعادة استخدام مفتاح API طويل الأمد. دورة حياة الـ token مؤتمتة بالكامل — التحديث، والتوليد، وإعادة المحاولة عند أخطاء 401 العابرة — ولن تراها أبدًا.

كما تشغّل عمليات الـ gateway ولوحة التحكم طويلة التشغيل آلية keepalive في الخلفية تحدّث الـ token قبل انتهاء صلاحيته، حتى لا تتحمّل الوكلاء الخاملة جولة 401 إضافية عند أول طلب في كل مدة صلاحية لبيانات الاعتماد. وتستمد آلية keepalive فترة نبضها من مدة الصلاحية التي أصدرها Portal فعليًا (عدة نبضات لكل مدة صلاحية)، بحدّ أقصى يحدده:

إذا أبطل Portal الـ refresh token (بسبب تغيير كلمة المرور، أو الإلغاء اليدوي، أو انتهاء الجلسة)، يُوضع الـ refresh token غير الصالح في الحجر محليًا حتى يتوقف Hermes عن إعادة استخدامه ولا ترى سلسلة من أخطاء 401 المتطابقة. ويُظهر الاستدعاء التالي رسالة واضحة "re-authentication required". نفّذ hermes auth add nous لتسجيل الدخول مجددًا؛ ويُرفع الحجر عند تسجيل الدخول الناجح التالي.

ظهور رسالة "re-authentication required" في منتصف الجلسة

أُبطل الـ refresh token الخاص بـ Portal (بسبب تغيير كلمة المرور، أو الإلغاء اليدوي، أو انتهاء الجلسة). نفّذ hermes auth add nous وسيستخدم طلبك التالي بيانات الاعتماد الجديدة. ويُرفع أي حجر على الـ token القديم تلقائيًا عند نجاح إعادة تسجيل الدخول.

تريد استخدام نموذج مزوّد معيّن لا يعرضه Portal

يوجّه Portal كل نموذج إلى backend مناسب — بعضها عبر OpenRouter، وأخرى عبر مزوّدين خاصين أو ثانويين — لذا فمعظم النماذج التي يدعمها OpenRouter متاحة عمومًا. إذا لم يظهر نموذج معيّن في /model، فجرّب المعرّف (slug) بأسلوب OpenRouter مباشرة:

إذا كان النموذج مفقودًا فعلًا، افتح issue — فنحن نعرض كتالوج Portal داخل Hermes، وغالبًا ما تعني الثغرات وجود إعداد توجيه يمكننا تحديثه.

الفواتير لا تظهر في حسابي على Portal

راجع hermes portal info أولًا — إذا أظهر أنك تستخدم مزوّدًا مختلفًا (Model: currently openrouter بدلًا من using Nous as inference provider)، فهذا يعني أن إعداداتك المحلية قد انحرفت. نفّذ hermes model، واختر Nous Portal، وسيُوجَّه الطلب التالي عبر اشتراكك.

انظر أيضًا

  • Tool Gateway — تفاصيل كاملة عن كل أداة في الـ gateway، وإعدادات كل أداة، والتسعير
  • وكيل الاشتراك (Subscription proxy) — استخدم اشتراكك في Portal من أدوات غير Hermes (وكلاء آخرين، أو سكربتات، أو عملاء من جهات خارجية)
  • الوضع الصوتي (Voice Mode) — محادثات صوتية باستخدام OpenAI TTS المتاح عبر Portal
  • مزوّدو الذكاء الاصطناعي (AI Providers) — الكتالوج الكامل للمزوّدين إذا أردت مقارنة البدائل
  • OAuth عبر SSH — تسجيل الدخول من أجهزة بعيدة أو من بيئات لا تتوفر فيها إلا المتصفحات
  • Profiles — عدة إعدادات لـ Hermes تتشارك تسجيل دخول واحدًا إلى Portal
