QQ Bot

اربط Hermes بـ QQ عبر Official QQ Bot API (v2) — مع دعم الرسائل الخاصة (C2C)، والإشارات بـ @ في المجموعات، وقنوات guild، والرسائل المباشرة، إضافةً إلى تفريغ الرسائل الصوتية نصيًا.

نظرة عامة

يستخدم محوّل QQ Bot واجهة Official QQ Bot API من أجل:

  • استقبال الرسائل عبر اتصال WebSocket دائم ببوابة QQ Gateway
  • إرسال الردود النصية وبتنسيق markdown عبر REST API
  • تنزيل الصور والرسائل الصوتية ومرفقات الملفات ومعالجتها
  • تفريغ الرسائل الصوتية نصيًا باستخدام ASR المدمج من Tencent أو مزوّد STT قابل للضبط

المتطلبات المسبقة

  1. تطبيق QQ Bot — سجّل في q.qq.com:

    • أنشئ تطبيقًا جديدًا ودوّن App ID و App Secret الخاصين بك
    • فعّل الـ intents المطلوبة: رسائل C2C، ورسائل @ في المجموعات، ورسائل Guild
    • اضبط البوت في وضع sandbox للاختبار، أو انشره للإنتاج

  2. الاعتماديات — يتطلب المحوّل aiohttp و httpx:

الرسائل الصوتية (STT)

يعمل تفريغ الرسائل الصوتية على مرحلتين:

  1. ASR المدمج في QQ (مجاني، ويُجرَّب أولًا دائمًا) — يوفّر QQ الحقل asr_refer_text في مرفقات الرسائل الصوتية، وهو يعتمد على تقنية التعرّف على الكلام الخاصة بـ Tencent

  2. مزوّد STT المُعدّ (احتياطي) — إذا لم يُرجع ASR الخاص بـ QQ نصًا، يستدعي المحوّل واجهة STT API متوافقة مع OpenAI:

    • Zhipu/GLM (zai): المزوّد الافتراضي، ويستخدم النموذج glm-asr
    • OpenAI Whisper: اضبط QQ_STT_BASE_URL و QQ_STT_MODEL
    • أي STT endpoint متوافق مع OpenAI

استكشاف الأخطاء وإصلاحها

البوت ينقطع فورًا (انقطاع سريع)

يعني هذا عادةً أحد الأسباب التالية:

  • App ID / Secret غير صالح — تحقق جيدًا من بيانات الاعتماد في q.qq.com
  • صلاحيات مفقودة — تأكد من تفعيل الـ intents المطلوبة للبوت
  • بوت مقتصر على sandbox — إذا كان البوت في وضع sandbox، فلا يمكنه استقبال الرسائل إلا من قناة الاختبار sandbox في QQ

الرسائل الصوتية لا تُفرَّغ نصيًا

  1. تحقق مما إذا كان الحقل asr_refer_text المدمج في QQ موجودًا في بيانات المرفق
  2. إذا كنت تستخدم مزوّد STT مخصصًا، فتحقق من ضبط QQ_STT_API_KEY بشكل صحيح
  3. راجع سجلات الـ gateway بحثًا عن رسائل خطأ STT

الرسائل لا تُسلَّم

  • تحقق من تفعيل intents البوت في q.qq.com
  • تحقق من QQ_ALLOWED_USERS إذا كان الوصول عبر الرسائل المباشرة مقيّدًا
  • بالنسبة لرسائل المجموعات، تأكد من الإشارة إلى البوت بـ @ (قد تتطلب سياسة المجموعات إضافته إلى قائمة السماح)
  • تحقق من QQBOT_HOME_CHANNEL لتسليم مخرجات cron والإشعارات

أخطاء الاتصال

  • تأكد من تثبيت aiohttp و httpx: pip install aiohttp httpx
  • تحقق من الاتصال الشبكي بـ api.sgroup.qq.com وبوابة WebSocket
  • راجع سجلات الـ gateway للاطلاع على رسائل الخطأ التفصيلية وسلوك إعادة الاتصال
