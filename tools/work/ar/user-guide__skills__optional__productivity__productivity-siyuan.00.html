معلومة

ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

واجهة SiYuan Note API

استخدم واجهة نواة SiYuan عبر curl للبحث في الكتل والمستندات وقراءتها وإنشائها وتحديثها وحذفها في قاعدة معرفة مستضافة ذاتيًا. لا حاجة إلى أدوات إضافية -- فقط curl ورمز API.

المتطلبات المسبقة

  1. ثبّت SiYuan وشغّله (سطح مكتب أو Docker)
  2. احصل على رمز API الخاص بك: Settings > About > API token
  3. خزّنه في ${HERMES_HOME:-~/.hermes}/.env:
    تكون القيمة الافتراضية لـ SIYUAN_URL هي http://127.0.0.1:6806 إن لم تُضبط.

المزالق

  • كل النقاط الطرفية (endpoints) من نوع POST -- حتى العمليات المقتصرة على القراءة. لا تستخدم GET.
  • سلامة SQL: استخدم استعلامات SELECT فقط. عبارات INSERT/UPDATE/DELETE/DROP خطيرة ويجب ألا تُرسَل أبدًا.
  • التحقق من المعرّف: تطابق المعرّفات النمط YYYYMMDDHHmmss-xxxxxxx. ارفض أي شيء آخر.
  • استجابات الخطأ: تحقق دائمًا من code != 0 في الاستجابات قبل معالجة data.
  • المستندات الكبيرة: يمكن أن يكون محتوى الكتلة ونتائج التصدير كبيرين جدًا. استخدم LIMIT في SQL ومرّر الناتج عبر jq لاستخراج ما تحتاجه فقط.
  • معرّفات دفاتر الملاحظات: عند العمل مع دفتر ملاحظات معيَّن، اجلب معرّفه أولًا عبر lsNotebooks.
