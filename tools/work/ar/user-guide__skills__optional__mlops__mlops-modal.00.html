سحابة Modal بلا خادم للـ GPU

دليل تشغيل أحمال عمل تعلّم الآلة على منصة سحابة GPU بلا خادم (serverless) من Modal.

متى تستخدم Modal

استخدم Modal عندما:

  • تريد تشغيل أحمال عمل تعلّم الآلة كثيفة استخدام GPU دون إدارة بنية تحتية
  • تنشر نماذج تعلّم الآلة كواجهات API تتوسع تلقائيًا
  • تشغّل مهام معالجة دفعية (تدريب، inference، معالجة بيانات)
  • تحتاج تسعيرًا للـ GPU بالثانية دون تكاليف خمول
  • تريد بناء نماذج أولية لتطبيقات تعلّم الآلة بسرعة
  • تشغّل مهامًا مجدولة (أحمال عمل شبيهة بـ cron)

الميزات الرئيسية:

  • وحدات GPU بلا خادم: T4، L4، A10G، L40S، A100، H100، H200، B200 عند الطلب
  • Python أصلي: عرّف البنية التحتية بكود Python، دون YAML
  • التوسع التلقائي (Auto-scaling): التوسع إلى صفر، أو إلى أكثر من 100 وحدة GPU فوريًا
  • بدء بارد دون ثانية: بنية تحتية مبنية بلغة Rust لإطلاق حاويات سريع
  • تخزين مؤقت للحاويات: طبقات الصور مخزَّنة مؤقتًا لتكرار سريع
  • Web endpoints: انشر الدوال كواجهات REST API مع تحديثات بلا توقف

استخدم بدائل أخرى بدلًا من ذلك:

  • RunPod: للـ pods طويلة التشغيل ذات الحالة الدائمة
  • Lambda Labs: لوحدات GPU المحجوزة
  • SkyPilot: للتنسيق متعدد السُّحُب وتحسين التكلفة
  • Kubernetes: للبُنى المعمارية متعددة الخدمات المعقّدة

الإعدادات الشائعة

إعادة تسمية autoscaler في Modal 1.0 (راجع دليل الانتقال):

  • container_idle_timeout ← scaledown_window
  • concurrency_limit ← max_containers
  • keep_warm ← min_containers
  • allow_concurrent_inputs=N ← decorator الـ @modal.concurrent(max_inputs=N)
