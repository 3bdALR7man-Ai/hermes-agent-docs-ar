معلومة

ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

مهارة MPP Agent

تُغلّف هذه المهارة عملاء Machine Payments Protocol (MPP، https://mpp.dev) بحيث يستطيع Hermes الدفع مقابل الوصول لكل طلب إلى واجهات برمجية على خوادم تستجيب بـ HTTP 402 Payment Required.

ثلاثة خيارات عملاء، جميعها موزَّعة عبر npm. اختر الأخف الذي يلبّي حاجة المستخدم. مقيَّدة بـ [linux, macos] إلى أن تنضج أدوات الدفع الأوسع على Windows.

متى تُستخدم

  • عندما تعيد واجهة برمجية تابعة لتاجر HTTP 402 مع ترويسة www-authenticate — ويريد المستخدم دفع المبلغ فعليًا لا مجرد تسجيل الاستجابة.
  • عندما يطلب المستخدم "الدفع لكل طلب"، أو "إعداد محفظة وكيل"، أو "استخدام Tempo / Privy / AgentCash"، أو يريد اكتشاف خدمات مسعّرة عبر MPP.
  • عندما ينتج عن إنفاق عبر Stripe Link رمز دفع مشترك (SPT) ويحتاج الوكيل إلى إرفاقه بتحدّي 402 — في هذا التدفق، يُفضَّل استخدام link-cli mpp pay (راجع مهارة stripe-link-cli).

المزالق

  • لا يمكن دفع HTTP 402 بلا method="stripe" عبر Stripe Link. إذا أعلن التحدّي عن Tempo أو طرق أخرى فقط، استخدم mppx (أو أي محفظة مطابقة) — إذ سيرفضه Link. وبالعكس، إذا أعلن عن method="stripe"، يُفضَّل استخدام Link عبر مهارة stripe-link-cli بحيث يمرّ الإنفاق عبر بطاقة المستخدم المعتمدة.
  • عدة تحدّيات في ترويسة واحدة. قد تُدرج www-authenticate عدة طرق (مثل tempo, stripe). سيختار أمر mpp decode في Link CLI طريقة Stripe؛ بينما تختار mppx طريقة Tempo. لا يوجد عميل "صحيح" واحد — اختر بحسب المحفظة التي مَوَّلها المستخدم.
  • تحدّيات بقيمة صفرية. بعض نقاط نهاية MPP تفرض $0.00 وتريد فقط بيانات اعتماد إثبات. تعمل هذه دون محفظة ممولة. لا ترفضها باعتبارها "معطّلة".
  • مفاتيح المحفظة لا تدخل سياق الوكيل أبدًا. تخزّن العملاء الأربعة جميعًا المفاتيح ضمن أدلة إعداداتها الخاصة (أو تولّد أزواج مفاتيح مؤقتة لكل جلسة، في حالة Privy). لا تستخدم cat/read_file عليها.
  • الجانب الخادمي لـ MPP مهارة مختلفة. إذا أراد المستخدم إضافة 402 إلى واجهته البرمجية الخاصة، فهذه المهارة ليست المناسبة — وجّهه إلى https://mpp.dev/quickstart/server وطبقات middleware الخاصة بـ mppx/nextjs وmppx/hono وmppx/express وmppx/elysia. قد تصدر لاحقًا مهارة mpp-server مخصصة.
