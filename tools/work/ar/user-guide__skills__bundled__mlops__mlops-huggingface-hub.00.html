دليل مرجعي لـ Hugging Face CLI (hf)

الأمر hf هو واجهة سطر الأوامر الحديثة للتعامل مع Hugging Face Hub، وتوفّر أدوات لإدارة المستودعات (repositories) والنماذج ومجموعات البيانات والـ Spaces.

مهم: يحلّ الأمر hf محل الأمر huggingface-cli المُهمَل (deprecated) الآن.

البدء السريع

  • التثبيت: curl -LsSf https://hf.co/cli/install.sh | bash -s
  • المساعدة: استخدم hf --help لعرض جميع الوظائف المتاحة وأمثلة عملية.
  • المصادقة: يُوصى بها عبر متغير البيئة HF_TOKEN أو الخيار --token.

الأوامر الأساسية

العمليات العامة

  • hf download REPO_ID: تنزيل الملفات من الـ Hub.
  • hf upload REPO_ID: رفع الملفات/المجلدات (يُوصى به لعملية commit واحدة؛ ويتعامل أيضًا مع الرفع القابل للاستئناف للمجلدات الكبيرة).
  • hf upload-large-folder REPO_ID LOCAL_PATH: [مُهمَل] — استخدم hf upload بدلًا منه.
  • hf sync: مزامنة الملفات بين مجلد محلي وحاوية تخزين (bucket).
  • hf env / hf version: عرض تفاصيل البيئة والإصدار.

المصادقة (hf auth)

  • login / logout: إدارة الجلسات باستخدام tokens من huggingface.co/settings/tokens.
  • list / switch: إدارة عدّة access tokens مخزّنة والتبديل بينها.
  • whoami: تحديد الحساب المسجَّل الدخول حاليًا.

إدارة المستودعات (hf repos)

  • create / delete: إنشاء مستودعات أو حذفها نهائيًا.
  • duplicate: استنساخ نموذج أو مجموعة بيانات أو Space إلى معرّف (ID) جديد.
  • move: نقل مستودع بين النطاقات (namespaces).
  • branch / tag: إدارة مراجع شبيهة بـ Git.
  • delete-files: حذف ملفات محدّدة باستخدام أنماط (patterns).

تفاعلات متخصّصة مع الـ Hub

مجموعات البيانات والنماذج

  • مجموعات البيانات: hf datasets list، وinfo، وparquet (لعرض روابط parquet).
  • استعلامات SQL: hf datasets sql SQL — نفّذ استعلامات SQL خام عبر DuckDB على روابط parquet لمجموعات البيانات.
  • النماذج: hf models list وinfo.
  • الأوراق البحثية: hf papers ls — لعرض الأوراق البحثية اليومية.

النقاشات وطلبات السحب (hf discussions)

  • إدارة دورة حياة مساهمات الـ Hub: list، وcreate، وinfo، وcomment، وclose، وreopen، وrename.
  • diff: عرض التغييرات في pull request.
  • merge: إنهاء pull requests.

البنية التحتية والحوسبة

  • نقاط النهاية (Endpoints): نشر وإدارة Inference Endpoints (deploy، وpause، وresume، وscale-to-zero، وcatalog).
  • المهام (Jobs): تشغيل مهام حوسبة على بنية HF التحتية. يشمل ذلك hf jobs uv لتشغيل سكربتات Python باعتماديات مضمّنة، وstats لمراقبة الموارد.
  • الـ Spaces: إدارة التطبيقات التفاعلية. يشمل ذلك dev-mode وhot-reload لملفات Python دون إعادة تشغيل كاملة.

التخزين والأتمتة

  • حاويات التخزين (Buckets): إدارة كاملة لحاويات تخزين شبيهة بـ S3 (create، وcp، وmv، وrm، وsync).
  • التخزين المؤقت (Cache): إدارة التخزين المحلي عبر list، وprune (لحذف الإصدارات المنفصلة)، وverify (للتحقق من checksum).
  • الـ Webhooks: أتمتة سير العمل عبر إدارة webhooks الخاصة بالـ Hub (create، وwatch، وenable/disable).
  • المجموعات (Collections): تنظيم عناصر الـ Hub ضمن مجموعات (add-item، وupdate، وlist).

استخدام متقدّم ونصائح

الخيارات العامة (Global Flags)

  • --format json: ينتج مخرجات قابلة للقراءة الآلية للأتمتة.
  • -q / --quiet: يقتصر المخرَج على المعرّفات (IDs) فقط.

الإضافات والمهارات (Skills)

  • الإضافات (Extensions): وسّع وظائف CLI عبر مستودعات GitHub باستخدام hf extensions install REPO_ID.
  • المهارات (Skills): أدر مهارات مساعد الذكاء الاصطناعي باستخدام hf skills add.
