lm-evaluation-harness - قياس أداء LLM

ما الذي تحتويه

تقيّم هذه الأداة نماذج LLM عبر أكثر من 60 معيارًا أكاديميًا (MMLU، HumanEval، GSM8K، TruthfulQA، HellaSwag). استخدمها عند قياس جودة النموذج، أو مقارنة النماذج، أو الإبلاغ عن نتائج أكاديمية، أو تتبّع تقدّم التدريب. وهي معيار صناعي تستخدمه EleutherAI وHuggingFace ومختبرات كبرى أخرى. تدعم HuggingFace وvLLM وواجهات API.

متى تستخدمها مقابل البدائل

استخدم lm-evaluation-harness عندما:

  • تقيس أداء نماذج لأبحاث أكاديمية
  • تقارن جودة النماذج عبر مهام قياسية
  • تتتبّع تقدّم التدريب
  • تُبلِّغ عن مقاييس موحَّدة (الجميع يستخدم نفس الـ prompts)
  • تحتاج إلى تقييم قابل لإعادة الإنتاج

استخدم بدائل أخرى بدلًا منها:

  • HELM (ستانفورد): تقييم أوسع (العدالة، الكفاءة، المعايرة)
  • AlpacaEval: تقييم اتّباع التعليمات باستخدام قضاة من نماذج LLM
  • MT-Bench: تقييم محادثي متعدّد الأدوار
  • سكربتات مخصّصة: تقييم خاص بمجال معيّن

مواضيع متقدّمة

أوصاف المعايير: راجع references/benchmark-guide.md للحصول على وصف تفصيلي لجميع المهام الـ60+، وما تقيسه، وكيفية تفسيرها.

المهام المخصّصة: راجع references/custom-tasks.md لإنشاء مهام تقييم خاصة بمجال معيّن.

التقييم عبر API: راجع references/api-evaluation.md لتقييم نماذج OpenAI وAnthropic ونماذج API أخرى.

استراتيجيات تعدّد GPU: راجع references/distributed-eval.md للتقييم المتوازي على مستوى البيانات (data parallel) والموتّرات (tensor parallel).

متطلبات العتاد

  • GPU: NVIDIA (CUDA 11.8+)، يعمل على CPU (بطيء جدًا)
  • VRAM:
    • نموذج 7B: 16GB (bf16) أو 8GB (8-bit)
    • نموذج 13B: 28GB (bf16) أو 14GB (8-bit)
    • نموذج 70B: يتطلّب تعدّد GPU أو التكميم
  • الوقت (نموذج 7B، A100 واحد):
    • HellaSwag: 10 دقائق
    • GSM8K: 5 دقائق
    • MMLU (كامل): ساعتان
    • HumanEval: 20 دقيقة
