التحقق

لا تكون الصفحة مكتملة بمجرد نجاح تجميع الكود. تكتمل عندما:

  1. node scripts/slopscan.mjs <src-dir> يخرج بالرمز 0 (تُصلَح الإخفاقات ولا تُخفى — يوجد /* auteur-allow: RULE_ID -- reason */ للاختيارات المتعمَّدة ويتطلب سببًا حقيقيًا)؛
  2. node scripts/shoot.mjs <url> أنتج مسارات لقطات شاشة عند 390 / 768 / 1440 وقد فحصت كل إطار — تُكتشف تجاوزات النص والمشاهد الفارغة وتأثيرات الظهور المعطوبة وانهيار التخطيط بالعين، لا بالبحث النصي؛
  3. تنجح معايير التقييم الرقمية في references/verify.md (التباين و LCP و CLS ومسار تقليل الحركة وتنوع المشاهد)؛
  4. لأسلوب direct:CINEMA-QA.md (من القوالب) مُعبّأ بقيمة PASS في كل صف.

إذا فشل أي حاجز — أصلح وأعد التشغيل. أبلغ عن النتائج بصدق: "slopscan سليم، روجعت 21 لقطة شاشة، LCP 1.9s" أفضل من "يبدو رائعًا".
