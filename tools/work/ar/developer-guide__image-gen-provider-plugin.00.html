بناء إضافة لمزوّد توليد الصور

تسجّل إضافات مزوّدي توليد الصور backend يخدم كل استدعاء للأداة image_generate — سواء كان DALL·E أو gpt-image أو Grok أو Flux أو Imagen أو Stable Diffusion أو fal أو Replicate أو منصة ComfyUI محلية، أو أي شيء آخر. وتأتي المزوّدات المدمجة (OpenAI و OpenAI-Codex و xAI و FAL و Krea و DeepInfra و OpenRouter و Meta Model API) كلها على هيئة إضافات. ويمكنك إضافة مزوّد جديد، أو تجاوز مزوّد مضمّن، بوضع مجلد في plugins/image_gen/<name>/.

نصيحة

توليد الصور واحد من عدة أنواع من إضافات الـ backend التي يدعمها Hermes. أما الأنواع الأخرى (ذات الفئات المجردة الأكثر تخصصًا) فهي إضافات مزوّدي الذاكرة وإضافات Context Engine وإضافات مزوّدي النماذج. وتجد إضافات الأدوات والـ hooks و CLI العامة في بناء إضافة لـ Hermes.

كيف يعمل الاكتشاف

يبحث Hermes عن backends توليد الصور في ثلاثة مواضع:

  1. المضمّنة — <repo>/plugins/image_gen/<name>/ (تُحمَّل تلقائيًا مع kind: backend، ومتاحة دائمًا)
  2. الخاصة بالمستخدم — ~/.hermes/plugins/image_gen/<name>/ (تُفعَّل صراحةً عبر plugins.enabled)
  3. حزم pip — الحزم التي تصرّح بنقطة دخول hermes_agent.plugins

تستدعي الدالة register(ctx) في كل إضافة ctx.register_image_gen_provider(...) — وهذا ما يضعها في السجل (registry) الموجود في agent/image_gen_registry.py. ويُحدَّد المزوّد النشط عبر image_gen.provider في config.yaml؛ ويرشد hermes tools المستخدمين خلال عملية الاختيار.

يطلب مغلّف الأداة image_generate من السجل المزوّد النشط ويوجّه الاستدعاء إليه. وإذا لم يكن أي مزوّد مسجّلًا، تعرض الأداة رسالة خطأ مفيدة تشير إلى hermes tools.

بنية المجلدات

تكون الإضافة المضمّنة مكتملة عند هذه النقطة. أما إضافات المستخدم الموجودة في ~/.hermes/plugins/image_gen/<name>/ فيجب إضافتها إلى plugins.enabled في config.yaml (أو تنفيذ hermes plugins enable <name>).

الفئة المجردة ImageGenProvider

أنشئ فئة فرعية من agent.image_gen_provider.ImageGenProvider. العنصران الإلزاميان الوحيدان هما الخاصية name والدالة generate() — ولكل ما عداهما قيم افتراضية معقولة:

plugin.yaml

القيمة kind: backend هي ما يوجّه الإضافة إلى مسار تسجيل توليد الصور. ويُطلب من المستخدم إدخال requires_env أثناء hermes plugins install.

العقد الكامل موجود في agent/image_gen_provider.py. والدوال التي ستعيد تعريفها عادةً:

صيغة الاستجابة

يجب أن تُرجع generate() قاموسًا مبنيًا عبر success_response() أو error_response()، وكلتاهما موجودتان في agent/image_gen_provider.py.

الخطأ:

يحوّل مغلّف الأداة القاموس إلى JSON ويسلّمه إلى الـ LLM. وتُعرض الأخطاء بوصفها نتيجة الأداة، ويقرر الـ LLM كيف يشرحها للمستخدم.

التعامل مع مخرجات base64 مقابل عناوين URL

تُرجع بعض الـ backends عناوين URL للصور (fal و Replicate)، بينما تُرجع أخرى بيانات بترميز base64 ‏(OpenAI gpt-image-2). في حالة base64، استخدم save_b64_image() — فهي تكتب الصورة في $HERMES_HOME/cache/images/<prefix>_<timestamp>_<uuid>.<ext> وتُرجع Path المطلق. مرّر هذا المسار (بصيغة str) بوصفه image= في success_response(). ويتعرّف التسليم عبر الـ gateway (فقاعة الصورة في Telegram، والمرفق في Discord) على عناوين URL والمسارات المطلقة معًا.

تجاوزات المستخدم

ضع إضافة مستخدم في ~/.hermes/plugins/image_gen/<name>/ تحمل قيمة الخاصية name نفسها التي تحملها إضافة مضمّنة، وفعّلها عبر hermes plugins enable <name> — فالسجل يعتمد قاعدة "آخر من يكتب هو الفائز"، وبذلك تحل نسختك محل المدمجة. وهذا مفيد لتوجيه الإضافة openai إلى وكيل (proxy) خاص، أو لاستبدال كتالوج النماذج بكتالوج مخصص.

الاختبار

أو تفاعليًا: hermes tools → "Image Generation" → اختر my-backend → أدخل مفتاح API إذا طُلب منك.

تطبيقات مرجعية

  • plugins/image_gen/openai/__init__.py — يقدّم gpt-image-2 بمستويات low/medium/high على هيئة ثلاثة معرّفات نماذج افتراضية تتشارك نموذج API واحدًا بقيم مختلفة للمعامل quality. مثال جيد على النماذج متعددة المستويات تحت backend واحد، وعلى سلسلة الأسبقية في config.yaml.
  • plugins/image_gen/xai/__init__.py — يقدّم Grok Imagine عبر xAI. بنية مختلفة (مخرجات على هيئة عناوين URL، وكتالوج أبسط).
  • plugins/image_gen/openai-codex/__init__.py — نسخة تعتمد Responses API على نمط Codex، وتعيد استخدام OpenAI SDK مع عنوان base URL مختلف للتوجيه.

التوزيع عبر pip

يجب أن تتيح الحزمة my_backend_imggen_package دالة register على المستوى الأعلى. راجع قسم التوزيع عبر pip في دليل الإضافات العام للاطلاع على الإعداد الكامل.
