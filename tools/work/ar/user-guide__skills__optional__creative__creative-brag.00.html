Brag (تصونه الجهة الأصلية)

إدخال مرجعي في الكتالوج. تصون الجهة الأصلية هذا الإدخال في latent-spaces/brag: يضم المشروع مجلد المهارة (skills/brag/) مع مراجع خطواتها، والإعدادات المسبقة للنبرة، ومكتبة الموسيقى والمؤثرات الصوتية المضمّنة، وسكربت تحليل الإشارات. يجلب hermes skills install official/creative/brag الشجرة الحالية مباشرةً من ذلك المستودع (وتُعزل وتُفحص مثل أي تثبيت من hub) — ولا يحتوي هذا المجلد إلا على بيانات الكتالوج الوصفية، فلا يمكن للنسخة المضمّنة أن تصبح قديمة.

/brag يقرأ المشروع في المجلد الحالي، ويختار زاوية ونبرة (default, polished, yc-parody, chaotic, deadpan, cinematic, app-store، أو توجيهًا حرًا)، ويخطط مشاهد فيديو مدته 15–25 ثانية، ويسلّم موجز التركيب إلى Hyperframes، ويصيّر brag-output/brag.mp4 مع ملصق من أفضل إطار ونص للمشاركة. الخيارات: --tone, --format landscape|vertical|square, --duration, --title, --no-music, --no-sfx، و --voice (تعليق صوتي من Kokoro، معطّل افتراضيًا).

على Claude Opus 5.5، يسلّم المهمة إلى نسخته المضمّنة من brag-slim ما لم يطلب الاستدعاء --full أو --voice.

المتطلبات المسبقة

  • Node.js 22+، و FFmpeg على PATH، و Hyperframes CLI (يتحقق npx hyperframes doctor من البيئة).
  • مسار Hyperframes (--full, --voice، أو أي نموذج غير Opus 5.5) يحمّل مهارات HeyGen المتخصصة بأسمائها: hyperframes-core, hyperframes-animation, hyperframes-creative, hyperframes-keyframes و hyperframes-cli، وتُثبَّت باستخدام hermes skills install heygen-com/hyperframes/skills/<name>. يحظر حارس المهارات حاليًا 4 من أصل 5 بسبب تعليقات HTML وتوثيق بيانات الاعتماد في أمثلتها (تُصنَّف hyperframes-creative خطيرة، ولا يستطيع --force تجاوز ذلك)، ولذلك لا يمكن تثبيت هذا المسار كاملًا بعد. لا تملك brag-slim هذه الاعتمادية. والمهارة الاختيارية hyperframes في هذا الكتالوج نسخة محوّلة إلى ملف واحد، ولا توفر تلك الأسماء.
  • uv يشغّل scripts/analyze_music_cues.py عندما يحتاج مقطع مخصص إلى إشارات متزامنة مع الإيقاع؛ وتأتي المقاطع المضمّنة بإشارات محسوبة مسبقًا.
  • تجلب التثبيتات نحو 290 ملفًا (نحو 16 MB، معظمها الموسيقى والمؤثرات الصوتية المضمّنة) عبر GitHub contents API. اضبط GITHUB_TOKEN أو سجّل الدخول عبر gh CLI أولًا؛ فحد الوصول المجهول البالغ 60 طلبًا في الساعة منخفض جدًا لهذه الحزمة.
