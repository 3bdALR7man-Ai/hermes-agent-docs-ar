Actual Computer

استخدم عتادك نفسه كعنقود inference خاص عبر Actual Computer. يتوفر وضعان للخدمة، كلاهما يستخدم Chat Completions لإعادة محتوى الاستدلال والمحتوى النهائي معًا:

  • وسيط مستضاف — https://api.actual.inc، بتشفير من طرف إلى طرف، يوجّه إلى عنقودك . صادِق باستخدام مفتاح inference ذي بادئة ac_ من actual.inc/user/keys.
  • daemon محلي — على الجهاز عند http://127.0.0.1:8080، ويعمل دون اتصال تمامًا. لا يلزم مفتاح API: يكتشف Hermes عنوان loopback الأساسي ويصادق تلقائيًا بقيمة بديلة داخلية.

خزّن إعدادات المزوّد في ~/.hermes/config.yaml؛ ولا يُحفظ في .envإلا مفتاح API الخاص بالخدمة المستضافة:

ملاحظات:

  • تأتي معرّفات النماذج من GET /v1/models في عنقودك — اكتشفها باستخدام hermes model أو curl -s https://api.actual.inc/v1/models -H "Authorization: Bearer $ACTUAL_API_KEY".
  • تُطبَّع عناوين المضيف المجرّدة في model.base_url : فيصبح http://127.0.0.1:8080 تلقائيًا http://127.0.0.1:8080/v1 . ويُستخدم متغير البيئة القديم ACTUAL_BASE_URL كخيار احتياطي عندما لا يُضبط URL لـ Actual في YAML.
  • يستخدم Actual /v1/chat/completions للمحادثة، والضغط، وتوليد العناوين، وكل المهام المساعدة الأخرى. وينطبق ذلك أيضًا على المزوّدين المخصّصين المستهدفين لـ api.actual.inc، والتبديل بين النماذج، والخيارات الاحتياطية. وتُتجاوز إعدادات Responses القديمة في إعدادات النموذج الرئيسي أو المزوّد المخصّص أو المهمة المساعدة تلقائيًا.
  • يُحصر جهد الاستدلال في النطاق الذي يدعمه Actual (none/low/medium/high/max) — فلا تؤدي قيمة عامة من xhigh/ultra إلى إخفاق الطلبات بخطأ 400.
  • النماذج المحلية الصغيرة: يمكن لـ toolset الافتراضية الكاملة في Hermes مع system prompt أن تتجاوز context window بحجم 32k، مما يسبب خطأ بث فارغ من خوادم عائلة llama.cpp. قلّص toolset (-t file,web) أو حمّل النموذج بسياق أكبر. وتغطي المهارة الاختيارية actual-setup (hermes skills install official/devops/actual-setup ) الإعداد واستكشاف الأخطاء وإصلاحها بالتفصيل.
  • الأسماء البديلة: actual-computer، actualcomputer، aci.

StepFun

نماذج سلسلة Step عبر StepFun — API متوافقة مع OpenAI، ومصادقة بمفتاح API.

أو اضبطها بصورة دائمة في config.yaml:

يمكن تجاوز العنوان الأساسي باستخدام STEPFUN_BASE_URL (الافتراضي: https://api.stepfun.com/v1).

Hugging Face Inference Providers

يوجّه Hugging Face Inference Providers إلى أكثر من 20 نموذجًا مفتوحًا عبر endpoint موحّد متوافق مع OpenAI (router.huggingface.co/v1). تُوجَّه الطلبات تلقائيًا إلى أسرع خلفية متاحة (Groq و Together و SambaNova وغيرها) مع تبديل تلقائي عند الفشل (automatic failover).

أو اضبطه بشكل دائم في config.yaml:

احصل على token من huggingface.co/settings/tokens — تأكد من تفعيل صلاحية "Make calls to Inference Providers". تتوفر فئة مجانية (رصيد 0.10$ شهريًا، بلا هامش ربح إضافي على أسعار المزوّدين).

يمكنك إلحاق لواحق توجيه (routing suffixes) بأسماء النماذج: :fastest (الافتراضي)، أو :cheapest، أو :provider_name لفرض خلفية محدَّدة.

يمكن تجاوز الـ base URL عبر HF_BASE_URL.
