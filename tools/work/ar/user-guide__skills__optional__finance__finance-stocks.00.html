معلومة

ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

مهارة Stocks

بيانات سوق للقراءة فقط عبر Yahoo Finance. خمسة أوامر: quote، search، history، compare، crypto. مكتبة Python القياسية فقط — بلا مفتاح API، وبلا تثبيت عبر pip. نقطة نهاية Yahoo غير رسمية وقد تفرض حدّ معدل أو تتغيّر.

متى تُستخدم

  • يطلب المستخدم سعر سهم حالي (AAPL، TSLA، MSFT، ...)
  • يريد المستخدم البحث عن رمز سهم باسم الشركة
  • يريد المستخدم سجل OHLCV أو الأداء عبر نطاق تاريخي
  • يريد المستخدم مقارنة عدة رموز أسهم جنبًا إلى جنب
  • يطلب المستخدم سعر عملة رقمية (BTC، ETH، SOL، ...)

المتطلبات المسبقة

مكتبة Python 3.8+ القياسية فقط. اختياري: اضبط ALPHA_VANTAGE_KEY لإثراء market_cap وpe_ratio ومستويات 52 أسبوعًا عندما تعود حقول Yahoo المحمية بـ crumb فارغة (null). مفتاح مجاني: https://www.alphavantage.co/support/#api-key

مرجع سريع

الأوامر

quote SYMBOL [SYMBOL2 ...]

السعر الحالي، والتغيّر، ونسبة التغيّر، والحجم، وأعلى/أدنى سعر خلال 52 أسبوعًا.

search QUERY

ابحث عن رموز الأسهم باسم الشركة. يُعيد أعلى 5 نتائج: الرمز، الاسم، البورصة، النوع.

history SYMBOL [--range RANGE]

بيانات OHLCV اليومية بالإضافة إلى إحصائيات (الحد الأدنى، الحد الأقصى، المتوسط، نسبة العائد الإجمالي). النطاقات: 1mo، 3mo، 6mo، 1y، 5y. الافتراضي: 1mo.

compare SYMBOL1 SYMBOL2 [...]

جنبًا إلى جنب: السعر، نسبة التغيّر، الأداء خلال 52 أسبوعًا.

crypto SYMBOL [SYMBOL2 ...]

أسعار العملات الرقمية. مرّر BTC (يضيف السكربت -USD تلقائيًا).

مزالق شائعة

  • واجهة Yahoo Finance غير رسمية. يمكن أن تتغير نقاط النهاية أو يُفرض عليها حدّ معدل دون إشعار — إذا بدأت الطلبات تفشل، فهذا هو السبب.
  • قد يعيد market_cap وpe_ratio قيمة فارغة (null) في quote عندما لا تكون جلسة crumb الخاصة بـ Yahoo مُنشأة. اضبط ALPHA_VANTAGE_KEY لملء النقص.
  • أضف تأخيرًا صغيرًا بين الطلبات المجمّعة لتجنب فرض حدّ المعدل.
  • هذه الأداة للقراءة فقط — بلا تنفيذ أوامر، وبلا تكامل مع الحسابات.
