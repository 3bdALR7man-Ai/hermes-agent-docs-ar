إعداد Raft

يتّصل Hermes بـRaft كوكيل خارجي عبر جسر قناة إيقاظ (wake-channel bridge) محلي. يشغّل المحوّل نقطة نهاية HTTP على loopback تستقبل تلميحات إيقاظ خالية من المحتوى من الجسر، ثم يحقنها في خط أنابيب جلسة gateway الخاص بـ Hermes. يقرأ الوكيل الرسائل ويرسلها عبر Raft CLI — لا يلمس المحوّل أبدًا نصوص الرسائل أو مؤشرات التسليم.

تقسيم العمل
  • الجسر يتولى: استهلاك تلميحات الإيقاظ، وإزالة التكرار، والتراجع التدريجي (backoff)، وإعادة الاتصال، والتسليم بمرة واحدة على الأقل، وتسجيل الإثباتات.
  • محوّل Hermes يتولى: نقطة نهاية إيقاظ على localhost وحقن إشعار قصير في سياق الوكيل.
  • الوكيل يتولى: سحب الرسائل (raft message check)، والرد (raft message send)، وكل تفاعلات Raft الأخرى عبر CLI.

لا يحمل المحوّل أي بيانات اعتماد لـ Raft — فقط رمز مشترك (token) خاص بكل جلسة لمصادقة localhost بين الجسر ونقطة النهاية.

المتطلبات المسبقة

  • مساحة عمل Raft يمكنك فيها إنشاء وكيل خارجي (External Agent)
  • Raft CLI مُثبَّت ومسجَّل الدخول إلى ملف تعريف ذلك الوكيل الخارجي
  • aiohttp — حزمة Python (مضمَّنة في إضافات (extras) [all] الخاصة بـ Hermes)

في Raft، افتح قائمة Agents، وأنشئ وكيلًا خارجيًا، واتّبع بطاقة الإعداد لتثبيت Raft CLI وتسجيل دخول ملف تعريف الوكيل. بمجرد إنشاء الوكيل، يعرض Raft دليل إعداد Hermes مع متغيرات البيئة والإعدادات اللازمة لتشغيل gateway.

الإعداد

أضِف إلى ~/.hermes/.env:

هذا كل ما في الأمر — يُفعَّل المحوّل تلقائيًا عند ضبط RAFT_PROFILE. يولّد رمز جسر خاصًا بكل جلسة، ويختار منفذًا (port) مؤقتًا، وينشئ العملية الفرعية للجسر تلقائيًا عند تشغيل gateway.

كيف يعمل

  1. يرسل خادم Raft تلميحات إيقاظ إلى عملية الجسر عبر SSE.
  2. يُعيد الجسر توجيه كل تلميح كـ POST /wake إلى نقطة نهاية loopback الخاصة بالمحوّل.
  3. يتحقق المحوّل من رمز الجسر، ويتأكد أن الحمولة خالية من المحتوى، ثم يحقن إشعار إيقاظ في جلسة Hermes.
  4. يرى الوكيل إشعار الإيقاظ ويستخدم Raft CLI لقراءة الرسائل والرد.

حمولات الإيقاظ خالية من المحتوى بموجب العقد (contract) — تحمل بيانات وصفية (معرّف الحدث، ومعرّف الرسالة، والطوابع الزمنية) لكن أبدًا نصوص الرسائل، أو أسماء القنوات، أو هويات المُرسِلين. يرفض المحوّل أي حمولة تحتوي حقولًا شبيهة بالمحتوى (text، وbody، وcontent، وmessages، إلخ).

الجسر (Bridge)

ينشئ المحوّل تلقائيًا raft agent bridge كعملية فرعية، مُمرِّرًا رابط نقطة النهاية والرمز. يتصل الجسر بخادم Raft باستخدام ملف التعريف المُعَدّ ويبدأ بإعادة توجيه تلميحات الإيقاظ. يُنهى عند إيقاف gateway.
