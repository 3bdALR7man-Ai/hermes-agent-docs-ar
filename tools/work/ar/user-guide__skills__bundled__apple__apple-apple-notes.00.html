Apple Notes

استخدم memo لإدارة Apple Notes مباشرةً من الطرفية. تتزامن الملاحظات عبر جميع أجهزة Apple عبر iCloud.

المتطلبات المسبقة

  • macOS مع تطبيق Notes.app
  • التثبيت: brew tap antoniorodr/memo && brew install antoniorodr/memo/memo
  • امنح صلاحية Automation لتطبيق Notes.app عند الطلب (System Settings → Privacy → Automation)

متى تُستخدم

  • عندما يطلب المستخدم إنشاء ملاحظات Apple Notes أو عرضها أو البحث فيها
  • حفظ المعلومات في Notes.app للوصول إليها من عدة أجهزة
  • تنظيم الملاحظات في مجلدات
  • تصدير الملاحظات إلى Markdown أو HTML

متى لا تُستخدم

  • إدارة خزنة Obsidian → استخدم مهارة obsidian
  • Bear Notes → تطبيق مختلف (غير مدعوم هنا)
  • ملاحظات سريعة خاصة بالوكيل فقط → استخدم أداة memory بدلًا من ذلك

القيود

  • لا يمكن تعديل الملاحظات التي تحتوي على صور أو مرفقات
  • المطالبات التفاعلية تتطلب الوصول إلى الطرفية (استخدم pty=true عند الحاجة)
  • مخصّص لنظام macOS فقط — يتطلّب تطبيق Apple Notes.app

القواعد

  1. فضّل Apple Notes عندما يريد المستخدم التزامن بين الأجهزة (iPhone/iPad/Mac)
  2. استخدم أداة memory للملاحظات الداخلية الخاصة بالوكيل التي لا تحتاج إلى تزامن
  3. استخدم مهارة obsidian لإدارة المعرفة المبنية على Markdown
