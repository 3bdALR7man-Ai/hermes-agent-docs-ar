Docker Management

أدِر حاويات Docker وصوره وأحجامه (volumes) وشبكاته ومكدّسات Compose باستخدام أوامر Docker CLI القياسية. لا حاجة إلى أي اعتماديات إضافية غير Docker نفسه.

متى تُستخدم

  • تشغيل الحاويات أو إيقافها أو إعادة تشغيلها أو حذفها أو فحصها
  • بناء صور Docker أو سحبها أو دفعها أو وسمها أو تنظيفها
  • العمل مع Docker Compose (مكدّسات متعددة الخدمات)
  • إدارة الأحجام (volumes) أو الشبكات
  • تشخيص حاوية متعطّلة أو تحليل السجلات
  • التحقق من استخدام Docker لمساحة القرص أو تحرير المساحة
  • مراجعة Dockerfile أو تحسينه

المتطلبات المسبقة

  • محرّك Docker مثبّت وقيد التشغيل
  • المستخدم مُضاف إلى مجموعة docker (أو استخدم sudo)
  • Docker Compose v2 (مضمّن مع تثبيتات Docker الحديثة)

التحقق

بعد أي عملية Docker، تحقّق من النتيجة:

  • هل بدأت الحاوية؟ → docker ps (تحقّق أن الحالة "Up")
  • هل السجلات نظيفة؟ → docker logs --tail 20 NAME (بلا أخطاء)
  • هل المنفذ متاح؟ → curl -s http://localhost:PORT أو docker port NAME
  • هل تم بناء الصورة؟ → docker images | grep TAG
  • هل مكدّس Compose سليم؟ → docker compose ps (كل الخدمات "running" أو "healthy")
  • هل تحرّرت مساحة القرص؟ → docker system df (قارن قبل/بعد)

نصائح لتحسين Dockerfile

عند مراجعة Dockerfile أو إنشائه، اقترح هذه التحسينات:

  1. البناء متعدد المراحل — افصل بيئة البناء عن بيئة التشغيل لتقليل حجم الصورة النهائية
  2. ترتيب الطبقات — ضع الاعتماديات قبل كود المصدر حتى لا تُبطل التغييرات الطبقات المخزّنة مؤقتًا
  3. دمج أوامر RUN — طبقات أقل، صورة أصغر
  4. استخدام .dockerignore — استبعِد node_modules، .git، __pycache__، وما شابه
  5. تثبيت إصدارات الصورة الأساسية — node:20-alpine بدلًا من node:latest
  6. التشغيل بدون صلاحيات root — أضِف تعليمة USER لأغراض الأمان
  7. استخدام قواعد slim/alpine — python:3.12-slim بدلًا من python:3.12
