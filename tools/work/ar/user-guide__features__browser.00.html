أتمتة المتصفح

يتضمن Hermes Agent مجموعة أدوات (toolset) كاملة لأتمتة المتصفح مع عدة خيارات للـ backend:

  • وضع Browser Use السحابي عبر Browser Use للحصول على Chromium مُدار مع وضع التخفّي (stealth)، و proxies سكنية، وحلّ CAPTCHA، و profiles متصفح قابلة لإعادة الاستخدام
  • وضع Browserbase السحابي عبر Browserbase كمزوّد بديل للمتصفح السحابي مع أدوات لمكافحة اكتشاف الروبوتات (anti-bot)
  • وضع Browser Use عبر Browser Use CLI 3.0، وهو مشغّل المتصفح الافتراضي لـ Chrome المحلي ولمتصفحات Browser Use السحابية
  • وضع Firecrawl السحابي عبر Firecrawl للحصول على متصفحات سحابية مع استخراج مدمج للبيانات (scraping)
  • وضع Camofox المحلي عبر Camofox للتصفح المحلي المقاوم للاكتشاف (انتحال بصمة المتصفح المعتمد على Firefox)
  • محرك Lightpanda المحلي عبر Lightpanda — متصفح headless بُني من الصفر بلغة Zig ومصمَّم للآلات؛ يبدأ فورًا، ويستهلك ذاكرة أقل بـ 16 مرة، وأسرع بـ 9 مرات من Chrome. يعمل في وضع Browser Use (يشغّله Hermes، دون الحاجة إلى Chromium أو Node) ومع الأدوات المدمجة (مع رجوع تلقائي إلى Chrome للإجراءات التي لا يدعمها بعد)
  • CDP محلي لعائلة Chromium — اربط أدوات المتصفح بنسخة Chrome أو Brave أو Chromium أو Edge الخاصة بك باستخدام /browser connect
  • وضع المتصفح المحلي عبر أداة agent-browser CLI وتثبيت محلي لـ Chromium

في جميع الأوضاع، يستطيع الوكيل التنقل في المواقع، والتفاعل مع عناصر الصفحة، وتعبئة النماذج، واستخراج المعلومات.

نظرة عامة

تُمثَّل الصفحات في صورة أشجار إمكانية الوصول (accessibility trees) (لقطات نصية)، مما يجعلها مثالية لوكلاء LLM. تحصل العناصر التفاعلية على معرّفات مرجعية (ref IDs) (مثل @e1 و @e2) يستخدمها الوكيل للنقر والكتابة.

القدرات الرئيسية:

  • تنفيذ سحابي متعدد المزوّدين — Browser Use أو Browserbase أو Firecrawl — دون الحاجة إلى متصفح محلي
  • تكامل محلي مع عائلة Chromium — اتصل بمتصفح Chrome أو Brave أو Chromium أو Edge قيد التشغيل لديك عبر CDP للتصفح العملي المباشر
  • دعم سحابي لمكافحة الروبوتات — يتضمن Browser Use Cloud وضع التخفّي، و proxies سكنية، وحلّ CAPTCHA
  • Profiles سحابية دائمة — يستطيع Browser Use Cloud إعادة استخدام ملفات تعريف الارتباط (cookies) و localStorage وكلمات المرور المحفوظة عبر الجلسات
  • عزل الجلسات — تحصل كل مهمة على جلسة متصفح خاصة بها
  • تنظيف تلقائي — تُغلق الجلسات غير النشطة بعد انقضاء مهلة زمنية
  • تحليل بصري (Vision) — لقطة شاشة + تحليل بالذكاء الاصطناعي للفهم البصري
