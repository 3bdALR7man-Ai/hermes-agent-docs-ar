Blogwatcher

تتبّع تحديثات المدونات وخلاصات RSS/Atom باستخدام أداة blogwatcher-cli. تدعم الأداة الاكتشاف التلقائي للخلاصات، والرجوع إلى استخراج HTML عند الحاجة (scraping fallback)، واستيراد OPML، وإدارة حالة المقالات المقروءة/غير المقروءة.

العمل مع أدوات Hermes (اقرأ هذا أولًا)

blogwatcher-cli هي قاعدة بيانات الخلاصات؛ أدوات Hermes تتكفّل بالأتمتة حولها:

  • المراقبة المتكررة — استخدم حقل monitor في أداة cronjob، لا جدولًا مجردًا. يشغّل monitor سكربتًا في كل دورة ولا يوقظ الوكيل إلا عند تغيّر المخرجات: اضبطه على سكربت يشغّل blogwatcher-cli scan >/dev/null 2>&1 && blogwatcher-cli articles (مخرجات حتمية؛ ظهور مقالات جديدة = تغيّر المخرجات = يستيقظ الوكيل مع حقن الفرق (diff)). الدورات التي لا تغيّر فيها المخرجات لا تكلّف أي استدعاء LLM. اضبط deliver لتوجيه الملخصات إلى محادثة/قناة؛ أضف continuity: true ليتسنى للملخصات المتتالية إزالة التكرار.
  • قراءة مقال يسأل عنه المستخدم: استخدم web_extract([url]) على رابط المقال من blogwatcher-cli articles — لا تُعِد استخراج المحتوى يدويًا.
  • طلب لمرة واحدة لـ"مراقبة هذه الصفحة عند تغيّرها" بدون دلالات الخلاصات: تجاوز هذه المهارة؛ حقل monitor في أداة cronjob يقبل رابط http(s) مباشرةً.
  • قراءة لمرة واحدة لخلاصة أو أحدث منشورات موقع، دون الحاجة للتثبيت: استخدم مهارة rss-feeds المضمّنة (scripts/feed.py read URL)؛ تستحق blogwatcher التثبيت عندما تتبّع خلاصات كثيرة بحالة مقروء/غير مقروء.
  • تتبّع الشركات/المنافسين مع تحليل واستشهادات: يُفضَّل استخدام مهارة competitor-news-monitor؛ وتُعد blogwatcher الطبقة الأخف للخلاصات الخام التي يمكن أن تعتمد عليها.

التثبيت

اختر إحدى الطرق:

  • Go: go install github.com/JulienTant/blogwatcher-cli/cmd/blogwatcher-cli@latest
  • Docker: docker run --rm -v blogwatcher-cli:/data ghcr.io/julientant/blogwatcher-cli
  • ملف تنفيذي (Linux amd64): curl -sL https://github.com/JulienTant/blogwatcher-cli/releases/latest/download/blogwatcher-cli_linux_amd64.tar.gz | tar xz -C /usr/local/bin blogwatcher-cli
  • ملف تنفيذي (Linux arm64): curl -sL https://github.com/JulienTant/blogwatcher-cli/releases/latest/download/blogwatcher-cli_linux_arm64.tar.gz | tar xz -C /usr/local/bin blogwatcher-cli
  • ملف تنفيذي (macOS Apple Silicon): curl -sL https://github.com/JulienTant/blogwatcher-cli/releases/latest/download/blogwatcher-cli_darwin_arm64.tar.gz | tar xz -C /usr/local/bin blogwatcher-cli
  • ملف تنفيذي (macOS Intel): curl -sL https://github.com/JulienTant/blogwatcher-cli/releases/latest/download/blogwatcher-cli_darwin_amd64.tar.gz | tar xz -C /usr/local/bin blogwatcher-cli

الأوامر الشائعة

إدارة المدونات

  • إضافة مدونة: blogwatcher-cli add "My Blog" https://example.com
  • إضافة مع تحديد الخلاصة صراحةً: blogwatcher-cli add "My Blog" https://example.com --feed-url https://example.com/feed.xml
  • إضافة مع استخراج HTML: blogwatcher-cli add "My Blog" https://example.com --scrape-selector "article h2 a"
  • عرض قائمة المدونات المتتبَّعة: blogwatcher-cli blogs
  • حذف مدونة: blogwatcher-cli remove "My Blog" --yes
  • الاستيراد من OPML: blogwatcher-cli import subscriptions.opml

الفحص والقراءة

  • فحص جميع المدونات: blogwatcher-cli scan
  • فحص مدونة واحدة: blogwatcher-cli scan "My Blog"
  • عرض المقالات غير المقروءة: blogwatcher-cli articles
  • عرض جميع المقالات: blogwatcher-cli articles --all
  • التصفية حسب المدونة: blogwatcher-cli articles --blog "My Blog"
  • التصفية حسب الفئة: blogwatcher-cli articles --category "Engineering"
  • تعليم مقال كمقروء: blogwatcher-cli read 1
  • تعليم مقال كغير مقروء: blogwatcher-cli unread 1
  • تعليم الكل كمقروء: blogwatcher-cli read-all
  • تعليم الكل كمقروء لمدونة معينة: blogwatcher-cli read-all --blog "My Blog" --yes

متغيرات البيئة (Environment Variables)

يمكن ضبط جميع الخيارات عبر متغيرات بيئة تبدأ بالبادئة BLOGWATCHER_:

المتغيرالوصف
BLOGWATCHER_DBمسار ملف قاعدة بيانات SQLite
BLOGWATCHER_WORKERSعدد عمليات الفحص المتزامنة (الافتراضي: 8)
BLOGWATCHER_SILENTطباعة "scan done" فقط عند الفحص
BLOGWATCHER_YESتخطي مطالبات التأكيد
BLOGWATCHER_CATEGORYالفلتر الافتراضي لتصفية المقالات حسب الفئة

ملاحظات

  • تكتشف الأداة تلقائيًا خلاصات RSS/Atom من الصفحات الرئيسية للمدونات عندما لا يُحدَّد --feed-url.
  • تلجأ إلى استخراج HTML إذا فشل RSS وكان --scrape-selector مضبوطًا.
  • تُحفظ الفئات المستخرجة من خلاصات RSS/Atom ويمكن استخدامها لتصفية المقالات.
  • استورد المدونات بالجملة من ملفات OPML المصدَّرة من Feedly أو Inoreader أو NewsBlur وغيرها.
  • تُخزَّن قاعدة البيانات افتراضيًا في ~/.blogwatcher-cli/blogwatcher-cli.db (يمكن تجاوز ذلك عبر --db أو BLOGWATCHER_DB).
  • استخدم blogwatcher-cli <command> --help لاكتشاف جميع الخيارات والإعدادات.
