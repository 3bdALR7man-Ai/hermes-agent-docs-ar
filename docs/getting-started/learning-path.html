      مسار التعلّم

      يستطيع Hermes Agent فعل الكثير — مساعد عبر CLI، وبوت على Telegram/Discord، وأتمتة المهام، والتدريب بالتعلّم المعزز (RL)، وغير ذلك. تساعدك هذه الصفحة على تحديد نقطة البداية وما يجب أن تقرأه بناءً على مستوى خبرتك وما تسعى إلى تحقيقه.

      ابدأ من هنا

      إذا لم تكن قد ثبّتَّ Hermes Agent بعد، فابدأ بـ دليل التثبيت ثم اتبع خطوات البدء السريع. كل ما يلي يفترض أن لديك تثبيتًا يعمل.

      إعداد المزوّد لأول مرة

      يحتاج المستخدمون الجدد في الغالب إلى hermes setup --portal — إذ تغطي عملية OAuth واحدة نموذجًا إضافةً إلى أدوات Tool Gateway الأربع (البحث/الصور/TTS/المتصفح). راجع Nous Portal.

      كيفية استخدام هذه الصفحة​

      • هل تعرف مستواك؟ انتقل إلى جدول مستويات الخبرة واتبع ترتيب القراءة الخاص بمستواك.
      • هل لديك هدف محدد؟ انتقل مباشرةً إلى حسب حالة الاستخدام وابحث عن السيناريو المناسب لك.
      • هل تتصفح فقط؟ اطّلع على جدول الميزات الرئيسية للحصول على نظرة عامة سريعة على كل ما يستطيع Hermes Agent فعله.

      حسب مستوى الخبرة​

      المستوىالهدفالقراءة الموصى بهاالوقت التقديري
      مبتدئالتشغيل والبدء، وإجراء محادثات أساسية، واستخدام الأدوات المدمجةالتثبيت → البدء السريع → استخدام CLI → الإعدادات~ساعة واحدة
      متوسطإعداد بوتات المراسلة، واستخدام الميزات المتقدمة مثل الذاكرة ومهام cron والمهاراتالجلسات (Sessions) → المراسلة → الأدوات → المهارات (Skills) → الذاكرة → Cron~2–3 ساعات
      متقدمبناء أدوات مخصصة، وإنشاء المهارات، وتدريب النماذج بالتعلّم المعزز (RL)، والمساهمة في المشروعالبنية المعمارية (Architecture) → إضافة أدوات → إنشاء المهارات (Skills) → المساهمة~4–6 ساعات

      حسب حالة الاستخدام​

      اختر السيناريو الذي يطابق ما تريد فعله. يربطك كل سيناريو بالمستندات ذات الصلة بالترتيب الذي ينبغي أن تقرأها به.

      "أريد مساعدًا برمجيًا عبر CLI"​

      استخدم Hermes Agent مساعدًا تفاعليًا في الطرفية لكتابة الكود ومراجعته وتشغيله.

      1. التثبيت
      2. البدء السريع
      3. استخدام CLI
      4. تنفيذ الكود
      5. ملفات السياق (Context Files)
      6. نصائح وحيل
      نصيحة

      مرّر الملفات مباشرةً إلى محادثتك باستخدام ملفات السياق. يستطيع Hermes Agent قراءة الكود وتعديله وتشغيله في مشاريعك.

      "أريد بوتًا على Telegram/Discord"​

      انشر Hermes Agent كبوت على منصة المراسلة المفضلة لديك.

      1. التثبيت
      2. الإعدادات
      3. نظرة عامة على المراسلة
      4. إعداد Telegram
      5. إعداد Discord
      6. الوضع الصوتي (Voice Mode)
      7. استخدام Voice Mode مع Hermes
      8. الأمان

      للاطلاع على أمثلة مشاريع كاملة، راجع:

      • بوت الملخّص اليومي
      • مساعد Telegram للفريق

      "أريد أتمتة المهام"​

      جدوِل المهام المتكررة، أو شغّل مهام دفعية، أو اربط إجراءات الوكيل ببعضها في سلسلة.

      1. البدء السريع
      2. الجدولة باستخدام Cron
      3. المعالجة الدفعية (Batch Processing)
      4. التفويض
      5. Hooks
      نصيحة

      تتيح مهام cron لـ Hermes Agent تنفيذ المهام وفق جدول زمني — ملخصات يومية، وفحوصات دورية، وتقارير آلية — دون الحاجة إلى وجودك.

      "أريد فريقًا من البوتات المتخصصة"​

      أنشئ بوتات مسمّاة لكل منها نموذجه وذاكرته ومهاراته وروتيناته ومحادثاته الخاصة، ثم اجمعها معًا في محادثات جماعية أو عبر @mentions.

      1. Desktop
      2. Profiles
      3. Bot Mode
      4. الجدولة باستخدام Cron
      5. Desktop متعدد الاتصالات

      "أريد بناء أدوات/مهارات مخصصة"​

      وسّع Hermes Agent بأدواتك الخاصة وحزم مهارات قابلة لإعادة الاستخدام.

      1. الإضافات (Plugins)
      2. بناء إضافة لـ Hermes
      3. نظرة عامة على الأدوات
      4. نظرة عامة على المهارات
      5. MCP (Model Context Protocol)
      6. البنية المعمارية (Architecture)
      7. إضافة أدوات
      8. إنشاء المهارات (Skills)
      نصيحة

      في معظم حالات إنشاء أدوات مخصصة، ابدأ بالإضافات (plugins). فصفحة إضافة أدوات مخصصة لتطوير أدوات Hermes الأساسية المدمجة، وليست المسار المعتاد للمستخدمين أو للأدوات المخصصة.

      "أريد تدريب النماذج"​

      استخدم التعلّم المعزز (reinforcement learning) لإجراء fine-tuning لسلوك النموذج عبر pipeline تدريب RL الخاص بـ Hermes Agent (المدعوم بـ Atropos).

      1. البدء السريع
      2. الإعدادات
      3. بيئات Atropos RL (رابط خارجي)
      4. توجيه المزوّدين (Provider Routing)
      5. البنية المعمارية (Architecture)
      نصيحة

      يحقق تدريب RL أفضل النتائج عندما تكون قد فهمت بالفعل أساسيات تعامل Hermes Agent مع المحادثات واستدعاءات الأدوات. إذا كنت جديدًا، فاتبع مسار المبتدئين أولًا.

      "أريد استخدامه كمكتبة Python"​

      ادمج Hermes Agent برمجيًا في تطبيقات Python الخاصة بك.

      1. التثبيت
      2. البدء السريع
      3. دليل مكتبة Python
      4. البنية المعمارية (Architecture)
      5. الأدوات
      6. الجلسات (Sessions)

      ماذا تقرأ بعد ذلك​

      بناءً على موقعك الحالي:

      • هل انتهيت للتو من التثبيت؟ → توجّه إلى البدء السريع لإجراء أول محادثة لك.
      • هل أكملت البدء السريع؟ → اقرأ استخدام CLI و الإعدادات لتخصيص إعدادك.
      • هل أصبحت مرتاحًا مع الأساسيات؟ → استكشف الأدوات، و المهارات (Skills)، و الذاكرة لإطلاق القدرات الكاملة للوكيل.
      • هل تُعدّه لفريق؟ → اقرأ الأمان و الجلسات (Sessions) لفهم التحكم في الوصول وإدارة المحادثات.
      • هل أنت مستعد للبناء؟ → انتقل إلى دليل المطوّر لفهم الآليات الداخلية والبدء في المساهمة.
      • هل تريد أمثلة عملية؟ → اطّلع على قسم الأدلة للحصول على مشاريع ونصائح من الواقع.
      نصيحة

      لا تحتاج إلى قراءة كل شيء. اختر المسار الذي يناسب هدفك، واتبع الروابط بالترتيب، وستصبح منتجًا بسرعة. ويمكنك دائمًا العودة إلى هذه الصفحة لمعرفة خطوتك التالية.
