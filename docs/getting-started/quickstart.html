      البدء السريع مع Hermes Agent

      ينقلك هذا الدليل من نقطة الصفر إلى إعداد Hermes يعمل ويصمد أمام الاستخدام الفعلي: ثبّت، واختر مزوّدًا، وتحقق من نجاح محادثة، واعرف بالضبط ما عليك فعله عندما يتعطل شيء ما.

      تفضّل المشاهدة؟​

      أعدّت Onchain AI Garage درسًا شاملًا (Masterclass) يشرح التثبيت والإعداد والأوامر الأساسية — وهو رفيق جيد لهذه الصفحة إن كنت تفضّل المتابعة بالفيديو. وللمزيد، راجع قائمة التشغيل الكاملة Hermes Agent Tutorials & Use Cases.

      لمن هذا الدليل​

      • أنت جديد تمامًا وتريد أقصر طريق للوصول إلى إعداد يعمل
      • تنتقل إلى مزوّد آخر ولا تريد إضاعة الوقت في أخطاء الإعدادات
      • تُعدّ Hermes لفريق أو بوت أو سير عمل يعمل على مدار الساعة
      • سئمت من حالة "تم التثبيت، لكنه لا يفعل شيئًا"

      الطريق الأسرع​

      اختر الصف الذي يطابق هدفك:

      الهدفابدأ بهذاثم نفّذ هذا
      أريد فقط أن يعمل Hermes على جهازيhermes setupابدأ محادثة حقيقية وتحقق من أنه يستجيب
      أعرف المزوّد الذي أريده مسبقًاhermes modelاحفظ الإعدادات، ثم ابدأ المحادثة
      أريد بوتًا أو إعدادًا يعمل باستمرارhermes gateway setup بعد أن يعمل CLIاربط Telegram أو Discord أو Slack أو منصة أخرى
      أريد نموذجًا محليًا أو مستضافًا ذاتيًاhermes model → endpoint مخصصتحقق من الـ endpoint واسم النموذج وطول السياق
      أريد احتياطيًا (fallback) عبر عدة مزوّدينhermes model أولًاأضف التوجيه (routing) والاحتياطي فقط بعد أن تعمل المحادثة الأساسية

      قاعدة عامة: إذا لم يتمكن Hermes من إكمال محادثة عادية، فلا تُضِف مزيدًا من الميزات بعد. احرص أولًا على نجاح محادثة واحدة سليمة، ثم أضف تباعًا gateway أو cron أو المهارات أو الصوت أو التوجيه.

      1. تثبيت Hermes Agent​

      باستخدام مُثبّت Hermes Desktop على macOS أو Windows (موصى به)​

      لتثبيت تطبيقَي سطر الأوامر وسطح المكتب بسهولة، نزّل مُثبّت Hermes Desktop من موقعنا وشغّله.

      بدون Hermes Desktop:​

      لتثبيت سطر الأوامر فقط دون Hermes Desktop، نفّذ:

      Linux / macOS / WSL2 / Android (Termux)​

      curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

      Windows (تثبيت أصلي)​

      نفّذ في PowerShell:

      iex (irm https://hermes-agent.nousresearch.com/install.ps1)
      Android / Termux

      إذا كنت تثبّت على هاتف، فراجع دليل Termux المخصص لمعرفة المسار اليدوي المُختبَر، والإضافات (extras) المدعومة، والقيود الحالية الخاصة بـ Android.

      بعد انتهاء التثبيت، أعد تحميل الـ shell:

      source ~/.bashrc   # or source ~/.zshrc

      للاطلاع على خيارات التثبيت التفصيلية والمتطلبات المسبقة واستكشاف الأخطاء وإصلاحها، راجع دليل التثبيت.

      2. اختيار المزوّد​

      هذه أهم خطوة في الإعداد على الإطلاق. استخدم hermes model للمرور بخطوات الاختيار تفاعليًا:

      hermes model
      أسهل طريق: Nous Portal

      اشتراك واحد يغطي أكثر من 300 نموذج، إضافةً إلى Tool Gateway (البحث في الويب، وتوليد الصور، و TTS، والمتصفح السحابي). في تثبيت جديد:

      hermes setup --portal

      يسجّل هذا الأمر دخولك، ويضبط Nous مزوّدًا لك، ويفعّل Tool Gateway، كل ذلك بأمر واحد.

      أوضاع الإعداد

      في تثبيت جديد، يوفّر hermes setup ثلاثة أوضاع:

      • Quick Setup (Nous Portal) — تسجيل دخول عبر OAuth دون مفاتيح API تحتاج إلى إدارتها؛ يُعدّ نموذجًا إضافةً إلى أدوات Tool Gateway، وتُحتسب التكلفة على اشتراك Nous Portal الخاص بك. وهو المسار السريع الموصى به.
      • Full Setup — تمرّ بنفسك على كل مزوّد وأداة وخيار (باستخدام مفاتيحك الخاصة).
      • Blank Slate — يبدأ كل شيء معطّلًا باستثناء الحد الأدنى اللازم لتشغيل وكيل: المزوّد والنموذج، و toolset عمليات الملفات (File Operations)، و toolset الخاص بـ Terminal. لا ويب ولا متصفح ولا تنفيذ كود ولا رؤية (vision) ولا ذاكرة ولا تفويض ولا cron ولا مهارات ولا إضافات ولا خوادم MCP — كما تُعطَّل جميعًا ميزات الضغط ونقاط الحفظ (checkpoints) والتوجيه الذكي والتقاط الذاكرة. بعد تطبيق خط الأساس الأدنى، تختار أحد مسارين: البدء مع تعطيل كل شيء (الإنهاء الآن بالوكيل الأدنى)، أو المرور على جميع الإعدادات (تفعيل ما تختاره من الأدوات والمهارات والإضافات و MCP والمراسلة). اختر هذا الوضع عندما تريد وكيلًا بحد أدنى وتحت سيطرتك الكاملة، وتنوي تفعيل ما تحتاج إليه بالضبط فقط.

      يكتب Blank Slate قائمة صريحة في platform_toolsets.cli إضافةً إلى agent.disabled_toolsets، بحيث لا يُحمَّل أبدًا أي شيء لم تختره — ولا حتى بعد hermes update. يمكنك لاحقًا إعادة تفعيل أي شيء باستخدام hermes tools، أو إضافة المهارات الأولية عبر hermes skills opt-in --sync، أو ضبط الإعدادات عبر hermes setup agent.

      لمعظم المستخدمين لأول مرة: اختر مزوّدًا، واقبل القيم الافتراضية ما لم تكن تعرف سبب تغييرها. ستجد الكتالوج الكامل للمزوّدين مع متغيرات البيئة وخطوات الإعداد في صفحة المزوّدين (Providers).

      الحد الأدنى للسياق: 64K token

      يتطلب Hermes Agent نموذجًا بسياق لا يقل عن 64,000 token. لا تستطيع النماذج ذات النوافذ الأصغر الاحتفاظ بذاكرة عمل كافية لسير العمل متعدد الخطوات القائم على استدعاء الأدوات، وستُرفض عند بدء التشغيل. تستوفي معظم النماذج المستضافة (Claude و GPT و Gemini و Qwen و DeepSeek) هذا الشرط بسهولة. إذا كنت تشغّل نموذجًا محليًا، فاضبط حجم سياقه على 64K على الأقل (مثل --ctx-size 65536 لـ llama.cpp أو -c 65536 لـ Ollama).

      نصيحة

      يمكنك تبديل المزوّد في أي وقت باستخدام hermes model — دون أي ارتباط إلزامي. للاطلاع على القائمة الكاملة لجميع المزوّدين المدعومين وتفاصيل إعدادهم، راجع مزوّدو الذكاء الاصطناعي (AI Providers).

      كيف تُخزَّن الإعدادات​

      يفصل Hermes الأسرار (secrets) عن الإعدادات العادية:

      • الأسرار و tokens → ~/.hermes/.env
      • الإعدادات غير السرية → ~/.hermes/config.yaml

      أسهل طريقة لضبط القيم بشكل صحيح هي عبر CLI:

      hermes config set model anthropic/claude-opus-4.6
      hermes config set terminal.backend docker
      hermes config set OPENROUTER_API_KEY sk-or-...

      تذهب كل قيمة إلى الملف الصحيح تلقائيًا.

      3. ابدأ محادثتك الأولى​

      hermes            # classic CLI
      hermes --tui      # modern TUI (recommended)

      سترى شعار ترحيب يعرض نموذجك والأدوات والمهارات المتاحة. استخدم prompt محددًا يسهل التحقق من نتيجته:

      اختر واجهتك

      يأتي Hermes بواجهتين للطرفية: واجهة CLI الكلاسيكية المبنية على prompt_toolkit، وواجهة TUI أحدث تتضمن نوافذ منبثقة (modal overlays) وتحديدًا بالماوس وإدخالًا غير حاجب (non-blocking). تتشارك الواجهتان الجلسات و slash commands والإعدادات نفسها — جرّب كلًا منهما باستخدام hermes مقابل hermes --tui.

      Summarize this repo in 5 bullets and tell me what the main entrypoint is.
      Check my current directory and tell me what looks like the main project file.
      Help me set up a clean GitHub PR workflow for this codebase.

      علامات النجاح:

      • يعرض الشعار النموذج/المزوّد الذي اخترته
      • يردّ Hermes دون أخطاء
      • يمكنه استخدام أداة عند الحاجة (الطرفية، قراءة الملفات، البحث في الويب)
      • تستمر المحادثة بشكل طبيعي لأكثر من دور واحد

      إذا نجح ذلك، فقد تجاوزت الجزء الأصعب.

      4. تحقّق من عمل الجلسات​

      قبل المتابعة، تأكد من أن استئناف الجلسة يعمل:

      hermes --continue    # Resume the most recent session
      hermes -c            # Short form

      يُفترض أن يعيدك هذا إلى الجلسة التي أجريتها للتو. إن لم يحدث ذلك، فتحقق مما إذا كنت في الـ profile نفسه وما إذا كانت الجلسة قد حُفظت فعلًا. سيكون لهذا أهمية لاحقًا عندما تتعامل مع عدة إعدادات أو أجهزة.

      5. جرّب الميزات الرئيسية​

      استخدام الطرفية (terminal)​

      ❯ What's my disk usage? Show the top 5 largest directories.

      ينفّذ الوكيل أوامر الطرفية نيابةً عنك ويعرض النتائج.

      Slash commands​

      اكتب / لعرض قائمة منسدلة بالإكمال التلقائي لجميع الأوامر:

      الأمروظيفته
      /helpيعرض جميع الأوامر المتاحة
      /toolsيسرد الأدوات المتاحة
      /modelيبدّل النماذج تفاعليًا
      /personality pirateيجرّب شخصية مرحة
      /saveيحفظ المحادثة

      الإدخال متعدد الأسطر​

      اضغط Alt+Enter أو Ctrl+J أو Shift+Enter لإضافة سطر جديد. يتطلب Shift+Enter طرفية ترسله كتسلسل مميز (Kitty / foot / WezTerm / Ghostty افتراضيًا؛ و iTerm2 / Alacritty / طرفية VS Code بعد تفعيل Kitty keyboard protocol). يعمل Alt+Enter و Ctrl+J في كل الطرفيات.

      مقاطعة الوكيل​

      إذا استغرق الوكيل وقتًا طويلًا، فاكتب رسالة جديدة واضغط Enter — سيقاطع ذلك المهمة الحالية وينتقل إلى تعليماتك الجديدة. يعمل Ctrl+C أيضًا.

      6. أضف الطبقة التالية​

      فقط بعد أن تعمل المحادثة الأساسية. اختر ما تحتاج إليه:

      بوت أو مساعد مشترك​

      hermes gateway setup    # Interactive platform configuration

      اربط Telegram أو Discord أو Slack أو WhatsApp أو Signal أو البريد الإلكتروني أو Home Assistant أو Microsoft Teams.

      الأتمتة والأدوات​

      • hermes tools — اضبط الوصول إلى الأدوات لكل منصة
      • hermes skills — تصفّح وثبّت سير عمل قابلًا لإعادة الاستخدام
      • Cron — فقط بعد استقرار إعداد البوت أو CLI

      طرفية معزولة (Sandboxed)​

      من أجل الأمان، شغّل الوكيل داخل حاوية Docker أو على خادم بعيد:

      hermes config set terminal.backend docker    # Docker isolation
      hermes config set terminal.backend ssh       # Remote server

      في sandboxes الخاصة بـ Docker، يمكنك أيضًا تفعيل egress proxy لحقن بيانات الاعتماد بحيث لا يرى الـ sandbox مفاتيح API الحقيقية الخاصة بك أبدًا — بل فقط tokens وكيل مُعمّاة (opaque) لا تعمل إلا من خلف daemon محلي يعترض اتصالات TLS. راجع Egress proxy. يتم الإعداد عبر hermes egress setup && hermes egress start؛ كما يوجّه hermes setup terminal مستخدمي Docker إليه. أما Modal و SSH و Daytona و Singularity فلم تُربط به بعد.

      الوضع الصوتي​

      # From the Hermes install directory (the curl installer placed it at
      # ~/.hermes/hermes-agent on Linux/macOS or %LOCALAPPDATA%\hermes\hermes-agent on Windows):
      cd ~/.hermes/hermes-agent
      uv pip install --python ./venv/bin/python -e ".[voice]"
      # Includes faster-whisper for free local speech-to-text

      ثم في CLI: /voice on. اضغط Ctrl+B للتسجيل. راجع الوضع الصوتي (Voice Mode).

      المهارات (Skills)​

      المهارات مستندات تعليمات تُستدعى عند الطلب، تعلّم Hermes كيفية تنفيذ مهمة محددة — النشر على Kubernetes، أو فتح GitHub PR، أو إجراء fine-tuning لنموذج، أو البحث عن صور GIF. كل مهارة عبارة عن ملف SKILL.md يتضمن اسمًا ووصفًا وإجراءً خطوة بخطوة. يقرأ الوكيل الأوصاف القصيرة دون تكلفة تُذكر، ولا يحمّل المحتوى الكامل للمهارة إلا عندما تتطلبه مهمة فعلًا، لذا فإن إضافة المهارات لا تُضخّم كل طلب.

      يأتي Hermes مع كتالوج من المهارات المضمّنة (bundled) المثبّتة مسبقًا في ~/.hermes/skills/. يمكنك إضافة المزيد من Skills Hub، أو كتابة مهاراتك الخاصة.

      التصفح والتثبيت من الـ hub:

      hermes skills browse                      # list everything available
      hermes skills search kubernetes           # find skills by keyword
      hermes skills install openai/skills/k8s   # install one (runs a security scan first)

      وسيط التثبيت هو معرّف (slug) بصيغة source/path من الـ hub — فمثلًا openai/skills/k8s تعني مهارة k8s من كتالوج OpenAI. يعرض hermes skills browse المعرّفات الدقيقة التي يجب استخدامها.

      استخدام مهارة — تصبح كل مهارة مثبّتة slash command تلقائيًا:

      /k8s deploy the staging manifest          # run the skill with a request
      /k8s                                       # load it and let Hermes ask what you need

      يعمل هذا في CLI وفي أي منصة مراسلة متصلة. لا يلزمك تثبيت كل شيء مسبقًا — إذ يختار الوكيل من تلقاء نفسه المهارة المضمّنة المناسبة أثناء المحادثة العادية عندما تتطابق مهمة مع إحداها.

      راجع نظام المهارات (Skills) لمعرفة كيفية كتابة مهاراتك الخاصة، ومجلدات المهارات الخارجية، والقائمة الكاملة لمصادر الـ hub.

      خوادم MCP​

      # Add to ~/.hermes/config.yaml
      mcp_servers:
        github:
          command: npx
          args: ["-y", "@modelcontextprotocol/server-github"]
          env:
            GITHUB_PERSONAL_ACCESS_TOKEN: "ghp_xxx"

      التكامل مع المحررات (ACP)​

      يأتي دعم ACP ضمن الإضافات القياسية [all]، لذا فإن مُثبّت curl يتضمنه بالفعل. نفّذ فقط:

      hermes acp

      (إذا ثبّتّ دون [all]، فنفّذ cd ~/.hermes/hermes-agent && uv pip install -e ".[acp]" أولًا.)

      راجع التكامل مع المحررات عبر ACP.

      أنماط الأعطال الشائعة​

      هذه هي المشكلات التي تُهدر أكبر قدر من الوقت:

      العَرَضالسبب المحتملالحل
      يفتح Hermes لكنه يعطي ردودًا فارغة أو معطوبةمصادقة المزوّد أو اختيار النموذج غير صحيحنفّذ hermes model مجددًا وتأكد من المزوّد والنموذج والمصادقة
      الـ endpoint المخصص "يعمل" لكنه يُرجع مخرجات عديمة المعنىbase URL أو اسم النموذج خاطئ، أو أنه ليس متوافقًا فعلًا مع OpenAIتحقق من الـ endpoint في عميل منفصل أولًا
      يبدأ Gateway لكن لا أحد يستطيع مراسلتهtoken البوت أو قائمة السماح (allowlist) أو إعداد المنصة غير مكتملأعد تنفيذ hermes gateway setup وتحقق من hermes gateway status
      hermes --continue لا يجد الجلسة القديمةبدّلت الـ profile أو لم تُحفظ الجلسة قطتحقق من hermes sessions list وتأكد من أنك في الـ profile الصحيح
      النموذج غير متاح أو سلوك احتياطي (fallback) غريبإعدادات التوجيه أو الاحتياطي مفرطة في الحدّةأبقِ التوجيه معطّلًا حتى يستقر المزوّد الأساسي
      hermes doctor يبلّغ عن مشكلات في الإعداداتقيم الإعدادات مفقودة أو قديمةأصلح الإعدادات، وأعد اختبار محادثة بسيطة قبل إضافة الميزات
