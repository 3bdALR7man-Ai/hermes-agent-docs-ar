      كتالوج المهارات الاختيارية (Optional)

      تأتي المهارات الاختيارية مع hermes-agent ضمن optional-skills/ لكنها غير مفعّلة افتراضيًا. ثبّتها صراحة:

      hermes skills install official/<category>/<skill>

      مثال:

      hermes skills install official/blockchain/solana
      hermes skills install official/mlops/flash-attention

      تشير كل مهارة أدناه إلى صفحة مخصّصة تحوي تعريفها الكامل وإعدادها وطريقة استخدامها.

      لإلغاء التثبيت:

      hermes skills uninstall <skill-name>

      autonomous-ai-agents​

      المهارةالوصف
      agent-merge-conflict-arbiterحَكَم محايد لحل تعارضات الدمج (merge conflicts) بين وكيلين.

      openhandsتفويض البرمجة إلى OpenHands CLI (مستقل عن النموذج، عبر LiteLLM).

      المساهمة بمهارات اختيارية​

      لإضافة مهارة اختيارية جديدة إلى المستودع:

      1. أنشئ دليلًا تحت optional-skills/<category>/<skill-name>/
      2. أضف ملف SKILL.md مع ترويسة (frontmatter) قياسية (الاسم، الوصف، الإصدار، المؤلف)
      3. أدرج أي ملفات مساندة في الأدلة الفرعية references/ أو templates/ أو scripts/
      4. قدّم pull request — ستظهر المهارة في هذا الكتالوج وتحصل على صفحة توثيق خاصة بها بمجرد الدمج
