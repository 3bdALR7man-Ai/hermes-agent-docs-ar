      Antigravity CLI

      تشغيل Antigravity CLI (agy): الإضافات، المصادقة، sandbox.

      بيانات المهارة الوصفية​

      المصدراختيارية — ثبّتها باستخدام hermes skills install official/autonomous-ai-agents/antigravity-cli

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      Antigravity CLI (agy)

      دليل تشغيل Antigravity CLI، الذي يُستدعى بالأمر agy. نفّذ كل أوامر agy عبر أداة terminal في Hermes؛ وافحص إعداداته وسجلاته باستخدام read_file. هذه المهارة مرجع + إجراء — فهي لا تُغلّف واجهة برمجية عبر الشبكة، لذا لا حاجة إلى أي مصادقة من داخل Hermes نفسه.

      متى تُستخدم​

      • تثبيت الملف التنفيذي agy أو تحديثه أو اختبار عمله بسرعة
      • تشغيل أوامر agy --print / agy -p غير التفاعلية لمرة واحدة
      • تصحيح حالة المصادقة أو الـ sandbox أو الصلاحيات أو الإضافات في Antigravity
      • قراءة إعدادات Antigravity، أو اختصارات لوحة المفاتيح، أو المحادثات، أو السجلات

      النموذج الذهني​

      يتألف Antigravity من طبقتين — حافظ على التمييز بينهما وإلا سيصبح الإرشاد خاطئًا:

      1. أوامر غلاف shell — agy help، agy install، agy plugin، agy update، agy changelog. نفّذ هذه عبر أداة terminal.
      2. أوامر شرطة مائلة تفاعلية داخل الجلسة — /config، /permissions، /skills، /agents، وغيرها. لا توجد هذه إلا داخل جلسة TUI جارية لـ agy، وليس على غلاف shell.

      يعرض agy help سطح غلاف shell، وليس أوامر الشرطة المائلة داخل الجلسة.

      المتطلبات الأساسية​

      • الملف التنفيذي agy على PATH. تحقق عبر أداة terminal: command -v agy && agy --version.
      • لا حاجة إلى متغيرات بيئة أو مفاتيح API لهذه المهارة — يدير Antigravity مصادقته الخاصة عبر keyring نظام التشغيل / تسجيل الدخول عبر المتصفح (انظر المصادقة أدناه).

      طريقة التشغيل​

      نفّذ كل أمر agy عبر أداة terminal. أمثلة:

      terminal(command="agy --version")
      terminal(command="agy help")
      terminal(command="agy plugin list")
      terminal(command="agy --print 'Summarize the repo in 3 bullets'", workdir="/path/to/project")

      لجلسة TUI تفاعلية متعددة الأدوار، شغّل agy بالوسيط pty=true (مع tmux للالتقاط/المراقبة)، وهو نفس النمط الذي تستخدمه مهارتا codex / claude-code. أما لاختبارات التشغيل السريعة والمطالبات المكتوبة مسبقًا، فضّل agy --print (غير تفاعلي).

      لفحص ملفات Antigravity نفسها، استخدم read_file على المسارات تحت "المسارات الأساسية" أدناه — لا تستخدم cat عبر الطرفية.

      أنماط التفويض​

      agy هو backend وكيل برمجي (coding agent) من نفس عائلة codex / claude-code، لذا تنطبق عليه أنماط التفويض نفسها. استخدم هذه الأنماط عند إسناد عمل حقيقي (ميزات، إصلاحات، مراجعات، رأي ثانٍ) إلى Antigravity، لا لمجرد اختبار سريع.

      تشغيل لمرة واحدة (مفضّل للمطالبات المكتوبة مسبقًا والآراء الثانية)​

      terminal(command="agy -p 'Review this diff for bugs and security issues' --model 'Gemini 3.1 Pro (High)'", workdir="/path/to/repo", timeout=300)

      -p غير تفاعلي: ينفّذ المطالبة ثم يخرج. اختر المحرك عبر --model (نفّذ agy models للحصول على نصوص العرض الدقيقة، مثل 'Gemini 3.1 Pro (High)'، 'Claude Opus 4.6 (Thinking)'). أضف جذور سياق إضافية بتكرار --add-dir.

      التشغيلات الطويلة / المحدودة (الاختبارات، البناء، التغييرات متعددة الملفات)​

      شغّلها في الخلفية واحصل على إشعار عند الاكتمال، بنفس طريقة مهارة codex:

      terminal(command="agy -p 'Implement the change described in TASK.md and run the tests' --dangerously-skip-permissions", workdir="/path/to/repo", background=true, notify_on_complete=true)
      # then: process(action="poll"/"log"/"wait", session_id=<id>)

      تفاعلي متعدد الأدوار (PTY + tmux)​

      لجلسة حوارية، شغّل agy -i (أو agy مجردة) تحت pty=true مع tmux لأوامر capture-pane / send-keys، وهو تمامًا النمط الموثّق في مهارتَي codex / claude-code. استأنف لاحقًا بـ --continue / -c أو بتحديد --conversation <id>.

      نُسخ متوازية (تفريع batch لمهام فرعية / worktree)​

      أنشئ worktree واحد لكل مهمة وشغّل نسخة agy -p مستقلة في كل منها (في الخلفية)، ثم اجمع النتائج — وهو نفس أسلوب تفريع worktree الذي تستخدمه مهارة codex لإصلاح المهام الدفعية. اضبط مستوى التوازي بما يتحمّله الجهاز وقدرتك على المراجعة.

      ملاحظة حول المخرجات والتحديد الزمني (تختلف عن Claude Code)​

      • يُعيد agy -p نصًا خامًا فقط — لا يوجد --output-format json ولا مغلّف نتائج يحتوي session_id / التكلفة / عدد الأدوار. حلّل stdout مباشرة؛ لا تتوقع كائن JSON.
      • لا يوجد --max-turns. يُحدَّد تشغيل الطباعة بـ --print-timeout (الافتراضي 5m). ارفعه للمهام الطويلة: --print-timeout 20m. اقرنه مع terminal ذات الخيار timeout= حتى لا يقطع الاستدعاء الخارجي التشغيل مبكرًا.

      حدود التنسيق (Orchestration)​

      Antigravity هو backend تنفيذ عامل أو مراجع رأي ثالث — تفصيل تنفيذي يملكه الوكيل/الـ profile الذي يشغّل المهمة، وليس عنصر تنسيق أساسي (first-class orchestration primitive). لا تضع agy على لوحة Kanban كبطاقة مستقلة ولا تعامله كطبقة تنسيق؛ وجّه العمل عبر مخطط المهام العادي ودع العامل المُسند يختار agy (مقابل codex/claude-code/الأدوات المباشرة) كأسلوبه. استخدمه صراحة فقط عندما يطلب المستخدم ذلك، أو عندما يُضبط عامل ليُغلّفه، أو عندما تريد تدقيقًا مستقلًا من عائلة Gemini على خطة أو diff وكيل آخر.

      المسارات الأساسية​

      • الملف التنفيذي / نقطة الدخول: agy
      • مجلد بيانات التطبيق: ~/.gemini/antigravity-cli/
      • ملف الإعدادات: ~/.gemini/antigravity-cli/settings.json
      • ملف اختصارات لوحة المفاتيح: ~/.gemini/antigravity-cli/keybindings.json
      • السجلات: ~/.gemini/antigravity-cli/log/cli-*.log
      • المحادثات: ~/.gemini/antigravity-cli/conversations/
      • مخرجات brain: ~/.gemini/antigravity-cli/brain/
      • السجل التاريخي: ~/.gemini/antigravity-cli/history.jsonl
      • ملفات تهيئة الإضافات: ~/.gemini/antigravity-cli/plugins/<plugin_name>/

      مرجع سريع​

      أوامر الغلاف (wrapper)​

      • agy changelog
      • agy help
      • agy install
      • agy plugin / agy plugins
      • agy update

      خيارات مفيدة​

      • --add-dir
      • --continue / -c
      • --conversation
      • --dangerously-skip-permissions
      • --print / -p
      • --print-timeout
      • --prompt
      • --prompt-interactive / -i
      • --sandbox
      • --log-file
      • --version

      أوامر إضافات فرعية (agy plugin --help)​

      • list، import [source]، install <target>، uninstall <name>، enable <name>، disable <name>، validate [path]، link <mp> <target>، help

      خيارات التثبيت (agy install --help)​

      • --dir، --skip-aliases، --skip-path

      أوامر الشرطة المائلة داخل الجلسة​

      • التحكم بالمحادثة: /resume (/switch)، /rewind (/undo)، /rename <name>، /clear، /fork، /reset، /new
      • الإعدادات والأدوات: /config، /settings، /permissions، /model، /keybindings، /statusline، /tasks، /skills، /mcp، /open <path>، /usage، /logout، /agents
      • مساعدات المطالبة: @ إكمال تلقائي للمسارات، esc esc يمسح المطالبة (عند عدم البث)، ! ينفّذ أمر طرفية مباشرة، ? يفتح المساعدة

      الإعدادات والصلاحيات​

      مفاتيح إعدادات شائعة (settings.json)​

      • allowNonWorkspaceAccess
      • colorScheme
      • permissions.allow
      • trustedWorkspaces

      أوضاع الصلاحيات​

      request-review، always-proceed، strict، proceed-in-sandbox.

      سلوك الـ sandbox​

      • enableTerminalSandbox قيمة منطقية في settings.json؛ الافتراضي false.
      • يمكن لتجاوزات وقت الإطلاق (--sandbox، --dangerously-skip-permissions) أن تتجاوز الإعدادات الدائمة للجلسة الحالية.

      سلوك المصادقة​

      • تجرّب الـ CLI أولًا keyring نظام التشغيل الآمن.
      • في حال عدم وجود جلسة محفوظة، تعود إلى تسجيل الدخول عبر Google في المتصفح.
      • محليًا تفتح المتصفح الافتراضي؛ وعبر SSH تطبع رابط تفويض وتنتظر لصق رمز المصادقة.
      • /logout يحذف بيانات الاعتماد المحفوظة.

      الإضافات (Plugins)​

      • تُهيَّأ الإضافات تحت ~/.gemini/antigravity-cli/plugins/<plugin_name>/.
      • يمكنها تجميع مهارات وعملاء وقواعد وخوادم MCP وhooks.
      • عودة agy plugin list بلا إضافات مستوردة حالة فارغة صالحة.

      المزالق​

      • يعرض agy help أوامر الغلاف، لا أوامر الشرطة المائلة التفاعلية.
      • agy --version هو فحص الإصدار الآمن غير التفاعلي؛ أما agy version فتفاعلي وقد يفشل بلا TTY حقيقي.
      • أول مكان تفحصه عند الإخفاقات: ~/.gemini/antigravity-cli/log/cli-*.log (اقرأه بـ read_file).
      • لا تخلط بين إعدادات JSON الدائمة وتجاوزات وقت الإطلاق.
      • ~/.gemini/antigravity-cli/bin/agentapi هو غلاف رقيق لـ agy agentapi.
      • على WSL، يعتمد تخزين الرموز على الملفات، لذا مشاكل المصادقة عادة ما تكون مشاكل ملفات/حالة محلية، لا مشاكل متصفح فقط.
      • يمكن أن تعتمد هوية مساحة العمل على مجلد الإطلاق وعلامة المشروع .antigravitycli.
      • يطبع agy -p نصًا خامًا فقط — لا --output-format json ولا مغلّف نتائج. لا تحاول تحليل كائن JSON منه (بخلاف claude-code).
      • حدّد تشغيلات الطباعة بـ --print-timeout (الافتراضي 5m)، لا بـ --max-turns (غير موجود في agy).

      التحقق​

      تأكد من أن التثبيت حقيقي وقابل للاستخدام، كل ذلك عبر أداة terminal (اقرأ الملفات بـ read_file):

      1. terminal(command="command -v agy")
      2. terminal(command="agy --version")
      3. terminal(command="agy help")
      4. terminal(command="agy plugin list")
      5. read_file على ~/.gemini/antigravity-cli/settings.json
      6. read_file على أحدث ~/.gemini/antigravity-cli/log/cli-*.log
      7. عند الحاجة، read_file على ~/.gemini/antigravity-cli/keybindings.json
