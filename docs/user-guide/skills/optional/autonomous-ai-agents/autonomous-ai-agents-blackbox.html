      Blackbox

      فوّض مهام البرمجة إلى Blackbox AI، الـ CLI متعدد النماذج.

      بيانات المهارة الوصفية​

      المصدراختيارية — ثبّتها باستخدام hermes skills install official/autonomous-ai-agents/blackbox
      المسارoptional-skills/autonomous-ai-agents/blackbox

      المؤلفHermes Agent (Nous Research)
      الترخيصMIT

      الوسومCoding-Agent, Blackbox, Multi-Agent, Judge, Multi-Model

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      Blackbox CLI

      فوّض مهام البرمجة إلى Blackbox AI عبر طرفية Hermes. Blackbox هو CLI لوكيل برمجي متعدد النماذج يوزّع المهام على عدة نماذج لغوية كبيرة (Claude، Codex، Gemini، Blackbox Pro) ويستخدم حكمًا (judge) لاختيار أفضل تنفيذ.

      الـ CLI (حزمة npm باسم @blackbox_ai/blackbox-cli، والملف التنفيذي blackbox) هو وكيل برمجي مكتوب بـ TypeScript (متفرّع عن Gemini CLI) ويدعم الجلسات التفاعلية، وتنفيذ مهام لمرة واحدة غير تفاعلي، ونقاط الحفظ (checkpointing)، وMCP، والتبديل بين نماذج الرؤية.

      المتطلبات الأساسية​

      • Node.js 20+ مثبّت
      • Blackbox CLI مثبّت: npm install -g @blackbox_ai/blackbox-cli (الملف التنفيذي: blackbox)
      • مفتاح API من app.blackbox.ai/dashboard
      • مضبوط: نفّذ blackbox configure وأدخل مفتاح API الخاص بك
      • استخدم pty=true في استدعاءات الطرفية — فـ Blackbox CLI تطبيق طرفية تفاعلي

      المهام لمرة واحدة (One-Shot)​

      terminal(command="blackbox --prompt 'Add JWT authentication with refresh tokens to the Express API'", workdir="/path/to/project", pty=true)

      لعمل سريع ومؤقت:

      terminal(command="cd $(mktemp -d) && git init && blackbox --prompt 'Build a REST API for todos with SQLite'", pty=true)

      وضع الخلفية (المهام الطويلة)​

      للمهام التي تستغرق دقائق، استخدم وضع الخلفية حتى تتمكن من مراقبة التقدم:

      # Start in background with PTY
      terminal(command="blackbox --prompt 'Refactor the auth module to use OAuth 2.0'", workdir="~/project", background=true, pty=true)
      # Returns session_id

      # Monitor progress
      process(action="poll", session_id="<id>")
      process(action="log", session_id="<id>")

      # Send input if Blackbox asks a question
      process(action="submit", session_id="<id>", data="yes")

      # Kill if needed
      process(action="kill", session_id="<id>")

      نقاط الحفظ (Checkpoints) والاستئناف​

      يحتوي Blackbox CLI على دعم مدمج لنقاط الحفظ لإيقاف المهام مؤقتًا واستئنافها:

      # After a task completes, Blackbox shows a checkpoint tag
      # Resume with a follow-up task:
      terminal(command="blackbox --resume-checkpoint 'task-abc123-2026-03-06' --prompt 'Now add rate limiting to the endpoints'", workdir="~/project", pty=true)

      أوامر الجلسة​

      أثناء جلسة تفاعلية، استخدم هذه الأوامر:

      الأمرالأثر
      /compressتقليص سجل المحادثة لتوفير token
      /clearمسح السجل والبدء من جديد
      /statsعرض استهلاك token الحالي
      Ctrl+Cإلغاء العملية الحالية

      مراجعات PR​

      استنسخ إلى مجلد مؤقت لتجنّب تعديل شجرة العمل الحالية:

      terminal(command="REVIEW=$(mktemp -d) && git clone https://github.com/user/repo.git $REVIEW && cd $REVIEW && gh pr checkout 42 && blackbox --prompt 'Review this PR against main. Check for bugs, security issues, and code quality.'", pty=true)

      العمل المتوازي​

      استدعِ عدة نُسخ من Blackbox لمهام مستقلة:

      terminal(command="blackbox --prompt 'Fix the login bug'", workdir="/tmp/issue-1", background=true, pty=true)
      terminal(command="blackbox --prompt 'Add unit tests for auth'", workdir="/tmp/issue-2", background=true, pty=true)

      # Monitor all
      process(action="list")

      وضع تعدد النماذج​

      الميزة الفريدة لـ Blackbox هي تشغيل المهمة نفسها عبر عدة نماذج ثم الحكم على النتائج. اضبط النماذج التي تريد استخدامها عبر blackbox configure — اختر عدة مزوّدين لتفعيل سير عمل Chairman/judge حيث يقيّم الـ CLI مخرجات نماذج مختلفة ويختار الأفضل.

      الخيارات الرئيسية​

      الخيارالأثر
      --prompt "task" (-p)تنفيذ غير تفاعلي لمرة واحدة
      --resume-checkpoint "tag"استئناف من نقطة حفظ محفوظة
      --yolo (-y)الموافقة التلقائية على كل الإجراءات والتبديلات بين النماذج
      --vlm-switch-mode <mode>معالجة الصور: once أو session أو persist
      -c, --checkpointingتفعيل حفظ نقاط تعديل الملفات
      blackbox configureتغيير الإعدادات والمزوّدين والنماذج
      blackbox updateتحديث الـ CLI إلى أحدث إصدار
      blackbox mcpإدارة خوادم MCP
      blackbox extensionsإدارة إضافات الـ CLI
      blackbox voice <action> / blackbox shortcutضبط الإدخال الصوتي / اختصار b

      دعم الرؤية​

      يكتشف Blackbox الصور في المدخلات تلقائيًا ويمكنه التبديل إلى التحليل متعدد الوسائط. أوضاع VLM:

      • "once" — التبديل للاستعلام الحالي فقط
      • "session" — التبديل للجلسة كاملة
      • "persist" — البقاء على النموذج الحالي (بلا تبديل)

      حدود Token​

      تحكّم في استهلاك token عبر .blackboxcli/settings.json:

      {
        "sessionTokenLimit": 32000
      }

      القواعد​

      1. استخدم دائمًا pty=true — فـ Blackbox CLI تطبيق طرفية تفاعلي وسيتجمد بلا PTY
      2. استخدم workdir — لإبقاء الوكيل مركّزًا على المجلد الصحيح
      3. استخدم الخلفية للمهام الطويلة — استخدم background=true وراقب عبر أداة process
      4. لا تتدخل — راقب عبر poll/log، ولا تُنهِ الجلسات لمجرد أنها بطيئة
      5. أبلغ عن النتائج — بعد الاكتمال، تحقّق مما تغيّر ولخّصه للمستخدم
      6. الرصيد يكلّف مالًا — يستخدم Blackbox نظامًا قائمًا على الرصيد (credits)؛ ووضع تعدد النماذج يستهلكه أسرع
      7. تحقّق من المتطلبات الأساسية — تأكد من تثبيت blackbox CLI قبل محاولة التفويض
