      FastMCP

      ابنِ خوادم MCP بلغة Python واختبرها وانشرها.

      بيانات المهارة الوصفية​

      المصدراختيارية — ثبّتها باستخدام hermes skills install official/mcp/fastmcp

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      FastMCP

      ابنِ خوادم MCP بلغة Python باستخدام FastMCP، وتحقّق منها محليًا، وثبّتها في عملاء MCP، وانشرها كنقاط نهاية HTTP.

      متى تُستخدم​

      استخدم هذه المهارة عندما تكون المهمة:

      • إنشاء خادم MCP جديد بلغة Python
      • تغليف واجهة برمجية، أو قاعدة بيانات، أو CLI، أو سير معالجة ملفات كأدوات MCP
      • عرض موارد (resources) أو prompts بالإضافة إلى الأدوات
      • اختبار سريع لخادم باستخدام FastMCP CLI قبل ربطه بـ Hermes أو عميل آخر
      • تثبيت خادم في Claude Code أو Claude Desktop أو Cursor أو عميل MCP مشابه
      • تجهيز مستودع خادم FastMCP للنشر عبر HTTP

      استخدم native-mcp عندما يكون الخادم موجودًا بالفعل ويحتاج فقط إلى ربطه بـ Hermes. استخدم mcporter عندما يكون الهدف الوصول عبر CLI بشكل مخصّص إلى خادم MCP موجود بدلًا من بناء واحد.

      المتطلبات المسبقة​

      ثبّت FastMCP في بيئة العمل أولًا:

      pip install fastmcp
      fastmcp version

      بالنسبة لقالب API، ثبّت httpx إن لم يكن موجودًا بالفعل:

      pip install httpx

      الملفات المضمّنة​

      القوالب​

      • templates/api_wrapper.py - غلاف REST API مع دعم ترويسة المصادقة
      • templates/database_server.py - خادم استعلامات SQLite للقراءة فقط
      • templates/file_processor.py - خادم فحص وبحث في الملفات النصية

      السكربتات​

      • scripts/scaffold_fastmcp.py - نسخ قالب بداية واستبدال العنصر النائب لاسم الخادم

      المراجع​

      • references/fastmcp-cli.md - سير عمل FastMCP CLI، وأهداف التثبيت، وفحوصات النشر

      سير العمل​

      1. اختر أصغر شكل قابل للتطبيق للخادم​

      اختر أضيق نطاق مفيد أولًا:

      • غلاف API: ابدأ بـ 1 إلى 3 نقاط نهاية عالية القيمة، لا الواجهة البرمجية كاملة
      • خادم قاعدة بيانات: اعرض استكشافًا للقراءة فقط ومسار استعلام مقيّد
      • معالج ملفات: اعرض عمليات حتمية بمعطيات مسار صريحة
      • prompts/resources: أضِفها فقط عندما يحتاج العميل قوالب prompt قابلة لإعادة الاستخدام أو مستندات قابلة للاكتشاف

      فضّل خادمًا نحيفًا بأسماء ووثائق دوال (docstrings) ومخططات (schemas) جيدة على خادم كبير بأدوات غامضة.

      2. أنشئ الهيكل من قالب​

      انسخ قالبًا مباشرة أو استخدم مساعد إنشاء الهيكل (scaffold):

      python ~/.hermes/skills/mcp/fastmcp/scripts/scaffold_fastmcp.py \
        --template api_wrapper \
        --name "Acme API" \
        --output ./acme_server.py

      القوالب المتاحة:

      python ~/.hermes/skills/mcp/fastmcp/scripts/scaffold_fastmcp.py --list

      إذا كنت تنسخ يدويًا، استبدل __SERVER_NAME__ باسم خادم حقيقي.

      3. نفّذ الأدوات أولًا​

      ابدأ بدوال @mcp.tool قبل إضافة الموارد أو الـ prompts.

      قواعد تصميم الأدوات:

      • امنح كل أداة اسمًا محدّدًا مبنيًا على فعل
      • اكتب وثائق الدوال (docstrings) كأوصاف أدوات موجّهة للمستخدم
      • أبقِ المعطيات صريحة ومحدّدة النوع
      • أعِد بيانات مُنظّمة وآمنة لصيغة JSON حيثما أمكن
      • تحقّق من المدخلات غير الآمنة مبكرًا
      • فضّل السلوك للقراءة فقط افتراضيًا في الإصدارات الأولى

      أمثلة جيدة على أدوات:

      • get_customer
      • search_tickets
      • describe_table
      • summarize_text_file

      أمثلة ضعيفة على أدوات:

      • run
      • process
      • do_thing

      4. أضِف الموارد والـ prompts فقط عندما تكون مفيدة​

      أضِف @mcp.resource عندما يستفيد العميل من جلب محتوى مستقر للقراءة فقط مثل المخططات، أو مستندات السياسات، أو التقارير المُولَّدة.

      أضِف @mcp.prompt عندما ينبغي للخادم توفير قالب prompt قابل لإعادة الاستخدام لسير عمل معروف.

      لا تحوّل كل مستند إلى prompt. فضّل:

      • الأدوات للإجراءات
      • الموارد لاسترجاع البيانات/المستندات
      • الـ prompts للتعليمات القابلة لإعادة الاستخدام لـ LLM

      5. اختبر الخادم قبل دمجه في أي مكان​

      استخدم FastMCP CLI للتحقق المحلي:

      fastmcp inspect acme_server.py:mcp
      fastmcp list acme_server.py --json
      fastmcp call acme_server.py search_resources query=router limit=5 --json

      للتصحيح التكراري السريع، شغّل الخادم محليًا:

      fastmcp run acme_server.py:mcp

      لاختبار نقل HTTP محليًا:

      fastmcp run acme_server.py:mcp --transport http --host 127.0.0.1 --port 8000
      fastmcp list http://127.0.0.1:8000/mcp --json
      fastmcp call http://127.0.0.1:8000/mcp search_resources query=router --json

      شغّل دائمًا استدعاء fastmcp call حقيقيًا واحدًا على الأقل مقابل كل أداة جديدة قبل الادّعاء بأن الخادم يعمل.

      6. ثبّته في عميل عندما ينجح التحقق المحلي​

      يستطيع FastMCP تسجيل الخادم لدى عملاء MCP المدعومين:

      fastmcp install claude-code acme_server.py
      fastmcp install claude-desktop acme_server.py
      fastmcp install cursor acme_server.py -e .

      استخدم fastmcp discover لفحص خوادم MCP المُسمّاة المُعدَّة بالفعل على الجهاز.

      عندما يكون الهدف التكامل مع Hermes، إما:

      • اضبط الخادم في ~/.hermes/config.yaml باستخدام مهارة native-mcp، أو
      • استمر في استخدام أوامر FastMCP CLI أثناء التطوير حتى تستقر الواجهة

      7. انشر بعد استقرار العقد المحلي​

      للاستضافة المُدارة، يُعدّ Prefect Horizon هو المسار الذي توثّقه FastMCP بشكل مباشر أكثر من غيره. قبل النشر:

      fastmcp inspect acme_server.py:mcp

      تأكّد من أن المستودع يحتوي على:

      • ملف Python يحوي كائن خادم FastMCP
      • requirements.txt أو pyproject.toml
      • أي توثيق لمتغيرات البيئة اللازمة للنشر

      للاستضافة العامة عبر HTTP، تحقّق من نقل HTTP محليًا أولًا، ثم انشر على أي منصة متوافقة مع Python يمكنها عرض منفذ الخادم.

      أنماط شائعة​

      نمط غلاف API​

      استخدمه عند عرض واجهة REST أو HTTP كأدوات MCP.

      الشريحة الأولى المُوصى بها:

      • مسار قراءة واحد
      • مسار سرد/بحث واحد
      • فحص صحة اختياري

      ملاحظات التنفيذ:

      • أبقِ المصادقة في متغيرات البيئة، لا مُرمَّزة مباشرة (hardcoded)
      • مركِز منطق الطلبات في مساعد واحد
      • اعرض أخطاء الواجهة البرمجية بسياق موجز
      • وحِّد حمولات المصدر (upstream) غير المتّسقة قبل إعادتها

      ابدأ من templates/api_wrapper.py.

      نمط قاعدة البيانات​

      استخدمه عند عرض قدرات استعلام وفحص آمنة.

      الشريحة الأولى المُوصى بها:

      • list_tables
      • describe_table
      • أداة استعلام قراءة واحدة مقيّدة

      ملاحظات التنفيذ:

      • اجعل الوصول لقاعدة البيانات للقراءة فقط افتراضيًا
      • ارفض أي SQL ليس SELECT في الإصدارات الأولى
      • حدّ عدد الصفوف
      • أعِد الصفوف مع أسماء الأعمدة

      ابدأ من templates/database_server.py.

      نمط معالج الملفات​

      استخدمه عندما يحتاج الخادم إلى فحص أو تحويل ملفات عند الطلب.

      الشريحة الأولى المُوصى بها:

      • تلخيص محتوى الملف
      • البحث داخل الملفات
      • استخراج بيانات وصفية حتمية

      ملاحظات التنفيذ:

      • اقبل مسارات ملفات صريحة
      • تحقّق من الملفات المفقودة وأخطاء الترميز
      • حدّد سقفًا للمعاينات وعدد النتائج
      • تجنّب تنفيذ أوامر خارجية (shelling out) ما لم تكن أداة خارجية معيّنة مطلوبة

      ابدأ من templates/file_processor.py.

      معيار الجودة​

      قبل تسليم خادم FastMCP، تحقّق من كل ما يلي:

      • يستورد الخادم دون أخطاء
      • ينجح fastmcp inspect <file.py:mcp>
      • ينجح fastmcp list <server spec> --json
      • كل أداة جديدة لها استدعاء fastmcp call حقيقي واحد على الأقل
      • متغيرات البيئة موثّقة
      • سطح الأدوات صغير بما يكفي لفهمه دون تخمين

      استكشاف الأخطاء وإصلاحها​

      أمر FastMCP مفقود​

      ثبّت الحزمة في البيئة النشطة:

      pip install fastmcp
      fastmcp version

      فشل fastmcp inspect​

      تحقّق من:

      • أن الملف يُستورد دون آثار جانبية تتسبّب بانهيار
      • أن نسخة FastMCP مُسمّاة بشكل صحيح في <file.py:object>
      • أن الاعتماديات الاختيارية من القالب مثبّتة

      الأداة تعمل في Python لكن ليس عبر CLI​

      شغّل:

      fastmcp list server.py --json
      fastmcp call server.py your_tool_name --json

      يكشف هذا عادةً عن عدم تطابق في الأسماء، أو معطيات مطلوبة مفقودة، أو قيم إرجاع غير قابلة للتسلسل (serialization).

      لا يستطيع Hermes رؤية الخادم المنشور​

      قد يكون الجزء الخاص ببناء الخادم صحيحًا بينما إعدادات Hermes ليست كذلك. حمّل مهارة native-mcp واضبط الخادم في ~/.hermes/config.yaml، ثم أعِد تشغيل Hermes.

      المراجع​

      لتفاصيل CLI، وأهداف التثبيت، وفحوصات النشر، اقرأ references/fastmcp-cli.md.
