      Excel Author

      ابنِ ملفات عمل مالية قابلة للتدقيق بلا واجهة رسومية عبر openpyxl.

      بيانات المهارة الوصفية​

      المصدراختيارية — ثبّتها باستخدام hermes skills install official/finance/excel-author
      المسارoptional-skills/finance/excel-author
      الإصدار1.0.0
      المؤلفAnthropic (بتكييف من Nous Research)
      الترخيصApache-2.0
      المنصاتlinux, macos, windows
      الوسومexcel, openpyxl, finance, spreadsheet, modeling
      مهارات ذات صلةxlsx, pptx-author, dcf-model, comps-analysis, lbo-model, 3-statement-model

      المرجع: ملف SKILL.md كاملًا​

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      excel-author

      أنتِج ملف .xlsx على القرص باستخدام openpyxl. اتّبع الاصطلاحات المصرفية الاحترافية أدناه بحيث يكون النموذج قابلًا للتدقيق ومرنًا وقابلًا للمراجعة من قِبل شخص آخر غير من بناه.

      مُكيَّفة من مهارتَي xlsx-author وaudit-xls من Anthropic في مستودع anthropics/financial-services. أُزيلت الفروع الخاصة بـ MCP / Office-JS / Cowork من النسختين الأصليتين — تفترض هذه المهارة بيئة Python بلا واجهة رسومية.

      عقد المخرجات​

      • اكتب إلى ./out/<name>.xlsx. أنشئ ./out/ إذا لم يكن موجودًا.
      • أعِد المسار النسبي في رسالتك النهائية حتى تتمكّن الأدوات اللاحقة من استخدامه.
      • نموذج منطقي واحد لكل ملف. لا تُلحِق بملف عمل موجود ما لم يُطلب ذلك صراحةً.

      الإعداد​

      pip install "openpyxl>=3.0"

      الاصطلاحات الأساسية (غير قابلة للتفاوض)​

      لون الخلية أزرق / أسود / أخضر​

      • أزرق (Font(color="0000FF")) — مدخل ثابت أدخله إنسان. محرّكات الإيراد، مدخلات WACC، النمو النهائي، بيانات السوق.
      • أسود (الافتراضي) — صيغة. كل خلية مشتقّة هي صيغة Excel حيّة.
      • أخضر (Font(color="006100")) — رابط إلى ورقة أخرى أو ملف خارجي.

      يتمكّن المراجع حينها من مسح الورقة برؤيته للتمييز الفوري بين ما هو افتراض وما هو محسوب.

      الصيغ لا القيم الثابتة​

      يجب أن تكون كل خلية حسابية سلسلة صيغة، وليست رقمًا محسوبًا في Python ولاصقًا كقيمة.

      # WRONG — silent bug waiting to happen
      ws["D20"] = revenue_prior_year * (1 + growth)

      # CORRECT — flexes when the user changes the assumption
      ws["D20"] = "=D19*(1+$B$8)"

      الأرقام الثابتة المسموح بها فقط:

      1. المدخلات التاريخية الخام (الإيرادات الفعلية، EBITDA المُعلَن، إلخ)
      2. عوامل الافتراض المخصَّصة للمستخدم ليعدّلها (معدلات النمو، مدخلات WACC، النمو النهائي g)
      3. بيانات السوق الحالية (سعر السهم، رصيد الدين) — مع تعليق خلية يوثّق المصدر والتاريخ

      إذا لاحظت أنك تحسب قيمة في Python وتكتب النتيجة، توقّف.

      النطاقات المسمّاة للمراجع بين الأوراق​

      استخدم النطاقات المسمّاة لأي رقم يُشار إليه من ورقة أخرى أو عرض تقديمي أو مذكّرة.

      from openpyxl.workbook.defined_name import DefinedName
      wb.defined_names["WACC"] = DefinedName("WACC", attr_text="Inputs!$C$8")
      # then elsewhere:
      calc["D30"] = "=D29/WACC"

      ورقة فحوصات التوازن​

      أضِف ورقة Checks تربط كل شيء وتُظهر TRUE/FALSE:

      • توازن الميزانية العمومية (الأصول = الالتزامات + حقوق الملكية)
      • ارتباط التدفق النقدي بتغيّر النقد من فترة إلى أخرى في الميزانية العمومية
      • ارتباط مجموع الأجزاء بالإجماليات الموحَّدة
      • عدم وجود قيم ثابتة متسلّلة داخل نطاقات الحساب

      مثال:

      checks = wb.create_sheet("Checks")
      checks["A2"] = "BS balances"
      checks["B2"] = "=IS!D20-IS!D21-IS!D22"
      checks["C2"] = "=ABS(B2)<0.01"  # TRUE/FALSE

      تعليقات الخلايا على كل مدخل ثابت​

      أضف التعليق فور إنشاء الخلية، لا لاحقًا.

      from openpyxl.comments import Comment
      ws["C2"] = 1_250_000_000
      ws["C2"].font = Font(color="0000FF")
      ws["C2"].comment = Comment("Source: 10-K FY2024, p.47, revenue line", "analyst")

      الصيغة: Source: [System/Document], [Date], [Reference], [URL if applicable].

      لا تؤجّل التوثيق أبدًا. لا تكتب TODO: add source أبدًا.

      الهيكل الأساسي: نموذج مالي نموذجي​

      from openpyxl import Workbook
      from openpyxl.styles import Font, PatternFill, Alignment, Border, Side
      from openpyxl.comments import Comment
      from openpyxl.utils import get_column_letter
      from pathlib import Path

      BLUE = Font(color="0000FF")
      BLACK = Font(color="000000")
      GREEN = Font(color="006100")
      BOLD = Font(bold=True)
      HEADER_FILL = PatternFill("solid", fgColor="1F4E79")
      HEADER_FONT = Font(color="FFFFFF", bold=True)

      wb = Workbook()

      # --- Inputs tab ---
      inp = wb.active
      inp.title = "Inputs"
      inp["A1"] = "MARKET DATA & KEY INPUTS"
      inp["A1"].font = HEADER_FONT
      inp["A1"].fill = HEADER_FILL
      inp.merge_cells("A1:C1")

      inp["B3"] = "Revenue FY2024"
      inp["C3"] = 1_250_000_000
      inp["C3"].font = BLUE
      inp["C3"].comment = Comment("Source: 10-K FY2024 p.47", "model")

      inp["B4"] = "Growth Rate"
      inp["C4"] = 0.12
      inp["C4"].font = BLUE

      # --- Calc tab ---
      calc = wb.create_sheet("DCF")
      calc["B2"] = "Projected Revenue"
      calc["C2"] = "=Inputs!C3*(1+Inputs!C4)"   # formula, black

      # --- Checks tab ---
      chk = wb.create_sheet("Checks")
      chk["A2"] = "BS balances"
      chk["B2"] = "=ABS(BS!D20-BS!D21-BS!D22)<0.01"

      Path("./out").mkdir(exist_ok=True)
      wb.save("./out/model.xlsx")

      ترويسات الأقسام بخلايا مدمجة​

      خاصية في openpyxl: عند الدمج، عيّن القيمة على الخلية العلوية اليسرى ونسّق النطاق الكامل بشكل منفصل.

      ws["A7"] = "CASH FLOW PROJECTION"
      ws["A7"].font = HEADER_FONT
      ws.merge_cells("A7:H7")
      for col in range(1, 9):  # A..H
          ws.cell(row=7, column=col).fill = HEADER_FILL

      جداول الحساسية​

      ابنِها بحلقات، لا بصيغ ثابتة لكل خلية. القواعد:

      • عدد فردي من الصفوف/الأعمدة (5×5 أو 7×7) — يضمن وجود خلية مركزية حقيقية.
      • الخلية المركزية = الحالة الأساسية. يجب أن تساوي ترويسة الصف/العمود الأوسط قيمة WACC والنمو النهائي g الفعليَّين للنموذج بحيث يساوي الناتج المركزي سعر السهم الضمني للحالة الأساسية. هذا هو فحص المنطقية.
      • ميّز الخلية المركزية بتعبئة زرقاء متوسطة ("BDD7EE") وخط عريض.
      • املأ كل خلية بصيغة إعادة حساب كاملة — لا تقريب أبدًا.
      # 5x5 WACC (rows) x terminal growth (cols) sensitivity
      wacc_axis = [0.08, 0.085, 0.09, 0.095, 0.10]        # center row = base 9.0%
      term_axis = [0.02, 0.025, 0.03, 0.035, 0.04]        # center col = base 3.0%

      start_row = 40
      ws.cell(row=start_row, column=1).value = "Implied Share Price ($)"
      ws.cell(row=start_row, column=1).font = BOLD

      for j, g in enumerate(term_axis):
          ws.cell(row=start_row+1, column=2+j).value = g
          ws.cell(row=start_row+1, column=2+j).font = BLUE

      for i, w in enumerate(wacc_axis):
          r = start_row + 2 + i
          ws.cell(row=r, column=1).value = w
          ws.cell(row=r, column=1).font = BLUE
          for j, g in enumerate(term_axis):
              c = 2 + j
              # Full DCF recalc formula (simplified for illustration).
              # In a real model this references the full projection block.
              ws.cell(row=r, column=c).value = (
                  f"=SUMPRODUCT(FCF_range,1/(1+{w})^year_offset) + "
                  f"FCF_terminal*(1+{g})/({w}-{g})/(1+{w})^terminal_year"
              )

      # Highlight center cell (base case)
      center = ws.cell(row=start_row+2+len(wacc_axis)//2,
                       column=2+len(term_axis)//2)
      center.fill = PatternFill("solid", fgColor="BDD7EE")
      center.font = BOLD

      إعادة الحساب قبل التسليم​

      يكتب openpyxl سلاسل الصيغ لكنه لا يحسبها. يُعيد Excel الحساب عند الفتح، لكن الأدوات المستهلِكة اللاحقة (سكربتات الفحص التلقائي، CI) تحتاج إلى قيم محسوبة.

      شغّل LibreOffice أو خطوة إعادة حساب مخصَّصة قبل التسليم:

      # LibreOffice headless recalc
      libreoffice --headless --calc --convert-to xlsx ./out/model.xlsx --outdir ./out/

      أو استخدم مساعد إعادة حساب بلغة Python (راجع scripts/recalc.py في هذه المهارة).

      تخطيط بنية النموذج​

      قبل كتابة أي صيغة:

      1. حدّد مواقع صفوف جميع الأقسام
      2. اكتب جميع الترويسات والتسميات
      3. اكتب جميع الفواصل بين الأقسام والصفوف الفارغة
      4. ثم اكتب الصيغ باستخدام مواقع الصفوف المثبَّتة

      يمنع هذا نمط انهيار الصيغ المتسلسل حيث يؤدي إدراج صف ترويسة بعد كتابة الصيغ إلى إزاحة كل مرجع لاحق.

      تحقّق خطوة بخطوة مع المستخدم​

      بالنسبة للنماذج الكبيرة (DCF، البيانات المالية الثلاث، LBO)، توقّف واعرض على المستخدم المخرجات الوسيطة قبل المتابعة. اكتشاف افتراض هامش خاطئ قبل بناء جداول الحساسية اللاحقة يوفّر ساعة من الوقت.

      نمط نقاط التحقّق:

      • بعد كتلة المدخلات ← اعرض المدخلات الخام، تأكّد قبل الإسقاط
      • بعد إسقاطات الإيراد ← تأكّد من الخط العلوي + النمو
      • بعد بناء FCF ← تأكّد من الجدول الكامل
      • بعد WACC ← تأكّد من المدخلات
      • بعد التقييم ← تأكّد من جسر حقوق الملكية
      • ثم ابنِ جداول الحساسية

      متى لا تستخدم هذه المهارة​

      • المستخدمون في جلسة Excel مباشرة مع توفّر Office MCP — استخدم ملف عملهم المباشر بدلًا من ذلك.
      • تصدير بيانات جدولية بحتة بلا صيغ — csv أو pandas.to_excel أبسط.
      • لوحات المعلومات/الرسوم البيانية ذات التفاعلية العالية — استخدم أداة BI حقيقية.
