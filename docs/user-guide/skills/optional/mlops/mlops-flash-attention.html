      Flash Attention

      تسريع تدريب واستدلال (inference) نماذج transformer على التسلسلات الطويلة.

      بيانات المهارة الوصفية​

      المصدراختيارية — ثبّتها باستخدام hermes skills install official/mlops/flash-attention

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      Flash Attention - آلية Attention سريعة وفعّالة في استخدام الذاكرة

      البدء السريع​

      توفّر Flash Attention تسريعًا بمقدار 2 إلى 4 مرات وتقليلًا للذاكرة بمقدار 10 إلى 20 مرة لآلية attention في نماذج transformer، عبر التبليط (tiling) والحساب المُعاد (recomputation) الواعيين بعمليات الإدخال/الإخراج (IO-aware).

      الدعم الأصلي في PyTorch (الأسهل، PyTorch 2.2+):

      import torch
      import torch.nn.functional as F

      q = torch.randn(2, 8, 512, 64, device='cuda', dtype=torch.float16)  # [batch, heads, seq, dim]
      k = torch.randn(2, 8, 512, 64, device='cuda', dtype=torch.float16)
      v = torch.randn(2, 8, 512, 64, device='cuda', dtype=torch.float16)

      # Automatically uses Flash Attention if available
      out = F.scaled_dot_product_attention(q, k, v)

      مكتبة flash-attn (ميزات أكثر):

      pip install flash-attn --no-build-isolation
      from flash_attn import flash_attn_func

      # q, k, v: [batch, seqlen, nheads, headdim]
      out = flash_attn_func(q, k, v, dropout_p=0.0, causal=True)

      سيناريوهات العمل الشائعة​

      السيناريو 1: التفعيل في نموذج PyTorch موجود​

      انسخ قائمة التحقق هذه:

      Flash Attention Integration:
      - [ ] Step 1: Check PyTorch version (≥2.2)
      - [ ] Step 2: Enable Flash Attention backend
      - [ ] Step 3: Verify speedup with profiling
      - [ ] Step 4: Test accuracy matches baseline

      الخطوة 1: تحقّق من إصدار PyTorch

      python -c "import torch; print(torch.__version__)"
      # Should be ≥2.2.0

      إذا كان الإصدار أقل من 2.2، رقِّه:

      pip install --upgrade torch

      الخطوة 2: فعِّل backend الخاص بـ Flash Attention

      استبدل آلية attention القياسية:

      # Before (standard attention)
      attn_weights = torch.softmax(q @ k.transpose(-2, -1) / math.sqrt(d_k), dim=-1)
      out = attn_weights @ v

      # After (Flash Attention)
      import torch.nn.functional as F
      out = F.scaled_dot_product_attention(q, k, v, attn_mask=mask)

      افرض استخدام backend الخاص بـ Flash Attention (أصبح torch.backends.cuda.sdp_kernel مهملًا (deprecated)؛ استخدم torch.nn.attention.sdpa_kernel مع SDPBackend):

      from torch.nn.attention import SDPBackend, sdpa_kernel

      with sdpa_kernel(SDPBackend.FLASH_ATTENTION):
          out = F.scaled_dot_product_attention(q, k, v)

      الخطوة 3: تحقّق من التسريع عبر التحليل الجانبي (profiling)

      import torch.utils.benchmark as benchmark

      def test_attention(use_flash):
          q, k, v = [torch.randn(2, 8, 2048, 64, device='cuda', dtype=torch.float16) for _ in range(3)]

          if use_flash:
              from torch.nn.attention import SDPBackend, sdpa_kernel
              with sdpa_kernel(SDPBackend.FLASH_ATTENTION):
                  return F.scaled_dot_product_attention(q, k, v)
          else:
              attn = (q @ k.transpose(-2, -1) / 8.0).softmax(dim=-1)
              return attn @ v

      # Benchmark
      t_flash = benchmark.Timer(stmt='test_attention(True)', globals=globals())
      t_standard = benchmark.Timer(stmt='test_attention(False)', globals=globals())

      print(f"Flash: {t_flash.timeit(100).mean:.3f}s")
      print(f"Standard: {t_standard.timeit(100).mean:.3f}s")

      المتوقَّع: تسريع بمقدار 2 إلى 4 مرات للتسلسلات التي تتجاوز 512 توكن.

      الخطوة 4: اختبر تطابق الدقة مع خط الأساس (baseline)

      # Compare outputs
      q, k, v = [torch.randn(1, 8, 512, 64, device='cuda', dtype=torch.float16) for _ in range(3)]

      # Flash Attention
      out_flash = F.scaled_dot_product_attention(q, k, v)

      # Standard attention
      attn_weights = torch.softmax(q @ k.transpose(-2, -1) / 8.0, dim=-1)
      out_standard = attn_weights @ v

      # Check difference
      diff = (out_flash - out_standard).abs().max()
      print(f"Max difference: {diff:.6f}")
      # Should be <1e-3 for float16

      السيناريو 2: استخدام مكتبة flash-attn للميزات المتقدمة​

      لأجل multi-query attention، أو sliding window، أو FP8 على H100.

      انسخ قائمة التحقق هذه:

      flash-attn Library Setup:
      - [ ] Step 1: Install flash-attn library
      - [ ] Step 2: Modify attention code
      - [ ] Step 3: Enable advanced features
      - [ ] Step 4: Benchmark performance

      الخطوة 1: ثبّت مكتبة flash-attn

      # NVIDIA GPUs (CUDA 12.0+)
      pip install flash-attn --no-build-isolation

      # Verify installation
      python -c "from flash_attn import flash_attn_func; print('Success')"

      الخطوة 2: عدِّل كود attention

      from flash_attn import flash_attn_func

      # Input: [batch_size, seq_len, num_heads, head_dim]
      # Transpose from [batch, heads, seq, dim] if needed
      q = q.transpose(1, 2)  # [batch, seq, heads, dim]
      k = k.transpose(1, 2)
      v = v.transpose(1, 2)

      out = flash_attn_func(
          q, k, v,
          dropout_p=0.1,
          causal=True,  # For autoregressive models
          window_size=(-1, -1),  # No sliding window
          softmax_scale=None  # Auto-scale
      )

      out = out.transpose(1, 2)  # Back to [batch, heads, seq, dim]

      الخطوة 3: فعِّل الميزات المتقدمة

      Multi-query attention (مشاركة K/V بين الرؤوس):

      from flash_attn import flash_attn_func

      # q: [batch, seq, num_q_heads, dim]
      # k, v: [batch, seq, num_kv_heads, dim]  # Fewer KV heads
      out = flash_attn_func(q, k, v)  # Automatically handles MQA

      Sliding window attention (attention محلية):

      # Only attend to window of 256 tokens before/after
      out = flash_attn_func(
          q, k, v,
          window_size=(256, 256),  # (left, right) window
          causal=True
      )

      الخطوة 4: قِس الأداء (benchmark)

      import torch
      from flash_attn import flash_attn_func
      import time

      q, k, v = [torch.randn(4, 4096, 32, 64, device='cuda', dtype=torch.float16) for _ in range(3)]

      # Warmup
      for _ in range(10):
          _ = flash_attn_func(q, k, v)

      # Benchmark
      torch.cuda.synchronize()
      start = time.time()
      for _ in range(100):
          out = flash_attn_func(q, k, v)
          torch.cuda.synchronize()
      end = time.time()

      print(f"Time per iteration: {(end-start)/100*1000:.2f}ms")
      print(f"Memory allocated: {torch.cuda.max_memory_allocated()/1e9:.2f}GB")

      السيناريو 3: تحسين FP8 على H100 (FlashAttention-3)​

      لأقصى أداء على وحدات GPU من فئة Hopper (H100).

      مهم: حزمة pip باسم flash-attn (الإصدار 2.8.x) تتضمّن FlashAttention-2 فقط — و لا تحتوي على FA3 أو نوى (kernels) FP8 الخاصة بـ H100، كما أن flash_attn_func لا يستخدم FP8 تلقائيًا. أما FlashAttention-3 فهي بنية تجريبية (beta) منفصلة تُبنى من المصدر انطلاقًا من مجلد hopper/ في المستودع، ويُصل إليها عبر وحدة flash_attn_interface. تدعم FA3 كلًا من FP16/BF16 للتمرير الأمامي والخلفي (forward+backward) أما FP8 فمدعوم للتمرير الأمامي فقط.

      FP8 Setup:
      - [ ] Step 1: Verify Hopper (H100) GPU available
      - [ ] Step 2: Build & install FlashAttention-3 from source (hopper/)
      - [ ] Step 3: Use the FA3 interface (FP8 forward)

      الخطوة 1: تحقّق من وجود GPU من طراز H100

      nvidia-smi --query-gpu=name --format=csv
      # Should show "H100" or "H800"

      الخطوة 2: ابنِ وثبِّت FlashAttention-3 من المصدر

      FA3 غير مضمَّنة في pip install flash-attn. ابنِها من المجلد الفرعي hopper/:

      git clone https://github.com/Dao-AILab/flash-attention.git
      cd flash-attention/hopper
      python setup.py install
      # (compilation is heavy and requires a CUDA toolchain + Hopper GPU)

      الخطوة 3: استخدم واجهة FA3 (التمرير الأمامي بـ FP8)

      تُوفّر FA3 وحدتها الخاصة flash_attn_interface (مختلفة عن وحدة flash_attn الخاصة بـ FA2). مسار FP8 مخصّص للتمرير الأمامي فقط ويتوقّع مدخلات من نوع float8_e4m3fn:

      import torch
      from flash_attn_interface import flash_attn_func  # FA3 (hopper build), not `flash_attn`

      # q, k, v: [batch, seqlen, nheads, headdim]
      q = torch.randn(2, 4096, 32, 64, device='cuda', dtype=torch.float16)
      k = torch.randn(2, 4096, 32, 64, device='cuda', dtype=torch.float16)
      v = torch.randn(2, 4096, 32, 64, device='cuda', dtype=torch.float16)

      # FP8 forward (inference / forward-only): cast to float8_e4m3fn
      q_fp8 = q.to(torch.float8_e4m3fn)
      k_fp8 = k.to(torch.float8_e4m3fn)
      v_fp8 = v.to(torch.float8_e4m3fn)

      out = flash_attn_func(q_fp8, k_fp8, v_fp8, causal=True)
      # FP16/BF16 forward+backward is also supported by the FA3 interface.

      متى تستخدمها مقابل البدائل​

      استخدم Flash Attention عندما:

      • تدرِّب نماذج transformer بتسلسلات تتجاوز 512 توكن
      • تشغِّل inference بسياق طويل (أكثر من 2K توكن)
      • ذاكرة GPU محدودة (نفاد الذاكرة مع attention القياسية)
      • تحتاج تسريعًا بمقدار 2 إلى 4 مرات دون فقدان في الدقة
      • تستخدم PyTorch 2.2+ أو يمكنك تثبيت flash-attn

      استخدم البدائل بدلًا من ذلك:

      • Attention القياسية: للتسلسلات الأقصر من 256 توكن (العبء الإضافي لا يستحق)
      • xFormers: عند الحاجة إلى أنواع attention أكثر (وليس السرعة فقط)
      • Attention فعّالة في الذاكرة: لـ inference على CPU (تحتاج Flash Attention إلى GPU)

      المشكلات الشائعة​

      المشكلة: ImportError: cannot import flash_attn

      ثبِّت باستخدام خيار no-build-isolation:

      pip install flash-attn --no-build-isolation

      أو ثبِّت CUDA toolkit أولًا:

      conda install cuda -c nvidia
      pip install flash-attn --no-build-isolation

      المشكلة: أبطأ من المتوقَّع (بلا تسريع)

      تزداد فائدة Flash Attention مع طول التسلسل:

      • أقل من 512 توكن: تسريع طفيف (10-20%)
      • 512 إلى 2K توكن: تسريع بمقدار 2 إلى 3 مرات

      • 2K توكن: تسريع بمقدار 3 إلى 4 مرات

      تحقّق من أن طول التسلسل كافٍ.

      المشكلة: RuntimeError: CUDA error

      تحقّق من أن GPU يدعم Flash Attention:

      import torch
      print(torch.cuda.get_device_capability())
      # Should be ≥(7, 5) for Turing+

      تتطلّب Flash Attention:

      • Ampere (A100، A10): ✅ دعم كامل
      • Turing (T4): ✅ مدعوم
      • Volta (V100): ❌ غير مدعوم

      المشكلة: تراجع في الدقة

      تحقّق من أن dtype هو float16 أو bfloat16 (وليس float32):

      q = q.to(torch.float16)  # Or torch.bfloat16

      تستخدم Flash Attention float16/bfloat16 من أجل السرعة. float32 غير مدعوم.

      مواضيع متقدمة​

      التكامل مع HuggingFace Transformers: راجع references/transformers-integration.md لتفعيل Flash Attention في نماذج BERT وGPT وLlama.

      مقاييس الأداء (benchmarks): راجع references/benchmarks.md لمقارنات تفصيلية للسرعة والذاكرة عبر وحدات GPU وأطوال التسلسل.

      متطلبات العتاد​

      • GPU: NVIDIA Ampere أو أحدث (A100، A10، A30) أو AMD MI200 أو أحدث
      • VRAM: نفس متطلبات attention القياسية (لا تزيد Flash Attention الذاكرة)
      • CUDA: 12.0+ (11.8 كحد أدنى)
      • PyTorch: 2.2+ للدعم الأصلي

      غير مدعوم: V100 (Volta)، وinference على CPU
