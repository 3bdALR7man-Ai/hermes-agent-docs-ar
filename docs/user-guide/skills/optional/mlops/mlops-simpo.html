      SimPO

      محاذاة تفضيلات (preference alignment) بدون نموذج مرجعي، أبسط من DPO.

      بيانات المهارة الوصفية​

      المصدراختيارية — ثبّتها باستخدام hermes skills install official/mlops/simpo
      المسارoptional-skills/mlops/simpo
      الإصدار1.0.0
      المؤلفOrchestra Research
      الترخيصMIT
      الاعتمادياتtorch, transformers, datasets, trl, accelerate
      المنصاتlinux, macos, windows
      الوسومPost-Training, SimPO, Preference Optimization, Alignment, DPO Alternative, Reference-Free, LLM Alignment, Efficient Training

      المرجع: ملف SKILL.md كاملًا​

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      SimPO - تحسين تفضيلات مبسّط (Simple Preference Optimization)

      البدء السريع​

      SimPO هي طريقة لتحسين التفضيلات بدون نموذج مرجعي، تتفوق على DPO دون الحاجة إلى نموذج مرجعي.

      التثبيت:

      # Create environment
      conda create -n simpo python=3.10 && conda activate simpo

      # Install PyTorch 2.2.2
      # Visit: https://pytorch.org/get-started/locally/

      # Install alignment-handbook
      git clone https://github.com/huggingface/alignment-handbook.git
      cd alignment-handbook
      python -m pip install .

      # Install Flash Attention 2
      python -m pip install flash-attn --no-build-isolation

      التدريب (Mistral 7B):

      ACCELERATE_LOG_LEVEL=info accelerate launch \
        --config_file accelerate_configs/deepspeed_zero3.yaml \
        scripts/run_simpo.py \
        training_configs/mistral-7b-base-simpo.yaml

      سير العمل الشائع​

      سير العمل 1: التدريب من نموذج أساسي (Mistral 7B)​

      الإعداد (mistral-7b-base-simpo.yaml):

      # Model
      model_name_or_path: mistralai/Mistral-7B-v0.1
      torch_dtype: bfloat16

      # Dataset
      dataset_mixer:
        HuggingFaceH4/ultrafeedback_binarized: 1.0
      dataset_splits:
        - train_prefs
        - test_prefs

      # SimPO hyperparameters
      beta: 2.0                  # Reward scaling (2.0-10.0)
      gamma_beta_ratio: 0.5       # Target margin (0-1)
      loss_type: sigmoid          # sigmoid or hinge
      sft_weight: 0.0             # Optional SFT regularization

      # Training
      learning_rate: 5e-7         # Critical: 3e-7 to 1e-6
      num_train_epochs: 1
      per_device_train_batch_size: 1
      gradient_accumulation_steps: 8

      # Output
      output_dir: ./outputs/mistral-7b-simpo

      تشغيل التدريب:

      accelerate launch --config_file accelerate_configs/deepspeed_zero3.yaml \
        scripts/run_simpo.py training_configs/mistral-7b-base-simpo.yaml

      سير العمل 2: الضبط الدقيق لنموذج instruct (Llama 3 8B)​

      الإعداد (llama3-8b-instruct-simpo.yaml):

      model_name_or_path: meta-llama/Meta-Llama-3-8B-Instruct

      dataset_mixer:
        argilla/ultrafeedback-binarized-preferences-cleaned: 1.0

      beta: 2.5
      gamma_beta_ratio: 0.5
      learning_rate: 5e-7
      sft_weight: 0.1             # Add SFT loss to preserve capabilities

      num_train_epochs: 1
      per_device_train_batch_size: 2
      gradient_accumulation_steps: 4
      output_dir: ./outputs/llama3-8b-simpo

      التشغيل:

      accelerate launch --config_file accelerate_configs/deepspeed_zero3.yaml \
        scripts/run_simpo.py training_configs/llama3-8b-instruct-simpo.yaml

      سير العمل 3: المهام كثيفة الاستدلال (معدل تعلم أقل)​

      لمهام الرياضيات/الكود:

      model_name_or_path: deepseek-ai/deepseek-math-7b-base

      dataset_mixer:
        argilla/distilabel-math-preference-dpo: 1.0

      beta: 5.0                   # Higher for stronger signal
      gamma_beta_ratio: 0.7       # Larger margin
      learning_rate: 3e-7         # Lower LR for reasoning
      sft_weight: 0.0

      num_train_epochs: 1
      per_device_train_batch_size: 1
      gradient_accumulation_steps: 16

      متى تستخدمه مقابل البدائل​

      استخدم SimPO عندما:

      • تريد تدريبًا أبسط من DPO (دون نموذج مرجعي)
      • لديك بيانات تفضيلات (أزواج مُختارة/مرفوضة)
      • تحتاج إلى أداء أفضل من DPO
      • موارد حوسبة محدودة
      • التدريب على عقدة واحدة كافٍ

      اختيار الخوارزمية:

      • SimPO: الأبسط، وأفضل أداء، دون نموذج مرجعي
      • DPO: عند الحاجة إلى نموذج مرجعي كخط أساس، أكثر تحفظًا
      • PPO: أقصى تحكم، يحتاج إلى نموذج مكافأة، وإعداد معقد
      • GRPO: تعلّم معزز فعّال من حيث الذاكرة، دون ناقد (critic)

      استخدم البدائل بدلًا من ذلك:

      • OpenRLHF: تدريب موزّع متعدد العُقد، PPO/GRPO
      • TRL: عند الحاجة إلى طرق متعددة ضمن إطار عمل واحد
      • DPO: للمقارنة مع خط أساس راسخ

      المشكلات الشائعة​

      المشكلة: تباعد الخسارة (loss divergence)

      قلّل معدل التعلم:

      learning_rate: 3e-7  # Reduce from 5e-7

      قلّل قيمة beta:

      beta: 1.0  # Reduce from 2.0

      المشكلة: النموذج ينسى القدرات

      أضف تنظيمًا (regularization) قائمًا على SFT:

      sft_weight: 0.1  # Add SFT loss component

      المشكلة: ضعف الفصل بين التفضيلات

      زِد قيمتَي beta وmargin:

      beta: 5.0            # Increase from 2.0
      gamma_beta_ratio: 0.8  # Increase from 0.5

      المشكلة: نفاد الذاكرة أثناء التدريب

      قلّل حجم الدفعة (batch size):

      per_device_train_batch_size: 1
      gradient_accumulation_steps: 16  # Maintain effective batch

      فعّل gradient checkpointing:

      gradient_checkpointing: true

      مواضيع متقدمة​

      دوال الخسارة: راجع references/loss-functions.md للاطلاع على خسارة sigmoid مقابل hinge، والصياغات الرياضية، ومتى تُستخدم كل منها.

      ضبط المعاملات الفائقة: راجع references/hyperparameters.md لدليل اختيار beta وgamma ومعدل التعلم، والتوصيات الخاصة بحجم النموذج.

      تحضير مجموعة البيانات: راجع references/datasets.md لصيغ بيانات التفضيلات، وتصفية الجودة، وإنشاء مجموعات بيانات مخصصة.

      متطلبات الأجهزة​

      • GPU: يُوصى بـ NVIDIA A100/H100
      • VRAM:
        • نموذج 7B: وحدة A100 40GB واحدة (DeepSpeed ZeRO-3)
        • نموذج 8B: وحدتا A100 40GB
        • نموذج 70B: 8 وحدات A100 80GB
      • عقدة واحدة: DeepSpeed ZeRO-3 كافٍ
      • الدقة المختلطة: يُوصى بـ BF16

      تحسين استخدام الذاكرة:

      • DeepSpeed ZeRO-3 (الإعداد الافتراضي)
      • Gradient checkpointing
      • Flash Attention 2
