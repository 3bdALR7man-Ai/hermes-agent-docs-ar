      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      HuggingFace Tokenizers - تقطيع نصي سريع لمعالجة اللغة الطبيعية

      tokenizers سريعة وجاهزة للإنتاج، تجمع بين أداء Rust وسهولة استخدام Python.

      متى تستخدم HuggingFace Tokenizers​

      استخدم HuggingFace Tokenizers عندما:

      • تحتاج إلى تقطيع نصي سريع جدًا (أقل من 20 ثانية لكل GB من النص)
      • تدرّب tokenizers مخصّصة من الصفر
      • تريد تتبّع المحاذاة (alignment) (من الـ token إلى موضعه في النص الأصلي)
      • تبني خطوط أنابيب (pipelines) إنتاجية لمعالجة اللغة الطبيعية
      • تحتاج إلى تقطيع مجموعات نصية ضخمة بكفاءة

      الأداء:

      • السرعة: أقل من 20 ثانية لتقطيع 1 GB على المعالج (CPU)
      • التنفيذ: نواة Rust مع روابط (bindings) لـ Python/Node.js
      • الكفاءة: أسرع بـ 10-100 مرة من تنفيذات Python الخالصة

      استخدم البدائل بدلًا من ذلك:

      • SentencePiece: مستقلّ عن اللغة، تستخدمه T5/ALBERT
      • tiktoken: tokenizer بخوارزمية BPE من OpenAI لنماذج GPT
      • transformers AutoTokenizer: لتحميل النماذج المدرَّبة مسبقًا فقط (يستخدم هذه المكتبة داخليًا)

      البدء السريع​

      التثبيت​

      # Install tokenizers
      pip install tokenizers

      # With transformers integration
      pip install tokenizers transformers

      تحميل tokenizer مدرَّب مسبقًا​

      from tokenizers import Tokenizer

      # Load from HuggingFace Hub
      tokenizer = Tokenizer.from_pretrained("bert-base-uncased")

      # Encode text
      output = tokenizer.encode("Hello, how are you?")
      print(output.tokens)  # ['hello', ',', 'how', 'are', 'you', '?']
      print(output.ids)     # [7592, 1010, 2129, 2024, 2017, 1029]

      # Decode back
      text = tokenizer.decode(output.ids)
      print(text)  # "hello, how are you?"

      تدريب tokenizer مخصّص بخوارزمية BPE​

      from tokenizers import Tokenizer
      from tokenizers.models import BPE
      from tokenizers.trainers import BpeTrainer
      from tokenizers.pre_tokenizers import Whitespace

      # Initialize tokenizer with BPE model
      tokenizer = Tokenizer(BPE(unk_token="[UNK]"))
      tokenizer.pre_tokenizer = Whitespace()

      # Configure trainer
      trainer = BpeTrainer(
          vocab_size=30000,
          special_tokens=["[UNK]", "[CLS]", "[SEP]", "[PAD]", "[MASK]"],
          min_frequency=2
      )

      # Train on files
      files = ["train.txt", "validation.txt"]
      tokenizer.train(files, trainer)

      # Save
      tokenizer.save("my-tokenizer.json")

      زمن التدريب: نحو 1-2 دقيقة لمجموعة نصية بحجم 100 MB، ونحو 10-20 دقيقة لحجم 1 GB

      ترميز دفعي (batch) مع الحشو (padding)​

      # Enable padding
      tokenizer.enable_padding(pad_id=3, pad_token="[PAD]")

      # Encode batch
      texts = ["Hello world", "This is a longer sentence"]
      encodings = tokenizer.encode_batch(texts)

      for encoding in encodings:
          print(encoding.ids)
      # [101, 7592, 2088, 102, 3, 3, 3]
      # [101, 2023, 2003, 1037, 2936, 6251, 102]

      خوارزميات التقطيع النصي​

      BPE (ترميز أزواج البايت)​

      كيف تعمل:

      1. ابدأ بمفردات على مستوى الأحرف
      2. ابحث عن أكثر زوج أحرف تكرارًا
      3. ادمجه في token جديد، وأضفه إلى المفردات
      4. كرّر العملية حتى الوصول إلى حجم المفردات المطلوب

      تستخدمها: GPT-2، GPT-3، RoBERTa، BART، DeBERTa

      from tokenizers import Tokenizer
      from tokenizers.models import BPE
      from tokenizers.trainers import BpeTrainer
      from tokenizers.pre_tokenizers import ByteLevel

      tokenizer = Tokenizer(BPE(unk_token="<|endoftext|>"))
      tokenizer.pre_tokenizer = ByteLevel()

      trainer = BpeTrainer(
          vocab_size=50257,
          special_tokens=["<|endoftext|>"],
          min_frequency=2
      )

      tokenizer.train(files=["data.txt"], trainer=trainer)

      المزايا:

      • تتعامل جيدًا مع الكلمات خارج المفردات (OOV) (تقسّمها إلى وحدات فرعية)
      • حجم مفردات مرن
      • جيدة للغات ذات البنية الصرفية الغنية

      المقايضات:

      • يعتمد التقطيع على ترتيب الدمج
      • قد تُقسَّم كلمات شائعة بشكل غير متوقّع

      WordPiece​

      كيف تعمل:

      1. ابدأ بمفردات على مستوى الأحرف
      2. قيِّم أزواج الدمج المحتملة: frequency(pair) / (frequency(first) × frequency(second))
      3. ادمج الزوج الأعلى تقييمًا
      4. كرّر العملية حتى الوصول إلى حجم المفردات المطلوب

      تستخدمها: BERT، DistilBERT، MobileBERT

      from tokenizers import Tokenizer
      from tokenizers.models import WordPiece
      from tokenizers.trainers import WordPieceTrainer
      from tokenizers.pre_tokenizers import Whitespace
      from tokenizers.normalizers import BertNormalizer

      tokenizer = Tokenizer(WordPiece(unk_token="[UNK]"))
      tokenizer.normalizer = BertNormalizer(lowercase=True)
      tokenizer.pre_tokenizer = Whitespace()

      trainer = WordPieceTrainer(
          vocab_size=30522,
          special_tokens=["[UNK]", "[CLS]", "[SEP]", "[PAD]", "[MASK]"],
          continuing_subword_prefix="##"
      )

      tokenizer.train(files=["corpus.txt"], trainer=trainer)

      المزايا:

      • تُعطي الأولوية لعمليات الدمج ذات المعنى (تقييم مرتفع = علاقة دلالية)
      • استُخدمت بنجاح في BERT (نتائج على أحدث مستوى)

      المقايضات:

      • تصبح الكلمات غير المعروفة [UNK] إذا لم توجد وحدة فرعية مطابقة
      • تُحفَظ المفردات فقط، لا قواعد الدمج (ملفات أكبر حجمًا)

      Unigram​

      كيف تعمل:

      1. ابدأ بمفردات كبيرة (كل السلاسل الفرعية)
      2. احسب دالة الخسارة (loss) للمجموعة النصية بالمفردات الحالية
      3. أزل الرموز (tokens) ذات الأثر الأقل على الخسارة
      4. كرّر العملية حتى الوصول إلى حجم المفردات المطلوب

      تستخدمها: ALBERT، T5، mBART، XLNet (عبر SentencePiece)

      from tokenizers import Tokenizer
      from tokenizers.models import Unigram
      from tokenizers.trainers import UnigramTrainer

      tokenizer = Tokenizer(Unigram())

      trainer = UnigramTrainer(
          vocab_size=8000,
          special_tokens=["<unk>", "<s>", "</s>"],
          unk_token="<unk>"
      )

      tokenizer.train(files=["data.txt"], trainer=trainer)

      المزايا:

      • احتمالية (تجد التقطيع الأكثر ترجيحًا)
      • تعمل جيدًا مع اللغات التي لا تفصل بين الكلمات بحدود واضحة
      • تتعامل مع سياقات لغوية متنوّعة

      المقايضات:

      • مكلفة حسابيًا عند التدريب
      • عدد أكبر من المعاملات الفائقة (hyperparameters) التي يجب ضبطها

      خط أنابيب التقطيع النصي​

      خط الأنابيب الكامل: التسوية (Normalization) ← التقطيع المبدئي (Pre-tokenization) ← النموذج ← المعالجة اللاحقة (Post-processing)

      التسوية (Normalization)​

      تنظيف النص وتوحيد صيغته:

      from tokenizers.normalizers import NFD, StripAccents, Lowercase, Sequence

      tokenizer.normalizer = Sequence([
          NFD(),           # Unicode normalization (decompose)
          Lowercase(),     # Convert to lowercase
          StripAccents()   # Remove accents
      ])

      # Input: "Héllo WORLD"
      # After normalization: "hello world"

      أدوات تسوية شائعة:

      • NFD, NFC, NFKD, NFKC - صيغ تسوية Unicode
      • Lowercase() - التحويل إلى أحرف صغيرة
      • StripAccents() - إزالة علامات النطق (é → e)
      • Strip() - إزالة المسافات البيضاء
      • Replace(pattern, content) - استبدال عبر regex

      التقطيع المبدئي (Pre-tokenization)​

      تقسيم النص إلى وحدات شبيهة بالكلمات:

      from tokenizers.pre_tokenizers import Whitespace, Punctuation, Sequence, ByteLevel

      # Split on whitespace and punctuation
      tokenizer.pre_tokenizer = Sequence([
          Whitespace(),
          Punctuation()
      ])

      # Input: "Hello, world!"
      # After pre-tokenization: ["Hello", ",", "world", "!"]

      أدوات تقطيع مبدئي شائعة:

      • Whitespace() - التقسيم عند المسافات وعلامات التبويب والأسطر الجديدة
      • ByteLevel() - تقسيم على مستوى البايت بأسلوب GPT-2
      • Punctuation() - عزل علامات الترقيم
      • Digits(individual_digits=True) - تقسيم الأرقام كلًا على حدة
      • Metaspace() - استبدال المسافات بالرمز ▁ (بأسلوب SentencePiece)

      المعالجة اللاحقة (Post-processing)​

      إضافة رموز (tokens) خاصة لمدخل النموذج:

      from tokenizers.processors import TemplateProcessing

      # BERT-style: [CLS] sentence [SEP]
      tokenizer.post_processor = TemplateProcessing(
          single="[CLS] $A [SEP]",
          pair="[CLS] $A [SEP] $B [SEP]",
          special_tokens=[
              ("[CLS]", 1),
              ("[SEP]", 2),
          ],
      )

      أنماط شائعة:

      # GPT-2: sentence <|endoftext|>
      TemplateProcessing(
          single="$A <|endoftext|>",
          special_tokens=[("<|endoftext|>", 50256)]
      )

      # RoBERTa: <s> sentence </s>
      TemplateProcessing(
          single="<s> $A </s>",
          pair="<s> $A </s> </s> $B </s>",
          special_tokens=[("<s>", 0), ("</s>", 2)]
      )

      تتبّع المحاذاة (Alignment Tracking)​

      تتبّع مواضع الـ tokens في النص الأصلي:

      output = tokenizer.encode("Hello, world!")

      # Get token offsets
      for token, offset in zip(output.tokens, output.offsets):
          start, end = offset
          print(f"{token:10} → [{start:2}, {end:2}): {text[start:end]!r}")

      # Output:
      # hello      → [ 0,  5): 'Hello'
      # ,          → [ 5,  6): ','
      # world      → [ 7, 12): 'world'
      # !          → [12, 13): '!'

      حالات الاستخدام:

      • التعرّف على الكيانات المسمّاة (ربط التنبّؤات مرة أخرى بالنص)
      • الإجابة على الأسئلة (استخراج نطاقات الإجابة)
      • تصنيف الـ tokens (محاذاة التصنيفات مع المواضع الأصلية)

      التكامل مع transformers​

      التحميل عبر AutoTokenizer​

      from transformers import AutoTokenizer

      # AutoTokenizer automatically uses fast tokenizers
      tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased")

      # Check if using fast tokenizer
      print(tokenizer.is_fast)  # True

      # Access underlying tokenizers.Tokenizer
      fast_tokenizer = tokenizer.backend_tokenizer
      print(type(fast_tokenizer))  # <class 'tokenizers.Tokenizer'>

      تحويل tokenizer مخصّص إلى صيغة transformers​

      from tokenizers import Tokenizer
      from transformers import PreTrainedTokenizerFast

      # Train custom tokenizer
      tokenizer = Tokenizer(BPE())
      # ... train tokenizer ...
      tokenizer.save("my-tokenizer.json")

      # Wrap for transformers
      transformers_tokenizer = PreTrainedTokenizerFast(
          tokenizer_file="my-tokenizer.json",
          unk_token="[UNK]",
          pad_token="[PAD]",
          cls_token="[CLS]",
          sep_token="[SEP]",
          mask_token="[MASK]"
      )

      # Use like any transformers tokenizer
      outputs = transformers_tokenizer(
          "Hello world",
          padding=True,
          truncation=True,
          max_length=512,
          return_tensors="pt"
      )

      أنماط شائعة​

      التدريب من مُكرِّر (iterator) (مجموعات بيانات كبيرة)​

      from datasets import load_dataset

      # Load dataset
      dataset = load_dataset("wikitext", "wikitext-103-raw-v1", split="train")

      # Create batch iterator
      def batch_iterator(batch_size=1000):
          for i in range(0, len(dataset), batch_size):
              yield dataset[i:i + batch_size]["text"]

      # Train tokenizer
      tokenizer.train_from_iterator(
          batch_iterator(),
          trainer=trainer,
          length=len(dataset)  # For progress bar
      )

      الأداء: يعالج 1 GB في نحو 10-20 دقيقة

      تفعيل الاقتطاع (truncation) والحشو (padding)​

      # Enable truncation
      tokenizer.enable_truncation(max_length=512)

      # Enable padding
      tokenizer.enable_padding(
          pad_id=tokenizer.token_to_id("[PAD]"),
          pad_token="[PAD]",
          length=512  # Fixed length, or None for batch max
      )

      # Encode with both
      output = tokenizer.encode("This is a long sentence that will be truncated...")
      print(len(output.ids))  # 512

      المعالجة متعددة العمليات​

      from tokenizers import Tokenizer
      from multiprocessing import Pool

      # Load tokenizer
      tokenizer = Tokenizer.from_file("tokenizer.json")

      def encode_batch(texts):
          return tokenizer.encode_batch(texts)

      # Process large corpus in parallel
      with Pool(8) as pool:
          # Split corpus into chunks
          chunk_size = 1000
          chunks = [corpus[i:i+chunk_size] for i in range(0, len(corpus), chunk_size)]

          # Encode in parallel
          results = pool.map(encode_batch, chunks)

      تسريع: 5-8× مع 8 أنوية
