      TensorRT-LLM

      مكتبة NVIDIA مفتوحة المصدر لتحسين inference نماذج LLM بأداء عالٍ على معالجات NVIDIA GPU.

      متى تستخدم TensorRT-LLM​

      استخدم TensorRT-LLM عندما:

      • تنشر على معالجات NVIDIA GPU (A100، H100، GB200)
      • تحتاج إلى أقصى إنتاجية (+24,000 token/ثانية على Llama 3)
      • تحتاج إلى زمن استجابة منخفض للتطبيقات الفورية (real-time)
      • تعمل مع نماذج مُكمَّمة (quantized) (FP8، INT4، FP4)
      • توسّع النطاق عبر عدة GPU أو عُقد

      استخدم vLLM بدلًا من ذلك عندما:

      • تحتاج إلى إعداد أبسط و API يعتمد على Python بالدرجة الأولى
      • تريد PagedAttention دون الحاجة إلى تجميع TensorRT
      • تعمل مع معالجات AMD أو عتاد من غير NVIDIA

      استخدم llama.cpp بدلًا من ذلك عندما:

      • تنشر على CPU أو Apple Silicon
      • تحتاج إلى نشر على الحافة (edge) بدون معالجات NVIDIA GPU
      • تريد صيغة تكميم GGUF الأبسط

      البدء السريع​

      التثبيت​

      # Docker (recommended) — images are on NGC (nvcr.io), not Docker Hub.
      # Replace x.y.z with the desired version (e.g. 1.2.1). Browse tags on NGC:
      # https://catalog.ngc.nvidia.com/orgs/nvidia/teams/tensorrt-llm/containers/release/tags
      docker pull nvcr.io/nvidia/tensorrt-llm/release:x.y.z

      # pip install (current stable GA)
      pip install tensorrt_llm

      # Requires CUDA 13.2.1, TensorRT 10.x, Python 3.10-3.12

      Inference أساسي​

      from tensorrt_llm import LLM, SamplingParams

      # Initialize model
      llm = LLM(model="meta-llama/Meta-Llama-3-8B")

      # Configure sampling
      sampling_params = SamplingParams(
          max_tokens=100,
          temperature=0.7,
          top_p=0.9
      )

      # Generate
      prompts = ["Explain quantum computing"]
      outputs = llm.generate(prompts, sampling_params)

      for output in outputs:
          print(output.text)

      التقديم (serving) باستخدام trtllm-serve​

      # Start server (automatic model download and compilation)
      trtllm-serve meta-llama/Meta-Llama-3-8B \
          --tp_size 4 \              # Tensor parallelism (4 GPUs)
          --max_batch_size 256 \
          --max_num_tokens 4096

      # Client request
      curl -X POST http://localhost:8000/v1/chat/completions \
        -H "Content-Type: application/json" \
        -d '{
          "model": "meta-llama/Meta-Llama-3-8B",
          "messages": [{"role": "user", "content": "Hello!"}],
          "temperature": 0.7,
          "max_tokens": 100
        }'

      الميزات الرئيسية​

      تحسينات الأداء​

      • In-flight batching: تجميع ديناميكي أثناء التوليد
      • Paged KV cache: إدارة ذاكرة فعّالة
      • Flash Attention: نوى انتباه (attention kernels) مُحسَّنة
      • Quantization: FP8، INT4، FP4 لتسريع الـ inference بمقدار 2-4×
      • CUDA graphs: تقليل تكاليف إطلاق النوى (kernel launch overhead)

      التوازي (Parallelism)​

      • Tensor parallelism (TP): تقسيم النموذج عبر عدة GPU
      • Pipeline parallelism (PP): توزيع على مستوى الطبقات
      • Expert parallelism: لنماذج Mixture-of-Experts
      • Multi-node: التوسع إلى ما بعد جهاز واحد

      ميزات متقدمة​

      • Speculative decoding: توليد أسرع باستخدام نماذج مسودة (draft models)
      • LoRA serving: نشر فعّال لعدة محوّلات (adapters)
      • Disaggregated serving: فصل مرحلتَي prefill والتوليد

      أنماط شائعة​

      نموذج مُكمَّم (FP8)​

      from tensorrt_llm import LLM

      # Load FP8 quantized model (2× faster, 50% memory)
      llm = LLM(
          model="meta-llama/Meta-Llama-3-70B",
          dtype="fp8",
          max_num_tokens=8192
      )

      # Inference same as before
      outputs = llm.generate(["Summarize this article..."])

      نشر متعدد GPU​

      # Tensor parallelism across 8 GPUs
      llm = LLM(
          model="meta-llama/Meta-Llama-3-405B",
          tensor_parallel_size=8,
          dtype="fp8"
      )

      Inference دُفعي (Batch)​

      # Process 100 prompts efficiently
      prompts = [f"Question {i}: ..." for i in range(100)]

      outputs = llm.generate(
          prompts,
          sampling_params=SamplingParams(max_tokens=200)
      )

      # Automatic in-flight batching for maximum throughput

      معايير الأداء (Benchmarks)​

      Meta Llama 3-8B (معالج H100):

      • الإنتاجية: 24,000 token/ثانية
      • زمن الاستجابة: نحو 10 مللي ثانية لكل token
      • مقارنة بـ PyTorch: أسرع بمقدار 100×

      Llama 3-70B (8× A100 80GB):

      • تكميم FP8: أسرع بمقدار 2× من FP16
      • الذاكرة: انخفاض بنسبة 50% مع FP8

      النماذج المدعومة​

      • عائلة LLaMA: Llama 2، Llama 3، CodeLlama
      • عائلة GPT: GPT-2، GPT-J، GPT-NeoX
      • Qwen: Qwen، Qwen2، QwQ
      • DeepSeek: DeepSeek-V2، DeepSeek-V3
      • Mixtral: Mixtral-8x7B، Mixtral-8x22B
      • Vision: LLaVA، Phi-3-vision
      • أكثر من 100 نموذج على HuggingFace
