      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      CLIP - Contrastive Language-Image Pre-Training

      نموذج OpenAI الذي يفهم الصور انطلاقًا من اللغة الطبيعية.

      متى تستخدم CLIP​

      استخدمه عندما:

      • تحتاج تصنيف صور بدون أمثلة تدريب (zero-shot) (بلا بيانات تدريب)
      • تحتاج تشابه/مطابقة بين الصور والنصوص
      • تحتاج بحثًا دلاليًا عن الصور
      • تحتاج فحص المحتوى (كشف المحتوى غير اللائق أو العنف)
      • تحتاج الإجابة عن أسئلة بصرية
      • تحتاج استرجاعًا عبر الوسائط (صورة←نص، نص←صورة)

      مقاييس:

      • أكثر من 25,300 نجمة على GitHub
      • مدرَّب على 400 مليون زوج صورة-نص
      • يضاهي ResNet-50 على ImageNet (zero-shot)
      • ترخيص MIT

      استخدم البدائل بدلًا من ذلك:

      • BLIP-2: كتابة توصيفات (captioning) أفضل
      • LLaVA: محادثة بصرية-لغوية
      • Segment Anything: تجزئة الصور (segmentation)

      التصنيف بدون أمثلة تدريب (zero-shot)​

      import torch
      import clip
      from PIL import Image

      # Load model
      device = "cuda" if torch.cuda.is_available() else "cpu"
      model, preprocess = clip.load("ViT-B/32", device=device)

      # Load image
      image = preprocess(Image.open("photo.jpg")).unsqueeze(0).to(device)

      # Define possible labels
      text = clip.tokenize(["a dog", "a cat", "a bird", "a car"]).to(device)

      # Compute similarity
      with torch.no_grad():
          image_features = model.encode_image(image)
          text_features = model.encode_text(text)

          # Cosine similarity
          logits_per_image, logits_per_text = model(image, text)
          probs = logits_per_image.softmax(dim=-1).cpu().numpy()

      # Print results
      labels = ["a dog", "a cat", "a bird", "a car"]
      for label, prob in zip(labels, probs[0]):
          print(f"{label}: {prob:.2%}")

      التشابه بين الصور والنصوص​

      # Compute embeddings
      image_features = model.encode_image(image)
      text_features = model.encode_text(text)

      # Normalize
      image_features /= image_features.norm(dim=-1, keepdim=True)
      text_features /= text_features.norm(dim=-1, keepdim=True)

      # Cosine similarity
      similarity = (image_features @ text_features.T).item()
      print(f"Similarity: {similarity:.4f}")

      البحث الدلالي عن الصور​

      # Index images
      image_paths = ["img1.jpg", "img2.jpg", "img3.jpg"]
      image_embeddings = []

      for img_path in image_paths:
          image = preprocess(Image.open(img_path)).unsqueeze(0).to(device)
          with torch.no_grad():
              embedding = model.encode_image(image)
              embedding /= embedding.norm(dim=-1, keepdim=True)
          image_embeddings.append(embedding)

      image_embeddings = torch.cat(image_embeddings)

      # Search with text query
      query = "a sunset over the ocean"
      text_input = clip.tokenize([query]).to(device)
      with torch.no_grad():
          text_embedding = model.encode_text(text_input)
          text_embedding /= text_embedding.norm(dim=-1, keepdim=True)

      # Find most similar images
      similarities = (text_embedding @ image_embeddings.T).squeeze(0)
      top_k = similarities.topk(3)

      for idx, score in zip(top_k.indices, top_k.values):
          print(f"{image_paths[idx]}: {score:.3f}")

      فحص المحتوى​

      # Define categories
      categories = [
          "safe for work",
          "not safe for work",
          "violent content",
          "graphic content"
      ]

      text = clip.tokenize(categories).to(device)

      # Check image
      with torch.no_grad():
          logits_per_image, _ = model(image, text)
          probs = logits_per_image.softmax(dim=-1)

      # Get classification
      max_idx = probs.argmax().item()
      max_prob = probs[0, max_idx].item()

      print(f"Category: {categories[max_idx]} ({max_prob:.2%})")

      المعالجة الدفعية (Batch Processing)​

      # Process multiple images
      images = [preprocess(Image.open(f"img{i}.jpg")) for i in range(10)]
      images = torch.stack(images).to(device)

      with torch.no_grad():
          image_features = model.encode_image(images)
          image_features /= image_features.norm(dim=-1, keepdim=True)

      # Batch text
      texts = ["a dog", "a cat", "a bird"]
      text_tokens = clip.tokenize(texts).to(device)

      with torch.no_grad():
          text_features = model.encode_text(text_tokens)
          text_features /= text_features.norm(dim=-1, keepdim=True)

      # Similarity matrix (10 images × 3 texts)
      similarities = image_features @ text_features.T
      print(similarities.shape)  # (10, 3)

      التكامل مع قواعد البيانات المتجهية (vector databases)​

      # Store CLIP embeddings in Chroma/FAISS
      import chromadb

      client = chromadb.Client()
      collection = client.create_collection("image_embeddings")

      # Add image embeddings
      for img_path, embedding in zip(image_paths, image_embeddings):
          collection.add(
              embeddings=[embedding.cpu().numpy().tolist()],
              metadatas=[{"path": img_path}],
              ids=[img_path]
          )

      # Query with text
      query = "a sunset"
      text_embedding = model.encode_text(clip.tokenize([query]))
      results = collection.query(
          query_embeddings=[text_embedding.cpu().numpy().tolist()],
          n_results=5
      )

      أفضل الممارسات​

      1. استخدم ViT-B/32 في معظم الحالات - يوازن جيدًا بين المتطلبات
      2. طبّع (normalize) الـ embeddings - مطلوب لحساب تشابه جيب التمام (cosine similarity)
      3. المعالجة الدفعية - أكثر كفاءة
      4. خزّن الـ embeddings مؤقتًا (cache) - إعادة حسابها مكلفة
      5. استخدم تسميات وصفية - لأداء zero-shot أفضل
      6. يُنصح باستخدام GPU - أسرع بمقدار 10 إلى 50 مرة
      7. عالج الصور مسبقًا (preprocess) - استخدم دالة preprocess المتوفرة

      الأداء​

      العمليةCPUGPU (V100)
      ترميز الصور~200 مللي ثانية~20 مللي ثانية
      ترميز النصوص~50 مللي ثانية~5 مللي ثانية
      حساب التشابه<1 مللي ثانية<1 مللي ثانية

      القيود​

      1. غير مناسب للمهام الدقيقة التفصيل - الأفضل للفئات العامة الواسعة
      2. يتطلّب نصًا وصفيًا - التسميات الغامضة تعطي أداءً ضعيفًا
      3. متحيّز نتيجة بيانات الويب - قد يحمل تحيّزات من مجموعة البيانات
      4. بدون مربعات إحاطة (bounding boxes) - يتعامل مع الصورة كاملة فقط
      5. فهم مكاني محدود - ضعيف في تحديد الموضع والعدّ
