      Outlines

      Outlines: توليد نصوص LLM مُقيَّد بصيغة JSON/regex/Pydantic.

      بيانات المهارة الوصفية​

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      Outlines: التوليد المُقيَّد للنص

      متى تستخدم هذه المهارة​

      استخدم Outlines عندما تحتاج إلى:

      • ضمان صحة بنية JSON/XML/الكود أثناء التوليد
      • استخدام نماذج Pydantic لمخرجات آمنة النوع (type-safe)
      • دعم النماذج المحلية (Transformers، llama.cpp، vLLM)
      • تعظيم سرعة الـ inference بتوليد مُقيَّد بلا أي تكلفة إضافية
      • التوليد وفق مخططات JSON تلقائيًا
      • التحكم في أخذ عينات token على مستوى القواعد النحوية (grammar)

      نجوم GitHub: أكثر من 12,000 | من: dottxt.ai (المعروفة سابقًا باسم .txt)

      ملاحظة حول الواجهة (Outlines 1.x): تستهدف هذه المهارة واجهة الإصدار v1 الحالية. المساعدات السابقة للإصدار 1.0 (outlines.models.transformers(...)، outlines.generate.json/choice/regex/...) قد أُزيلت. في الإصدار v1 تُنشئ النموذج باستخدام outlines.from_transformers(...) (أو from_vllm، from_llamacpp، from_openai) ثم تستدعي النموذج مباشرةً مع نوع مخرجات: model(prompt, output_type). تُعاد مخرجات JSON/Pydantic كـ سلسلة JSON نصية — تحقق منها باستخدام YourModel.model_validate_json(result).

      التثبيت​

      # Base installation
      pip install outlines

      # With specific backends
      pip install outlines transformers  # Hugging Face models
      pip install outlines llama-cpp-python  # llama.cpp
      pip install outlines vllm  # vLLM for high-throughput

      البدء السريع​

      مثال أساسي: التصنيف​

      import outlines
      from typing import Literal
      from transformers import AutoModelForCausalLM, AutoTokenizer

      MODEL_NAME = "microsoft/Phi-3-mini-4k-instruct"

      # v1: wrap a Transformers model + tokenizer
      model = outlines.from_transformers(
          AutoModelForCausalLM.from_pretrained(MODEL_NAME, device_map="auto"),
          AutoTokenizer.from_pretrained(MODEL_NAME),
      )

      # Call the model directly with an output type
      prompt = "Sentiment of 'This product is amazing!': "
      sentiment = model(prompt, Literal["positive", "negative", "neutral"])

      print(sentiment)  # "positive" (guaranteed one of these)

      مع نماذج Pydantic​

      from pydantic import BaseModel
      import outlines
      from transformers import AutoModelForCausalLM, AutoTokenizer

      class User(BaseModel):
          name: str
          age: int
          email: str

      MODEL_NAME = "microsoft/Phi-3-mini-4k-instruct"
      model = outlines.from_transformers(
          AutoModelForCausalLM.from_pretrained(MODEL_NAME, device_map="auto"),
          AutoTokenizer.from_pretrained(MODEL_NAME),
      )

      # Generate structured output (returns a JSON string)
      prompt = "Extract user: John Doe, 30 years old, john@example.com"
      result = model(prompt, User, max_new_tokens=200)

      user = User.model_validate_json(result)  # parse into the Pydantic model
      print(user.name)   # "John Doe"
      print(user.age)    # 30
      print(user.email)  # "john@example.com"

      المفاهيم الأساسية​

      1. أخذ عينات token مُقيَّد​

      يقيّد Outlines توليد الـ token على مستوى logit باستخدام آلة حالات (automaton) مُصرَّفة (compiled) من نوع مخرجاتك.

      كيف يعمل:

      1. تحويل نوع المخرجات (JSON/Pydantic/regex/Literal) إلى مخطط (schema) أو قواعد نحوية (grammar)
      2. تصريف (compile) القواعد النحوية إلى آلة حالات على مستوى الـ token
      3. تصفية الـ tokens غير الصالحة في كل خطوة أثناء التوليد
      4. التقديم السريع (fast-forward) عندما يوجد token صالح واحد فقط

      الفوائد:

      • بلا أي تكلفة إضافية: تجري التصفية على مستوى الـ token
      • تحسين السرعة: تقديم سريع عبر المسارات الحتمية
      • صلاحية مضمونة: يستحيل صدور مخرجات غير صالحة
      import outlines
      from pydantic import BaseModel
      from transformers import AutoModelForCausalLM, AutoTokenizer

      class Person(BaseModel):
          name: str
          age: int

      model = outlines.from_transformers(
          AutoModelForCausalLM.from_pretrained("microsoft/Phi-3-mini-4k-instruct", device_map="auto"),
          AutoTokenizer.from_pretrained("microsoft/Phi-3-mini-4k-instruct"),
      )

      result = model("Generate person: Alice, 25", Person)
      person = Person.model_validate_json(result)

      2. أنواع المخرجات​

      في الإصدار v1، تمرّر نوع المخرجات المطلوب مباشرةً كوسيط ثانٍ.

      الاختيار المتعدد (Literal)​

      from typing import Literal

      sentiment = model("Review: This is great!", Literal["positive", "negative", "neutral"])
      # Result: one of the three choices

      JSON عبر Pydantic​

      from pydantic import BaseModel

      class Product(BaseModel):
          name: str
          price: float
          in_stock: bool

      result = model("Extract: iPhone 15, $999, available", Product)
      product = Product.model_validate_json(result)  # valid Product instance

      Regex (مرّر سلسلة regex)​

      # Generate text matching a regex pattern
      phone = model("Generate phone number:", r"[0-9]{3}-[0-9]{3}-[0-9]{4}")
      # Result: "555-123-4567" (guaranteed to match the pattern)

      الأنواع الرقمية​

      # Pass the Python type directly
      age = model("Person's age:", int)      # guaranteed integer
      price = model("Product price:", float)  # guaranteed float

      4. التكامل مع Pydantic​

      يوفّر Outlines دعمًا أصيلًا لـ Pydantic مع ترجمة تلقائية للمخططات (schema). يُعاد التوليد كسلسلة JSON نصية؛ استدعِ model_validate_json للحصول على نسخة (instance).

      نماذج أساسية​

      from pydantic import BaseModel, Field

      class Article(BaseModel):
          title: str = Field(description="Article title")
          author: str = Field(description="Author name")
          word_count: int = Field(description="Number of words", gt=0)
          tags: list[str] = Field(description="List of tags")

      result = model("Generate article about AI", Article, max_new_tokens=300)
      article = Article.model_validate_json(result)
      print(article.title)
      print(article.word_count)  # Guaranteed > 0

      نماذج متداخلة​

      class Address(BaseModel):
          street: str
          city: str
          country: str

      class Person(BaseModel):
          name: str
          age: int
          address: Address  # Nested model

      result = model("Generate person in New York", Person)
      person = Person.model_validate_json(result)
      print(person.address.city)  # "New York"

      Enums و Literals​

      from enum import Enum
      from typing import Literal

      class Status(str, Enum):
          PENDING = "pending"
          APPROVED = "approved"
          REJECTED = "rejected"

      class Application(BaseModel):
          applicant: str
          status: Status  # Must be one of enum values
          priority: Literal["low", "medium", "high"]  # Must be one of literals

      result = model("Generate application", Application)
      app = Application.model_validate_json(result)
      print(app.status)  # Status.PENDING (or APPROVED/REJECTED)

      أنماط شائعة​

      النمط 1: استخراج البيانات​

      from pydantic import BaseModel
      import outlines
      from transformers import AutoModelForCausalLM, AutoTokenizer

      class CompanyInfo(BaseModel):
          name: str
          founded_year: int
          industry: str
          employees: int

      model = outlines.from_transformers(
          AutoModelForCausalLM.from_pretrained("microsoft/Phi-3-mini-4k-instruct", device_map="auto"),
          AutoTokenizer.from_pretrained("microsoft/Phi-3-mini-4k-instruct"),
      )

      text = """
      Apple Inc. was founded in 1976 in the technology industry.
      The company employs approximately 164,000 people worldwide.
      """

      prompt = f"Extract company information:\n{text}\n\nCompany:"
      company = CompanyInfo.model_validate_json(model(prompt, CompanyInfo, max_new_tokens=200))

      print(f"Name: {company.name}")
      print(f"Founded: {company.founded_year}")
      print(f"Industry: {company.industry}")
      print(f"Employees: {company.employees}")

      النمط 2: التصنيف​

      from typing import Literal
      from pydantic import BaseModel

      # Binary classification
      result = model("Email: Buy now! 50% off!", Literal["spam", "not_spam"])

      # Multi-class classification
      category = model(
          "Article: Apple announces new iPhone...",
          Literal["technology", "business", "sports", "entertainment"],
      )

      # With confidence
      class Classification(BaseModel):
          label: Literal["positive", "negative", "neutral"]
          confidence: float

      out = model("Review: This product is okay, nothing special", Classification)
      result = Classification.model_validate_json(out)

      النمط 4: استخراج كيانات متعددة​

      from typing import Literal

      class Entity(BaseModel):
          name: str
          type: Literal["PERSON", "ORGANIZATION", "LOCATION"]

      class DocumentEntities(BaseModel):
          entities: list[Entity]

      text = "Tim Cook met with Satya Nadella at Microsoft headquarters in Redmond."
      prompt = f"Extract entities from: {text}"

      result = DocumentEntities.model_validate_json(model(prompt, DocumentEntities, max_new_tokens=300))
      for entity in result.entities:
          print(f"{entity.name} ({entity.type})")

      النمط 5: توليد الكود​

      class PythonFunction(BaseModel):
          function_name: str
          parameters: list[str]
          docstring: str
          body: str

      prompt = "Generate a Python function to calculate factorial"
      func = PythonFunction.model_validate_json(model(prompt, PythonFunction, max_new_tokens=300))

      print(f"def {func.function_name}({', '.join(func.parameters)}):")
      print(f'    """{func.docstring}"""')
      print(f"    {func.body}")

      النمط 6: المعالجة الدفعية​

      import outlines
      from transformers import AutoModelForCausalLM, AutoTokenizer
      from pydantic import BaseModel

      class Person(BaseModel):
          name: str
          age: int

      model = outlines.from_transformers(
          AutoModelForCausalLM.from_pretrained("microsoft/Phi-3-mini-4k-instruct", device_map="auto"),
          AutoTokenizer.from_pretrained("microsoft/Phi-3-mini-4k-instruct"),
      )

      texts = [
          "John is 30 years old",
          "Alice is 25 years old",
          "Bob is 40 years old",
      ]

      # v1 accepts a list of prompts for batched generation
      prompts = [f"Extract from: {t}" for t in texts]
      outputs = model(prompts, Person, max_new_tokens=100)
      people = [Person.model_validate_json(o) for o in outputs]
      for person in people:
          print(f"{person.name}: {person.age}")

      أفضل الممارسات​

      1. استخدم أنواعًا محددة​

      # ✅ Good: Specific types
      class Product(BaseModel):
          name: str
          price: float  # Not str
          quantity: int  # Not str
          in_stock: bool  # Not str

      # ❌ Bad: Everything as string
      class Product(BaseModel):
          name: str
          price: str  # Should be float
          quantity: str  # Should be int

      2. أضِف قيودًا​

      from pydantic import Field

      # ✅ Good: With constraints
      class User(BaseModel):
          name: str = Field(min_length=1, max_length=100)
          age: int = Field(ge=0, le=120)
          email: str = Field(pattern=r"^[\w\.-]+@[\w\.-]+\.\w+$")

      # ❌ Bad: No constraints
      class User(BaseModel):
          name: str
          age: int
          email: str

      3. استخدم Enums للفئات​

      # ✅ Good: Enum for fixed set
      class Priority(str, Enum):
          LOW = "low"
          MEDIUM = "medium"
          HIGH = "high"

      class Task(BaseModel):
          title: str
          priority: Priority

      # ❌ Bad: Free-form string
      class Task(BaseModel):
          title: str
          priority: str  # Can be anything

      4. قدّم سياقًا ضمن الـ prompts​

      # ✅ Good: Clear context
      prompt = """
      Extract product information from the following text.
      Text: iPhone 15 Pro costs $999 and is currently in stock.
      Product:
      """

      # ❌ Bad: Minimal context
      prompt = "iPhone 15 Pro costs $999 and is currently in stock."

      5. تعامل مع الحقول الاختيارية​

      from typing import Optional

      # ✅ Good: Optional fields for incomplete data
      class Article(BaseModel):
          title: str  # Required
          author: Optional[str] = None  # Optional
          date: Optional[str] = None  # Optional
          tags: list[str] = []  # Default empty list

      # Can succeed even if author/date missing

      6. تحقّق دائمًا من مخرجات JSON​

      # v1 returns a JSON string for Pydantic/JSON output types.
      result = model(prompt, Article)          # str
      article = Article.model_validate_json(result)  # Article instance

      متى تختار Outlines:

      • عند استخدام نماذج محلية (Transformers، llama.cpp، vLLM)
      • عند الحاجة إلى أقصى سرعة inference
      • عند الرغبة في دعم نماذج Pydantic
      • عند الحاجة إلى توليد مُقيَّد بلا أي تكلفة إضافية
      • عند الحاجة إلى التحكم في عملية أخذ عينات token

      متى تختار بدائل أخرى:

      • Instructor: عند الحاجة إلى نماذج API مع إعادة محاولة تلقائية
      • Guidance: عند الحاجة إلى token healing وسير عمل معقّد
      • LMQL: عند تفضيل صياغة استعلام تصريحية (declarative)

      خصائص الأداء​

      السرعة:

      • بلا أي تكلفة إضافية: التوليد المُقيَّد بسرعة التوليد غير المُقيَّد نفسها
      • تحسين التقديم السريع (Fast-forward): يتخطى الـ tokens الحتمية
      • أسرع بمقدار 1.2 إلى 2 مرة من أساليب التحقق بعد التوليد

      الذاكرة:

      • تُصرَّف آلة الحالات مرة واحدة لكل نوع مخرجات (وتُخزَّن مؤقتًا)
      • تكلفة إضافية طفيفة أثناء التشغيل
      • كفاءة عالية مع vLLM للإنتاجية المرتفعة

      الدقة:

      • 100% مخرجات صالحة (مضمونة عبر آلة الحالات المُقيَّدة)
      • لا حاجة لحلقات إعادة المحاولة
      • تصفية حتمية للـ tokens
