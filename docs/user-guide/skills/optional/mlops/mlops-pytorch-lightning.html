      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      PyTorch Lightning - إطار عمل تدريب عالي المستوى

      البدء السريع​

      ينظّم PyTorch Lightning كود PyTorch للتخلص من الكود المتكرر مع الحفاظ على المرونة.

      التثبيت:

      pip install lightning

      تحويل PyTorch إلى Lightning (3 خطوات):

      import lightning as L
      import torch
      from torch import nn
      from torch.utils.data import DataLoader, Dataset

      # Step 1: Define LightningModule (organize your PyTorch code)
      class LitModel(L.LightningModule):
          def __init__(self, hidden_size=128):
              super().__init__()
              self.model = nn.Sequential(
                  nn.Linear(28 * 28, hidden_size),
                  nn.ReLU(),
                  nn.Linear(hidden_size, 10)
              )

          def training_step(self, batch, batch_idx):
              x, y = batch
              y_hat = self.model(x)
              loss = nn.functional.cross_entropy(y_hat, y)
              self.log('train_loss', loss)  # Auto-logged to TensorBoard
              return loss

          def configure_optimizers(self):
              return torch.optim.Adam(self.parameters(), lr=1e-3)

      # Step 2: Create data
      train_loader = DataLoader(train_dataset, batch_size=32)

      # Step 3: Train with Trainer (handles everything else!)
      trainer = L.Trainer(max_epochs=10, accelerator='gpu', devices=2)
      model = LitModel()
      trainer.fit(model, train_loader)

      هذا كل ما في الأمر! يتولى Trainer:

      • التبديل بين GPU/TPU/CPU
      • التدريب الموزّع (DDP، FSDP، DeepSpeed)
      • الدقة المختلطة (FP16، BF16)
      • تراكم التدرجات (gradient accumulation)
      • الحفظ التلقائي للنقاط (checkpointing)
      • التسجيل (logging)
      • أشرطة التقدم

      سير العمل الشائع​

      سير العمل 1: من PyTorch إلى Lightning​

      كود PyTorch الأصلي:

      model = MyModel()
      optimizer = torch.optim.Adam(model.parameters())
      model.to('cuda')

      for epoch in range(max_epochs):
          for batch in train_loader:
              batch = batch.to('cuda')
              optimizer.zero_grad()
              loss = model(batch)
              loss.backward()
              optimizer.step()

      نسخة Lightning:

      class LitModel(L.LightningModule):
          def __init__(self):
              super().__init__()
              self.model = MyModel()

          def training_step(self, batch, batch_idx):
              loss = self.model(batch)  # No .to('cuda') needed!
              return loss

          def configure_optimizers(self):
              return torch.optim.Adam(self.parameters())

      # Train
      trainer = L.Trainer(max_epochs=10, accelerator='gpu')
      trainer.fit(LitModel(), train_loader)

      الفوائد: من 40+ سطرًا إلى 15 سطرًا، دون إدارة يدوية للأجهزة، وتوزيع تلقائي

      سير العمل 2: التحقق والاختبار​

      class LitModel(L.LightningModule):
          def __init__(self):
              super().__init__()
              self.model = MyModel()

          def training_step(self, batch, batch_idx):
              x, y = batch
              y_hat = self.model(x)
              loss = nn.functional.cross_entropy(y_hat, y)
              self.log('train_loss', loss)
              return loss

          def validation_step(self, batch, batch_idx):
              x, y = batch
              y_hat = self.model(x)
              val_loss = nn.functional.cross_entropy(y_hat, y)
              acc = (y_hat.argmax(dim=1) == y).float().mean()
              self.log('val_loss', val_loss)
              self.log('val_acc', acc)

          def test_step(self, batch, batch_idx):
              x, y = batch
              y_hat = self.model(x)
              test_loss = nn.functional.cross_entropy(y_hat, y)
              self.log('test_loss', test_loss)

          def configure_optimizers(self):
              return torch.optim.Adam(self.parameters(), lr=1e-3)

      # Train with validation
      trainer = L.Trainer(max_epochs=10)
      trainer.fit(model, train_loader, val_loader)

      # Test
      trainer.test(model, test_loader)

      ميزات تلقائية:

      • يعمل التحقق (validation) في كل حقبة (epoch) افتراضيًا
      • تُسجَّل المقاييس في TensorBoard
      • حفظ أفضل نموذج تلقائيًا استنادًا إلى val_loss

      سير العمل 3: التدريب الموزّع (DDP)​

      # Same code as single GPU!
      model = LitModel()

      # 8 GPUs with DDP (automatic!)
      trainer = L.Trainer(
          accelerator='gpu',
          devices=8,
          strategy='ddp'  # Or 'fsdp', 'deepspeed'
      )

      trainer.fit(model, train_loader)

      التشغيل:

      # Single command, Lightning handles the rest
      python train.py

      لا حاجة لأي تعديل:

      • توزيع تلقائي للبيانات
      • مزامنة التدرجات
      • دعم عُقد متعددة (فقط اضبط num_nodes=2)

      سير العمل 4: Callbacks للمراقبة​

      from lightning.pytorch.callbacks import ModelCheckpoint, EarlyStopping, LearningRateMonitor

      # Create callbacks
      checkpoint = ModelCheckpoint(
          monitor='val_loss',
          mode='min',
          save_top_k=3,
          filename='model-{epoch:02d}-{val_loss:.2f}'
      )

      early_stop = EarlyStopping(
          monitor='val_loss',
          patience=5,
          mode='min'
      )

      lr_monitor = LearningRateMonitor(logging_interval='epoch')

      # Add to Trainer
      trainer = L.Trainer(
          max_epochs=100,
          callbacks=[checkpoint, early_stop, lr_monitor]
      )

      trainer.fit(model, train_loader, val_loader)

      النتيجة:

      • حفظ تلقائي لأفضل 3 نماذج
      • إيقاف مبكر عند عدم وجود تحسن لمدة 5 حقب
      • تسجيل معدل التعلم (learning rate) في TensorBoard

      سير العمل 5: جدولة معدل التعلم​

      class LitModel(L.LightningModule):
          # ... (training_step, etc.)

          def configure_optimizers(self):
              optimizer = torch.optim.Adam(self.parameters(), lr=1e-3)

              # Cosine annealing
              scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
                  optimizer,
                  T_max=100,
                  eta_min=1e-5
              )

              return {
                  'optimizer': optimizer,
                  'lr_scheduler': {
                      'scheduler': scheduler,
                      'interval': 'epoch',  # Update per epoch
                      'frequency': 1
                  }
              }

      # Learning rate auto-logged!
      trainer = L.Trainer(max_epochs=100)
      trainer.fit(model, train_loader)

      متى تستخدمه مقابل البدائل​

      استخدم PyTorch Lightning عندما:

      • تريد كودًا نظيفًا ومنظمًا
      • تحتاج إلى حلقات تدريب جاهزة للإنتاج
      • تنتقل بين GPU واحد، متعدد GPU، وTPU
      • تريد callbacks وتسجيلًا مدمجَين
      • العمل الجماعي (بنية موحّدة)

      المزايا الرئيسية:

      • منظّم: يفصل كود البحث عن كود الهندسة
      • تلقائي: DDP وFSDP وDeepSpeed بسطر واحد
      • Callbacks: امتدادات تدريب معيارية
      • قابل لإعادة الإنتاج: كود متكرر أقل يعني أخطاءً أقل
      • مُختبَر: أكثر من مليون تنزيل شهريًا، مُختبَر ميدانيًا

      استخدم البدائل بدلًا من ذلك:

      • Accelerate: تعديلات طفيفة على الكود الحالي، مرونة أكبر
      • Ray Train: تنسيق متعدد العُقد، ضبط المعاملات الفائقة (hyperparameter tuning)
      • PyTorch الخام: أقصى تحكم، لأغراض التعلّم
      • Keras: نظام TensorFlow البيئي

      المشكلات الشائعة​

      المشكلة: الخسارة (loss) لا تنخفض

      تحقق من إعداد البيانات والنموذج:

      # Add to training_step
      def training_step(self, batch, batch_idx):
          if batch_idx == 0:
              print(f"Batch shape: {batch[0].shape}")
              print(f"Labels: {batch[1]}")
          loss = ...
          return loss

      المشكلة: نفاد الذاكرة

      قلّل حجم الدفعة (batch size) أو استخدم تراكم التدرجات:

      trainer = L.Trainer(
          accumulate_grad_batches=4,  # Effective batch = batch_size × 4
          precision='bf16'  # Or 'fp16', reduces memory 50%
      )

      المشكلة: التحقق لا يعمل

      تأكد من تمرير val_loader:

      # WRONG
      trainer.fit(model, train_loader)

      # CORRECT
      trainer.fit(model, train_loader, val_loader)

      المشكلة: DDP يُنشئ عمليات متعددة بشكل غير متوقع

      يكتشف Lightning وحدات GPU تلقائيًا. اضبط devices صراحةً:

      # Test on CPU first
      trainer = L.Trainer(accelerator='cpu', devices=1)

      # Then GPU
      trainer = L.Trainer(accelerator='gpu', devices=1)

      متطلبات الأجهزة​

      • CPU: يعمل (جيد لتصحيح الأخطاء)
      • GPU واحد: يعمل
      • GPU متعدد: DDP (افتراضي)، أو FSDP، أو DeepSpeed
      • عُقد متعددة: DDP، FSDP، DeepSpeed
      • TPU: مدعوم (8 أنوية)
      • Apple MPS: مدعوم

      خيارات الدقة:

      • FP32 (افتراضي)
      • FP16 (V100، وحدات GPU الأقدم)
      • BF16 (A100/H100، مُوصى به)
      • FP8 (H100)
