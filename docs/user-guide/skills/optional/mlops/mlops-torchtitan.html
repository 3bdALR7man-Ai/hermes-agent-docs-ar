      درّب نماذج LLM مسبقًا على نطاق واسع باستخدام تفريع PyTorch الرباعي الأبعاد (4D parallelism).

      TorchTitan - تدريب مسبق موزّع أصيل لنماذج LLM في PyTorch

      البدء السريع​

      TorchTitan هو المنصة الرسمية من PyTorch للتدريب المسبق للنماذج اللغوية الكبيرة على نطاق واسع، بتفريع رباعي الأبعاد قابل للتركيب (FSDP2 و TP و PP و CP)، ويحقق تسريعًا يزيد على 65% مقارنة بالخط الأساسي على معالجات H100.

      التثبيت:

      # From PyPI (stable)
      pip install torchtitan

      # From source (latest features, requires PyTorch nightly)
      git clone https://github.com/pytorch/torchtitan
      cd torchtitan
      pip install -r requirements.txt

      تنزيل الـ tokenizer:

      # Get HF token from https://huggingface.co/settings/tokens
      python scripts/download_hf_assets.py --repo_id meta-llama/Llama-3.1-8B --assets tokenizer --hf_token=...

      ابدأ التدريب على 8 معالجات GPU:

      # Configs are selected by name from the Python config registry
      # (torchtitan/models/llama3/config_registry.py), not by TOML path
      MODULE=llama3 CONFIG=llama3_8b ./run_train.sh

      سير عمل شائع​

      سير العمل 1: تدريب Llama 3.1 8B مسبقًا على عقدة واحدة​

      انسخ قائمة التحقق هذه:

      Single Node Pretraining:
      - [ ] Step 1: Download tokenizer
      - [ ] Step 2: Configure training
      - [ ] Step 3: Launch training
      - [ ] Step 4: Monitor and checkpoint

      الخطوة 1: تنزيل الـ tokenizer

      python scripts/download_hf_assets.py \
        --repo_id meta-llama/Llama-3.1-8B \
        --assets tokenizer \
        --hf_token=YOUR_HF_TOKEN

      الخطوة 2: إعداد التدريب

      في البنية الحالية لـ torchtitan، تُعرَّف إعدادات التشغيل ضمن سجل إعدادات (config registry) بلغة Python (torchtitan/models/llama3/config_registry.py) ويُختار منها بالاسم عبر CONFIG=<name> (أو --config <name>). للتخصيص، سجّل إعدادك الخاص في السجل، أو تجاوَز (override) حقولًا فردية من سطر الأوامر (مثل --optimizer.lr 3e-4 --training.steps 1000).

      الإعدادات المكافئة لتشغيل بحجم 8B تبدو كالتالي (مُعروضة كحقول؛ اضبطها في إدخال السجل أو كتجاوزات --section.key value):

      # fields for a llama3 8B run (register in config_registry.py or pass as --overrides)
      [job]
      dump_folder = "./outputs"
      description = "Llama 3.1 8B training"

      [model]
      name = "llama3"
      flavor = "8B"
      hf_assets_path = "./assets/hf/Llama-3.1-8B"

      [optimizer]
      name = "AdamW"
      lr = 3e-4

      [lr_scheduler]
      warmup_steps = 200

      [training]
      local_batch_size = 2
      seq_len = 8192
      max_norm = 1.0
      steps = 1000
      dataset = "c4"

      [parallelism]
      data_parallel_shard_degree = -1  # Use all GPUs for FSDP

      [activation_checkpoint]
      mode = "selective"
      selective_ac_option = "op"

      [checkpoint]
      enable = true
      folder = "checkpoint"
      interval = 500

      الخطوة 3: تشغيل التدريب

      # 8 GPUs on single node (config selected by name from the registry)
      MODULE=llama3 CONFIG=llama3_8b ./run_train.sh

      # Override individual fields on the command line
      MODULE=llama3 CONFIG=llama3_8b ./run_train.sh --optimizer.lr 3e-4 --training.steps 1000

      # Or explicitly with torchrun (run_train.sh wraps this)
      torchrun --nproc_per_node=8 \
        -m torchtitan.train \
        --module llama3 --config llama3_8b

      الخطوة 4: المراقبة وحفظ نقاط التفتيش (checkpoints)

      تُحفظ سجلات TensorBoard في ./outputs/tb/:

      tensorboard --logdir ./outputs/tb

      سير العمل 2: تدريب متعدد العُقد باستخدام SLURM​

      Multi-Node Training:
      - [ ] Step 1: Configure parallelism for scale
      - [ ] Step 2: Set up SLURM script
      - [ ] Step 3: Submit job
      - [ ] Step 4: Resume from checkpoint

      الخطوة 1: إعداد التفريع (parallelism) للتوسع

      لنموذج 70B على 256 معالج GPU (32 عقدة):

      [parallelism]
      data_parallel_shard_degree = 32  # FSDP across 32 ranks
      tensor_parallel_degree = 8        # TP within node
      pipeline_parallel_degree = 1      # No PP for 70B
      context_parallel_degree = 1       # Increase for long sequences

      الخطوة 2: إعداد سكربت SLURM

      #!/bin/bash
      #SBATCH --job-name=llama70b
      #SBATCH --nodes=32
      #SBATCH --ntasks-per-node=8
      #SBATCH --gpus-per-node=8

      srun torchrun \
        --nnodes=32 \
        --nproc_per_node=8 \
        --rdzv_backend=c10d \
        --rdzv_endpoint=$MASTER_ADDR:$MASTER_PORT \
        -m torchtitan.train \
        --module llama3 --config llama3_70b

      الخطوة 3: إرسال المهمة (job)

      sbatch multinode_trainer.slurm

      الخطوة 4: الاستئناف من نقطة تفتيش

      يستأنف التدريب تلقائيًا إذا وُجدت نقطة تفتيش في المجلد المُعدّ.

      سير العمل 3: تفعيل التدريب بصيغة Float8 لمعالجات H100​

      توفّر Float8 تسريعًا بنسبة 30-50% على معالجات H100.

      Float8 Training:
      - [ ] Step 1: Install torchao
      - [ ] Step 2: Configure Float8
      - [ ] Step 3: Launch with compile

      الخطوة 1: تثبيت torchao

      USE_CPP=0 pip install git+https://github.com/pytorch/ao.git

      الخطوة 2: إعداد Float8

      في الإصدار الحالي من torchtitan، تُطبَّق Float8 وقت الإعداد عبر معامل quantization داخل استدعاء model_registry() ضمن سجل الإعدادات (وليس عبر قسم TOML باسم [quantize.linear.float8]). أضف Float8LinearConverter.Config:

      # in torchtitan/models/llama3/config_registry.py (your model_registry(...) call)
      from torchtitan.components.quantization import Float8LinearConverter

      model_spec = model_registry(
          "8B",
          quantization=[
              Float8LinearConverter.Config(
                  recipe_name="rowwise",          # or "rowwise_with_gw_hp"
                  filter_fqns=["output"],          # skip layers too small to benefit
                  model_compile_enabled=True,      # requires torch.compile for competitive perf
              ),
          ],
      )

      فعّل أيضًا torch.compile في إعداد التشغيل الخاص بك:

      [compile]
      enable = true
      components = ["model", "loss"]

      الخطوة 3: التشغيل مع compile

      # Float8 config is baked into the registered config; just select it and enable compile
      MODULE=llama3 CONFIG=llama3_8b ./run_train.sh --compile.enable

      سير العمل 4: تفريع رباعي الأبعاد (4D) لنماذج 405B​

      4D Parallelism (FSDP + TP + PP + CP):
      - [ ] Step 1: Create seed checkpoint
      - [ ] Step 2: Configure 4D parallelism
      - [ ] Step 3: Launch on 512 GPUs

      الخطوة 1: إنشاء نقطة تفتيش بذرية (seed checkpoint)

      مطلوبة لضمان تهيئة متسقة عبر مراحل PP:

      NGPU=1 MODULE=llama3 CONFIG=llama3_405b ./run_train.sh \
        --checkpoint.enable \
        --checkpoint.create_seed_checkpoint \
        --parallelism.data_parallel_shard_degree 1 \
        --parallelism.tensor_parallel_degree 1 \
        --parallelism.pipeline_parallel_degree 1

      الخطوة 2: إعداد التفريع الرباعي الأبعاد

      [parallelism]
      data_parallel_shard_degree = 8   # FSDP
      tensor_parallel_degree = 8       # TP within node
      pipeline_parallel_degree = 8     # PP across nodes
      context_parallel_degree = 1      # CP for long sequences

      [training]
      local_batch_size = 32
      seq_len = 8192

      الخطوة 3: التشغيل على 512 معالج GPU

      # 64 nodes x 8 GPUs = 512 GPUs
      srun torchrun --nnodes=64 --nproc_per_node=8 \
        -m torchtitan.train \
        --module llama3 --config llama3_405b

      متى تستخدمها مقابل البدائل​

      استخدم TorchTitan عندما:

      • تريد تدريب نماذج LLM مسبقًا من الصفر (من 8B إلى أكثر من 405B)
      • تحتاج إلى حل أصيل في PyTorch بلا اعتماديات من أطراف ثالثة
      • تحتاج إلى تفريع رباعي الأبعاد قابل للتركيب (FSDP2 و TP و PP و CP)
      • تدرّب على معالجات H100 بدعم Float8
      • تريد نقاط تفتيش قابلة للتبادل مع torchtune/HuggingFace

      استخدم بدائل أخرى بدلًا من ذلك:

      • Megatron-LM: لأقصى أداء في عمليات النشر الخاصة بـ NVIDIA فقط
      • DeepSpeed: منظومة أوسع لتحسين ZeRO، مع دعم للـ inference
      • Axolotl/TRL: للـ fine-tuning بدلًا من التدريب المسبق
      • LitGPT: للتعليم والتدريب على نطاق أصغر

      مشكلات شائعة​

      المشكلة: نفاد الذاكرة مع النماذج الكبيرة

      فعّل activation checkpointing وقلّل حجم الدفعة (batch size):

      [activation_checkpoint]
      mode = "full"  # Instead of "selective"

      [training]
      local_batch_size = 1

      أو استخدم تجميع التدرجات (gradient accumulation):

      [training]
      local_batch_size = 1
      global_batch_size = 32  # Accumulates gradients

      المشكلة: TP يسبب استهلاكًا عاليًا للذاكرة مع async collectives

      اضبط متغير البيئة:

      export TORCH_NCCL_AVOID_RECORD_STREAMS=1

      المشكلة: تدريب Float8 ليس أسرع

      لا تفيد Float8 إلا عمليات GEMM الكبيرة. صفِّ الطبقات الصغيرة عبر filter_fqns الخاص بالمحوّل (converter):

      from torchtitan.components.quantization import Float8LinearConverter

      Float8LinearConverter.Config(
          # add "auto_filter_small_kn" to auto-skip layers too small to benefit
          filter_fqns=["attention.wk", "attention.wv", "output", "auto_filter_small_kn"],
          model_compile_enabled=True,
      )

      المشكلة: فشل تحميل نقطة التفتيش بعد تغيير التفريع

      استخدم قدرة إعادة التقسيم (resharding) في DCP:

      # Convert sharded checkpoint to single file
      python -m torch.distributed.checkpoint.format_utils \
        dcp_to_torch checkpoint/step-1000 checkpoint.pt

      المشكلة: تهيئة التفريع بالخطوط الأنبوبية (pipeline parallelism)

      أنشئ نقطة تفتيش بذرية أولًا (راجع سير العمل 4، الخطوة 1).

      مواضيع متقدمة​

      إعداد FSDP2: راجع references/fsdp.md للمقارنة التفصيلية بين FSDP2 و FSDP1 ومكافئات ZeRO.
