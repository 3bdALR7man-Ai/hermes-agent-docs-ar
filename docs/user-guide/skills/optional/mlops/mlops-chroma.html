      Chroma

      قاعدة بيانات embeddings لـ RAG والبحث الدلالي (semantic search).

      بيانات المهارة الوصفية​

      المصدراختيارية — ثبّتها باستخدام hermes skills install official/mlops/chroma
      المسارoptional-skills/mlops/chroma
      الإصدار1.0.0
      المؤلفOrchestra Research
      الترخيصMIT
      الاعتمادياتchromadb, sentence-transformers
      المنصاتlinux, macos, windows
      الوسومRAG, Chroma, Vector Database, Embeddings, Semantic Search, Open Source, Self-Hosted, Document Retrieval, Metadata Filtering

      المرجع: ملف SKILL.md كاملًا​

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      Chroma - قاعدة بيانات embeddings مفتوحة المصدر

      قاعدة البيانات المُصمَّمة أصلًا للذكاء الاصطناعي لبناء تطبيقات LLM ذات ذاكرة.

      متى تستخدم Chroma​

      استخدم Chroma عندما:

      • تبني تطبيقات RAG (retrieval-augmented generation)
      • تحتاج قاعدة بيانات متجهية (vector database) محلية أو مستضافة ذاتيًا
      • تريد حلًا مفتوح المصدر (Apache 2.0)
      • تُجري نمذجة أولية في notebooks
      • تحتاج بحثًا دلاليًا (semantic search) عبر المستندات
      • تخزّن embeddings مع بيانات وصفية (metadata)

      مقاييس:

      • أكثر من 24,300 نجمة على GitHub
      • أكثر من 1,900 fork
      • v1.3.3 (مستقرة، إصدارات أسبوعية)
      • ترخيص Apache 2.0

      استخدم البدائل بدلًا من ذلك:

      • Pinecone: سحابة مُدارة، وتوسّع تلقائي (auto-scaling)
      • FAISS: بحث تشابه خالص، بلا بيانات وصفية
      • Weaviate: قاعدة بيانات إنتاجية مُصمَّمة أصلًا للتعلّم الآلي
      • Qdrant: أداء عالٍ، مبني بلغة Rust

      البدء السريع​

      التثبيت​

      # Python
      pip install chromadb

      # JavaScript/TypeScript
      npm install chromadb @chroma-core/default-embed

      الاستخدام الأساسي (Python)​

      import chromadb

      # Create client
      client = chromadb.Client()

      # Create collection
      collection = client.create_collection(name="my_collection")

      # Add documents
      collection.add(
          documents=["This is document 1", "This is document 2"],
          metadatas=[{"source": "doc1"}, {"source": "doc2"}],
          ids=["id1", "id2"]
      )

      # Query
      results = collection.query(
          query_texts=["document about topic"],
          n_results=2
      )

      print(results)

      العمليات الأساسية​

      1. إنشاء collection​

      # Simple collection
      collection = client.create_collection("my_docs")

      # With custom embedding function
      from chromadb.utils import embedding_functions

      openai_ef = embedding_functions.OpenAIEmbeddingFunction(
          api_key="your-key",
          model_name="text-embedding-3-small"
      )

      collection = client.create_collection(
          name="my_docs",
          embedding_function=openai_ef
      )

      # Get existing collection
      collection = client.get_collection("my_docs")

      # Delete collection
      client.delete_collection("my_docs")

      2. إضافة مستندات​

      # Add with auto-generated IDs
      collection.add(
          documents=["Doc 1", "Doc 2", "Doc 3"],
          metadatas=[
              {"source": "web", "category": "tutorial"},
              {"source": "pdf", "page": 5},
              {"source": "api", "timestamp": "2025-01-01"}
          ],
          ids=["id1", "id2", "id3"]
      )

      # Add with custom embeddings
      collection.add(
          embeddings=[[0.1, 0.2, ...], [0.3, 0.4, ...]],
          documents=["Doc 1", "Doc 2"],
          ids=["id1", "id2"]
      )

      3. الاستعلام (بحث التشابه)​

      # Basic query
      results = collection.query(
          query_texts=["machine learning tutorial"],
          n_results=5
      )

      # Query with filters
      results = collection.query(
          query_texts=["Python programming"],
          n_results=3,
          where={"source": "web"}
      )

      # Query with metadata filters
      results = collection.query(
          query_texts=["advanced topics"],
          where={
              "$and": [
                  {"category": "tutorial"},
                  {"difficulty": {"$gte": 3}}
              ]
          }
      )

      # Access results
      print(results["documents"])      # List of matching documents
      print(results["metadatas"])      # Metadata for each doc
      print(results["distances"])      # Similarity scores
      print(results["ids"])            # Document IDs

      4. جلب المستندات​

      # Get by IDs
      docs = collection.get(
          ids=["id1", "id2"]
      )

      # Get with filters
      docs = collection.get(
          where={"category": "tutorial"},
          limit=10
      )

      # Get all documents
      docs = collection.get()

      5. تحديث المستندات​

      # Update document content
      collection.update(
          ids=["id1"],
          documents=["Updated content"],
          metadatas=[{"source": "updated"}]
      )

      6. حذف المستندات​

      # Delete by IDs
      collection.delete(ids=["id1", "id2"])

      # Delete with filter
      collection.delete(
          where={"source": "outdated"}
      )

      التخزين الدائم​

      # Persist to disk
      client = chromadb.PersistentClient(path="./chroma_db")

      collection = client.create_collection("my_docs")
      collection.add(documents=["Doc 1"], ids=["id1"])

      # Data persisted automatically
      # Reload later with same path
      client = chromadb.PersistentClient(path="./chroma_db")
      collection = client.get_collection("my_docs")

      دوال الـ embedding​

      الافتراضية (Sentence Transformers)​

      # Uses sentence-transformers by default
      collection = client.create_collection("my_docs")
      # Default model: all-MiniLM-L6-v2

      OpenAI​

      from chromadb.utils import embedding_functions

      openai_ef = embedding_functions.OpenAIEmbeddingFunction(
          api_key="your-key",
          model_name="text-embedding-3-small"
      )

      collection = client.create_collection(
          name="openai_docs",
          embedding_function=openai_ef
      )

      HuggingFace​

      huggingface_ef = embedding_functions.HuggingFaceEmbeddingFunction(
          api_key="your-key",
          model_name="sentence-transformers/all-mpnet-base-v2"
      )

      collection = client.create_collection(
          name="hf_docs",
          embedding_function=huggingface_ef
      )

      دالة embedding مخصّصة​

      from chromadb import Documents, EmbeddingFunction, Embeddings

      class MyEmbeddingFunction(EmbeddingFunction):
          def __call__(self, input: Documents) -> Embeddings:
              # Your embedding logic
              return embeddings

      my_ef = MyEmbeddingFunction()
      collection = client.create_collection(
          name="custom_docs",
          embedding_function=my_ef
      )

      تصفية عبر البيانات الوصفية (metadata)​

      # Exact match
      results = collection.query(
          query_texts=["query"],
          where={"category": "tutorial"}
      )

      # Comparison operators
      results = collection.query(
          query_texts=["query"],
          where={"page": {"$gt": 10}}  # $gt, $gte, $lt, $lte, $ne
      )

      # Logical operators
      results = collection.query(
          query_texts=["query"],
          where={
              "$and": [
                  {"category": "tutorial"},
                  {"difficulty": {"$lte": 3}}
              ]
          }  # Also: $or
      )

      # Contains
      results = collection.query(
          query_texts=["query"],
          where={"tags": {"$in": ["python", "ml"]}}
      )

      التكامل مع LangChain​

      from langchain_chroma import Chroma
      from langchain_openai import OpenAIEmbeddings
      from langchain.text_splitter import RecursiveCharacterTextSplitter

      # Split documents
      text_splitter = RecursiveCharacterTextSplitter(chunk_size=1000)
      docs = text_splitter.split_documents(documents)

      # Create Chroma vector store
      vectorstore = Chroma.from_documents(
          documents=docs,
          embedding=OpenAIEmbeddings(),
          persist_directory="./chroma_db"
      )

      # Query
      results = vectorstore.similarity_search("machine learning", k=3)

      # As retriever
      retriever = vectorstore.as_retriever(search_kwargs={"k": 5})

      التكامل مع LlamaIndex​

      from llama_index.vector_stores.chroma import ChromaVectorStore
      from llama_index.core import VectorStoreIndex, StorageContext
      import chromadb

      # Initialize Chroma
      db = chromadb.PersistentClient(path="./chroma_db")
      collection = db.get_or_create_collection("my_collection")

      # Create vector store
      vector_store = ChromaVectorStore(chroma_collection=collection)
      storage_context = StorageContext.from_defaults(vector_store=vector_store)

      # Create index
      index = VectorStoreIndex.from_documents(
          documents,
          storage_context=storage_context
      )

      # Query
      query_engine = index.as_query_engine()
      response = query_engine.query("What is machine learning?")

      وضع الخادم (Server mode)​

      # Run Chroma server
      # Terminal: chroma run --path ./chroma_db --port 8000

      # Connect to server
      import chromadb
      from chromadb.config import Settings

      client = chromadb.HttpClient(
          host="localhost",
          port=8000,
          settings=Settings(anonymized_telemetry=False)
      )

      # Use as normal
      collection = client.get_or_create_collection("my_docs")

      أفضل الممارسات​

      1. استخدم العميل الدائم (persistent client) - لتجنّب فقدان البيانات عند إعادة التشغيل
      2. أضف بيانات وصفية - يتيح التصفية والتتبّع
      3. عمليات دفعية (batch) - أضف عدة مستندات دفعة واحدة
      4. اختر نموذج embedding المناسب - وازن بين السرعة والجودة
      5. استخدم المرشّحات (filters) - لتضييق مساحة البحث
      6. معرّفات فريدة (Unique IDs) - لتجنّب التعارضات
      7. نسخ احتياطية منتظمة - انسخ مجلد chroma_db
      8. راقب حجم الـ collection - وسّع النطاق عند الحاجة
      9. اختبر دوال الـ embedding - لضمان الجودة
      10. استخدم وضع الخادم للإنتاج - أفضل لتعدد المستخدمين

      الأداء​

      العمليةزمن الاستجابة (Latency)ملاحظات
      إضافة 100 مستند~1-3 ثانيةمع الـ embedding
      الاستعلام (أفضل 10)~50-200 مللي ثانيةيعتمد على حجم الـ collection
      تصفية البيانات الوصفية~10-50 مللي ثانيةسريعة مع فهرسة مناسبة
