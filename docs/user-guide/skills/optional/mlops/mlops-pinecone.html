      Pinecone

      قاعدة بيانات متجهية مُدارة لـ RAG والبحث في بيئة الإنتاج.

      بيانات المهارة الوصفية​

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      Pinecone - قاعدة بيانات متجهية مُدارة

      قاعدة البيانات المتجهية لتطبيقات الذكاء الاصطناعي في بيئة الإنتاج.

      متى تستخدم Pinecone​

      استخدمها عندما:

      • تحتاج إلى قاعدة بيانات متجهية مُدارة وبلا خادم (serverless)
      • لديك تطبيقات RAG في بيئة الإنتاج
      • يلزم التوسع التلقائي
      • يكون زمن الاستجابة المنخفض (أقل من 100 مللي ثانية) حاسمًا
      • لا تريد إدارة بنية تحتية
      • تحتاج إلى بحث هجين (متجهات كثيفة + متفرقة)

      المقاييس:

      • خدمة SaaS مُدارة بالكامل
      • تتوسع تلقائيًا إلى مليارات المتجهات
      • زمن استجابة p95 أقل من 100 مللي ثانية
      • اتفاقية مستوى خدمة (SLA) بتوافر 99.9%

      استخدم بدائل أخرى بدلًا من ذلك:

      • Chroma: مستضافة ذاتيًا ومفتوحة المصدر
      • FAISS: بحث تشابه غير متصل (offline) خالص
      • Weaviate: مستضافة ذاتيًا بميزات أكثر

      البدء السريع​

      التثبيت​

      pip install pinecone

      ملاحظة: حزمة pinecone-client القديمة أصبحت مهملة (deprecated). ثبّت pinecone (الإصدار 5 فما فوق؛ الحالي 9.x). يبقى الاستيراد from pinecone import Pinecone.

      الاستخدام الأساسي​

      from pinecone import Pinecone, ServerlessSpec

      # Initialize
      pc = Pinecone(api_key="your-api-key")

      # Create index
      pc.create_index(
          name="my-index",
          dimension=1536,  # Must match embedding dimension
          metric="cosine",  # or "euclidean", "dotproduct"
          spec=ServerlessSpec(cloud="aws", region="us-east-1")
      )

      # Connect to index
      index = pc.Index("my-index")

      # Upsert vectors
      index.upsert(vectors=[
          {"id": "vec1", "values": [0.1, 0.2, ...], "metadata": {"category": "A"}},
          {"id": "vec2", "values": [0.3, 0.4, ...], "metadata": {"category": "B"}}
      ])

      # Query
      results = index.query(
          vector=[0.1, 0.2, ...],
          top_k=5,
          include_metadata=True
      )

      print(results["matches"])

      إدراج/تحديث المتجهات (Upsert)​

      # Single upsert
      index.upsert(vectors=[
          {
              "id": "doc1",
              "values": [0.1, 0.2, ...],  # 1536 dimensions
              "metadata": {
                  "text": "Document content",
                  "category": "tutorial",
                  "timestamp": "2025-01-01"
              }
          }
      ])

      # Batch upsert (recommended)
      vectors = [
          {"id": f"vec{i}", "values": embedding, "metadata": metadata}
          for i, (embedding, metadata) in enumerate(zip(embeddings, metadatas))
      ]

      index.upsert(vectors=vectors, batch_size=100)

      استعلام المتجهات​

      # Basic query
      results = index.query(
          vector=[0.1, 0.2, ...],
          top_k=10,
          include_metadata=True,
          include_values=False
      )

      # With metadata filtering
      results = index.query(
          vector=[0.1, 0.2, ...],
          top_k=5,
          filter={"category": {"$eq": "tutorial"}}
      )

      # Namespace query
      results = index.query(
          vector=[0.1, 0.2, ...],
          top_k=5,
          namespace="production"
      )

      # Access results
      for match in results["matches"]:
          print(f"ID: {match['id']}")
          print(f"Score: {match['score']}")
          print(f"Metadata: {match['metadata']}")

      التصفية بالبيانات الوصفية (Metadata)​

      # Exact match
      filter = {"category": "tutorial"}

      # Comparison
      filter = {"price": {"$gte": 100}}  # $gt, $gte, $lt, $lte, $ne

      # Logical operators
      filter = {
          "$and": [
              {"category": "tutorial"},
              {"difficulty": {"$lte": 3}}
          ]
      }  # Also: $or

      # In operator
      filter = {"tags": {"$in": ["python", "ml"]}}

      Namespaces​

      # Partition data by namespace
      index.upsert(
          vectors=[{"id": "vec1", "values": [...]}],
          namespace="user-123"
      )

      # Query specific namespace
      results = index.query(
          vector=[...],
          namespace="user-123",
          top_k=5
      )

      # List namespaces
      stats = index.describe_index_stats()
      print(stats['namespaces'])

      البحث الهجين (كثيف + متفرق)​

      # Upsert with sparse vectors
      index.upsert(vectors=[
          {
              "id": "doc1",
              "values": [0.1, 0.2, ...],  # Dense vector
              "sparse_values": {
                  "indices": [10, 45, 123],  # Token IDs
                  "values": [0.5, 0.3, 0.8]   # TF-IDF scores
              },
              "metadata": {"text": "..."}
          }
      ])

      # Hybrid query
      # NOTE: index.query() does NOT accept an `alpha` kwarg. Pinecone stores a
      # single sparse-dense vector, so weighting must be applied by pre-scaling the
      # query vectors before sending them. Use the hybrid_score_norm helper below
      # (alpha * dense + (1 - alpha) * sparse; alpha=1 → pure dense, 0 → pure sparse).

      def hybrid_score_norm(dense, sparse, alpha: float):
          """Scale dense/sparse query vectors for weighted hybrid search."""
          if not 0 <= alpha <= 1:
              raise ValueError("alpha must be between 0 and 1")
          scaled_sparse = {
              "indices": sparse["indices"],
              "values": [v * (1 - alpha) for v in sparse["values"]],
          }
          return [v * alpha for v in dense], scaled_sparse

      hdense, hsparse = hybrid_score_norm(
          dense=[0.1, 0.2, ...],
          sparse={"indices": [10, 45], "values": [0.5, 0.3]},
          alpha=0.5,  # 0=sparse, 1=dense, 0.5=balanced
      )

      results = index.query(
          vector=hdense,
          sparse_vector=hsparse,
          top_k=5,
      )

      # Create vector store
      vector_store = PineconeVectorStore(pinecone_index=pinecone_index)

      # Use in LlamaIndex

      أفضل الممارسات​

      1. استخدم serverless - توسع تلقائي واقتصادي
      2. اجمع عمليات upsert في دفعات - أكفأ (100-200 عنصر لكل دفعة)
      3. أضِف بيانات وصفية (metadata) - لتفعيل التصفية
      4. استخدم Namespaces - لعزل البيانات حسب المستخدم/المستأجر (tenant)
      5. راقب الاستخدام - تحقق من لوحة تحكم Pinecone
      6. حسّن المرشِّحات (filters) - فهرِس الحقول المُستخدَمة كثيرًا في التصفية
      7. اختبر بالمستوى المجاني - فهرس واحد، 100 ألف متجه مجانًا
      8. استخدم البحث الهجين - جودة أفضل
      9. اضبط الأبعاد المناسبة - بما يطابق نموذج التضمين (embedding)
      10. انسخ احتياطيًا بانتظام - صدّر البيانات المهمة

      الأداء​

      العمليةزمن الاستجابةملاحظات

      استعلام (p50)~50 مللي ثانيةيعتمد على حجم الفهرس
      استعلام (p95)~100 مللي ثانيةهدف SLA
      تصفية بالبيانات الوصفية~10-20 مللي ثانية إضافيةتكلفة إضافية

      التسعير (اعتبارًا من 2025)​

      Serverless:

      • 0.096$ لكل مليون وحدة قراءة
      • 0.06$ لكل مليون وحدة كتابة
      • 0.06$ لكل GB من التخزين شهريًا

      المستوى المجاني:

      • فهرس serverless واحد
      • 100 ألف متجه (1536 بُعدًا)
      • مناسب جدًا لبناء النماذج الأولية
