      Modal

      سحابة GPU بلا خادم (serverless) لمهام تعلّم الآلة و APIs النماذج.

      بيانات المهارة الوصفية​

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      سحابة Modal بلا خادم للـ GPU

      دليل تشغيل أحمال عمل تعلّم الآلة على منصة سحابة GPU بلا خادم (serverless) من Modal.

      متى تستخدم Modal​

      استخدم Modal عندما:

      • تريد تشغيل أحمال عمل تعلّم الآلة كثيفة استخدام GPU دون إدارة بنية تحتية
      • تنشر نماذج تعلّم الآلة كواجهات API تتوسع تلقائيًا
      • تشغّل مهام معالجة دفعية (تدريب، inference، معالجة بيانات)
      • تحتاج تسعيرًا للـ GPU بالثانية دون تكاليف خمول
      • تريد بناء نماذج أولية لتطبيقات تعلّم الآلة بسرعة
      • تشغّل مهامًا مجدولة (أحمال عمل شبيهة بـ cron)

      الميزات الرئيسية:

      • وحدات GPU بلا خادم: T4، L4، A10G، L40S، A100، H100، H200، B200 عند الطلب
      • Python أصلي: عرّف البنية التحتية بكود Python، دون YAML
      • التوسع التلقائي (Auto-scaling): التوسع إلى صفر، أو إلى أكثر من 100 وحدة GPU فوريًا
      • بدء بارد دون ثانية: بنية تحتية مبنية بلغة Rust لإطلاق حاويات سريع
      • تخزين مؤقت للحاويات: طبقات الصور مخزَّنة مؤقتًا لتكرار سريع
      • Web endpoints: انشر الدوال كواجهات REST API مع تحديثات بلا توقف

      استخدم بدائل أخرى بدلًا من ذلك:

      • RunPod: للـ pods طويلة التشغيل ذات الحالة الدائمة
      • Lambda Labs: لوحدات GPU المحجوزة
      • SkyPilot: للتنسيق متعدد السُّحُب وتحسين التكلفة
      • Kubernetes: للبُنى المعمارية متعددة الخدمات المعقّدة

      البدء السريع​

      التثبيت​

      pip install modal
      modal setup  # Opens browser for authentication

      مثال Hello World مع GPU​

      import modal

      app = modal.App("hello-gpu")

      @app.function(gpu="T4")
      def gpu_info():
          import subprocess
          return subprocess.run(["nvidia-smi"], capture_output=True, text=True).stdout

      @app.local_entrypoint()
      def main():
          print(gpu_info.remote())

      شغّله بالأمر: modal run hello_gpu.py

      endpoint أساسي للـ inference​

      import modal

      app = modal.App("text-generation")
      image = modal.Image.debian_slim().pip_install("transformers", "torch", "accelerate")

      @app.cls(gpu="A10G", image=image)
      class TextGenerator:
          @modal.enter()
          def load_model(self):
              from transformers import pipeline
              self.pipe = pipeline("text-generation", model="gpt2", device=0)

          @modal.method()
          def generate(self, prompt: str) -> str:
              return self.pipe(prompt, max_length=100)[0]["generated_text"]

      @app.local_entrypoint()
      def main():
          print(TextGenerator().generate.remote("Hello, world"))

      إعداد GPU​

      وحدات GPU المتاحة​

      GPUVRAMالأنسب لـ
      T416GBinference اقتصادي، نماذج صغيرة
      L424GBinference، بنية Ada Lovelace
      A10G24GBتدريب/inference، أسرع 3.3 مرة من T4
      L40S48GBالموصى به للـ inference (أفضل نسبة تكلفة/أداء)
      A100-40GB40GBتدريب نماذج كبيرة
      A100-80GB80GBنماذج كبيرة جدًا
      H10080GBالأسرع، FP8 وTransformer Engine
      H200141GBترقية تلقائية من H100، عرض نطاق ترددي 4.8TB/s
      B200الأحدثبنية Blackwell

      أنماط تحديد GPU​

      # Single GPU
      @app.function(gpu="A100")

      # Specific memory variant
      @app.function(gpu="A100-80GB")

      # Multiple GPUs (up to 8)
      @app.function(gpu="H100:4")

      # GPU with fallbacks
      @app.function(gpu=["H100", "A100", "L40S"])

      # Any available GPU
      @app.function(gpu="any")

      صور الحاويات​

      # Basic image with pip
      image = modal.Image.debian_slim(python_version="3.11").pip_install(
          "torch==2.1.0", "transformers==4.36.0", "accelerate"
      )

      # From CUDA base
      image = modal.Image.from_registry(
          "nvidia/cuda:12.1.0-cudnn8-devel-ubuntu22.04",
          add_python="3.11"
      ).pip_install("torch", "transformers")

      # With system packages
      image = modal.Image.debian_slim().apt_install("git", "ffmpeg").pip_install("whisper")

      التخزين الدائم​

      volume = modal.Volume.from_name("model-cache", create_if_missing=True)

      @app.function(gpu="A10G", volumes={"/models": volume})
      def load_model():
          import os
          model_path = "/models/llama-7b"
          if not os.path.exists(model_path):
              model = download_model()
              model.save_pretrained(model_path)
              volume.commit()  # Persist changes
          return load_from_path(model_path)

      Web endpoints​

      decorator خاص بـ endpoint من FastAPI​

      @app.function()
      @modal.fastapi_endpoint(method="POST")
      def predict(text: str) -> dict:
          return {"result": model.predict(text)}

      تطبيق ASGI كامل​

      from fastapi import FastAPI
      web_app = FastAPI()

      @web_app.post("/predict")
      async def predict(text: str):
          return {"result": await model.predict.remote.aio(text)}

      @app.function()
      @modal.asgi_app()
      def fastapi_app():
          return web_app

      أنواع Web endpoints​

      Decoratorحالة الاستخدام
      @modal.fastapi_endpoint()دالة بسيطة ← API
      @modal.asgi_app()تطبيقات FastAPI/Starlette كاملة
      @modal.wsgi_app()تطبيقات Django/Flask
      @modal.web_server(port)خوادم HTTP عشوائية

      التجميع الديناميكي (Dynamic batching)​

      @app.function()
      @modal.batched(max_batch_size=32, wait_ms=100)
      async def batch_predict(inputs: list[str]) -> list[dict]:
          # Inputs automatically batched
          return model.batch_predict(inputs)

      تحسين الأداء​

      تخفيف أثر البدء البارد​

      # Modal 1.0 autoscaler params: scaledown_window (was container_idle_timeout).
      # Input concurrency moved to the @modal.concurrent decorator.
      @app.function(scaledown_window=300)  # Keep warm 5 min
      @modal.concurrent(max_inputs=10)     # Handle concurrent requests per container
      def inference():
          pass

      أفضل ممارسات تحميل النماذج​

      @app.cls(gpu="A100")
      class Model:
          @modal.enter()  # Run once at container start
          def load(self):
              self.model = load_model()  # Load during warm-up

          @modal.method()
          def predict(self, x):
              return self.model(x)

      المعالجة المتوازية​

      @app.function()
      def process_item(item):
          return expensive_computation(item)

      @app.function()
      def run_parallel():
          items = list(range(1000))
          # Fan out to parallel containers
          results = list(process_item.map(items))
          return results

      الإعدادات الشائعة​

      @app.function(
          gpu="A100",
          memory=32768,              # 32GB RAM
          cpu=4,                     # 4 CPU cores
          timeout=3600,              # 1 hour max
          scaledown_window=120,      # Keep warm 2 min (was container_idle_timeout)
          retries=3,                 # Retry on failure
          max_containers=10,         # Max concurrent containers (was concurrency_limit)
          min_containers=1,          # Keep N containers warm (was keep_warm)
      )
      def my_function():
          pass

      إعادة تسمية autoscaler في Modal 1.0 (راجع دليل الانتقال):

      • container_idle_timeout ← scaledown_window
      • concurrency_limit ← max_containers
      • keep_warm ← min_containers
      • allow_concurrent_inputs=N ← decorator الـ @modal.concurrent(max_inputs=N)

      المشكلات الشائعة​

      المشكلةالحل
      تأخر زمن البدء الباردزِد قيمة scaledown_window، واستخدم @modal.enter()
      نفاد ذاكرة GPU (OOM)استخدم وحدة GPU أكبر (A100-80GB)، وفعّل gradient checkpointing
      فشل بناء الصورةثبّت إصدارات الاعتماديات، وتحقق من توافق CUDA
      أخطاء انتهاء المهلة (Timeout)زِد قيمة timeout، وأضِف نقاط تفتيش (checkpointing)
