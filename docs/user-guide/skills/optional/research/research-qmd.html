      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      QMD — استعلام مستندات Markdown

      محرك بحث محلي يعمل على الجهاز مباشرةً لقواعد المعرفة الشخصية. يفهرس ملاحظات markdown، والنصوص المفرغة من الاجتماعات، والوثائق، وأي ملفات نصية، ثم يوفّر بحثًا هجينًا يجمع بين مطابقة الكلمات المفتاحية والفهم الدلالي وإعادة الترتيب المدعوم بـ LLM — وكل ذلك يعمل محليًا دون أي اعتماد على السحابة.

      من إنشاء Tobi Lütke. مرخّص بموجب MIT.

      متى تستخدمها​

      • يطلب المستخدم البحث في ملاحظاته أو مستنداته أو قاعدة معرفته أو نصوص اجتماعاته المفرغة
      • يريد المستخدم إيجاد شيء ما عبر مجموعة كبيرة من ملفات markdown/النصوص
      • يريد المستخدم بحثًا دلاليًا ("ابحث عن ملاحظات حول مفهوم X") لا مجرد grep بالكلمات المفتاحية
      • سبق للمستخدم إعداد مجموعات qmd (collections) ويريد الاستعلام عنها
      • يطلب المستخدم إعداد قاعدة معرفة محلية أو نظام بحث في المستندات
      • كلمات مفتاحية: "search my notes"، "find in my docs"، "knowledge base"، "qmd"

      المتطلبات المسبقة​

      Node.js >= 22 (مطلوب)​

      # Check version
      node --version  # must be >= 22

      # macOS — install or upgrade via Homebrew
      brew install node@22

      # Linux — use NodeSource or nvm
      curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
      sudo apt-get install -y nodejs
      # or with nvm:
      nvm install 22 && nvm use 22

      SQLite بدعم الإضافات (macOS فقط)​

      لا يدعم SQLite النظامي في macOS تحميل الإضافات. ثبّته عبر Homebrew:

      brew install sqlite

      تثبيت qmd​

      npm install -g @tobilu/qmd
      # or with Bun:
      bun install -g @tobilu/qmd

      يقوم أول تشغيل بتنزيل 3 نماذج GGUF محلية تلقائيًا (حوالي 2 GB إجمالًا):

      النموذجالغرضالحجم
      embeddinggemma-300M-Q8_0متجهات التضمين (embeddings)~300MB
      qwen3-reranker-0.6b-q8_0إعادة ترتيب النتائج~640MB
      qmd-query-expansion-1.7Bتوسيع الاستعلام~1.1GB

      التحقق من التثبيت​

      qmd --version
      qmd status

      مرجع سريع​

      الأمرما يقوم بهالسرعة
      qmd search "query"بحث بالكلمات المفتاحية BM25 (بدون نماذج)~0.2s
      qmd vsearch "query"بحث متجهي دلالي (نموذج واحد)~3s
      qmd query "query"بحث هجين + إعادة ترتيب (النماذج الثلاثة كلها)~2-3s دافئ، ~19s بارد
      qmd get <docid>استرجاع محتوى المستند كاملًافوري
      qmd multi-get "glob"استرجاع عدة ملفاتفوري
      qmd collection add <path> --name <n>إضافة دليل كمجموعة (collection)فوري
      qmd context add <path> "description"إضافة بيانات سياق وصفية لتحسين الاسترجاعفوري
      qmd embedتوليد/تحديث متجهات التضمينمتغيّر
      qmd statusعرض سلامة الفهرس ومعلومات المجموعاتفوري
      qmd mcpتشغيل خادم MCP (stdio)دائم
      qmd mcp --http --daemonتشغيل خادم MCP (HTTP، نماذج دافئة)دائم

      سير عمل الإعداد​

      1. إضافة المجموعات (Collections)​

      وجّه qmd نحو الأدلة التي تحتوي على مستنداتك:

      # Add a notes directory
      qmd collection add ~/notes --name notes

      # Add project docs
      qmd collection add ~/projects/myproject/docs --name project-docs

      # Add meeting transcripts
      qmd collection add ~/meetings --name meetings

      # List all collections
      qmd collection list

      2. إضافة أوصاف السياق​

      تساعد بيانات السياق الوصفية محرك البحث على فهم ما تحتويه كل مجموعة. هذا يُحسّن جودة الاسترجاع بشكل كبير:

      qmd context add qmd://notes "Personal notes, ideas, and journal entries"
      qmd context add qmd://project-docs "Technical documentation for the main project"
      qmd context add qmd://meetings "Meeting transcripts and action items from team syncs"

      3. توليد متجهات التضمين (Embeddings)​

      qmd embed

      تعالج هذه الخطوة جميع المستندات في جميع المجموعات وتولّد متجهات تضمين. أعد تشغيلها بعد إضافة مستندات أو مجموعات جديدة.

      4. التحقق​

      qmd status   # shows index health, collection stats, model info

      أنماط البحث​

      بحث سريع بالكلمات المفتاحية (BM25)​

      الأفضل لـ: المصطلحات الدقيقة، معرّفات الكود، الأسماء، العبارات المعروفة. لا تُحمَّل أي نماذج — نتائج شبه فورية.

      qmd search "authentication middleware"
      qmd search "handleError async"

      البحث المتجهي الدلالي​

      الأفضل لـ: الأسئلة باللغة الطبيعية، الاستعلامات المفاهيمية. يُحمِّل نموذج التضمين (~3s للاستعلام الأول).

      qmd vsearch "how does the rate limiter handle burst traffic"
      qmd vsearch "ideas for improving onboarding flow"

      البحث الهجين مع إعادة الترتيب (أفضل جودة)​

      الأفضل لـ: الاستعلامات المهمة التي تكون فيها الجودة هي الأهم. يستخدم النماذج الثلاثة كلها — توسيع الاستعلام، BM25 والبحث المتجهي معًا، وإعادة الترتيب.

      qmd query "what decisions were made about the database migration"

      استعلامات مُهيكلة متعددة الأنماط​

      اجمع بين أنواع بحث مختلفة في استعلام واحد لتحقيق الدقة:

      # BM25 for exact term + vector for concept
      qmd query $'lex: rate limiter\nvec: how does throttling work under load'

      # With query expansion
      qmd query $'expand: database migration plan\nlex: "schema change"'

      صياغة الاستعلام (نمط lex/BM25)​

      الصياغةالتأثيرمثال
      termمطابقة البادئةperf يطابق "performance"
      "phrase"عبارة دقيقة"rate limiter"
      -termاستبعاد مصطلحperformance -sports

      HyDE (متجهات تضمين المستند الافتراضي)​

      للمواضيع المعقّدة، اكتب ما تتوقّع أن تبدو عليه الإجابة:

      qmd query $'hyde: The migration plan involves three phases. First, we add the new columns without dropping the old ones. Then we backfill data. Finally we cut over and remove legacy columns.'

      تحديد النطاق ضمن مجموعات معيّنة​

      qmd search "query" --collection notes
      qmd query "query" --collection project-docs

      صيغ الإخراج​

      qmd search "query" --json        # JSON output (best for parsing)
      qmd search "query" --limit 5     # Limit results
      qmd get "#abc123"                # Get by document ID
      qmd get "path/to/file.md"       # Get by file path
      qmd get "file.md:50" -l 100     # Get specific line range
      qmd multi-get "journals/*.md" --json  # Batch retrieve by glob

      التكامل مع MCP (موصى به)​

      يوفّر qmd خادم MCP يتيح أدوات البحث مباشرةً لـ Hermes Agent عبر عميل MCP الأصلي. هذا هو التكامل المفضّل — فبمجرد إعداده، يحصل الوكيل على أدوات qmd تلقائيًا دون الحاجة إلى تحميل هذه المهارة.

      الخيار أ: نمط Stdio (بسيط)​

      أضف إلى ~/.hermes/config.yaml:

      mcp_servers:
        qmd:
          command: "qmd"
          args: ["mcp"]
          timeout: 30
          connect_timeout: 45

      يسجّل هذا الأدوات التالية: mcp_qmd_search، mcp_qmd_vsearch، mcp_qmd_deep_search، mcp_qmd_get، mcp_qmd_status.

      المقايضة: تُحمَّل النماذج عند أول استدعاء بحث (~19s بدء بارد)، ثم تبقى دافئة طوال الجلسة. مقبول للاستخدام غير المتكرر.

      الخيار ب: نمط HTTP Daemon (سريع، موصى به للاستخدام الكثيف)​

      شغّل daemon الخاص بـ qmd بشكل منفصل — فهو يُبقي النماذج دافئة في الذاكرة:

      # Start daemon (persists across agent restarts)
      qmd mcp --http --daemon

      # Runs on http://localhost:8181 by default

      ثم اضبط Hermes Agent للاتصال عبر HTTP:

      mcp_servers:
        qmd:
          url: "http://localhost:8181/mcp"
          timeout: 30

      المقايضة: يستهلك حوالي 2 GB من الذاكرة أثناء التشغيل، لكن كل استعلام يكون سريعًا (~2-3s). الأفضل للمستخدمين الذين يبحثون باستمرار.

      إبقاء الـ daemon قيد التشغيل​

      macOS (launchd)​

      cat > ~/Library/LaunchAgents/com.qmd.daemon.plist << 'EOF'
      <?xml version="1.0" encoding="UTF-8"?>
      <!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
        "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
      <plist version="1.0">
      <dict>
        <key>Label</key>
        <string>com.qmd.daemon</string>
        <key>ProgramArguments</key>
        <array>
          <string>qmd</string>
          <string>mcp</string>
          <string>--http</string>
          <string>--daemon</string>
        </array>
        <key>RunAtLoad</key>
        <true/>
        <key>KeepAlive</key>
        <true/>
        <key>StandardOutPath</key>
        <string>/tmp/qmd-daemon.log</string>
        <key>StandardErrorPath</key>
        <string>/tmp/qmd-daemon.log</string>
      </dict>
      </plist>
      EOF

      launchctl load ~/Library/LaunchAgents/com.qmd.daemon.plist

      Linux (خدمة systemd للمستخدم)​

      mkdir -p ~/.config/systemd/user

      cat > ~/.config/systemd/user/qmd-daemon.service << 'EOF'
      [Unit]
      Description=QMD MCP Daemon
      After=network.target

      [Service]
      ExecStart=qmd mcp --http --daemon
      Restart=on-failure
      RestartSec=10
      Environment=PATH=/usr/local/bin:/usr/bin:/bin

      [Install]
      WantedBy=default.target
      EOF

      systemctl --user daemon-reload
      systemctl --user enable --now qmd-daemon
      systemctl --user status qmd-daemon

      مرجع أدوات MCP​

      بمجرد الاتصال، تتوفّر هذه الأدوات باسم mcp_qmd_*:

      أداة MCPتقابلالوصف
      mcp_qmd_searchqmd searchبحث بالكلمات المفتاحية BM25
      mcp_qmd_vsearchqmd vsearchبحث متجهي دلالي
      mcp_qmd_deep_searchqmd queryبحث هجين + إعادة ترتيب
      mcp_qmd_getqmd getاسترجاع مستند حسب المعرّف أو المسار
      mcp_qmd_statusqmd statusسلامة الفهرس والإحصاءات

      تقبل أدوات MCP استعلامات JSON مُهيكلة للبحث متعدد الأنماط:

      {
        "searches": [
          {"type": "lex", "query": "authentication middleware"},
          {"type": "vec", "query": "how user login is verified"}
        ],
        "collections": ["project-docs"],
        "limit": 10
      }

      استخدام CLI (بدون MCP)​

      عندما لا يكون MCP مُعدًّا، استخدم qmd مباشرةً عبر الطرفية:

      terminal(command="qmd query 'what was decided about the API redesign' --json", timeout=30)

      لمهام الإعداد والإدارة، استخدم الطرفية دائمًا:

      terminal(command="qmd collection add ~/Documents/notes --name notes")
      terminal(command="qmd context add qmd://notes 'Personal research notes and ideas'")
      terminal(command="qmd embed")
      terminal(command="qmd status")

      كيف تعمل خط أنابيب البحث​

      يساعد فهم الآليات الداخلية على اختيار نمط البحث المناسب:

      1. توسيع الاستعلام — يولّد نموذج مُدرَّب دقيقًا بحجم 1.7B استعلامَين بديلَين. يحصل الاستعلام الأصلي على وزن مضاعف عند الدمج.
      2. الاسترجاع المتوازي — يعمل BM25 (عبر SQLite FTS5) والبحث المتجهي في آنٍ واحد عبر جميع صيغ الاستعلام.
      3. دمج RRF — يدمج Reciprocal Rank Fusion (k=60) النتائج. مكافأة أعلى ترتيب: يحصل رقم 1 على +0.05، ورقمَا 2-3 على +0.02.
      4. إعادة الترتيب بواسطة LLM — يُقيّم qwen3-reranker أفضل 30 مرشحًا (0.0-1.0).
      5. المزج الواعي بالموضع — الرتب 1-3: 75% استرجاع / 25% إعادة ترتيب. الرتب 4-10: 60/40. الرتب 11+: 40/60 (يعتمد أكثر على إعادة الترتيب في الذيل الطويل).

      التقطيع الذكي: تُقسَّم المستندات عند نقاط الفصل الطبيعية (العناوين، كتل الكود، الأسطر الفارغة) بهدف الوصول إلى ~900 token مع تداخل 15%. لا تُقسَّم كتل الكود أبدًا في منتصفها.

      أفضل الممارسات​

      1. أضِف دائمًا أوصاف السياق — qmd context add يُحسّن دقة الاسترجاع بشكل كبير. صف ما تحتويه كل مجموعة.
      2. أعد التضمين بعد إضافة مستندات — يجب إعادة تشغيل qmd embed عند إضافة ملفات جديدة إلى المجموعات.
      3. استخدم qmd search من أجل السرعة — عندما تحتاج إلى بحث سريع بالكلمات المفتاحية (معرّفات الكود، الأسماء الدقيقة)، فإن BM25 فوري ولا يحتاج إلى أي نماذج.
      4. استخدم qmd query من أجل الجودة — عندما يكون السؤال مفاهيميًا أو يحتاج المستخدم إلى أفضل النتائج الممكنة، استخدم البحث الهجين.
      5. فضّل التكامل مع MCP — فبمجرد إعداده، يحصل الوكيل على أدوات أصلية دون الحاجة إلى تحميل هذه المهارة في كل مرة.
      6. نمط daemon للمستخدمين المتكررين — إذا كان المستخدم يبحث في قاعدة معرفته بانتظام، فأوصِ بإعداد HTTP daemon.
      7. يحصل أول استعلام في البحث المُهيكل على وزن مضاعف — ضع الاستعلام الأهم/الأكثر يقينًا أولًا عند الجمع بين lex وvec.

      استكشاف الأخطاء وإصلاحها​

      "تنزيل النماذج عند أول تشغيل"​

      أمر طبيعي — يقوم qmd بتنزيل حوالي 2 GB من نماذج GGUF تلقائيًا عند أول استخدام. هذه عملية تحدث مرة واحدة فقط.

      زمن استجابة البدء البارد (~19s)​

      يحدث هذا عندما لا تكون النماذج محمّلة في الذاكرة. الحلول:

      • استخدم نمط HTTP daemon (qmd mcp --http --daemon) لإبقائها دافئة
      • استخدم qmd search (BM25 فقط) عندما لا تكون النماذج ضرورية
      • يُحمّل نمط MCP stdio النماذج عند أول بحث، ثم يبقيها دافئة طوال الجلسة

      macOS: "unable to load extension"​

      ثبّت SQLite من Homebrew: brew install sqlite ثم تأكد من وجوده في PATH قبل SQLite النظامي.

      "No collections found"​

      شغّل qmd collection add <path> --name <name> لإضافة الأدلة، ثم qmd embed لفهرستها.

      تجاوز نموذج التضمين (CJK/متعدد اللغات)​

      اضبط متغير البيئة QMD_EMBED_MODEL للمحتوى غير الإنجليزي:

      export QMD_EMBED_MODEL="your-multilingual-model"

      تخزين البيانات​

      • الفهرس والمتجهات: ~/.cache/qmd/index.sqlite
      • النماذج: تُنزَّل تلقائيًا إلى الذاكرة المؤقتة المحلية عند أول تشغيل
      • بلا اعتماديات سحابية — كل شيء يعمل محليًا
