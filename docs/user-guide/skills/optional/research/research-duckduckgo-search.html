      DuckDuckGo Search

      بحث مجاني في الويب والأخبار والصور دون مفتاح API عبر ddgs.

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      DuckDuckGo Search

      بحث مجاني في الويب باستخدام DuckDuckGo. لا حاجة لمفتاح API.

      تُفضَّل عندما تكون web_search غير متاحة أو غير مناسبة (مثلًا عندما لا يكون FIRECRAWL_API_KEY مضبوطًا). يمكن أيضًا استخدامها كمسار بحث مستقل عندما تكون نتائج DuckDuckGo مطلوبة تحديدًا.

      مسار الاكتشاف​

      تحقّق مما هو متاح فعليًا قبل اختيار النهج:

      # Check CLI availability
      command -v ddgs >/dev/null && echo "DDGS_CLI=installed" || echo "DDGS_CLI=missing"

      شجرة القرار:

      1. إذا كان CLI الخاص بـ ddgs مثبَّتًا، فضِّل terminal + ddgs
      2. إذا كان CLI الخاص بـ ddgs مفقودًا، لا تفترض أن execute_code يستطيع استيراد ddgs
      3. إذا أراد المستخدم DuckDuckGo تحديدًا، ثبّت ddgs أولًا في البيئة المعنية
      4. وإلا ارجع إلى أدوات الويب/المتصفح المدمجة

      ملاحظة مهمة حول بيئات التشغيل:

      • الطرفية (terminal) وexecute_code بيئتا تشغيل منفصلتان
      • نجاح تثبيت عبر shell لا يضمن أن execute_code يستطيع استيراد ddgs
      • لا تفترض أبدًا أن حزم Python الخارجية مثبَّتة مسبقًا داخل execute_code

      التثبيت​

      ثبّت ddgs فقط عند الحاجة الفعلية إلى بحث DuckDuckGo وعندما لا توفّره بيئة التشغيل بالفعل.

      # Python package + CLI entrypoint
      pip install ddgs

      # Verify CLI
      ddgs --help

      إذا كان سير العمل يعتمد على استيراد Python، تحقّق من أن بيئة التشغيل نفسها تستطيع استيراد ddgs قبل استخدام from ddgs import DDGS.

      الطريقة 1: البحث عبر CLI (مفضّلة)​

      استخدم أمر ddgs عبر terminal عند توفّره. هذا المسار مفضَّل لأنه يتجنّب افتراض أن sandbox الخاص بـ execute_code يحتوي حزمة Python الخاصة بـ ddgs.

      # Text search
      ddgs text -q "python async programming" -m 5

      # News search
      ddgs news -q "artificial intelligence" -m 5

      # Image search
      ddgs images -q "landscape photography" -m 10

      # Video search
      ddgs videos -q "python tutorial" -m 5

      # With region filter
      ddgs text -q "best restaurants" -m 5 -r us-en

      # Recent results only (d=day, w=week, m=month, y=year)
      ddgs text -q "latest AI news" -m 5 -t w

      # JSON output for parsing
      ddgs text -q "fastapi tutorial" -m 5 -o json

      خيارات CLI​

      الخيارالوصفمثال
      -qالاستعلام — مطلوب-q "search terms"
      -mالحد الأقصى للنتائج-m 5
      -rالمنطقة-r us-en
      -tالحد الزمني-t w (أسبوع)
      -sالبحث الآمن-s off
      -oصيغة المخرجات-o json

      الطريقة 2: واجهة Python (بعد التحقّق فقط)​

      استخدم صنف DDGS داخل execute_code أو أي بيئة Python أخرى فقط بعد التحقّق من أن ddgs مثبَّت هناك. لا تفترض أن execute_code يتضمّن حزمًا خارجية افتراضيًا.

      صياغة آمنة:

      • "استخدم execute_code مع ddgs بعد تثبيت الحزمة أو التحقّق منها عند الحاجة"

      تجنّب قول:

      • "execute_code يتضمّن ddgs"
      • "بحث DuckDuckGo يعمل افتراضيًا في execute_code"

      مهم: يجب دائمًا تمرير max_results كـ وسيط بالاسم (keyword argument) — الاستخدام كوسيط موضعي يرفع خطأ في جميع الطرق.

      بحث نصي​

      الأنسب لـ: البحث العام، الشركات، التوثيق.

      from ddgs import DDGS

      with DDGS() as ddgs:
          for r in ddgs.text("python async programming", max_results=5):
              print(r["title"])
              print(r["href"])
              print(r.get("body", "")[:200])
              print()

      يُرجع: title، href، body

      بحث الأخبار​

      الأنسب لـ: الأحداث الجارية، الأخبار العاجلة، آخر التحديثات.

      from ddgs import DDGS

      with DDGS() as ddgs:
          for r in ddgs.news("AI regulation 2026", max_results=5):
              print(r["date"], "-", r["title"])
              print(r.get("source", ""), "|", r["url"])
              print(r.get("body", "")[:200])
              print()

      يُرجع: date، title، body، url، image، source

      بحث الصور​

      الأنسب لـ: المراجع البصرية، صور المنتجات، المخططات.

      from ddgs import DDGS

      with DDGS() as ddgs:
          for r in ddgs.images("semiconductor chip", max_results=5):
              print(r["title"])
              print(r["image"])
              print(r.get("thumbnail", ""))
              print(r.get("source", ""))
              print()

      يُرجع: title، image، thumbnail، url، height، width، source

      بحث الفيديو​

      الأنسب لـ: الدروس، العروض التوضيحية، الشروحات.

      from ddgs import DDGS

      with DDGS() as ddgs:
          for r in ddgs.videos("FastAPI tutorial", max_results=5):
              print(r["title"])
              print(r.get("content", ""))
              print(r.get("duration", ""))
              print(r.get("provider", ""))
              print(r.get("published", ""))
              print()

      يُرجع: title، content، description، duration، provider، published، statistics، uploader

      مرجع سريع​

      الطريقةمتى تُستخدمالحقول الرئيسية
      text()البحث العام، الشركاتtitle, href, body
      news()الأحداث الجارية، التحديثاتdate, title, source, body, url
      images()الصور، المخططاتtitle, image, thumbnail, url
      videos()الدروس، العروض التوضيحيةtitle, content, duration, provider

      سير العمل: البحث ثم الاستخراج​

      يعيد DuckDuckGo العناوين والروابط والمقتطفات — لا محتوى الصفحة الكامل. للحصول على محتوى الصفحة الكامل، ابحث أولًا ثم استخرج الرابط الأنسب باستخدام web_extract، أو أدوات المتصفح، أو curl.

      مثال CLI:

      ddgs text -q "fastapi deployment guide" -m 3 -o json

      مثال Python، بعد التحقّق فقط من أن ddgs مثبَّت في تلك البيئة:

      from ddgs import DDGS

      with DDGS() as ddgs:
          results = list(ddgs.text("fastapi deployment guide", max_results=3))
          for r in results:
              print(r["title"], "->", r["href"])

      ثم استخرج أفضل رابط باستخدام web_extract أو أداة استرجاع محتوى أخرى.

      القيود​

      • حدّ المعدل (rate limiting): قد يحدّ DuckDuckGo من الطلبات بعد كثير من الطلبات السريعة المتتالية. أضف تأخيرًا قصيرًا بين عمليات البحث عند الحاجة.
      • لا يوجد استخراج للمحتوى: يعيد ddgs مقتطفات، لا محتوى الصفحة الكامل. استخدم web_extract أو أدوات المتصفح أو curl للحصول على المقال/الصفحة كاملةً.
      • جودة النتائج: جيدة عمومًا لكن أقل قابلية للتهيئة من بحث Firecrawl.
      • التوفّر: قد يحجب DuckDuckGo الطلبات من بعض عناوين IP السحابية. إن عادت نتائج البحث فارغة، جرّب كلمات مفتاحية مختلفة أو انتظر بضع ثوانٍ.
      • تفاوت الحقول: قد تتفاوت حقول الإرجاع بين النتائج أو إصدارات ddgs. استخدم .get() للحقول الاختيارية لتفادي KeyError.
      • بيئات تشغيل منفصلة: نجاح تثبيت ddgs في الطرفية لا يعني تلقائيًا أن execute_code يستطيع استيراده.

      استكشاف الأخطاء وإصلاحها​

      المشكلةالسبب المحتملما يجب فعله
      ddgs: command not foundCLI غير مثبَّت في بيئة shellثبّت ddgs، أو استخدم أدوات الويب/المتصفح المدمجة بدلًا منه
      ModuleNotFoundError: No module named 'ddgs'بيئة Python لا تحتوي الحزمة مثبَّتةلا تستخدم DDGS في Python هناك حتى تُهيَّأ تلك البيئة
      البحث لا يعيد شيئًاحدّ معدل مؤقت أو استعلام ضعيفانتظر بضع ثوانٍ، أعد المحاولة، أو عدِّل الاستعلام
      CLI يعمل لكن استيراد execute_code يفشلالطرفية وexecute_code بيئتا تشغيل مختلفتانواصل استخدام CLI، أو هيّئ بيئة Python بشكل منفصل

      المزالق​

      • max_results وسيط بالاسم حصرًا: يرفع ddgs.text("query", 5) خطأً. استخدم ddgs.text("query", max_results=5).
      • لا تفترض وجود CLI: تحقّق بـ command -v ddgs قبل استخدامه.
      • لا تفترض أن execute_code يستطيع استيراد ddgs: قد يفشل from ddgs import DDGS بخطأ ModuleNotFoundError ما لم تُهيَّأ تلك البيئة بشكل منفصل.
      • اسم الحزمة: اسم الحزمة هو ddgs (سابقًا duckduckgo-search). ثبِّتها بـ pip install ddgs.
      • لا تخلط بين -q و-m (في CLI): -q للاستعلام، و-m للحد الأقصى لعدد النتائج.
      • نتائج فارغة: إذا لم يُعِد ddgs أي شيء، فقد يكون خاضعًا لحدّ معدل. انتظر بضع ثوانٍ وأعد المحاولة.
