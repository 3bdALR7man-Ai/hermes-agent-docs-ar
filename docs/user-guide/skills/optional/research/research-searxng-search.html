      البحث عبر SearXNG

      محرك بحث تجميعي (meta-search) مجاني وبلا مفتاح، يجمع أكثر من 70 محركًا.

      بيانات المهارة الوصفية​

      المصدراختيارية — ثبّتها باستخدام hermes skills install official/research/searxng-search
      المسارoptional-skills/research/searxng-search
      الإصدار1.0.1
      المؤلفhermes-agent
      الترخيصMIT
      المنصاتlinux، macos
      الوسومsearch، searxng، meta-search، self-hosted، free، fallback
      مهارات ذات صلةduckduckgo-search، domain-intel

      المرجع: ملف SKILL.md كاملًا​

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      بحث SearXNG

      بحث تجميعي مجاني باستخدام SearXNG — مجمّع بحث مستضاف ذاتيًا ويحترم الخصوصية، يستعلم أكثر من 70 محرك بحث في آن واحد.

      لا يتطلب مفتاح API عند استخدام نسخة عامة (public instance). يمكن أيضًا استضافته ذاتيًا للتحكم الكامل. يظهر تلقائيًا كخيار احتياطي (fallback) عندما لا يكون toolset البحث الرئيسي في الويب مضبوطًا (FIRECRAWL_API_KEY).

      الإعدادات​

      يتطلب SearXNG متغير بيئة SEARXNG_URL يشير إلى نسختك من SearXNG:

      # Public instances (no setup required)
      SEARXNG_URL=https://searxng.example.com

      # Self-hosted SearXNG
      SEARXNG_URL=http://localhost:8888

      إذا لم تُضبط أي نسخة، تصبح هذه المهارة غير متاحة ويعود الوكيل إلى خيارات بحث أخرى.

      مسار الاكتشاف​

      تحقق مما هو متاح فعليًا قبل اختيار نهج:

      # Check if SEARXNG_URL is set and the instance is reachable
      curl -s --max-time 5 "${SEARXNG_URL}/search?q=test&format=json" | head -c 200

      شجرة القرار:

      1. إذا كان SEARXNG_URL مضبوطًا وكانت النسخة تستجيب، استخدم SearXNG
      2. إذا كان SEARXNG_URL غير مضبوط أو يتعذّر الوصول إليه، عُد إلى أدوات بحث أخرى متاحة
      3. إذا أراد المستخدم SearXNG تحديدًا، ساعده على إعداد نسخة أو إيجاد نسخة عامة

      الطريقة 1: CLI عبر curl (مفضّلة)​

      استخدم curl عبر terminal لاستدعاء واجهة SearXNG JSON API. هذا يتفادى افتراض تثبيت أي حزمة Python بعينها.

      # Text search (JSON output)
      curl -s --max-time 10 \
        "${SEARXNG_URL}/search?q=python+async+programming&format=json&engines=google,bing&limit=10"

      # With Safesearch off
      curl -s --max-time 10 \
        "${SEARXNG_URL}/search?q=example&format=json&safesearch=0"

      # Specific categories (general, news, science, etc.)
      curl -s --max-time 10 \
        "${SEARXNG_URL}/search?q=AI+news&format=json&categories=news"

      خيارات CLI الشائعة​

      الخيارالوصفمثال
      qنص الاستعلام (مُرمَّز URL)q=python+async
      formatصيغة الإخراج: json، csv، rssformat=json
      enginesأسماء المحركات مفصولة بفواصلengines=google,bing,ddg
      limitالحد الأقصى للنتائج لكل محرك (الافتراضي 10)limit=5
      categoriesالتصفية حسب الفئةcategories=news,science
      safesearch0=بلا، 1=معتدل، 2=صارمsafesearch=0
      time_rangeالتصفية: day، week، month، yeartime_range=week

      تحليل نتائج JSON​

      # Extract titles and URLs from JSON
      curl -s --max-time 10 "${SEARXNG_URL}/search?q=fastapi&format=json&limit=5" \
        | python3 -c "
      import json, sys
      data = json.load(sys.stdin)
      for r in data.get('results', []):
          print(r.get('title',''))
          print(r.get('url',''))
          print(r.get('content','')[:200])
          print()
      "

      يُعيد لكل نتيجة: title، url، content (مقتطف)، engine، parsed_url، img_src، thumbnail، author، published_date

      الطريقة 2: واجهة Python عبر requests​

      استخدم واجهة SearXNG REST مباشرةً من Python بواسطة مكتبة requests:

      import os, requests, urllib.parse

      base_url = os.environ.get("SEARXNG_URL", "")
      if not base_url:
          raise RuntimeError("SEARXNG_URL is not set")

      query = "fastapi deployment guide"
      params = {
          "q": query,
          "format": "json",
          "limit": 5,
          "engines": "google,bing",
      }

      resp = requests.get(f"{base_url}/search", params=params, timeout=10)
      resp.raise_for_status()
      data = resp.json()

      for r in data.get("results", []):
          print(r["title"])
          print(r["url"])
          print(r.get("content", "")[:200])
          print()

      استضافة SearXNG ذاتيًا​

      لتشغيل نسختك الخاصة من SearXNG:

      # Using Docker
      docker run -d -p 8888:8080 \
        -v $(pwd)/searxng:/etc/searxng \
        searxng/searxng:latest

      # Then set
      SEARXNG_URL=http://localhost:8888

      أو ثبّتها عبر pip:

      pip install searxng
      # Edit /etc/searxng/settings.yml
      searxng-run

      تتوفر نسخ عامة من SearXNG على:

      • https://searxng.example.com (استبدلها بأي نسخة عامة)

      سير العمل: البحث ثم الاستخلاص​

      يُعيد SearXNG العناوين والروابط والمقتطفات — لا المحتوى الكامل للصفحة. للحصول على المحتوى الكامل، ابحث أولًا ثم استخلص الرابط الأنسب باستخدام web_extract، أو أدوات المتصفح، أو curl.

      # Search for relevant pages
      curl -s "${SEARXNG_URL}/search?q=fastapi+deployment&format=json&limit=3"
      # Output: list of results with titles and URLs

      # Then extract the best URL with web_extract

      القيود​

      • توفّر النسخة: إذا كانت نسخة SearXNG معطلة أو يتعذّر الوصول إليها، يفشل البحث. تحقق دائمًا من ضبط SEARXNG_URL ومن إمكانية الوصول إلى النسخة.
      • لا استخلاص للمحتوى: يُعيد SearXNG مقتطفات لا محتوى الصفحة الكامل. استخدم web_extract أو أدوات المتصفح أو curl للمقالات الكاملة.
      • تحديد المعدل (rate limiting): بعض النسخ العامة تحدّ من الطلبات. الاستضافة الذاتية تتجنب ذلك.
      • تغطية المحركات: تعتمد المحركات المتاحة على إعدادات نسخة SearXNG. قد تكون بعض المحركات معطّلة.
      • حداثة النتائج: يجمّع البحث التجميعي محركات خارجية — وتعتمد حداثة النتائج على تلك المحركات.

      استكشاف الأخطاء وإصلاحها​

      المشكلةالسبب المحتملما يجب فعله
      SEARXNG_URL غير مضبوطلا نسخة مضبوطةاستخدم نسخة عامة من SearXNG أو أعدّ نسختك الخاصة
      رُفض الاتصالالنسخة غير مشغَّلة أو الرابط خاطئتحقق من صحة الرابط ومن تشغيل النسخة
      نتائج فارغةالنسخة تحظر الاستعلامجرّب نسخة أخرى أو استضف نسختك الخاصة
      استجابات بطيئةالنسخة العامة محمَّلة بشكل زائداستضف نسختك الخاصة أو استخدم نسخة عامة أقل ازدحامًا
      صيغة json غير مدعومةإصدار SearXNG قديمجرّب format=rss أو حدّث SearXNG

      مزالق​

      • اضبط SEARXNG_URL دائمًا: بدونه، لا يمكن للمهارة أن تعمل.
      • رمّز الاستعلامات (URL-encode): يجب ترميز المسافات والرموز الخاصة في curl، أو استخدام urllib.parse.quote() في Python.
      • استخدم format=json: قد لا تكون الصيغة الافتراضية قابلة للقراءة الآلية. اطلب JSON صراحةً دائمًا.
      • اضبط مهلة زمنية: استخدم دائمًا --max-time أو timeout= لتفادي التعليق عند تعذّر الوصول إلى النسخة.
      • الاستضافة الذاتية هي الأفضل: قد تتعطل النسخ العامة أو تحدّ المعدل أو تحظر. النسخة المستضافة ذاتيًا موثوقة.

      اكتشاف النسخ​

      إذا لم يكن SEARXNG_URL مضبوطًا وسأل المستخدم عن SearXNG، ساعده على أحد الخيارين:

      1. إيجاد نسخة عامة من SearXNG (ابحث عن "public searxng instance")
      2. إعداد نسخته الخاصة عبر Docker أو pip

      تُدرَج النسخ العامة على: https://searxng.org/
