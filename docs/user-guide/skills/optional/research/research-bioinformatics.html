      Bioinformatics

      بوابة إلى أكثر من 400 مهارة في الجينوميات والأحياء الحاسوبية.

      بيانات المهارة الوصفية​

      المصدراختيارية — ثبّتها باستخدام hermes skills install official/research/bioinformatics
      المسارoptional-skills/research/bioinformatics
      الإصدار1.0.0
      المؤلفTeknium (teknium1)، Hermes Agent

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      بوابة مهارات المعلوماتية الحيوية (Bioinformatics)

      استخدمها عند السؤال عن المعلوماتية الحيوية، أو الجينوميات، أو التسلسل (sequencing)، أو استدعاء المتغيرات (variant calling)، أو التعبير الجيني، أو تحليل الخلية المفردة، أو بنية البروتين، أو الجينوميات الدوائية (pharmacogenomics)، أو الجينوميات الميتاجينية (metagenomics)، أو التطور الجيني (phylogenetics)، أو أي مهمة في الأحياء الحاسوبية.

      هذه المهارة بوابة إلى مكتبتَي مهارات معلوماتية حيوية مفتوحتَي المصدر. فبدلًا من تضمين مئات المهارات المتخصصة، تُفهرسها وتجلب ما تحتاجه عند الطلب.

      المصادر​

      ◆ bioSkills — 385 مهارة مرجعية (أنماط كود، أدلة معاملات، أشجار قرار) المستودع: https://github.com/GPTomics/bioSkills الصيغة: ملف SKILL.md لكل موضوع مع أمثلة كود. Python/R/CLI.

      ◆ ClawBio — 33 مهارة خط أنابيب قابلة للتشغيل (سكربتات تنفيذية، حزم لقابلية إعادة الإنتاج) المستودع: https://github.com/ClawBio/ClawBio الصيغة: سكربتات Python مع عروض توضيحية. كل تحليل يُصدِر report.md + commands.sh + environment.yml.

      كيفية جلب مهارة واستخدامها​

      1. حدّد المجال واسم المهارة من الفهرس أدناه.
      2. استنسخ (clone) المستودع المعني (استنساخ سطحي shallow clone لتوفير الوقت): 
        # bioSkills (reference material)
        git clone --depth 1 https://github.com/GPTomics/bioSkills.git /tmp/bioSkills

        # ClawBio (runnable pipelines)
        git clone --depth 1 https://github.com/ClawBio/ClawBio.git /tmp/ClawBio
      3. اقرأ المهارة المحددة: 
        # bioSkills — each skill is at: <category>/<skill-name>/SKILL.md
        cat /tmp/bioSkills/variant-calling/gatk-variant-calling/SKILL.md

        # ClawBio — each skill is at: skills/<skill-name>/
        cat /tmp/ClawBio/skills/pharmgx-reporter/README.md
      4. اتبع المهارة المجلوبة كمادة مرجعية. هذه المهارات ليست بصيغة Hermes — تعامل معها كأدلة خبراء في المجال. تحتوي على معاملات صحيحة، وخيارات أدوات مناسبة، وخطوط أنابيب مُتحقَّق منها.

      إعداد البيئة​

      تفترض هذه المهارات محطة عمل مخصصة للمعلوماتية الحيوية. الاعتماديات الشائعة:

      # Python
      pip install biopython pysam cyvcf2 pybedtools pyBigWig scikit-allel anndata scanpy mygene

      # R/Bioconductor
      Rscript -e 'BiocManager::install(c("DESeq2","edgeR","Seurat","clusterProfiler","methylKit"))'

      # CLI tools (Ubuntu/Debian)
      sudo apt install samtools bcftools ncbi-blast+ minimap2 bedtools

      # CLI tools (macOS)
      brew install samtools bcftools blast minimap2 bedtools

      # Or via Conda (recommended for reproducibility)
      conda install -c bioconda samtools bcftools blast minimap2 bedtools fastp kraken2

      مطبّات شائعة (Pitfalls)​

      • المهارات المجلوبة ليست بصيغة Hermes الخاصة بملفات SKILL.md، بل تستخدم بنيتها الخاصة (bioSkills: كتب أنماط كود؛ ClawBio: ملف README + سكربتات Python). اقرأها كمادة مرجعية من خبراء.
      • مهارات bioSkills أدلة مرجعية — تُظهر المعاملات وأنماط الكود الصحيحة لكنها ليست خطوط أنابيب قابلة للتنفيذ.
      • مهارات ClawBio قابلة للتنفيذ — يملك كثير منها خيار --demo ويمكن تشغيلها مباشرة.
      • يفترض كلا المستودعين أن أدوات المعلوماتية الحيوية مثبَّتة بالفعل. تحقق من المتطلبات الأساسية قبل تشغيل خطوط الأنابيب.
      • بالنسبة لـ ClawBio، شغّل pip install -r requirements.txt في المستودع المستنسخ أولًا.
      • يمكن أن تكون ملفات البيانات الجينومية كبيرة جدًا. انتبه لمساحة القرص عند تنزيل الجينومات المرجعية، أو مجموعات بيانات SRA، أو بناء الفهارس.
