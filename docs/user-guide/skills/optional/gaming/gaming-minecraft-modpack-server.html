      خادم حزم تعديلات Minecraft

      استضف خوادم Minecraft المُعدَّلة (CurseForge، Modrinth).

      بيانات المهارة الوصفية​

      المصدراختيارية — ثبّتها باستخدام hermes skills install official/gaming/minecraft-modpack-server
      المسارoptional-skills/gaming/minecraft-modpack-server
      الإصدار1.0.0
      المؤلفTeknium (teknium1)، Hermes Agent
      الترخيصMIT
      المنصاتlinux, macos

      المرجع: ملف SKILL.md كاملًا​

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      إعداد خادم حزمة تعديلات Minecraft

      متى تُستخدم​

      • يريد المستخدم إعداد خادم Minecraft مُعدَّل من ملف zip لحزمة الخادم
      • يحتاج المستخدم إلى مساعدة في إعداد NeoForge/Forge للخادم
      • يسأل المستخدم عن ضبط أداء خادم Minecraft أو النسخ الاحتياطي

      اجمع تفضيلات المستخدم أولًا​

      قبل بدء الإعداد، اسأل المستخدم عن:

      • اسم الخادم / رسالة اليوم (MOTD) — ماذا يجب أن يظهر في قائمة الخوادم؟
      • البذرة (Seed) — بذرة محددة أم عشوائية؟
      • الصعوبة — سلمية / سهلة / عادية / صعبة؟
      • نمط اللعب — البقاء / الإبداع / المغامرة؟
      • الوضع المتصل (Online mode) — صحيح (مصادقة Mojang، حسابات شرعية) أم خاطئ (مناسب لشبكة محلية/حسابات مقرصنة)؟
      • عدد اللاعبين — كم عدد اللاعبين المتوقع؟ (يؤثر على ضبط الذاكرة العشوائية ومسافة الرؤية)
      • تخصيص الذاكرة العشوائية (RAM) — أم تترك الوكيل يقرر بناءً على عدد التعديلات والذاكرة المتاحة؟
      • مسافة الرؤية / مسافة المحاكاة — أم تترك الوكيل يختار بناءً على عدد اللاعبين والعتاد؟
      • PvP — مفعّل أم معطّل؟
      • القائمة البيضاء — خادم مفتوح أم قائمة بيضاء فقط؟
      • النسخ الاحتياطي — هل تريد نسخًا احتياطيًا تلقائيًا؟ كم مرة؟

      استخدم قيمًا افتراضية معقولة إذا لم يهتم المستخدم، لكن اسأل دائمًا قبل توليد الإعدادات.

      الخطوات​

      1. نزّل الحزمة وافحصها​

      mkdir -p ~/minecraft-server
      cd ~/minecraft-server
      wget -O serverpack.zip "<URL>"
      unzip -o serverpack.zip -d server
      ls server/

      ابحث عن: startserver.sh، وملف تثبيت jar (neoforge/forge)، وuser_jvm_args.txt، ومجلد mods/. تحقّق من السكربت لتحديد: نوع مُحمِّل التعديلات، والإصدار، وإصدار Java المطلوب.

      2. ثبّت Java​

      • Minecraft 1.21+ ← Java 21: sudo apt install openjdk-21-jre-headless
      • Minecraft 1.18-1.20 ← Java 17: sudo apt install openjdk-17-jre-headless
      • Minecraft 1.16 وما دونه ← Java 8: sudo apt install openjdk-8-jre-headless
      • تحقّق: java -version

      3. ثبّت مُحمِّل التعديلات​

      تتضمن معظم حزم الخادم سكربت تثبيت. استخدم متغير البيئة INSTALL_ONLY للتثبيت دون التشغيل:

      cd ~/minecraft-server/server
      ATM10_INSTALL_ONLY=true bash startserver.sh
      # Or for generic Forge packs:
      # java -jar forge-*-installer.jar --installServer

      يقوم هذا بتنزيل المكتبات، وتصحيح ملف jar الخاص بالخادم، إلخ.

      4. اقبل اتفاقية الترخيص (EULA)​

      echo "eula=true" > ~/minecraft-server/server/eula.txt

      5. اضبط server.properties​

      الإعدادات الرئيسية للخوادم المُعدَّلة/الشبكة المحلية:

      motd=\u00a7b\u00a7lServer Name \u00a7r\u00a78| \u00a7aModpack Name
      server-port=25565
      online-mode=true          # false for LAN without Mojang auth
      enforce-secure-profile=true  # match online-mode
      difficulty=hard            # most modpacks balance around hard
      allow-flight=true          # REQUIRED for modded (flying mounts/items)
      spawn-protection=0         # let everyone build at spawn
      max-tick-time=180000       # modded needs longer tick timeout
      enable-command-block=true

      إعدادات الأداء (اضبطها حسب العتاد):

      # 2 players, beefy machine:
      view-distance=16
      simulation-distance=10

      # 4-6 players, moderate machine:
      view-distance=10
      simulation-distance=6

      # 8+ players or weaker hardware:
      view-distance=8
      simulation-distance=4

      6. اضبط معطيات JVM (user_jvm_args.txt)​

      اضبط الذاكرة العشوائية حسب عدد اللاعبين وعدد التعديلات. قاعدة عامة للخوادم المُعدَّلة:

      • 100-200 تعديل: 6-12 جيجابايت
      • 200-350+ تعديل: 12-24 جيجابايت
      • اترك 8 جيجابايت على الأقل حرة لنظام التشغيل/المهام الأخرى
      -Xms12G
      -Xmx24G
      -XX:+UseG1GC
      -XX:+ParallelRefProcEnabled
      -XX:MaxGCPauseMillis=200
      -XX:+UnlockExperimentalVMOptions
      -XX:+DisableExplicitGC
      -XX:+AlwaysPreTouch
      -XX:G1NewSizePercent=30
      -XX:G1MaxNewSizePercent=40
      -XX:G1HeapRegionSize=8M
      -XX:G1ReservePercent=20
      -XX:G1HeapWastePercent=5
      -XX:G1MixedGCCountTarget=4
      -XX:InitiatingHeapOccupancyPercent=15
      -XX:G1MixedGCLiveThresholdPercent=90
      -XX:G1RSetUpdatingPauseTimePercent=5
      -XX:SurvivorRatio=32
      -XX:+PerfDisableSharedMem
      -XX:MaxTenuringThreshold=1

      7. افتح جدار الحماية​

      sudo ufw allow 25565/tcp comment "Minecraft Server"

      تحقّق باستخدام: sudo ufw status | grep 25565

      8. أنشئ سكربت تشغيل​

      cat > ~/start-minecraft.sh << 'EOF'
      #!/bin/bash
      cd ~/minecraft-server/server
      java @user_jvm_args.txt @libraries/net/neoforged/neoforge/<VERSION>/unix_args.txt nogui
      EOF
      chmod +x ~/start-minecraft.sh

      ملاحظة: بالنسبة لـ Forge (وليس NeoForge)، يختلف مسار ملف المعطيات. تحقّق من startserver.sh لمعرفة المسار الدقيق.

      9. أعِدَّ النسخ الاحتياطي التلقائي​

      أنشئ سكربت النسخ الاحتياطي:

      cat > ~/minecraft-server/backup.sh << 'SCRIPT'
      #!/bin/bash
      SERVER_DIR="$HOME/minecraft-server/server"
      BACKUP_DIR="$HOME/minecraft-server/backups"
      WORLD_DIR="$SERVER_DIR/world"
      MAX_BACKUPS=24
      mkdir -p "$BACKUP_DIR"
      [ ! -d "$WORLD_DIR" ] && echo "[BACKUP] No world folder" && exit 0
      TIMESTAMP=$(date +%Y-%m-%d_%H-%M-%S)
      BACKUP_FILE="$BACKUP_DIR/world_${TIMESTAMP}.tar.gz"
      echo "[BACKUP] Starting at $(date)"
      tar -czf "$BACKUP_FILE" -C "$SERVER_DIR" world
      SIZE=$(du -h "$BACKUP_FILE" | cut -f1)
      echo "[BACKUP] Saved: $BACKUP_FILE ($SIZE)"
      BACKUP_COUNT=$(ls -1t "$BACKUP_DIR"/world_*.tar.gz 2>/dev/null | wc -l)
      if [ "$BACKUP_COUNT" -gt "$MAX_BACKUPS" ]; then
          REMOVE=$((BACKUP_COUNT - MAX_BACKUPS))
          ls -1t "$BACKUP_DIR"/world_*.tar.gz | tail -n "$REMOVE" | xargs rm -f
          echo "[BACKUP] Pruned $REMOVE old backup(s)"
      fi
      echo "[BACKUP] Done at $(date)"
      SCRIPT
      chmod +x ~/minecraft-server/backup.sh

      أضِف مهمة cron كل ساعة:

      (crontab -l 2>/dev/null | grep -v "minecraft/backup.sh"; echo "0 * * * * $HOME/minecraft-server/backup.sh >> $HOME/minecraft-server/backups/backup.log 2>&1") | crontab -

      مزالق شائعة​

      • اضبط دائمًا allow-flight=true للخوادم المُعدَّلة — التعديلات التي تحتوي على نفاثات/طيران ستطرد اللاعبين وإلا
      • max-tick-time=180000 أو أعلى — غالبًا ما تكون للخوادم المُعدَّلة دورات (ticks) طويلة أثناء توليد العالم
      • التشغيل الأول بطيء (عدة دقائق للحزم الكبيرة) — لا داعي للقلق
      • تحذيرات "Can't keep up!" عند التشغيل الأول طبيعية، وتستقر بعد توليد القطع (chunks) الأولي
      • إذا كان online-mode=false، اضبط enforce-secure-profile=false أيضًا وإلا سيُرفض العملاء
      • غالبًا ما يحتوي startserver.sh الخاص بالحزمة على حلقة إعادة تشغيل تلقائية — أنشئ سكربت تشغيل نظيف بدونها
      • احذف مجلد world/ لإعادة التوليد ببذرة جديدة
      • بعض الحزم لديها متغيرات بيئة للتحكم بالسلوك (مثلًا، تستخدم ATM10: ATM10_JAVA وATM10_RESTART وATM10_INSTALL_ONLY)

      التحقق​

      • pgrep -fa neoforge أو pgrep -fa minecraft للتحقق مما إذا كان قيد التشغيل
      • تحقّق من السجلات: tail -f ~/minecraft-server/server/logs/latest.log
      • ابحث عن "Done (Xs)!" في السجل = الخادم جاهز
      • اختبر الاتصال: يضيف اللاعب عنوان IP الخاص بالخادم في وضع اللاعبين المتعددين
