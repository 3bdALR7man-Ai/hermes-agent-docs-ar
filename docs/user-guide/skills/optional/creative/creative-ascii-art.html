      فن ASCII

      فن ASCII: pyfiglet وcowsay وboxes وتحويل الصور إلى ASCII.

      بيانات المهارة الوصفية​

      المصدراختيارية — ثبّتها باستخدام hermes skills install official/creative/ascii-art
      المسارoptional-skills/creative/ascii-art
      الإصدار4.0.0
      المؤلف0xbyt4, Hermes Agent
      الترخيصMIT
      المنصاتlinux, macos, windows
      الوسومASCII, Art, Banners, Creative, Unicode, Text-Art, pyfiglet, figlet, cowsay, boxes
      مهارات ذات صلةexcalidraw

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      مهارة فن ASCII

      أدوات متعددة لاحتياجات مختلفة من فن ASCII. جميع الأدوات إما برامج CLI محلية أو REST APIs مجانية — لا حاجة لمفاتيح API.

      الأداة 1: لافتات نصية (pyfiglet — محلية)​

      عرض النص كلافتات فن ASCII كبيرة. 571 خطًا مدمجًا.

      الإعداد​

      pip install pyfiglet --break-system-packages -q

      الاستخدام​

      python -m pyfiglet "YOUR TEXT" -f slant
      python -m pyfiglet "TEXT" -f doom -w 80    # Set width
      python -m pyfiglet --list_fonts             # List all 571 fonts

      الخطوط الموصى بها​

      النمطالخطالأنسب لـ
      نظيف وعصريslantأسماء المشاريع، العناوين
      عريض ومتكتلdoomالعناوين، الشعارات
      كبير وواضحbigاللافتات
      لافتة كلاسيكيةbanner3الشاشات العريضة
      مضغوطsmallالعناوين الفرعية
      سايبربانكcyberlargeالمواضيع التقنية
      تأثير ثلاثي الأبعاد3-dشاشات الافتتاح
      قوطيgothicنص درامي

      نصائح​

      • اعرض 2-3 خطوط ودع المستخدم يختار الخط المفضل لديه
      • النص القصير (1-8 أحرف) يعمل بشكل أفضل مع الخطوط التفصيلية مثل doom أو block
      • النص الطويل يعمل بشكل أفضل مع الخطوط المضغوطة مثل small أو mini

      الأداة 2: لافتات نصية (asciified API — عن بُعد، بلا تثبيت)​

      واجهة REST API مجانية تحوّل النص إلى فن ASCII. أكثر من 250 خط FIGlet. تُعيد نصًا عاديًا مباشرة — دون حاجة لتحليل. استخدمها عندما لا يكون pyfiglet مثبّتًا أو كبديل سريع.

      الاستخدام (عبر الطرفية باستخدام curl)​

      # Basic text banner (default font)
      curl -s "https://asciified.thelicato.io/api/v2/ascii?text=Hello+World"

      # With a specific font
      curl -s "https://asciified.thelicato.io/api/v2/ascii?text=Hello&font=Slant"
      curl -s "https://asciified.thelicato.io/api/v2/ascii?text=Hello&font=Doom"
      curl -s "https://asciified.thelicato.io/api/v2/ascii?text=Hello&font=Star+Wars"
      curl -s "https://asciified.thelicato.io/api/v2/ascii?text=Hello&font=3-D"
      curl -s "https://asciified.thelicato.io/api/v2/ascii?text=Hello&font=Banner3"

      # List all available fonts (returns JSON array)
      curl -s "https://asciified.thelicato.io/api/v2/fonts"

      نصائح​

      • رمّز المسافات في معامل النص كـ +
      • الاستجابة نص عادي على شكل فن ASCII — بدون تغليف JSON، جاهز للعرض مباشرة
      • أسماء الخطوط حساسة لحالة الأحرف؛ استخدم نقطة نهاية الخطوط (fonts endpoint) للحصول على الأسماء الدقيقة
      • يعمل من أي طرفية تحتوي curl — لا حاجة لـ Python أو pip

      الأداة 3: Cowsay (فن الرسائل)​

      أداة كلاسيكية تضع النص داخل فقاعة كلام مع شخصية من فن ASCII.

      الإعداد​

      sudo apt install cowsay -y    # Debian/Ubuntu
      # brew install cowsay         # macOS

      الاستخدام​

      cowsay "Hello World"
      cowsay -f tux "Linux rules"       # Tux the penguin
      cowsay -f dragon "Rawr!"          # Dragon
      cowsay -f stegosaurus "Roar!"     # Stegosaurus
      cowthink "Hmm..."                  # Thought bubble
      cowsay -l                          # List all characters

      الشخصيات المتاحة (أكثر من 50)​

      beavis.zen, bong, bunny, cheese, daemon, default, dragon, dragon-and-cow, elephant, eyes, flaming-skull, ghostbusters, hellokitty, kiss, kitty, koala, luke-koala, mech-and-cow, meow, moofasa, moose, ren, sheep, skeleton, small, stegosaurus, stimpy, supermilker, surgery, three-eyes, turkey, turtle, tux, udder, vader, vader-koala, www

      مُعدِّلات العين/اللسان​

      cowsay -b "Borg"       # =_= eyes
      cowsay -d "Dead"       # x_x eyes
      cowsay -g "Greedy"     # $_$ eyes
      cowsay -p "Paranoid"   # @_@ eyes
      cowsay -s "Stoned"     # *_* eyes
      cowsay -w "Wired"      # O_O eyes
      cowsay -e "OO" "Msg"   # Custom eyes
      cowsay -T "U " "Msg"   # Custom tongue

      الأداة 4: Boxes (حدود زخرفية)​

      رسم حدود/إطارات زخرفية من فن ASCII حول أي نص. أكثر من 70 تصميمًا مدمجًا.

      الإعداد​

      sudo apt install boxes -y    # Debian/Ubuntu
      # brew install boxes         # macOS

      الاستخدام​

      echo "Hello World" | boxes                    # Default box
      echo "Hello World" | boxes -d stone           # Stone border
      echo "Hello World" | boxes -d parchment       # Parchment scroll
      echo "Hello World" | boxes -d cat             # Cat border
      echo "Hello World" | boxes -d dog             # Dog border
      echo "Hello World" | boxes -d unicornsay      # Unicorn
      echo "Hello World" | boxes -d diamonds        # Diamond pattern
      echo "Hello World" | boxes -d c-cmt           # C-style comment
      echo "Hello World" | boxes -d html-cmt        # HTML comment
      echo "Hello World" | boxes -a c               # Center text
      boxes -l                                       # List all 70+ designs

      الجمع مع pyfiglet أو asciified​

      python -m pyfiglet "HERMES" -f slant | boxes -d stone
      # Or without pyfiglet installed:
      curl -s "https://asciified.thelicato.io/api/v2/ascii?text=HERMES&font=Slant" | boxes -d stone

      الأداة 5: TOIlet (فن نصي ملوّن)​

      مثل pyfiglet لكن مع تأثيرات ألوان ANSI ومرشحات بصرية. رائعة لإضفاء جمالية على الطرفية.

      الإعداد​

      sudo apt install toilet toilet-fonts -y    # Debian/Ubuntu
      # brew install toilet                      # macOS

      الاستخدام​

      toilet "Hello World"                    # Basic text art
      toilet -f bigmono12 "Hello"            # Specific font
      toilet --gay "Rainbow!"                 # Rainbow coloring
      toilet --metal "Metal!"                 # Metallic effect
      toilet -F border "Bordered"             # Add border
      toilet -F border --gay "Fancy!"         # Combined effects
      toilet -f pagga "Block"                 # Block-style font (unique to toilet)
      toilet -F list                          # List available filters

      المرشحات​

      crop, gay (قوس قزح), metal, flip, flop, 180, left, right, border

      ملاحظة: يُخرج toilet رموز إفلات ANSI (ANSI escape codes) للألوان — تعمل في الطرفيات لكن قد لا تُعرض في كل السياقات (مثل ملفات النصوص العادية، وبعض منصات المحادثة).

      الأداة 6: تحويل صورة إلى فن ASCII​

      تحويل الصور (PNG وJPEG وGIF وWEBP) إلى فن ASCII.

      الخيار أ: ascii-image-converter (موصى به، حديث)​

      # Install
      sudo snap install ascii-image-converter
      # OR: go install github.com/TheZoraiz/ascii-image-converter@latest
      ascii-image-converter image.png                  # Basic
      ascii-image-converter image.png -C               # Color output
      ascii-image-converter image.png -d 60,30         # Set dimensions
      ascii-image-converter image.png -b               # Braille characters
      ascii-image-converter image.png -n               # Negative/inverted
      ascii-image-converter https://url/image.jpg      # Direct URL
      ascii-image-converter image.png --save-txt out   # Save as text

      الخيار ب: jp2a (خفيف، JPEG فقط)​

      sudo apt install jp2a -y
      jp2a --width=80 image.jpg
      jp2a --colors image.jpg              # Colorized

      الأداة 7: البحث عن فن ASCII جاهز​

      البحث عن فن ASCII منسّق من الويب. استخدم terminal مع curl.

      المصدر أ: ascii.co.uk (موصى به للفن الجاهز)​

      مجموعة كبيرة من فن ASCII الكلاسيكي مُنظّمة حسب الموضوع. الفن موجود داخل وسوم HTML من نوع <pre>. اجلب الصفحة باستخدام curl، ثم استخرج الفن باستخدام مقتطف Python صغير.

      نمط الرابط: https://ascii.co.uk/art/{subject}

      الخطوة 1 — جلب الصفحة:

      curl -s 'https://ascii.co.uk/art/cat' -o /tmp/ascii_art.html

      الخطوة 2 — استخراج الفن من وسوم pre:

      import re, html
      with open('/tmp/ascii_art.html') as f:
          text = f.read()
      arts = re.findall(r'<pre[^>]*>(.*?)</pre>', text, re.DOTALL)
      for art in arts:
          clean = re.sub(r'<[^>]+>', '', art)
          clean = html.unescape(clean).strip()
          if len(clean) > 30:
              print(clean)
              print('\n---\n')

      المواضيع المتاحة (استخدمها كمسار في الرابط):

      • الحيوانات: cat, dog, horse, bird, fish, dragon, snake, rabbit, elephant, dolphin, butterfly, owl, wolf, bear, penguin, turtle
      • الأشياء: car, ship, airplane, rocket, guitar, computer, coffee, beer, cake, house, castle, sword, crown, key
      • الطبيعة: tree, flower, sun, moon, star, mountain, ocean, rainbow
      • الشخصيات: skull, robot, angel, wizard, pirate, ninja, alien
      • الأعياد: christmas, halloween, valentine

      نصائح:

      • حافظ على توقيعات/مبادرات الفنانين — من آداب التعامل المهمة
      • هناك قطع فن متعددة في كل صفحة — اختر الأنسب للمستخدم
      • يعمل بشكل موثوق عبر curl، دون حاجة لـ JavaScript

      المصدر ب: GitHub Octocat API (مفاجأة طريفة)​

      يُعيد شخصية Octocat عشوائية من GitHub مع اقتباس حكيم. لا حاجة لمصادقة.

      curl -s https://api.github.com/octocat

      الأداة 8: أدوات ASCII طريفة (عبر curl)​

      هذه الخدمات المجانية تُعيد فن ASCII مباشرة — رائعة كإضافات طريفة.

      رموز QR كفن ASCII​

      curl -s "qrenco.de/Hello+World"
      curl -s "qrenco.de/https://example.com"

      الطقس كفن ASCII​

      curl -s "wttr.in/London"          # Full weather report with ASCII graphics
      curl -s "wttr.in/Moon"            # Moon phase in ASCII art
      curl -s "v2.wttr.in/London"       # Detailed version

      الأداة 9: فن مخصّص يولّده LLM (خيار احتياطي)​

      عندما لا تتوفر الأدوات السابقة لما هو مطلوب، ولّد فن ASCII مباشرة باستخدام أحرف Unicode التالية:

      لوحة الأحرف​

      رسم الصناديق: ╔ ╗ ╚ ╝ ║ ═ ╠ ╣ ╦ ╩ ╬ ┌ ┐ └ ┘ │ ─ ├ ┤ ┬ ┴ ┼ ╭ ╮ ╰ ╯

      عناصر الكتل: ░ ▒ ▓ █ ▄ ▀ ▌ ▐ ▖ ▗ ▘ ▝ ▚ ▞

      الأشكال الهندسية والرموز: ◆ ◇ ◈ ● ○ ◉ ■ □ ▲ △ ▼ ▽ ★ ☆ ✦ ✧ ◀ ▶ ◁ ▷ ⬡ ⬢ ⌂

      القواعد​

      • أقصى عرض: 60 حرفًا في السطر (آمن للطرفية)
      • أقصى ارتفاع: 15 سطرًا للافتات، 25 للمشاهد
      • عرض ثابت فقط: يجب أن يُعرض الناتج بشكل صحيح في الخطوط ذات العرض الثابت

      مخطط القرار​

      1. نص كلافتة → pyfiglet إذا كان مثبّتًا، وإلا asciified API عبر curl
      2. وضع رسالة داخل فن شخصية طريفة → cowsay
      3. إضافة حدود/إطار زخرفي → boxes (يمكن دمجها مع pyfiglet/asciified)
      4. فن لشيء محدد (قطة، صاروخ، تنين) → ascii.co.uk عبر curl + التحليل
      5. تحويل صورة إلى ASCII → ascii-image-converter أو jp2a
      6. رمز QR → qrenco.de عبر curl
      7. فن الطقس/القمر → wttr.in عبر curl
      8. شيء مخصّص/إبداعي → توليد بواسطة LLM باستخدام لوحة Unicode
      9. أي أداة غير مثبّتة → ثبّتها، أو ارجع إلى الخيار التالي
