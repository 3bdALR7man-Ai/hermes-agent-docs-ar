      فن البكسل (Pixel Art)

      فن بكسل بلوحات ألوان عصور قديمة (NES، Game Boy، PICO-8).

      بيانات المهارة الوصفية​

      المصدراختيارية — ثبّتها باستخدام hermes skills install official/creative/pixel-art
      المسارoptional-skills/creative/pixel-art
      الإصدار2.0.0
      المؤلفdodo-reach
      الترخيصMIT
      المنصاتlinux, macos, windows
      الوسومcreative, pixel-art, arcade, snes, nes, gameboy, retro, image, video

      المرجع: ملف SKILL.md كاملًا​

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      فن البكسل (Pixel Art)

      حوّل أي صورة إلى فن بكسل بطابع قديم، ثم حرّكها اختياريًا في مقطع MP4 أو GIF قصير مع تأثيرات مناسبة للعصر (مطر، يراعات، ثلج، جمرات).

      يأتي مع هذه المهارة سكربتان:

      • scripts/pixel_art.py — صورة ← PNG فن بكسل (تظليل Floyd-Steinberg)
      • scripts/pixel_art_video.py — PNG فن بكسل ← فيديو MP4 متحرك (+ GIF اختياري)

      كل منهما قابل للاستيراد أو للتشغيل المباشر. تنطبق الإعدادات المسبقة (presets) على لوحات ألوان الأجهزة عندما تريد ألوانًا مطابقة للعصر (NES، Game Boy، PICO-8، إلخ)، أو استخدم التكميم التكيّفي بعدد ألوان N للحصول على مظهر بطراز الأركيد/SNES.

      متى تُستخدم​

      • يريد المستخدم فن بكسل قديم الطابع من صورة مصدر
      • يطلب المستخدم طابع NES / Game Boy / PICO-8 / C64 / أركيد / SNES
      • يريد المستخدم رسمًا متحركًا قصيرًا متكررًا (مشهد مطر، سماء ليلية، ثلج، إلخ)
      • الملصقات، أغلفة الألبومات، منشورات التواصل الاجتماعي، الشخصيات المتحركة (sprites)، الشخصيات، الصور الرمزية

      سير العمل​

      قبل التوليد، تأكّد من النمط مع المستخدم. تنتج الإعدادات المسبقة المختلفة مخرجات مختلفة جدًا، وإعادة التوليد مكلفة.

      الخطوة 1 — اعرض نمطًا​

      استدعِ clarify مع 4 إعدادات مسبقة تمثيلية. اختر المجموعة بناءً على ما طلبه المستخدم — لا تعرض الأنماط الـ14 كلها دفعة واحدة.

      القائمة الافتراضية عندما يكون قصد المستخدم غير واضح:

      clarify(
          question="Which pixel-art style do you want?",
          choices=[
              "arcade — bold, chunky 80s cabinet feel (16 colors, 8px)",
              "nes — Nintendo 8-bit hardware palette (54 colors, 8px)",
              "gameboy — 4-shade green Game Boy DMG",
              "snes — cleaner 16-bit look (32 colors, 4px)",
          ],
      )

      عندما يذكر المستخدم عصرًا بالفعل (مثل "80s arcade" أو "Gameboy")، تخطَّ clarify واستخدم الإعداد المسبق المطابق مباشرة.

      الخطوة 2 — اعرض التحريك (اختياري)​

      إذا طلب المستخدم فيديو/GIF، أو قد يستفيد الناتج من الحركة، اسأل عن المشهد المطلوب:

      clarify(
          question="Want to animate it? Pick a scene or skip.",
          choices=[
              "night — stars + fireflies + leaves",
              "urban — rain + neon pulse",
              "snow — falling snowflakes",
              "skip — just the image",
          ],
      )

      لا تستدعِ clarify أكثر من مرتين متتاليتين. مرة للنمط، ومرة للمشهد إذا كان التحريك مطروحًا. إذا حدّد المستخدم صراحة نمطًا ومشهدًا في رسالته، تخطَّ clarify تمامًا.

      الخطوة 3 — التوليد​

      شغّل pixel_art() أولًا؛ إذا طُلب التحريك، تابع بتمرير الناتج إلى pixel_art_video().

      أنماط الاستدعاء​

      Python (استيراد)​

      import sys
      import os
      sys.path.insert(0, os.path.expanduser("~/.hermes/skills/creative/pixel-art/scripts"))
      from pixel_art import pixel_art
      from pixel_art_video import pixel_art_video

      # 1. Convert to pixel art
      pixel_art("/path/to/photo.jpg", "/tmp/pixel.png", preset="nes")

      # 2. Animate (optional)
      pixel_art_video(
          "/tmp/pixel.png",
          "/tmp/pixel.mp4",
          scene="night",
          duration=6,
          fps=15,
          seed=42,
          export_gif=True,
      )

      CLI​

      cd ~/.hermes/skills/creative/pixel-art/scripts

      python pixel_art.py in.jpg out.png --preset gameboy
      python pixel_art.py in.jpg out.png --preset snes --palette PICO_8 --block 6

      python pixel_art_video.py out.png out.mp4 --scene night --duration 6 --gif

      أساس الـ pipeline​

      تحويل البكسل:

      1. عزّز التباين/الألوان/الحدة (بقوة أكبر للوحات الألوان الأصغر)
      2. طبّق Posterize لتبسيط المناطق اللونية قبل التكميم
      3. قلّص الحجم بمقدار block باستخدام Image.NEAREST (بكسلات حادة، بدون استيفاء)
      4. كمِّم باستخدام تظليل Floyd-Steinberg — مقابل لوحة ألوان تكيّفية بعدد N من الألوان أو لوحة ألوان أجهزة مسمّاة
      5. كبّر الحجم مجددًا باستخدام Image.NEAREST

      يحافظ التكميم بعد التصغير على توافق التظليل مع شبكة البكسل النهائية. أما التكميم قبل ذلك فسيهدر انتشار الخطأ على تفاصيل ستختفي لاحقًا.

      تراكب الفيديو:

      • ينسخ الإطار الأساسي في كل نبضة زمنية (خلفية ثابتة)
      • يراكب رسومات جسيمات عديمة الحالة لكل إطار (دالة واحدة لكل تأثير)
      • يُرمّز عبر ffmpeg بـ libx264 -pix_fmt yuv420p -crf 18
      • GIF اختياري عبر palettegen + paletteuse

      الاعتماديات​

      • Python 3.9+
      • Pillow (pip install Pillow)
      • ffmpeg متاح في PATH (مطلوب فقط للفيديو — يثبّته Hermes تلقائيًا كحزمة)

      مزالق شائعة​

      • مفاتيح لوحات الألوان حساسة لحالة الأحرف ("NES"، "PICO_8"، "GAMEBOY_ORIGINAL").
      • الصور المصدر الصغيرة جدًا (أقل من 100 بكسل عرضًا) تنهار تحت كتل بحجم 8-10 بكسل. كبّر الصورة المصدر أولًا إذا كانت صغيرة جدًا.
      • القيم الكسرية لـ block أو palette ستكسر التكميم — أبقِها أعدادًا صحيحة موجبة.
      • عدد جسيمات التحريك مضبوط لقماشات (canvases) بحجم 640×480 تقريبًا. في الصور الكبيرة جدًا قد تحتاج إلى تمريرة ثانية ببذرة (seed) مختلفة للكثافة.
      • يفرض mono_green / mono_amber القيمة color=0.0 (إزالة التشبع). إذا تجاوزت هذا وأبقيت على درجة اللون (chroma)، فقد تنتج لوحة الألوان ثنائية اللون خطوطًا على المناطق الملساء.
      • حلقة clarify: استدعِها مرتين على الأكثر لكل دور محادثة (النمط، ثم المشهد). لا تُثقل على المستخدم بمزيد من الاختيارات.

      التحقّق​

      • تم إنشاء PNG في مسار الإخراج
      • كتل بكسل مربعة واضحة تظهر بحجم الكتلة الخاص بالإعداد المسبق
      • عدد الألوان يطابق الإعداد المسبق (افحص الصورة بالعين أو شغّل Image.open(p).getcolors())
      • الفيديو ملف MP4 صالح (يمكن لـ ffprobe فتحه) بحجم غير صفري

      الإسناد​

      لوحات ألوان الأجهزة المسمّاة وحلقات التحريك الإجرائية في pixel_art_video.py منقولة من pixel-art-studio (ترخيص MIT). راجع ATTRIBUTION.md في مجلد هذه المهارة للتفاصيل.
