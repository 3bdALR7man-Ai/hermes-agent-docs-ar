      توليد الميمز (Meme Generation)

      أنشئ صور ميمز بصيغة PNG من قوالب مع تراكب نص باستخدام Pillow.

      بيانات المهارة الوصفية​

      المصدراختيارية — ثبّتها باستخدام hermes skills install official/creative/meme-generation
      المسارoptional-skills/creative/meme-generation
      الإصدار2.0.0
      المؤلفadanaleycio
      الترخيصMIT
      المنصاتlinux, macos, windows
      الوسومcreative, memes, humor, images
      مهارات ذات صلةascii-art

      المرجع: ملف SKILL.md كاملًا​

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      توليد الميمز (Meme Generation)

      ولّد صور ميمز حقيقية من موضوع معيّن. تختار المهارة قالبًا، وتكتب التعليقات، وتُصدر ملف .png فعليًا مع تراكب نص.

      متى تُستخدم​

      • يطلب المستخدم منك صنع أو توليد ميم
      • يريد المستخدم ميمًا عن موضوع أو موقف أو إحباط معيّن
      • يقول المستخدم "meme this" أو ما شابه

      القوالب المتاحة​

      يدعم السكربت أيًا من قوالب imgflip الشائعة الـ100 تقريبًا بالاسم أو بالمعرّف (ID)، إضافة إلى 10 قوالب منتقاة بعناية مع مواضع نص مضبوطة يدويًا.

      القوالب الديناميكية (من imgflip API)​

      يمكن استخدام أي قالب غير موجود في القائمة المنتقاة بالاسم أو بمعرّف imgflip. تحصل هذه القوالب على موضع نص افتراضي ذكي (أعلى/أسفل لحقلين، وتوزيع متساوٍ لثلاثة حقول أو أكثر). ابحث باستخدام:

      python "$SKILL_DIR/scripts/generate_meme.py" --search "disaster"

      الإجراء​

      النمط 1: القالب الكلاسيكي (الافتراضي)​

      1. اقرأ موضوع المستخدم وحدّد الديناميكية الأساسية (الفوضى، المعضلة، التفضيل، التهكم، إلخ).
      2. اختر القالب الأنسب. استخدم عمود "الأنسب لـ"، أو ابحث باستخدام --search.
      3. اكتب تعليقات قصيرة لكل حقل (8-12 كلمة كحد أقصى لكل حقل، والأقصر أفضل).
      4. حدّد مجلد سكربتات المهارة: 
        SKILL_DIR=$(dirname "$(find ~/.hermes/skills -path '*/meme-generation/SKILL.md' 2>/dev/null | head -1)")
      5. شغّل المولّد: 
        python "$SKILL_DIR/scripts/generate_meme.py" <template_id> /tmp/meme.png "caption 1" "caption 2" ...
      6. أعِد الصورة عبر MEDIA:/tmp/meme.png

      النمط 2: صورة مخصّصة بالذكاء الاصطناعي (عند توفر image_generate)​

      استخدم هذا النمط عندما لا يناسب أي قالب كلاسيكي، أو عندما يريد المستخدم شيئًا أصليًا.

      1. اكتب التعليقات أولًا.
      2. استخدم image_generate لإنشاء مشهد يطابق فكرة الميم. لا تُدرِج أي نص في الـ prompt الخاص بالصورة — سيضيف السكربت النص لاحقًا. اوصف المشهد المرئي فقط.
      3. حدّد مسار الصورة المولَّدة من رابط نتيجة image_generate. نزّلها إلى مسار محلي إذا لزم الأمر.
      4. شغّل السكربت مع --image لتراكب النص، واختر نمطًا:
        • Overlay (نص مباشرة على الصورة، أبيض بحدّ أسود): 
          python "$SKILL_DIR/scripts/generate_meme.py" --image /path/to/scene.png /tmp/meme.png "top text" "bottom text"
        • Bars (أشرطة سوداء أعلى/أسفل مع نص أبيض — أنظف وواضح دائمًا): 
          python "$SKILL_DIR/scripts/generate_meme.py" --image /path/to/scene.png --bars /tmp/meme.png "top text" "bottom text"
        استخدم --bars عندما تكون الصورة مزدحمة/مليئة بالتفاصيل ويصعب قراءة النص فوقها.
      5. تحقّق بالرؤية (إذا كان vision_analyze متاحًا): تأكّد أن النتيجة تبدو جيدة: 
        vision_analyze(image_url="/tmp/meme.png", question="Is the text legible and well-positioned? Does the meme work visually?")
        إذا أشار نموذج الرؤية إلى مشكلات (صعوبة قراءة النص، موضع سيئ، إلخ)، جرّب النمط الآخر (بدّل بين overlay و bars) أو أعِد توليد المشهد.
      6. أعِد الصورة عبر MEDIA:/tmp/meme.png

      أمثلة​

      "debugging production at 2 AM":

      python generate_meme.py this-is-fine /tmp/meme.png "SERVERS ARE ON FIRE" "This is fine"

      "choosing between sleep and one more episode":

      python generate_meme.py drake /tmp/meme.png "Getting 8 hours of sleep" "One more episode at 3 AM"

      "the stages of a Monday morning":

      python generate_meme.py expanding-brain /tmp/meme.png "Setting an alarm" "Setting 5 alarms" "Sleeping through all alarms" "Working from bed"

      سرد القوالب​

      لعرض جميع القوالب المتاحة:

      python generate_meme.py --list

      مزالق شائعة​

      • حافظ على قِصر التعليقات. الميمز ذات النص الطويل تبدو سيئة.
      • طابق عدد وسائط النص مع عدد حقول القالب.
      • اختر القالب المناسب لبنية النكتة، لا لمجرد الموضوع فقط.
      • لا تولّد محتوى كارهًا أو مسيئًا أو يستهدف أشخاصًا بعينهم.
      • يخزّن السكربت صور القوالب مؤقتًا في scripts/.cache/ بعد أول تنزيل.

      التحقّق​

      يكون الناتج صحيحًا إذا:

      • تم إنشاء ملف .png في مسار الإخراج
      • النص واضح للقراءة (أبيض بحدّ أسود) على القالب
      • النكتة تصيب هدفها — التعليق يطابق البنية المقصودة للقالب
