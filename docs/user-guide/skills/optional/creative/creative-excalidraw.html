      Excalidraw

      مخططات Excalidraw بصيغة JSON بطابع مرسوم يدويًا (بنية، تدفّق، تسلسل).

      بيانات المهارة الوصفية​

      المصدراختيارية — ثبّتها باستخدام hermes skills install official/creative/excalidraw
      المسارoptional-skills/creative/excalidraw
      الإصدار1.0.1
      المؤلفHermes Agent
      الترخيصMIT
      المنصاتlinux, macos, windows
      الوسومExcalidraw, Diagrams, Flowcharts, Architecture, Visualization, JSON

      المرجع: ملف SKILL.md كاملًا​

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      Excalidraw Diagram Skill

      أنشئ مخططات بكتابة JSON قياسي لعناصر Excalidraw وحفظه كملفات .excalidraw. يمكن سحب هذه الملفات وإفلاتها في excalidraw.com للعرض والتحرير. دون حسابات، ودون مفاتيح API، ودون مكتبات رسم -- مجرد JSON.

      متى تُستخدم​

      ولّد ملفات .excalidraw لمخططات البنية، ومخططات التدفّق، والمخططات التسلسلية، وخرائط المفاهيم، وغيرها. يمكن فتح الملفات على excalidraw.com أو رفعها للحصول على روابط قابلة للمشاركة.

      سير العمل​

      1. حمّل هذه المهارة (فعلت ذلك بالفعل)
      2. اكتب JSON العناصر -- مصفوفة من كائنات عناصر Excalidraw
      3. احفظ الملف باستخدام write_file لإنشاء ملف .excalidraw
      4. ارفعه اختياريًا للحصول على رابط قابل للمشاركة باستخدام scripts/upload.py عبر terminal

      حفظ مخطط​

      ضع مصفوفة عناصرك داخل الغلاف القياسي لملف .excalidraw واحفظه باستخدام write_file:

      {
        "type": "excalidraw",
        "version": 2,
        "source": "hermes-agent",
        "elements": [ ...your elements array here... ],
        "appState": {
          "viewBackgroundColor": "#ffffff"
        }
      }

      احفظه في أي مسار، مثل ~/diagrams/my_diagram.excalidraw.

      الرفع للحصول على رابط قابل للمشاركة​

      شغّل سكربت الرفع (الموجود في مجلد scripts/ الخاص بهذه المهارة) عبر terminal:

      python skills/creative/excalidraw/scripts/upload.py ~/diagrams/my_diagram.excalidraw

      هذا يرفع إلى excalidraw.com (دون حاجة لحساب) ويطبع رابطًا قابلًا للمشاركة. يتطلّب حزمة pip باسم cryptography (pip install cryptography).

      مرجع صيغة العناصر​

      الحقول المطلوبة (كل العناصر)​

      type, id (نص فريد), x, y, width, height

      القيم الافتراضية (تخطّاها -- تُطبّق تلقائيًا)​

      • strokeColor: "#1e1e1e"
      • backgroundColor: "transparent"
      • fillStyle: "solid"
      • strokeWidth: 2
      • roughness: 1 (طابع مرسوم يدويًا)
      • opacity: 100

      خلفية اللوحة بيضاء.

      أنواع العناصر​

      مستطيل:

      { "type": "rectangle", "id": "r1", "x": 100, "y": 100, "width": 200, "height": 100 }
      • roundness: { "type": 3 } لزوايا مستديرة
      • backgroundColor: "#a5d8ff", fillStyle: "solid" للتعبئة

      قطع ناقص (Ellipse):

      { "type": "ellipse", "id": "e1", "x": 100, "y": 100, "width": 150, "height": 150 }

      معيّن (Diamond):

      { "type": "diamond", "id": "d1", "x": 100, "y": 100, "width": 150, "height": 150 }

      شكل مع تسمية (ربط بحاوية) -- أنشئ عنصر نص مرتبطًا بالشكل:

      تحذير: لا تستخدم "label": { "text": "..." } على الأشكال. هذه ليست خاصية صالحة في Excalidraw وستُتجاهل بصمت، مما ينتج عنه أشكال فارغة. يجب عليك استخدام أسلوب ربط الحاوية أدناه.

      يحتاج الشكل إلى boundElements يسرد النص، ويحتاج النص إلى containerId يشير رجوعًا إليه:

      { "type": "rectangle", "id": "r1", "x": 100, "y": 100, "width": 200, "height": 80,
        "roundness": { "type": 3 }, "backgroundColor": "#a5d8ff", "fillStyle": "solid",
        "boundElements": [{ "id": "t_r1", "type": "text" }] },
      { "type": "text", "id": "t_r1", "x": 105, "y": 110, "width": 190, "height": 25,
        "text": "Hello", "fontSize": 20, "fontFamily": 1, "strokeColor": "#1e1e1e",
        "textAlign": "center", "verticalAlign": "middle",
        "containerId": "r1", "originalText": "Hello", "autoResize": true }
      • يعمل مع المستطيل والقطع الناقص والمعيّن
      • يُمركَز النص تلقائيًا بواسطة Excalidraw عند ضبط containerId
      • قيم x/y/width/height للنص تقريبية -- تُعاد حسابها بواسطة Excalidraw عند التحميل
      • يجب أن يطابق originalText قيمة text
      • ضمّن دائمًا fontFamily: 1 (خط Virgil المرسوم يدويًا)

      سهم مع تسمية -- نفس أسلوب ربط الحاوية:

      { "type": "arrow", "id": "a1", "x": 300, "y": 150, "width": 200, "height": 0,
        "points": [[0,0],[200,0]], "endArrowhead": "arrow",
        "boundElements": [{ "id": "t_a1", "type": "text" }] },
      { "type": "text", "id": "t_a1", "x": 370, "y": 130, "width": 60, "height": 20,
        "text": "connects", "fontSize": 16, "fontFamily": 1, "strokeColor": "#1e1e1e",
        "textAlign": "center", "verticalAlign": "middle",
        "containerId": "a1", "originalText": "connects", "autoResize": true }

      نص مستقل (للعناوين والتعليقات التوضيحية فقط -- دون حاوية):

      { "type": "text", "id": "t1", "x": 150, "y": 138, "text": "Hello", "fontSize": 20,
        "fontFamily": 1, "strokeColor": "#1e1e1e", "originalText": "Hello", "autoResize": true }
      • x هو الحافة اليسرى. للتمركز عند الموضع cx: x = cx - (text.length * fontSize * 0.5) / 2
      • لا تعتمد على textAlign أو width للتموضع

      سهم:

      { "type": "arrow", "id": "a1", "x": 300, "y": 150, "width": 200, "height": 0,
        "points": [[0,0],[200,0]], "endArrowhead": "arrow" }
      • points: إزاحات [dx, dy] من x, y الخاصين بالعنصر
      • endArrowhead: null | "arrow" | "bar" | "dot" | "triangle"
      • strokeStyle: "solid" (الافتراضي) | "dashed" | "dotted"

      روابط الأسهم (وصل الأسهم بالأشكال)​

      {
        "type": "arrow", "id": "a1", "x": 300, "y": 150, "width": 150, "height": 0,
        "points": [[0,0],[150,0]], "endArrowhead": "arrow",
        "startBinding": { "elementId": "r1", "fixedPoint": [1, 0.5] },
        "endBinding": { "elementId": "r2", "fixedPoint": [0, 0.5] }
      }

      إحداثيات fixedPoint: top=[0.5,0], bottom=[0.5,1], left=[0,0.5], right=[1,0.5]

      ترتيب الرسم (z-order)​

      • ترتيب المصفوفة = ترتيب الطبقات z (الأول = خلف، الأخير = أمام)
      • أصدر تدريجيًا: مناطق الخلفية ← الشكل ← نصه المرتبط ← أسهمه ← الشكل التالي
      • سيّئ: كل المستطيلات، ثم كل النصوص، ثم كل الأسهم
      • جيد: bg_zone ← shape1 ← text_for_shape1 ← arrow1 ← arrow_label_text ← shape2 ← text_for_shape2 ← ...
      • ضع دائمًا عنصر النص المرتبط مباشرة بعد شكل الحاوية الخاص به

      إرشادات الأحجام​

      أحجام الخط:

      • الحد الأدنى لـ fontSize: 16 لنص المحتوى، والتسميات، والأوصاف
      • الحد الأدنى لـ fontSize: 20 للعناوين والترويسات
      • الحد الأدنى لـ fontSize: 14 للتعليقات التوضيحية الثانوية فقط (باعتدال)
      • لا تستخدم fontSize أقل من 14 أبدًا

      أحجام العناصر:

      • الحد الأدنى لحجم الشكل: 120×60 للمستطيلات/القطوع الناقصة ذات التسميات
      • اترك فجوة لا تقل عن 20-30 بكسل بين العناصر
      • فضّل عناصر أقل وأكبر بدلًا من عناصر صغيرة كثيرة

      لوحة الألوان​

      انظر references/colors.md لجداول الألوان الكاملة. مرجع سريع:

      الاستخداملون التعبئةHex
      أساسي / إدخالأزرق فاتح#a5d8ff
      نجاح / إخراجأخضر فاتح#b2f2bb
      تحذير / خارجيبرتقالي فاتح#ffd8a8
      معالجة / خاصبنفسجي فاتح#d0bfff
      خطأ / حرجأحمر فاتح#ffc9c9
      ملاحظات / قراراتأصفر فاتح#fff3bf
      تخزين / بياناتتركواز فاتح#c3fae8

      نصائح​

      • استخدم لوحة الألوان باتّساق عبر المخطط
      • تباين النص أمر بالغ الأهمية -- لا تستخدم أبدًا رماديًا فاتحًا على خلفيات بيضاء. الحد الأدنى للون النص على الأبيض: #757575
      • لا تستخدم الرموز التعبيرية (emoji) في النص -- فهي لا تُعرض في خط Excalidraw
      • لمخططات الوضع الداكن، انظر references/dark-mode.md
      • لأمثلة أكبر، انظر references/examples.md
