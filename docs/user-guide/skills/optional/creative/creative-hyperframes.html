      Hyperframes

      عرض فيديوهات MP4/WebM من تركيبات HTML.

      بيانات المهارة الوصفية​

      المصدراختيارية — ثبّتها باستخدام hermes skills install official/creative/hyperframes
      المسارoptional-skills/creative/hyperframes
      الإصدار1.0.0
      المؤلفheygen-com
      الترخيصApache-2.0
      المنصاتlinux, macos, windows
      الوسومcreative, video, animation, html, gsap, motion-graphics
      مهارات ذات صلةmanim-video, meme-generation

      المرجع: ملف SKILL.md كاملًا​

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      HyperFrames

      HTML هو مصدر الحقيقة للفيديو. التركيبة (composition) هي ملف HTML بسمات data-* للتوقيت، وخط زمني GSAP للحركة، و CSS للمظهر. يلتقط محرّك HyperFrames الصفحة إطارًا بإطار ويرمّزها إلى MP4/WebM باستخدام FFmpeg.

      مكمّل لـ manim-video: استخدم manim-video للشروحات الرياضية/الهندسية (المعادلات، بأسلوب 3B1B). استخدم hyperframes للرسوم المتحركة (motion-graphics)، والفيديو بصوت وصورة متحدث مع ترجمات، وجولات المنتجات، وطبقات السوشيال ميديا (overlays)، وانتقالات الشيدر (shader)، وأي شيء مدفوع بوسائط فيديو/صوت حقيقية.

      متى تُستخدم​

      • يطلب المستخدم فيديو مُعرَّضًا من نص، أو سيناريو، أو موقع ويب
      • بطاقات عناوين متحركة، أو أشرطة سفلية (lower thirds)، أو مقدمات نمطية بالخط
      • فيديو سرد صوتي مع ترجمات (TTS + ترجمات متزامنة مع الموجة الصوتية)
      • مرئيات تفاعلية مع الصوت (مزامنة النبضات، أعمدة الطيف، وهج نابض)
      • انتقالات بين المشاهد (تلاشٍ متقاطع، مسح، تشويه شيدر، ومضة عبر الأبيض)
      • طبقات سوشيال ميديا (بأسلوب Instagram/TikTok/YouTube)
      • خط أنابيب من موقع ويب إلى فيديو (التقاط رابط URL، وإنتاج فيديو ترويجي)
      • أي رسم متحرك بـ HTML/CSS/JS يجب أن يُعرَّض بشكل حتمي إلى ملف فيديو

      لا تستخدم هذه المهارة من أجل:

      • الرسوم المتحركة الرياضية/المعادلات البحتة (← manim-video)
      • توليد الصور أو الميمز (← meme-generation، نماذج الصور)
      • مؤتمرات الفيديو المباشرة أو البث المباشر

      مرجع سريع​

      npx hyperframes init my-video               # scaffold a project
      cd my-video
      npx hyperframes lint                        # validate before preview/render
      npx hyperframes preview                     # live-reload preview (long-lived server, port 3002)
      npx hyperframes render --output final.mp4   # render to MP4
      npx hyperframes doctor                      # diagnose environment issues

      preview خادم Next.js طويل الأمد يبقي عمال عرض Chrome مفتوحين. أوقفه دائمًا عند الانتهاء (انظر التنظيف) — إذ يُبقي preview منسي عمال chrome-headless-shell خاملين يعمل كل منهم على استهلاك نواة CPU بشكل مستمر عبر WebGL البرمجي (swiftshader) على الأجهزة المضيفة الخالية من GPU (WSL، الحاويات، CI).

      خيارات العرض: --quality draft|standard|high · --fps 24|30|60 · --format mp4|webm · --docker (قابل لإعادة الإنتاج) · --strict.

      مرجع CLI الكامل: references/cli.md.

      الإعداد (مرة واحدة)​

      bash "$(dirname "$(find ~/.hermes/skills -path '*/hyperframes/SKILL.md' 2>/dev/null | head -1)")/scripts/setup.sh"

      يقوم السكربت بما يلي:

      1. يتحقق من تثبيت Node.js >= 22 و FFmpeg (يطبع تعليمات الإصلاح إن لم يكونا مثبّتين).
      2. يثبّت CLI الخاص بـ hyperframes بشكل عام (npm install -g hyperframes@>=0.4.2).
      3. يخزّن chrome-headless-shell مسبقًا عبر Puppeteer — وهذا مطلوب لأفضل جودة عرض عبر مسار التقاط HeadlessExperimental.beginFrame الخاص بـ Chrome.
      4. يشغّل npx hyperframes doctor ويُبلغ عن النتيجة.

      انظر references/troubleshooting.md إذا فشل الإعداد.

      الإجراء​

      1. خطّط قبل كتابة HTML​

      قبل لمس الكود، حدّد على مستوى عالٍ:

      • ماذا — المسار السردي، اللحظات الرئيسية، النبضات العاطفية
      • البنية — التركيبات، المسارات (فيديو/صوت/طبقات)، المدد الزمنية
      • الهوية البصرية — الألوان، الخطوط، طابع الحركة (انفجاري / سينمائي / سلس / تقني)
      • الإطار الرئيسي (Hero frame) — لكل مشهد، اللحظة التي تظهر فيها أكبر عدد من العناصر في وقت واحد. هذا هو التخطيط الثابت الذي ستبنيه أولًا.

      بوابة الهوية البصرية (بوابة إلزامية). قبل كتابة أي HTML لتركيبة، يجب تحديد هوية بصرية. لا تكتب تركيبات بألوان افتراضية أو عامة (#333، #3b82f6، Roboto علامات على تخطّي هذه الخطوة). تحقّق بالترتيب التالي:

      1. هل يوجد DESIGN.md في جذر المشروع؟ ← استخدم ألوانه وخطوطه وقواعد حركته وقيود "ما لا يجب فعله" بالضبط.

      2. هل حدّد المستخدم نمطًا (مثل "Swiss Pulse"، "داكن وتقني"، "علامة فاخرة")؟ ← ولّد ملف DESIGN.md بسيطًا يحتوي ## Style Prompt، و## Colors (3-5 ألوان hex مع أدوارها)، و## Typography (عائلة خط أو اثنتين)، و## What NOT to Do (3-5 أنماط يجب تجنّبها).

      3. لا شيء مما سبق؟ ← اطرح 3 أسئلة قبل كتابة أي HTML:

        • ما المزاج؟ (انفجاري / سينمائي / سلس / تقني / فوضوي / دافئ)
        • لوحة فاتحة أم داكنة؟
        • أي ألوان علامة تجارية، أو خطوط، أو مراجع بصرية؟

        ثم ولّد DESIGN.md من الإجابات. يجب أن ترتبط لوحة كل تركيبة وطباعتها بـ DESIGN.md أو بتوجيه صريح من المستخدم.

      2. الهيكل الأساسي (Scaffold)​

      npx hyperframes init my-video --non-interactive

      القوالب: blank, warm-grain, play-mode, swiss-grid, vignelli, decision-tree, kinetic-type, product-promo, nyt-graph. مرّر --example <name> لاختيار واحد، و --video clip.mp4 أو --audio track.mp3 للبذر بوسائط.

      3. التخطيط قبل الحركة​

      اكتب HTML+CSS الثابت لـ الإطار الرئيسي أولًا — دون GSAP بعد. يجب أن يملأ حاوية .scene-content المشهد (width:100%; height:100%; padding:Npx) باستخدام display:flex + gap. استخدم الحشوة (padding) لدفع المحتوى للداخل — لا تستخدم أبدًا position: absolute; top: Npx على حاوية محتوى (يفيض المحتوى عندما يكون أطول من المساحة المتبقية).

      فقط بعد أن يبدو الإطار الرئيسي صحيحًا، أضف دخول gsap.from() (الحركة إلى موضع CSS) وخروج gsap.to() (الحركة من موضعه).

      انظر references/composition.md لمخطط سمات البيانات الكامل وقواعد التركيب.

      4. حرّك باستخدام GSAP​

      يجب على كل تركيبة:

      • تسجيل خطها الزمني: window.__timelines["<composition-id>"] = tl
      • البدء متوقفة مؤقتًا: gsap.timeline({ paused: true }) — المشغّل يتحكم في التشغيل
      • استخدام قيم repeat محدودة (لا repeat: -1 — يُعطّل محرّك الالتقاط). احسب: repeat: Math.ceil(duration / cycleDuration) - 1.
      • البناء بشكل حتمي — دون Math.random()، أو Date.now()، أو منطق يعتمد على الساعة الحقيقية. استخدم مولّد أرقام شبه عشوائية (PRNG) مزروعًا إن احتجت عشوائية زائفة.
      • البناء بشكل متزامن — دون async/await، أو setTimeout، أو Promises حول بناء الخط الزمني.

      انظر references/gsap.md لواجهة GSAP الأساسية (tweens، eases، stagger، timelines).

      5. الانتقالات بين المشاهد​

      تتطلب التركيبات متعددة المشاهد انتقالات. القواعد:

      1. استخدم دائمًا انتقالًا بين المشاهد — بلا قطع مفاجئ (jump cuts).
      2. استخدم دائمًا رسوم دخول متحركة على كل عنصر في المشهد (gsap.from(...)).
      3. لا تستخدم أبدًا رسوم خروج متحركة إلا في المشهد الأخير — الانتقال نفسه هو الخروج.
      4. يمكن للمشهد الأخير أن يتلاشى.

      استخدم npx hyperframes add <transition-name> لتثبيت انتقالات الشيدر (flash-through-white، liquid-wipe، إلخ). القائمة الكاملة: npx hyperframes add --list.

      6. الصوت، الترجمات، TTS، التفاعل الصوتي، التمييز​

      • الصوت: دائمًا عنصر <audio> منفصل (الفيديو muted playsinline).
      • TTS: npx hyperframes tts "Script text" --voice af_nova --output narration.wav. اعرض الأصوات المتاحة بـ --list. الحرف الأول من معرّف الصوت يرمز إلى اللغة (a/b=الإنجليزية، e=الإسبانية، f=الفرنسية، j=اليابانية، z=الماندرين، إلخ) — يستنتج CLI موقع نظام النطق تلقائيًا؛ مرّر --lang فقط لتجاوز ذلك. يتطلب النطق بغير الإنجليزية تثبيت espeak-ng على مستوى النظام.
      • الترجمات: npx hyperframes transcribe narration.wav ← نسخ نصي على مستوى الكلمة. اختر النمط من نبرة النسخ (حماسي / رسمي / تعليمي / سردي / سوشيال ميديا — انظر الجدول في references/features.md). قاعدة اللغة: لا تستخدم أبدًا نماذج whisper بلاحقة .en ما لم يكن الصوت مؤكّدًا أنه إنجليزي — إذ تترجم .en الصوت غير الإنجليزي بدلًا من نسخه. يجب أن تحمل كل مجموعة ترجمات إيقافًا صارمًا tl.set(el, { opacity: 0, visibility: "hidden" }, group.end) بعد تحريك خروجها — وإلا تسرّبت المجموعات مرئية إلى المجموعات اللاحقة.
      • المرئيات التفاعلية مع الصوت: استخرج نطاقات الصوت مسبقًا (باس / متوسط / حاد) وأخذ عيّنة لكل إطار داخل الخط الزمني بحلقة for من tl.call(draw, [], f / fps) — لا يتفاعل تحريك واحد طويل مع الصوت. اربط الباس ← scale (نبض)، الحاد ← textShadow/boxShadow (توهّج)، السعة الكلية ← opacity/y/backgroundColor. تجنّب الأنماط النمطية لأعمدة equalizer — دع المحتوى يوجّه المرئيات، والصوت يوجّه سلوكها.
      • التمييز بأسلوب الماركر: تأثيرات التمييز، والتدوير، والانفجار، والخربشة، والرسم الخطي لتوكيد النص حتمية بـ CSS+GSAP — انظر references/features.md#marker-highlighting. قابلة للتنقل الزمني بالكامل، دون مرشحات SVG متحركة.
      • انتقالات المشاهد: يجب أن تستخدم كل تركيبة متعددة المشاهد انتقالات (بلا قطع مفاجئ). اختر من أساسيات CSS (انزلاق دفع، تلاشٍ متقاطع ضبابي، تكبير عبر، كتل متدرّجة) أو انتقالات شيدر (flash-through-white، liquid-wipe، cross-warp-morph، chromatic-split، إلخ) عبر npx hyperframes add. جداول المزاج والطاقة موجودة في references/features.md#transitions. لا تخلط بين انتقالات CSS والشيدر في نفس التركيبة.

      7. Lint، التحقق، الفحص، المعاينة، العرض​

      npx hyperframes lint              # catches missing data-composition-id, overlapping tracks, unregistered timelines
      npx hyperframes validate          # WCAG contrast audit at 5 timestamps
      npx hyperframes inspect           # visual layout audit — overflow, off-frame elements, occluded text
      npx hyperframes preview           # live browser preview
      npx hyperframes render --quality draft --output draft.mp4    # fast iteration
      npx hyperframes render --quality high --output final.mp4     # final delivery

      تأخذ hyperframes validate عيّنات من بكسلات الخلفية خلف كل عنصر نص وتحذّر عند نسب تباين أقل من 4.5:1 (أو 3:1 للنص الكبير). hyperframes inspect هو المرافق من جهة التخطيط — يشغّل الصفحة عند طوابع زمنية متعددة ويكشف مشاكل لا يستطيع الـ lint الثابت رؤيتها (تعليق ترجمة يلتف خارج المنطقة الآمنة عند 4.5 ثانية فقط، بطاقة تفيض عندما يكون عنوانها هو أطول متغيّر، عنصر ينتهي خلف شيدر انتقال). شغّل inspect خصوصًا على التركيبات ذات فقاعات الحوار، أو البطاقات، أو الترجمات، أو الطباعة الضيقة.

      8. من موقع ويب إلى فيديو (إذا أعطى المستخدم رابط URL)​

      استخدم سير عمل الالتقاط إلى الفيديو المكوّن من 7 خطوات في references/website-to-video.md: التقاط ← DESIGN.md ← SCRIPT.md ← لوحة قصة (storyboard) ← تركيب ← عرض ← تسليم.

      التنظيف​

      render يعمل مرة واحدة فقط (تخرج العمليات عند انتهائه). preview ليس كذلك — إذ يشغّل خادم Next.js في الخلفية يبقي عمال Chrome مقيمين حتى توقفه. لا تترك واحدًا يعمل أبدًا: على الأجهزة المضيفة الخالية من GPU، تُثقل عملية swiftshader الخاصة بكل عامل خامل نواة CPU، ويتراكم عدة عمليات إذا تُرك preview مفتوحًا لأيام.

      أوقف المعاينة عندما ينتهي المستخدم من المراجعة (أو قبل بدء واحدة جديدة):

      pkill -f "hyperframes.*preview"     # the Studio server (frees port 3002)
      pkill -f chrome-headless-shell      # its render workers; only safe if nothing else uses them

      إذا لم تكن متأكدًا مما إذا كانت أدوات أخرى تستخدم chrome-headless-shell، تحقّق أولًا: pgrep -af chrome-headless-shell. عالج جهازًا مُعطَّلًا (عدة عمال خاملين يستهلكون CPU) بنفس الطريقة — انظر references/troubleshooting.md.

      مزالق شائعة​

      • ترك preview يعمل — إنه خادم طويل الأمد يُبقي عمال Chrome مفتوحين؛ على WSL/الحاويات/CI يستهلك كل عامل خامل نواة CPU (عبر WebGL برمجي). أوقفه عند الانتهاء — انظر التنظيف.

      • HeadlessExperimental.beginFrame' wasn't found — أزال Chromium 147+ هذا البروتوكول. تأكّد من أنك على hyperframes@>=0.4.2 (يكتشف تلقائيًا ويرجع لوضع لقطة الشاشة). مخرج طوارئ: export PRODUCER_FORCE_SCREENSHOT=true. انظر hyperframes#294 وreferences/troubleshooting.md.

      • متصفح Chrome النظامي (وليس chrome-headless-shell) — تتعطّل عمليات العرض 120 ثانية ثم تنتهي المهلة. شغّل npx puppeteer browsers install chrome-headless-shell (يقوم setup.sh بذلك). يُبلغ hyperframes doctor عن الملف الثنائي الذي سيُستخدم.

      • repeat: -1 في أي مكان — يُعطّل محرّك الالتقاط. احسب دائمًا عدد تكرار محدود.

      • استخدام gsap.set() على عناصر مقطوعة تدخل لاحقًا — العنصر غير موجود عند تحميل الصفحة. استخدم tl.set(selector, vars, timePosition) داخل الخط الزمني بدلًا من ذلك، عند أو بعد data-start الخاص بالمقطع.

      • استخدام <br> داخل نص المحتوى — الفواصل الإجبارية لا تعرف عرض الخط المعروض، لذا يُضاعف اللف الطبيعي + <br> الفواصل. استخدم max-width للسماح بلف النص طبيعيًا. الاستثناء: العناوين العرضية القصيرة حيث تكون كل كلمة عمدًا في سطرها الخاص.

      • تحريك visibility أو display — لا يمكن لـ GSAP تحريك هذه الخصائص. استخدم autoAlpha (تتعامل مع كل من الرؤية والشفافية).

      • استدعاء video.play() أو audio.play() — الإطار يمتلك التحكم بالتشغيل. لا تستدعِ هذه بنفسك أبدًا.

      • بناء الخطوط الزمنية بشكل غير متزامن — يقرأ محرّك الالتقاط window.__timelines بشكل متزامن بعد تحميل الصفحة. لا تغلّف بناء الخط الزمني أبدًا في async، أو setTimeout، أو Promise.

      • ملف index.html مستقل ملفوف بـ <template> — يُخفي كل المحتوى عن المتصفح. فقط التركيبات الفرعية المحمّلة عبر data-composition-src تستخدم <template>.

      • استخدام الفيديو للصوت — استخدم دائمًا <video> مكتوم الصوت + <audio> منفصل.

      التحقّق​

      قبل العرض وبعده:

      1. نجاح Lint + validate + inspect: npx hyperframes lint --strict && npx hyperframes validate && npx hyperframes inspect (يلتقط lint المشاكل البنيوية، ويلتقط validate التباين، ويلتقط inspect مشاكل التخطيط المرئي/الفيض — انظر troubleshooting.md إذا ظهرت تحذيرات).
      2. تنسيق الحركة (choreography) — للتركيبات الجديدة أو التغييرات الكبيرة في الحركة، شغّل خريطة الحركة. تنسخ npx hyperframes init سكربتات المهارة إلى المشروع، لذا يكون المسار محليًا للمشروع: 
        node skills/hyperframes/scripts/animation-map.mjs <composition-dir> \
          --out <composition-dir>/.hyperframes/anim-map
        يُخرج ملف animation-map.json واحدًا بملخصات لكل تحريك، وخط زمني Gantt نصي، واكتشاف التدرّج (stagger)، ومناطق ميتة (أكثر من ثانية دون حركة)، ودورات حياة العناصر، وأعلامًا (offscreen، collision، invisible، paced-fast أقل من 0.2 ثانية، paced-slow أكثر من 2 ثانية). افحص الملخصات والأعلام — أصلح كل واحدة أو برّرها. تخطَّ هذا للتعديلات الصغيرة.
      3. الملف موجود وغير فارغ: ls -lh final.mp4.
      4. تطابق المدة مع data-duration: ffprobe -v error -show_entries format=duration -of default=nw=1:nk=1 final.mp4.
      5. فحص بصري: استخرج إطارًا من منتصف التركيبة: ffmpeg -i final.mp4 -ss 00:00:05 -vframes 1 preview.png.
      6. وجود الصوت إن كان متوقعًا: ffprobe -v error -show_streams -select_streams a -of default=nw=1:nk=1 final.mp4 | head -1.

      إذا فشل hyperframes render، شغّل npx hyperframes doctor وأرفق مخرجاته عند الإبلاغ.
