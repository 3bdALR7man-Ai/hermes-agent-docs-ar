      Baoyu Article Illustrator

      توضيحات المقالات: اتساق النوع × الأسلوب × لوحة الألوان.

      بيانات المهارة الوصفية​

      المصدراختيارية — ثبّتها باستخدام hermes skills install official/creative/baoyu-article-illustrator
      المسارoptional-skills/creative/baoyu-article-illustrator

      المؤلف宝玉 (JimLiu)

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      Article Illustrator

      مُقتبسة من baoyu-article-illustrator لمنظومة أدوات Hermes Agent.

      تحليل المقالات، وتحديد مواضع التوضيحات، وتوليد صور باتساق النوع × الأسلوب × لوحة الألوان.

      متى تُستخدم​

      فعّل هذه المهارة عندما يطلب المستخدم توضيح مقالة، أو إضافة صور إلى مقالة، أو توليد توضيحات لمحتوى، أو يستخدم عبارات مثل "为文章配图" أو "illustrate article" أو "add images". يقدّم المستخدم مقالة (مسار ملف أو محتوى ملصق) ويحدّد اختياريًا النوع أو الأسلوب أو لوحة الألوان أو الكثافة.

      الأبعاد الثلاثة​

      البُعديتحكّم فيأمثلة
      النوع (Type)بنية المعلوماتinfographic, scene, flowchart, comparison, framework, timeline
      الأسلوب (Style)طريقة العرضnotion, warm, minimal, blueprint, watercolor, elegant
      لوحة الألوان (Palette)مخطط الألوان (اختياري)macaron, warm, neon — تتجاوز ألوان الأسلوب الافتراضية

      ادمج بحرية: type=infographic, style=vector-illustration, palette=macaron.

      أو استخدم إعدادات جاهزة (presets): edu-visual ← النوع + الأسلوب + لوحة الألوان دفعة واحدة. راجع style-presets.md.

      الأنواع​

      النوعالأنسب لـ
      infographicالبيانات، المقاييس، التقنيات
      sceneالسرديات، الجوانب العاطفية
      flowchartالعمليات، سيرورات العمل
      comparisonالمقارنة جنبًا إلى جنب، الخيارات
      frameworkالنماذج، البنية المعمارية
      timelineالتاريخ، التطوّر

      الأساليب​

      راجع references/styles.md للاطلاع على الأساليب الأساسية، والمعرض الكامل، وتوافق النوع × الأسلوب.

      بنية الناتج​

      {output-dir}/
      ├── source-{slug}.{ext}    # Only for pasted content
      ├── outline.md
      ├── prompts/
      │   └── NN-{type}-{slug}.md
      └── NN-{type}-{slug}.png

      مجلد الناتج الافتراضي:

      المُدخلمجلد الناتجمسار الإدراج في Markdown
      مسار ملف المقالة{article-dir}/imgs/imgs/NN-{type}-{slug}.png
      محتوى ملصقillustrations/{topic-slug}/ (cwd)illustrations/{topic-slug}/NN-{type}-{slug}.png

      إذا طلب المستخدم تخطيطًا مختلفًا (كأن تكون الصور بجانب المقالة، أو مجلد فرعي باسم illustrations/)، فراعِ ذلك.

      الاسم المختصر (Slug): من 2 إلى 4 كلمات، بصيغة kebab-case. عند التعارض: أضف -YYYYMMDD-HHMMSS.

      المبادئ الأساسية​

      • جسّد المفاهيم بصريًا، لا الاستعارات — إذا استخدمت المقالة استعارة (مثل "电锯切西瓜")، صوّر المفهوم الكامن، لا الصورة الحرفية.
      • التسميات تعتمد على بيانات المقالة — أرقام ومصطلحات واقتباسات فعلية من المقالة، لا عناصر نائبة عامة.
      • ملفات الـ prompt سجلّات لإعادة الإنتاج — يجب أن يكون لكل توضيح ملف prompt محفوظ ضمن prompts/ قبل توليد أي صورة.
      • احذف الأسرار — امسح المحتوى المصدري بحثًا عن مفاتيح API أو tokens أو بيانات اعتماد قبل كتابة أي شيء على القرص.

      سير العمل​

      - [ ] Step 1: Detect reference images (if provided)
      - [ ] Step 2: Analyze content
      - [ ] Step 3: Confirm settings (clarify tool, one question at a time)
      - [ ] Step 4: Generate outline
      - [ ] Step 5: Generate prompts
      - [ ] Step 6: Generate images (image_generate)
      - [ ] Step 7: Finalize

      الخطوة 1: اكتشاف الصور المرجعية​

      إذا زوّد المستخدم بصور مرجعية (مسارات ملصقة ضمن النص، أو مرفقات، أو رابط):

      1. لكل مرجع، استدعِ vision_analyze مع المسار/الرابط وسؤال يطلب الأسلوب ولوحة الألوان والتكوين والموضوع. سجّل الوصف المُعاد في {output-dir}/references/NN-ref-{slug}.md عبر write_file.
      2. لا تحاول نسخ الملف الثنائي عبر write_file / read_file — فهذه أدوات نصية فقط. إذا أردت نسخة محلية للتوثيق، استخدم terminal (cp "$src" "{output-dir}/references/NN-ref-{slug}.{ext}"). المهارة نفسها لا تحتاج أبدًا لقراءة الملف الثنائي؛ فهي تعمل بناءً على وصف الرؤية (vision).
      3. بما أن image_generate لا يقبل مُدخلات صور، فإن وصف الرؤية هو ما يُدمَج في الـ prompts أثناء الخطوة 5.

      الإجراءات الكاملة: references/workflow.md.

      الخطوة 2: التحليل​

      التحليلالناتج
      نوع المحتوىتقني / درس تطبيقي / منهجية / سردي
      الغرضمعلوماتي / بصري / تخيّلي
      الحجج الأساسية2-5 نقاط رئيسية
      المواضعأين تضيف التوضيحات قيمة

      اقرأ المصدر (مسار ملف ← read_file، أو نص ملصق) واكتب التحليل إلى {output-dir}/analysis.md باستخدام write_file.

      الإجراءات الكاملة: references/workflow.md.

      الخطوة 3: تأكيد الإعدادات​

      استخدم أداة clarify. بما أن clarify تعالج سؤالًا واحدًا في كل مرة، اطرح أهم سؤال أولًا. تخطَّ أي سؤال إذا كانت إجابته موجودة بالفعل في طلب المستخدم.

      الترتيبالسؤالالخيارات
      Q1الإعداد الجاهز (Preset) أو النوع[الإعداد الجاهز الموصى به]، [إعداد جاهز بديل]، أو يدويًا: infographic, scene, flowchart, comparison, framework, timeline, mixed
      Q2الكثافةالحد الأدنى (1-2)، متوازنة (3-5)، لكل قسم (موصى به)، غنية (6+)
      Q3الأسلوب (تخطَّ إذا اختير إعداد جاهز في Q1)[موصى به]، minimal-flat, sci-fi, hand-drawn, editorial, scene, poster
      Q4لوحة الألوان (اختياري)الافتراضية (ألوان الأسلوب)، macaron, warm, neon
      Q5اللغة (فقط إذا كانت لغة المقالة غير واضحة)لغة المقالة / لغة المستخدم

      لا تطرح أكثر من 2-3 أسئلة clarify متتالية. إذا حدّد المستخدم هذه الإعدادات بالفعل في طلبه، فتخطَّها تمامًا.

      الإجراءات الكاملة: references/workflow.md.

      الخطوة 4: توليد المخطط (Outline) ← outline.md​

      احفظ {output-dir}/outline.md باستخدام write_file مع frontmatter (النوع، الكثافة، الأسلوب، لوحة الألوان، عدد الصور) وإدخال واحد لكل توضيح:

      ## Illustration 1
      **Position**: [section/paragraph]
      **Purpose**: [why]
      **Visual Content**: [what to show]
      **Filename**: 01-infographic-concept-name.png

      القالب الكامل: references/workflow.md.

      الخطوة 5: توليد الـ Prompts​

      حاجز إلزامي (BLOCKING): يجب أن يكون لكل توضيح ملف prompt محفوظ قبل توليد أي صورة — فملف الـ prompt هو سجلّ إعادة الإنتاج.

      لكل توضيح:

      1. أنشئ ملف prompt وفق references/prompt-construction.md.
      2. احفظه في {output-dir}/prompts/NN-{type}-{slug}.md باستخدام write_file مع YAML frontmatter.
      3. يجب أن تستخدم الـ prompts قوالب خاصة بالنوع تحتوي أقسامًا منظّمة (ZONES / LABELS / COLORS / STYLE / ASPECT).
      4. يجب أن تتضمّن LABELS بيانات خاصة بالمقالة: أرقامًا ومصطلحات ومقاييس واقتباسات فعلية.
      5. عالج المراجع (direct/style/palette) وفق frontmatter الخاص بالـ prompt — بالنسبة لاستخدام direct، ضمّن وصفًا نصيًا للمرجع في الـ prompt (بما أن image_generate لا يقبل مُدخلات صور مرجعية).

      الخطوة 6: توليد الصور​

      لكل ملف prompt:

      1. استدعِ image_generate(prompt=..., aspect_ratio=...). تُعيد image_generate نتيجة JSON تحتوي رابط صورة؛ ولا تكتب على القرص ولا تقبل مسار ناتج.
      2. حوّل ASPECT الخاص بالـ prompt إلى تعداد image_generate: 16:9 ← landscape، 9:16 ← portrait، 1:1 ← square. النسب المخصّصة ← أقرب اتجاه مُسمّى.
      3. نزّل الرابط المُعاد إلى {output-dir}/NN-{type}-{slug}.png عبر terminal (مثل curl -sSL -o "{output-dir}/NN-{type}-{slug}.png" "{url}").
      4. عند فشل التوليد، أعد المحاولة تلقائيًا مرة واحدة.

      ملاحظة: الواجهة الخلفية لتوليد الصور مُهيّأة من قبل المستخدم (الافتراضي: FAL FLUX 2 Klein 9B) وليست قابلة للاختيار من قبل الوكيل عبر image_generate. لا تكتب أسماء نماذج في الـ prompts متوقعًا أن يُوجَّه إليها.

      الخطوة 7: الإنهاء​

      أدرج ![description](https://github.com/NousResearch/hermes-agent/blob/main/optional-skills/creative/baoyu-article-illustrator/{relative-path}/NN-{type}-{slug}.png) بعد الفقرة المقابلة. النص البديل: وصف موجز بلغة المقالة.

      التقرير:

      Article Illustration Complete!
      Article: [path] | Type: [type] | Density: [level] | Style: [style] | Palette: [palette or default]
      Images: X/N generated

      مزالق يجب تجنّبها​

      1. سلامة البيانات أمر جوهري — لا تُلخّص أو تُعيد صياغة أو تُغيّر الإحصائيات المصدرية أبدًا. تبقى "زيادة بنسبة 73%" كما هي "زيادة بنسبة 73%".
      2. احذف الأسرار — امسح المحتوى المصدري بحثًا عن مفاتيح API أو tokens أو بيانات اعتماد قبل تضمينها في أي ملف ناتج.
      3. لا تصوّر الاستعارات حرفيًا — صوّر المفهوم الكامن بصريًا.
      4. ملفات الـ prompt إلزامية — لا توليد صور بلا ملف prompt محفوظ. فالملف هو ما يتيح لك إعادة التوليد أو تبديل الواجهات الخلفية لاحقًا.
      5. نسب أبعاد image_generate — تدعم الأداة landscape وportrait وsquare. النسب المخصّصة تُحوَّل إلى أقرب خيار.
      6. image_generate يُعيد رابطًا لا ملفًا محليًا — نزّل دائمًا عبر terminal (curl) قبل إدراج مسارات صور محلية في المقالة.
      7. لا اختيار للواجهة الخلفية من قبل الوكيل — تستخدم image_generate أي نموذج هيّأه المستخدم (الافتراضي: FAL FLUX 2 Klein 9B). لا تكتب "use <model> to generate this" في الـ prompts متوقعًا أن يُوجَّه إليها.
