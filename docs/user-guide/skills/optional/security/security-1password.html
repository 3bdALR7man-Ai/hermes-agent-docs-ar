      1Password

      أعدّ op CLI، وسجّل الدخول، واقرأ الأسرار أو احقنها.

      بيانات المهارة الوصفية​

      المصدراختيارية — ثبّتها باستخدام hermes skills install official/security/1password
      المسارoptional-skills/security/1password
      الإصدار1.0.0
      المؤلفarceus77-7، بتحسينات من Hermes Agent
      الترخيصMIT
      المنصاتlinux، macos، windows
      الوسومsecurity، secrets، 1password، op، cli

      المرجع: ملف SKILL.md كاملًا​

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      1Password CLI

      استخدم هذه المهارة عندما يريد المستخدم إدارة الأسرار عبر 1Password بدلًا من متغيرات البيئة أو الملفات النصية غير المشفّرة.

      المتطلبات​

      • حساب 1Password
      • واجهة سطر أوامر 1Password (op) مثبَّتة
      • أحد الآتي: تكامل تطبيق سطح المكتب، أو رمز حساب خدمة (OP_SERVICE_ACCOUNT_TOKEN)، أو خادم Connect
      • tmux متاح لجلسات مصادقة مستقرة أثناء استدعاءات terminal في Hermes (لمسار تطبيق سطح المكتب فقط)

      متى تُستخدم​

      • تثبيت أو إعداد 1Password CLI
      • تسجيل الدخول باستخدام op signin
      • قراءة مراجع الأسرار مثل op://Vault/Item/field
      • حقن الأسرار في الإعدادات/القوالب باستخدام op inject
      • تشغيل أوامر بمتغيرات بيئة سرّية عبر op run

      طرق المصادقة​

      حساب الخدمة (المُوصى به لـ Hermes)​

      اضبط OP_SERVICE_ACCOUNT_TOKEN في ${HERMES_HOME:-~/.hermes}/.env (ستطلب المهارة ذلك عند أول تحميل). لا حاجة لتطبيق سطح المكتب. يدعم op read وop inject وop run.

      export OP_SERVICE_ACCOUNT_TOKEN="your-token-here"
      op whoami  # verify — should show Type: SERVICE_ACCOUNT

      تكامل تطبيق سطح المكتب (تفاعلي)​

      1. فعّله في تطبيق 1Password لسطح المكتب: Settings ← Developer ← Integrate with 1Password CLI
      2. تأكد من أن التطبيق غير مقفل
      3. شغّل op signin ووافق على طلب المقياس الحيوي (biometric)

      خادم Connect (مستضاف ذاتيًا)​

      export OP_CONNECT_HOST="http://localhost:8080"
      export OP_CONNECT_TOKEN="your-connect-token"

      الإعداد​

      1. ثبّت CLI:
      # macOS
      brew install 1password-cli

      # Linux (official package/install docs)
      # See references/get-started.md for distro-specific links.

      # Windows (winget)
      winget install AgileBits.1Password.CLI
      1. تحقق:
      op --version
      1. اختر إحدى طرق المصادقة أعلاه واضبطها.

      نمط تنفيذ Hermes (مسار تطبيق سطح المكتب)​

      أوامر terminal في Hermes غير تفاعلية بشكل افتراضي وقد تفقد سياق المصادقة بين الاستدعاءات. لاستخدام op بشكل موثوق مع تكامل تطبيق سطح المكتب، شغّل عمليات تسجيل الدخول والتعامل مع الأسرار داخل جلسة tmux مخصصة.

      ملاحظة: هذا غير ضروري عند استخدام OP_SERVICE_ACCOUNT_TOKEN — إذ يبقى الرمز مستمرًا عبر استدعاءات terminal تلقائيًا.

      SOCKET_DIR="${TMPDIR:-/tmp}/hermes-tmux-sockets"
      mkdir -p "$SOCKET_DIR"
      SOCKET="$SOCKET_DIR/hermes-op.sock"
      SESSION="op-auth-$(date +%Y%m%d-%H%M%S)"

      tmux -S "$SOCKET" new -d -s "$SESSION" -n shell

      # Sign in (approve in desktop app when prompted)
      tmux -S "$SOCKET" send-keys -t "$SESSION":0.0 -- "eval \"\$(op signin --account my.1password.com)\"" Enter

      # Verify auth
      tmux -S "$SOCKET" send-keys -t "$SESSION":0.0 -- "op whoami" Enter

      # Example read
      tmux -S "$SOCKET" send-keys -t "$SESSION":0.0 -- "op read 'op://Private/Npmjs/one-time password?attribute=otp'" Enter

      # Capture output when needed
      tmux -S "$SOCKET" capture-pane -p -J -t "$SESSION":0.0 -S -200

      # Cleanup
      tmux -S "$SOCKET" kill-session -t "$SESSION"

      عمليات شائعة​

      قراءة سرّ​

      op read "op://app-prod/db/password"

      الحصول على OTP​

      op read "op://app-prod/npm/one-time password?attribute=otp"

      الحقن في قالب​

      echo "db_password: {{ op://app-prod/db/password }}" | op inject

      تشغيل أمر بمتغير بيئة سرّي​

      export DB_PASSWORD="op://app-prod/db/password"  # example op:// reference, resolved by `op run`
      op run -- sh -c '[ -n "$DB_PASSWORD" ] && echo "DB_PASSWORD is set" || echo "DB_PASSWORD missing"'

      ضوابط الأمان​

      • لا تطبع الأسرار الخام للمستخدم أبدًا إلا إذا طلب القيمة صراحةً.
      • فضّل op run / op inject على كتابة الأسرار في الملفات.
      • إذا فشل الأمر بخطأ "account is not signed in"، شغّل op signin مرة أخرى في نفس جلسة tmux.
      • إذا كان تكامل تطبيق سطح المكتب غير متاح (بيئة headless/CI)، استخدم مسار رمز حساب الخدمة.

      ملاحظة CI / بيئة Headless​

      للاستخدام غير التفاعلي، صادق باستخدام OP_SERVICE_ACCOUNT_TOKEN وتجنّب op signin التفاعلي. تتطلب حسابات الخدمة إصدار CLI 2.18.0 فأعلى.
