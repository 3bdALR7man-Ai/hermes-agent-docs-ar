      Apple Reminders

      Apple Reminders عبر remindctl: الإضافة، والعرض، والإكمال.

      بيانات المهارة الوصفية​

      المصدرمضمّنة (مثبّتة افتراضيًا)
      المسارskills/apple/apple-reminders
      الإصدار1.0.0
      المؤلفHermes Agent
      الترخيصMIT
      المنصاتmacos
      الوسومReminders, tasks, todo, macOS, Apple

      المرجع: ملف SKILL.md كاملًا​

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      Apple Reminders

      استخدم remindctl لإدارة Apple Reminders مباشرةً من الطرفية. تتزامن المهام عبر جميع أجهزة Apple عبر iCloud.

      المتطلبات المسبقة​

      • macOS مع تطبيق Reminders.app
      • التثبيت: brew install steipete/tap/remindctl
      • امنح صلاحية Reminders عند الطلب
      • التحقق: remindctl status / الطلب: remindctl authorize

      متى تُستخدم​

      • عندما يذكر المستخدم "reminder" أو "Reminders app"
      • إنشاء مهام شخصية بمواعيد استحقاق تتزامن مع iOS
      • إدارة قوائم Apple Reminders
      • عندما يريد المستخدم أن تظهر المهام على iPhone/iPad الخاص به

      متى لا تُستخدم​

      • جدولة تنبيهات الوكيل → استخدم أداة cronjob بدلًا من ذلك
      • أحداث التقويم → استخدم Apple Calendar أو Google Calendar
      • إدارة مهام المشاريع → استخدم GitHub Issues أو Notion وغيرها
      • إذا قال المستخدم "ذكّرني" لكنه يقصد تنبيه من الوكيل → استوضح الأمر أولًا

      مرجع سريع​

      عرض المهام التذكيرية​

      remindctl                    # Today's reminders
      remindctl today              # Today
      remindctl tomorrow           # Tomorrow
      remindctl week               # This week
      remindctl overdue            # Past due
      remindctl all                # Everything
      remindctl 2026-01-04         # Specific date

      إدارة القوائم​

      remindctl list               # List all lists
      remindctl list Work          # Show specific list
      remindctl list Projects --create    # Create list
      remindctl list Work --delete        # Delete list

      إنشاء مهام تذكيرية​

      remindctl add "Buy milk"
      remindctl add --title "Call mom" --list Personal --due tomorrow
      remindctl add --title "Meeting prep" --due "2026-02-15 09:00"

      موعد الاستحقاق مقابل التنبيه (Alarm) / التذكير المبكر​

      --due و --alarm حقلان مختلفان:

      • --due يضبط تاريخ/وقت استحقاق المهمة التذكيرية.
      • --alarm يضبط مُشغّل التنبيه/الإشعار الخاص بـ EventKit. قد تُضبط المهام التذكيرية ذات الموعد المحدد افتراضيًا على تنبيه في وقت الاستحقاق نفسه، لكن مرّر --alarm صراحةً عندما يطلب المستخدم تذكيرًا أبكر.

      لمهمة تذكيرية تستحق الساعة 2:00 مساءً مع إشعار قبلها بـ 30 دقيقة:

      remindctl add --title "Hairdresser" --due "2026-05-15 14:00" --alarm "2026-05-15 13:30"

      لتعديل مهمة تذكيرية موجودة:

      remindctl edit 87354 --due "2026-05-15 14:00" --alarm "2026-05-15 13:30"

      قد تعرض واجهة Reminders العنصر أو تجمّعه حسب وقت التنبيه لأن ذلك هو الوقت الذي يُطلق فيه الإشعار. تحقّق عبر JSON بدلًا من افتراض أن موعد الاستحقاق قد تغيّر:

      remindctl today --json

      الشكل المتوقّع:

      • dueDate: وقت الاستحقاق الفعلي
      • alarmDate: وقت الإشعار / التذكير المبكر

      توثيق Apple العام لـ EKReminder يسرد فقط الخصائص الخاصة بالمهام التذكيرية. دعم التنبيهات يأتي من سلوك EKCalendarItem الموروث الذي يعرضه خيار --alarm في remindctl.

      الإكمال / الحذف​

      remindctl complete 1 2 3          # Complete by ID
      remindctl delete 4A83 --force     # Delete by ID

      صيغ المخرجات​

      remindctl today --json       # JSON for scripting
      remindctl today --plain      # TSV format
      remindctl today --quiet      # Counts only

      صيغ التاريخ​

      الصيغ المقبولة لـ --due وفلاتر التاريخ:

      • today, tomorrow, yesterday
      • YYYY-MM-DD
      • YYYY-MM-DD HH:mm
      • ISO 8601 (2026-01-04T12:34:56Z)

      القواعد​

      1. عندما يقول المستخدم "ذكّرني"، استوضح: هل يقصد Apple Reminders (يتزامن مع الهاتف) أم تنبيه cronjob من الوكيل
      2. تأكّد دائمًا من محتوى المهمة التذكيرية وموعد استحقاقها قبل إنشائها
      3. استخدم --json للتحليل البرمجي
