      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      Popular Web Designs

      54 نظام تصميم واقعيًا جاهزًا للاستخدام عند توليد HTML/CSS. يلتقط كل قالب اللغة المرئية الكاملة للموقع: لوحة الألوان، تسلسل الطباعة الهرمي، أنماط المكونات، نظام التباعد، الظلال، السلوك المتجاوب، وأوامر عملية للوكيل مع قيم CSS دقيقة.

      مهارات التصميم ذات الصلة​

      • claude-design — استخدمها من أجل عملية التصميم والذوق (تحديد نطاق الطلب، وإنتاج تنويعات، والتحقق من مصنوع HTML محلي، وتجنّب رداءة التصميم الناتج عن الذكاء الاصطناعي). اقرنها بهذه المهارة عندما يريد المستخدم صفحة مصممة بعناية بأسلوب علامة تجارية معروفة: claude-design يقود سير العمل، وهذه المهارة توفّر المفردات المرئية.
      • design-md — استخدمها عندما يكون الناتج المطلوب ملف DESIGN.md رسميًا لمواصفات الرموز (tokens)، لا مصنوعًا مُصيّرًا.

      طريقة الاستخدام​

      1. اختر تصميمًا من الكتالوج أدناه
      2. حمّله: skill_view(name="popular-web-designs", file_path="templates/<site>.md")
      3. استخدم رموز التصميم (design tokens) ومواصفات المكونات عند توليد HTML
      4. اقرنها بمهارة generative-widgets لتقديم النتيجة عبر نفق cloudflared

      يتضمن كل قالب كتلة ملاحظات تنفيذ Hermes في الأعلى تحتوي على:

      • بديل خط عبر CDN وعلامة <link> لـ Google Fonts (جاهزة للّصق)
      • سلاسل عائلات خطوط CSS للخط الأساسي وخط المسافة الثابتة (monospace)
      • تذكيرات باستخدام write_file لإنشاء HTML و browser_vision للتحقق

      نمط توليد HTML​

      <!DOCTYPE html>
      <html lang="en">
      <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>Page Title</title>
        <!-- Paste the Google Fonts <link> from the template's Hermes notes -->
        <link href="https://fonts.googleapis.com/css2?family=..." rel="stylesheet">
        <style>
          /* Apply the template's color palette as CSS custom properties */
          :root {
            --color-bg: #ffffff;
            --color-text: #171717;
            --color-accent: #533afd;
            /* ... more from template Section 2 */
          }
          /* Apply typography from template Section 3 */
          body {
            font-family: 'Inter', system-ui, sans-serif;
            color: var(--color-text);
            background: var(--color-bg);
          }
          /* Apply component styles from template Section 4 */
          /* Apply layout from template Section 5 */
          /* Apply shadows from template Section 6 */
        </style>
      </head>
      <body>
        <!-- Build using component specs from the template -->
      </body>
      </html>

      اكتب الملف باستخدام write_file، وقدّمه عبر سير عمل generative-widgets (نفق cloudflared)، وتحقّق من النتيجة باستخدام browser_vision للتأكد من الدقة المرئية.

      مرجع استبدال الخطوط​

      تستخدم معظم المواقع خطوطًا مملوكة غير متاحة عبر CDN. يربط كل قالب بديلًا من Google Fonts يحافظ على طابع التصميم. أشهر التطابقات:

      الخط المملوكالبديل عبر CDNالطابع
      Geist / Geist SansGeist (على Google Fonts)هندسي، تباعد أحرف مضغوط
      Geist MonoGeist Mono (على Google Fonts)خط أحادي المسافة نظيف، بروابط حرفية (ligatures)
      sohne-var (Stripe)Source Sans 3أناقة بوزن خفيف
      Berkeley MonoJetBrains Monoخط أحادي المسافة تقني
      Airbnb Cereal VFDM Sansهندسي دائري وودود
      Circular (Spotify)DM Sansهندسي ودافئ
      figmaSansInterإنساني نظيف
      Pin Sans (Pinterest)DM Sansودود ودائري
      NVIDIA-EMEAInter (أو نظام Arial)صناعي ونظيف
      CoinbaseDisplay/SansDM Sansهندسي وموحٍ بالثقة
      UberMoveDM Sansجريء ومتقارب
      HashiCorp SansInterمؤسسي ومحايد
      waldenburgNormal (Sanity)Space Groteskهندسي ومكثّف قليلًا
      IBM Plex Sans/MonoIBM Plex Sans/Monoمتاح على Google Fonts
      Rubik (Sentry)Rubikمتاح على Google Fonts

      عندما يتطابق خط CDN الخاص بالقالب مع الأصلي (Inter وIBM Plex وRubik وGeist)، لا يحدث فقدان بسبب الاستبدال. وعند استخدام بديل (DM Sans بدلًا من Circular، أو Source Sans 3 بدلًا من sohne-var)، اتّبع قيم الوزن والحجم وتباعد الأحرف الخاصة بالقالب بدقة — فهي تحمل هوية مرئية أكبر من نوع الخط نفسه.
