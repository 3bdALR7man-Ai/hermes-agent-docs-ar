      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      بحث arXiv

      البحث عن الأوراق الأكاديمية واسترجاعها من arXiv عبر واجهة REST API المجانية الخاصة بهم. لا مفتاح API، لا اعتماديات — فقط curl.

      مرجع سريع​

      الإجراءالأمر
      البحث عن أوراقcurl "https://export.arxiv.org/api/query?search_query=all:QUERY&max_results=5"
      جلب ورقة محدّدةcurl "https://export.arxiv.org/api/query?id_list=2402.03300"
      قراءة الملخّص (ويب)web_extract(urls=["https://arxiv.org/abs/2402.03300"])
      قراءة الورقة كاملة (PDF)web_extract(urls=["https://arxiv.org/pdf/2402.03300"])

      البحث عن الأوراق​

      تُعيد واجهة API صيغة Atom XML. حلّلها باستخدام grep/sed أو مرّرها عبر python للحصول على مخرجات نظيفة.

      بحث أساسي​

      curl -s "https://export.arxiv.org/api/query?search_query=all:GRPO+reinforcement+learning&max_results=5"

      مخرجات نظيفة (تحويل XML إلى صيغة قابلة للقراءة)​

      curl -s "https://export.arxiv.org/api/query?search_query=all:GRPO+reinforcement+learning&max_results=5&sortBy=submittedDate&sortOrder=descending" | python -c "
      import sys, xml.etree.ElementTree as ET
      ns = {'a': 'http://www.w3.org/2005/Atom'}
      root = ET.parse(sys.stdin).getroot()
      for i, entry in enumerate(root.findall('a:entry', ns)):
          title = entry.find('a:title', ns).text.strip().replace('\n', ' ')
          arxiv_id = entry.find('a:id', ns).text.strip().split('/abs/')[-1]
          published = entry.find('a:published', ns).text[:10]
          authors = ', '.join(a.find('a:name', ns).text for a in entry.findall('a:author', ns))
          summary = entry.find('a:summary', ns).text.strip()[:200]
          cats = ', '.join(c.get('term') for c in entry.findall('a:category', ns))
          print(f'{i+1}. [{arxiv_id}] {title}')
          print(f'   Authors: {authors}')
          print(f'   Published: {published} | Categories: {cats}')
          print(f'   Abstract: {summary}...')
          print(f'   PDF: https://arxiv.org/pdf/{arxiv_id}')
          print()
      "

      صيغة استعلام البحث​

      البادئةما تبحث فيهمثال
      all:جميع الحقولall:transformer+attention
      ti:العنوانti:large+language+models
      au:المؤلفau:vaswani
      abs:الملخّصabs:reinforcement+learning
      cat:التصنيفcat:cs.AI
      co:التعليقco:accepted+NeurIPS

      عوامل بولية​

      # AND (default when using +)
      search_query=all:transformer+attention

      # OR
      search_query=all:GPT+OR+all:BERT

      # AND NOT
      search_query=all:language+model+ANDNOT+all:vision

      # Exact phrase
      search_query=ti:"chain+of+thought"

      # Combined
      search_query=au:hinton+AND+cat:cs.LG

      الترتيب والتصفح بين الصفحات​

      المعاملالخيارات
      sortByrelevance, lastUpdatedDate, submittedDate
      sortOrderascending, descending
      startإزاحة النتيجة (تبدأ من 0)
      max_resultsعدد النتائج (الافتراضي 10، الحد الأقصى 30000)
      # Latest 10 papers in cs.AI
      curl -s "https://export.arxiv.org/api/query?search_query=cat:cs.AI&sortBy=submittedDate&sortOrder=descending&max_results=10"

      جلب أوراق محدّدة​

      # By arXiv ID
      curl -s "https://export.arxiv.org/api/query?id_list=2402.03300"

      # Multiple papers
      curl -s "https://export.arxiv.org/api/query?id_list=2402.03300,2401.12345,2403.00001"

      توليد BibTeX​

      بعد جلب البيانات الوصفية لورقة، ولّد مُدخل BibTeX:

      {% raw %}

      curl -s "https://export.arxiv.org/api/query?id_list=1706.03762" | python -c "
      import sys, xml.etree.ElementTree as ET
      ns = {'a': 'http://www.w3.org/2005/Atom', 'arxiv': 'http://arxiv.org/schemas/atom'}
      root = ET.parse(sys.stdin).getroot()
      entry = root.find('a:entry', ns)
      if entry is None: sys.exit('Paper not found')
      title = entry.find('a:title', ns).text.strip().replace('\n', ' ')
      authors = ' and '.join(a.find('a:name', ns).text for a in entry.findall('a:author', ns))
      year = entry.find('a:published', ns).text[:4]
      raw_id = entry.find('a:id', ns).text.strip().split('/abs/')[-1]
      cat = entry.find('arxiv:primary_category', ns)
      primary = cat.get('term') if cat is not None else 'cs.LG'
      last_name = entry.find('a:author', ns).find('a:name', ns).text.split()[-1]
      print(f'@article{{{last_name}{year}_{raw_id.replace(\".\", \"\")},')
      print(f'  title     = {{{title}}},')
      print(f'  author    = {{{authors}}},')
      print(f'  year      = {{{year}}},')
      print(f'  eprint    = {{{raw_id}}},')
      print(f'  archivePrefix = {{arXiv}},')
      print(f'  primaryClass  = {{{primary}}},')
      print(f'  url       = {{https://arxiv.org/abs/{raw_id}}}')
      print('}')
      "

      {% endraw %}

      قراءة محتوى الورقة​

      بعد إيجاد ورقة، اقرأها:

      # Abstract page (fast, metadata + abstract)
      web_extract(urls=["https://arxiv.org/abs/2402.03300"])

      # Full paper (PDF → markdown via Firecrawl)
      web_extract(urls=["https://arxiv.org/pdf/2402.03300"])

      لمعالجة ملفات PDF محليًا، راجع مهارة ocr-and-documents.

      سكربت مساعد​

      يتولى سكربت scripts/search_arxiv.py تحليل XML ويوفّر مخرجات نظيفة:

      python scripts/search_arxiv.py "GRPO reinforcement learning"
      python scripts/search_arxiv.py "transformer attention" --max 10 --sort date
      python scripts/search_arxiv.py --author "Yann LeCun" --max 5
      python scripts/search_arxiv.py --category cs.AI --sort date
      python scripts/search_arxiv.py --id 2402.03300
      python scripts/search_arxiv.py --id 2402.03300,2401.12345

      لا اعتماديات — يستخدم فقط مكتبة Python القياسية.

      Semantic Scholar (الاستشهادات، الأوراق ذات الصلة، الملفات الشخصية للمؤلفين)​

      لا توفّر arXiv بيانات استشهاد أو توصيات. استخدم واجهة Semantic Scholar API لذلك — مجانية، لا تحتاج مفتاحًا للاستخدام الأساسي (طلب واحد/ثانية)، وتُعيد JSON.

      الحصول على تفاصيل الورقة + الاستشهادات​

      # By arXiv ID
      curl -s "https://api.semanticscholar.org/graph/v1/paper/arXiv:2402.03300?fields=title,authors,citationCount,referenceCount,influentialCitationCount,year,abstract" | python -m json.tool

      # By Semantic Scholar paper ID or DOI
      curl -s "https://api.semanticscholar.org/graph/v1/paper/DOI:10.1234/example?fields=title,citationCount"

      الحصول على الاستشهادات بورقة (مَن استشهد بها)​

      curl -s "https://api.semanticscholar.org/graph/v1/paper/arXiv:2402.03300/citations?fields=title,authors,year,citationCount&limit=10" | python -m json.tool

      الحصول على المراجع من ورقة (ما تستشهد به)​

      curl -s "https://api.semanticscholar.org/graph/v1/paper/arXiv:2402.03300/references?fields=title,authors,year,citationCount&limit=10" | python -m json.tool

      البحث عن أوراق (بديل لبحث arXiv، يُعيد JSON)​

      curl -s "https://api.semanticscholar.org/graph/v1/paper/search?query=GRPO+reinforcement+learning&limit=5&fields=title,authors,year,citationCount,externalIds" | python -m json.tool

      الحصول على توصيات بأوراق​

      curl -s -X POST "https://api.semanticscholar.org/recommendations/v1/papers/" \
        -H "Content-Type: application/json" \
        -d '{"positivePaperIds": ["arXiv:2402.03300"], "negativePaperIds": []}' | python -m json.tool

      الملف الشخصي للمؤلف​

      curl -s "https://api.semanticscholar.org/graph/v1/author/search?query=Yann+LeCun&fields=name,hIndex,citationCount,paperCount" | python -m json.tool

      حقول Semantic Scholar المفيدة​

      title, authors, year, abstract, citationCount, referenceCount, influentialCitationCount, isOpenAccess, openAccessPdf, fieldsOfStudy, publicationVenue, externalIds (يحتوي على معرّف arXiv، DOI، إلخ)

      سير عمل بحثي كامل​

      1. الاكتشاف: python scripts/search_arxiv.py "your topic" --sort date --max 10
      2. تقييم الأثر: curl -s "https://api.semanticscholar.org/graph/v1/paper/arXiv:ID?fields=citationCount,influentialCitationCount"
      3. قراءة الملخّص: web_extract(urls=["https://arxiv.org/abs/ID"])
      4. قراءة الورقة كاملة: web_extract(urls=["https://arxiv.org/pdf/ID"])
      5. إيجاد الأعمال ذات الصلة: curl -s "https://api.semanticscholar.org/graph/v1/paper/arXiv:ID/references?fields=title,citationCount&limit=20"
      6. الحصول على توصيات: POST إلى endpoint التوصيات في Semantic Scholar
      7. تتبّع المؤلفين: curl -s "https://api.semanticscholar.org/graph/v1/author/search?query=NAME"

      الواجهةالمعدلالمصادقة

      ملاحظات​

      • تُعيد arXiv صيغة Atom XML — استخدم السكربت المساعد أو مقتطف التحليل للحصول على مخرجات نظيفة
      • تُعيد Semantic Scholar صيغة JSON — مرّرها عبر python -m json.tool لسهولة القراءة
      • معرّفات arXiv: الصيغة القديمة (hep-th/0601001) مقابل الجديدة (2402.03300)
      • PDF: https://arxiv.org/pdf/{id} — الملخّص: https://arxiv.org/abs/{id}
      • HTML (عند توفّرها): https://arxiv.org/html/{id}
      • لمعالجة ملفات PDF محليًا، راجع مهارة ocr-and-documents

      ترقيم إصدارات المعرّفات​

      • arxiv.org/abs/1706.03762 يشير دائمًا إلى أحدث إصدار
      • arxiv.org/abs/1706.03762v1 يشير إلى إصدار محدّد غير قابل للتغيير
      • عند توليد الاستشهادات، احتفظ بلاحقة الإصدار التي قرأتها فعليًا لمنع انزياح الاستشهاد (قد يغيّر إصدار لاحق المحتوى بشكل جوهري)
      • يُعيد حقل <id> في الواجهة الرابط المُرقّم بالإصدار (مثل http://arxiv.org/abs/1706.03762v7)

      الأوراق المسحوبة​

      يمكن سحب الأوراق بعد تقديمها. عند حدوث ذلك:

      • يحتوي حقل <summary> على إشعار سحب (ابحث عن "withdrawn" أو "retracted")
      • قد تكون حقول البيانات الوصفية ناقصة
      • تحقّق دائمًا من الملخّص قبل التعامل مع نتيجة على أنها ورقة صالحة
