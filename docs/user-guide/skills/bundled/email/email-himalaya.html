      Himalaya

      Himalaya CLI: بريد إلكتروني عبر IMAP/SMTP من الطرفية.

      بيانات المهارة الوصفية​

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      Himalaya Email CLI

      Himalaya هو عميل بريد إلكتروني بواجهة سطر أوامر (CLI) يتيح لك إدارة رسائل البريد من الطرفية باستخدام backends من نوع IMAP أو SMTP أو Notmuch أو Sendmail.

      هذه المهارة منفصلة عن مُهايئ gateway البريد في Hermes. فمُهايئ الـ gateway يتيح للأشخاص إرسال بريد إلكتروني إلى الوكيل ويستخدم مُهايئ IMAP/SMTP المدمج في Hermes؛ أما هذه المهارة فتتيح للوكيل تشغيل صندوق بريد من أدوات الطرفية، وتتطلب CLI الخارجي himalaya.

      المراجع​

      • references/configuration.md (إعداد ملف الإعدادات + مصادقة IMAP/SMTP)
      • references/message-composition.md (صيغة MML لصياغة رسائل البريد)

      المتطلبات المسبقة​

      1. تثبيت Himalaya CLI (تحقّق بـ himalaya --version)
      2. ملف إعدادات في ~/.config/himalaya/config.toml
      3. ضبط بيانات اعتماد IMAP/SMTP (مع تخزين كلمة المرور بأمان)

      التثبيت​

      # Pre-built binary (Linux/macOS — recommended)
      curl -sSL https://raw.githubusercontent.com/pimalaya/himalaya/master/install.sh | PREFIX=~/.local sh

      # macOS via Homebrew
      brew install himalaya

      # Or via cargo (any platform with Rust)
      cargo install himalaya --locked

      إعداد الضبط​

      شغّل المعالج التفاعلي لإعداد حساب:

      himalaya account configure

      أو أنشئ ~/.config/himalaya/config.toml يدويًا:

      [accounts.personal]
      email = "you@example.com"
      display-name = "Your Name"
      default = true

      backend.type = "imap"
      backend.host = "imap.example.com"
      backend.port = 993
      backend.encryption.type = "tls"
      backend.login = "you@example.com"
      backend.auth.type = "password"
      backend.auth.cmd = "pass show email/imap"  # or use keyring

      message.send.backend.type = "smtp"
      message.send.backend.host = "smtp.example.com"
      message.send.backend.port = 587
      message.send.backend.encryption.type = "start-tls"
      message.send.backend.login = "you@example.com"
      message.send.backend.auth.type = "password"
      message.send.backend.auth.cmd = "pass show email/smtp"

      # Folder aliases (himalaya v1.2.0+ syntax). Required whenever the
      # server's folder names don't match himalaya's canonical names
      # (inbox/sent/drafts/trash). Gmail is the common case — see
      # `references/configuration.md` for the `[Gmail]/Sent Mail` mapping.
      folder.aliases.inbox = "INBOX"
      folder.aliases.sent = "Sent"
      folder.aliases.drafts = "Drafts"
      folder.aliases.trash = "Trash"

      تنبيه بشأن صيغة الأسماء المستعارة (alias). استخدمت الوثائق قبل الإصدار v1.2.0 قسمًا فرعيًا بالصيغة [accounts.NAME.folder.alias] (بصيغة المفرد alias). يتجاهل الإصدار v1.2.0 هذه الصيغة بصمت — فالـ TOML يُحلَّل بلا مشكلة، لكن مُحلِّل الأسماء المستعارة لا يقرؤه أبدًا، فيسقط كل بحث إلى الاسم الأصلي (canonical). في Gmail يعني هذا أن الحفظ في مجلد المُرسَل يفشل بعد نجاح تسليم SMTP، ويخرج himalaya message send برمز غير صفري. أي مستدعٍ (وكيل، سكربت، مستخدم) يعيد المحاولة عند رمز الخروج هذا سيعيد تشغيل عملية الإرسال بأكملها — بما فيها SMTP — مما ينتج رسائل مكررة للمستلمين. استخدم دائمًا folder.aliases.X (بصيغة الجمع، بمفاتيح منقوطة، مباشرة تحت [accounts.NAME]).

      ملاحظات حول التكامل مع Hermes​

      • القراءة، والسرد، والبحث، والنقل، والحذف تعمل جميعًا مباشرة عبر أداة الطرفية
      • الصياغة/الرد/إعادة التوجيه — يُنصح باستخدام الإدخال عبر أنبوب (cat << EOF | himalaya template send) لضمان الموثوقية. يعمل وضع $EDITOR التفاعلي مع pty=true + الخلفية + أداة العمليات، لكنه يتطلب معرفة المحرر وأوامره
      • استخدم --output json للحصول على مخرجات مُهيكلة يسهل تحليلها برمجيًا
      • يتطلب معالج himalaya account configure إدخالًا تفاعليًا — استخدم وضع PTY: terminal(command="himalaya account configure", pty=true)

      عمليات شائعة​

      سرد المجلدات​

      himalaya folder list

      سرد رسائل البريد​

      سرد الرسائل في INBOX (الافتراضي):

      himalaya envelope list

      سرد الرسائل في مجلد محدد:

      himalaya envelope list --folder "Sent"

      سرد مع ترقيم الصفحات:

      himalaya envelope list --page 1 --page-size 20

      البحث في رسائل البريد​

      himalaya envelope list from john@example.com subject meeting

      قراءة رسالة بريد​

      قراءة رسالة عبر المعرّف (تعرض نصًا عاديًا):

      himalaya message read 42

      تصدير MIME الخام:

      himalaya message export 42 --full

      الرد على رسالة بريد​

      للرد بشكل غير تفاعلي من Hermes، اقرأ الرسالة الأصلية، وصِغ ردًا، ثم مرّره عبر أنبوب:

      # Get the reply template, edit it, and send
      himalaya template reply 42 | sed 's/^$/\nYour reply text here\n/' | himalaya template send

      أو ابنِ الرد يدويًا:

      cat << 'EOF' | himalaya template send
      From: you@example.com
      To: sender@example.com
      Subject: Re: Original Subject
      In-Reply-To: <original-message-id>

      Your reply here.
      EOF

      الرد على الجميع (تفاعلي — يحتاج $EDITOR، استخدم بدلًا منه أسلوب القالب أعلاه):

      himalaya message reply 42 --all

      إعادة توجيه رسالة بريد​

      # Get forward template and pipe with modifications
      himalaya template forward 42 | sed 's/^To:.*/To: newrecipient@example.com/' | himalaya template send

      كتابة رسالة بريد جديدة​

      غير تفاعلي (استخدم هذا من Hermes) — مرّر الرسالة عبر stdin:

      cat << 'EOF' | himalaya template send
      From: you@example.com
      To: recipient@example.com
      Subject: Test Message

      Hello from Himalaya!
      EOF

      أو مع علم الترويسات (headers):

      himalaya message write -H "To:recipient@example.com" -H "Subject:Test" "Message body here"

      ملاحظة: himalaya message write بدون إدخال عبر أنبوب يفتح $EDITOR. يعمل هذا مع pty=true + وضع الخلفية، لكن التمرير عبر الأنبوب أبسط وأكثر موثوقية.

      نقل/نسخ رسائل البريد​

      النقل إلى مجلد (المجلد الهدف أولًا، ثم معرّف الرسالة):

      himalaya message move "Archive" 42

      النسخ إلى مجلد (المجلد الهدف أولًا، ثم معرّف الرسالة):

      himalaya message copy "Important" 42

      حذف رسالة بريد​

      himalaya message delete 42

      إدارة الأعلام (Flags)​

      إضافة علم:

      himalaya flag add 42 --flag seen

      إزالة علم:

      himalaya flag remove 42 --flag seen

      حسابات متعددة​

      سرد الحسابات:

      himalaya account list

      استخدام حساب محدد:

      himalaya --account work envelope list

      المرفقات​

      حفظ المرفقات من رسالة:

      himalaya attachment download 42

      الحفظ في دليل محدد:

      himalaya attachment download 42 --downloads-dir ~/Downloads

      صيغ المخرجات​

      معظم الأوامر تدعم --output لمخرجات مُهيكلة:

      himalaya envelope list --output json
      himalaya envelope list --output plain

      استكشاف الأخطاء​

      تفعيل سجلات التصحيح (debug):

      RUST_LOG=debug himalaya envelope list

      تتبّع كامل مع backtrace:

      RUST_LOG=trace RUST_BACKTRACE=1 himalaya envelope list

      نصائح​

      • استخدم himalaya --help أو himalaya <command> --help لتفاصيل الاستخدام.
      • معرّفات الرسائل نسبية إلى المجلد الحالي؛ أعد السرد بعد تغيير المجلد.
      • لصياغة رسائل غنية بالمرفقات، استخدم صيغة MML (راجع references/message-composition.md).
      • خزّن كلمات المرور بأمان باستخدام pass، أو مخزن مفاتيح النظام (keyring)، أو أمر يُخرج كلمة المرور.
