      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      Notion

      تعامل مع Notion بطريقتين. يعمل رمز التكامل نفسه لكلتيهما — اختر حسب المتاح.

      ◆ واجهة ntn CLI — واجهة CLI الرسمية لـ Notion. صياغة أقصر، ورفع ملفات بسطر واحد، ومطلوبة لـ Workers. تعمل فقط على macOS وLinux حتى مايو 2026 (دعم Windows "قادم قريبًا"). الخيار الافتراضي عند تثبيتها. ◆ HTTP + curl — تعمل في كل مكان بما في ذلك Windows. الخيار الاحتياطي الافتراضي عندما لا تكون ntn مثبّتة.

      الإعداد​

      1. احصل على رمز تكامل (مطلوب لكلا المسارين)​

      1. أنشئ تكاملًا من https://notion.so/my-integrations
      2. انسخ مفتاح API (يبدأ بـ ntn_ أو secret_)
      3. خزّنه في ${HERMES_HOME:-~/.hermes}/.env: 
        NOTION_API_KEY=ntn_your_key_here
      4. شارك الصفحات/قواعد البيانات المستهدفة مع التكامل في Notion: قائمة الصفحة ... ← Connect to ← اسم تكاملك. بدون ذلك، تُعيد الواجهة الخطأ 404 لتلك الصفحة رغم وجودها.

      2. ثبّت ntn (المسار المفضّل على macOS / Linux)​

      # Recommended
      curl -fsSL https://ntn.dev | bash

      # Or via npm (needs Node 22+, npm 10+)
      npm install --global ntn

      ntn --version    # verify

      تخطَّ ntn login — استخدم رمز التكامل بدلًا منه. يعمل هذا دون واجهة رسومية (headlessly)، بلا حاجة إلى متصفح:

      export NOTION_API_TOKEN=$NOTION_API_KEY      # ntn reads NOTION_API_TOKEN
      export NOTION_KEYRING=0                       # don't try to use the OS keychain

      أضِف تلك المتغيرات المُصدَّرة إلى ملف تعريف shell الخاص بك (أو إلى ${HERMES_HOME:-~/.hermes}/.env) بحيث ترثها كل جلسة.

      3. اختر المسار وقت التشغيل​

      if command -v ntn >/dev/null 2>&1; then
        # use ntn
      else
        # fall back to curl
      fi

      مستخدمو Windows: تخطَّ الخطوة 2 كليًا حتى يصدر ntn الأصلي — يعمل المسار B جيدًا. إذا أردت راحة استخدام CLI الآن، ثبّت ntn داخل WSL2.

      أساسيات API​

      Notion-Version: 2025-09-03 مطلوبة في كل طلبات HTTP. تتولى ntn ذلك نيابةً عنك. في هذا الإصدار، ما يسمّيه المستخدمون "قواعد بيانات" يُسمّى مصادر بيانات (data sources) في الواجهة.

      المسار A — واجهة ntn CLI (المفضّلة، macOS / Linux)​

      استدعاءات API الخام (اختصار لـ curl)​

      ntn api v1/users                                  # GET
      ntn api v1/pages parent[page_id]=abc123 \         # POST with inline body
        properties[title][0][text][content]="Notes"
      ntn api v1/pages/abc123 -X PATCH archived:=true   # PATCH; := is non-string (bool/num/null)

      ملاحظات الصياغة:

      • key=value — حقول نصية
      • key[nested]=value — حقول كائن متداخلة
      • key:=value — إسناد مُنمَّط (منطقية، أرقام، null، مصفوفات)

      البحث​

      ntn api v1/search query="page title"

      قراءة بيانات صفحة وصفية​

      ntn api v1/pages/{page_id}

      قراءة صفحة كصيغة Markdown (مناسبة للوكيل)​

      ntn api v1/pages/{page_id}/markdown

      قراءة محتوى صفحة ككتل​

      ntn api v1/blocks/{page_id}/children

      إنشاء صفحة من Markdown​

      ntn api v1/pages \
        parent[page_id]=xxx \
        properties[title][0][text][content]="Notes from meeting" \
        markdown="# Agenda

      - Q3 roadmap
      - Hiring"

      تحديث صفحة (PATCH) بواسطة Markdown​

      ntn api v1/pages/{page_id}/markdown -X PATCH \
        markdown="## Update

      Shipped the prototype."

      استعلام قاعدة بيانات (مصدر بيانات)​

      ntn api v1/data_sources/{data_source_id}/query -X POST \
        filter[property]=Status filter[select][equals]=Active

      للاستعلامات المعقدة التي تحتوي sorts، أو شروط فلترة متعددة، أو منطقًا مركّبًا، مرّر JSON عبر أنبوب (pipe):

      echo '{"filter": {"property": "Status", "select": {"equals": "Active"}}, "sorts": [{"property": "Date", "direction": "descending"}]}' | \
        ntn api v1/data_sources/{data_source_id}/query -X POST --json -

      رفع الملفات (بسطر واحد — أكبر ميزة في CLI)​

      ntn files create < photo.png
      ntn files create --external-url https://example.com/photo.png
      ntn files list

      قارن بتدفق HTTP المكوّن من 3 خطوات (إنشاء رفع ← PUT للبايتات ← الإشارة إليه).

      متغيرات بيئة مفيدة​

      المتغيرالتأثير
      NOTION_API_TOKENرمز المصادقة (يتجاوز الحلقة المفاتيح keychain) — اضبطه على رمز التكامل الخاص بك
      NOTION_KEYRING=0بيانات اعتماد قائمة على الملفات في ~/.config/notion/auth.json بدلًا من keychain نظام التشغيل
      NOTION_WORKSPACE_IDتخطي مطالبة اختيار مساحة العمل

      المسار B — HTTP + curl (متعدد المنصات، الافتراضي على Windows)​

      تشترك كل الطلبات في هذا النمط:

      curl -s -X GET "https://api.notion.com/v1/..." \
        -H "Authorization: Bearer $NOTION_API_KEY" \
        -H "Notion-Version: 2025-09-03" \
        -H "Content-Type: application/json"

      على Windows تعمل نسخة curl المرفقة مع Windows 10 فما فوق كما هي. يمكن لمستخدمي PowerShell أيضًا استخدام Invoke-RestMethod.

      البحث​

      curl -s -X POST "https://api.notion.com/v1/search" \
        -H "Authorization: Bearer $NOTION_API_KEY" \
        -H "Notion-Version: 2025-09-03" \
        -H "Content-Type: application/json" \
        -d '{"query": "page title"}'

      قراءة بيانات صفحة وصفية​

      curl -s "https://api.notion.com/v1/pages/{page_id}" \
        -H "Authorization: Bearer $NOTION_API_KEY" \
        -H "Notion-Version: 2025-09-03"

      قراءة صفحة كصيغة Markdown (مناسبة للوكيل)​

      أسهل تمريرًا لنموذج مقارنة بـ JSON الكتل.

      curl -s "https://api.notion.com/v1/pages/{page_id}/markdown" \
        -H "Authorization: Bearer $NOTION_API_KEY" \
        -H "Notion-Version: 2025-09-03"

      قراءة محتوى صفحة ككتل (عندما تحتاج إلى البنية)​

      curl -s "https://api.notion.com/v1/blocks/{page_id}/children" \
        -H "Authorization: Bearer $NOTION_API_KEY" \
        -H "Notion-Version: 2025-09-03"

      إنشاء صفحة من Markdown​

      يقبل POST /v1/pages معامل جسم markdown.

      curl -s -X POST "https://api.notion.com/v1/pages" \
        -H "Authorization: Bearer $NOTION_API_KEY" \
        -H "Notion-Version: 2025-09-03" \
        -H "Content-Type: application/json" \
        -d '{
          "parent": {"page_id": "xxx"},
          "properties": {"title": [{"text": {"content": "Notes from meeting"}}]},
          "markdown": "# Agenda\n\n- Q3 roadmap\n- Hiring\n\n## Decisions\n- Ship MVP Friday"
        }'

      تحديث صفحة (PATCH) بواسطة Markdown​

      curl -s -X PATCH "https://api.notion.com/v1/pages/{page_id}/markdown" \
        -H "Authorization: Bearer $NOTION_API_KEY" \
        -H "Notion-Version: 2025-09-03" \
        -H "Content-Type: application/json" \
        -d '{"markdown": "## Update\n\nShipped the prototype."}'

      إنشاء صفحة داخل قاعدة بيانات (خصائص مُنمَّطة)​

      curl -s -X POST "https://api.notion.com/v1/pages" \
        -H "Authorization: Bearer $NOTION_API_KEY" \
        -H "Notion-Version: 2025-09-03" \
        -H "Content-Type: application/json" \
        -d '{
          "parent": {"database_id": "xxx"},
          "properties": {
            "Name": {"title": [{"text": {"content": "New Item"}}]},
            "Status": {"select": {"name": "Todo"}}
          }
        }'

      استعلام قاعدة بيانات (مصدر بيانات)​

      curl -s -X POST "https://api.notion.com/v1/data_sources/{data_source_id}/query" \
        -H "Authorization: Bearer $NOTION_API_KEY" \
        -H "Notion-Version: 2025-09-03" \
        -H "Content-Type: application/json" \
        -d '{
          "filter": {"property": "Status", "select": {"equals": "Active"}},
          "sorts": [{"property": "Date", "direction": "descending"}]
        }'

      إنشاء قاعدة بيانات​

      curl -s -X POST "https://api.notion.com/v1/data_sources" \
        -H "Authorization: Bearer $NOTION_API_KEY" \
        -H "Notion-Version: 2025-09-03" \
        -H "Content-Type: application/json" \
        -d '{
          "parent": {"page_id": "xxx"},
          "title": [{"text": {"content": "My Database"}}],
          "properties": {
            "Name": {"title": {}},
            "Status": {"select": {"options": [{"name": "Todo"}, {"name": "Done"}]}},
            "Date": {"date": {}}
          }
        }'

      تحديث خصائص صفحة​

      curl -s -X PATCH "https://api.notion.com/v1/pages/{page_id}" \
        -H "Authorization: Bearer $NOTION_API_KEY" \
        -H "Notion-Version: 2025-09-03" \
        -H "Content-Type: application/json" \
        -d '{"properties": {"Status": {"select": {"name": "Done"}}}}'

      إلحاق كتل بصفحة​

      curl -s -X PATCH "https://api.notion.com/v1/blocks/{page_id}/children" \
        -H "Authorization: Bearer $NOTION_API_KEY" \
        -H "Notion-Version: 2025-09-03" \
        -H "Content-Type: application/json" \
        -d '{
          "children": [
            {"object": "block", "type": "paragraph", "paragraph": {"rich_text": [{"text": {"content": "Hello from Hermes!"}}]}}
          ]
        }'

      رفع الملفات (تدفق من 3 خطوات)​

      # 1. Create upload
      curl -s -X POST "https://api.notion.com/v1/file_uploads" \
        -H "Authorization: Bearer $NOTION_API_KEY" \
        -H "Notion-Version: 2025-09-03" \
        -H "Content-Type: application/json" \
        -d '{"filename": "photo.png", "content_type": "image/png"}'

      # 2. PUT bytes to the upload_url returned above
      curl -s -X PUT "{upload_url}" --data-binary @photo.png

      # 3. Reference {file_upload_id} in a page/block payload

      أنواع الخصائص​

      صيغ الخصائص الشائعة لعناصر قاعدة البيانات:

      • العنوان: {"title": [{"text": {"content": "..."}}]}
      • نص منسّق: {"rich_text": [{"text": {"content": "..."}}]}
      • اختيار مفرد: {"select": {"name": "Option"}}
      • اختيار متعدد: {"multi_select": [{"name": "A"}, {"name": "B"}]}
      • تاريخ: {"date": {"start": "2026-01-15", "end": "2026-01-16"}}
      • مربع اختيار: {"checkbox": true}
      • رقم: {"number": 42}
      • رابط: {"url": "https://..."}
      • بريد إلكتروني: {"email": "user@example.com"}
      • علاقة: {"relation": [{"id": "page_id"}]}

      إصدار API رقم 2025-09-03 — قواعد البيانات مقابل مصادر البيانات​

      • أصبحت قواعد البيانات مصادر بيانات. استخدم endpoints من نوع /data_sources/ للاستعلام والجلب.
      • معرّفان لكل قاعدة بيانات: database_id وdata_source_id.
        • database_id عند إنشاء الصفحات: parent: {"database_id": "..."}
        • data_source_id عند الاستعلام: POST /v1/data_sources/{id}/query
      • يُعيد البحث قواعد البيانات بصيغة "object": "data_source" مع حقل data_source_id.

      Notion Workers (متقدّم، يتطلّب ntn)​

      Workers هي برامج TypeScript تستضيفها Notion نيابةً عنك. يمكن لعامل (worker) واحد أن يعرض أي مزيج من:

      • Syncs — تسحب بيانات من واجهات API خارجية إلى قاعدة بيانات Notion وفق جدول زمني (30 دقيقة افتراضيًا).
      • Tools — تظهر كأدوات قابلة للاستدعاء داخل Custom Agents في Notion.
      • Webhooks — تستقبل أحداث HTTP من خدمات خارجية (GitHub، Stripe، وغيرها) وتتصرف داخل Notion.

      قيود الخطة/المنصة:

      • تعمل CLI على كل الخطط. يتطلب نشر Workers خطة Business أو Enterprise.
      • ntn متاحة فقط على macOS/Linux حتى مايو 2026. يحتاج مستخدمو Windows إلى WSL2 أو الانتظار حتى يتوفر الدعم الأصلي.
      • مجانية حتى 11 أغسطس 2026؛ ثم تُحتسب وفق ائتمانات Notion بعد ذلك.

      أبسط Worker​

      ntn workers new my-worker      # scaffold
      cd my-worker
      # Edit src/index.ts
      ntn workers deploy --name my-worker

      src/index.ts:

      import { Worker } from "@notionhq/workers";

      const worker = new Worker();
      export default worker;

      worker.tool("greet", {
        title: "Greet a User",
        description: "Returns a friendly greeting",
        inputSchema: { type: "object", properties: { name: { type: "string" } }, required: ["name"] },
        execute: async ({ name }) => `Hello, ${name}!`,
      });

      إمكانية Webhook​

      worker.webhook("onGithubPush", {
        title: "GitHub Push Handler",
        execute: async (events, { notion }) => {
          for (const event of events) {
            // event.body, event.rawBody (for signature verification), event.headers
            console.log("got delivery", event.deliveryId);
          }
        },
      });

      بعد النشر: يُظهر ntn workers webhooks list الرابط الذي تولّده Notion. عامل هذا الرابط كسرّ — فأي شخص يملكه يستطيع إرسال أحداث POST ما لم تُضِف تحقق التوقيع.

      أوامر دورة حياة Worker​

      ntn workers deploy
      ntn workers list
      ntn workers exec <capability-key> -d '{"name": "world"}'
      ntn workers sync trigger <key>            # run a sync now
      ntn workers sync pause <key>
      ntn workers env set GITHUB_WEBHOOK_SECRET=...
      ntn workers runs list                     # recent invocations
      ntn workers runs logs <run-id>
      ntn workers webhooks list

      عند الطلب ببناء Worker، أنشئ الهيكل بواسطة ntn workers new، واكتب الكود في src/index.ts، واضبط أي أسرار باستخدام ntn workers env set، ثم انشره. تغطي وثائق Notion على https://developers.notion.com/workers واجهة API كاملة.

      صيغة Notion الخاصة من Markdown (تستخدمها endpoints من نوع /markdown)​

      صيغة CommonMark القياسية بالإضافة إلى وسوم شبيهة بـ XML لكتل Notion الخاصة. استخدم tabs للمسافة البادئة.

      كتل تتجاوز CommonMark:

      <callout icon="🎯" color="blue_bg">
      	Ship the MVP by **Friday**.
      </callout>

      <details color="gray">
      <summary>Toggle title</summary>
      	Children indented one tab
      </details>

      <columns>
      	<column>Left side</column>
      	<column>Right side</column>
      </columns>

      <table_of_contents color="gray"/>

      ضمن السطر:

      • الإشارات (Mentions): <mention-user url="..."/>، و<mention-page url="...">Title</mention-page>، و<mention-date start="2026-05-15"/>
      • التسطير: <span underline="true">text</span>
      • اللون: <span color="blue">text</span> أو على مستوى الكتلة {color="blue"} في السطر الأول
      • الرياضيات: ضمن السطر $x^2$، وككتلة $$ ... $$
      • الاستشهادات: [^https://example.com]

      الألوان: gray brown orange yellow green blue purple pink red، بالإضافة إلى صيغ *_bg للخلفيات.

      تنهار العناوين من المستوى 5/6 إلى H4. تُعرض أسطر > المتعددة ككتل اقتباس منفصلة — استخدم <br> داخل علامة > واحدة للاقتباسات متعددة الأسطر.

      ملاحظات​

      • مُعرّفات الصفحات/قواعد البيانات هي UUID (بشرطات أو بدونها — كلاهما مقبول).
      • حدّ المعدل: نحو 3 طلبات/ثانية في المتوسط. لا تتجاوز CLI هذا الحد.
      • لا تستطيع الواجهة ضبط فلاتر عرض (view) قاعدة البيانات — فذلك مقتصر على الواجهة الرسومية فقط.
      • استخدم "is_inline": true عند إنشاء مصادر بيانات لتضمينها داخل صفحة.
      • مرّر دائمًا -s إلى curl لإخفاء أشرطة التقدم (ناتج أنظف للوكيل).
      • مرّر JSON عبر jq عند القراءة: ... | jq '.results[0].properties'.
      • توفّر Notion الآن أيضًا خادم MCP (Notion MCP، بكفاءة أعلى في استهلاك الـ tokens بنحو 91% على عمليات قواعد البيانات مقارنة بالإصدار السابق) — وصّله عبر دعم MCP في Hermes إن أردت وصولًا متدفقًا (streaming) إلى Notion من داخل الجلسة، لكن المسارات أعلاه كافية لمعظم المهام الفردية.
