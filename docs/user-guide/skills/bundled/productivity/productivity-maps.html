      Maps

      الترميز الجغرافي، ونقاط الاهتمام (POIs)، والمسارات، والمناطق الزمنية عبر OpenStreetMap/OSRM.

      بيانات المهارة الوصفية​

      المصدرمضمّنة (مثبّتة افتراضيًا)
      المسارskills/productivity/maps
      الإصدار1.2.0
      المؤلفMibayy
      الترخيصMIT
      المنصاتlinux, macos, windows
      الوسومmaps, geocoding, places, routing, distance, directions, nearby, location, openstreetmap, nominatim, overpass, osrm

      المرجع: ملف SKILL.md كاملًا​

      معلومة

      ما يلي هو التعريف الكامل للمهارة الذي يحمّله Hermes عند تفعيل هذه المهارة، وهو ما يراه الوكيل كتعليمات أثناء عمل المهارة.

      مهارة Maps

      ذكاء الموقع باستخدام مصادر بيانات مجانية ومفتوحة. 8 أوامر، و44 فئة من نقاط الاهتمام (POI)، وبلا اعتماديات (Python stdlib فقط)، وبلا حاجة إلى مفتاح API.

      مصادر البيانات: OpenStreetMap/Nominatim، وOverpass API، وOSRM، وTimeAPI.io.

      تحلّ هذه المهارة محل مهارة find-nearby القديمة — إذ تغطي وظيفة nearby أدناه كل ما كانت توفره find-nearby، بنفس اختصار --near "<place>" ودعم الفئات المتعددة.

      متى تُستخدم​

      • يرسل المستخدم دبوس موقع عبر Telegram (خطوط الطول/العرض في الرسالة) ← nearby
      • يريد المستخدم إحداثيات لاسم مكان ← search
      • لدى المستخدم إحداثيات ويريد العنوان ← reverse
      • يطلب المستخدم مطاعم أو مستشفيات أو صيدليات أو فنادق قريبة وغير ذلك ← nearby
      • يريد المستخدم مسافة أو زمن القيادة/المشي/ركوب الدراجة ← distance
      • يريد المستخدم إرشادات خطوة بخطوة بين مكانين ← directions
      • يريد المستخدم معلومات المنطقة الزمنية لموقع ما ← timezone
      • يريد المستخدم البحث عن نقاط اهتمام ضمن منطقة جغرافية ← area + bbox

      المتطلبات المسبقة​

      Python 3.8 فما فوق (stdlib فقط — بلا حاجة إلى تثبيتات pip).

      مسار السكربت: ~/.hermes/skills/maps/scripts/maps_client.py

      الأوامر​

      MAPS=~/.hermes/skills/maps/scripts/maps_client.py

      search — ترميز جغرافي لاسم مكان​

      python $MAPS search "Eiffel Tower"
      python $MAPS search "1600 Pennsylvania Ave, Washington DC"

      يُعيد: خط العرض، خط الطول، اسم العرض، النوع، المربع المحيط، ودرجة الأهمية.

      reverse — من الإحداثيات إلى العنوان​

      python $MAPS reverse 48.8584 2.2945

      يُعيد: تفصيل العنوان الكامل (الشارع، المدينة، الولاية/المحافظة، الدولة، الرمز البريدي).

      nearby — إيجاد الأماكن حسب الفئة​

      # By coordinates (from a Telegram location pin, for example)
      python $MAPS nearby 48.8584 2.2945 restaurant --limit 10
      python $MAPS nearby 40.7128 -74.0060 hospital --radius 2000

      # By address / city / zip / landmark — --near auto-geocodes
      python $MAPS nearby --near "Times Square, New York" --category cafe
      python $MAPS nearby --near "90210" --category pharmacy

      # Multiple categories merged into one query
      python $MAPS nearby --near "downtown austin" --category restaurant --category bar --limit 10

      46 فئة: restaurant, cafe, bar, hospital, pharmacy, hotel, guest_house, camp_site, supermarket, atm, gas_station, parking, museum, park, school, university, bank, police, fire_station, library, airport, train_station, bus_stop, church, mosque, synagogue, dentist, doctor, cinema, theatre, gym, swimming_pool, post_office, convenience_store, bakery, bookshop, laundry, car_wash, car_rental, bicycle_rental, taxi, veterinary, zoo, playground, stadium, nightclub.

      تتضمن كل نتيجة: name، وaddress، وlat/lon، وdistance_m، وmaps_url (رابط Google Maps قابل للنقر)، وdirections_url (اتجاهات Google Maps من نقطة البحث)، والوسوم البارزة عند توفرها — cuisine، وhours (opening_hours)، وphone، وwebsite.

      distance — مسافة وزمن السفر​

      python $MAPS distance "Paris" --to "Lyon"
      python $MAPS distance "New York" --to "Boston" --mode driving
      python $MAPS distance "Big Ben" --to "Tower Bridge" --mode walking

      الأوضاع: القيادة (الافتراضي)، المشي، ركوب الدراجة. يُعيد مسافة الطريق ومدته، والمسافة المستقيمة للمقارنة.

      directions — ملاحة خطوة بخطوة​

      python $MAPS directions "Eiffel Tower" --to "Louvre Museum" --mode walking
      python $MAPS directions "JFK Airport" --to "Times Square" --mode driving

      يُعيد خطوات مرقّمة تتضمن التعليمات والمسافة والمدة واسم الطريق ونوع المناورة (انعطاف، انطلاق، وصول، وغيرها).

      timezone — المنطقة الزمنية للإحداثيات​

      python $MAPS timezone 48.8584 2.2945
      python $MAPS timezone 35.6762 139.6503

      يُعيد اسم المنطقة الزمنية، وإزاحة UTC، والوقت المحلي الحالي.

      area — المربع المحيط ومساحة مكان ما​

      python $MAPS area "Manhattan, New York"
      python $MAPS area "London"

      يُعيد إحداثيات المربع المحيط، والعرض/الارتفاع بالكيلومتر، والمساحة التقريبية. مفيد كمدخل لأمر bbox.

      bbox — البحث ضمن مربع محيط​

      python $MAPS bbox 40.75 -74.00 40.77 -73.98 restaurant --limit 20

      يجد نقاط الاهتمام ضمن مستطيل جغرافي. استخدم area أولًا للحصول على إحداثيات المربع المحيط لمكان مُسمّى.

      العمل مع دبابيس مواقع Telegram​

      عندما يرسل المستخدم دبوس موقع، تحتوي الرسالة على حقلي latitude: و longitude:. استخرجهما ومرّرهما مباشرة إلى nearby:

      # User sent a pin at 36.17, -115.14 and asked "find cafes nearby"
      python $MAPS nearby 36.17 -115.14 cafe --radius 1500

      اعرض النتائج كقائمة مرقّمة تتضمن الأسماء والمسافات وحقل maps_url بحيث يحصل المستخدم على رابط قابل للنقر داخل المحادثة. بالنسبة لأسئلة "هل هو مفتوح الآن؟"، تحقق من حقل hours؛ وإن كان مفقودًا أو غير واضح، تحقق باستخدام web_search نظرًا لأن ساعات OSM يديرها المجتمع وقد لا تكون محدَّثة دائمًا.

      أمثلة على سير العمل​

      "ابحث عن مطاعم إيطالية قرب الكولوسيوم":

      1. nearby --near "Colosseum Rome" --category restaurant --radius 500 — أمر واحد، بترميز جغرافي تلقائي

      "ما القريب من دبوس الموقع الذي أرسلوه؟":

      1. استخرج خط العرض/الطول من رسالة Telegram
      2. nearby LAT LON cafe --radius 1500

      "كيف أمشي من الفندق إلى مركز المؤتمرات؟":

      1. directions "Hotel Name" --to "Conference Center" --mode walking

      "ما المطاعم الموجودة في وسط سياتل؟":

      1. area "Downtown Seattle" ← احصل على المربع المحيط
      2. bbox S W N E restaurant --limit 30

      مزالق شائعة​

      • شروط استخدام Nominatim: بحد أقصى طلب واحد/ثانية (يُدار تلقائيًا بواسطة السكربت)
      • يتطلب nearby إحداثيات أو --near "<address>" — يلزم توفر أحدهما
      • تغطية توجيه OSRM أفضل ما تكون في أوروبا وأمريكا الشمالية
      • قد تكون Overpass API بطيئة في أوقات الذروة؛ يعود السكربت تلقائيًا إلى مرايا (mirrors) بديلة (overpass-api.de ← overpass.kumi.systems)
      • يستخدم distance وdirections علم --to للوجهة (وليس كموضع)
      • إذا أعطى الرمز البريدي وحده نتائج غامضة عالميًا، أضِف الدولة/الولاية

      التحقق​

      python ~/.hermes/skills/maps/scripts/maps_client.py search "Statue of Liberty"
      # Should return lat ~40.689, lon ~-74.044

      python ~/.hermes/skills/maps/scripts/maps_client.py nearby --near "Times Square" --category restaurant --limit 3
      # Should return a list of restaurants within ~500m of Times Square
