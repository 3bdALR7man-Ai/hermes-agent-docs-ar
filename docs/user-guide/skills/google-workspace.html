      مهارة Google Workspace

      تكامل مع Gmail وCalendar وDrive وContacts وSheets وDocs لصالح Hermes. يستخدم OAuth2 مع تحديث تلقائي للرمز (token). يُفضِّل Google Workspace CLI (gws) عند توفره لتغطية أوسع، ويعود إلى مكتبات Python الرسمية من Google خلاف ذلك.

      مسار المهارة: skills/productivity/google-workspace/

      الإعداد​

      الإعداد مُدار بالكامل من الوكيل — اطلب من Hermes إعداد Google Workspace وسيرشدك خطوة بخطوة. سير العمل:

      1. إنشاء مشروع Google Cloud وتفعيل الواجهات البرمجية المطلوبة (Gmail، Calendar، Drive، Sheets، Docs، People)
      2. إنشاء بيانات اعتماد OAuth 2.0 (نوع تطبيق Desktop) وتحميل ملف client secret بصيغة JSON
      3. التفويض (Authorize) — يولّد Hermes رابط مصادقة، توافق عليه في المتصفح، ثم تلصق رابط إعادة التوجيه (redirect URL) مرة أخرى
      4. انتهى — يتجدَّد الرمز تلقائيًا من تلك اللحظة فصاعدًا
      لمستخدمي البريد الإلكتروني فقط

      إن كنت تحتاج البريد الإلكتروني فقط (بلا Calendar/Drive/Sheets)، استخدم مهارة himalaya بدلًا من ذلك — تعمل بكلمة مرور تطبيق (App Password) لـ Gmail وتستغرق دقيقتين. بلا حاجة لمشروع Google Cloud.

      Gmail​

      البحث​

      $GAPI gmail search "is:unread" --max 10
      $GAPI gmail search "from:boss@company.com newer_than:1d"
      $GAPI gmail search "has:attachment filename:pdf newer_than:7d"

      تُعيد JSON يحتوي id، وfrom، وsubject، وdate، وsnippet، وlabels لكل رسالة.

      القراءة​

      $GAPI gmail get MESSAGE_ID

      تُعيد نص الرسالة الكامل كنص (تفضّل النص العادي، وتعود إلى HTML عند عدم توفره).

      الإرسال​

      # Basic send
      $GAPI gmail send --to user@example.com --subject "Hello" --body "Message text"

      # HTML email
      $GAPI gmail send --to user@example.com --subject "Report" \
        --body "<h1>Q4 Results</h1><p>Details here</p>" --html

      # Custom From header (display name + email)
      $GAPI gmail send --to user@example.com --subject "Hello" \
        --from '"Research Agent" <user@example.com>' --body "Message text"

      # With CC
      $GAPI gmail send --to user@example.com --cc "team@example.com" \
        --subject "Update" --body "FYI"

      ترويسة From مخصَّصة​

      يتيح لك الخيار --from تخصيص اسم عرض المُرسِل في الرسائل الصادرة. مفيد عندما يشترك عدة وكلاء في حساب Gmail نفسه لكنك تريد أن يرى المستلمون أسماء مختلفة:

      # Agent 1
      $GAPI gmail send --to client@co.com --subject "Research Summary" \
        --from '"Research Agent" <shared@company.com>' --body "..."

      # Agent 2  
      $GAPI gmail send --to client@co.com --subject "Code Review" \
        --from '"Code Assistant" <shared@company.com>' --body "..."

      كيف يعمل: تُضبَط قيمة --from كترويسة From وفق RFC 5322 على رسالة MIME. يتيح Gmail تخصيص اسم العرض على عنوان بريدك الإلكتروني المُصادَق عليه دون أي إعداد إضافي. يرى المستلمون اسم العرض المخصَّص (مثل "Research Agent") بينما يبقى عنوان البريد الإلكتروني كما هو.

      مهم: إذا استخدمت عنوان بريد إلكتروني مختلفًا في --from (غير الحساب المُصادَق عليه)، يشترط Gmail أن يكون ذلك العنوان مُعَدًّا كـاسم مستعار للإرسال باسم (Send As alias) في Gmail Settings ← Accounts ← Send mail as.

      يعمل الخيار --from مع كل من send وreply:

      $GAPI gmail reply MESSAGE_ID \
        --from '"Support Bot" <shared@company.com>' --body "We're on it"

      الرد​

      $GAPI gmail reply MESSAGE_ID --body "Thanks, that works for me."

      يربط الرد تلقائيًا بمساره (يضبط ترويستَي In-Reply-To وReferences) ويستخدم معرّف مسار الرسالة الأصلية.

      التصنيفات (Labels)​

      # List all labels
      $GAPI gmail labels

      # Add/remove labels
      $GAPI gmail modify MESSAGE_ID --add-labels LABEL_ID
      $GAPI gmail modify MESSAGE_ID --remove-labels UNREAD

      Calendar​

      # List events (defaults to next 7 days)
      $GAPI calendar list
      $GAPI calendar list --start 2026-03-01T00:00:00Z --end 2026-03-07T23:59:59Z

      # Create event (timezone required)
      $GAPI calendar create --summary "Team Standup" \
        --start 2026-03-01T10:00:00-07:00 --end 2026-03-01T10:30:00-07:00

      # With location and attendees
      $GAPI calendar create --summary "Lunch" \
        --start 2026-03-01T12:00:00Z --end 2026-03-01T13:00:00Z \
        --location "Cafe" --attendees "alice@co.com,bob@co.com"

      # Delete event
      $GAPI calendar delete EVENT_ID
      تحذير

      يجب أن تتضمّن أوقات Calendar فرق توقيت (offset) للمنطقة الزمنية (مثل -07:00) أو تستخدم UTC (Z). التواريخ والأوقات المجرّدة مثل 2026-03-01T10:00:00 غامضة وستُعامَل كـ UTC.

      Drive​

      $GAPI drive search "quarterly report" --max 10
      $GAPI drive search "mimeType='application/pdf'" --raw-query --max 5

      Sheets​

      # Read a range
      $GAPI sheets get SHEET_ID "Sheet1!A1:D10"

      # Write to a range
      $GAPI sheets update SHEET_ID "Sheet1!A1:B2" --values '[["Name","Score"],["Alice","95"]]'

      # Append rows
      $GAPI sheets append SHEET_ID "Sheet1!A:C" --values '[["new","row","data"]]'

      Docs​

      $GAPI docs get DOC_ID

      تُعيد عنوان المستند ومحتواه النصي الكامل.

      Contacts​

      $GAPI contacts list --max 20

      صيغة المخرجات​

      تُعيد جميع الأوامر JSON. الحقول الرئيسية لكل خدمة:

      الأمرالحقول
      gmail searchid، threadId، from، to، subject، date، snippet، labels
      gmail getid، threadId، from، to، subject، date، labels، body
      gmail send/replystatus، id، threadId
      calendar listid، summary، start، end، location، description، htmlLink
      calendar createstatus، id، summary، htmlLink
      drive searchid، name، mimeType، modifiedTime، webViewLink
      contacts listname، emails، phones
      sheets getمصفوفة ثنائية الأبعاد من قيم الخلايا

      استكشاف الأخطاء وإصلاحها​

      المشكلةالحل
      NOT_AUTHENTICATEDشغّل الإعداد (اطلب من Hermes إعداد Google Workspace)
      REFRESH_FAILEDأُلغي الرمز (token) — أعِد تشغيل خطوات التفويض
      HttpError 403: Insufficient Permissionنطاق (scope) ناقص — ألغِ التفويض وأعِد تفويضه بالخدمات الصحيحة
      HttpError 403: Access Not Configuredالواجهة البرمجية غير مفعّلة في Google Cloud Console
      ModuleNotFoundErrorشغّل سكربت الإعداد مع --install-deps
