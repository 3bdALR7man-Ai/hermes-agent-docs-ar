      الاستيراد من وكلاء آخرين

      يستورد hermes import-agent إعداد Claude Code أو OpenAI Codex CLI الحالي لديك إلى Hermes بأمر واحد. يتّبع النمط نفسه المعتمد على المعاينة أولًا في hermes claw migrate: تشاهد دائمًا خطة لكل عنصر قبل كتابة أي شيء، ولا يمسّ --dry-run القرص أبدًا.

      hermes import-agent                    # auto-detect ~/.claude or ~/.codex
      hermes import-agent claude-code        # import from ~/.claude
      hermes import-agent codex              # import from ~/.codex
      hermes import-agent claude-code --dry-run          # preview only
      hermes import-agent codex --source /path/to/.codex # custom location
      hermes import-agent claude-code --overwrite --yes  # replace conflicts, skip prompts

      ما الذي يُستورَد​

      Claude Code (~/.claude)​

      Claude CodeHermes
      CLAUDE.md (التعليمات العامة)مدخلات الذاكرة في ~/.hermes/memories/MEMORY.md
      settings.json ← permissions.allow (قواعد Bash(...))command_allowlist في config.yaml
      settings.json ← permissions.deny (قواعد Bash(...))approvals.deny في config.yaml
      mcpServers (من ~/.claude.json و settings.json)mcp_servers في config.yaml
      skills/<name>/ (مجلدات تحتوي SKILL.md)~/.hermes/skills/claude-code-imports/<name>/
      commands/*.md (slash commands)تُتجاوَز مع ملاحظة — حوّلها إلى مهارات (skills)

      تتحوّل قواعد بادئة Bash(npm run test:*) الخاصة بـ Claude إلى أنماط npm run test*. أما قواعد الصلاحيات غير Bash (Read(...)، WebFetch، ...) فتضبط أدوات خاصة بـ Claude وتُدرَج كقواعد غير مُطابَقة بدلًا من استيرادها.

      ما لا يُستورَد أبدًا​

      مفاتيح API وبيانات الاعتماد. لا تُقرَأ ملفات بيانات الاعتماد (~/.claude/.credentials.json، ~/.codex/auth.json) أبدًا، وتُحذَف متغيرات بيئة خادم MCP أو الترويسات (headers) ذات الأسماء التي تبدو سرّية (*_TOKEN، *_API_KEY، Authorization، ...) وتُدرَج في التقرير حتى تعيد إضافتها عن قصد. شغّل hermes setup لإعداد المزوّدين، أو أضِف الأسرار (secrets) إلى ~/.hermes/.env.

      ملاحظات حول السلوك​

      • المعاينة أولًا، دائمًا. يطبع الأمر الخطة الكاملة قبل التطبيق؛ وفي الجلسات غير التفاعلية يتوقف عند المعاينة ما لم تمرّر --yes.
      • دمج، لا استبدال. تُنقَّى مدخلات الذاكرة من التكرار مقارنة بملف MEMORY.md الحالي لديك؛ وتُدمَج أنماط قائمتَي السماح والمنع مع ما هو موجود بالفعل في config.yaml.
      • تُتجاوَز التعارضات افتراضيًا. يُبلَّغ عن خادم MCP أو مهارة موجودة مسبقًا في Hermes كتعارض؛ مرِّر --overwrite لاستبدالها.
      • الملفات المُشوَّهة لا توقف التشغيل. يتحوّل ملف settings.json أو config.toml التالف إلى خطأ خاص بذلك العنصر في التقرير بينما يستمر استيراد كل شيء آخر.
      • قادم من OpenClaw بدلًا من ذلك؟ استخدم hermes claw migrate.
