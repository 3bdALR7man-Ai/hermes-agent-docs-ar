      BlueBubbles (iMessage)

      اربط Hermes بخدمة Apple iMessage عبر BlueBubbles — وهو خادم مجاني ومفتوح المصدر يعمل على macOS ويصل iMessage بأي جهاز.

      المتطلبات المسبقة​

      • جهاز Mac (يعمل باستمرار) يشغّل BlueBubbles Server
      • حساب Apple ID مسجَّل الدخول في Messages.app على ذلك الـ Mac
      • BlueBubbles Server بالإصدار v1.0.0 أو أحدث (تتطلب الـ webhooks هذا الإصدار)
      • اتصال شبكي بين Hermes وخادم BlueBubbles

      الإعداد​

      1. تثبيت BlueBubbles Server​

      نزّله وثبّته من bluebubbles.app. أكمل معالج الإعداد — سجّل الدخول بحساب Apple ID الخاص بك واضبط طريقة الاتصال (الشبكة المحلية، أو Ngrok، أو Cloudflare، أو Dynamic DNS).

      2. الحصول على عنوان URL للخادم وكلمة المرور​

      في BlueBubbles Server → Settings → API، دوّن ما يلي:

      • Server URL (مثلًا http://192.168.1.10:1234)
      • Server Password

      3. ضبط إعدادات Hermes​

      شغّل معالج الإعداد:

      hermes gateway setup

      اختر BlueBubbles (iMessage) وأدخل عنوان URL للخادم وكلمة المرور.

      أو اضبط متغيرات البيئة (environment variables) مباشرةً في ~/.hermes/.env:

      BLUEBUBBLES_SERVER_URL=http://192.168.1.10:1234
      BLUEBUBBLES_PASSWORD=your-server-password

      اختياري: اشتراط الإشارة في المحادثات الجماعية​

      افتراضيًا، يردّ Hermes على كل رسالة مباشرة أو جماعية مصرّح بها في BlueBubbles/iMessage. ولجعل المحادثات الجماعية تعمل بالاشتراك الاختياري (opt-in)، فعّل اشتراط الإشارة (mention gating):

      platforms:
        bluebubbles:
          enabled: true
          extra:
            require_mention: true

      مع require_mention: true، تظل الرسائل المباشرة تعمل بشكل طبيعي، لكن رسائل المحادثات الجماعية تُتجاهل ما لم تطابق نمط إشارة. وإذا لم تضبط أنماطًا مخصصة، يستخدم Hermes قيمًا افتراضية متحفظة تغطي صيغ Hermes و @Hermes agent.

      إذا كان للوكيل اسم مخصص، فاضبط أنماط regex:

      platforms:
        bluebubbles:
          extra:
            require_mention: true
            mention_patterns:
              - '(?<![\w@])@?amos\b[,:\-]?'

      4. تفويض المستخدمين​

      اختر إحدى الطرق التالية:

      الاقتران عبر الرسائل المباشرة (DM Pairing) (موصى به): عندما يراسل شخص ما حساب iMessage الخاص بك، يرسل إليه Hermes تلقائيًا رمز اقتران (pairing). وافق عليه باستخدام:

      hermes pairing approve bluebubbles <CODE>

      استخدم hermes pairing list لعرض الرموز المعلّقة والمستخدمين الذين تمت الموافقة عليهم.

      تفويض مستخدمين محددين مسبقًا (في ~/.hermes/.env):

      BLUEBUBBLES_ALLOWED_USERS=user@icloud.com,+15551234567

      وصول مفتوح (في ~/.hermes/.env):

      BLUEBUBBLES_ALLOW_ALL_USERS=true

      5. تشغيل الـ Gateway​

      hermes gateway run

      سيتصل Hermes بخادم BlueBubbles الخاص بك، ويسجّل webhook، ثم يبدأ بالاستماع لرسائل iMessage.

      آلية العمل​

      iMessage → Messages.app → BlueBubbles Server → Webhook → Hermes
      Hermes → BlueBubbles REST API → Messages.app → iMessage
      • الوارد: يرسل BlueBubbles أحداث webhook إلى مستمع محلي عند وصول رسائل جديدة. لا يوجد استطلاع دوري (polling) — فالتسليم فوري.
      • الصادر: يرسل Hermes الرسائل عبر BlueBubbles REST API.
      • الوسائط: الصور والرسائل الصوتية ومقاطع الفيديو والمستندات مدعومة في الاتجاهين. وتُنزَّل المرفقات الواردة وتُخزَّن مؤقتًا محليًا كي يعالجها الوكيل.

      متغيرات البيئة (Environment Variables)​

      المتغيرمطلوبالقيمة الافتراضيةالوصف
      BLUEBUBBLES_SERVER_URLنعم—عنوان URL لخادم BlueBubbles
      BLUEBUBBLES_PASSWORDنعم—كلمة مرور الخادم
      BLUEBUBBLES_WEBHOOK_HOSTلا127.0.0.1العنوان الذي يرتبط به مستمع الـ webhook
      BLUEBUBBLES_WEBHOOK_PORTلا8645منفذ مستمع الـ webhook
      BLUEBUBBLES_WEBHOOK_PATHلا/bluebubbles-webhookمسار عنوان URL للـ webhook
      BLUEBUBBLES_HOME_CHANNELلا—رقم الهاتف/البريد الإلكتروني لتسليم مخرجات cron
      BLUEBUBBLES_ALLOWED_USERSلا—المستخدمون المصرّح لهم، مفصولين بفواصل
      BLUEBUBBLES_ALLOW_ALL_USERSلاfalseالسماح لجميع المستخدمين
      BLUEBUBBLES_REQUIRE_MENTIONلاfalseاشتراط نمط إشارة قبل الرد في المحادثات الجماعية
      BLUEBUBBLES_MENTION_PATTERNSلاكلمات التنبيه الخاصة بـ Hermesأنماط regex لمطابقة الإشارات في المحادثات الجماعية، على شكل مصفوفة JSON أو مفصولة بأسطر جديدة أو بفواصل

      يُتحكَّم في وضع علامة "مقروءة" على الرسائل تلقائيًا عبر المفتاح send_read_receipts ضمن platforms.bluebubbles.extra في ~/.hermes/config.yaml (الافتراضي: true). ولا يوجد متغير بيئة مقابل له.

      الميزات​

      المراسلة النصية​

      أرسل رسائل iMessage واستقبلها. ويُزال تنسيق Markdown تلقائيًا لتسليم نص عادي نظيف.

      الوسائط الغنية​

      • الصور: تظهر الصور بشكل أصلي في محادثة iMessage
      • الرسائل الصوتية: تُرسَل الملفات الصوتية كرسائل iMessage صوتية
      • مقاطع الفيديو: مرفقات فيديو
      • المستندات: تُرسَل الملفات كمرفقات iMessage

      تفاعلات Tapback​

      تفاعلات الحب والإعجاب وعدم الإعجاب والضحك والتأكيد والاستفهام. تتطلب Private API helper الخاص بـ BlueBubbles.

      مؤشرات الكتابة​

      يعرض "typing..." في محادثة iMessage أثناء معالجة الوكيل للرسالة. يتطلب Private API.

      إشعارات القراءة​

      يضع علامة "مقروءة" على الرسائل تلقائيًا بعد معالجتها. يتطلب Private API.

      تحديد المحادثات​

      يمكنك تحديد المحادثات بالبريد الإلكتروني أو رقم الهاتف — إذ يحوّلها Hermes تلقائيًا إلى معرّفات GUID للمحادثات في BlueBubbles، فلا حاجة إلى استخدام صيغة GUID الخام.

      Private API​

      تتطلب بعض الميزات Private API helper الخاص بـ BlueBubbles:

      • تفاعلات Tapback
      • مؤشرات الكتابة
      • إشعارات القراءة
      • إنشاء محادثات جديدة عبر العنوان

      ومن دون Private API، تظل المراسلة النصية الأساسية والوسائط تعمل.

      استكشاف الأخطاء وإصلاحها​

      ظهور "Cannot reach server"​

      • تحقق من صحة عنوان URL للخادم ومن أن الـ Mac قيد التشغيل
      • تحقق من أن BlueBubbles Server يعمل
      • تأكد من الاتصال الشبكي (جدار الحماية، وإعادة توجيه المنافذ)

      الرسائل لا تصل​

      • تحقق من تسجيل الـ webhook في BlueBubbles Server → Settings → API → Webhooks
      • تحقق من إمكانية الوصول إلى عنوان URL للـ webhook من الـ Mac
      • راجع hermes logs gateway بحثًا عن أخطاء الـ webhook (أو استخدم hermes logs -f لمتابعة السجلات لحظيًا)

      ظهور "Private API helper not connected"​

      • ثبّت Private API helper: docs.bluebubbles.app
      • تعمل المراسلة الأساسية من دونه — ولا تتطلبه إلا التفاعلات ومؤشرات الكتابة وإشعارات القراءة
