      Yuanbao

      اربط Hermes بمنصة Yuanbao، منصة المراسلة المؤسسية من Tencent. يستخدم المحوّل (adapter) بوابة WebSocket لتسليم الرسائل في الوقت الفعلي، ويدعم المحادثات المباشرة (C2C) والمحادثات الجماعية على حد سواء.

      معلومة

      Yuanbao منصة مراسلة مؤسسية تُستخدم أساسًا داخل Tencent وفي بيئات المؤسسات. تستخدم WebSocket للتواصل في الوقت الفعلي، ومصادقة قائمة على HMAC، وتدعم الوسائط الغنية بما فيها الصور والملفات والرسائل الصوتية.

      المتطلبات المسبقة​

      • حساب Yuanbao يملك صلاحية إنشاء البوتات
      • قيمتا APP_ID و APP_SECRET الخاصتان بـ Yuanbao (من مسؤول المنصة)
      • حزم Python: websockets و httpx
      • لدعم الوسائط: aiofiles

      ثبّت الاعتماديات المطلوبة:

      pip install websockets httpx aiofiles

      الإعداد​

      1. إنشاء بوت في Yuanbao​

      1. نزّل تطبيق Yuanbao من https://yuanbao.tencent.com/
      2. في التطبيق، انتقل إلى PAI → My Bot وأنشئ بوتًا جديدًا
      3. بعد إنشاء البوت، انسخ APP_ID و APP_SECRET

      2. تشغيل معالج الإعداد​

      أسهل طريقة لإعداد Yuanbao هي عبر الإعداد التفاعلي:

      hermes gateway setup

      اختر Yuanbao عند المطالبة. سيقوم المعالج بما يلي:

      1. طلب قيمة APP_ID
      2. طلب قيمة APP_SECRET
      3. حفظ الإعدادات تلقائيًا
      نصيحة

      يتضمن WebSocket URL و API Domain قيمًا افتراضية مناسبة مدمجة. لا تحتاج إلا إلى توفير APP_ID و APP_SECRET للبدء.

      3. ضبط متغيرات البيئة​

      بعد الإعداد الأولي، تحقق من هذه المتغيرات في ~/.hermes/.env:

      # Required
      YUANBAO_APP_ID=your-app-id
      YUANBAO_APP_SECRET=your-app-secret
      YUANBAO_WS_URL=wss://api.yuanbao.example.com/ws
      YUANBAO_API_DOMAIN=https://api.yuanbao.example.com

      # Optional: bot account ID (normally obtained automatically from sign-token)
      # YUANBAO_BOT_ID=your-bot-id

      # Optional: internal routing environment (e.g. test/staging/production)
      # YUANBAO_ROUTE_ENV=production

      # Optional: home channel for cron/notifications (format: direct:<account> or group:<group_code>)
      YUANBAO_HOME_CHANNEL=direct:bot_account_id
      YUANBAO_HOME_CHANNEL_NAME="Bot Notifications"

      # Optional: restrict access (legacy, see Access Control below for fine-grained policies)
      YUANBAO_ALLOWED_USERS=user_account_1,user_account_2

      4. تشغيل الـ Gateway​

      hermes gateway

      سيتصل المحوّل ببوابة WebSocket الخاصة بـ Yuanbao، ويُجري المصادقة باستخدام توقيعات HMAC، ثم يبدأ بمعالجة الرسائل.

      الميزات​

      • بوابة WebSocket — تواصل ثنائي الاتجاه في الوقت الفعلي
      • مصادقة HMAC — توقيع آمن للطلبات باستخدام APP_ID/APP_SECRET
      • رسائل C2C — محادثات مباشرة بين المستخدم والبوت
      • الرسائل الجماعية — محادثات داخل المجموعات
      • دعم الوسائط — الصور والملفات والرسائل الصوتية عبر COS (Cloud Object Storage)
      • تنسيق Markdown — تُجزَّأ الرسائل تلقائيًا لتلائم حدود الحجم في Yuanbao
      • إزالة تكرار الرسائل — تمنع معالجة الرسالة نفسها أكثر من مرة
      • نبضات القلب/keep-alive — تحافظ على استقرار اتصال WebSocket
      • مؤشرات الكتابة — تعرض حالة "typing…" أثناء معالجة الوكيل
      • إعادة الاتصال التلقائية — تتعامل مع انقطاعات WebSocket بتأخير متزايد أُسيًّا (exponential backoff)
      • الاستعلام عن معلومات المجموعات — جلب تفاصيل المجموعات وقوائم أعضائها
      • دعم الملصقات/الرموز التعبيرية — إرسال ملصقات TIMFaceElem والرموز التعبيرية في المحادثات
      • دعم سجلات محادثات WeChat المُعاد توجيهها — عندما يعيد مستخدم توجيه حزمة سجل محادثة من WeChat إلى Yuanbao، يفك المحوّل ترميز السجلات المُعاد توجيهها (أسماء المرسلين المستعارة، والنصوص، وإدخالات الوسائط المتعددة، بما في ذلك عمليات إعادة التوجيه المتداخلة) ويُدرجها في المحادثة ليتمكن الوكيل من قراءة السلسلة المُعاد توجيهها كاملة
      • Auto-sethome — يُعيَّن أول مستخدم يراسل البوت تلقائيًا مالكًا للقناة الرئيسية (home channel)
      • إشعار بطء الاستجابة — يرسل رسالة انتظار عندما يستغرق الوكيل وقتًا أطول من المتوقع

      خيارات الإعداد​

      صيغ معرّفات المحادثات​

      يستخدم Yuanbao معرّفات ذات بادئات بحسب نوع المحادثة:

      نوع المحادثةالصيغةمثال
      رسالة مباشرة (C2C)direct:<account>direct:user123
      رسالة جماعيةgroup:<group_code>group:grp456

      رفع الوسائط​

      يتولى محوّل Yuanbao تلقائيًا رفع الوسائط عبر COS (Tencent Cloud Object Storage):

      • الصور: يدعم JPEG و PNG و GIF و WebP
      • الملفات: يدعم جميع أنواع المستندات الشائعة
      • الرسائل الصوتية: يدعم WAV و MP3 و OGG

      يُتحقق من عناوين URL للوسائط وتُنزَّل تلقائيًا قبل الرفع لمنع هجمات SSRF.

      القناة الرئيسية (Home Channel)​

      استخدم الأمر /sethome في أي محادثة على Yuanbao (رسالة مباشرة أو مجموعة) لتعيينها قناةً رئيسية. تُسلِّم المهام المجدولة (مهام cron) نتائجها إلى هذه القناة.

      Auto-sethome

      إذا لم تُضبط قناة رئيسية، فسيُعيَّن أول مستخدم يراسل البوت تلقائيًا مالكًا للقناة الرئيسية. وإذا كانت القناة الرئيسية الحالية محادثة جماعية، فستُرقّيها أول رسالة مباشرة إلى قناة مباشرة.

      يمكنك أيضًا ضبطها يدويًا في ~/.hermes/.env:

      YUANBAO_HOME_CHANNEL=direct:user_account_id
      # or for a group:
      # YUANBAO_HOME_CHANNEL=group:group_code
      YUANBAO_HOME_CHANNEL_NAME="My Bot Updates"

      مثال: تعيين القناة الرئيسية​

      1. ابدأ محادثة مع البوت في Yuanbao
      2. أرسل الأمر: /sethome
      3. يرد البوت: "Home channel set to [chat_name] with ID [chat_id]. Cron jobs will deliver to this location."
      4. ستُرسل مهام cron والإشعارات المستقبلية إلى هذه القناة

      مثال: تسليم مهمة Cron​

      أنشئ مهمة cron:

      /cron "0 9 * * *" Check server status

      ستُسلَّم المخرجات المجدولة إلى قناتك الرئيسية في Yuanbao كل يوم في الساعة 9 صباحًا.

      نصائح الاستخدام​

      بدء محادثة​

      أرسل أي رسالة إلى البوت في Yuanbao:

      hello

      يرد البوت في سلسلة المحادثة نفسها.

      الأوامر المتاحة​

      تعمل جميع أوامر Hermes القياسية على Yuanbao:

      الأمرالوصف
      /newبدء محادثة جديدة
      /model [provider:model]عرض النموذج أو تغييره
      /sethomeتعيين هذه المحادثة قناةً رئيسية
      /statusعرض معلومات الجلسة
      /helpعرض الأوامر المتاحة

      إرسال الملفات​

      لإرسال ملف إلى البوت، أرفقه ببساطة مباشرةً في محادثة Yuanbao. سينزّل البوت مرفق الملف ويعالجه تلقائيًا.

      يمكنك أيضًا تضمين رسالة مع المرفق:

      Please analyze this document

      استقبال الملفات​

      عندما تطلب من البوت إنشاء ملف أو تصديره، يرسل الملف مباشرةً إلى محادثتك في Yuanbao.

      استكشاف الأخطاء وإصلاحها​

      البوت متصل لكنه لا يرد على الرسائل​

      السبب: فشلت المصادقة أثناء مصافحة WebSocket.

      الحل:

      1. تحقق من صحة APP_ID و APP_SECRET
      2. تحقق من إمكانية الوصول إلى WebSocket URL
      3. تأكد من أن حساب البوت يملك الصلاحيات المناسبة
      4. راجع سجلات الـ gateway: tail -f ~/.hermes/logs/gateway.log

      خطأ "Connection refused"​

      السبب: تعذّر الوصول إلى WebSocket URL أو أنه غير صحيح.

      الحل:

      1. تحقق من صيغة WebSocket URL (يجب أن يبدأ بـ wss://)
      2. تحقق من الاتصال الشبكي بنطاق Yuanbao API
      3. تأكد من أن جدار الحماية يسمح باتصالات WebSocket
      4. اختبر الـ URL باستخدام: curl -I https://[YUANBAO_API_DOMAIN]

      فشل رفع الوسائط​

      السبب: بيانات اعتماد COS غير صالحة أو تعذّر الوصول إلى خادم الوسائط.

      الحل:

      1. تحقق من صحة API_DOMAIN
      2. تحقق من تفعيل صلاحيات رفع الوسائط للبوت الخاص بك
      3. تأكد من إمكانية الوصول إلى ملف الوسائط وأنه غير تالف
      4. راجع إعدادات COS bucket مع مسؤول المنصة

      الرسائل لا تُسلَّم إلى القناة الرئيسية​

      السبب: صيغة معرّف القناة الرئيسية غير صحيحة أو لم تُطلَق مهمة cron.

      الحل:

      1. تحقق من أن YUANBAO_HOME_CHANNEL بالصيغة الصحيحة
      2. اختبر باستخدام الأمر /sethome لاكتشاف الصيغة الصحيحة تلقائيًا
      3. تحقق من جدول مهمة cron باستخدام /status
      4. تحقق من أن البوت يملك صلاحيات الإرسال في المحادثة المستهدفة

      انقطاعات متكررة​

      السبب: اتصال WebSocket غير مستقر أو الشبكة غير موثوقة.

      الحل:

      1. راجع سجلات الـ gateway بحثًا عن أنماط الأخطاء
      2. زِد مهلة نبضات القلب في إعدادات الاتصال
      3. تأكد من استقرار الاتصال الشبكي بـ Yuanbao API
      4. فكّر في تفعيل السجلات المفصّلة: hermes gateway run -vv

      التحكم في الوصول​

      يدعم Yuanbao تحكمًا دقيقًا في الوصول لكل من الرسائل المباشرة والمحادثات الجماعية:

      # DM policy: open (default) | allowlist | disabled
      YUANBAO_DM_POLICY=open
      # Comma-separated user IDs allowed to DM the bot (only used when DM_POLICY=allowlist)
      YUANBAO_DM_ALLOW_FROM=user_id_1,user_id_2

      # Group policy: open (default) | allowlist | disabled
      YUANBAO_GROUP_POLICY=open
      # Comma-separated group codes allowed (only used when GROUP_POLICY=allowlist)
      YUANBAO_GROUP_ALLOW_FROM=group_code_1,group_code_2

      يمكن أيضًا ضبط هذه القيم في config.yaml:

      platforms:
        yuanbao:
          extra:
            dm_policy: allowlist
            dm_allow_from: "user1,user2"
            group_policy: open
            group_allow_from: ""

      الإعدادات المتقدمة​

      تجزئة الرسائل​

      لدى Yuanbao حد أقصى لحجم الرسالة. يجزّئ Hermes الردود الكبيرة تلقائيًا بتقسيم يراعي Markdown (يحترم كتل الشيفرة المسوّرة والجداول وحدود الفقرات).

      معاملات الاتصال​

      معاملات الاتصال التالية مدمجة في المحوّل بقيم افتراضية مناسبة:

      المعاملالقيمة الافتراضيةالوصف
      مهلة اتصال WebSocket15 ثانيةمدة انتظار مصافحة WS
      الفاصل الزمني لنبضات القلب30 ثانيةمعدل إرسال ping للحفاظ على الاتصال
      الحد الأقصى لمحاولات إعادة الاتصال100أقصى عدد لمحاولات إعادة الاتصال
      تأخير إعادة الاتصال (backoff)1s → 60s (أُسّي)مدة الانتظار بين محاولات إعادة الاتصال
      الفاصل الزمني لنبضات الرد2 ثانيةمعدل إرسال حالة RUNNING
      مهلة الإرسال30 ثانيةمهلة رسائل WS الصادرة
      ملاحظة

      لا يمكن حاليًا ضبط هذه القيم عبر متغيرات البيئة، وهي مُحسَّنة لعمليات نشر Yuanbao المعتادة.

      السجلات المفصّلة​

      فعّل سجلات التصحيح (debug) لاستكشاف مشكلات الاتصال وإصلاحها:

      hermes gateway run -vv

      التكامل مع الميزات الأخرى​

      مهام Cron​

      جدوِل مهامًا تعمل على Yuanbao:

      /cron "0 */4 * * *" Report system health

      تُسلَّم النتائج إلى قناتك الرئيسية.

      المهام في الخلفية​

      شغّل العمليات الطويلة دون تعطيل المحادثة:

      /bg Analyze all files in the archive

      الرسائل عبر المنصات​

      أرسل رسالة من CLI إلى Yuanbao:

      hermes chat -q "Send 'Hello from CLI' to yuanbao:group:group_code"
