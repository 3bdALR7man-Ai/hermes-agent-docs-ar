      إعداد SMS (Twilio)

      يتصل Hermes بخدمة SMS عبر API Twilio. يرسل المستخدمون رسائل نصية إلى رقم هاتف Twilio الخاص بك ويتلقّون ردود الذكاء الاصطناعي — بتجربة المحادثة نفسها التي يوفّرها Telegram أو Discord، ولكن عبر الرسائل النصية القياسية.

      بيانات اعتماد مشتركة

      يتشارك gateway الخاص بـ SMS بيانات الاعتماد مع مهارة الاتصالات الهاتفية (telephony) الاختيارية. إذا كنت قد أعددت Twilio مسبقًا للمكالمات الصوتية أو لرسائل SMS الفردية، فسيعمل gateway بالقيم نفسها: TWILIO_ACCOUNT_SID و TWILIO_AUTH_TOKEN و TWILIO_PHONE_NUMBER.

      المتطلبات المسبقة​

      • حساب Twilio — سجّل في twilio.com (تتوفر نسخة تجريبية مجانية)
      • رقم هاتف Twilio يدعم خدمة SMS
      • خادم يمكن الوصول إليه علنًا — إذ يرسل Twilio طلبات webhook إلى خادمك عند وصول رسالة SMS
      • aiohttp — cd ~/.hermes/hermes-agent && uv pip install -e ".[sms]"

      الخطوة 1: احصل على بيانات اعتماد Twilio​

      1. انتقل إلى Twilio Console
      2. انسخ Account SID و Auth Token من لوحة التحكم
      3. انتقل إلى Phone Numbers → Manage → Active Numbers — ودوّن رقم هاتفك بصيغة E.164 (مثل +15551234567)

      الخطوة 2: اضبط Hermes​

      الإعداد التفاعلي (موصى به)​

      hermes gateway setup

      اختر SMS (Twilio) من قائمة المنصات، وسيطلب منك المعالج بيانات الاعتماد.

      الإعداد اليدوي​

      أضف ما يلي إلى ~/.hermes/.env:

      TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
      TWILIO_AUTH_TOKEN=your_auth_token_here
      TWILIO_PHONE_NUMBER=+15551234567

      # Security: restrict to specific phone numbers (recommended)
      SMS_ALLOWED_USERS=+15559876543,+15551112222

      # Optional: set a home channel for cron job delivery
      SMS_HOME_CHANNEL=+15559876543

      الخطوة 3: اضبط Webhook في Twilio​

      يحتاج Twilio إلى معرفة الوجهة التي يرسل إليها الرسائل الواردة. في Twilio Console:

      1. انتقل إلى Phone Numbers → Manage → Active Numbers
      2. انقر على رقم هاتفك
      3. ضمن Messaging → A MESSAGE COMES IN، اضبط ما يلي:
        • Webhook: https://your-server:8080/webhooks/twilio
        • HTTP Method: POST
      إتاحة Webhook للوصول الخارجي

      إذا كنت تشغّل Hermes محليًا، فاستخدم نفقًا (tunnel) لإتاحة webhook:

      # Using cloudflared
      cloudflared tunnel --url http://localhost:8080

      # Using ngrok
      ngrok http 8080

      اضبط عنوان URL العام الناتج كـ webhook في Twilio.

      اضبط SMS_WEBHOOK_URL على عنوان URL نفسه الذي ضبطته في Twilio. هذا مطلوب للتحقق من توقيع Twilio — وسيرفض المحوّل (adapter) بدء التشغيل بدونه:

      # Must match the webhook URL in your Twilio Console
      SMS_WEBHOOK_URL=https://your-server:8080/webhooks/twilio

      منفذ webhook الافتراضي هو 8080. يمكنك تغييره باستخدام:

      SMS_WEBHOOK_PORT=3000

      الخطوة 4: شغّل Gateway​

      hermes gateway

      من المفترض أن ترى:

      [sms] Twilio webhook server listening on 127.0.0.1:8080, from: +1555***4567

      إذا ظهرت لك الرسالة Refusing to start: SMS_WEBHOOK_URL is required، فاضبط SMS_WEBHOOK_URL على عنوان URL العام المضبوط في Twilio Console (راجع الخطوة 3).

      أرسل رسالة نصية إلى رقم Twilio الخاص بك — وسيردّ Hermes عبر SMS.

      متغيرات البيئة​

      المتغيرمطلوبالوصف
      TWILIO_ACCOUNT_SIDنعمAccount SID الخاص بـ Twilio (يبدأ بـ AC)
      TWILIO_AUTH_TOKENنعمAuth Token الخاص بـ Twilio (يُستخدم أيضًا للتحقق من توقيع webhook)
      TWILIO_PHONE_NUMBERنعمرقم هاتف Twilio الخاص بك (بصيغة E.164)
      SMS_WEBHOOK_URLنعمعنوان URL العام للتحقق من توقيع Twilio — يجب أن يطابق عنوان webhook في Twilio Console
      SMS_WEBHOOK_PORTلامنفذ الاستماع لـ webhook (الافتراضي: 8080)
      SMS_WEBHOOK_HOSTلاعنوان الربط (bind address) لـ webhook (الافتراضي: 127.0.0.1)
      SMS_INSECURE_NO_SIGNATUREلااضبطه على true لتعطيل التحقق من التوقيع (للتطوير المحلي فقط — لا يُستخدم في بيئة الإنتاج)
      SMS_ALLOWED_USERSلاأرقام الهواتف المسموح لها بالمحادثة بصيغة E.164، مفصولة بفواصل
      SMS_ALLOW_ALL_USERSلااضبطه على true للسماح لأي شخص (غير مستحسن)
      SMS_HOME_CHANNELلارقم الهاتف الذي تُسلَّم إليه مخرجات مهام cron والإشعارات
      SMS_HOME_CHANNEL_NAMEلاالاسم المعروض للقناة الرئيسية (home channel) (الافتراضي: Home)

      سلوك خاص بـ SMS​

      • نص عادي فقط — تُزال صيغة Markdown تلقائيًا لأن SMS تعرضها كأحرف حرفية
      • حدّ 1600 حرف — تُقسَّم الردود الأطول على عدة رسائل عند حدود طبيعية (أسطر جديدة، ثم مسافات)
      • منع الصدى — تُتجاهَل الرسائل الواردة من رقم Twilio الخاص بك لمنع الحلقات المتكررة
      • إخفاء أرقام الهواتف — تُخفى أرقام الهواتف في السجلات حفاظًا على الخصوصية

      الأمان​

      التحقق من توقيع Webhook​

      يتحقق Hermes من أن طلبات webhook الواردة صادرة فعلًا من Twilio عبر التحقق من الترويسة X-Twilio-Signature (HMAC-SHA1). يمنع ذلك المهاجمين من حقن رسائل مزوّرة.

      SMS_WEBHOOK_URL مطلوب. اضبطه على عنوان URL العام المضبوط في Twilio Console. سيرفض المحوّل بدء التشغيل بدونه.

      للتطوير المحلي دون عنوان URL عام، يمكنك تعطيل التحقق:

      # Local dev only — NOT for production
      SMS_INSECURE_NO_SIGNATURE=true

      قوائم السماح للمستخدمين​

      يرفض gateway جميع المستخدمين افتراضيًا. اضبط قائمة سماح (allowlist):

      # Recommended: restrict to specific phone numbers
      SMS_ALLOWED_USERS=+15559876543,+15551112222

      # Or allow all (NOT recommended for bots with terminal access)
      SMS_ALLOW_ALL_USERS=true
      تحذير

      لا توفّر SMS تشفيرًا مدمجًا. لا تستخدم SMS للعمليات الحساسة ما لم تكن تدرك تبعاتها الأمنية. في حالات الاستخدام الحساسة، فضّل Signal أو Telegram.

      استكشاف الأخطاء وإصلاحها​

      الرسائل لا تصل​

      1. تحقّق من أن عنوان webhook في Twilio صحيح ويمكن الوصول إليه علنًا
      2. تحقّق من صحة TWILIO_ACCOUNT_SID و TWILIO_AUTH_TOKEN
      3. راجع Twilio Console → Monitor → Logs → Messaging بحثًا عن أخطاء التسليم
      4. تأكد من أن رقم هاتفك مُدرَج في SMS_ALLOWED_USERS (أو أن SMS_ALLOW_ALL_USERS=true)

      الردود لا تُرسَل​

      1. تحقّق من ضبط TWILIO_PHONE_NUMBER بشكل صحيح (بصيغة E.164 مع +)
      2. تحقّق من أن حساب Twilio يملك أرقامًا تدعم SMS
      3. راجع سجلات gateway في Hermes بحثًا عن أخطاء Twilio API

      تعارض منفذ Webhook​

      إذا كان المنفذ 8080 مستخدمًا بالفعل، فغيّره:

      SMS_WEBHOOK_PORT=3001

      ثم حدّث عنوان webhook في Twilio Console ليطابقه.
