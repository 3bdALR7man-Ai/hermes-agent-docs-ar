      Nous Tool Gateway

      اشتراك واحد. وكل الأدوات مدمجة.

      يأتي Tool Gateway مضمّنًا مع كل اشتراك مدفوع في Nous Portal. فهو يوجّه استدعاءات الأدوات في Hermes — البحث في الويب، وتوليد الصور، وتحويل النص إلى كلام، وأتمتة المتصفح السحابي — عبر بنية تحتية تشغّلها Nous بالفعل، فلا تحتاج إلى التسجيل لدى Firecrawl أو FAL أو OpenAI أو Browser Use أو غيرها لمجرد أن يصبح وكيلك مفيدًا.

      ابدأ اشتراكك أو أدِره →

      ما الذي يتضمنه​

      الأداةما تحصل عليه
      🔍البحث في الويب والاستخراجبحث في الويب واستخراج للصفحات كاملة بمستوى يلائم الوكلاء عبر Firecrawl. لا داعي للقلق بشأن حدود المعدل — فالـ gateway يتولى التوسع.
      🎨توليد الصورتسعة نماذج تحت endpoint واحد: FLUX 2 Klein 9B، و FLUX 2 Pro، و Z-Image Turbo، و Nano Banana Pro (Gemini 3 Pro Image)، و GPT Image 1.5، و GPT Image 2، و Ideogram V3، و Recraft V4 Pro، و Qwen Image. اختر النموذج لكل عملية توليد عبر خيار (flag)، أو دع Hermes يعتمد FLUX 2 Klein افتراضيًا.
      🔊تحويل النص إلى كلامأصوات OpenAI TTS موصولة بالأداة text_to_speech. أرسل ملاحظات صوتية إلى Telegram، وولّد الصوت لـ pipelines، وحوّل أي نص إلى سرد مسموع.
      🌐أتمتة المتصفح السحابيجلسات Chromium دون واجهة (headless) عبر Browser Use. browser_navigate و browser_click و browser_type و browser_vision — جميع العمليات الأساسية التي يقود بها الوكيل المتصفح، دون الحاجة إلى حساب Browserbase.

      تُحتسب الأدوات الأربع جميعها بنظام الدفع حسب الاستخدام على اشتراكك في Nous. استخدم أي تركيبة تريدها — شغّل الـ gateway للويب والصور مع الاحتفاظ بمفتاح ElevenLabs الخاص بك لـ TTS، أو وجّه كل شيء عبر Nous.

      لماذا يوجد​

      إن بناء وكيل قادر فعلًا على إنجاز الأشياء يعني الجمع بين أكثر من 5 اشتراكات API — لكلٍّ منها تسجيله وحدود معدله وفوترته وخصوصياته. ويختزل الـ gateway كل ذلك في حساب واحد:

      • فاتورة واحدة. ادفع لـ Nous؛ ونحن نتولى الباقي.
      • تسجيل واحد. لا حسابات Firecrawl أو FAL أو Browser Use أو OpenAI audio تحتاج إلى إدارتها.
      • مفتاح واحد. تغطي مصادقة OAuth الخاصة بـ Nous Portal جميع الأدوات.
      • الجودة نفسها. الـ backends نفسها التي يستخدمها مسار المفاتيح المباشرة — لكن عبر واجهتنا.

      استخدم مفاتيحك الخاصة في أي وقت — لكل أداة على حدة، متى شئت. فالـ gateway ليس قيدًا يحبسك، بل اختصار.

      ابدأ الآن​

      هناك ثلاث طرق للبدء — اختر ما يناسب وضعك:

      hermes setup --portal     # Fresh install: Nous OAuth + set Nous as provider + turn on the Tool Gateway in one go
      hermes model              # Switch your inference provider to Nous Portal — Hermes then offers to turn on the gateway for all tools
      hermes tools              # Enable the gateway per-tool — pick "Nous Subscription" for any tool you want

      يمثّل hermes setup --portal و hermes model المسارين الشاملين: سجّل الدخول مرة واحدة، ويمكنك اختياريًا تحويل جميع الأدوات إلى الـ gateway. أما hermes tools فهو مسار الاختيار حسب الطلب — فعّل الأدوات التي تريدها فقط، واحدة تلو الأخرى.

      لست مضطرًا إلى تسجيل الدخول أولًا. مع hermes tools، تُعرض الـ backends التي تديرها Nous (Web search و Image و Video و TTS و Browser) دائمًا، حتى لو لم تسجّل الدخول إلى Nous Portal من قبل. اختر أحدها وسيُجري Hermes تسجيل الدخول إلى Portal في المكان نفسه إذا لم تكن مصادَقًا بالفعل — دون الحاجة إلى تنفيذ hermes model مسبقًا. وإذا كانت مصادقة OAuth الخاصة بـ Nous نشطة بالفعل، فإن اختيار الـ backend يفعّله فورًا دون أي طلب إضافي. هذا المسار يسجّل دخولك ويفعّل الأداة الواحدة التي اخترتها فقط — فهو لا يغيّر مزوّد الـ inference لديك، كما أنه لا يطلب منك تفعيل الـ gateway لبقية الأدوات.

      تحقق مما هو نشط في أي وقت:

      hermes portal info        # Portal auth + Tool Gateway routing summary
      hermes portal tools       # Gateway catalog with current routing per tool
      hermes status             # Full system status (Tool Gateway is one section)

      يعرض hermes portal info قسمًا مثل:

      ◆ Nous Tool Gateway
        Nous Portal     ✓ managed tools available
        Web tools       ✓ active via Nous subscription
        Image gen       ✓ active via Nous subscription
        TTS             ✓ active via Nous subscription
        Browser         ○ active via Browser Use key

      الأدوات المعلَّمة بـ "active via Nous subscription" تمر عبر الـ gateway. وأي أداة أخرى تستخدم مفاتيحك الخاصة.

      الأهلية​

      إن Tool Gateway ميزة خاصة بالاشتراكات المدفوعة. رقِّ خطتك لفتح الوصول إلى الـ gateway.

      كما يحق لبعض الحسابات الحصول على رصيد أدوات مجاني — وهو حصة صغيرة من الأدوات المُدارة تغطي استدعاءات أدوات الـ gateway دون اشتراك مدفوع. وعندما يتوفر رصيد مجاني، يُظهره الـ gateway ويعرض طلب إعداد عند أول استخدام، لتتمكن من الاشتراك فيه والبدء في استخدام الأدوات المُدارة فورًا.

      قائمة التفعيل​

      عند اختيار نموذج من Nous (hermes model) تُعرض قائمة اختيار لكل أداة من backends الـ gateway. ويحترم سلوك هذه القائمة إعدادك الحالي:

      • الأدوات التي وجّهتها صراحةً إلى backend آخر (مثل web.backend: searxng و browser.cloud_provider: camofox) لا تُعرض أبدًا — فلا يمكن الكتابة فوق اختيارك عن طريق الخطأ.
      • الأدوات المضبوطة عبر متغيرات البيئة وحدها (مثل SEARXNG_URL و CAMOFOX_URL) تُعرض غير محدَّدة، مع تسمية توضح أنها ستُبقي على الـ backend الخاص بك.
      • لا تأتي محدَّدة مسبقًا إلا الأدوات غير المضبوطة فعلًا.
      • الرفض يبقى محفوظًا: إذا أرسلت القائمة مع ترك أداة غير محدَّدة، فلن تُحدَّد مسبقًا عند التبديل إلى نماذج Nous مستقبلًا (يُخزَّن ذلك في tool_gateway_declined_tools ضمن config.yaml؛ وتحديدها لاحقًا يلغي الرفض).

      امزج بين الخيارات​

      يعمل الـ gateway على مستوى كل أداة. فعّله لما تريده فقط:

      • كل الأدوات عبر Nous — الخيار الأسهل؛ اشتراك واحد وانتهى الأمر.
      • الـ gateway للويب + الصور، مع TTS خاص بك — احتفظ بصوت ElevenLabs الخاص بك، ودع Nous تتولى الباقي.
      • الـ gateway فقط لما لا تملك مفاتيح له — فسيناريو "أنا أدفع لـ Browserbase بالفعل، لكنني لا أريد حساب Firecrawl" يعمل دون مشكلات.

      بدّل أي أداة في أي وقت عبر:

      hermes tools          # Interactive picker for each tool category

      اختر الأداة، ثم اختر Nous Subscription مزوّدًا لها (أو أي مزوّد مباشر تفضّله). لا حاجة إلى تعديل الإعدادات. وإذا لم تكن قد سجّلت الدخول إلى Nous Portal بعد، فإن اختيار Nous Subscription يبدأ تسجيل الدخول إلى Portal في المكان نفسه — دون الحاجة إلى المصادقة عبر hermes model أولًا.

      مرجع الإعدادات​

      لا يحتاج معظم المستخدمين إلى هذا القسم أبدًا — إذ يغطي hermes model و hermes tools كل سير عمل بشكل تفاعلي. هذا القسم مخصص لكتابة config.yaml مباشرةً أو لأتمتة الإعداد عبر السكربتات.

      مفتاح اختيار واحد لكل فئة أدوات​

      لكل فئة أدوات مفتاح واحد لاختيار المزوّد، يكتبه منتقي hermes tools (أو واجهة سطح المكتب الرسومية). يؤدي اختيار صف Nous Subscription إلى تخزين القيمة nous، التي توجّه تلك الفئة عبر Tool Gateway المُدار. أما اختيار صف BYOK (استخدام مفتاحك الخاص) فيخزّن اسم المورّد (fal، openai، firecrawl، browser-use، ...)، الذي يتصل مباشرةً باستخدام بيانات الاعتماد الخاصة بك:

      web:
        backend: nous          # web search/extract via the Tool Gateway

      image_gen:
        provider: nous         # image generation via the Tool Gateway

      tts:
        provider: nous         # TTS via the Tool Gateway

      stt:
        provider: nous         # speech-to-text via the Tool Gateway

      browser:
        cloud_provider: nous   # cloud browser via the Tool Gateway

      تستخدم بيئة التشغيل الاختيار المخزَّن دائمًا — فوجود بيانات الاعتماد لا يختار فئة ولا يعيد توجيهها أبدًا. يُتجاهل FAL_KEY الموجود في .env ما دام image_gen.provider: nous مضبوطًا؛ وفي المقابل، يؤدي ضبط image_gen.provider: fal دون ضبط FAL_KEY إلى خطأ واضح بدلًا من الرجوع بصمت إلى الـ gateway:

      image_gen is configured to use fal (set via hermes tools), but FAL_KEY is not set. Run 'hermes tools' to change it.

      أما الفئات التي لم تضبطها قط (لم يُكتب لها مفتاح اختيار أبدًا) فتُكتشف تلقائيًا من بيانات الاعتماد المتاحة، كما كان الحال سابقًا. لكن بمجرد وجود اختيار، فإن إضافة مفتاح إلى .env لا تغيّر المسار — ولا يغيّره إلا hermes tools (أو تعديل مفتاح الاختيار).

      العودة إلى مفاتيحك الخاصة​

      hermes tools    # pick the tool → choose a direct provider (e.g. Firecrawl)

      أو اضبط مفتاح الاختيار مباشرةً:

      web:
        backend: firecrawl   # Hermes now uses FIRECRAWL_API_KEY from .env

      الخيار القديم use_gateway (مهمل)​

      استخدمت إصدارات Hermes الأقدم قيمة منطقية use_gateway: true لكل أداة للتوجيه عبر الـ gateway. هذا الخيار قديم: فلم يعد يُكتب أبدًا، ويزيله منتقي hermes tools من إعدادات الفئة عندما يعيد كتابة الاختيار. أما ملفات الإعدادات القديمة التي لا تزال تحتوي على use_gateway: true فتُفسَّر عند القراءة على أنها الاختيار nous، لذا تستمر الإعدادات الحالية في العمل. لا تضبط use_gateway في ملفات الإعدادات الجديدة — بل اختر المزوّد في hermes tools بدلًا من ذلك.

      Gateway مستضاف ذاتيًا (متقدم)​

      هل تشغّل gateway خاصًا بك متوافقًا مع Nous؟ تجاوز الـ endpoints في ~/.hermes/.env:

      TOOL_GATEWAY_DOMAIN=your-domain.example.com
      TOOL_GATEWAY_SCHEME=https
      TOOL_GATEWAY_USER_TOKEN=your-token        # normally auto-populated from Portal login
      FIRECRAWL_GATEWAY_URL=https://...         # override one endpoint specifically
      TOOL_GATEWAY_URL=http://127.0.0.1:3009    # pin the shared managed origin exactly
      CONNECTOR_GATEWAY_URL=http://127.0.0.1:3009 # pin the connectors origin exactly

      يُسمّى كل مضيف بالصيغة {label}-gateway.<domain>، ويعيد TOOL_GATEWAY_DOMAIN / TOOL_GATEWAY_SCHEME تشكيل أسمائها جميعًا؛ بينما يثبّت {LABEL}_GATEWAY_URL مضيفًا واحدًا بدقة ويتخطى عملية الاشتقاق:

      • {vendor}-gateway.<domain> — نقاط تمرير خاصة بكل مورّد (Firecrawl، و BFL، ...).
      • tool-gateway.<domain> — الأصل (origin) المُدار المشترك: المورّدون المستضافون على الـ gateway نفسه إضافةً إلى رفع الوسائط.
      • connector-gateway.<domain> — واجهة API الخاصة بالموصلات (/v1/connectors/*)، ولها نشر مستقل. راجع البحث عن الأدوات (Tool Search) → Connectors.

      توجد هذه الإعدادات لتهيئات البنية التحتية المخصصة (عمليات النشر في المؤسسات، وبيئات التطوير). ولا يحتاج المشتركون العاديون إلى ضبطها أبدًا.

      الأسئلة الشائعة​

      هل يعمل مع Telegram / Discord / بقية gateways المراسلة؟​

      نعم. يعمل Tool Gateway في طبقة تنفيذ الأدوات، وليس في CLI. لذا تستفيد منه بشكل شفاف كل واجهة يمكنها استدعاء أداة — CLI و Telegram و Discord و Slack و IRC و Teams وخادم API وأي واجهة أخرى.

      ماذا يحدث إذا انتهى اشتراكي؟​

      تتوقف الأدوات الموجَّهة عبر الـ gateway عن العمل حتى تجدد اشتراكك أو تستبدل بها مفاتيح API مباشرة عبر hermes tools. ويعرض Hermes خطأً واضحًا يرشدك إلى Portal.

      هل يمكنني رؤية الاستخدام أو التكاليف لكل أداة؟​

      نعم — تعرض لوحة تحكم Nous Portal الاستخدام مفصّلًا حسب الأداة، لتعرف ما الذي يرفع فاتورتك.

      هل Modal (طرفية serverless) مضمّن؟​

      يتوفر Modal كإضافة اختيارية عبر اشتراك Nous، وليس جزءًا من حزمة Tool Gateway الافتراضية. اضبطه عبر hermes setup terminal أو مباشرةً في config.yaml عندما تريد sandbox بعيدًا لتنفيذ أوامر الـ shell.

      هل عليّ حذف مفاتيح API الحالية عند تفعيل الـ gateway؟​

      لا — أبقِها في .env. فما دام اختيار الأداة هو Nous Subscription، تُتجاهل المفاتيح المباشرة لتلك الأداة ببساطة. اختر المزوّد المباشر مرة أخرى في hermes tools لتعود مفاتيحك هي المصدر. فالـ gateway ليس قيدًا يحبسك.
