      التكاملات

      يتصل Hermes Agent بأنظمة خارجية لأغراض inference بالذكاء الاصطناعي، وخوادم الأدوات، وسير عمل IDE، والوصول البرمجي، وغير ذلك. توسّع هذه التكاملات ما يستطيع Hermes فعله والأماكن التي يمكنه العمل فيها.

      ابدأ من هنا

      إذا لم يكن لديك وقت إلا لإعداد تكامل واحد، فأعِدّ Nous Portal — فتسجيل دخول واحد عبر OAuth يغطي أكثر من 300 نموذج، إضافة إلى أدوات Tool Gateway الأربع (البحث في الويب، وتوليد الصور، و TTS، وأتمتة المتصفح).

      مزوّدو الذكاء الاصطناعي والتوجيه​

      يدعم Hermes عدة مزوّدين لـ inference بالذكاء الاصطناعي مباشرة ودون إعداد إضافي. استخدم hermes model لإعدادهم تفاعليًا، أو اضبطهم في config.yaml.

      • مزوّدو الذكاء الاصطناعي (AI Providers) — OpenRouter و Anthropic و OpenAI و Google، وأي endpoint متوافق مع OpenAI. يكتشف Hermes تلقائيًا القدرات المتاحة لدى كل مزوّد، مثل الرؤية (vision) والبث (streaming) واستخدام الأدوات.
      • توجيه المزوّدين (Provider Routing) — تحكّم دقيق في المزوّدين الفعليين الذين يعالجون طلباتك عبر OpenRouter. حسّن التكلفة أو السرعة أو الجودة باستخدام الترتيب، وقوائم السماح، وقوائم الحظر، وترتيب الأولوية الصريح.
      • المزوّدون الاحتياطيون (Fallback Providers) — تحويل تلقائي إلى مزوّدي LLM احتياطيين عندما يواجه نموذجك الأساسي أخطاء. يشمل ذلك fallback للنموذج الأساسي، و fallback مستقلًا للمهام المساعدة مثل الرؤية والضغط واستخراج محتوى الويب.

      خوادم الأدوات (MCP)​

      • خوادم MCP — اربط Hermes بخوادم أدوات خارجية عبر Model Context Protocol. يمكنك الوصول إلى أدوات من GitHub وقواعد البيانات وأنظمة الملفات وحزم المتصفحات وواجهات API الداخلية وغيرها، دون كتابة أدوات Hermes أصلية. يدعم وسيلتي النقل stdio و SSE، وتصفية الأدوات لكل خادم، وتسجيل الموارد والـ prompts بحسب القدرات المتاحة.

      واجهات البحث في الويب الخلفية (Backends)​

      تدعم الأداتان web_search و web_extract ثمانية مزوّدين كـ backend، ويجري إعدادهم عبر config.yaml أو hermes tools:

      الـ Backendمتغير البيئةالبحثالاستخراجالزحف (Crawl)
      Firecrawl (الافتراضي)FIRECRAWL_API_KEY✔✔✔
      SearXNGSEARXNG_URL✔——
      Brave (فئة مجانية)BRAVE_SEARCH_API_KEY✔——
      DuckDuckGo (ddgs)(لا يوجد)✔——
      ExaEXA_API_KEY✔✔—

      مثال على إعداد سريع:

      web:
        backend: firecrawl    # firecrawl | searxng | brave-free | ddgs | tavily | perplexity | keenable | exa | parallel | xai

      إذا لم يكن web.backend مضبوطًا، يُكتشف الـ backend تلقائيًا بناءً على مفتاح API المتوفر. كما يُدعم Firecrawl المستضاف ذاتيًا (self-hosted) عبر FIRECRAWL_API_URL.

      أتمتة المتصفح​

      يتضمّن Hermes أتمتة كاملة للمتصفح مع عدة خيارات للـ backend، لتصفّح المواقع وتعبئة النماذج واستخراج المعلومات:

      • Browser Use Cloud — متصفح Chromium مُدار مع وضع التخفّي (stealth)، و proxies سكنية، وحلّ CAPTCHA، و profiles متصفح قابلة لإعادة الاستخدام
      • Browserbase — مزوّد بديل للمتصفحات السحابية يوفّر متصفحات مُدارة، وأدوات لمواجهة البوتات، وحلّ CAPTCHA، و proxies سكنية
      • Local Chromium-family CDP — اتصل بمتصفح Chrome أو Brave أو Chromium أو Edge قيد التشغيل لديك باستخدام /browser connect
      • Local Chromium — متصفح محلي بلا واجهة (headless) عبر CLI الخاص بـ agent-browser

      راجع أتمتة المتصفح لمعرفة طريقة الإعداد والاستخدام.

      مزوّدو الصوت و TTS​

      تحويل النص إلى كلام والكلام إلى نص على جميع منصات المراسلة:

      المزوّدالجودةالتكلفةمفتاح API
      Edge TTS (الافتراضي)جيدةمجانيغير مطلوب
      ElevenLabsممتازةمدفوعELEVENLABS_API_KEY
      OpenAI TTSجيدةمدفوعVOICE_TOOLS_OPENAI_KEY
      MiniMaxجيدةمدفوعMINIMAX_API_KEY
      xAI TTSجيدةمدفوعXAI_API_KEY
      NeuTTSجيدةمجانيغير مطلوب

      يدعم تحويل الكلام إلى نص (STT) ثمانية مزوّدين: faster-whisper المحلي (مجاني ويعمل على الجهاز نفسه)، و wrapper لأمر محلي، و Groq، و OpenAI Whisper API، و Mistral، و xAI، و ElevenLabs Scribe، و DeepInfra. ويعمل تفريغ الرسائل الصوتية على Telegram و Discord و WhatsApp وغيرها من منصات المراسلة. راجع الصوت و TTS و الوضع الصوتي (Voice Mode) لمزيد من التفاصيل.

      التكامل مع IDE والمحررات​

      • التكامل مع IDE (ACP) — استخدم Hermes Agent داخل المحررات المتوافقة مع ACP مثل VS Code و Zed و JetBrains. يعمل Hermes كخادم ACP، ويعرض رسائل المحادثة ونشاط الأدوات والفروقات في الملفات (diffs) وأوامر الطرفية داخل محررك.

      الوصول البرمجي​

      • خادم API — اعرض Hermes كـ endpoint HTTP متوافق مع OpenAI. يمكن لأي واجهة أمامية تتعامل بصيغة OpenAI — مثل Open WebUI و LobeChat و LibreChat و NextChat و ChatBox — أن تتصل بـ Hermes وتستخدمه كـ backend مع الـ toolset الكامل.

      الذاكرة والتخصيص​

      • الذاكرة المدمجة — ذاكرة دائمة ومنتقاة عبر الملفين MEMORY.md و USER.md. يحتفظ الوكيل بمخازن محدودة الحجم من الملاحظات الشخصية وبيانات ملف المستخدم تبقى محفوظة عبر الجلسات.
      • مزوّدو الذاكرة (Memory Providers) — أضف backends ذاكرة خارجية لتخصيص أعمق. هناك ثمانية مزوّدين مدعومين: Honcho (استدلال جدلي)، و OpenViking (استرجاع متدرّج)، و Mem0 (استخراج سحابي)، و Hindsight (رسوم بيانية معرفية)، و Holographic (SQLite محلي)، و RetainDB (بحث هجين)، و ByteRover (قائم على CLI)، و Supermemory.

      منصات المراسلة​

      يعمل Hermes كبوت gateway على أكثر من 27 منصة مراسلة، ويجري إعدادها جميعًا عبر النظام الفرعي نفسه gateway:

      • Telegram، Discord، Slack، WhatsApp، Signal، Matrix، Mattermost، البريد الإلكتروني (Email)، SMS، DingTalk، Feishu/Lark، WeCom، WeCom Callback، Weixin، BlueBubbles، Buzz، QQ Bot، Yuanbao، Home Assistant، Microsoft Teams، Microsoft Teams Meetings، Microsoft Graph Webhook، Google Chat، LINE، ntfy، SimpleX، Open WebUI، Webhooks

      راجع نظرة عامة على Messaging Gateway للاطلاع على جدول مقارنة المنصات ودليل الإعداد.

      روابط الاتصال السريع​

      لكل منصة من المنصات الكبرى رابط URL رسمي لـ "إنشاء البوت/التطبيق"، ويقبل بعضها معاملات تفتح النموذج الصحيح مباشرة. وفّر على نفسك عناء البحث في لوحات التحكم وانتقل إليها مباشرة:

      المنصةالرابط المباشرما يفتحه
      Telegramt.me/BotFatherمحادثة مع BotFather — أرسل /newbot لإنشاء bot token
      Discorddiscord.com/developers/applications?new_application=trueDeveloper Portal مع نافذة New Application مفتوحة مسبقًا
      Slackapi.slack.com/apps?new_app=1نافذة Create New App — اختر From an app manifest والصق الـ manifest الذي يولّده hermes slack manifest --agent-view
      LINEdevelopers.line.biz/consoleLINE Developers Console لإنشاء قناة Messaging API
      Feishu/Larkopen.feishu.cn/appلوحة تحكم منصة Feishu المفتوحة لإنشاء تطبيق مخصّص

      تشرح صفحة الإعداد الخاصة بكل منصة ما عليك فعله بعد الوصول إلى هناك.

      مساحات العمل التعاونية​

      • Buzz — مساحة عمل من Block مبنية على Nostr تجمع البشر والوكلاء. هناك ثلاثة مسارات للتكامل: يشغّل Buzz Desktop برنامج Hermes كبيئة تشغيل ACP مُدارة، أو يستضيف جسر الترحيل buzz-acp هوية Hermes على جانب الخادم، أو تنضم منصة الـ gateway الأصلية إلى قنوات Buzz مع كامل ميزات Hermes من ذاكرة ومهارات وموافقات و cron. تقارن صفحة النظرة العامة بين المسارات الثلاثة.

      أتمتة المنزل​

      • Home Assistant — تحكّم في أجهزة المنزل الذكي عبر أربع أدوات مخصّصة (ha_list_entities، ha_get_state، ha_list_services، ha_call_service). يُفعَّل toolset الخاص بـ Home Assistant تلقائيًا عند إعداد HASS_TOKEN.

      الإضافات (Plugins)​

      • نظام الإضافات (Plugins) — وسّع Hermes بأدوات مخصّصة، و hooks لدورة الحياة، وأوامر CLI دون تعديل الكود الأساسي. تُكتشف الإضافات من ~/.hermes/plugins/، ومن .hermes/plugins/ المحلي للمشروع، ومن نقاط الدخول (entry points) المثبّتة عبر pip.
      • بناء إضافة — دليل خطوة بخطوة لإنشاء إضافات Hermes تتضمّن أدوات و hooks وأوامر CLI.

      التدريب والتقييم​

      • المعالجة الدفعية (Batch Processing) — شغّل الوكيل على مئات الـ prompts بالتوازي، مع توليد بيانات trajectory منظّمة بصيغة ShareGPT لإنتاج بيانات التدريب أو للتقييم.
