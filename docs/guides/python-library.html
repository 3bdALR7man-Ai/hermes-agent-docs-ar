      استخدام Hermes كمكتبة Python

      Hermes ليس مجرد أداة CLI، إذ يمكنك استيراد AIAgent مباشرةً واستخدامه برمجيًا في سكربتات Python الخاصة بك، أو تطبيقات الويب، أو pipelines الأتمتة. يوضّح لك هذا الدليل كيفية ذلك.

      التثبيت​

      انسخ مستودع Hermes (clone) وأنشئ بيئة التطوير القابلة للتعديل (editable) المدعومة الخاصة به:

      git clone https://github.com/NousResearch/hermes-agent.git
      cd hermes-agent
      uv sync

      شغّل تطبيقك باستخدام uv run python your_app.py من داخل تلك النسخة المسحوبة (checkout). لا ينشر Hermes حزمة wheel أو توزيعة مصدرية (source distribution) مدعومة للتثبيت عبر requirements.txt.

      نصيحة

      متغيرات البيئة نفسها التي يستخدمها CLI مطلوبة أيضًا عند استخدام Hermes كمكتبة. اضبط على الأقل OPENROUTER_API_KEY (أو OPENAI_API_KEY / ANTHROPIC_API_KEY إذا كنت تستخدم الوصول المباشر إلى المزوّد).

      الاستخدام الأساسي​

      أبسط طريقة لاستخدام Hermes هي التابع chat() — مرّر رسالة، واحصل على سلسلة نصية في المقابل:

      from run_agent import AIAgent

      agent = AIAgent(
          model="anthropic/claude-sonnet-4.6",
          quiet_mode=True,
      )
      response = agent.chat("What is the capital of France?")
      print(response)

      يتولى chat() حلقة المحادثة كاملة داخليًا — استدعاءات الأدوات، وإعادة المحاولات، وكل شيء — ثم يُعيد الرد النصي النهائي فقط.

      تحذير

      اضبط دائمًا quiet_mode=True عند تضمين Hermes في الكود الخاص بك. فمن دونه، يطبع الوكيل مؤشرات الدوران (spinners) الخاصة بـ CLI، ومؤشرات التقدّم، وغيرها من مخرجات الطرفية التي ستُربك مخرجات تطبيقك.

      التحكم الكامل في المحادثة​

      لمزيد من التحكم في المحادثة، استخدم run_conversation() مباشرةً. يُعيد هذا التابع قاموسًا (dictionary) يحتوي على الرد الكامل، وسجل الرسائل، والبيانات الوصفية:

      agent = AIAgent(
          model="anthropic/claude-sonnet-4.6",
          quiet_mode=True,
      )

      result = agent.run_conversation(
          user_message="Search for recent Python 3.13 features",
          task_id="my-task-1",
      )

      print(result["final_response"])
      print(f"Messages exchanged: {len(result['messages'])}")

      يحتوي القاموس المُعاد على:

      • final_response — الرد النصي النهائي للوكيل
      • messages — سجل الرسائل الكامل (system، و user، و assistant، واستدعاءات الأدوات)

      (يُخزَّن task_id الذي تمرّره في نسخة الوكيل لأغراض عزل VM، لكنه لا يُعاد ضمن القاموس المُعاد.)

      يمكنك أيضًا تمرير رسالة system مخصصة تتجاوز الـ system prompt المؤقت (ephemeral) لذلك الاستدعاء:

      result = agent.run_conversation(
          user_message="Explain quicksort",
          system_message="You are a computer science tutor. Use simple analogies.",
      )

      إعداد الأدوات​

      تحكّم في الـ toolsets التي يمكن للوكيل الوصول إليها باستخدام enabled_toolsets أو disabled_toolsets:

      # Only enable web tools (browsing, search)
      agent = AIAgent(
          model="anthropic/claude-sonnet-4.6",
          enabled_toolsets=["web"],
          quiet_mode=True,
      )

      # Enable everything except terminal access
      agent = AIAgent(
          model="anthropic/claude-sonnet-4.6",
          disabled_toolsets=["terminal"],
          quiet_mode=True,
      )
      نصيحة

      استخدم enabled_toolsets عندما تريد وكيلًا بأدنى قدر من القدرات ومقيّدًا بإحكام (مثل البحث في الويب فقط لبوت بحثي). واستخدم disabled_toolsets عندما تريد معظم القدرات لكنك تحتاج إلى تقييد قدرات بعينها (مثل منع الوصول إلى الطرفية في بيئة مشتركة).

      المحادثات متعددة الأدوار​

      حافظ على حالة المحادثة عبر أدوار متعددة بإعادة تمرير سجل الرسائل:

      agent = AIAgent(
          model="anthropic/claude-sonnet-4.6",
          quiet_mode=True,
      )

      # First turn
      result1 = agent.run_conversation("My name is Alice")
      history = result1["messages"]

      # Second turn — agent remembers the context
      result2 = agent.run_conversation(
          "What's my name?",
          conversation_history=history,
      )
      print(result2["final_response"])  # "Your name is Alice."

      يقبل المعامل conversation_history قائمة messages من نتيجة سابقة. ينسخ الوكيل هذه القائمة داخليًا، لذا لا تُعدَّل قائمتك الأصلية أبدًا.

      حفظ الـ Trajectories​

      فعّل حفظ الـ trajectories لالتقاط المحادثات بصيغة ShareGPT — وهو مفيد لتوليد بيانات التدريب أو لتصحيح الأخطاء:

      agent = AIAgent(
          model="anthropic/claude-sonnet-4.6",
          save_trajectories=True,
          quiet_mode=True,
      )

      agent.chat("Write a Python function to sort a list")
      # Saves to trajectory_samples.jsonl in ShareGPT format

      تُضاف كل محادثة كسطر JSONL واحد، ما يسهّل جمع مجموعات البيانات من عمليات التشغيل المؤتمتة.

      System Prompts مخصصة​

      استخدم ephemeral_system_prompt لضبط system prompt مخصص يوجّه سلوك الوكيل لكنه لا يُحفظ في ملفات الـ trajectory (ما يُبقي بيانات التدريب لديك نظيفة):

      agent = AIAgent(
          model="anthropic/claude-sonnet-4",
          ephemeral_system_prompt="You are a SQL expert. Only answer database questions.",
          quiet_mode=True,
      )

      response = agent.chat("How do I write a JOIN query?")
      print(response)

      هذا مثالي لبناء وكلاء متخصصين — مراجع كود، أو كاتب توثيق، أو مساعد SQL — يستخدمون جميعًا الأدوات الأساسية نفسها.

      المعالجة الدفعية​

      لتشغيل عدد كبير من الـ prompts بالتوازي، يتضمن Hermes الملف batch_runner.py، الذي يدير نسخًا متزامنة من AIAgent مع عزل سليم للموارد:

      python batch_runner.py --input prompts.jsonl --output results.jsonl

      يحصل كل prompt على task_id خاص به وبيئة معزولة. وإذا احتجت إلى منطق دفعي مخصص، فيمكنك بناء منطقك الخاص باستخدام AIAgent مباشرةً:

      import concurrent.futures
      from run_agent import AIAgent

      prompts = [
          "Explain recursion",
          "What is a hash table?",
          "How does garbage collection work?",
      ]

      def process_prompt(prompt):
          # Create a fresh agent per task for thread safety
          agent = AIAgent(
              model="anthropic/claude-sonnet-4",
              quiet_mode=True,
              skip_memory=True,
          )
          return agent.chat(prompt)

      with concurrent.futures.ThreadPoolExecutor(max_workers=3) as executor:
          results = list(executor.map(process_prompt, prompts))

      for prompt, result in zip(prompts, results):
          print(f"Q: {prompt}\nA: {result}\n")
      تحذير

      أنشئ دائمًا نسخة جديدة من AIAgent لكل thread أو مهمة. يحتفظ الوكيل بحالة داخلية (سجل المحادثة، وجلسات الأدوات، وعدّادات التكرار) لا تُعد مشاركتها آمنة بين الـ threads.

      أمثلة على التكامل​

      Endpoint باستخدام FastAPI​

      from fastapi import FastAPI
      from pydantic import BaseModel
      from run_agent import AIAgent

      app = FastAPI()

      class ChatRequest(BaseModel):
          message: str
          model: str = "anthropic/claude-sonnet-4"

      @app.post("/chat")
      async def chat(request: ChatRequest):
          agent = AIAgent(
              model=request.model,
              quiet_mode=True,
              skip_context_files=True,
              skip_memory=True,
          )
          response = agent.chat(request.message)
          return {"response": response}

      بوت Discord​

      import discord
      from run_agent import AIAgent

      client = discord.Client(intents=discord.Intents.default())

      @client.event
      async def on_message(message):
          if message.author == client.user:
              return
          if message.content.startswith("!hermes "):
              query = message.content[8:]
              agent = AIAgent(
                  model="anthropic/claude-sonnet-4",
                  quiet_mode=True,
                  skip_context_files=True,
                  skip_memory=True,
                  platform="discord",
              )
              response = agent.chat(query)
              await message.channel.send(response[:2000])

      client.run("YOUR_DISCORD_TOKEN")

      خطوة ضمن CI/CD Pipeline​

      #!/usr/bin/env python3
      """CI step: auto-review a PR diff."""
      import subprocess
      from run_agent import AIAgent

      diff = subprocess.check_output(["git", "diff", "main...HEAD"]).decode()

      agent = AIAgent(
          model="anthropic/claude-sonnet-4",
          quiet_mode=True,
          skip_context_files=True,
          skip_memory=True,
          disabled_toolsets=["terminal", "browser"],
      )

      review = agent.chat(
          f"Review this PR diff for bugs, security issues, and style problems:\n\n{diff}"
      )
      print(review)

      modelstr""النموذج بصيغة OpenRouter (فارغ افتراضيًا؛ ويُحدَّد من إعدادات hermes لديك وقت التشغيل)

      enabled_toolsetsList[str]Noneالسماح بـ toolsets محددة فقط (قائمة سماح)
      disabled_toolsetsList[str]Noneحظر toolsets محددة (قائمة حظر)

      base_urlstrNoneURL لـ API endpoint مخصص
      platformstrNoneتلميح المنصة ("discord"، "telegram"، إلخ.)

      ملاحظات مهمة​

      نصيحة
      • اضبط skip_context_files=True إذا كنت لا تريد تحميل ملفات AGENTS.md الموجودة في مجلد العمل ضمن system prompt.
      • اضبط skip_memory=True لمنع الوكيل من القراءة من الذاكرة الدائمة أو الكتابة إليها — وهو موصى به لـ API endpoints عديمة الحالة (stateless).
      • يحقن المعامل platform (مثل "discord"، "telegram") تلميحات تنسيق خاصة بالمنصة، ليُكيّف الوكيل أسلوب مخرجاته وفقًا لها.
      تحذير
      • الأمان مع تعدد الـ threads: أنشئ نسخة واحدة من AIAgent لكل thread أو مهمة، ولا تشارك أي نسخة أبدًا بين استدعاءات متزامنة.
      • تنظيف الموارد: ينظّف الوكيل الموارد تلقائيًا (جلسات الطرفية، ونُسخ المتصفح) عند انتهاء المحادثة. إذا كنت تعمل ضمن عملية طويلة الأمد، فتأكد من أن كل محادثة تكتمل بشكل طبيعي.
      • حدود التكرار: القيمة الافتراضية max_iterations=500 سخية. في حالات الاستخدام البسيطة القائمة على السؤال والجواب، فكّر في خفضها (مثل max_iterations=10) لمنع حلقات استدعاء الأدوات الخارجة عن السيطرة وللتحكم في التكاليف.
