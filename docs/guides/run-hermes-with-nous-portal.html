      تشغيل Hermes Agent مع Nous Portal

      يرشدك هذا الدليل خطوة بخطوة إلى تشغيل Hermes Agent باشتراك Nous Portal من البداية إلى النهاية — بدءًا من التسجيل ووصولًا إلى التحقق من أن كل أداة تُوجَّه بشكل صحيح. وإذا كنت تريد فقط نظرة عامة على ماهية Portal وما يتضمنه الاشتراك، فراجع صفحة التكامل مع Nous Portal. أما هذه الصفحة فهي خطوات تنفيذ المهمة.

      المتطلبات المسبقة​

      • أن يكون Hermes Agent مثبّتًا (البدء السريع)
      • متصفح ويب على الجهاز الذي تُعدّه (أو إعادة توجيه المنافذ عبر SSH — راجع OAuth عبر SSH)
      • نحو 5 دقائق

      أنت لا تحتاج إلى: مفتاح OpenAI، أو مفتاح Anthropic، أو حساب Firecrawl، أو حساب FAL، أو حساب Browser Use، أو أي بيانات اعتماد أخرى خاصة بكل مورّد. وهذا هو جوهر الفكرة.

      1. احصل على اشتراك​

      افتح portal.nousresearch.com/manage-subscription، وسجّل، واختر خطة.

      مشترك بالفعل؟ انتقل مباشرةً إلى الخطوة 2.

      2. شغّل الإعداد بأمر واحد​

      hermes setup --portal

      يؤدي هذا الأمر الواحد خمس مهام:

      1. يفتح متصفحك على portal.nousresearch.com لتسجيل الدخول عبر OAuth
      2. يخزّن الـ refresh token في ~/.hermes/auth.json
      3. يضبط model.provider: nous في ~/.hermes/config.yaml
      4. يختار نموذجًا وكيليًا (agentic) افتراضيًا (anthropic/claude-sonnet-4.6 أو ما يماثله)
      5. يفعّل Tool Gateway للبحث في الويب وتوليد الصور و TTS وأتمتة المتصفح

      عند انتهائه، تعود إلى الطرفية جاهزًا للمحادثة.

      ماذا لو كنت متصلًا بخادم عبر SSH؟​

      يحتاج OAuth إلى متصفح، لكن استدعاء الرجوع (callback) عبر loopback يعمل على الجهاز الذي يعمل عليه Hermes. لديك خياران:

      # Option A: SSH port forwarding (preferred)
      ssh -N -L 8642:127.0.0.1:8642 user@remote-host    # in a local terminal
      hermes setup --portal                              # on the remote, open the printed URL in your local browser

      # Option B: device-code login (works from Cloud Shell, Codespaces, EC2 Instance Connect)
      hermes auth add nous --type oauth
      # Then re-run `hermes setup --portal` to wire the provider + gateway

      راجع OAuth عبر SSH / الأجهزة البعيدة للاطلاع على الشرح الكامل، بما في ذلك سلاسل ProxyJump و mosh/tmux والمشكلات الخفية في ControlMaster.

      3. تحقّق من نجاح العملية​

      hermes portal info

      يُفترض أن ترى:

        Nous Portal
        ───────────
        Auth:    ✓ logged in
        Portal:  https://portal.nousresearch.com
        Model:   ✓ using Nous as inference provider

        Tool Gateway
        ────────────
        Web search & extract  via Nous Portal
        Image generation      via Nous Portal
        Text-to-speech        via Nous Portal
        Browser automation    via Nous Portal

      إذا أظهر أي سطر شيئًا غير "via Nous Portal" أو كان سطر المصادقة يقول "not logged in"، فانتقل إلى قسم استكشاف الأخطاء وإصلاحها أدناه.

      4. أجرِ محادثتك الأولى​

      hermes chat

      جرّب شيئًا يستخدم كلًّا من النموذج و Tool Gateway:

      Hey, search the web for "Hermes Agent release notes" and summarize the top 3 hits.

      يُفترض أن ترى Hermes يستدعي web_search (المدعومة بـ Firecrawl، عبر الـ gateway) ويردّ بملخص. وإذا نُفّذ البحث وكانت الاستجابة منطقية، فقد انتهيت — فـ Portal موصول بالكامل من البداية إلى النهاية.

      5. اختر النموذج الذي تريده فعلًا​

      يتيح لك hermes setup --portal اختيار نموذج أثناء الإعداد، لكن جوهر الاشتراك هو الوصول إلى الكتالوج الكامل — بدّل في أي وقت باستخدام /model في منتصف الجلسة:

      /model anthropic/claude-sonnet-4.6     # best general-purpose agentic
      /model openai/gpt-5.4                  # strong reasoning + tool calling
      /model google/gemini-2.5-pro           # huge context window
      /model deepseek/deepseek-v3.2          # cost-effective coder
      /model anthropic/claude-opus-4.6       # heavyweight for hard problems

      أو افتح المنتقي لتصفّح النماذج:

      /model

      اختر نموذجًا افتراضيًا مختلفًا بشكل دائم:

      # in your terminal, outside any session
      hermes config set model.default anthropic/claude-sonnet-4.6

      لا تختر Hermes-4 لأعمال الوكيل​

      يتوفر Hermes-4-70B و Hermes-4-405B على Portal بخصومات كبيرة، لكنهما نموذجان للمحادثة/الاستدلال، وليسا مضبوطين لاستدعاء الأدوات. لذا سيواجهان صعوبة في حلقات الوكيل متعددة الخطوات. استخدمهما في أعمال المحادثة/البحث عبر وسيط الاشتراك (subscription proxy) من أدوات لا تعمل كوكلاء. أما لـ Hermes Agent نفسه، فالتزم بالنماذج الوكيلية المتقدمة المذكورة أعلاه.

      وتتضمن صفحة المعلومات الخاصة بـ Portal هذا التحذير أيضًا — فهو إرشاد رسمي من Nous، وليس مجرد رأي من جهة Hermes.

      6. (اختياري) خصّص توجيه Tool Gateway​

      الاشتراك في الـ gateway اختياري لكل أداة على حدة، وليس كل شيء أو لا شيء. فإذا كان لديك حساب Browserbase بالفعل وتريد الاستمرار في استخدامه مع توجيه البحث في الويب وتوليد الصور عبر Nous، فهذا مدعوم:

      hermes tools
      # → Web search       → "Nous Subscription"     (recommended)
      # → Image generation → "Nous Subscription"     (recommended)
      # → Browser          → "Browserbase"           (your existing key)
      # → TTS              → "Nous Subscription"     (recommended)

      تظهر هذه الصفوف في hermes tools حتى قبل تسجيل دخولك إلى Nous Portal — فإذا اخترت "Nous Subscription" دون جلسة نشطة، يُجري Hermes تسجيل الدخول إلى Portal مباشرةً في المكان نفسه (دون تغيير مزوّد الـ inference أو أدواتك الأخرى).

      تحقّق من التوليفة لديك باستخدام:

      hermes portal tools

      سترى التوجيه لكل أداة — via Nous Portal للأدوات الموجَّهة عبر الاشتراك، واسم الشريك (browserbase و firecrawl وغيرهما) للأدوات التي تستخدم مفاتيحك الخاصة.

      7. (اختياري) فعّل الوضع الصوتي​

      بما أن Tool Gateway يتضمن OpenAI TTS، فإن الوضع الصوتي (voice mode) يعمل دون مفتاح OpenAI منفصل:

      hermes setup tts
      # → pick "Nous Subscription" for TTS
      # → pick a speech-to-text backend (local faster-whisper is free, no setup)

      بعد ذلك، في أي جلسة على منصة مراسلة (Telegram و Discord و Signal وغيرها)، أرسل رسالة صوتية وسيحوّلها Hermes إلى نص، ويستجيب، ثم يردّ بصوت مُركَّب — وكل ذلك ضمن اشتراكك في Portal.

      8. (اختياري) Cron وسير العمل الدائم التشغيل​

      يعمل اشتراك Portal مع مهام cron والمعالجة الدفعية بالطريقة نفسها التي يعمل بها مع المحادثة التفاعلية — إذ يُعاد استخدام OAuth refresh token تلقائيًا. لا حاجة إلى إعداد إضافي؛ فقط جدوِل مهام cron وستُحتسب تكلفتها على اشتراكك.

      hermes cron create "0 9 * * *" \
        "Search the web for top AI news and summarize the 5 most important stories" \
        --name "Daily AI news"

      تعمل مهمة cron دون إشراف، وتستدعي النموذج والبحث في الويب والتلخيص، وكل ذلك عبر اشتراكك في Portal.

      Profiles والإعدادات متعددة المستخدمين​

      إذا كنت تستخدم Hermes profiles (مثل إعدادات منفصلة لكل مشروع)، فإن refresh token الخاص بـ Portal يُشارَك تلقائيًا بين جميع الـ profiles عبر مخزن tokens مشترك. سجّل الدخول مرة واحدة من أي profile، وستلتقطه البقية تلقائيًا.

      أما في إعدادات الفرق التي يتشارك فيها عدة أشخاص جهازًا واحدًا، فلكل شخص حسابه الخاص على Portal → لكل مجلد home ملف ~/.hermes/auth.json الخاص به → لا مشاركة للـ tokens بين المستخدمين. وهذا هو الحدّ الصحيح.

      استكشاف الأخطاء وإصلاحها​

      hermes portal info يعرض "not logged in" بعد hermes setup --portal​

      لم يكتمل مسار OAuth. أعد تشغيله:

      hermes portal

      إذا لم يُفتح متصفحك أو فشل استدعاء الرجوع، فالأرجح أنك على جهاز بعيد أو بلا واجهة (headless) — راجع OAuth عبر SSH للاطلاع على حلول إعادة توجيه المنافذ البديلة.

      ظهور "Model: currently openrouter" (أو مزوّد آخر) بدلًا من "using Nous as inference provider"​

      انحرفت إعداداتك المحلية. فقد نجح OAuth لكن model.provider لا يزال يشير إلى مزوّد مختلف. الحل:

      hermes config set model.provider nous

      أو بشكل تفاعلي:

      hermes model
      # pick Nous Portal

      أعد التحقق باستخدام hermes portal info.

      أدوات Tool Gateway تعرض أسماء الشركاء بدلًا من "via Nous Portal"​

      إعدادات كل أداة تتجاوز الـ gateway. نفّذ:

      hermes tools
      # pick "Nous Subscription" for any tool you want gateway-routed

      يمزج بعض المستخدمين عمدًا — مثل توجيه الويب عبر Nous مع استخدام مفتاح Browserbase الخاص بهم للمتصفح. فإن كان ذلك مقصودًا، فاتركه كما هو. وإن لم يكن كذلك، فهذا الأمر يُصلحه.

      ظهور "Re-authentication required" في منتصف الجلسة​

      أُبطل refresh token الخاص بـ Portal لديك (بسبب تغيير كلمة المرور، أو إلغاء يدوي، أو انتهاء صلاحية الجلسة). وقد عُزل الـ token الآن محليًا كي لا يعيد Hermes استخدامه بلا نهاية. ما عليك سوى تسجيل الدخول مجددًا:

      hermes auth add nous

      يُرفع العزل تلقائيًا عند نجاح تسجيل الدخول مجددًا.

      النموذج الذي أريده غير موجود في منتقي /model​

      يعتمد كتالوج Portal على قائمة نماذج OpenRouter (أكثر من 300) إضافةً إلى نماذج تُقدَّم عبر مزوّدين خاصين أو ثانويين. وإذا كان نموذج ما مفقودًا، فجرّب كتابة المعرّف (slug) بصيغة OpenRouter مباشرةً:

      /model anthropic/claude-opus-4.6
      /model openai/o1-2025-12-17

      إذا كان النموذج غير متاح فعلًا، افتح issue — فمعظم الثغرات تتعلق بإعدادات توجيه يمكننا تحديثها.

      الفوترة لا تظهر في حسابي على Portal​

      سيخبرك hermes portal info ما إذا كان التوجيه يتم فعلًا عبر Portal أو عبر مزوّد آخر. الأسباب الشائعة:

      • ضبط model.provider على openrouter/anthropic/وغيرهما بدلًا من nous
      • فشل في تحديث OAuth أدى إلى اللجوء احتياطيًا إلى مزوّد آخر مضبوط
      • وجود عدة Hermes profiles وأنت تستخدم الخطأ منها (تحقق باستخدام hermes profile list)

      تريد إلغاء التفويض والبدء من جديد​

      hermes auth logout nous       # wipes the local refresh token
      # Then re-run setup or remove the subscription from the Portal web UI

      ما الذي تحصل عليه، بالأرقام​

      دون Portalمع Portal
      مفتاح واحد لـ OpenRouter / Anthropic / OpenAI في .envOAuth refresh token واحد، دون مفاتيح في .env
      مفتاح Firecrawl واحد للويبالويب يُوجَّه عبر الـ gateway
      مفتاح FAL واحد لتوليد الصورتوليد الصور يُوجَّه عبر الـ gateway
      مفتاح Browser Use / Browserbase واحد للمتصفحالمتصفح يُوجَّه عبر الـ gateway
      مفتاح OpenAI واحد لـ TTS / الوضع الصوتيTTS يُوجَّه عبر الـ gateway
      5 لوحات تحكم منفصلة، وعمليات شحن رصيد، وفواتيراشتراك واحد، وفاتورة واحدة
      عبر الأجهزة: تكرار المفاتيح الخمسة جميعهاعبر الأجهزة: إعادة مصادقة OAuth مرة واحدة

      هذه هي الصفقة. وإذا كنت تستخدم أكثر من اثنتين من هذه الخدمات على أي حال، فإن الاشتراك يغطي تكلفته بنفسه.

      انظر أيضًا​

      • صفحة التكامل مع Nous Portal — نظرة عامة على ما يتضمنه الاشتراك
      • Tool Gateway — تفاصيل كاملة عن كل أداة تُوجَّه عبر الـ gateway
      • وسيط الاشتراك (Subscription proxy) — استخدم اشتراكك في Portal من أدوات غير Hermes
      • الوضع الصوتي (Voice Mode) — إعداد المحادثات الصوتية ضمن اشتراك Portal
      • OAuth عبر SSH — أنماط تسجيل الدخول على الأجهزة البعيدة أو التي بلا واجهة
      • Profiles — مشاركة تسجيل دخول واحد إلى Portal بين عدة إعدادات لـ Hermes
