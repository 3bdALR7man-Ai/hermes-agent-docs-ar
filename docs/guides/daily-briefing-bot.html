      درس تطبيقي: بناء بوت الملخّص اليومي

      في هذا الدرس التطبيقي، ستبني بوتًا شخصيًا للملخّصات يستيقظ كل صباح، ويبحث في المواضيع التي تهمّك، ويلخّص النتائج، ثم يسلّم إليك ملخّصًا موجزًا مباشرةً على Telegram أو Discord.

      في النهاية، سيكون لديك سير عمل مؤتمت بالكامل يجمع بين البحث في الويب، والجدولة عبر cron، والتفويض، والتسليم عبر المراسلة — دون الحاجة إلى كتابة أي كود.

      نصيحة

      تستخدم هذه الوصفة البحث في الويب، والتلخيص، و TTS اختياريًا — وكلها مضمّنة في اشتراك Portal. أسرع طريقة للإعداد هي hermes setup --portal. راجع Nous Portal.

      ما الذي سنبنيه​

      إليك سير العملية:

      1. 8:00 صباحًا — يُطلق مُجدوِل cron مهمتك
      2. يُنشئ Hermes جلسة وكيل جديدة باستخدام الـ prompt الخاص بك
      3. البحث في الويب يجلب أحدث الأخبار حول مواضيعك
      4. التلخيص يُكثّفها في صيغة ملخّص مرتّبة
      5. التسليم يرسل الملخّص إلى Telegram أو Discord

      تعمل العملية بأكملها دون أي تدخل منك. ما عليك سوى قراءة ملخّصك مع قهوة الصباح.

      المتطلبات المسبقة​

      قبل البدء، تأكد من توفّر ما يلي:

      • تثبيت Hermes Agent — راجع دليل التثبيت
      • تشغيل الـ Gateway — يتولى الـ daemon الخاص بالـ gateway تنفيذ مهام cron: 
        hermes gateway install   # Install as a user service
        sudo hermes gateway install --system   # Linux servers: boot-time system service
        # or
        hermes gateway           # Run in foreground
      • مفتاح Firecrawl API — اضبط FIRECRAWL_API_KEY في بيئتك لتفعيل البحث في الويب
      • إعداد المراسلة (اختياري لكنه موصى به) — إعداد Telegram أو Discord مع قناة رئيسية (home channel)
      لا تستخدم المراسلة؟ لا مشكلة

      لا يزال بإمكانك متابعة هذا الدرس باستخدام deliver: "local". ستُحفظ الملخّصات في ~/.hermes/cron/output/ ويمكنك قراءتها في أي وقت.

      الخطوة 1: اختبار سير العمل يدويًا​

      قبل أتمتة أي شيء، لنتأكد من أن الملخّص يعمل. ابدأ جلسة محادثة:

      hermes

      ثم أدخل هذا الـ prompt:

      Search for the latest news about AI agents and open source LLMs.
      Summarize the top 3 stories in a concise briefing format with links.

      سيبحث Hermes في الويب، ويقرأ النتائج، ثم يُنتج شيئًا مثل:

      ☀️ Your AI Briefing — March 8, 2026

      1. Qwen 3 Released with 235B Parameters
         Alibaba's latest open-weight model matches GPT-4.5 on several
         benchmarks while remaining fully open source.
         → https://qwenlm.github.io/blog/qwen3/

      2. LangChain Launches Agent Protocol Standard
         A new open standard for agent-to-agent communication gains
         adoption from 15 major frameworks in its first week.
         → https://blog.langchain.dev/agent-protocol/

      3. EU AI Act Enforcement Begins for General-Purpose Models
         The first compliance deadlines hit, with open source models
         receiving exemptions under the 10M parameter threshold.
         → https://artificialintelligenceact.eu/updates/

      ---
      3 stories • Sources searched: 8 • Generated by Hermes Agent

      إذا نجح ذلك، فأنت جاهز لأتمتته.

      حسّن الصيغة تدريجيًا

      جرّب prompts مختلفة حتى تحصل على مخرجات تُعجبك. أضف تعليمات مثل "استخدم رموز emoji في العناوين" أو "اجعل كل ملخّص أقل من جملتين." وأيًّا كان ما تستقر عليه، فهو ما سيدخل في مهمة cron.

      الخطوة 2: إنشاء مهمة Cron​

      لنجدول الآن هذه المهمة لتعمل تلقائيًا كل صباح. يمكنك فعل ذلك بطريقتين.

      قبل إنشاء مهام cron، تأكد من أن Hermes مضبوط على نموذج ومزوّد افتراضيين على المستوى العام. وإذا أردت أن تستخدم مهمة بعينها قيمًا مختلفة، فاضبط تجاوزات صريحة للنموذج/المزوّد خاصة بتلك المهمة عند إنشائها.

      الخيار A: اللغة الطبيعية (في المحادثة)​

      ما عليك سوى إخبار Hermes بما تريد:

      Every morning at 8am, search the web for the latest news about AI agents
      and open source LLMs. Summarize the top 3 stories in a concise briefing
      with links. Use a friendly, professional tone. Deliver to telegram.

      سيُنشئ Hermes مهمة cron نيابةً عنك باستخدام الأداة الموحّدة cronjob.

      الخيار B: Slash Command في CLI​

      استخدم الأمر /cron لمزيد من التحكم:

      /cron add "0 8 * * *" "Search the web for the latest news about AI agents and open source LLMs. Find at least 5 recent articles from the past 24 hours. Summarize the top 3 most important stories in a concise daily briefing format. For each story include: a clear headline, a 2-sentence summary, and the source URL. Use a friendly, professional tone. Format with emoji bullet points and end with a total story count."

      القاعدة الذهبية: prompts مكتفية بذاتها​

      مفهوم بالغ الأهمية

      تعمل مهام cron في جلسة جديدة تمامًا — دون أي ذاكرة لمحادثاتك السابقة، ودون أي سياق حول ما "أعددته سابقًا." يجب أن يتضمن الـ prompt كل ما يحتاجه الوكيل لإنجاز المهمة.

      prompt سيئ:

      Do my usual morning briefing.

      prompt جيد:

      Search the web for the latest news about AI agents and open source LLMs.
      Find at least 5 recent articles from the past 24 hours. Summarize the
      top 3 most important stories in a concise daily briefing format. For each
      story include: a clear headline, a 2-sentence summary, and the source URL.
      Use a friendly, professional tone. Format with emoji bullet points.

      الـ prompt الجيد محدد بشأن ما يجب البحث عنه، وعدد المقالات، والصيغة المطلوبة، والأسلوب. إنه يمنح الوكيل كل ما يحتاجه دفعة واحدة.

      الخطوة 3: تخصيص الملخّص​

      بمجرد أن يعمل الملخّص الأساسي، يمكنك إطلاق العنان لإبداعك.

      ملخّصات متعددة المواضيع​

      غطِّ عدة مجالات في ملخّص واحد:

      /cron add "0 8 * * *" "Create a morning briefing covering three topics. For each topic, search the web for recent news from the past 24 hours and summarize the top 2 stories with links.

      Topics:
      1. AI and machine learning — focus on open source models and agent frameworks
      2. Cryptocurrency — focus on Bitcoin, Ethereum, and regulatory news
      3. Space exploration — focus on SpaceX, NASA, and commercial space

      Format as a clean briefing with section headers and emoji. End with today's date and a motivational quote."

      استخدام التفويض للبحث المتوازي​

      للحصول على ملخّصات أسرع، اطلب من Hermes تفويض كل موضوع إلى sub-agent (وكيل فرعي):

      /cron add "0 8 * * *" "Create a morning briefing by delegating research to sub-agents. Delegate three parallel tasks:

      1. Delegate: Search for the top 2 AI/ML news stories from the past 24 hours with links
      2. Delegate: Search for the top 2 cryptocurrency news stories from the past 24 hours with links
      3. Delegate: Search for the top 2 space exploration news stories from the past 24 hours with links

      Collect all results and combine them into a single clean briefing with section headers, emoji formatting, and source links. Add today's date as a header."

      يبحث كل وكيل فرعي بشكل مستقل وبالتوازي، ثم يجمع الوكيل الرئيسي كل النتائج في ملخّص واحد متقن. راجع توثيق التفويض لمعرفة المزيد عن آلية عمل ذلك.

      جدولة لأيام العمل فقط​

      لا تحتاج إلى ملخّصات في عطلة نهاية الأسبوع؟ استخدم تعبير cron يستهدف الأيام من الاثنين إلى الجمعة:

      /cron add "0 8 * * 1-5" "Search for the latest AI and tech news..."

      ملخّصات مرتين يوميًا​

      احصل على نظرة عامة صباحية وخلاصة مسائية:

      /cron add "0 8 * * *" "Morning briefing: search for AI news from the past 12 hours..."
      /cron add "0 18 * * *" "Evening recap: search for AI news from the past 12 hours..."

      إضافة سياق شخصي عبر الذاكرة​

      إذا كانت الذاكرة مفعّلة لديك، فيمكنك تخزين تفضيلات تستمر عبر الجلسات. لكن تذكّر — تعمل مهام cron في جلسات جديدة دون ذاكرة للمحادثات. لإضافة سياق شخصي، ضمّنه مباشرةً في الـ prompt:

      /cron add "0 8 * * *" "You are creating a briefing for a senior ML engineer who cares about: PyTorch ecosystem, transformer architectures, open-weight models, and AI regulation in the EU. Skip stories about product launches or funding rounds unless they involve open source.

      Search for the latest news on these topics. Summarize the top 3 stories with links. Be concise and technical — this reader doesn't need basic explanations."
      خصّص الشخصية المستهدفة

      إن تضمين تفاصيل حول الشخص الذي أُعدّ الملخّص من أجله يحسّن مدى ملاءمته بشكل كبير. أخبر الوكيل بدورك، واهتماماتك، وما يجب تجاهله.

      الخطوة 4: إدارة مهامك​

      عرض جميع المهام المجدولة​

      في المحادثة:

      /cron list

      أو من الطرفية:

      hermes cron list

      سترى مخرجات مثل:

      ID          | Name              | Schedule    | Next Run           | Deliver
      ------------|-------------------|-------------|--------------------|--------
      a1b2c3d4    | Morning Briefing  | 0 8 * * *   | 2026-03-09 08:00   | telegram
      e5f6g7h8    | Evening Recap     | 0 18 * * *  | 2026-03-08 18:00   | telegram

      حذف مهمة​

      في المحادثة:

      /cron remove a1b2c3d4

      أو اطلب ذلك بأسلوب المحادثة:

      Remove my morning briefing cron job.

      سيستخدم Hermes cronjob(action="list") للعثور عليها، ثم cronjob(action="remove") لحذفها.

      التحقق من حالة الـ Gateway​

      تأكد من أن المُجدوِل يعمل فعلًا:

      hermes cron status

      إذا لم يكن الـ gateway قيد التشغيل، فلن تُنفَّذ مهامك. ثبّته كخدمة تعمل في الخلفية لضمان الموثوقية:

      hermes gateway install
      # or on Linux servers
      sudo hermes gateway install --system

      التعمّق أكثر​

      لقد بنيت بوت ملخّص يومي يعمل. إليك بعض الاتجاهات التي يمكنك استكشافها لاحقًا:

      • المهام المجدولة (Cron) — مرجع كامل لصيغ الجدولة، وحدود التكرار، وخيارات التسليم
      • التفويض — نظرة معمّقة على سير العمل المتوازي مع الوكلاء الفرعيين
      • منصات المراسلة — إعداد Telegram أو Discord أو وجهات تسليم أخرى
      • الذاكرة — سياق دائم عبر الجلسات
      • نصائح وأفضل الممارسات — مزيد من النصائح حول هندسة الـ prompts
      ما الذي يمكنك جدولته أيضًا؟

      يصلح نمط بوت الملخّص لأي شيء: مراقبة المنافسين، أو ملخّصات مستودعات GitHub، أو توقعات الطقس، أو تتبّع المحفظة الاستثمارية، أو فحوص سلامة الخوادم، أو حتى نكتة يومية. إذا استطعت وصفه في prompt، فبإمكانك جدولته.
