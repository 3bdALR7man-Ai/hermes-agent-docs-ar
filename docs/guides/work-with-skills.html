      العمل مع المهارات (Skills)

      المهارات (Skills) هي مستندات معرفة تُحمَّل عند الطلب وتعلّم Hermes كيفية التعامل مع مهام محددة — من توليد فن ASCII إلى إدارة GitHub PRs. يرشدك هذا الدليل إلى استخدامها في عملك اليومي.

      للمرجع التقني الكامل، راجع نظام المهارات (Skills).

      العثور على المهارات​

      يأتي كل تثبيت لـ Hermes مزوّدًا بمهارات مضمّنة (bundled). اطّلع على المتاح منها:

      # In any chat session:
      /skills

      # Or from the CLI:
      hermes skills list

      يعرض هذا قائمة مختصرة بالأسماء والأوصاف:

      ascii-art         Generate ASCII art using pyfiglet, cowsay, boxes...
      arxiv             Search and retrieve academic papers from arXiv...
      github-pr-workflow Full PR lifecycle — create branches, commit...
      plan              Plan mode — inspect context, write a markdown...
      excalidraw        Create hand-drawn style diagrams using Excalidraw...

      البحث عن مهارة​

      # Search by keyword
      /skills search docker
      /skills search music

      Skills Hub​

      المهارات الاختيارية الرسمية (المهارات الأثقل أو المتخصصة غير المفعّلة افتراضيًا) متاحة عبر الـ Hub:

      # Browse official optional skills
      /skills browse

      # Search the hub
      /skills search blockchain

      استخدام مهارة​

      كل مهارة مثبّتة تصبح تلقائيًا slash command. فقط اكتب اسمها:

      # Load a skill and give it a task
      /ascii-art Make a banner that says "HELLO WORLD"
      /plan Design a REST API for a todo app
      /github-pr-workflow Create a PR for the auth refactor

      # Just the skill name (no task) loads it and lets you describe what you need
      /excalidraw

      يمكنك أيضًا تفعيل المهارات عبر محادثة طبيعية — اطلب من Hermes استخدام مهارة معينة، وسيحمّلها عبر أداة skill_view.

      الكشف التدريجي (Progressive Disclosure)​

      تستخدم المهارات نمط تحميل موفّرًا لـ token. لا يحمّل الوكيل كل شيء دفعة واحدة:

      1. skills_list() — قائمة مختصرة بكل المهارات (نحو 3 آلاف token). تُحمَّل عند بدء الجلسة.
      2. skill_view(name) — محتوى SKILL.md الكامل لمهارة واحدة. يُحمَّل عندما يقرر الوكيل أنه يحتاج تلك المهارة.
      3. skill_view(name, file_path) — ملف مرجعي محدد ضمن المهارة. يُحمَّل فقط عند الحاجة.

      هذا يعني أن المهارات لا تكلّف tokens حتى تُستخدم فعليًا.

      التثبيت من الـ Hub​

      تأتي المهارات الاختيارية الرسمية مع Hermes لكنها غير مفعّلة افتراضيًا. ثبّتها صراحةً:

      # Install an official optional skill
      hermes skills install official/research/arxiv

      # Install from the hub in a chat session
      /skills install official/creative/songwriting-and-ai-music

      # Install SKILL.md and its referenced support files from an HTTP(S) URL
      hermes skills install https://sharethis.chat/SKILL.md
      /skills install https://example.com/SKILL.md --name my-skill

      ما الذي يحدث:

      1. يُنسخ مجلد المهارة إلى ~/.hermes/skills/
      2. تظهر في مخرجات skills_list الخاصة بك
      3. تصبح متاحة كـ slash command
      نصيحة

      تسري المهارات المثبّتة في الجلسات الجديدة. إذا أردت إتاحتها في الجلسة الحالية، استخدم /reset لبدء جلسة جديدة، أو أضف --now لإبطال ذاكرة الـ prompt المؤقتة فورًا (يكلّف tokens أكثر في الدور التالي).

      التحقق من التثبيت​

      # Check it's there
      hermes skills list | grep arxiv

      # Or in chat
      /skills search arxiv

      المهارات المُقدَّمة عبر الإضافات (Plugins)​

      يمكن للإضافات تضمين مهاراتها الخاصة بأسماء ذات مساحة اسم (namespaced) بصيغة plugin:skill. يمنع هذا تعارض الأسماء مع المهارات المدمجة.

      # Load a plugin skill by its qualified name
      skill_view("superpowers:writing-plans")

      # Built-in skill with the same base name is unaffected
      skill_view("writing-plans")

      مهارات الإضافات لا تُدرج في system prompt ولا تظهر في skills_list. فهي اختيارية بالانضمام (opt-in) — حمّلها صراحةً عندما تعلم أن إضافة ما توفّرها. عند تحميلها، يرى الوكيل شريطًا يسرد المهارات الشقيقة من الإضافة نفسها.

      لمعرفة كيفية شحن المهارات في إضافتك الخاصة، راجع Build a Hermes Plugin → Bundle skills.

      ضبط إعدادات المهارة​

      تعلن بعض المهارات عن إعدادات تحتاجها في الـ frontmatter الخاص بها:

      metadata:
        hermes:
          config:
            - key: tenor.api_key
              description: "Tenor API key for GIF search"
              prompt: "Enter your Tenor API key"
              url: "https://developers.google.com/tenor/guides/quickstart"

      عند تحميل مهارة تحمل إعدادات لأول مرة، يطلب منك Hermes القيم. تُخزَّن في config.yaml تحت skills.config.*.

      أدر إعدادات المهارة من CLI:

      # Interactive config for a specific skill
      hermes skills config gif-search

      # View all skill config
      hermes config get skills.config --json

      إنشاء مهارتك الخاصة​

      المهارات هي مجرد ملفات Markdown بها frontmatter بصيغة YAML. إنشاء واحدة يستغرق أقل من خمس دقائق.

      1. أنشئ المجلد​

      mkdir -p ~/.hermes/skills/my-category/my-skill

      2. اكتب SKILL.md​

      ~/.hermes/skills/my-category/my-skill/SKILL.md
      ---
      name: my-skill
      description: Brief description of what this skill does
      version: 1.0.0
      metadata:
        hermes:
          tags: [my-tag, automation]
          category: my-category
      ---

      # My Skill

      ## When to Use
      Use this skill when the user asks about [specific topic] or needs to [specific task].

      ## Procedure
      1. First, check if [prerequisite] is available
      2. Run `command --with-flags`
      3. Parse the output and present results

      ## Pitfalls
      - Common failure: [description]. Fix: [solution]
      - Watch out for [edge case]

      ## Verification
      Run `check-command` to confirm the result is correct.

      3. أضف ملفات مرجعية (اختياري)​

      يمكن للمهارات تضمين ملفات داعمة يحمّلها الوكيل عند الطلب:

      my-skill/
      ├── SKILL.md                    # Main skill document
      ├── references/
      │   ├── api-docs.md             # API reference the agent can consult
      │   └── examples.md             # Example inputs/outputs
      ├── templates/
      │   └── config.yaml             # Template files the agent can use
      └── scripts/
          └── setup.sh                # Scripts the agent can execute

      اذكر هذه الملفات في SKILL.md الخاص بك:

      For API details, load the reference: `skill_view("my-skill", "references/api-docs.md")`

      4. اختبرها​

      ابدأ جلسة جديدة وجرّب مهارتك:

      hermes chat -q "/my-skill help me with the thing"

      تظهر المهارة تلقائيًا — دون الحاجة إلى تسجيل. ضعها في ~/.hermes/skills/ وتصبح جاهزة للعمل.

      معلومة

      يمكن للوكيل أيضًا إنشاء المهارات وتحديثها بنفسه باستخدام skill_manage. بعد حل مشكلة معقدة، قد يعرض Hermes حفظ الأسلوب المتّبع كمهارة للمرة القادمة.

      إدارة المهارات لكل منصة​

      تحكم في المهارات المتاحة على كل منصة:

      hermes skills

      يفتح هذا واجهة TUI تفاعلية يمكنك من خلالها تفعيل أو تعطيل المهارات لكل منصة (CLI، Telegram، Discord، إلخ). مفيد عندما تريد إتاحة مهارات معينة في سياقات محددة فقط — مثل إبقاء مهارات التطوير بعيدة عن Telegram.

      المهارات مقابل الذاكرة​

      كلاهما دائم عبر الجلسات، لكنهما يخدمان غرضين مختلفين:

      المهارات (Skills)الذاكرة (Memory)
      ما هيمعرفة إجرائية — كيفية فعل الأشياءمعرفة واقعية — ماهية الأشياء
      متى تُحمَّلتُحمَّل عند الطلب، فقط عند الحاجةتُحقَن في كل جلسة تلقائيًا
      الحجميمكن أن يكون كبيرًا (مئات الأسطر)ينبغي أن يكون مختصرًا (حقائق أساسية فقط)
      التكلفةصفر tokens حتى تُحمَّلتكلفة token صغيرة لكن ثابتة
      أمثلة"كيفية النشر إلى Kubernetes""يفضّل المستخدم الوضع الداكن، ويعيش في PST"
      من ينشئهاأنت أو الوكيل أو التثبيت من الـ Hubالوكيل، استنادًا إلى المحادثات

      قاعدة عامة: إذا كنت ستضعها في مستند مرجعي، فهي مهارة. وإذا كنت ستضعها على ورقة لاصقة، فهي ذاكرة.

      نصائح​

      حافظ على تركيز المهارات. مهارة تحاول تغطية "كل DevOps" ستكون طويلة جدًا وغامضة جدًا. مهارة تغطي "نشر تطبيق Python إلى Fly.io" محددة بما يكفي لتكون مفيدة فعلًا.

      دع الوكيل ينشئ المهارات. بعد مهمة معقدة متعددة الخطوات، غالبًا ما يعرض Hermes حفظ الأسلوب المتّبع كمهارة. وافق — فهذه المهارات التي يؤلفها الوكيل تلتقط سير العمل الدقيق بما في ذلك المزالق التي اكتُشفت في الطريق.

      استخدم الفئات. نظّم المهارات في مجلدات فرعية (~/.hermes/skills/devops/، ~/.hermes/skills/research/، إلخ). هذا يبقي القائمة قابلة للإدارة ويساعد الوكيل على إيجاد المهارات ذات الصلة أسرع.

      حدّث المهارات عندما تصبح قديمة. إذا استخدمت مهارة وواجهت مشكلات لا تغطيها، أخبر Hermes بتحديث المهارة بما تعلّمته. المهارات غير المُصانة تصبح عبئًا.

      للمرجع الكامل للمهارات — حقول الـ frontmatter، التفعيل الشرطي، المجلدات الخارجية، والمزيد — راجع نظام المهارات (Skills).
