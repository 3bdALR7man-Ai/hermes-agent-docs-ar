      Google Gemini

      يدعم Hermes Agent خدمة Google Gemini كمزوّد أصلي باستخدام Google AI Studio / Gemini API — وليس الـ endpoint المتوافق مع OpenAI. هذا يتيح لـ Hermes ترجمة حلقة الرسائل والأدوات الداخلية ذات الشكل الخاص بـ OpenAI إلى واجهة generateContent الأصلية في Gemini، مع الحفاظ على استدعاء الأدوات، والبث (streaming)، والمدخلات متعددة الوسائط، وبيانات الاستجابة الوصفية الخاصة بـ Gemini.

      المتطلبات الأساسية​

      • مفتاح API من Google AI Studio — أنشئ واحدًا من aistudio.google.com/apikey
      • مشروع Google Cloud مفعّل الفوترة — يُوصى به عند استخدام الوكيل. المستوى المجاني في Gemini صغير جدًا لجلسات الوكيل الطويلة، لأن Hermes قد يجري عدة استدعاءات للنموذج في كل دور من المستخدم.
      • تثبيت Hermes — لا حاجة إلى حزمة Python إضافية لمزوّد Gemini الأصلي.
      مسار مفتاح API

      اضبط GOOGLE_API_KEY أو GEMINI_API_KEY. يتحقق Hermes من كلا الاسمين لمزوّد gemini.

      البدء السريع​

      # Add your Gemini API key
      echo "GOOGLE_API_KEY=..." >> ~/.hermes/.env

      # Select Gemini as your provider
      hermes model
      # → Choose "More providers..." → "Google AI Studio"
      # → Hermes checks your key tier and shows Gemini models
      # → Select a model

      # Start chatting
      hermes chat

      إذا كنت تفضّل تعديل الإعدادات مباشرة، استخدم عنوان القاعدة الأصلي (base URL) لـ Gemini API:

      model:
        default: gemini-3.7-flash
        provider: gemini
        base_url: https://generativelanguage.googleapis.com/v1beta

      الإعدادات​

      بعد تشغيل hermes model، سيحتوي ملف ~/.hermes/config.yaml على:

      model:
        default: gemini-3.7-flash
        provider: gemini
        base_url: https://generativelanguage.googleapis.com/v1beta

      وفي ~/.hermes/.env:

      GOOGLE_API_KEY=...

      واجهة Gemini API الأصلية​

      الـ endpoint الموصى به هو:

      https://generativelanguage.googleapis.com/v1beta

      يكتشف Hermes هذا الـ endpoint وينشئ محوّله (adapter) الأصلي الخاص بـ Gemini. داخليًا، يبقي Hermes حلقة الوكيل بصيغة رسائل OpenAI، ثم يترجم كل طلب إلى مخطط (schema) Gemini الأصلي:

      • messages[] ← Gemini contents[]
      • الـ system prompts ← Gemini systemInstruction
      • مخططات الأدوات ← Gemini functionDeclarations
      • نتائج الأدوات ← أجزاء Gemini functionResponse
      • استجابات البث ← أجزاء stream بصيغة OpenAI لحلقة Hermes

      تُترجم مصفوفات نوع معامل الأداة مثل "type": ["number", "null"] إلى النوع القياسي (scalar) في Gemini مع صيغة nullable. أما الاتحادات متعددة الأنواع فتحتفظ بكل بديل عبر anyOf، بما في ذلك الخصائص المتداخلة وعناصر المصفوفات. يحدث هذا تلقائيًا؛ ولا حاجة إلى أي تغيير في إعدادات خادم MCP أو المزوّد.

      توقيعات التفكير (thought signatures) في Gemini 3

      عند استخدام الأدوات في Gemini 3، يحافظ Hermes على قيم thoughtSignature المرفقة بأجزاء استدعاء الدوال ويعيد إرسالها في دور استخدام الأداة التالي، وهذا يغطي المسار الحرج للتحقق (validation) في سير عمل الوكيل متعدد الخطوات.

      قد يُرفق Gemini 3 أيضًا توقيعات تفكير بأجزاء أخرى من الاستجابة. محوّل Hermes الأصلي مُحسَّن حاليًا لحلقات استخدام أدوات الوكيل، لذا فهو لا يعيد بعد إرسال كل توقيع غير خاص باستدعاء أداة بدقة كاملة على مستوى الجزء.

      تفضيل الـ Endpoint الأصلي​

      تعرض Google أيضًا endpoint متوافقًا مع OpenAI:

      https://generativelanguage.googleapis.com/v1beta/openai/

      لجلسات وكيل Hermes، يُفضَّل استخدام endpoint Gemini الأصلي أعلاه. يتضمّن Hermes محوّل Gemini أصليًا يتيح له تعيين استخدام الأدوات متعدد الأدوار، ونتائج استدعاء الأدوات، والبث، والمدخلات متعددة الوسائط، وبيانات استجابة Gemini الوصفية مباشرة إلى واجهة generateContent في Gemini. يبقى الـ endpoint المتوافق مع OpenAI مفيدًا عندما تحتاج تحديدًا إلى التوافق مع واجهة OpenAI.

      إذا سبق أن ضبطت GEMINI_BASE_URL على عنوان /openai، فأزله أو غيّره:

      GEMINI_BASE_URL=https://generativelanguage.googleapis.com/v1beta

      النماذج المتاحة​

      تعرض قائمة اختيار hermes model نماذج Gemini الموجودة في سجل مزوّدي Hermes. من الخيارات الشائعة:

      النموذجالمعرّف (ID)ملاحظات
      Gemini 3.8 Flashgemini-3.8-flashأقدر نموذج Flash للأعمال البرمجية والوكيلية طويلة المدى
      Gemini 3.7 Flashgemini-3.7-flashالتوازن الافتراضي الموصى به بين السرعة والقدرة والفهم متعدد الوسائط
      Gemini 3.1 Pro Previewgemini-3.1-pro-previewأقدر نموذج في التفكير المنطقي والرياضيات والبرمجة
      Gemini 3.5 Flash Litegemini-3.5-flash-liteالخيار الأسرع والأقل تكلفة للمهام الخفيفة
      Gemini 2.5 Flashgemini-2.5-flashنموذج سريع من الجيل السابق يتمتع بقدرات تفكير (thinking)
      Gemini 2.5 Progemini-2.5-proنموذج تفكير معقّد من الجيل السابق

      تتغيّر إتاحة النماذج مع الوقت. إذا اختفى نموذج ما أو لم يكن مفعّلًا لمفتاحك، شغّل hermes model مرة أخرى واختر نموذجًا من القائمة الحالية.

      معرّفات النماذج (Model IDs)

      استخدم معرّفات نماذج Gemini الأصلية مثل gemini-3.7-flash، وليس معرّفات بأسلوب OpenRouter مثل google/gemini-3.7-flash، عند ضبط provider: gemini.

      أحدث الأسماء المستعارة (Aliases)​

      تنشر Google أسماء مستعارة متحرّكة لعائلتَي Gemini Pro و Flash. يفيدك gemini-pro-latest و gemini-flash-latest عندما تريد أن تُحدِّث Google النموذج تلقائيًا دون تغيير إعدادات Hermes لديك. لاحظ أن رسوم استخدامك قد تتأثر إذا فرضت النماذج الأحدث أسعارًا مختلفة.

      الاسم المستعاريتتبّع حاليًاملاحظات
      gemini-pro-latestأحدث نموذج Gemini Proالأفضل عندما تريد النموذج الافتراضي الحالي لـ Pro من Google
      gemini-flash-latestأحدث نموذج Gemini Flashالأفضل عندما تريد النموذج الافتراضي الحالي لـ Flash من Google
      model:
        default: gemini-pro-latest
        provider: gemini
        base_url: https://generativelanguage.googleapis.com/v1beta

      إذا كنت بحاجة إلى قابلية استنساخ صارمة (strict reproducibility)، فضّل معرّفات نماذج صريحة مثل gemini-3.1-pro-preview أو gemini-3.7-flash.

      Gemma عبر واجهة Gemini API​

      تعرض Google أيضًا نماذج Gemma عبر واجهة Gemini API. يتعرّف Hermes عليها كنماذج من Google، لكنه يخفي إدخالات Gemma ذات الإنتاجية المنخفضة جدًا من قائمة اختيار النماذج الافتراضية، حتى لا يختار المستخدمون الجدد بالخطأ نموذجًا بمستوى تقييمي لجلسة وكيل طويلة الأمد.

      من معرّفات التقييم المفيدة:

      النموذجالمعرّف (ID)ملاحظات
      Gemma 4 31B ITgemma-4-31b-itنموذج Gemma أكبر؛ مفيد للتوافق وتقييم الجودة
      Gemma 4 26B A4B ITgemma-4-26b-a4b-itنسخة بمعاملات نشطة أصغر عند توفرها

      يُستحسن التعامل مع هذه النماذج كخيارات تقييم على مفاتيح Gemini API. تسعير Gemma API من Google مقتصر على المستوى المجاني فقط وحدود الاستخدام فيه منخفضة مقارنة بنماذج Gemini الإنتاجية، لذا ينبغي عادةً أن ينتقل استخدام Hermes المستمر إلى نموذج Gemini مدفوع، أو نشر مستضاف ذاتيًا، أو مزوّد آخر بحصة استخدام مناسبة.

      لاستخدام نموذج Gemma مخفي عن قائمة الاختيار، اضبطه مباشرة:

      model:
        default: gemma-4-31b-it
        provider: gemini
        base_url: https://generativelanguage.googleapis.com/v1beta

      تبديل النماذج أثناء الجلسة​

      استخدم الأمر /model أثناء المحادثة:

      /model gemini-3.7-flash
      /model gemini-flash-latest
      /model gemini-3.1-pro-preview
      /model gemini-pro-latest
      /model gemma-4-31b-it
      /model gemini-3.1-flash-lite-preview

      إذا لم تكن قد أعددت Gemini بعد، فاخرج من الجلسة وشغّل hermes model أولًا. الأمر /model يبدّل بين المزوّدين والنماذج المُعدّة مسبقًا فقط؛ ولا يجمع مفاتيح API جديدة.

      التشخيص​

      hermes doctor

      يتحقق فحص doctor من:

      • ما إذا كان GOOGLE_API_KEY أو GEMINI_API_KEY متوفرًا
      • ما إذا كان يمكن تحديد بيانات اعتماد المزوّد المُعدّة

      Gateway (منصات المراسلة)​

      يعمل Gemini مع جميع منصات gateway الخاصة بـ Hermes (Telegram وDiscord وSlack وWhatsApp وLINE وFeishu وغيرها). اضبط Gemini كمزوّدك، ثم ابدأ الـ gateway كالمعتاد:

      hermes gateway setup
      hermes gateway start

      يقرأ الـ gateway ملف config.yaml ويستخدم إعدادات مزوّد Gemini نفسها.

      استكشاف الأخطاء وإصلاحها​

      "Gemini native client requires an API key"​

      لم يعثر Hermes على مفتاح API صالح للاستخدام. أضف أحد هذين إلى ~/.hermes/.env:

      GOOGLE_API_KEY=...
      # or
      GEMINI_API_KEY=...

      ثم شغّل hermes model مرة أخرى.

      "This Google API key is on the free tier"​

      يفحص Hermes مفاتيح Gemini API أثناء الإعداد. يمكن أن تُستنفد حصص المستوى المجاني بعد عدد قليل من أدوار الوكيل، لأن استخدام الأدوات وإعادة المحاولة والضغط (compression) والمهام المساعدة قد تتطلب استدعاءات متعددة للنموذج.

      فعّل الفوترة على مشروع Google Cloud المرتبط بمفتاحك، وأعد توليد المفتاح عند الحاجة، ثم شغّل:

      hermes model

      "404 model not found"​

      النموذج المختار غير متاح لحسابك أو منطقتك أو مفتاحك. شغّل hermes model مرة أخرى واختر نموذج Gemini آخر من القائمة الحالية.

      نموذج Gemma لا يظهر في hermes model​

      قد يخفي Hermes نماذج Gemma ذات الإنتاجية المنخفضة من قائمة الاختيار افتراضيًا. إذا كنت تريد تقييم أحدها عمدًا، اضبط معرّف النموذج مباشرة في ~/.hermes/config.yaml.

      "429 quota exceeded" في Gemma​

      نماذج Gemma المتاحة عبر واجهة Gemini API مفيدة للتقييم، لكن حدود المستوى المجاني في Gemini API الخاصة بها منخفضة. استخدمها لاختبار التوافق، ثم انتقل إلى نموذج Gemini مدفوع أو مزوّد آخر لجلسات الوكيل المستمرة.

      تم ضبط endpoint متوافق مع OpenAI​

      تحقق من ~/.hermes/.env بحثًا عن:

      GEMINI_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/

      غيّره إلى الـ endpoint الأصلي أو أزل التجاوز (override):

      GEMINI_BASE_URL=https://generativelanguage.googleapis.com/v1beta

      فشل استدعاء الأدوات بأخطاء في المخطط (schema)​

      حدّث Hermes وأعد تشغيل hermes model. يعمل محوّل Gemini الأصلي على تنقية مخططات الأدوات لتناسب صيغة إعلان الدوال الأكثر صرامة في Gemini؛ وقد لا تفعل الإصدارات القديمة أو الـ endpoints المخصّصة ذلك.
