      بناء إضافة لمزوّد توليد الصور

      تسجّل إضافات مزوّدي توليد الصور backend يخدم كل استدعاء للأداة image_generate — سواء كان DALL·E أو gpt-image أو Grok أو Flux أو Imagen أو Stable Diffusion أو fal أو Replicate أو منصة ComfyUI محلية، أو أي شيء آخر. وتأتي المزوّدات المدمجة (OpenAI و OpenAI-Codex و xAI و FAL و Krea و DeepInfra و OpenRouter و Meta Model API) كلها على هيئة إضافات. ويمكنك إضافة مزوّد جديد، أو تجاوز مزوّد مضمّن، بوضع مجلد في plugins/image_gen/<name>/.

      نصيحة

      توليد الصور واحد من عدة أنواع من إضافات الـ backend التي يدعمها Hermes. أما الأنواع الأخرى (ذات الفئات المجردة الأكثر تخصصًا) فهي إضافات مزوّدي الذاكرة وإضافات Context Engine وإضافات مزوّدي النماذج. وتجد إضافات الأدوات والـ hooks و CLI العامة في بناء إضافة لـ Hermes.

      كيف يعمل الاكتشاف​

      يبحث Hermes عن backends توليد الصور في ثلاثة مواضع:

      1. المضمّنة — <repo>/plugins/image_gen/<name>/ (تُحمَّل تلقائيًا مع kind: backend، ومتاحة دائمًا)
      2. الخاصة بالمستخدم — ~/.hermes/plugins/image_gen/<name>/ (تُفعَّل صراحةً عبر plugins.enabled)
      3. حزم pip — الحزم التي تصرّح بنقطة دخول hermes_agent.plugins

      تستدعي الدالة register(ctx) في كل إضافة ctx.register_image_gen_provider(...) — وهذا ما يضعها في السجل (registry) الموجود في agent/image_gen_registry.py. ويُحدَّد المزوّد النشط عبر image_gen.provider في config.yaml؛ ويرشد hermes tools المستخدمين خلال عملية الاختيار.

      يطلب مغلّف الأداة image_generate من السجل المزوّد النشط ويوجّه الاستدعاء إليه. وإذا لم يكن أي مزوّد مسجّلًا، تعرض الأداة رسالة خطأ مفيدة تشير إلى hermes tools.

      بنية المجلدات​

      plugins/image_gen/my-backend/
      ├── __init__.py      # ImageGenProvider subclass + register()
      └── plugin.yaml      # Manifest with kind: backend

      تكون الإضافة المضمّنة مكتملة عند هذه النقطة. أما إضافات المستخدم الموجودة في ~/.hermes/plugins/image_gen/<name>/ فيجب إضافتها إلى plugins.enabled في config.yaml (أو تنفيذ hermes plugins enable <name>).

      الفئة المجردة ImageGenProvider​

      أنشئ فئة فرعية من agent.image_gen_provider.ImageGenProvider. العنصران الإلزاميان الوحيدان هما الخاصية name والدالة generate() — ولكل ما عداهما قيم افتراضية معقولة:

      # plugins/image_gen/my-backend/__init__.py
      from typing import Any, Dict, List, Optional
      import os

      from agent.image_gen_provider import (
          DEFAULT_ASPECT_RATIO,
          ImageGenProvider,
          error_response,
          normalize_reference_images,
          resolve_aspect_ratio,
          save_b64_image,
          success_response,
      )


      class MyBackendImageGenProvider(ImageGenProvider):
          @property
          def name(self) -> str:
              # Stable id used in image_gen.provider config. Lowercase, no spaces.
              return "my-backend"

          @property
          def display_name(self) -> str:
              # Human label shown in `hermes tools`. Defaults to name.title() if omitted.
              return "My Backend"

          def is_available(self) -> bool:
              # Return False if credentials or deps are missing.
              # The tool's availability gate calls this before dispatch.
              if not os.environ.get("MY_BACKEND_API_KEY"):
                  return False
              try:
                  import my_backend_sdk  # noqa: F401
              except ImportError:
                  return False
              return True

          def list_models(self) -> List[Dict[str, Any]]:
              # Catalog shown in `hermes tools` model picker.
              return [
                  {
                      "id": "my-model-fast",
                      "display": "My Model (Fast)",
                      "speed": "~5s",
                      "strengths": "Quick iteration",
                      "price": "$0.01/image",
                  },
                  {
                      "id": "my-model-hq",
                      "display": "My Model (HQ)",
                      "speed": "~30s",
                      "strengths": "Highest fidelity",
                      "price": "$0.04/image",
                  },
              ]

          def default_model(self) -> Optional[str]:
              return "my-model-fast"

          def get_setup_schema(self) -> Dict[str, Any]:
              # Metadata for the `hermes tools` picker — keys to prompt for at setup.
              return {
                  "name": "My Backend",
                  "badge": "paid",        # optional; shown as a short tag in the picker
                  "tag": "One-line description shown under the name",
                  "env_vars": [
                      {
                          "key": "MY_BACKEND_API_KEY",
                          "prompt": "My Backend API key",
                          "url": "https://my-backend.example.com/api-keys",
                      },
                  ],
              }

          def capabilities(self) -> Dict[str, Any]:
              # Declare whether this backend supports image-to-image / editing.
              # The tool layer surfaces this in the dynamic schema so the model
              # knows when `image_url` is honored. Default (if you omit this) is
              # text-only: {"modalities": ["text"], "max_reference_images": 0}.
              return {"modalities": ["text", "image"], "max_reference_images": 4}

          def generate(
              self,
              prompt: str,
              aspect_ratio: str = DEFAULT_ASPECT_RATIO,
              *,
              image_url: Optional[str] = None,
              reference_image_urls: Optional[List[str]] = None,
              **kwargs: Any,
          ) -> Dict[str, Any]:
              prompt = (prompt or "").strip()
              aspect_ratio = resolve_aspect_ratio(aspect_ratio)

              if not prompt:
                  return error_response(
                      error="Prompt is required",
                      error_type="invalid_input",
                      provider=self.name,
                      prompt="",
                      aspect_ratio=aspect_ratio,
                  )

              # Routing: if image_url (or reference_image_urls) is set, the call is
              # an image-to-image / edit request; otherwise text-to-image. Report
              # which path you took via the `modality` field of success_response.
              sources = []
              if image_url:
                  sources.append(image_url)
              sources.extend(normalize_reference_images(reference_image_urls) or [])
              modality = "image" if sources else "text"

              # Model selection precedence: env var → config → default. The helper
              # _resolve_model() in the built-in openai plugin is a good reference.
              model_id = kwargs.get("model") or self.default_model() or "my-model-fast"

              try:
                  import my_backend_sdk
                  client = my_backend_sdk.Client(api_key=os.environ["MY_BACKEND_API_KEY"])
                  if modality == "image":
                      result = client.edit(
                          prompt=prompt,
                          model=model_id,
                          image_urls=sources,
                      )
                  else:
                      result = client.generate(
                          prompt=prompt,
                          model=model_id,
                          aspect_ratio=aspect_ratio,
                      )

                  # Two shapes supported:
                  #   - URL string: return it as `image`
                  #   - base64 data: save under $HERMES_HOME/cache/images/ via save_b64_image()
                  if result.get("image_b64"):
                      path = save_b64_image(
                          result["image_b64"],
                          prefix=self.name,
                          extension="png",
                      )
                      image = str(path)
                  else:
                      image = result["image_url"]

                  return success_response(
                      image=image,
                      model=model_id,
                      prompt=prompt,
                      aspect_ratio=aspect_ratio,
                      provider=self.name,
                      modality=modality,
                  )
              except Exception as exc:
                  return error_response(
                      error=str(exc),
                      error_type=type(exc).__name__,
                      provider=self.name,
                      model=model_id,
                      prompt=prompt,
                      aspect_ratio=aspect_ratio,
                  )


      def register(ctx) -> None:
          """Plugin entry point — called once at load time."""
          ctx.register_image_gen_provider(MyBackendImageGenProvider())

      plugin.yaml​

      name: my-backend
      version: 1.0.0
      description: My image backend — text-to-image via My Backend SDK
      author: Your Name
      kind: backend
      requires_env:
        - MY_BACKEND_API_KEY

      القيمة kind: backend هي ما يوجّه الإضافة إلى مسار تسجيل توليد الصور. ويُطلب من المستخدم إدخال requires_env أثناء hermes plugins install.

      مرجع الفئة المجردة​

      العقد الكامل موجود في agent/image_gen_provider.py. والدوال التي ستعيد تعريفها عادةً:

      العنصرإلزاميالقيمة الافتراضيةالغرض
      name✅—معرّف ثابت يُستخدم في إعداد image_gen.provider
      display_name—name.title()التسمية المعروضة في hermes tools
      is_available()—Trueبوابة تحقق عند غياب بيانات الاعتماد أو الاعتماديات
      list_models()—[]الكتالوج الخاص بأداة اختيار النموذج في hermes tools
      default_model()—أول عنصر من list_models()الخيار الاحتياطي عند عدم ضبط أي نموذج
      get_setup_schema()—حد أدنىالبيانات الوصفية لأداة الاختيار وطلبات إدخال متغيرات البيئة
      generate(prompt, aspect_ratio, **kwargs)✅—الاستدعاء نفسه

      صيغة الاستجابة​

      يجب أن تُرجع generate() قاموسًا مبنيًا عبر success_response() أو error_response()، وكلتاهما موجودتان في agent/image_gen_provider.py.

      النجاح:

      success_response(
          image=<url-or-absolute-path>,
          model=<model-id>,
          prompt=<echoed-prompt>,
          aspect_ratio="landscape" | "square" | "portrait",
          provider=<your-provider-name>,
          extra={...},  # optional backend-specific fields
      )

      الخطأ:

      error_response(
          error="human-readable message",
          error_type="provider_error" | "invalid_input" | "<exception class name>",
          provider=<your-provider-name>,
          model=<model-id>,
          prompt=<prompt>,
          aspect_ratio=<resolved aspect>,
      )

      يحوّل مغلّف الأداة القاموس إلى JSON ويسلّمه إلى الـ LLM. وتُعرض الأخطاء بوصفها نتيجة الأداة، ويقرر الـ LLM كيف يشرحها للمستخدم.

      التعامل مع مخرجات base64 مقابل عناوين URL​

      تُرجع بعض الـ backends عناوين URL للصور (fal و Replicate)، بينما تُرجع أخرى بيانات بترميز base64 (OpenAI gpt-image-2). في حالة base64، استخدم save_b64_image() — فهي تكتب الصورة في $HERMES_HOME/cache/images/<prefix>_<timestamp>_<uuid>.<ext> وتُرجع Path المطلق. مرّر هذا المسار (بصيغة str) بوصفه image= في success_response(). ويتعرّف التسليم عبر الـ gateway (فقاعة الصورة في Telegram، والمرفق في Discord) على عناوين URL والمسارات المطلقة معًا.

      تجاوزات المستخدم​

      ضع إضافة مستخدم في ~/.hermes/plugins/image_gen/<name>/ تحمل قيمة الخاصية name نفسها التي تحملها إضافة مضمّنة، وفعّلها عبر hermes plugins enable <name> — فالسجل يعتمد قاعدة "آخر من يكتب هو الفائز"، وبذلك تحل نسختك محل المدمجة. وهذا مفيد لتوجيه الإضافة openai إلى وكيل (proxy) خاص، أو لاستبدال كتالوج النماذج بكتالوج مخصص.

      الاختبار​

      export HERMES_HOME=/tmp/hermes-imggen-test
      mkdir -p $HERMES_HOME/plugins/image_gen/my-backend
      # …copy __init__.py + plugin.yaml into that dir…

      export MY_BACKEND_API_KEY=your-test-key
      hermes plugins enable my-backend

      # Pick it as the active provider
      echo "image_gen:" >> $HERMES_HOME/config.yaml
      echo "  provider: my-backend" >> $HERMES_HOME/config.yaml

      # Exercise it
      hermes -z "Generate an image of a corgi in a spacesuit"

      أو تفاعليًا: hermes tools → "Image Generation" → اختر my-backend → أدخل مفتاح API إذا طُلب منك.

      تطبيقات مرجعية​

      • plugins/image_gen/openai/__init__.py — يقدّم gpt-image-2 بمستويات low/medium/high على هيئة ثلاثة معرّفات نماذج افتراضية تتشارك نموذج API واحدًا بقيم مختلفة للمعامل quality. مثال جيد على النماذج متعددة المستويات تحت backend واحد، وعلى سلسلة الأسبقية في config.yaml.
      • plugins/image_gen/xai/__init__.py — يقدّم Grok Imagine عبر xAI. بنية مختلفة (مخرجات على هيئة عناوين URL، وكتالوج أبسط).
      • plugins/image_gen/openai-codex/__init__.py — نسخة تعتمد Responses API على نمط Codex، وتعيد استخدام OpenAI SDK مع عنوان base URL مختلف للتوجيه.

      التوزيع عبر pip​

      # pyproject.toml
      [project.entry-points."hermes_agent.plugins"]
      my-backend-imggen = "my_backend_imggen_package"

      يجب أن تتيح الحزمة my_backend_imggen_package دالة register على المستوى الأعلى. راجع قسم التوزيع عبر pip في دليل الإضافات العام للاطلاع على الإعداد الكامل.
