      بناء إضافة مزوّد بحث في الويب (Web Search Provider Plugin)

      تسجّل إضافات مزوّدي البحث في الويب backend يخدم استدعاءات أدوات web_search، وweb_extract، و(اختياريًا) الزحف العميق (deep-crawl). المزوّدون المدمجون — Firecrawl، وSearXNG، وTavily، وPerplexity، وExa، وParallel، وKeenable، وBrave Search (الطبقة المجانية)، وxAI، وDDGS — يُشحَنون جميعًا كإضافات تحت plugins/web/<name>/. يمكنك إضافة واحد جديد، أو استبدال واحد مضمَّن، بوضع دليل بجانبها.

      نصيحة

      البحث في الويب أحد عدة إضافات backend يدعمها Hermes. البقية (ولكل منها صنفها المجرد الخاص) هي إضافات مزوّدي توليد الصور، وإضافات مزوّدي توليد الفيديو، وإضافات مزوّدي الذاكرة، وإضافات Context Engine، وإضافات مزوّدي النماذج. إضافات الأدوات/الـ hooks/CLI العامة موجودة في بناء إضافة Hermes.

      كيف يعمل الاكتشاف​

      يفحص Hermes بحثًا عن backends البحث في الويب في ثلاثة أماكن:

      1. مضمّن (Bundled) — <repo>/plugins/web/<name>/ (يُحمَّل تلقائيًا بـ kind: backend، متاح دائمًا)
      2. المستخدم (User) — ~/.hermes/plugins/web/<name>/ (اختياري عبر plugins.enabled أو hermes plugins enable <name>)
      3. Pip — حزم تعلن نقطة دخول hermes_agent.plugins

      تستدعي دالة register(ctx) الخاصة بكل إضافة ctx.register_web_search_provider(...) — وهذا ما يضع النسخة في السجل الموجود في agent/web_search_registry.py. يُختار المزوّد النشط لكل قدرة عبر الإعدادات:

      القدرةمفتاح الإعداداتيرجع احتياطيًا إلى
      web_searchweb.search_backendweb.backend
      web_extractweb.extract_backendweb.backend
      أوضاع الزحف العميق داخل web_extractweb.extract_backendweb.backend

      عندما لا يُضبَط أي من المفتاحين، يكتشف Hermes تلقائيًا الـ backend من أي مفتاح API/رابط موجود في البيئة. تُرشِد hermes tools المستخدمين خلال الاختيار.

      هيكل الدليل​

      plugins/web/my-backend/
      ├── __init__.py     # register() entry point
      ├── provider.py     # WebSearchProvider subclass
      └── plugin.yaml     # Manifest with kind: backend and provides_web_providers

      brave_free/ وddgs/ هما أصغر مرجعين ضمن الشجرة — brave_free لمزوّد بحث فقط مقيّد بمفتاح API، وddgs لمزوّد بلا مفتاح يثبّت SDK الخاص به بشكل كسول (lazy).

      الصنف المجرد WebSearchProvider​

      اشتق من agent.web_search_provider.WebSearchProvider. الأعضاء المطلوبون فقط هم name، وis_available()، وأيًا من search() / extract() تنفّذه. (الزحف العميق ليس دالة منفصلة — بل وضع من أوضاع extract().)

      # plugins/web/my-backend/provider.py
      from __future__ import annotations

      import os
      from typing import Any, Dict, List

      from agent.web_search_provider import WebSearchProvider


      class MyBackendWebSearchProvider(WebSearchProvider):
          """Minimal search-only provider against the My Backend HTTP API."""

          @property
          def name(self) -> str:
              # Stable id used in web.search_backend / web.extract_backend / web.backend
              # config keys. Lowercase, no spaces; hyphens permitted.
              return "my-backend"

          @property
          def display_name(self) -> str:
              # Human label shown in `hermes tools`. Defaults to `name`.
              return "My Backend"

          def is_available(self) -> bool:
              # Cheap check — env var present, optional dep importable, etc.
              # MUST NOT make network calls (runs on every `hermes tools` paint).
              return bool(os.getenv("MY_BACKEND_API_KEY", "").strip())

          def supports_search(self) -> bool:
              return True

          def supports_extract(self) -> bool:
              return False

          def search(self, query: str, limit: int = 5) -> Dict[str, Any]:
              import httpx

              api_key = os.environ["MY_BACKEND_API_KEY"]
              try:
                  resp = httpx.get(
                      "https://api.example.com/search",
                      params={"q": query, "count": max(1, min(int(limit), 20))},
                      headers={"Authorization": f"Bearer {api_key}"},
                      timeout=15,
                  )
                  resp.raise_for_status()
                  data = resp.json()
              except httpx.HTTPError as exc:
                  return {"success": False, "error": str(exc)}

              # Response shape is fixed — see "Response shape" below.
              return {
                  "success": True,
                  "data": {
                      "web": [
                          {
                              "title": item.get("title", ""),
                              "url": item.get("url", ""),
                              "description": item.get("snippet", ""),
                              "position": idx + 1,
                          }
                          for idx, item in enumerate(data.get("results", []))
                      ],
                  },
              }
      # plugins/web/my-backend/__init__.py
      from plugins.web.my_backend.provider import MyBackendWebSearchProvider


      def register(ctx) -> None:
          """Plugin entry point — called once at load time."""
          ctx.register_web_search_provider(MyBackendWebSearchProvider())

      plugin.yaml​

      name: web-my-backend
      version: 1.0.0
      description: "My Backend web search — Bearer-auth REST API"
      author: Your Name
      kind: backend
      provides_web_providers:
        - my-backend
      requires_env:
        - MY_BACKEND_API_KEY
      المفتاحالغرض
      kind: backendيوجّه الإضافة عبر مسار تحميل backend
      provides_web_providersقائمة أسماء (name) المزوّدين الذين تسجّلهم هذه الإضافة — يستخدمها المحمّل لعرض الإضافة في hermes tools حتى قبل تشغيل register()
      requires_envمطالبة تفاعلية ببيانات الاعتماد أثناء hermes plugins install (راجع بناء إضافة Hermes للصيغة الغنية)

      مرجع الصنف المجرد​

      العقد الكامل في agent/web_search_provider.py. الدوال التي يمكنك تجاوزها (override):

      العضومطلوبالافتراضيالغرض
      name✅—معرّف ثابت يُستخدَم في إعدادات web.*_backend
      display_name—nameالتسمية المعروضة في hermes tools
      is_available()✅—بوابة توفّر رخيصة التكلفة — متغيرات بيئة، اعتماديات اختيارية
      supports_search()—Trueعلامة قدرة لتوجيه web_search
      supports_extract()—Falseعلامة قدرة لتوجيه web_extract
      search(query, limit)مشروطيُطلق استثناءًمطلوب عندما تعيد supports_search() القيمة True
      extract(urls, **kwargs)مشروطيُطلق استثناءًمطلوب عندما تعيد supports_extract() القيمة True

      يمكن للمزوّدين الإعلان عن عدة قدرات من صنف واحد — تنفّذ Firecrawl وTavily وPerplexity وKeenable وExa وParallel كلًا من البحث والاستخراج. Brave Search وDDGS للبحث فقط؛ وSearXNG للبحث فقط مع سير عمل موثَّق "اقرنّي بمزوّد استخراج".

      شكل الاستجابة​

      يتوقع مغلّف الأداة مغلَّفًا (envelope) ثابتًا حتى لا يضطر إلى الترجمة بين الـ backends.

      نجاح البحث:

      {
          "success": True,
          "data": {
              "web": [
                  {"title": str, "url": str, "description": str, "position": int},
                  ...
              ],
          },
      }

      نجاح الاستخراج:

      {
          "success": True,
          "data": [
              {
                  "url": str,
                  "title": str,
                  "content": str,
                  "raw_content": str,
                  "metadata": dict,    # optional
                  "error": str,        # optional, only on per-URL failure
              },
              ...
          ],
      }

      أي من القدرتين، عند الفشل:

      {"success": False, "error": "human-readable message"}

      يمكن أن يكون كل من search() وextract() بصيغة async def — يكتشف المرسِل (dispatcher) دوال coroutine عبر inspect.iscoroutinefunction وينتظرها (await) وفق ذلك. التنفيذات المتزامنة التي تجري عمليات إدخال/إخراج حاجبة (HTTP، استدعاءات SDK) مناسبة للـ backends الصغيرة؛ يتولى المرسِل أمر الـ threading.

      علامات القدرة​

      يوجّه Hermes الاستدعاءات إلى المزوّد الصحيح استنادًا إلى علامات supports_*. إعداد شائع متعدد المزوّدين:

      # ~/.hermes/config.yaml
      web:
        search_backend: "brave-free"     # search-only, fast, free 2k/mo
        extract_backend: "firecrawl"     # extract + crawl, paid quota

      عندما لا يُضبَط web.search_backend أو web.extract_backend، يرجع كلاهما احتياطيًا إلى web.backend. وعندما لا يُضبَط ذلك أيضًا، يختار Hermes أول مزوّد متاح يدعم القدرة المطلوبة استنادًا إلى وجود متغير البيئة.

      إذا كان مزوّدك يدعم قدرة واحدة فقط، اترك العلامة الأخرى على قيمتها الافتراضية (False) وسيتجاوزه السجل لتلك الأداة — فلن يرى المستخدمون أخطاء "فشل المزوّد X" مضلِّلة عندما يستخدمون X للبحث فقط ويطلبون من الوكيل الاستخراج.

      كيف يربط Hermes ذلك بالأدوات​

      تعيش أداتا web_search وweb_extract في tools/web_tools.py. عند الاستدعاء، تقومان بـ:

      1. قراءة مفتاح الإعدادات المناسب (web.search_backend لـ web_search، وweb.extract_backend لـ web_extract)
      2. سؤال السجل عن المزوّد بذلك الاسم (name)
      3. التحقق من is_available() وعلامة supports_*() المطابقة
      4. الإرسال إلى search() / extract() (يعمل الزحف العميق كوضع داخل extract())، مع الانتظار (await) إذا كانت الدالة coroutine
      5. تسلسل الاستجابة إلى JSON وتسليمها إلى LLM

      تظهر الأخطاء كنتيجة الأداة؛ ويقرر LLM كيفية شرحها. إذا لم يكن هناك مزوّد مسجَّل (أو فشل كل المزوّدين المتاحين في اجتياز بوابة القدرة)، تعيد الأداة خطأً مفيدًا يشير إلى hermes tools.

      التثبيت الكسول للاعتماديات الاختيارية​

      إذا كان مزوّدك يغلّف SDK تابعًا لطرف ثالث (كما تفعل DDGS مع حزمة ddgs)، فلا تستورده (import) في أعلى الوحدة (module). استخدم tools.lazy_deps.ensure(...) داخل is_available() أو search() — سيُثبّت Hermes الحزمة عند أول استخدام، مقيّدًا بـ security.allow_lazy_installs. راجع بناء إضافة Hermes → التثبيت الكسول للنموذج الأمني.

      التنفيذات المرجعية​

      • plugins/web/brave_free/ — مزوّد HTTP صغير، مقيّد بمفتاح API، للبحث فقط. قالب بداية جيد.
      • plugins/web/ddgs/ — مزوّد بلا مفتاح يثبّت SDK الخاص به بشكل كسول. نمط مفيد للـ backends التي تغلّف حزمة Python.
      • plugins/web/firecrawl/ — مزوّد كامل متعدد القدرات (بحث + استخراج + زحف) مع أوضاع تنسيق متعددة.
      • plugins/web/searxng/ — backend مستضاف ذاتيًا، مُعدّ بالرابط، بلا مصادقة.
      • plugins/web/xai/ — بحث مدعوم بـ LLM عبر أداة web_search الخاصة بـ Grok من جهة الخادم. يوضح كيفية إعادة استخدام سطح بيانات اعتماد OAuth/متغير بيئة موجود مسبقًا (tools/xai_http.py) دون إضافة متغيرات بيئة جديدة، وكيفية كتابة is_available() رخيصة التكلفة تحترم عقد اللاشبكة (no-network).

      التوزيع عبر pip​

      # pyproject.toml
      [project.entry-points."hermes_agent.plugins"]
      my-backend-web = "my_backend_web_package"

      يجب أن تعرض my_backend_web_package دالة register على المستوى الأعلى. راجع التوزيع عبر pip في دليل الإضافات العام للإعداد الكامل.
