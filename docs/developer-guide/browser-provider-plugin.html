      بناء إضافة مزوّد متصفح (Browser Provider Plugin)

      تسجّل إضافات مزوّدي المتصفح backend متصفح سحابي يخدم استدعاءات أدوات browser_* في وضع السحابة (التنقّل، النقر، لقطة الشاشة، …). المزوّدون المدمجون — Browserbase، وBrowser Use، وFirecrawl — يُشحَنون جميعًا كإضافات تحت plugins/browser/<name>/. يمكنك إضافة واحد جديد، أو استبدال واحد مضمَّن، بوضع دليل بجانبها.

      نصيحة

      backends المتصفح أحد عدة إضافات backend يدعمها Hermes. البقية (ولكل منها صنفها المجرد الخاص) هي إضافات مزوّدي البحث في الويب (التي يحاكيها هذا الصنف المجرد عمدًا)، وتوليد الصور، وتوليد الفيديو، ومزوّدو الذاكرة، ومحركات السياق (Context Engines)، ومصادر الأسرار (Secrets)، ومزوّدو النماذج. إضافات الأدوات/الـ hooks/CLI العامة موجودة في بناء إضافة Hermes.

      كيف يترابط ذلك​

      مزوّد المتصفح لا ينفّذ التصفح. بل ينفّذ دورة حياة الجلسة: ينشئ جلسة متصفح بعيدة، ويعيد رابط WebSocket خاصًا بـ CDP، ويفكّك الجلسة. تتصل مجموعة المتصفح الخاصة بـ Hermes نفسها (agent-browser + tools/browser_tool.py) بأي رابط CDP تُعيده وتقود الصفحة من هناك — يحصل كل مزوّد على مجموعة أدوات browser_* الكاملة مجانًا.

      يُختار المزوّد النشط عبر browser.cloud_provider في config.yaml؛ والمرسِل (dispatcher) في tools/browser_tool.py هو مجرد بحث في سجل خالٍ من أي شروط خاصة بكل مزوّد.

      الاكتشاف​

      يفحص Hermes بحثًا عن backends المتصفح في ثلاثة أماكن:

      1. مضمّن (Bundled) — <repo>/plugins/browser/<name>/ (يُحمَّل تلقائيًا بـ kind: backend)
      2. المستخدم (User) — ~/.hermes/plugins/browser/<name>/ (اختياري عبر plugins.enabled أو hermes plugins enable <name>)
      3. Pip — حزم تعلن نقطة دخول hermes_agent.plugins

      تستدعي دالة register(ctx) الخاصة بكل إضافة ctx.register_browser_provider(...)، وهذا ما يضع النسخة في السجل الموجود في agent/browser_registry.py.

      هيكل الدليل​

      plugins/browser/my-backend/
      ├── __init__.py     # register() entry point
      ├── provider.py     # BrowserProvider subclass
      └── plugin.yaml     # Manifest with kind: backend and provides_browser_providers

      plugin.yaml:

      name: browser-my-backend
      version: 1.0.0
      description: "My cloud browser backend. Requires MY_BACKEND_API_KEY."
      author: you
      kind: backend
      provides_browser_providers:
        - my-backend

      __init__.py:

      from plugins.browser.my_backend.provider import MyBackendProvider


      def register(ctx) -> None:
          ctx.register_browser_provider(MyBackendProvider())

      الصنف المجرد BrowserProvider​

      نفّذ agent.browser_provider.BrowserProvider. ثلاث دوال لدورة الحياة بالإضافة إلى الهوية:

      from agent.browser_provider import BrowserProvider


      class MyBackendProvider(BrowserProvider):
          @property
          def name(self) -> str:
              return "my-backend"          # the browser.cloud_provider config value

          @property
          def display_name(self) -> str:
              return "My Backend"          # shown in `hermes tools`

          def is_available(self) -> bool:
              """Cheap check only — env var present, dep importable.
              NO network calls: runs at tool-registration time and on every
              `hermes tools` paint."""
              return bool(os.environ.get("MY_BACKEND_API_KEY"))

          def create_session(self, task_id: str) -> dict:
              """Create a remote browser session; return the session-metadata contract."""
              session = my_api.create_browser(...)
              return {
                  "session_name": f"my-backend-{task_id}",  # unique agent-browser session name
                  "bb_session_id": session.id,              # provider session ID (for cleanup)
                  "cdp_url": session.cdp_ws_url,            # CDP websocket URL
                  "features": {"stealth": True},            # feature flags you enabled
              }

          def close_session(self, session_id: str) -> bool:
              """Terminate by provider session ID. Log-and-return-False on error —
              never raise, so the dispatcher's cleanup loop keeps moving."""
              ...

          def emergency_cleanup(self, session_id: str) -> None:
              """Best-effort teardown from atexit/signal handlers. Must not raise."""
              ...

      عقد بيانات الجلسة الوصفية​

      يجب أن تُعيد create_session() على الأقل session_name، وbb_session_id، وcdp_url، وfeatures. غرابتان تستحقان المعرفة:

      • bb_session_id اسم مفتاح قديم (legacy) يُحتفَظ به حرفيًا للتوافق العكسي مع tools/browser_tool.py — ويحمل معرّف جلسة مزوّدك أنت بصرف النظر عن المزوّد التجاري. لا تُعِد تسميته.
      • create_session() يجوز أن تُطلق استثناءً — ValueError لبيانات اعتماد مفقودة، وRuntimeError لإخفاقات الشبكة/API. يُظهر المرسِل هذه للمستخدم. يختلف هذا عن close_session/emergency_cleanup، اللتين يجب ألا تُطلقا استثناءً أبدًا.

      مفتاح external_call_id الاختياري يدعم الفوترة عبر gateway مُدار.

      دالة get_setup_schema() — صف اختيار hermes tools​

      تجاوز (override) هذه الدالة لتظهر كخيار من الدرجة الأولى في مُنتقي التصفح الآلي (Browser Automation) مع مطالبات مفتاح API وربط تثبيت:

      def get_setup_schema(self) -> dict:
          return {
              "name": "My Backend",
              "badge": "paid",
              "tag": "Cloud browser with stealth and proxies",
              "env_vars": [
                  {"key": "MY_BACKEND_API_KEY",
                   "prompt": "My Backend API key",
                   "url": "https://mybackend.example"},
              ],
              "post_setup": "agent_browser",   # ensures local Chromium is installed (agent-browser itself resolves via npx)
          }

      وفق معيار المشروع لـ backends الأدوات: إذا تعذّر اختيار backend وضبطه عبر hermes tools، فهو غير مكتمل — "اضبط متغير البيئة هذا يدويًا" ليس تكاملًا.

      يضبطه المستخدمون​

      browser:
        cloud_provider: my-backend

      التنفيذات المرجعية​

      المزوّدون الثلاثة المضمّنون تحت plugins/browser/ هم الأمثلة المرجعية، بترتيب تصاعدي في التعقيد: firecrawl (الأبسط)، وbrowser_use، وbrowserbase (علامات ميزات تخفٍّ/بروكسي/إبقاء حي مع تدهور رشيق عندما تكون الميزات المدفوعة غير متاحة). انسخ الأقرب إليك.

      قائمة التحقق​

      • name بأحرف صغيرة وثابت (فهو قيمة إعدادات يكتبها المستخدمون)
      • is_available() لا تُجري أي استدعاءات شبكة
      • تُعيد create_session() عقد البيانات الوصفية الكامل (اسم مفتاح bb_session_id سليمًا)
      • close_session() / emergency_cleanup() لا تُطلقان استثناءً أبدًا
      • تعرض get_setup_schema() متغيرات بيئتك بحيث يمكن لـ hermes tools ضبط الـ backend
      • يعلن plugin.yaml عن kind: backend + provides_browser_providers
