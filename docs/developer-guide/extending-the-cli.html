      توسعة CLI

      يوفّر Hermes نقاط توسعة محمية (protected extension hooks) على HermesCLI بحيث يمكن لواجهات CLI المُغلِّفة (wrapper CLIs) إضافة عناصر واجهة (widgets) واختصارات لوحة مفاتيح وتخصيصات للتخطيط دون تجاوز (override) التابع run() أو بنية TUI في hermes_cli/cli_tui_mixin.py (حيث تُعرَّف هذه الـ hooks؛ ويدمجها HermesCLI في cli.py). هذا يبقي توسعتك منفصلة عن التغييرات الداخلية.

      نقاط التوسعة​

      هناك خمس نقاط توسعة (extension seams) متاحة:

      الـ Hookالغرضتجاوَزْه (override) عندما...
      _get_extra_tui_widgets()حقن عناصر واجهة (widgets) في التخطيطتحتاج عنصر واجهة دائمًا (لوحة، سطر حالة، مشغّل مصغّر)
      _register_extra_tui_keybindings(kb, *, input_area)إضافة اختصارات لوحة مفاتيحتحتاج مفاتيح سريعة (تبديل اللوحات، أزرار تحكم، اختصارات نمطية)
      _build_tui_layout_children(**widgets)تحكّم كامل في ترتيب عناصر الواجهةتحتاج إعادة ترتيب أو تغليف عناصر الواجهة الموجودة (نادر)
      process_command()إضافة أوامر slash مخصّصةتحتاج معالجة /mycommand الخاصة بك (hook موجود مسبقًا)
      _build_tui_style_dict()أنماط prompt_toolkit مخصّصةتحتاج ألوانًا أو تنسيقًا مخصّصًا (hook موجود مسبقًا)

      أول ثلاث نقاط هي hooks محمية جديدة. أما الاثنتان الأخيرتان فكانتا موجودتين مسبقًا.

      البدء السريع: واجهة CLI مُغلِّفة (wrapper)​

      #!/usr/bin/env python3
      """my_cli.py — Example wrapper CLI that extends Hermes."""

      from cli import HermesCLI
      from prompt_toolkit.layout import FormattedTextControl, Window
      from prompt_toolkit.filters import Condition


      class MyCLI(HermesCLI):

          def __init__(self, **kwargs):
              super().__init__(**kwargs)
              self._panel_visible = False

          def _get_extra_tui_widgets(self):
              """Add a toggleable info panel above the status bar."""
              cli_ref = self
              return [
                  Window(
                      FormattedTextControl(lambda: "📊 My custom panel content"),
                      height=1,
                      filter=Condition(lambda: cli_ref._panel_visible),
                  ),
              ]

          def _register_extra_tui_keybindings(self, kb, *, input_area):
              """F2 toggles the custom panel."""
              cli_ref = self

              @kb.add("f2")
              def _toggle_panel(event):
                  cli_ref._panel_visible = not cli_ref._panel_visible

          def process_command(self, cmd: str) -> bool:
              """Add a /panel slash command."""
              if cmd.strip().lower() == "/panel":
                  self._panel_visible = not self._panel_visible
                  state = "visible" if self._panel_visible else "hidden"
                  print(f"Panel is now {state}")
                  return True
              return super().process_command(cmd)


      if __name__ == "__main__":
          cli = MyCLI()
          cli.run()

      شغّلها:

      cd ~/.hermes/hermes-agent
      source .venv/bin/activate
      python my_cli.py

      مرجع الـ Hooks​

      _get_extra_tui_widgets()​

      يُعيد قائمة بعناصر واجهة prompt_toolkit لإدراجها في تخطيط TUI. تظهر عناصر الواجهة بين الفاصل (spacer) وشريط الحالة — أعلى منطقة الإدخال لكن أسفل المُخرَج الرئيسي.

      def _get_extra_tui_widgets(self) -> list:
          return []  # default: no extra widgets

      ينبغي أن يكون كل عنصر واجهة حاوية (container) من نوع prompt_toolkit (مثل Window أو ConditionalContainer أو HSplit). استخدم ConditionalContainer أو filter=Condition(...) لجعل عناصر الواجهة قابلة للتبديل (toggleable).

      from prompt_toolkit.layout import ConditionalContainer, Window, FormattedTextControl
      from prompt_toolkit.filters import Condition

      def _get_extra_tui_widgets(self):
          return [
              ConditionalContainer(
                  Window(FormattedTextControl("Status: connected"), height=1),
                  filter=Condition(lambda: self._show_status),
              ),
          ]

      _register_extra_tui_keybindings(kb, *, input_area)​

      يُستدعى بعد أن يُسجّل Hermes اختصاراته الخاصة وقبل بناء التخطيط. أضِف اختصاراتك إلى kb.

      def _register_extra_tui_keybindings(self, kb, *, input_area):
          pass  # default: no extra keybindings

      المعاملات:

      • kb — نسخة KeyBindings الخاصة بتطبيق prompt_toolkit
      • input_area — عنصر TextArea الرئيسي، إن احتجت إلى قراءة إدخال المستخدم أو التعامل معه
      def _register_extra_tui_keybindings(self, kb, *, input_area):
          cli_ref = self

          @kb.add("f3")
          def _clear_input(event):
              input_area.text = ""

          @kb.add("f4")
          def _insert_template(event):
              input_area.text = "/search "

      تجنّب التعارض مع اختصارات لوحة المفاتيح المدمجة: Enter (إرسال)، Escape Enter (سطر جديد)، Ctrl-C (مقاطعة)، Ctrl-D (خروج)، Tab (قبول الاقتراح التلقائي). مفاتيح الوظائف F2 وما بعدها وتركيبات Ctrl آمنة بشكل عام.

      _build_tui_layout_children(**widgets)​

      تجاوَزْ هذا فقط عندما تحتاج تحكّمًا كاملًا في ترتيب عناصر الواجهة. ينبغي لمعظم التوسعات استخدام _get_extra_tui_widgets() بدلًا من ذلك.

      def _build_tui_layout_children(self, *, sudo_widget, secret_widget,
          approval_widget, clarify_widget, model_picker_widget=None,
          spinner_widget=None, spacer, status_bar, input_rule_top,
          image_bar, input_area, input_rule_bot, voice_status_bar,
          completions_menu) -> list:

      التنفيذ الافتراضي يُعيد (يتم استبعاد أي عناصر واجهة قيمتها None):

      [
          Window(height=0),       # anchor
          sudo_widget,            # sudo password prompt (conditional)
          secret_widget,          # secret input prompt (conditional)
          approval_widget,        # dangerous command approval (conditional)
          clarify_widget,         # clarify question UI (conditional)
          model_picker_widget,    # model picker overlay (conditional)
          spinner_widget,         # thinking spinner (conditional)
          spacer,                 # fills remaining vertical space
          *self._get_extra_tui_widgets(),  # YOUR WIDGETS GO HERE
          status_bar,             # model/token/context status line
          input_rule_top,         # ─── border above input
          image_bar,              # attached images indicator
          input_area,             # user text input
          input_rule_bot,         # ─── border below input
          voice_status_bar,       # voice mode status (conditional)
          completions_menu,       # autocomplete dropdown
      ]

      مخطط التخطيط (Layout)​

      التخطيط الافتراضي من الأعلى إلى الأسفل:

      1. منطقة المُخرَج — سجلّ المحادثة القابل للتمرير
      2. الفاصل (Spacer)
      3. عناصر واجهة إضافية — من _get_extra_tui_widgets()
      4. شريط الحالة — النموذج، نسبة السياق، الوقت المنقضي
      5. شريط الصور — عدد الصور المُرفَقة
      6. منطقة الإدخال — طلب المستخدم (prompt)
      7. حالة الصوت — مؤشّر التسجيل
      8. قائمة الإكمال التلقائي — اقتراحات الإكمال التلقائي

      نصائح​

      • أعِد رسم العرض (invalidate) بعد تغيّرات الحالة: استدعِ self._invalidate() لإطلاق إعادة رسم من prompt_toolkit.
      • الوصول إلى حالة الوكيل: self.agent و self.model و self.conversation_history كلها متاحة.
      • أنماط مخصّصة: تجاوَزْ _build_tui_style_dict() وأضِف مُدخلات لفئات النمط المخصّصة الخاصة بك.
      • أوامر Slash: تجاوَزْ process_command()، وعالِج أوامرك، ثم استدعِ super().process_command(cmd) لكل شيء آخر.
      • لا تتجاوَزْ run() إلا إذا كان ذلك ضروريًا جدًا — إذ إن نقاط التوسعة (hooks) موجودة خصّيصًا لتجنّب هذا الترابط (coupling).
